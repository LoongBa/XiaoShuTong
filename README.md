# XiaoShuTong（小书童）

> AI 学习助手：基于 **AI 导师引导** + **艾宾浩斯记忆原理**的私域背记工具（背书搭子）。
> 由专业人士（老师/家长）提供高质量内容，AI 导师陪伴学生完成从模糊到熟练的记忆跃迁。
> 文档体系、目录结构、版本管理规则、文档模板，适用于一人或小团队 + AI Agent 协作的项目。

## 快速开始

### 第一步：确定子系统划分

`docs/3-开发迭代/` 下 A-子系统A / B-子系统B / C-子系统C 为占位目录，确定实际子系统后重命名，并同步更新 `docs/AGENTS.md`。

### 第二步：完善产品规划

在 `docs/0-产品规划/` 下创建：
- `竞品分析报告-V1.md`
- `用户画像-V1.md`
- `产品定位与差异化-V1.md`
- `商业模型画布-V1.md`

### 第三步：需求分析

需求分析 V3 已定稿：`docs/1-需求分析/V1/“小书童（背书搭子）”产品需求分析和设计-V3.md`（V1 基线）。
历史草稿与评估报告归档于 `docs/草稿/归档/`。

### 第四步：进入迭代

1. 需求分析 → `docs/1-需求分析/V1/`
2. 架构设计 → `docs/2-架构设计/V1/`
3. 开发迭代 → `docs/3-开发迭代/<子系统>/V1/`

## 版本管理一览

```
MinVer 风格：V{major}.{minor}.{patch}

大版本 V3→V4：建子目录隔离，旧版不删
小版本 V3.1.11→V3.1.12：同目录新增文件

开发方案命名：V3.1.11-采集频率优化-开发方案.md
审核报告命名：V3.1.11-采集频率优化-审核报告.md

Tag 纪律：必须有开发方案 + 审核报告，且征得同意
```
