# AGENTS.md - 小书童-平台管理系统 AdminWasm

> 本目录为 **Blazor WebAssembly 管理端**（群主/平台侧），`TKWFRole=ApiClient`，纯消费端项目。后端契约（Domain + WebApi）已就绪，本目录只做前端页面与 SG3 生成的 Api 调用代理调用。

## 项目定位

- **Blazor WebAssembly 管理端**（群主/平台），与 WebH5（React 学生端）并列的独立消费端。
- `TKWFRole=ApiClient`：**SG3 自动生成 Api 调用代理**（GraphQL），页面代码不直接接触传输层。
- 框架引用走 `$(TKWFDeployPath)build\refs\`（Dll 模式），另引用 Domain 项目 UserInfo 类型与 WebApi 元数据（`TKWFDomain=XiaoShuTong.WebApi`）。
- 编译前 `_EnsureWebApiMetadata` Target 会先构建 WebApi 生成 `.TKWF/XiaoShuTong.WebApi/ApiMetadata.g.cs`，SG3 消费该元数据生成代理——WebApi 源码变动会触发 AdminWasm 重建。

## 技术栈与 UI 模式

- **AntDesign.ProLayout**（BasicLayout）+ **AntDesign Pro 组件模式**（参考 `DMP-Lite.AdminUI` 页面写法），**不引入新 UI 库**。
- net10.0，`ScopedCssEnabled=true`，CSS 隔离产物构建后拷贝到 `wwwroot/`。
- 登录走 WASM 认证（`User/Login/Login.razor`），`Home.razor` 为占位欢迎页。

## 调用通道（关键）

- 数据访问一律 `DomainUser.Use<TService>()` 走 GraphQL 代理（SG3 封装），禁止手写 HttpClient / gql 字符串 / 手改生成代理文件。
- DTO 类型定义在 Domain 项目（Service 内联 record，字段注释齐全）；判错用 `res.Success == false` → 显示 `res.ErrorCode`。
- Service 接口名/方法签名以活态文档 `.TKWF/{域}/Domain_Api.md` 与 `DataService_API.md` 为准。

## 开发工具

- 本目录是 .NET 项目：`codemap`、`dotnet-analyzer` 等 .NET 类 MCP 可用（与 WebH5 的关闭策略相反）。
- 涉及 TKWF 机制（生成/DI/事务）问题先读 `Agents_Use_TKWF.md` 与 `%TKWFDeployPath%/AC-Kit/guides/Agent-TKWF使用行为守则.md`。

## Architecture

- **页面/路由/Service 清单**：完整映射见 `docs/平台管理系统-迭代计划.md` §〇（页面建成状态 13/13 + 4 超计划页）与 §一（后端 Service 映射表）。目录结构细节见 `docs/AGENTS-参考附录.md §1.2`。
- 关键入口路由统一挂 `/owner/*`（dashboard / groups/list / groups/detail/{id} / tasks/create / banks / platform/ai-models）。

## 版本纪律

- **独立版本线 `AdminWasm-V`**：csproj 覆盖 `<MinVerTagPrefix>AdminWasm-V</MinVerTagPrefix>`，与领域线（`v` 前缀）隔离互不干扰。
- **tag 必须征求用户同意**（tag = 版本发布确认），日常迭代只 push 不打 tag。
- AdminWasm-V0.1.0 已打 tag；实际沿 V0.1.x 功能线推进（当前 V0.1.8 全绿：345/0/2）。

## 生成物禁区

- ❌ 禁止读生成源码：`*.g.cs` / `*.biz.cs` / `DataServices\*.cs` / `Entities\*.cs`。
- ❌ 禁止手写 Controller / DI 注册 / gql 字符串 / 手改生成代理文件（`Generated\**` 已从编译排除）。
- ✅ DTO 字段以 Domain 项目 Service 源文件注释为准，方法签名以 `.TKWF/{域}/` 活态文档为准。
- ✅ 禁止降低守卫规则 Severity、删除 `[GeneratedBySg]`、修改 `// <auto-generated>`。

## 构建与验证
