# 判题 Prompt 库（设计文档 v1）

> 用途：AI 导师判题的大模型 Prompt 资产库，与题库配套使用
> 设计模式：策略模式（通用基线 + 题型专用，默认绑定 + 按级覆盖）
> 关联需求：V3 两层判题架构（本地关键词 → LLM 语义判题）、AI 判题接口契约

---

## 一、设计原则（评审确认 + 补充）

1. **输出 Schema 全局统一**：所有 Prompt 的 LLM 输出必须为统一 JSON 契约，上层代码只写一份解析逻辑：

```json
{
  "result": "correct | partial | wrong",
  "confidence": 0.92,
  "matched_keywords": ["唐太宗"],
  "missing_keywords": ["年号"],
  "hint": "提示：与年号有关"
}
```

2. **绑定优先级**（自高向低覆盖）：

```
单题级 > 题型级 > 题库级 > 全局默认
```

- 全局默认：通用判题 Prompt（兜底，所有题可用）
- 题库级：某题库默认绑定的 Prompt（如"古诗文默写库"绑定 S1-S4 题型集）
- 题型级：某题型（S1/S2/S3/S4）专用 Prompt
- 单题级：个别特殊题目单独绑定（如背景钩子趣味题）

3. **Prompt 版本管理**：每个 Prompt 带 `version` + `status`（草稿/活跃/已归档），变更需跑测试集回归。

4. **降级路由**（LLM 层之前的防线）：

```
本地关键词匹配（命中率 ≥80%）→ 直接判 correct，不调 LLM
命中率 <80% → 调 LLM（带对应 Prompt）
LLM 超时(>3s)/失败 → 降级本地规则引擎 + 提示用户
```

5. **测试集**：每个 Prompt 绑定 50-500 题校准集，评估判题准确率（目标 ≥95%），Prompt 迭代必须回归。

## 二、Prompt 文件索引

### 2.1 语文（题型级）

| 文件 | 类型 | 适用 |
|------|------|------|
| `通用判题-Prompt.md` | 通用基线 | 所有问答型题目（兜底） |
| `题型-R1-补全记忆.md` | 题型专用 | 语文 S1：上句接下句/名句填空 |
| `题型-R2-逆向补全.md` | 题型专用 | 语文 S2：下句接上句（逆向） |
| `题型-R3a-段落默写.md` | 题型专用 | 语文 S3：判段落完整性/顺序/关键词 |
| `题型-R3b-整篇默写.md` | 题型专用 | 语文 S4：判整篇完整性 |
| `背景钩子-提示生成-Prompt.md` | 专用（提示生成器） | "请提示我"交互，从背景钩子库提取线索（非判题） |
| `趣味点评-Prompt.md` | 专用（PK 赛后点评） | PK 挑战：AI 评分 + 趣味点评 + 错题知识彩蛋（非判题） |

### 2.2 英语（学科级）

| 文件 | 类型 | 适用 |
|------|------|------|
| `学科-english-R1R2-翻译判题.md` | 学科专用 | 英语 R1（英→中）/R2（中→英）翻译判题，双重容错 |
| `学科-english-R3aR3b-拼写判题.md` | 学科专用 | 英语 R3a/R3b 段落/整篇默写，拼写宽容判题 |

### 2.3 历史/地理（复用通用 + 规则判题）

历史和地理的判题策略为 `exact`（精确匹配），复用以下底座：

| 底座 | 说明 |
|------|------|
| `通用判题-Prompt.md` | 兜底 LLM 判题（条款/特征等非精确类） |
| `rule_grader.py` | O1-O5 客观题规则判题（零 LLM 成本，跨学科通用） |
| `题型注册表.json` | 13 题型注册，O 系列全部走规则判题 |
| `学科注册表.json` | 8 学科适配器配置（gradingPreference / knowledgeCardTemplate / promptOverrides） |

> R 系列（R1/R2）暂无学科专用 Prompt，使用通用判题兜底；历史/地理 R 系列为事实性知识，关键词匹配率通常 ≥80%，直接命中规则引擎即可判 correct，无需调用 LLM。

## 四、hint_level 与 V3 记忆状态机对齐

`hint_level` 是判题 Prompt 与"请提示我"交互、四阶记忆状态机的**连接信号**：

| hint_level | V3 交互 | 判题后状态变化 |
|-----------|---------|---------------|
| `none` | 用户独立作答 | 答对 → ○/★ 升级路径，答错 → ✕/△ |
| `partial` | 点击"请提示我"后作答 | 答对 → △（求助后答对，记忆不牢固） |
| `full` | 直接查看答案 | 不计入答题记录，不改变记忆状态 |

**协作流程**：背景钩子提示生成（出线索）→ 用户作答 → 判题 Prompt（带 hint_level）→ 状态机更新。
