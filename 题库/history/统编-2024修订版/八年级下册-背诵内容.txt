# ===== 第一单元 中华人民共和国成立和社会主义制度建立 =====

# 第1课 中华人民共和国成立
中国人民政治协商会议第一届全体会议召开的时间、地点和任务是？###1949年9月，在北平召开，完成了筹建新中国的工作（代行全国人民代表大会职权）
《共同纲领》的地位和规定是？###新中国的建国纲领，具有临时宪法的作用；规定中华人民共和国是新民主主义即人民民主主义的国家，实行工人阶级领导的、以工农联盟为基础的、团结各民主阶级和国内各民族的人民民主专政
政协一届全体会议作出的重要决定有？###定都北平并改名为北京；采用公元纪年；国歌未正式制定前以《义勇军进行曲》为国歌；以五星红旗为国旗；选举中央人民政府委员会（毛泽东为主席）；建立人民英雄纪念碑
开国大典的时间和"中国人民站起来"的意义是？###1949年10月1日下午3时，首都北京30万军民在天安门广场举行开国大典，毛泽东庄严宣告"中华人民共和国中央人民政府今天成立了"；新中国成立彻底结束了旧中国半殖民地半封建社会的历史，实现了从封建专制政治向人民民主的伟大飞跃，中国人民从此站起来了，中国发展从此开启了新纪元
西藏和平解放的时间和方式是？###1951年，中央人民政府代表与西藏地方政府代表团（以阿沛·阿旺晋美为首席代表）达成《中央人民政府和西藏地方政府关于和平解放西藏办法的协议》，西藏和平解放；同年10月人民解放军进驻拉萨，祖国大陆获得完全统一

# 第2课 巩固人民民主政权
土地改革的时间、法律依据和内容是？###1950年中央人民政府颁布《中华人民共和国土地改革法》，同年冬新解放区分批进行；规定废除地主阶级封建剥削的土地所有制，实行农民的土地所有制；到1952年底全国大陆基本完成
土地改革的意义是？###彻底摧毁了我国存在2000多年的封建土地制度，消灭了地主阶级；农民翻了身，得到土地，成为土地的主人；解放了农村生产力，为国家的工业化建设准备了条件
镇压反革命运动的时间和意义是？###1950年10月中共中央发出指示，12月镇压反革命运动在全国展开，到1951年10月底基本结束；扫除了国民党遗留在大陆的反革命残余势力，社会秩序获得前所未有的安定，有力地配合了土地改革和抗美援朝战争
抗美援朝的时间、统帅和结果是？###1950年10月，应朝鲜党和政府请求，组建以彭德怀为司令员兼政治委员的中国人民志愿军入朝作战，抗美援朝、保家卫国；经过艰苦卓绝的战斗，1953年7月美国不得不在停战协定上签字
抗美援朝战争的伟大意义和英雄人物是？###意义：抵御了帝国主义侵略扩张，捍卫了新中国安全，保卫了中国人民和平生活；稳定了朝鲜半岛局势，维护了亚洲和世界和平，彰显了新中国的大国地位；是中国人民站起来后屹立于世界东方的宣言书，是中华民族走向伟大复兴的重要里程碑；英雄人物：杨根思、黄继光、邱少云、罗盛教等30多万名英雄功臣，被誉为"最可爱的人"

# 第3课 社会主义制度建立
第一个五年计划的时间和基本任务是？###1953年开始执行；集中主要力量发展重工业，建立国家工业化和国防现代化的初步基础；相应发展交通运输业、轻工业、农业和商业，相应培养建设人才
第一个五年计划的重大成就有？###鞍山钢铁公司大型轧钢厂等三大工程、长春第一汽车制造厂、沈阳第一机床厂和飞机制造厂建成投产；新建宝成、鹰厦铁路，川藏、青藏、新藏公路通车；1957年武汉长江大桥建成；到1957年底超额完成，初步奠定了社会主义工业化的基础
三大改造的对象和方式是？###农业：把分散的个体农民组织起来，参加农业生产合作社；手工业：组织手工业生产合作社；资本主义工商业：以加工订货再到公私合营，国家对资本家占有的生产资料实行赎买政策，实现了和平过渡，是中国社会主义改造的创举
三大改造完成的时间和意义是？###1956年基本完成对生产资料私有制的社会主义改造，基本上实现生产资料公有制，建立起社会主义经济制度；社会主义制度在我国建立起来，是我国历史上最为广泛而深刻的社会变革，为我国一切进步和发展奠定了重要基础
1954年《中华人民共和国宪法》确立的政治制度是？###1954年9月第一届全国人民代表大会第一次会议通过《中华人民共和国宪法》（社会主义类型宪法）；以国家根本法的形式确立了人民代表大会制度（根本政治制度）；中国共产党领导的多党合作和政治协商制度、民族区域自治制度这两项基本政治制度的确立，为人民当家作主提供了制度保证

# 第4课 独立自主的和平外交
新中国三条外交方针的内容是？###"另起炉灶"（不承认国民党政府同各国建立的旧外交关系，取消帝国主义在华特权）；"打扫干净屋子再请客"（把帝国主义在中国的残余势力清除干净后再建交）；"一边倒"（明确宣布新中国站在社会主义和世界和平民主阵营一边）
苏联同中国建交的情况是？###1949年10月苏联第一个宣布承认中华人民共和国并与我国正式建交；1950年2月中苏签订《中苏友好同盟互助条约》，苏联贷款给中国3亿美元
和平共处五项原则提出的时间和内容是？###1953年底周恩来在接见印度代表团时首次提出；内容是互相尊重主权和领土完整、互不侵犯、互不干涉内政、平等互利、和平共处；成为中国对外政策的基石，是国际关系史上的重大创举
万隆会议的时间和"求同存异"方针是？###1955年周恩来率中国代表团参加在印度尼西亚万隆召开的亚非会议（第一次没有西方殖民主义国家参加的国际会议）；周恩来提出"求同存异"方针，会议通过《亚非会议最后公报》形成和平共处、友好合作的十项原则，取得圆满成功
新中国成立初期的重要外交成就（建交高潮）是？###成立后第一年里就同苏联等十几个国家建立外交关系，迎来第一次建交高潮；参加1954年日内瓦会议（第一次以五大国之一的身份）；1955年万隆会议"求同存异"

# ===== 第二单元 社会主义建设道路的探索 =====

# 第5课 艰辛探索与曲折发展
《论十大关系》的时间和意义是？###1956年毛泽东作《论十大关系》报告，提出把国内外一切积极因素全部调动起来，把我国建设成为一个强大的社会主义国家，是毛泽东关于怎样建设社会主义的根本指导思想
中共八大召开的时间和主要内容是？###1956年在北京举行；正确分析了国内主要矛盾，指出党和人民的主要任务是集中力量把我国尽快从落后的农业国变为先进的工业国；提出既反保守又反冒进、在综合平衡中稳步前进的经济建设方针；以《论十大关系》和中共八大为标志，中国共产党对社会主义建设道路的探索有了良好开端
"大跃进"和人民公社化运动的情况是？###1958年中共八大二次会议提出"鼓足干劲、力争上游、多快好省地建设社会主义"的总路线；随后全国掀起"大跃进"和人民公社化运动，急于求成、忽视客观经济规律，加上自然灾害，1959年至1961年国民经济发生严重困难
"八字方针"的内容和作用是？###1961年1月中共中央决定对国民经济实行"调整、巩固、充实、提高"的八字方针；到1965年调整任务基本完成，工农业生产恢复和发展
"文化大革命"的时间和结束是？###1966年夏全面发动起来；国家主席刘少奇被诬蔑为"叛徒、内奸、工贼"，成为文化大革命中最大的冤案；1971年"九一三事件"林彪反革命集团被粉碎；1976年10月粉碎江青反革命集团（"四人帮"），结束了长达十年之久的"文化大革命"；它的发动有复杂的社会历史原因，我们在探索中走了弯路

# 第6课 社会主义建设的巨大成就和先锋模范
这一时期工农业建设成就有？###建设了武汉、包头两大钢铁基地，建成大庆油田，开发建设胜利油田和大港油田；修建兰新、兰青、成昆等铁路；1965年实现原油和石油产品全部自给；建立起独立的比较完整的工业体系和国民经济体系
"两弹一星"的成就和意义是？###1964年10月16日第一颗原子弹爆炸成功；1966年第一次成功进行发射导弹核武器的试验；1967年第一颗氢弹爆炸成功；1970年用长征一号运载火箭成功发射第一颗人造地球卫星——东方红一号，成为世界上第五个能独立发射人造地球卫星的国家；打破了当时有核大国的核垄断和核讹诈，增强了我国的国防实力，大大提高了我国的国际地位
屠呦呦和袁隆平的贡献是？###屠呦呦1972年提取出青蒿素（全新化学结构的抗疟药），2015年获诺贝尔生理学或医学奖、2019年被授予"共和国勋章"；袁隆平1966年首次提出利用"三系法"培育杂交优势水稻，创建领先世界的超级杂交稻技术体系，2001年获国家最高科学技术奖、2019年被授予"共和国勋章"
民族区域自治制度和五个自治区是？###我国实行民族区域自治制度，民族自治地方分为自治区、自治州、自治县；内蒙古自治区1947年成立，随后新疆维吾尔自治区（1955.10）、广西壮族自治区（1958.3）、宁夏回族自治区（1958.10）和西藏自治区（1965.9）先后成立；民族地区还保护整理了《格萨尔王传》《江格尔》《玛纳斯》三大英雄史诗
艰苦奋斗的先锋模范和时代精神有？###钱学森、邓稼先、郭永怀等"两弹一星"元勋（两弹一星精神：热爱祖国、无私奉献、自力更生、艰苦奋斗、大力协同、勇于登攀）；"铁人"王进喜（大庆精神、铁人精神）；红旗渠精神；河南兰考县委书记焦裕禄（焦裕禄精神）；战士雷锋（1963年毛泽东发出"向雷锋同志学习"号召，雷锋精神）

# 第7课 国防现代化起步和外交工作新突破
新中国海军建设的成就是？###1949年4月第一支海军部队——华东军区海军建立，后建立东海、南海和北海舰队；1971年自行研制的导弹驱逐舰入列服役；1974年第一艘国产攻击型核潜艇交付部队
导弹部队（第二炮兵）是什么时候组建的？###1966年，导弹部队正式组建，被命名为第二炮兵部队，是中国实施战略威慑的核心力量
中国恢复在联合国合法席位的时间和意义是？###1971年10月，第26届联合国大会通过2758号决议，恢复中华人民共和国在联合国的一切合法权利，并立即把台湾当局"代表"从联合国及其一切所属机构中驱逐出去；是中国外交的重大胜利
中美关系走向正常化的经过是？###1971年7月基辛格秘密访问中国；1972年美国总统尼克松访华，毛泽东会见尼克松，双方于2月28日在上海发表《中美联合公报》，两国关系开始走向正常化
中日恢复邦交的情况是？###1972年日本首相田中角荣访华，中日两国实现邦交正常化；到1976年底，同中国建交国家达到111个

# 第8课 伟大的历史转折
真理标准问题大讨论的时间和意义是？###1978年5月《光明日报》公开发表《实践是检验真理的唯一标准》一文；在邓小平领导和叶剑英、胡耀邦等支持下展开大讨论，是一场深刻而广泛的思想解放运动；成为正本清源、拨乱反正和改革开放的思想先导
中共十一届三中全会召开的时间和主要内容是？###1978年12月在北京召开（邓小平《解放思想，实事求是，团结一致向前看》讲话是主题报告）；冲破长期"左"的错误的严重束缚，彻底否定"两个凡是"，果断结束"以阶级斗争为纲"，重新确立马克思主义的思想路线、政治路线、组织路线，作出把全党工作重点转移到社会主义现代化建设上来、实行改革开放的历史性决策
中共十一届三中全会的历史意义是？###开启了改革开放和社会主义现代化建设新时期，实现了新中国成立以来党的历史上具有深远意义的伟大转折
拨乱反正的标志性成果是？###1980年彻底推翻强加给刘少奇的种种罪名；1981年中共十一届六中全会通过《关于建国以来党的若干历史问题的决议》，标志着中国共产党在指导思想上的拨乱反正胜利完成
高考制度恢复的情况是？###1977年冬天进行高考制度恢复后的第一次考试，是教育工作的重大拨乱反正，为国家现代化建设培养了大批人才

# 第9课 改革开放的起步
农村家庭联产承包责任制的主要形式和意义是？###1978年安徽凤阳小岗村农民实行包干到户、自负盈亏；以包产到户、包干到户为主要形式，到1983年在农村普遍实行；激发了农民劳动热情，带来农村生产力的大解放，乡镇企业在农村"异军突起"
城市经济体制改革初步展开的措施是？###1979年首都钢铁公司等8家大型企业进行扩大企业自主权的试点；将企业的经济利益、职工的经济收入与企业经营成果联系起来，克服了吃"大锅饭"的弊病；支持城镇集体经济和个体经济发展
经济特区是哪年、哪些？###1980年，中央决定在广东、福建两省兴办深圳、珠海、汕头、厦门4个经济特区，实行特殊的经济政策和经济管理体制；兴办经济特区是党和国家为推进改革开放和社会主义现代化建设进行的伟大创举
20世纪80年代外交政策调整的情况是？###1978年中国同日本签订中日和平友好条约；1979年中美正式建立外交关系；1985年邓小平提出"和平和发展是当代世界的两大问题"论断；到1989年同中国建交的国家达到137个
我国对外开放的重大突破是？###对外开放的重大突破是兴办经济特区（1980年深圳、珠海、汕头、厦门），此后从经济特区到沿海开放城市、沿海经济开放区的开放格局逐步形成

# 第10课 改革开放和社会主义现代化建设的全面展开
中共十二大和"小康"目标的提出是？###1982年中共十二大在北京举行，邓小平提出"把马克思主义的普遍真理同我国的具体实际结合起来，走自己的道路，建设有中国特色的社会主义"；大会制定到20世纪末实现小康的奋斗目标（工农业年总产值翻两番）；1979年12月邓小平会见日本首相大平正芳时第一次使用"小康"概念
"一国两制"科学构想的内容是？###邓小平创造性地提出"一个国家，两种制度"：在一个中国的前提下，国家的主体坚持社会主义制度，香港、澳门、台湾保持原有的资本主义制度长期不变；"和平统一、一国两制"是完成祖国统一大业的基本方针
"一国两制"运用于解决港澳问题的结果？###1984年中英两国政府签署联合声明，确认中国政府于1997年7月1日对香港恢复行使主权；1987年中葡两国政府签署联合声明，宣布中国政府于1999年12月20日对澳门恢复行使主权
社会主义民主法制和精神文明建设的成就有？###1982年五届全国人大五次会议通过新修改的《中华人民共和国宪法》；1984年《民族区域自治法》颁布施行；20世纪80年代初"五讲四美三热爱"活动在全国展开；中国女排创下世界女子排球史上第一个五连冠，女排精神代表一个时代的精神
国防和军队现代化建设的情况是？###1981年邓小平提出建设强大的现代化正规化革命军队的总目标；1985年军队建设指导思想实行战略性转变，开展百万大裁军；1988年开始实行新的军官军衔制度

# 第11课 社会主义初级阶段基本路线
中共十三大的时间和理论贡献是？###1987年在北京举行；系统阐述了社会主义初级阶段理论；确立了党在社会主义初级阶段的基本路线，概括为"一个中心、两个基本点"（以经济建设为中心，坚持四项基本原则，坚持改革开放）；正式提出"三步走"发展战略

1988年、1990年扩大开放的重大举措是？###1988年海南省设立、海南经济特区建立；1990年中共中央作出开发开放上海浦东的重大决策
邓小平南方谈话的时间和主要内容是？###1992年初，邓小平到武昌、深圳、珠海、上海等地视察发表谈话：党的基本路线要管一百年，动摇不得；要抓住时机，发展才是硬道理；计划多一点还是市场多一点，不是社会主义与资本主义的本质区别，计划和市场都是经济手段；社会主义的本质是解放生产力、发展生产力、消灭剥削、消除两极分化、最终达到共同富裕；是把改革开放和社会主义现代化建设推向新阶段的又一个解放思想、实事求是的宣言书
