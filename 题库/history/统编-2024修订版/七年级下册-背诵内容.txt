# 七年级下册 历史 背诵内容测试题
# 教材：人教统编版 2024 修订版（4 单元 18 课）
# 格式：问题###答案（# 开头为注释）

# ===== 第一单元 隋唐时期 =====

# 第1课 隋朝的统一与灭亡
隋朝统一的时间和建立者是？###581年，杨坚（隋文帝）建立隋朝，定都长安
隋朝统一的意义是？###结束了魏晋南北朝以来长期分裂的局面，顺应了统一多民族国家的历史发展大趋势
隋朝大运河的概况是？###以洛阳为中心，北抵涿郡，南至余杭，连接海河/黄河/淮河/长江/钱塘江五大水系
大运河的作用是？###加强了南北地区政治、经济和文化交流
科举制创立的标志是？###隋炀帝时设立进士科
科举制的影响是？###加强了皇帝在选官和用人上的权力，扩大了官吏选拔范围，推动了教育的发展

# 第2课 唐朝的建立与"贞观之治"
唐朝建立的时间和建立者是？###618年，李渊（唐高祖）建立唐朝，定都长安
贞观之治的表现是？###政治比较清明，经济得到进一步发展，国力增强，文教昌盛
唐太宗的治国措施有？###吸取隋亡教训、虚心纳谏（魏征）、广纳贤才（房玄龄/杜如晖）、完善三省六部制
"开元盛世"的表现是？###政治稳定，经济繁荣，国库充盈，民众生活安定，唐朝进入鼎盛时期

# 第3课 盛唐气象
唐朝农业发展的表现是？###曲辕犁（耕地工具）、筒车（灌溉工具）
唐朝手工业发展的表现是？###唐三彩（闻名中外）、丝织业发达
文成公主入藏的意义是？###促进了吐蕃经济和社会的发展，增进了汉藏两族的友好关系
李白的诗歌特点是？###飘逸洒脱，充满想象力和感染力，具有浓郁的浪漫情怀，"诗仙"
杜甫的诗歌特点是？###反映了历史的真情实况，"诗史"，"诗圣"

# 第4课 唐朝的民族关系与对外交流
"天可汗"的含义是？###唐太宗得到周边各族的拥戴，被尊奉为"天可汗"
遣唐使的含义是？###日本为了学习中国先进文化，派遣到唐朝的使节
鉴真东渡的贡献是？###在日本传授佛经，还传播中国的医药、文学、书法、建筑、绘画等
玄奘西行的贡献是？###前往天竺取经，回国后译经，并著有《大唐西域记》

# 第5课 隋唐时期的科技与文化
雕版印刷术发明的时间是？###唐朝前期
火药开始应用于军事的时间是？###唐朝末年
敦煌莫高窟的地位是？###是世界上现存规模最大、内容最丰富的佛教艺术圣地

# ===== 第二单元 宋元时期 =====

# 第6课 北宋的政治
北宋建立的时间和建立者是？###960年，赵匡胤（宋太祖）建立北宋，定都东京（开封）
陈桥兵变的含义是？###赵匡胤在陈桥驿发动兵变，黄袍加身
重文轻武政策的影响是？###扭转了五代十国时期尚武轻文的风气，有利于政权的稳固和社会的安定

# 第7课 辽宋夏金元的并立与民族交融
澶渊之盟的内容是？###北宋与辽议和，宋给辽岁币，双方约为兄弟之国
岳飞抗金的事迹是？###率领岳家军收复许多失地，郾城大捷
绍兴和议的内容是？###南宋与金议和，南宋向金称臣，并给金岁币，双方以淮水至大散关一线为界
两宋时期民族关系的特点是？###民族政权并立，民族交融进一步发展

# 第8课 宋元时期的社会生活
宋代市民阶层的生活特点是？###城市繁荣，市民阶层壮大，文化娱乐活动丰富
瓦子和勾栏的含义是？###瓦子是娱乐兼营商业的场所，勾栏是瓦子中的演出场所
行省制度的内容是？###元朝在中央设中书省，地方设行中书省，简称"行省"
行省制度的影响是？###是我国省制的开端，加强了中央对地方的控制

# 第9课 宋元时期的经济与重心南移
经济重心南移完成的标志是？###南宋时，中央的财政收入主要来自南方，特别是东南地区
宋代海外贸易发达的表现是？###广州、泉州是闻名世界的大商港；政府设立市舶司管理海外贸易
宋代纸币的出现是？###北宋前期，四川地区出现"交子"，是世界上最早的纸币

# 第10课 宋元时期的科技与文化
活字印刷术的发明者是？###北宋毕昇
活字印刷术的影响是？###降低了制书成本，加快了图书的普及和文化的传播
指南针应用于航海的时间是？###北宋末年
火药广泛应用于军事的时间是？###宋元时期
宋词的代表人物有？###苏轼（豪放派）、李清照（婉约派）、辛弃疾（豪放派）
元曲的代表人物有？###关汉卿（《窦娥冤》）、马致远、郑光祖、白朴
《资治通鉴》的作者是？###司马光，是一部编年体通史巨著

# ===== 第三单元 明清时期 =====

# 第12课 明朝的建立与统一
明朝建立的时间和建立者是？###1368年，朱元璋（明太祖）建立明朝，定都应天府（南京）
废丞相的目的是？###加强皇权，使六部直接向皇帝负责
设锦衣卫的目的是？###监视官民，加强皇权
八股取士的影响是？###禁锢了人们的思想，阻碍了文化的发展
资本主义萌芽出现的表现是？###苏州等地出现"机户出资、机工出力"的雇佣关系

# 第13课 明朝的对外关系
郑和下西洋的概况是？###1405-1433年，郑和率船队七次下西洋，到达亚非30多个国家和地区
郑和下西洋的意义是？###增进了中国与亚非国家和地区的相互了解和友好往来
戚继光抗倭的事迹是？###率领戚家军在台州九战九捷，基本平息东南沿海倭患
戚继光抗倭的性质是？###一场反抗外来侵略的正义战争

# 第14课 明朝的科技、建筑与文学
《本草纲目》的作者是？###李时珍，是一部具有总结性的药物学巨著
《天工开物》的作者是？###宋应星，被誉为"中国17世纪的工艺百科全书"
《农政全书》的作者是？###徐光启，是一部农业百科全书
北京故宫的地位是？###是当时世界上最宏大、最辉煌的皇家建筑群
明长城的起止点是？###东起鸭绿江边，西至嘉峪关
《三国演义》的作者是？###罗贯中，是我国最早的一部长篇历史小说
《水浒传》的作者是？###施耐庵，是一部以农民起义为题材的长篇小说
《西游记》的作者是？###吴承恩，是一部充满浪漫主义气息的长篇神话小说

# 第15课 明朝的灭亡与清朝的建立
李自成起义的原因是？###明朝后期政治腐败，赋税沉重
李自成起义的口号是？###"均田免赋"
清朝建立的时间和建立者是？###1636年，皇太极改国号为清；1644年，清军入关
清朝巩固统一的措施有？###册封达赖/班禅、设置驻藏大臣、平定大小和卓叛乱、设置伊犁将军、收复台湾

# ===== 第四单元 明清时期的科技与文化 =====

# 第16课 清朝的科技与文化
《红楼梦》的作者是？###曹雪芹（前80回）、高鹗（后40回），是我国古典小说的高峰
《儒林外史》的作者是？###吴敬梓，是一部讽刺小说
京剧形成的时期是？###道光年间，徽剧和汉剧融合形成京剧

# 第17课 清朝的对外关系
闭关锁国政策的内容是？###严格限制对外贸易，只开放广州一处作为对外通商口岸
闭关锁国的影响是？###使中国逐渐落伍于世界历史的发展进程

# 第18课 统一多民族国家的巩固与发展
清朝对西藏的管理措施有？###册封达赖/班禅、设置驻藏大臣、建立金瓶掣签制度
清朝对新疆的管理措施有？###平定大小和卓叛乱、设置伊犁将军
清朝对台湾的管理措施有？###1684年设置台湾府，隶属福建省
清朝的疆域是？###西跨葱岭，西北达巴尔喀什湖，北接西伯利亚，东北至黑龙江以北的外兴安岭和库页岛，东临太平洋，东南到台湾及其附属岛屿，南至南海诸岛
