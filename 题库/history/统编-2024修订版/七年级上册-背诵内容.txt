# 第1课 远古时期的人类活动

北京人的体质特征是？###前额低平、眉骨粗大、颧骨突出、吻部前伸，脑容量比现代人小，能够直立行走
北京人使用火的证据和意义是？###遗址中发现灰烬、烧石、烧骨，说明北京人会使用火；学会用火是人类演化史上的里程碑
山顶洞人与北京人相比有哪些进步？###属于晚期智人，掌握磨光和钻孔技术，可能已知道人工取火，有爱美意识和埋葬死者的行为

# 第2课 原始农业与史前社会
我国原始农业起源的时间和标志是？###距今约1万年南北方出现人工栽培的农作物；目前已知世界上最早的栽培水稻、粟和黍均发现于我国
河姆渡人的生产和生活特征是？###距今约7000年，位于长江下游（浙江余姚），种植水稻，住干栏式房屋，使用骨耜，会制作陶器玉器
半坡人的生产和生活特征是？###距今约6000年，位于黄河流域（陕西西安半坡），种植粟和黍，住半地穴式房屋，制作彩陶，会纺织制衣
仰韶文化的重要特征是？###分布在黄河中游，距今约7000—5000年，以彩陶为主要特征，先民能养蚕缫丝制作丝织品
原始农业对古代文明形成的意义是？###原始农业为古代文明社会的形成奠定了重要基础，促进了定居生活

西周建立的关键战役是？###公元前1046年，周武王在牧野之战中击败商军，建立西周，定都镐京
分封制的内容是？###周王室根据血缘关系远近和功劳大小，将宗亲和功臣分封到各地，授予管理土地和民众的权力，建立诸侯国；诸侯须向周王进献贡赋、服从军队调遣
分封制确立的贵族等级是？###天子、诸侯、卿大夫、士

# 第5课 动荡变化中的春秋时期
春秋时期开始的标志是？###公元前770年，周平王将国都从镐京东迁洛邑，进入东周；东周前期为春秋时期
春秋时期政治格局的变化是？###周王室衰微，权威削弱，诸侯国各自为政，大国诸侯操控政治、竞相争霸
春秋时期的霸主有？###齐桓公、晋文公、楚庄王先后称霸；春秋末期吴国和越国先后北上争霸
春秋时期农业生产力提高的重要标志是？###铁制农具和牛耕的出现
春秋时期民族关系的发展是？###中原的"诸夏"与周边"戎""狄""蛮""夷"长期交往，产生了华夏认同观念

# 第6课 战国时期的社会变革
战国七雄是？###齐、楚、燕、韩、赵、魏、秦（晋国被韩、赵、魏三家大夫瓜分，齐国国君之位被田氏夺取）
商鞅变法的时间和成效是？###公元前356年，秦孝公任用商鞅主持变法；使秦国综合国力大为增强，一跃成为最强盛的诸侯国，为以后秦统一中国奠定了基础
商鞅变法的政治措施有？###确立县制由国君直接派官吏治理、废除贵族的世袭特权、建立户籍制度、严明法度禁止私斗
商鞅变法的经济措施有？###废除旧的土地制度、鼓励耕织（生产粮食布帛多者可免除徭役）、统一度量衡
都江堰的修建时间和作用是？###公元前256年，蜀郡郡守李冰在岷江上主持修建；发挥防洪、灌溉、水运等多方面作用，使成都平原成为"天府之国"

# 第7课 百家争鸣
老子的思想主张是？###道家学派创始人，思想核心是"道"；主张顺应事物规律、无为而治，认为事物都有对立面且能互相转化
孔子的思想核心和政治主张是？###儒家学派创始人，思想核心是"仁"，主张"仁者爱人"；政治上主张恢复西周礼乐文明，提出"为政以德"
孔子的教育贡献是？###兴办私学，主张有教无类，注重因材施教、举一反三，培养弟子三千
孟子和荀子的主张分别是？###孟子主张实行"仁政"，提出"民为贵，社稷次之，君为轻"；荀子主张实行礼治，提倡礼法并用
百家争鸣中主要学派及其代表人物是？###儒家（孔子/孟子/荀子）、道家（老子/庄子）、墨家（墨子）、法家（韩非）、兵家（孙武）
百家争鸣的历史意义是？###促进了思想文化的繁荣，成为我国古代第一次思想文化发展的高峰

# 第8课 夏商周时期的科技与文化
甲骨文的价值是？###商朝人刻在龟甲兽骨上的占卜文字，已经具备汉字的基本结构，是我国已发现的古代文字中年代最早、体系较为完整的成熟文字
我国有文字可考的历史始于哪个朝代？###商朝
青铜器的代表及地位是？###司母戊鼎（重832.84千克，是世界上出土最重的青铜器之一）、四羊方尊；金文记载有"宅兹中国"，是"中国"一词最早的实物见证
夏商周时期天文历法的成就有？###《诗经》记载了公元前776年的日食（传世文献中我国第一次有确切日期的日食记录）；战国时期把一年分为二十四节气
《诗经》和楚辞的地位是？###《诗经》是我国现存第一部诗歌总集（305篇，分风雅颂）；屈原创作楚辞，代表作《离骚》

# ===== 第三单元 秦汉时期：统一多民族封建国家的建立和巩固 =====

# 第9课 秦统一中国
秦灭六国的时间和意义是？###公元前230年起，不到十年先后攻灭韩、赵、魏、楚、燕、齐，公元前221年完成统一；建立起我国历史上第一个统一多民族的封建国家
秦朝中央集权制度的内容是？###最高统治者称皇帝，总揽全国大权；中央设丞相（行政）、太尉（军事）、御史大夫（监察）"三公"；地方废除分封制，实行郡县制（36郡）
郡县制的历史意义是？###郡县长官由朝廷直接任免，开创了此后我国历代王朝地方行政的基本模式
秦朝巩固统一的措施有？###统一文字（小篆）、统一货币（圆形方孔半两钱）、统一度量衡、统一车轨和道路宽度、开凿灵渠沟通湘江和漓江
秦朝疆域四至是？###东至东海，西到陇西，北至长城一带，南达南海

# 第10课 秦末农民大起义
秦朝暴政的表现有？###赋税沉重、连年大规模征调民力服徭役兵役、法律严苛、刑罚残酷，以及"焚书坑儒"禁锢思想
陈胜吴广起义的时间、地点和意义是？###公元前209年，在大泽乡爆发；是中国历史上第一次农民大起义，建立了张楚政权
秦朝灭亡的时间和经过是？###公元前207年，刘邦率军直抵咸阳，秦朝统治者被迫出城投降，秦朝灭亡
楚汉之争的双方和结果是？###项羽（西楚霸王）与刘邦（汉王）争夺国家统治权；双方在垓下决战，楚军战败，刘邦获胜

西汉建立的时间和建立者是？###公元前202年，刘邦建立汉朝，后定都长安，史称西汉
汉高祖休养生息政策的内容有？###让部分士兵还乡务农、释放奴婢为平民、实行轻徭薄赋（田租定为十五税一）、对匈奴采取和亲政策
"文景之治"的表现是？###政治清明，经济发展，人口增长，人民生活安定

# 第12课 大一统王朝的巩固
汉武帝削弱地方势力的措施有？###采纳主父偃建议实行"推恩令"（诸侯王可将封地分封给子弟，封地越来越小）；建立刺史制度（把全国划分为13个州部，派刺史监察）
汉武帝加强经济管控的措施有？###把铸币权收归中央统一铸造五铢钱、设盐铁官实行盐铁和酒的官营专卖、统一调配物资平抑物价
汉武帝尊崇儒术的措施和影响是？###接受董仲舒建议，把儒家学说立为正统思想；在长安兴办太学。儒学从此成为国家的统治思想
汉武帝北击匈奴的史实有？###公元前119年漠北战役，卫青、霍去病率精骑出击匈奴，大获全胜；西汉在河西走廊设置武威、张掖、酒泉、敦煌四郡
汉武帝巩固大一统的影响是？###从政治、经济、思想和军事等方面巩固了大一统的局面，使西汉王朝进入鼎盛时期

# 第13课 东汉的兴衰
东汉建立的时间和建立者是？###25年，刘秀称帝，后定都洛阳，史称东汉；刘秀即光武帝

东汉中后期政局动荡的原因是？###继位皇帝大多年幼，外戚与宦官交替专权，豪强大族势力膨胀
黄巾起义的时间、领导者和影响是？###184年，张角领导太平道徒起义，起义军头裹黄巾；沉重打击了东汉的统治，使其名存实亡

# 第14课 丝绸之路的开通与经营西域
张骞两次出使西域的时间和目的是？###公元前138年第一次出使（联络大月氏夹击匈奴，虽未达目的但了解了西域情况）；公元前119年第二次出使（访问乌孙等西域许多地方，促进了汉朝与西域的往来）
陆上丝绸之路的路线是？###从长安出发，穿过河西走廊，经西域运往中亚、西亚，再转运到欧洲和北非
丝绸之路的意义是？###是古代东西方往来的大动脉，促进了中国同其他国家和地区的贸易与文化交流
通过丝绸之路交流的物品有？###汉朝输出丝绸、漆器及开渠凿井铸铁等技术；西域传入核桃、葡萄、石榴、苜蓿、良种马、香料等
西域都护设立的时间和意义是？###公元前60年，西汉在乌垒城设置西域都护府；标志着西域正式归属中央政权
东汉经营西域的史实有？###73年班超出使西域，经营西域30多年；123年东汉改西域都护府为西域长史府

# 第15课 秦汉时期的科技与文化
造纸术的发明与改进是？###西汉时期已掌握造纸基本方法；105年东汉蔡伦改进造纸工艺，以树皮、麻头、破布、旧渔网为原料造纸，纸逐渐取代简帛
张仲景和华佗的医学贡献是？###张仲景著《伤寒杂病论》，是中医临床理论体系的开创者，被后世称为"医圣"；华佗发明"麻沸散"，创编"五禽戏"
《九章算术》和《氾胜之书》分别是？###《九章算术》最晚成书于东汉，是当时世界上先进的数学著作；《氾胜之书》总结农业生产经验，是秦汉农学代表作
《史记》的地位是？###司马迁著，是我国古代第一部纪传体通史，记述从传说中的黄帝到汉武帝时的史事

西晋建立和统一的过程是？###263年魏灭蜀；266年司马炎称帝建立西晋（定都洛阳）；280年西晋灭吴，统一全国
八王之乱的时间和影响是？###晋惠帝时八个宗室亲王争夺中央政权混战十余年；严重削弱西晋国力，成为西晋由盛而衰的转折点，出现我国古代历史上第一次大规模的人口迁徙

北方各族内迁的概况是？###东汉、魏、晋时期，匈奴、鲜卑、羯、氐、羌等北方民族不断内迁（氐羌入关中、匈奴羯入汾河流域、鲜卑入辽河流域与河套河西走廊）

# 第18课 东晋南朝政治和江南地区开发
东晋建立的时间和建立者是？###317年，皇族司马睿在建康重建晋王朝，史称东晋

南朝的朝代更替是？###420—589年，南方相继出现宋、齐、梁、陈四个朝代，都在建康定都，统称"南朝"
江南地区开发的原因是？###西晋末年起北方人大规模南迁，给江南输送了大量劳动力和中原先进的生产工具与技术
江南地区开发的表现在？###荒地开垦、兴修水利、水稻育秧移栽和麦稻兼作、缫丝织布制瓷冶铸等手工业进步、建康成为商业活跃的大都市

北魏孝文帝改革的影响是？###改善和巩固了鲜卑拓跋部与汉人的关系，促进了民族交融
北方民族交融的意义是？###北方出现各族大交融，为中华民族发展注入新的活力，为隋唐时期统一多民族国家的发展奠定了基础

# 第20课 三国两晋南北朝时期的科技与文化
贾思勰的贡献是？###北朝贾思勰撰写《齐民要术》，是我国现存最早的一部完整的农书，总结农、林、牧、副、渔生产技术
祖冲之的贡献是？###南朝祖冲之把圆周率精确到小数点以后第七位（3.1415926—3.1415927之间），领先世界近千年；创制《大明历》，制造指南车、水碓磨、千里船
王羲之和顾恺之的成就是？###东晋王羲之代表作《兰亭集序》被称为"天下第一行书"，被后人誉为"书圣"；东晋顾恺之代表作《女史箴图》《洛神赋图》
著名的石窟艺术有？###山西大同云冈石窟、河南洛阳龙门石窟，继承秦汉雕塑传统并吸收外来佛教造型艺术特点
郦道元的贡献是？###北魏郦道元著《水经注》，记载1252条河流，是一部综合性的地理学著作
