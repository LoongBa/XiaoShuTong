# 七年级上册 历史 背诵内容测试题
# 教材：人教统编版 2024 修订版（4 单元 18 课）
# 格式：问题###答案（# 开头为注释）

# ===== 第一单元 史前时期 =====

# 第1课 中国境内早期人类的代表
中国境内已确认的最早古人类是？###元谋人（距今约170万年）
北京人的特征是？###保留了猿的某些特征，能够制造和使用工具，使用天然火，过群居生活
山顶洞人掌握了哪些技术？###磨制技术、钻孔技术、人工取火
旧石器时代与新石器时代的区别是？###旧石器时代使用打制石器，新石器时代使用磨制石器

# 第2课 原始农耕生活
河姆渡人的生活特征是？###长江流域，种植水稻，住干栏式房屋，使用磨制石器
半坡人的生活特征是？###黄河流域，种植粟，住半地穴式房屋，使用磨制石器
河姆渡人与半坡人的相同点是？###都使用磨制石器，都从事原始农业，都过定居生活
原始农业兴起的标志是？###农作物种植、家畜饲养、聚落出现、磨制石器

# 第3课 远古的传说
华夏族的由来是？###炎帝和黄帝部落联盟逐渐融合而成
禅让制的含义是？###将部落首领位置传给贤德之人
黄帝的贡献有？###建造宫室、制作衣裳、挖掘水井、制造船只、发明指南车
炎帝的贡献有？###教民开垦耕种、制作生产工具、发明纺织、煮盐、通商交换

# ===== 第二单元 夏商周时期 =====

# 第4课 夏商西周的更替
夏朝建立的时间和建立者是？###约公元前2070年，禹建立夏朝
世袭制代替禅让制的标志是？###禹死后，启继承父位，"家天下"代替"公天下"
商朝的青铜器代表有？###司母戊鼎（最大）、四羊方尊（精美）
分封制的内容是？###周天子将土地和人民分封给诸侯，诸侯服从周天子命令，镇守疆土
分封制的作用是？###巩固了西周的统治，扩大了统治范围

# 第5课 青铜器与甲骨文
甲骨文的历史价值是？###是中国已发现的古代文字中年代最早、体系较为完整的文字
甲骨文的造字方法有？###象形、指事、会意、形声、假借
青铜器的功能变化是？###由食器等发展到礼器，成为王公贵族象征身份地位乃至国家权力的代表性器物
司母戊鼎的地位是？###迄今世界上出土的最重的青铜器

# 第6课 动荡的春秋时期
春秋时期经济发展的表现是？###铁制农具和牛耕出现，促进了农业上的深耕细作
诸侯争霸的原因是？###王室衰微，诸侯势力强大，竞相称霸
春秋五霸中最著名的霸主是？###齐桓公（首霸）、晋文公、楚庄王
春秋争霸的影响是？###给社会带来灾难，但在客观上促进了民族交融

# 第7课 战国时期的社会变化
战国七雄是？###齐、楚、秦、燕、赵、魏、韩
商鞅变法的内容有？###废井田开阡陌、奖励耕战、建立县制、废除贵族世袭特权
商鞅变法的影响是？###使秦国国力大增，为以后秦统一全国奠定了基础
都江堰的作用是？###防洪、灌溉、水运，使成都平原成为"天府之国"

# 第8课 百家争鸣
老子的思想主张是？###道家学派创始人，主张"无为而治"，认为事物都有对立面
孔子的思想主张是？###儒家学派创始人，核心思想"仁"，主张"以德治国"，创办私学
百家争鸣的学派有？###儒家（孔子/孟子）、道家（老子/庄子）、墨家（墨子）、法家（韩非）
百家争鸣的意义是？###促进了思想和学术的繁荣，成为中国古代第一次思想文化发展的高峰

# ===== 第三单元 秦汉时期 =====

# 第9课 秦统一中国
秦灭六国的顺序是？###韩→赵→魏→楚→燕→齐（前230-前221年）
秦统一的意义是？###结束了春秋战国以来长期争战混乱的局面，建立起我国历史上第一个统一的多民族的封建国家
中央集权制度的内容是？###最高统治者称皇帝，中央设丞相/太尉/御史大夫，地方推行郡县制
巩固统一的措施有？###统一文字（小篆）、统一货币（圆形方孔半两钱）、统一度量衡

# 第10课 秦末农民大起义
陈胜吴广起义的原因是？###秦的暴政（赋税沉重、徭役兵役繁重、刑法残酷）
陈胜吴广起义的历史意义是？###是中国历史上第一次大规模的农民起义
楚汉之争的双方是？###刘邦（汉王）与项羽（西楚霸王）
秦朝灭亡的时间是？###公元前207年

# 第11课 西汉建立和"文景之治"
西汉建立的时间和建立者是？###公元前202年，刘邦建立西汉，定都长安
休养生息政策的内容是？###减轻农民徭役、兵役和赋税负担，注重发展农业生产
文景之治的表现是？###政治清明，经济发展，人民生活安定，国力增强
汉初统治者采取休养生息政策的原因是？###吸取秦亡教训，社会经济凋敝

# 第12课 汉武帝巩固大一统王朝
推恩令的作用是？###削弱了诸侯王的势力，加强了中央集权
"罢黜百家，独尊儒术"的建议者是？###董仲舒
盐铁专卖的目的是？###控制国家经济命脉，增加财政收入
汉武帝大一统的影响是？###西汉王朝开始进入鼎盛时期

# 第13课 东汉的兴衰
光武中兴的措施是？###释放奴婢、减轻农民负担、合并郡县裁减官员
黄巾起义的领导者是？###张角（太平道）
黄巾起义的影响是？###沉重打击了东汉的统治，使其名存实亡
东汉衰落的原因是？###外戚宦官交替专权

# 第14课 沟通中外文明的"丝绸之路"
张骞第一次出使西域的目的和结果是？###联络大月氏夹击匈奴，未能达到目的，但了解了西域情况
丝绸之路的路线是？###长安→河西走廊→西域→中亚→西亚→欧洲（大秦）
丝绸之路的历史意义是？###是古代东西方往来的大动脉，促进了东西方经济文化交流
西域都护设立的时间和意义是？###公元前60年，标志着西域正式归属中央政权

# ===== 第四单元 三国两晋南北朝时期 =====

# 第15课 三国两晋南北朝的政权更迭
官渡之战的交战双方和结果是？###曹操vs袁绍，曹操以少胜多
赤壁之战的交战双方和结果是？###曹操vs孙刘联军，孙刘联军以少胜多
三国鼎立形成的标志是？###220年曹丕建魏、221年刘备建蜀、229年孙权建吴
淝水之战的交战双方和结果是？###前秦vs东晋，东晋以少胜多
北魏孝文帝改革的内容是？###迁都洛阳、穿汉服、说汉话、改汉姓、与汉族通婚
北魏孝文帝改革的影响是？###促进了民族交融，增强了北魏的实力

# 第16课 三国两晋南北朝的科技与文化
祖冲之的贡献是？###把圆周率精确到小数点后第七位，领先世界近千年
贾思勰的贡献是？###著有《齐民要术》，是我国现存最早的一部完整的农书
郦道元的贡献是？###著有《水经注》，是一部综合性的地理学著作
王羲之的代表作是？###《兰亭集序》，被称为"天下第一行书"
