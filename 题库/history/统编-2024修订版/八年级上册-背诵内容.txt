# ===== 第一单元 中国开始沦为半殖民地半封建社会 =====

# 第1课 鸦片战争
鸦片战争前英国向中国走私鸦片的原因和影响是？###原因：英国工业品在中国滞销，为开辟海外市场掠夺原料；影响：白银大量外流威胁清政府财政，官员士兵吸食鸦片导致政治腐败和军队战斗力削弱
虎门销烟的时间、主持人和意义是？###1839年6月3日至25日，林则徐主持在虎门海滩当众销毁鸦片（110多万千克）；是中国人民禁烟斗争的伟大胜利，显示了中华民族反抗外来侵略的坚强意志
鸦片战争爆发的时间和经过是？###1840年6月英国舰队封锁广东珠江口，鸦片战争爆发；英军攻陷定海、进抵大沽口威胁清廷，后转攻东南沿海，1842年8月初到达南京下关江面，清政府屈服
《南京条约》的主要内容是？###开放广州、福州、厦门、宁波、上海五处为通商口岸；割香港岛给英国；赔偿英国2100万银元；英商进出口货物应纳的税款必须经过双方协议
鸦片战争对中国社会的影响是？###改变了中国历史发展的进程；中国独立主权的完整性遭到破坏，传统的小农经济逐步瓦解，中国开始沦为半殖民地半封建社会；鸦片战争成为中国近代史的开端

# 第2课 第二次鸦片战争
第二次鸦片战争的时间、借口和发动者是？###1856年10月至1860年；英法在俄美两国支持下，分别以"亚罗号事件"和"马神甫事件"为借口对中国发动
《天津条约》的主要内容是？###外国公使进驻北京；增开汉口、南京等十处通商口岸；外国商船和军舰可以在长江各口岸自由航行；英法获巨额赔款
火烧圆明园的时间及《北京条约》的主要内容是？###1860年10月英法联军大肆抢劫并火烧圆明园；《北京条约》承认《天津条约》有效，增开天津为通商口岸，割九龙半岛南端给英国，赔款额大幅增加
第二次鸦片战争期间俄国侵占中国北方领土的情况是？###沙俄先后割占中国东北100多万平方千米、西北44万多平方千米领土，从19世纪50年代到80年代共割占150多万平方千米
第二次鸦片战争的影响是？###中国丧失更多主权，西方侵略势力由东南沿海一带深入长江中下游地区，俄国侵占中国北方大片领土，中国的半殖民地化程度进一步加深

# 第3课 太平天国运动
太平天国运动爆发的标志是？###1851年1月11日，洪秀全在广西桂平金田村发动武装起义，建号太平天国，起义军称太平军
太平天国定都天京的时间和《天朝田亩制度》的内容是？###1853年3月太平军攻占南京并将南京改名天京作为都城；《天朝田亩制度》规定不分男女按人口和年龄平均分配土地，反映了农民要求得到土地的强烈愿望，但带有浓厚空想色彩未能推行
太平天国由盛转衰的标志和原因是？###1856年秋的天京事变；东王杨秀清逼封"万岁"意图篡位引发内斗，杨秀清被杀、韦昌辉被处死、石达开率部出走，太平军损失惨重
太平天国运动失败的时间和标志是？###1864年夏天京陷落，标志着太平天国运动失败；运动坚持14年，转战大半个中国，沉重打击了清朝的统治和外国侵略势力
太平天国运动失败的原因是？###农民阶级的局限性：无法提出切合实际的革命纲领，无法制止和克服领导集团的腐败，无法长期保持领导集团的团结；在中外反动势力联合镇压下最终失败

# ===== 第二单元 早期现代化的初步探索和民族危机加剧 =====

# 第4课 洋务运动和边疆危机
洋务运动的时间、口号和代表人物是？###从19世纪60年代到90年代中期；以"自强""求富"为口号；中央以恭亲王奕䜣为代表，地方以曾国藩、李鸿章、左宗棠、张之洞为代表
洋务派创办的军事工业和民用企业各有哪些？###军事工业：江南机器制造总局、福州船政局等；民用企业：轮船招商局、开平煤矿、汉阳铁厂、湖北织布局等
洋务运动的结果和客观作用是？###求强求富的目标没有实现（清朝政治的腐败和外国势力的挤压）；在客观上促进了中国民族资本主义的产生，是中国早期现代化的初步探索
左宗棠收复新疆的经过是？###1875年清政府任命左宗棠督办新疆军务，采取先北后南、缓进急战的策略，1878年消灭阿古柏侵略势力，收复除伊犁地区以外的新疆领土
中法战争中的重要战役和结果是？###1884年马尾海战福建水师大部被击沉；1885年冯子材取得镇南关大捷，扭转战局；此后清政府签订《越南条款》，承认越南受法国"保护"，法国的势力侵入中国云南、广西

# 第5课 甲午中日战争与列强瓜分中国狂潮
甲午中日战争的导火索和标志性战役是？###1894年朝鲜东学党起义，日本乘机出兵蓄意挑起战争（1894年为农历甲午年）；黄海海战中邓世昌、林永升壮烈殉国；1895年初威海卫之战北洋舰队全军覆没
《马关条约》签订的时间和主要内容是？###1895年清政府被迫与日本签订；规定割辽东半岛、台湾全岛及所有附属各岛屿、澎湖列岛给日本；赔偿日本军费白银2亿两；开放沙市、重庆、苏州、杭州为通商口岸；日本可在中国通商口岸开设工厂
《马关条约》的影响是？###使中国的领土主权遭到严重破坏；巨额赔款迫使清政府大举外债；外国侵略势力深入中国腹地，通过投资办厂加紧对华资本输出；中国的半殖民地化程度大大加深
列强瓜分中国狂潮的表现是？###三国干涉还辽后，列强以"赎辽费"为契机，在中国掀起抢夺路矿利权、强租租借地、划分"势力范围"的瓜分狂潮；1899年美国提出"门户开放"照会
民族资本主义初步发展的表现是？###甲午中日战争后清政府放松了对民间设厂的限制，民族资本主义得到初步发展；状元实业家张謇创办大生纱厂，带动很多人走上"实业救国"道路

# 第6课 戊戌变法
公车上书的时间和意义是？###1895年春《马关条约》签订消息传出后，康有为、梁启超联合各省应试举人上书光绪帝，请求拒和、迁都、变法；拉开了维新运动的序幕
维新运动中影响较大的报刊和著作是？###上海《时务报》（梁启超发表《变法通议》）、天津《国闻报》（严复主持）；严复翻译《天演论》，宣传"物竞天择""适者生存"
百日维新开始的时间和主要措施是？###1898年6月11日光绪帝颁布"明定国是"诏书宣布变法；政治（裁撤冗官冗员、允许士民上书言事）、经济（鼓励私人兴办工矿企业、改革财政编制国家预算）、教育（废除八股文改试策论、创办京师大学堂）、军事（裁减绿营、训练新式军队）
戊戌政变和"戊戌六君子"是？###1898年9月21日慈禧太后发动政变，软禁光绪帝，搜捕维新人士，废除变法诏令；谭嗣同、刘光第、林旭、杨锐、杨深秀、康广仁六人被捕遇害，史称"戊戌六君子"
戊戌变法的历史意义是？###是中国近代第一次思想解放运动，也是资产阶级改良运动；促进了思想启蒙和民族意识的觉醒，对近代教育和报刊事业的发展产生长远影响

# 第7课 义和团运动和八国联军侵华
义和团运动的兴起和口号是？###由山东、直隶一带的义和拳、民间秘密结社和练拳习武组织发展而来，主要成员是农民，1898年10月冠县起义揭开序幕；提出"扶清灭洋"口号
"扶清灭洋"口号的评价是？###"灭洋"鲜明表达了中国人民反对帝国主义的斗争意志，但具有盲目排外的落后性；"扶清"反映出义和团对清政府本质认识不清
八国联军侵华的时间和义和团抗击的情况是？###1900年6月，英、美、法、德、俄、日、奥匈、意八国组织联军2000多人进犯北京；义和团在廊坊一带阻击联军，后在天津保卫战中直隶提督聂士成殉国；1900年8月14日八国联军攻陷北京
《辛丑条约》签订的时间和主要内容是？###1901年9月清政府与英、美、法、德、俄、日、奥匈、意、西、荷、比11国签订；主要内容：惩办"首祸诸臣"、停止科举考试5年；赔款白银4.5亿两，分39年还清；划定东交民巷为使馆界；拆毁大沽炮台、允许外国军队驻扎北京到山海关铁路沿线要地；严禁人民参加反帝活动；改总理衙门为外务部
《辛丑条约》的影响是？###是中国近代史上赔款数目最庞大、主权丧失最严重的不平等条约；清政府成为帝国主义列强统治中国的工具，中国完全陷入半殖民地半封建社会的深渊

# ===== 第三单元 资产阶级民主革命与中华民国的建立 =====

# 第8课 中国同盟会
兴中会成立的时间和纲领是？###1894年11月，孙中山在檀香山联合华侨成立兴中会，提出"振兴中华"，号召"驱除鞑虏，恢复中国，创立合众政府"；是中国第一个资产阶级革命团体
宣传资产阶级革命思想的著作有？###章炳麟《驳康有为论革命书》、邹容《革命军》、陈天华《猛回头》和《警世钟》
中国同盟会成立的时间、纲领和意义是？###1905年8月，孙中山联合兴中会、华兴会、光复会等在日本东京成立中国同盟会；政治纲领为"驱除鞑虏，恢复中华，创立民国，平均地权"；是第一个全国规模的、统一的资产阶级革命政党
三民主义的内容是？###孙中山在《民报》发刊词中将同盟会政治纲领阐发为民族主义（推翻清王朝统治、反对民族压迫）、民权主义（推翻君主专制政体、建立资产阶级民主共和国）、民生主义（平均地权），是为"三民主义"，是孙中山领导资产阶级革命的指导思想
革命党人发动的武装起义有？###1906年萍浏醴起义（同盟会成立后领导的第一次武装起义）、1907年徐锡麟安庆起义和秋瑾就义、1911年4月黄花岗起义（黄兴领导，收殓烈士遗骸72具合葬于黄花岗）

# 第9课 辛亥革命
武昌起义的时间和结果是？###1911年10月10日晚，武昌城内新军工程营的革命党人首先起义，一夜之间占领武昌，汉阳、汉口的新军起义响应；10月11日成立湖北军政府，推举黎元洪为都督；各省纷纷响应，一半以上省份宣布独立
辛亥革命名称的由来是？###1911年是农历辛亥年，历史上称这次革命为"辛亥革命"
中华民国建立的时间和标志是？###1912年1月1日，孙中山在南京宣誓就任中华民国临时大总统，宣告中华民国临时政府成立，以1912年为中华民国元年，改用阳历
《中华民国临时约法》的主要内容和地位是？###规定中华民国的主权属于全体国民；国民不分种族、阶级、宗教信仰一律平等，享有人身、言论、出版、集会、结社等自由和权利；参议院行使立法权，法院行使司法权、司法独立；是中国历史上第一部具有资产阶级共和国宪法性质的重要文件
辛亥革命的历史意义和局限性是？###意义：推翻了清王朝的统治，宣告了中国两千多年君主专制制度的终结，拉开了中国完全意义上的近代民族民主革命的序幕，极大推动了中华民族的思想解放；局限性：没有解决近代中国社会的主要矛盾，没有完成民族独立、人民解放的历史任务，中国半殖民地半封建的社会性质没有改变

# ===== 第四单元 新民主主义革命的兴起 =====

# 第10课 帝制复辟与军阀割据
袁世凯复辟帝制的步骤有？###强迫国会选举他为正式大总统、解散国民党、解散国会、废除《中华民国临时约法》颁布《中华民国约法》改内阁制为总统制；1915年接受日本"二十一条"的大部分内容；1915年底下令改中华民国为中华帝国，年号"洪宪"
护国战争的过程和结果是？###1915年底，唐继尧、蔡锷、李烈钧在云南宣告独立，组织护国军北上讨袁；袁世凯众叛亲离，1916年3月被迫宣布取消帝制，6月在绝望中死去
袁世凯死后军阀割据的局面是？###以冯国璋、曹锟为首的直系控制直隶、江苏、江西、湖北等省；以段祺瑞为首的皖系掌握北京政府；奉系军阀张作霖盘踞东北；滇系唐继尧、桂系陆荣廷等盘踞南方各省
军阀割据的危害是？###各派军阀为争夺地盘不惜出卖国家利益、依附帝国主义，大小军阀连年混战，中国陷入军阀割据纷争的动乱之中

# 第11课 五四运动
新文化运动兴起的时间、标志和口号是？###1915年，陈独秀在上海创办《青年杂志》（后改名《新青年》），新文化运动由此发端；基本口号是提倡民主和科学（"德先生"和"赛先生"），抨击旧道德和旧文化
新文化运动的主要阵地和代表作品是？###北京大学和《新青年》编辑部成为主要阵地；李大钊《孔子与宪法》、鲁迅《狂人日记》、胡适《文学改良刍议》、陈独秀《文学革命论》
五四运动的导火索是？###1919年巴黎和会上中国外交失败：列强操纵会议，将德国在中国山东的特权全部转让给日本
五四运动的经过和口号是？###1919年5月4日，北京大学等校3000多名学生汇集天安门前示威游行，提出"外争主权、内除国贼""誓死力争、还我青岛""取消二十一条"等口号；6月5日后上海工人罢工、商人罢市，工人阶级成为运动主力，运动中心由北京转移到上海
五四运动的历史意义是？###是一场以先进青年知识分子为先锋、广大人民群众参加的彻底反帝反封建的伟大爱国革命运动；促进了马克思主义在中国的传播及其与中国工人运动的结合，为中国共产党成立做了思想上干部上的准备；是中国旧民主主义革命走向新民主主义革命的转折点；五四精神的核心是爱国主义精神

# 第12课 中国共产党诞生
马克思主义在中国传播的代表人物是？###李大钊发表《庶民的胜利》《我的马克思主义观》等文章，系统介绍马克思主义；1920年8月陈望道翻译的《共产党宣言》中文全译本在上海出版
中国共产党第一次全国代表大会的时间和内容是？###1921年7月23日在上海开幕（后转移到浙江嘉兴南湖游船举行）；确定党的名称为"中国共产党"，通过第一个纲领，明确党的奋斗目标是推翻资产阶级政权、建立无产阶级专政、实现共产主义；确定党的中心工作是领导和组织工人运动，成立中央局，陈独秀当选为中央局书记
中国共产党诞生的历史意义是？###是中国历史上开天辟地的大事变；自从有了中国共产党，中国革命的面貌就焕然一新了；中国共产党的创建形成了伟大建党精神
中共二大的内容和意义是？###1922年7月在北京（上海）举行，制定党的最低纲领：在民主革命阶段打倒军阀，推翻帝国主义的压迫，将中国统一为真正的民主共和国；是中国历史上第一次提出明确的反帝反封建的民主革命纲领

长征中的重大事件是？###四渡赤水、渡过金沙江跳出包围圈、强渡大渡河、飞夺泸定桥、翻雪山、过草地、突破天险腊子口

# ===== 第六单元 中华民族的抗日战争 =====

# 第16课 从九一八事变到西安事变

九一八事变的意义是？###九一八事变是中国人民抗日战争的起点，东北各族民众组织抗日义勇军抵抗日军侵略，揭开了世界反法西斯战争的序幕
一二·九运动的时间和意义是？###1935年12月9日，在中国共产党领导下，北平学生向国民党当局请愿并举行示威游行，高呼"打倒日本帝国主义""反对华北自治""停止内战，一致对外"；揭露了日本侵略者企图吞并华北的阴谋，极大促进了中华民族的觉醒，标志着中国人民抗日救亡民主运动新高潮的到来

西安事变和平解决的意义是？###揭开了国共两党由内战到联合抗日的序幕，成为时局转换的枢纽；从此十年内战基本结束，在抗日的前提下国共两党实行第二次合作已成为不可抗拒的大势

抗日战争胜利的进程是？###1945年7月，中、美、英发表《波茨坦公告》敦促日本无条件投降；8月6日和9日美国向广岛和长崎投掷原子弹，8月8日苏联对日宣战出兵中国东北；毛泽东发表《对日寇的最后一战》；8月15日日本天皇宣布无条件投降，9月2日日本政府正式签署投降书

# ===== 第七单元 人民解放战争 =====
