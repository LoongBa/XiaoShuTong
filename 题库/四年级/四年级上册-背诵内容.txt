# 《观潮》（片段背诵：第3-4自然段）
句子接龙：那条白线很快地向我们移来，###逐渐拉长，变粗，横贯江面
句子接龙：再近些，只见白浪翻滚，###形成一堵两丈多高的水墙
句子接龙：浪潮越来越近，犹如千万匹白色战马齐头并进，###浩浩荡荡地飞奔而来；那声音如同山崩地裂，好像大地都被震得颤动起来
课文理解：浪潮来时的声音是怎样的？###那声音如同山崩地裂，好像大地都被震得颤动起来
默写《观潮》第3-4自然段###那条白线很快地向我们移来，逐渐拉长，变粗，横贯江面。再近些，只见白浪翻滚，形成一堵两丈多高的水墙。浪潮越来越近，犹如千万匹白色战马齐头并进，浩浩荡荡地飞奔而来；那声音如同山崩地裂，好像大地都被震得颤动起来。霎时，潮头奔腾西去，可是余波还在漫天卷地般涌来，江面上依旧风号浪吼。过了好久，钱塘江才恢复了平静。

# 《走月亮》（片段背诵：第4-5自然段）
句子接龙：细细的溪水，###流着山草和野花的香味，流着月光
句子接龙：灰白色的鹅卵石，###布满河床
句子接龙：哟，卵石间有多少可爱的小水塘啊，###每个小水塘都抱着一个月亮
句子接龙：哦，阿妈，白天你在溪里洗衣裳，###而我，用树叶做小船，运载许多新鲜的花瓣
默写《走月亮》第4自然段###细细的溪水，流着山草和野花的香味，流着月光。灰白色的鹅卵石，布满河床。哟，卵石间有多少可爱的小水塘啊，每个小水塘都抱着一个月亮！

# 《秋晚的江上》刘大白（现代诗，全文背诵）
文学常识：《秋晚的江上》的作者是？###刘大白
句子接龙：归巢的鸟儿，尽管是倦了，###还驮着斜阳回去
句子接龙：双翅一翻，把斜阳掉在江上；###头白的芦苇，也妆成一瞬的红颜了
默写《秋晚的江上》###归巢的鸟儿，尽管是倦了，还驮着斜阳回去。双翅一翻，把斜阳掉在江上；头白的芦苇，也妆成一瞬的红颜了。

# 《花牛歌》徐志摩（现代诗，全文背诵）
文学常识：《花牛歌》的作者是？###徐志摩
句子接龙：花牛在草地里坐，###压扁了一穗剪秋萝
句子接龙：花牛在草地里眠，###白云霸占了半个天
句子接龙：花牛在草地里走，###小尾巴甩得的溜溜
句子接龙：花牛在草地里做梦，###太阳偷渡了西山的青峰
默写《花牛歌》###花牛在草地里坐，压扁了一穗剪秋萝。花牛在草地里眠，白云霸占了半个天。花牛在草地里走，小尾巴甩得的溜溜。花牛在草地里做梦，太阳偷渡了西山的青峰。

# 《繁星》巴金（现代文，背诵第1自然段）
文学常识：《繁星》的作者是？###巴金
句子接龙：我爱月夜，但我也爱星天。从前在家乡，七八月的夜晚，在庭院里纳凉的时候，###我最爱看天上密密麻麻的繁星
句子接龙：望着星天，我就会忘记一切，###仿佛回到了母亲的怀里似的
名句理解：为什么说"望着星天，我就会忘记一切，仿佛回到了母亲的怀里似的"？###星星给作者带来温暖与亲切的感觉，像回到母亲怀抱一样安宁
默写《繁星》第1自然段###我爱月夜，但我也爱星天。从前在家乡，七八月的夜晚，在庭院里纳凉的时候，我最爱看天上密密麻麻的繁星。望着星天，我就会忘记一切，仿佛回到了母亲的怀里似的。

# 《爬山虎的脚》（片段背诵：第2-3自然段）
句子接龙：爬山虎的叶子绿得那么新鲜，看着非常舒服。叶尖一顺儿朝下，在墙上铺得那么均匀，###没有重叠起来的，也不留一点儿空隙
句子接龙：一阵风拂过，一墙的叶子就漾起波纹，###好看得很
句子接龙：爬山虎的脚长在茎上。茎上长叶柄的地方，反面伸出枝状的六七根细丝，###每根细丝像蜗牛的触角
默写《爬山虎的脚》第3自然段###爬山虎的脚长在茎上。茎上长叶柄的地方，反面伸出枝状的六七根细丝，每根细丝像蜗牛的触角。细丝跟新叶子一样，也是嫩红的。这就是爬山虎的脚。

# 《蟋蟀的住宅》（片段背诵：第1-2自然段）
句子接龙：居住在草地上的蟋蟀，差不多和蝉一样有名。它的出名不光由于它的唱歌，###还由于它的住宅
句子接龙：蟋蟀和它们不同，###不肯随遇而安
句子接龙：它常常慎重地选择住址，###一定要排水优良，并且有温和的阳光
默写《蟋蟀的住宅》第2自然段###别的昆虫大多在临时的隐蔽所藏身。它们的隐蔽所得来不费功夫，弃去毫不可惜。蟋蟀和它们不同，不肯随遇而安。它常常慎重地选择住址，一定要排水优良，并且有温和的阳光。

# ===== 课内古诗 =====

《题西林壁》的作者及朝代是？###苏轼，宋
《题西林壁》中"横看成岭侧成峰"的后一句是？###远近高低各不同
《题西林壁》中"不识庐山真面目"的后一句是？###只缘身在此山中
《题西林壁》中蕴含哲理的名句是？###不识庐山真面目，只缘身在此山中。
默写《题西林壁》###横看成岭侧成峰，远近高低各不同。不识庐山真面目，只缘身在此山中。

《游山西村》的作者及朝代是？###陆游，宋
《游山西村》中"莫笑农家腊酒浑"的后一句是？###丰年留客足鸡豚
《游山西村》中"山重水复疑无路"的后一句是？###柳暗花明又一村
《游山西村》中蕴含"绝处逢生"哲理的名句是？###山重水复疑无路，柳暗花明又一村。
默写《游山西村》###莫笑农家腊酒浑，丰年留客足鸡豚。山重水复疑无路，柳暗花明又一村。箫鼓追随春社近，衣冠简朴古风存。从今若许闲乘月，拄杖无时夜叩门。

《过故人庄》的作者及朝代是？###孟浩然，唐
《过故人庄》中"故人具鸡黍"的后一句是？###邀我至田家
《过故人庄》中"绿树村边合"的后一句是？###青山郭外斜
《过故人庄》中"待到重阳日"的后一句是？###还来就菊花
默写《过故人庄》###故人具鸡黍，邀我至田家。绿树村边合，青山郭外斜。开轩面场圃，把酒话桑麻。待到重阳日，还来就菊花。

# ===== 文言文 =====

《精卫填海》选自哪部著作？###《山海经》
《精卫填海》中"炎帝之少女"的后一句是？###名曰女娃
《精卫填海》中"女娃游于东海"的后一句是？###溺而不返
《精卫填海》中精卫为什么要"常衔西山之木石"？###要把东海填平（以堙于东海）
默写《精卫填海》###炎帝之少女，名曰女娃。女娃游于东海，溺而不返，故为精卫，常衔西山之木石，以堙于东海。

《王戎不取道旁李》选自哪部著作？###《世说新语》
《王戎不取道旁李》中"王戎七岁"的后一句是？###尝与诸小儿游
《王戎不取道旁李》中"诸儿竞走取之"的后一句是？###唯戎不动
《王戎不取道旁李》中王戎为什么不取道旁李？###树在道边而多子，此必苦李
默写《王戎不取道旁李》###王戎七岁，尝与诸小儿游。看道边李树多子折枝，诸儿竞走取之，唯戎不动。人问之，答曰："树在道边而多子，此必苦李。"取之，信然。
