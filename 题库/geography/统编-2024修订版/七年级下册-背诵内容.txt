# ===== 第七章 我们生活的大洲——亚洲 =====

# 第1节 自然环境
亚洲的半球位置是？###绝大部分地区位于北半球和东半球
亚洲的海陆位置是？###位于亚欧大陆的大部，北、东、南三面依次濒临北冰洋、太平洋和印度洋
亚洲的面积是多少？###约4400万平方千米，是世界面积最大的大洲，约占世界陆地面积的1/3
亚洲被划分为哪六个地理分区？###东亚、东南亚、南亚、西亚、中亚、北亚
亚洲的地势特点是？###中部高、四周低（中部以青藏高原、帕米尔高原最为高峻）
被称为"山结"的是？###帕米尔高原（亚洲地形的主要"骨架"——主要山脉交汇于此）
亚洲的大河分布特点是？###多发源于中部山地、高原，呈放射状流向周边的海洋
注入太平洋的亚洲大河有？###黄河、长江、湄公河等
注入印度洋的亚洲大河有？###恒河、印度河等
亚洲气候的特点有？###季风气候显著、大陆性气候分布广、气候类型多样
亚洲季风气候分布最典型的地区是？###亚洲东部和南部（世界上季风气候分布面积最大、季风特点最典型的地区）
亚洲广大的内陆地区属于什么气候？###温带大陆性气候（冬季寒冷，夏季温暖，气温日较差和年较差大）
亚洲北冰洋沿岸地带属于什么气候？###寒带气候
亚洲中部青藏高原属于什么气候？###高原山地气候（世界上面积最大的高原山地气候区，自然景观垂直变化明显）
亚洲气候类型多样的原因是？###受纬度位置、海陆位置和地形的综合影响

# 第2节 人文环境
亚洲人口数量及地位是？###2020年亚洲人口达46.4亿，是世界上人口最多的大洲，以占世界1/3的陆地养活了占世界3/5的人口
亚洲人口稠密的地区有？###东亚、东南亚和南亚
亚洲人口稠密的原因？###地处中低纬度，气候适宜，离海洋较近，平均海拔较低，河流多；优越的自然条件适宜农耕，农业开发历史悠久

# ===== 第八章 我们邻近的地区和国家 =====

# 第3节 日本
日本的地理位置是？###亚洲东部、太平洋西北部，由北海道、本州、四国、九州四个大岛及一些邻近的小岛组成
日本多火山、地震的原因是？###位于亚欧板块与太平洋板块交界地带，地壳活跃
日本的地形特点是？###以山地、丘陵为主，平原面积狭小
日本最大的平原是？###关东平原
日本气候的特点？###温带季风气候和亚热带季风气候，海洋性特征明显
日本工业的特点是？###进口原料和燃料，加工后出口工业产品（加工贸易型经济）
日本工业的主要分布地区是？###太平洋沿岸和濑户内海沿岸（城市和人口集中，是国内最大的消费地；便于进口原料、出口产品）
日本工业集中分布的原因是？###原料燃料依靠进口、产品主要用于出口、城市人口集中、海岸线曲折多优良港湾
日本应对地震的措施有？###建筑采用轻质材料、定期举行防震演练、普及抗震知识等

# 第4节 东南亚
东南亚的地理位置是？###位于亚洲东南部，包括中南半岛和马来群岛两大部分
东南亚被称为"十字路口"的原因？###地处亚洲与大洋洲、太平洋与印度洋的"十字路口"
马六甲海峡的重要性？###位于马来半岛和苏门答腊岛之间，是西亚、非洲石油运输到东亚的重要通道，被称为"海上生命线"
东南亚主要的气候类型是？###热带雨林气候（马来群岛大部分）和热带季风气候（中南半岛）
东南亚的主要粮食作物是？###水稻（种植历史悠久，是世界主要的稻米出口地区）
东南亚主要的热带经济作物有？###天然橡胶、油棕（棕榈油）、蕉麻、椰子等
东南亚中南半岛的地形特点是？###山河相间、纵列分布
中南半岛大城市的分布特点是？###主要分布在大河沿岸及河口三角洲地区（如湄公河沿岸）
东南亚是世界上华人华侨分布最集中的地区

# 第5节 印度
印度在世界中的位置是？###位于亚洲南部，南亚面积最大的国家，东临孟加拉湾，西临阿拉伯海
印度的主要气候类型是？###热带季风气候（全年高温，分旱雨两季）
印度水旱灾害频繁的原因是？###西南季风不稳定（来得早退得晚易涝，来得晚退得早易旱）
印度主要的粮食作物是？###水稻（东北部和沿海平原）和小麦（德干高原西北部）
印度的"绿色革命"是？###改进农业技术、推广高产良种，提高粮食产量
印度被称为"世界办公室"的原因是？###服务外包产业发展迅速，信息技术含量高、利润大、资源消耗少
印度服务外包产业的中心是？###班加罗尔

# 第6节 俄罗斯
俄罗斯的领土特点？###横跨亚欧大陆北部，是世界上面积最大的国家
俄罗斯为什么是欧洲国家？###欧洲部分虽仅占1/4，却集中了全国约3/4的人口，一直是全国政治、经济和文化的中心地区；俄罗斯也是起源于欧洲的国家
俄罗斯的主要气候类型是？###温带大陆性气候（冬季漫长严寒，夏季短促温暖）
俄罗斯的自然资源特点是？###自然资源十分丰富，种类多、储量大，是世界少数几个资源基本自给的大国之一
俄罗斯的工业特点是？###重工业发达，航空航天技术先进，核技术先进；轻工业相对薄弱
俄罗斯的交通运输特点是？###铁路运输为主
西伯利亚大铁路的地位？###世界最长的铁路，由莫斯科途经西伯利亚到太平洋沿岸
俄罗斯的主要河流湖泊有？###伏尔加河（欧洲最长的河流）、鄂毕河、叶尼塞河、勒拿河、贝加尔湖（世界最深的湖泊）

# ===== 第九章 东半球其他的地区和国家 =====

# 第7节 西亚
西亚的地理位置是？###位于亚洲西南部，地处"三洲五海"之地（亚、欧、非三洲之间，阿拉伯海、红海、地中海、黑海和里海之间）
西亚石油的分布？###主要分布在波斯湾及其沿岸地区
西亚石油主要出口到哪些地区？###东亚、欧洲西部、北美等
霍尔木兹海峡的重要性？###波斯湾沿岸地区唯一的出海通道，全球大约1/3的海上石油运输通过这一海峡
西亚水资源匮乏的原因是？###气候干旱，降水稀少
西亚发展节水农业的典型国家？###以色列（发展滴灌、喷灌等节水农业）
西亚成为热点地区的原因是？###地理位置重要、石油资源丰富、水资源匮乏、宗教文化差异大

# 第8节 欧洲西部
欧洲西部的位置？###位于欧洲西半部，北临北冰洋，西临大西洋，南临地中海
欧洲西部经济的特点？###发达国家集中的地区（工业中心多、工艺水平高、农业机械化程度高）
欧洲西部畜牧业发达的原因是？###温带海洋性气候，全年温和湿润，适合多汁牧草生长；牧草被称为"绿色金子"
欧洲西部主要的气候类型有？###温带海洋性气候（西部）和地中海气候（南部）
欧洲西部旅游业发达的原因？###自然和人文旅游资源丰富

# 第9节 撒哈拉以南非洲
撒哈拉以南非洲的位置？###绝大部分位于世界最大的沙漠——撒哈拉沙漠以南，东临印度洋，西濒大西洋
撒哈拉以南非洲的人种特点是？###黑种人的故乡（90%以上是黑种人）
撒哈拉以南非洲的地形特点是？###以高原为主，被称为"高原大陆"
撒哈拉以南非洲的气候分布特点是？###以赤道为中心，南北对称分布
世界最长的河流尼罗河流经此地；刚果河是世界水量最大的河流之一
撒哈拉以南非洲的经济特点？###历史上形成"单一商品经济"（出口初级产品，进口工业制成品），在国际贸易中处于不利地位；近年来经济快速发展，努力发展多样化经济
撒哈拉以南非洲面临的主要问题？###人口增长过快、粮食供应不足、环境恶化（人口、粮食与环境三大问题）

# 第10节 澳大利亚
澳大利亚的位置？###位于大洋洲，是世界上唯一独占一块大陆的国家
澳大利亚的特有动植物有？###袋鼠（"跳远名将"）、考拉、鸭嘴兽、鸸鹋等（因长期孤立、缺少大型食肉动物而独特）
澳大利亚被称为"骑在羊背上的国家"的原因是？###养羊业发达，羊毛产量和出口量居世界前列
澳大利亚被称为"坐在矿车上的国家"的原因是？###煤炭和铁矿石产量、出口量居世界前列
澳大利亚的铁矿特点？###储量居全球首位，品质优，埋藏浅，开采成本低；距离我国近，运输成本低
澳大利亚的气候分布特点是？###呈半环状分布
澳大利亚人口的分布特点是？###主要分布在东南沿海地区（气候温暖湿润）

# ===== 第十章 西半球的国家 =====

# 第11节 美国
美国的地理位置是？###本土横贯美洲大陆中部，东临大西洋，西濒太平洋；还包括北美洲西北部的阿拉斯加和太平洋中的夏威夷群岛
美国的人口特点？###人口超过3亿，是世界第三人口大国；是接收移民数量最多的国家（移民国家）
美国的地形特点？###西部是高大的山系（科迪勒拉山系），中部是广阔的中央平原，东部是低缓的阿巴拉契亚山地
美国的农业特点是？###地区生产专业化，形成了传统的农业带（区）（每个农业带综合地形、气候、水源、市场等多种条件形成）
美国高新技术产业中心是？###旧金山东南的"硅谷"
美国是世界最发达的工业国家

# 第12节 巴西
巴西的位置？###位于南美洲东部，大部分国土位于热带，东临大西洋
巴西的地形特点是？###以平原和高原为主：西北部为亚马孙平原，东南部为巴西高原
巴西的人口特点？###人口超过2亿，是南美洲人口最多的国家；混血种人数量众多，约占总人口的45%
亚马孙河的特点？###世界流域面积最广、水量最大的河流
亚马孙热带雨林的地位？###地球上面积最大的热带雨林，其中60%在巴西境内；被称为"地球之肺"，能吸收二氧化碳放出氧气
巴西主要的农产品？###咖啡、蔗糖（甘蔗）、柑橘等产量和出口量居世界前列
巴西的矿产特点？###铁矿石储量大、品质优，产量和出口量均居世界前列
巴西的城市化特点？###东南沿海的圣保罗、里约热内卢等是主要城市；20世纪70年代以来积极发展生物燃料（甘蔗乙醇）
热带雨林遭受破坏的原因及影响？###大规模开发亚马孙地区（修路、开矿、伐木、开辟农场），导致水土流失加剧、生物多样性减少，影响全球气候

# ===== 第十一章 极地地区 =====

# 第13节 极地地区
极地地区包括？###南极地区和北极地区
南极地区的位置？###主要位于南极圈以南，包括南极洲及其周边海域；主体是南极大陆
南极地区的气候特点？###酷寒（大部分地区年平均气温很低）、多狂风、降水稀少；有"冰雪高原"之称（覆盖2000多米厚冰层）
南极地区比北极地区冷得多的原因？###南极地区主体是大陆、平均海拔超过2300米、被冰冷海水环绕；北极地区近2/3是海洋、海拔低、有较低纬度流入的温暖海水
北极地区的位置？###主要位于北极圈以北，包括北冰洋的大部分及周边陆地；主体是北冰洋
北极地区的气候特点？###没有南极地区寒冷（年平均气温约-10℃），降水量比南极地区大，风速远不及南极大
南极地区的代表性动物是？###企鹅
北极地区的代表性动物是？###北极熊
南极地区的资源？###淡水资源（固体冰川）、矿产资源（煤铁等）、海洋生物资源（磷虾等）
我国在南极建立的科考站有？###长城站、中山站、昆仑站、泰山站等
极地科考的意义？###认识极地自然环境、研究全球气候变化、开发利用极地资源
保护极地的措施？###《南极条约》规定南极只用于和平目的；限制旅游、科学考察活动；保护极地生态环境
