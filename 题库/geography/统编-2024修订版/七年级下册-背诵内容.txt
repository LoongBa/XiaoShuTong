# ===== 第一章 我们生活的大洲——亚洲 =====

# 第1节 位置和范围
亚洲的半球位置是？###主要位于东半球和北半球
亚洲的海陆位置是？###东临太平洋，南临印度洋，北临北冰洋，西与欧洲相连
亚洲的经纬度位置是？###约26°E~170°W，约11°S~81°N
亚洲的六大地理分区是？###东亚、东南亚、南亚、西亚、中亚、北亚
亚洲的面积是？###约4400万平方千米，是世界第一大洲
亚洲的纬度范围广意味着什么？###地跨寒、温、热三带

# 第2节 自然环境
亚洲的地势特点是？###中部高，四周低
亚洲的河流分布特点是？###发源于中部山地高原，呈放射状流向周边海洋
亚洲的主要河流有？###长江、黄河、湄公河、恒河、印度河、鄂毕河、叶尼塞河、勒拿河
亚洲的气候特点有？###气候复杂多样、季风气候显著、大陆性气候分布广
亚洲没有的气候类型是？###温带海洋性气候
# ===== 第二章 我们邻近的地区和国家 =====

# 第3节 日本
日本的地理位置是？###亚洲东部，太平洋西北部，由北海道、本州、四国、九州四个大岛及附近小岛组成
日本的地形特点是？###以山地丘陵为主，平原面积狭小，多火山地震
日本的气候类型是？###温带季风气候和亚热带季风气候
日本经济的特点是？###发达经济，进口原料燃料，出口工业产品，加工贸易型经济
日本多火山地震的原因是？###位于亚欧板块与太平洋板块交界处，地壳活跃
日本的工业分布特点是？###太平洋沿岸和濑户内海沿岸

# 第4节 东南亚
东南亚的地理位置是？###亚洲东南部，包括中南半岛和马来群岛两部分
东南亚的"十字路口"位置是？###连接亚洲与大洋洲、太平洋与印度洋
马六甲海峡的重要性是？###是欧洲、非洲向东航行到东南亚、东亚各港口最短航线的必经之地
东南亚的主要气候类型是？###热带雨林气候（马来群岛）和热带季风气候（中南半岛）
东南亚的主要农作物是？###水稻（粮食作物）、天然橡胶、棕榈油、椰子等（热带经济作物）
东南亚的华人华侨分布特点是？###是世界上华人华侨分布最集中的地区

# 第5节 印度
印度的地理位置是？###南亚次大陆，北临喜马拉雅山脉，南临印度洋
印度的主要气候类型是？###热带季风气候（全年高温，分旱雨两季）
印度水旱灾害频繁的原因是？###西南季风不稳定（来得早退得晚/来得晚退得早）
印度的主要粮食作物是？###水稻和小麦
印度的"绿色革命"是？###改进农业技术，推广高产良种，提高粮食产量
印度的服务外包产业特点是？###信息技术含量高、利润大、资源消耗少，被称为"世界办公室"

# 第6节 俄罗斯
俄罗斯的地理位置是？###横跨亚欧大陆北部，世界上面积最大的国家
俄罗斯的主要气候类型是？###温带大陆性气候（冬季漫长严寒，夏季短促温暖）
俄罗斯的自然资源特点是？###自然资源丰富，种类齐全，自给程度高
俄罗斯的工业特点是？###重工业发达，核工业和航空航天工业居世界前列，轻工业相对薄弱
俄罗斯的交通特点是？###铁路运输为主，西伯利亚大铁路横贯亚欧大陆
俄罗斯的主要河流湖泊有？###伏尔加河（欧洲最长）、鄂毕河、叶尼塞河、勒拿河、贝加尔湖（世界最深）

# ===== 第三章 东半球其他的地区和国家 =====

# 第7节 中东
中东的地理位置是？###"三洲五海之地"（亚、非、欧三洲，阿拉伯海、红海、地中海、黑海、里海）
中东成为热点地区的原因是？###地理位置重要、石油资源丰富、水资源匮乏、宗教文化差异
中东石油资源的分布是？###波斯湾及其沿岸地区
中东石油的主要出口地区是？###西欧、美国、日本
中东水资源匮乏的原因是？###气候干旱，降水稀少
中东的主要宗教有？###伊斯兰教、基督教、犹太教

# 第8节 欧洲西部
欧洲西部的地理位置是？###欧洲西半部，北临北冰洋，西临大西洋，南临地中海
欧洲西部的气候类型以什么为主？###温带海洋性气候和地中海气候
欧洲西部畜牧业发达的原因是？###温带海洋性气候，全年温和湿润，适合多汁牧草生长
欧洲西部的旅游业特点是？###自然和人文旅游资源丰富，是世界上旅游业最发达的地区之一
欧洲西部的发达国家集中表现在？###工业中心多，工艺水平高，农业机械化程度高

# 第9节 撒哈拉以南的非洲
撒哈拉以南非洲的地理位置是？###非洲中部和南部，赤道穿过中部
撒哈拉以南非洲的人种特点是？###黑种人的故乡，90%以上是黑种人
撒哈拉以南非洲的经济特点？###以初级产品为主的"单一商品经济"，在国际贸易中处于不利地位
撒哈拉以南非洲的气候分布特点是？###以赤道为中心，南北对称分布
非洲的主要气候类型有？###热带雨林气候、热带草原气候、热带沙漠气候

# 第10节 澳大利亚
澳大利亚的地理位置是？###独占澳大利亚大陆，位于南半球
澳大利亚的别称是？###"骑在羊背上的国家"（养羊业发达）、"坐在矿车上的国家"（矿产资源丰富）
澳大利亚的特有动物有？###袋鼠、考拉、鸭嘴兽、鸸鹋
澳大利亚的气候分布特点是？###呈半环状分布
澳大利亚的经济支柱是？###服务业（占GDP比重最大）

# ===== 第四章 西半球的国家 =====

# 第11节 美国
美国的地理位置是？###北美洲中部，本土48个州+阿拉斯加州+夏威夷州
美国的地形特点是？###西部是高大的山系（科迪勒拉山系），中部是广阔的平原，东部是低缓的山地
美国的气候特点是？###气候类型多样，以温带大陆性气候为主
美国的农业特点是？###地区生产专业化，形成多个农业带（乳畜带、玉米带、小麦区、棉花带等）
美国的高新技术产业中心是？###旧金山东南的"硅谷"
美国是世界最大的？###工业国家和军事强国

# 第12节 巴西
巴西的地理位置是？###南美洲东部，东临大西洋，大部分位于热带
巴西的主要地形区有？###亚马孙平原（世界最大平原）、巴西高原（世界最大高原）
巴西的主要气候类型是？###热带雨林气候（亚马孙平原）和热带草原气候（巴西高原）
巴西的主要农作物有？###咖啡、甘蔗、柑橘产量居世界前列
巴西的水资源特点是？###亚马孙河是世界上流量最大、流域面积最广的河流
巴西的城市化特点是？###城市化水平高，但出现"虚假城市化"问题

# 第13节 极地地区
南极地区的地理位置是？###南极圈以南，包括南极大陆及其周边海域
南极地区的气候特点是？###酷寒、多狂风、降水稀少（"冰雪高原"、"风库"、"白色荒漠"）
南极地区的主要资源有？###淡水资源（固体）、矿产资源（煤铁丰富）、海洋生物资源（磷虾）
南极科考的最佳时间是？###每年11月至次年3月（暖季）
北极地区的地理位置是？###北极圈以北，包括北冰洋及其周边陆地
北极地区的居民是？###因纽特人（黄种人）
北极地区的气候特点是？###比南极温暖，降水稍多
# ===== 第五章 发展与合作 =====

# 第14节 人类的居住地——聚落
城市与乡村的差异是？###城市人口密度大，乡村人口密度小；城市以非农业为主，乡村以农业为主
聚落形成与发展的条件是？###地形平坦、土壤肥沃、水源充足、交通便利、自然资源丰富

# 第15节 发展与合作
发达国家与发展中国家的分布特点是？###发达国家主要分布在北半球北部，发展中国家主要分布在南半球和北半球南部
"南南合作"的含义是？###发展中国家之间的合作
"南北对话"的含义是？###发展中国家与发达国家之间的政治、经济商谈
# ===== 第六章 中国的自然环境 =====

# 第16节 地形和地势
中国地形的特点是？###地形类型多样，山区面积广大（山区约占全国总面积的2/3）
中国地势的特点是？###西高东低，呈三级阶梯状分布
中国地势第一级阶梯的地形以什么为主？###高原（青藏高原，平均海拔4000米以上）
中国地势第二级阶梯的地形以什么为主？###高原和盆地（内蒙古高原、黄土高原、云贵高原、塔里木盆地、准噶尔盆地、四川盆地）
中国地势第三级阶梯的地形以什么为主？###平原和丘陵（东北平原、华北平原、长江中下游平原、东南丘陵）
中国地势三级阶梯的分界线是？###第一级阶梯：昆仑山脉—祁连山脉—横断山脉；第二级阶梯：大兴安岭—太行山脉—巫山—雪峰山

# 第17节 气候
中国气候的特征是？###气候复杂多样、季风气候显著
中国温度带的划分是？###热带、亚热带、暖温带、中温带、寒温带（从南到北）
中国干湿地区的划分是？###湿润区、半湿润区、半干旱区、干旱区（从东南到西北）
中国季风气候的特点是？###夏季高温多雨，冬季温和少雨（亚热带季风）；夏季高温多雨，冬季寒冷干燥（温带季风）
影响中国气候的主要因素是？###纬度位置、海陆位置、地形
中国季风区与非季风区的分界线是？###大兴安岭—阴山—贺兰山—巴颜喀拉山—冈底斯山

# 第18节 河流
中国的主要河流分为哪两类？###外流河（最终流入海洋）和内流河（最终未流入海洋）
外流河的主要分布区是？###东部季风区
内流河的主要分布区是？###西北内陆地区
长江的基本概况是？###中国第一大河，发源于青藏高原唐古拉山脉，注入东海，全长6300千米
长江的主要支流有？###雅砻江、岷江、嘉陵江、乌江、湘江、赣江
黄河的基本概况是？###中国第二长河，发源于青藏高原巴颜喀拉山，注入渤海，全长5464千米
黄河下游"地上河"形成的原因是？###中游流经黄土高原，携带大量泥沙，下游华北平原流速减慢，泥沙淤积
黄河的治理措施是？###中游保持水土（植树造林），下游加固堤坝
