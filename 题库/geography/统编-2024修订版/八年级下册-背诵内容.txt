# ===== 第六章 中国的地理差异 =====

# 第1节 中国的地理差异
我国自然地理差异的主要表现？###自南向北纬度差异（气温）、自东向西海陆差异（降水）、地势三级阶梯差异（地形）；青藏高原地高天寒、长江三角洲地势低平
秦岭—淮河一线是我国什么重要的地理分界线？###南北方的分界线（我国一条重要的地理分界线）
秦岭—淮河以北的自然与人文特征？###耕地多为旱地，以种植小麦为主；冬季寒冷，河流有结冰期；民居屋顶坡度较小
秦岭—淮河以南的自然与人文特征？###耕地多为水田，以种植水稻为主；降水丰富，河流无结冰期；民居屋顶坡度大，水运发达
我国四大地理区域是？###北方地区、南方地区、西北地区、青藏地区
四大地理区域划分的主导因素？###北方与南方：气候（气温降水）；西北与北方：降水（海陆位置）；青藏与其余：地形（海拔）
大兴安岭—长城大致与哪条等降水量线分布一致？###400毫米年降水量线（东部半湿润区与半干旱区、农耕区与牧区的分界线）

# ===== 第七章 北方地区 =====

# 第2节 自然特征与农业
北方地区的位置？###大体位于大兴安岭、青藏高原以东，内蒙古高原以南，秦岭—淮河以北，东临渤海和黄海
北方地区的地形？###以平原和高原为主：东部东北平原和华北平原，西部黄土高原
北方地区的土壤？###东北平原"黑土地"，黄土高原、华北平原"黄土地"
北方地区的气候？###大部分属于温带季风气候，冬季寒冷（最冷月平均气温在0℃以下），夏季炎热
北方地区的耕地类型？###旱地为主（重要的旱作农业区）
北方地区的主要农作物？###小麦、玉米、大豆、甜菜、棉花等
东北平原与华北平原农业差异？###东北平原水资源较丰富，除旱作外还种植水稻；华北平原、黄土高原水资源不足，春旱严重

# 第3节 "白山黑水"——东北三省
东北三省包括？###黑龙江省、吉林省、辽宁省
"白山黑水"的含义？###白山指长白山，黑水指黑龙江
东北三省的山河大势？###"山环水绕、沃野千里"（西倚大兴安岭、北为小兴安岭、东为长白山脉，山地之间是东北平原）
东北三省的气候特点？###纬度较高，邻近冬季风源地，冬季严寒漫长、夏季暖热短促；降水集中在夏季
东北三省成为商品粮基地的条件？###夏季暖热、雨热同期；平原辽阔坦荡，适宜大规模机械化耕作；黑土地肥沃
从"北大荒"到"北大仓"指的是？###东北平原由原来的荒原开垦为重要的商品粮基地

# 第4节 世界最大的黄土堆积区——黄土高原
黄土高原的位置？###东起太行山脉，西至乌鞘岭，北连内蒙古高原，南抵秦岭
黄土高原的成因？###风成说——由风力搬运堆积形成（世界最大的黄土堆积区）
黄土高原水土流失严重的原因？###黄土土质疏松、植被稀少、夏季降水集中多暴雨、地表千沟万壑；人类过度开垦、放牧、采矿
水土流失的危害？###带走肥沃土壤、使沟谷加深加宽、淤塞河道、引发洪涝灾害
水土流失的治理措施？###植树种草、退耕还林还草、修建梯田、打坝淤地、合理放牧

# 第5节 祖国的首都——北京
北京的城市职能？###全国政治中心、文化中心、国际交往中心、科技创新中心
北京的地理位置？###华北平原北部边缘，背靠燕山，西邻太行山，东南与天津相邻、面向渤海
北京的历史地位？###著名古都和历史文化名城，3000多年建城史、800多年建都史；故宫（紫禁城）、长城、颐和园、天坛、明十三陵等名胜古迹
北京旧城的格局？###方方正正，中轴线对称（内城、外城）
北京为缓解城市问题采取的措施？###在通州建设城市副中心；建设北京大兴国际机场（京津冀一体化）；治理大城市病
北京发展高新技术产业的中心？###中关村（中关村科学城）
北京为改善环境的举措？###首钢迁出北京（首钢园改造）；建设街心公园、绿地广场

# ===== 第八章 南方地区 =====

# 第6节 自然特征与农业
南方地区的位置？###位于秦岭—淮河以南、青藏高原以东，东临黄海、东海，南临南海
南方地区的地形？###西部以高原、盆地为主（四川盆地、云贵高原）；东部以平原、低山丘陵为主（长江中下游平原、东南丘陵）
南方地区的气候？###湿润的亚热带、热带季风气候（夏季高温多雨、冬季温和少雨）
南方地区的土壤？###红壤（东南丘陵）、紫色土（四川盆地，成都平原"天府之国"）
南方地区的主要农作物？###水稻（水田农业区）、油菜、甘蔗、茶叶、竹、柑橘、香蕉、菠萝等热带亚热带作物
都江堰水利工程的作用？###引水灌溉，使成都平原成为"天府之国"

# 第7节 "鱼米之乡"——长江三角洲地区
长江三角洲地区包括？###上海市、江苏省南部、浙江省北部（江海交汇之地）
长江三角洲的位置优势？###地处江海交汇之地，沿江沿海港口众多，是我国南北海上航运的中枢；可通过长江联系广大内陆地区
长江三角洲被称为"鱼米之乡"的原因？###地势低平、河网密布、湖泊众多，亚热带季风气候，是我国重要的稻米产区和淡水养殖区
长江三角洲的著名世界文化遗产？###苏州古典园林、杭州西湖
长江三角洲地区的核心城市？###上海（我国超大城市，国际经济、金融、贸易、航运、科技创新中心）
"同城效应"的含义？###借助发达的高速铁路、高速公路、城际交通和网络信息技术，长江三角洲城市之间联系密切，如同一座城市
长江三角洲区域一体化？###以上海为龙头，区域内各城市优势互补、互利共赢

# 第8节 特别行政区——香港和澳门
香港和澳门回归时间？###1997年7月1日香港回归；1999年12月20日澳门回归
"一国两制"政策？###祖国内地实行社会主义制度，香港和澳门实行资本主义制度
香港的位置与组成？###位于珠江口东侧，与广东相邻；由香港岛、九龙、"新界"组成
澳门的位置与组成？###位于珠江口西侧；由澳门半岛、氹仔岛和路环岛组成
香港和澳门的地形与气候？###香港以低山丘陵为主、平地较少；澳门整体海拔较低以平地为主；均属亚热带季风气候，夏秋季多台风
香港的城市用地扩展方式？###"上天"（高层建筑）、"下海"（填海造地）
香港的经济地位？###世界著名的自由贸易港，重要的国际金融中心、航运中心、贸易中心和国际航空枢纽
澳门的经济特点？###世界旅游休闲中心
香港和澳门发展经济的条件？###地狭人稠、自然资源匮乏，主要依靠祖国内地的支持，经济持续繁荣

# 第9节 祖国的神圣领土——台湾省
台湾省的位置与组成？###位于我国东南沿海，北临东海、东临太平洋、南临南海、西隔台湾海峡与福建相望；包括台湾岛及澎湖列岛、钓鱼岛等众多岛屿
台湾岛的特点？###我国面积最大的岛屿
台湾的地形？###以山地为主（玉山是我国东部最高峰），西部平原为主
台湾的物产？###"海上米仓"（稻米）、"东方甜岛"（甘蔗）、"水果之乡"（香蕉菠萝等）、"森林之海"（樟树，樟脑产量世界第一）、"东南盐库"
台湾的经济发展特点？###出口导向型经济（进口原料—加工—出口工业产品）；新竹科学园区是高新技术产业中心
台湾的人口与民族？###以汉族为主，少数民族主要是高山族

# ===== 第九章 西北地区 =====

# 第10节 自然特征与农业
西北地区的位置？###主要位于我国地势第二级阶梯，大体位于大兴安岭以西、长城和昆仑山—阿尔金山—祁连山以北
西北地区的地形？###以高原和盆地为主：东部内蒙古高原，西部高山和盆地相间分布
西北地区气候干旱的原因？###深居内陆、距海遥远，降水少；大部分年降水量400毫米以下，中西部不足200毫米
西北地区的景观变化？###从东到西：草原→荒漠草原→荒漠（降水逐渐减少）
西北地区河流特点？###河流稀少、多为季节性河流，是我国内流河的主要分布区
西北地区的畜牧业？###我国重要的畜牧业基地：贺兰山以东（呼伦贝尔草原、锡林郭勒草原）；以西山地（天山、阿尔泰山、祁连山高山牧场）
西北地区的灌溉农业区？###甘肃河西走廊、新疆绿洲（利用河水、地下水）；宁夏平原、内蒙古河套平原（引黄灌溉）
新疆成为我国最大棉花生产基地的条件？###光照充足、昼夜温差大，利于棉花生长和采摘

# 第11节 干旱的宝地——塔里木盆地
塔里木盆地的位置？###位于我国新疆南部，天山山脉和昆仑山脉之间
塔里木盆地的自然环境？###深居内陆、被高大山脉环抱，气候干旱，戈壁沙漠广布；塔克拉玛干沙漠是我国面积最大的沙漠
塔里木盆地的绿洲分布？###分布在盆地边缘的山麓地带（水源充足），人口城镇沿绿洲分布
塔里木盆地的油气资源？###蕴藏丰富，是我国最大的内陆含油气盆地
西气东输工程？###将塔里木盆地的天然气输送到我国东部地区；是我国西部大开发的标志性工程（2002年开工）
西气东输的意义？###发挥西部资源优势、促进西部经济发展；缓解东部能源紧张；带动沿线经济发展
塔里木盆地的沙漠公路？###1995年建成第一条沙漠公路（轮台—民丰），为油气开发提供交通便利

# ===== 第十章 青藏地区 =====

# 第12节 自然特征与农业
青藏地区的位置？###位于我国西南部，昆仑山—祁连山以南、横断山脉以西，包括青藏高原
青藏高原的特点？###"世界屋脊"，平均海拔4000米以上；雪山连绵、冰川广布
青藏地区的气候？###高寒（海拔高、气温低、昼夜温差大、空气稀薄）；日照时间长、太阳能丰富
青藏高原的独特风光？###高寒牧区：牦牛（"高原之舟"）、藏绵羊、藏山羊
青藏地区的河谷农业？###分布在雅鲁藏布江谷地、湟水谷地等海拔较低地区，种植青稞、小麦、油菜
河谷农业农产品品质优良的原因？###日照时间长利于光合作用，昼夜温差大利于养分积累
藏族居民的生活？###主食糌粑、常喝酥油茶，传统服饰藏袍

# 第13节 "中华水塔"——三江源地区
三江源地区指？###长江、黄河、澜沧江的发源地（位于青海省南部，中华水塔）
三江源地区的生态环境？###雪山冰川广布、湿地面积广大，是世界高海拔地区生物多样性最集中的地区
三江源生态环境恶化的原因？###全球气候变暖、冰川退缩、过度放牧、乱采滥挖
三江源生态环境恶化的危害？###水源涵养功能下降、生物多样性减少、影响中下游生态安全
保护三江源的措施？###建立三江源自然保护区、退牧还草、禁采禁挖、生态移民
