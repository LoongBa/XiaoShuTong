我国海陆位置的优越性？###位于亚欧大陆东部、太平洋西岸，海陆兼备；西部深入亚欧大陆内部，陆上与许多国家接壤；海岸线曲折漫长
我国的陆地领土面积约是多少？###约960万平方千米，仅次于俄罗斯和加拿大，居世界第三位
我国陆上邻国有多少个？###14个
我国隔海相望的国家有多少个？###8个（其中与朝鲜、越南既陆上相邻又隔海相望）
我国大陆濒临的海洋，从北到南依次是？###渤海、黄海、东海、南海（渤海、琼州海峡是我国的内海）
我国大陆海岸线长约？###1.8万千米
我国主张管辖海域面积约？###300万平方千米
我国领土最南端和最北端？###最南端：海南省南沙群岛的曾母暗沙附近；最北端：黑龙江省漠河市北端

我国两个特别行政区是？###香港、澳门
山东省的简称和省会是？###鲁，济南

# 第4节 地形
我国地势的总体特征？###西高东低，呈三级阶梯状分布
我国第一级阶梯的地形以什么为主？###高原（青藏高原，平均海拔4000米以上，被称为"世界屋脊"）
我国第二级阶梯的地形以什么为主？###高原和盆地（内蒙古高原、黄土高原、云贵高原、塔里木盆地、准噶尔盆地、四川盆地）
我国第三级阶梯的地形以什么为主？###平原和丘陵（东北平原、华北平原、长江中下游平原、东南丘陵）
我国第一、二级阶梯分界线？###昆仑山脉-祁连山脉-横断山脉
我国第二、三级阶梯分界线？###大兴安岭-太行山脉-巫山-雪峰山
我国四大高原及特征？###青藏高原（最高，"世界屋脊"）、内蒙古高原（平坦开阔）、黄土高原（千沟万壑、水土流失严重）、云贵高原（喀斯特地貌、地面崎岖）
我国四大盆地？###塔里木盆地（最大，内有塔克拉玛干沙漠）、准噶尔盆地（纬度最高）、柴达木盆地（"聚宝盆"，海拔最高）、四川盆地（"紫色盆地""天府之国"）
我国三大平原？###东北平原（最大，黑土地）、华北平原（黄土地）、长江中下游平原（"鱼米之乡"）
我国山区面积约占总面积的多少？###约2/3（山区面积广大）
我国东西走向的主要山脉有？###天山-阴山、昆仑山-秦岭、南岭

# 第5节 气候
我国主要的气候类型有哪些？###温带季风气候、亚热带季风气候、热带季风气候、温带大陆性气候、高原山地气候
我国气候的主要特征是？###气候复杂多样、季风气候显著
我国季风区与非季风区的分界线？###大兴安岭-阴山-贺兰山-巴颜喀拉山-冈底斯山
影响我国气候的主要因素？###纬度位置、海陆位置、地形
我国划分的温度带有？###寒温带、中温带、暖温带、亚热带、热带、高原气候区
我国划分的干湿地区有？###湿润区、半湿润区、半干旱区、干旱区
秦岭-淮河一线的地理意义？###大致与1月0℃等温线、800毫米年等降水量线吻合，是南北方分界线、水田旱地分界线
我国冬季气温分布特点？###南暖北冷，南北温差大
我国夏季气温分布特点？###全国普遍高温（青藏高原除外）
我国年降水量分布总趋势？###从东南沿海向西北内陆递减

# 第6节 河流与湖泊
我国河流分为哪两类？###外流河（最终流入海洋）和内流河（最终未流入海洋）
外流河主要分布在哪里？###东部季风区
内流河主要分布在哪里？###西北内陆地区（最大内流河是塔里木河）
我国最长的河流是？###长江（6300多千米，发源于青藏高原唐古拉山脉，注入东海）
长江上中下游分界点？###宜昌（上中游）、湖口（中下游）
长江被称为"黄金水道"的原因是？###航运价值高，干支流通航里程长
长江流域可持续发展原则？###"生态优先，绿色发展"
我国含沙量最大的河流是？###黄河
黄河发源于？###青藏高原巴颜喀拉山脉，注入渤海
黄河"地上河"出现在哪个河段？###下游（华北平原段，因泥沙淤积河床抬高）
黄河的治理措施？###上中游保持水土（植树造林、退耕还林还草），下游加固堤坝、疏浚河道
我国汛期最长的河流是？###珠江
我国最长的人工河是？###京杭运河
我国主要的淡水湖？###鄱阳湖（最大淡水湖）、洞庭湖等
我国最大的咸水湖？###青海湖

# 第7节 自然灾害
我国自然灾害的特点是？###灾害种类多、发生频率高、分布广，是世界上自然灾害较为严重的国家之一
我国常见的气象灾害有？###旱灾、洪涝、台风、寒潮
旱灾、洪涝灾害主要分布在哪里？###东部季风区（东部平原和沿海地区洪涝多发；秦岭-淮河一线以北旱灾多发）
台风灾害主要分布在哪里？###东南沿海地区
寒潮灾害主要影响？###北方地区（大风降温、雨雪冰冻）
我国常见的地质灾害有？###地震、滑坡、泥石流
我国地跨哪两条地震带？###环太平洋地震带与地中海-喜马拉雅地震带
滑坡、泥石流多发区？###山区（西南地区等）

# ===== 第三章 中国的自然资源 =====

# 第8节 自然资源
什么是可再生资源？###可以在较短时间内更新、再生，或可以循环使用的资源（如土地、水、森林、太阳能）
什么是非可再生资源？###用一点就少一点，短时间内不能再生或循环使用的资源（如矿产）

# 第9节 土地资源
我国土地资源的主要特征？###土地资源总量丰富、类型多样，但人均土地资源远低于世界人均水平；分布不均、区域差异明显
我国耕地主要分布在哪里？###东部湿润、半湿润区的平原和低山丘陵区
我国林地主要分布在哪里？###山区（东北、西南、东南）
我国草地主要分布在哪里？###西部干旱、半干旱区（用于牧业）
我国耕地紧缺到什么程度？###人均耕地面积不到0.1公顷（约1/4的耕地是梯田）
合理利用土地资源的原则？###尊重自然规律，因地制宜地统筹安排各类用地

# 第10节 水资源
我国水资源的时空分布特点？###空间上南多北少（东多西少）；时间上夏秋多、冬春少，年际变化大
解决水资源空间分布不均的措施？###跨流域调水（南水北调工程）
解决水资源时间分配不均的措施？###修建水库（调节径流）
南水北调工程？###把长江流域的水调往华北、西北地区，缓解北方缺水

# 第11节 矿产资源
我国矿产资源的总特点？###世界矿产资源种类齐全、储量丰富的国家之一；已探明矿产资源储量大、居世界前列；但人均矿产资源储量低于世界人均水平
我国能源矿产（煤炭、石油、天然气）的分布特点？###多煤少油气，总体北多南少、西多东少；近海地区油气储量不断增长
我国煤炭储量主要分布在？###山西、内蒙古、新疆等（可开采储量占比大）
我国已探明大型油气田盆地主要分布在？###东北、华北、西北（新疆、陕西、内蒙古、四川等）
我国铁矿资源特点？###储量排世界第四位，但贫矿多、富矿少
我国储量居世界首位的矿产？###钨、锡、锑；稀土、锂、镓、铟等三稀矿产储量居世界首位
我国矿产资源供需矛盾？###"有而不够、有而不优"——作为世界最大制造业国家，多数矿产需要从国外进口（石油、铜、铁、铝土、锂等）
我国铁矿石进口主要来自？###澳大利亚、巴西等
保障矿产资源供给的措施？###加强国内勘探、提高利用效率、发展循环利用（如废钢铁回收）、保障战略资源安全

# 海洋资源
我国海洋资源特点？###海域辽阔、自然条件优越，是世界最大的海鱼、海盐生产国
我国主要的渔场？###舟山渔场等（众多优质渔场）；海洋渔业中海水养殖量已超过海洋捕捞量
我国最大的盐场？###长芦盐场（渤海沿岸，我国最大海盐盐场）
我国海洋石油和天然气主要分布？###渤海和南海北部的大陆架
我国海洋清洁能源？###海上风电、潮汐能等
我国沿海港口群？###环渤海、长三角、东南沿海、珠三角、西南沿海五大港口群
我国海洋资源开发原则？###优化近海综合利用，大力发展生态友好型"海洋牧场"，保护海洋生态

# ===== 第四章 中国的经济发展 =====

# 第12节 农业
农业包括哪些部门？###种植业、畜牧业、林业、渔业
我国农业生产的区域差异（东西）？###东部农区水热条件优越，以种植业、林业、渔业为主；西部牧区降水较少，畜牧业地位重要，种植业分布在有灌溉条件的绿洲
我国农业生产的区域差异（南北）？###秦岭-淮河以北以旱地为主（小麦、玉米），以南多水田（水稻）；长城沿线以北一年一熟，以南两年三熟或一年两熟
我国三大主粮是？###水稻（长江中下游平原和东北平原）、小麦（华北平原产量最大）、玉米（东北平原和华北平原）
我国棉花主要产自哪里？###新疆（超过80%的棉花产自新疆）
我国糖料作物分布？###南方甘蔗、北方甜菜（甜菜主要分布在北方）
高标准农田的特点？###集中连片、旱涝保收

# 第13节 工业
我国工业的现状？###门类齐全的工业大国：世界唯一拥有联合国产业分类中全部工业门类的国家；2010年以后成为世界第一工业制造大国
我国工业的分布特点？###自然资源开采、原材料加工多集中在中西部资源丰富地区；机械设备、电子产品生产多集中在东部沿海地区；工业增加值看，东部沿海地区和长江沿线地区集中了我国重要的工业城市
我国高新技术产业？###信息通信网络覆盖全国；"东数西算"工程（把东部数据传输到西部处理，发挥西部能源优势）
工业绿色转型方向？###发展低碳工业、新能源汽车、资源循环利用

# 第14节 交通运输
我国交通运输现状？###已形成由公路、铁路、航空、内河航道等组成的庞大交通网；拥有世界最大的高速铁路网、高速公路网和世界级港口群、机场群
我国交通线分布格局？###东密西疏（受自然环境、人口分布、经济发展影响；地形平坦、人口密集地区交通线稠密）
我国高速公路网？###首都放射线、南北纵线、东西横线组成的高速公路网
我国高速铁路网？###"四纵四横"为主骨架，连接直辖市、省会城市及其他大中城市
陇海-兰新铁路？###东起江苏连云港，西至新疆阿拉山口，出境后成为新亚欧大陆桥的重要通道

# ===== 第五章 建设美丽中国 =====

# 第15节 自然灾害与防灾减灾
防灾减灾的重要意义？###防灾减灾是建设美丽中国的基本保障
我国主要气象灾害的分布？###旱灾洪涝（东部季风区）、台风（东南沿海）、寒潮（北方及全国大部）
我国主要地质灾害的分布？###地震（环太平洋地震带与地中海-喜马拉雅地震带）、滑坡泥石流（山区）
防灾减灾的主要措施？###建立灾害监测预警系统、加强防灾工程、提高公众防灾意识、制定应急预案
遇到地震如何自救互救？###躲在坚固物体旁、护住头部；震后有序撤离到空旷地带
洪水来袭如何自救？###向高处转移、避开电线杆和危房、不涉水强行通过

# 第16节 环境保护与发展
我国面临的主要环境问题？###大气污染、水污染、土壤污染、水土流失、土地荒漠化等
"两山"理念？###"绿水青山就是金山银山"
生态文明建设的要求？###坚持人与自然和谐共生；加快发展科技含量高、资源消耗低、环境污染少的产业
建设美丽中国的内涵？###青山就是美丽，蓝天也是幸福，良好生态环境是建设美丽中国的重要基础
绿色发展的重要途径？###碳中和（节能减排）、绿色能源、循环经济、生态保护与修复
