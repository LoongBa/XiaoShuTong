# 七年级上册 地理 背诵内容测试题
# 教材：人教统编版 2024 修订版（5 章 15 节）
# 格式：问题###答案（# 开头为注释）

# ===== 第一章 地球和地图 =====

# 第1节 地球的形状和大小
地球的形状是？###一个两极稍扁、赤道略鼓的不规则球体
地球的平均半径是？###6371千米
地球的赤道周长是？###约4万千米
地球的表面积是？###约5.1亿平方千米
证明地球形状的证据有？###月食、麦哲伦环球航行、地球卫星照片

# 第2节 地球的运动
地球自转的方向是？###自西向东
地球自转的周期是？###约24小时（一天）
地球自转产生的现象是？###昼夜交替、时间差异
地球公转的方向是？###自西向东
地球公转的周期是？###约365天（一年）
地球公转产生的现象是？###四季变化、五带划分、昼夜长短变化
五带的划分是？###热带、北温带、南温带、北寒带、南寒带

# 第3节 地图的阅读
比例尺的公式是？###比例尺=图上距离÷实际距离
比例尺的三种表示方式是？###数字式、文字式、线段式
比例尺大小的比较是？###分母越大，比例尺越小；分母越小，比例尺越大
地图上辨别方向的方法有？###经纬网定向、指向标定向、一般定向（上北下南左西右东）
常见的图例符号有？###铁路、公路、山峰、河流、城市等

# 第4节 地形图的判读
海拔的定义是？###地面某个地点高出海平面的垂直距离
相对高度的定义是？###某个地点高出另一个地点的垂直距离
等高线地形图中，等高线密集表示？###坡度陡
等高线地形图中，等高线稀疏表示？###坡度缓
五种基本地形类型是？###高原、山地、盆地、平原、丘陵
山地的地形特点是？###海拔较高，坡度较陡，沟谷较深

# ===== 第二章 陆地和海洋 =====

# 第5节 大洲和大洋
七大洲的名称和面积从大到小是？###亚洲、非洲、北美洲、南美洲、南极洲、欧洲、大洋洲
四大洋的名称和面积从大到小是？###太平洋、大西洋、印度洋、北冰洋
亚洲与欧洲的分界线是？###乌拉尔山脉、乌拉尔河、里海、大高加索山脉、黑海、土耳其海峡
亚洲与非洲的分界线是？###苏伊士运河
北美洲与南美洲的分界线是？###巴拿马运河
面积最大的大洲是？###亚洲
面积最大的大洋是？###太平洋

# 第6节 海陆的变迁
大陆漂移假说的提出者是？###魏格纳
全球大致划分为几大板块？###六大板块（亚欧板块、非洲板块、印度洋板块、太平洋板块、美洲板块、南极洲板块）
板块运动的特点是？###板块内部地壳比较稳定，板块与板块交界地带地壳比较活跃
世界两大火山地震带是？###环太平洋火山地震带、地中海—喜马拉雅火山地震带
喜马拉雅山脉的形成原因是？###亚欧板块与印度洋板块碰撞挤压

# 第7节 海陆分布
海洋与陆地的比例是？###七分海洋（71%）三分陆地（29%）
北半球的海陆分布特点是？###陆地面积较大，海洋面积也较大
南半球的海陆分布特点是？###海洋面积远大于陆地面积

# ===== 第三章 天气与气候 =====

# 第8节 多变的天气
天气与气候的区别是？###天气是短时间的大气状况，气候是长时间的天气平均状况
天气预报的符号有？###阴晴、风力风向、气温、降水等
空气质量的高低用什么表示？###空气质量指数（AQI）

# 第9节 气温的变化与分布
一天中最高气温出现的时间是？###午后2时左右
一天中最低气温出现的时间是？###日出前后
一年中北半球最高气温出现的月份是？###7月
一年中北半球最低气温出现的月份是？###1月
气温分布的基本规律是？###从低纬向高纬递减
影响气温分布的因素有？###纬度位置、海陆分布、地形

# 第10节 降水的变化与分布
降水的分布规律是？###赤道附近降水多，两极地区降水少；回归线附近大陆东岸降水多，西岸降水少；中纬度沿海地区降水多，内陆降水少
影响降水分布的因素有？###纬度位置、海陆位置、地形
山地降水的特点是？###迎风坡降水多，背风坡降水少

# 第11节 世界的气候
热带气候类型有？###热带雨林气候、热带草原气候、热带季风气候、热带沙漠气候
温带气候类型有？###温带海洋性气候、温带大陆性气候、温带季风气候、亚热带季风气候
寒带气候类型有？###苔原气候、冰原气候
影响气候的主要因素是？###纬度位置、海陆位置、地形
热带雨林气候的特点是？###全年高温多雨
热带沙漠气候的特点是？###全年高温少雨

# ===== 第四章 居民与聚落 =====

# 第12节 人口与人种
世界人口增长的特点是？###18世纪前增长缓慢，二战后增长迅速
人口密度的定义是？###每平方千米内居住的人口数
三大人种是？###黄色人种、白色人种、黑色人种
黄色人种的主要分布地区是？###亚洲东部
白色人种的主要分布地区是？###欧洲、北美洲、大洋洲、西亚北非
黑色人种的主要分布地区是？###非洲中部和南部

# 第13节 语言和宗教
世界六大语言是？###汉语、英语、法语、俄语、西班牙语、阿拉伯语
使用人数最多的语言是？###汉语
使用范围最广的语言是？###英语
三大宗教是？###基督教、伊斯兰教、佛教
基督教的经典是？###《圣经》
伊斯兰教的经典是？###《古兰经》
佛教的经典是？###《佛经》

# ===== 第五章 发展与合作 =====

# 第14节 人类的居住地——聚落
城市与乡村的差异是？###城市人口密度大，乡村人口密度小；城市以非农业为主，乡村以农业为主
聚落形成与发展的条件是？###地形平坦、土壤肥沃、水源充足、交通便利、自然资源丰富

# 第15节 发展与合作
发达国家与发展中国家的分布特点是？###发达国家主要分布在北半球北部，发展中国家主要分布在南半球和北半球南部
"南南合作"的含义是？###发展中国家之间的合作
"南北对话"的含义是？###发展中国家与发达国家之间的政治、经济商谈
