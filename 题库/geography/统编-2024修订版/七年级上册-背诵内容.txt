# ===== 第一章 地球 =====

# 第一节 地球的宇宙环境
太阳系有几颗行星？###八颗（水星、金星、地球、火星、木星、土星、天王星、海王星）
按距日由近及远的行星排序是？###水星、金星、地球、火星、木星、土星、天王星、海王星
为什么说地球是迄今人类唯一的家园？###地球距太阳距离适中、体积质量适中，易形成适合生命存在的温度、大气和水等条件
人类第一颗人造地球卫星发射时间和国家是？###1957年，苏联（东方红一号为我国1970年发射第一颗人造卫星）
我国太空探索的重要成就？###1970东方红一号、2003神舟五号载人航天、2016中国天眼、2022天宫空间站全面建成

# 第二节 地球与地球仪
地球的形状是？###一个两极稍扁、赤道略鼓的不规则球体
人类认识地球形状的过程？###天圆地方→麦哲伦环球航行确证地球是球体→卫星影像精确测定
地球的平均半径是？###约6371千米
地球的最大周长（赤道周长）是？###约4万千米
地球的表面积是？###约5.1亿平方千米
地球仪上地轴与球面的交点叫？###两极（对着北极星方向的叫北极，是地球最北点；对应为南极）
地球仪上连接南北两极的半圆叫？###经线（子午线）
与经线垂直、绕地球一周的圆圈叫？###纬线（赤道是最长的纬线）

# 第三节 地球的运动
地球自转的方向和周期是？###自西向东；约24小时（一天）
地球自转产生的现象是？###昼夜交替、时间差异
地球公转的方向和周期是？###自西向东；约365天（一年）
地球公转产生的现象是？###四季变化、五带划分、昼夜长短变化
五带的划分是？###热带、北温带、南温带、北寒带、南寒带

# ===== 第二章 地图 =====

# 第一节 地图的阅读
比例尺的公式是？###比例尺=图上距离÷实际距离
比例尺的三种表示方式是？###数字式、文字式、线段式
比例尺大小的比较？###分母越大比例尺越小；分母越小比例尺越大
地图上辨别方向的方法有？###经纬网定向、指向标定向、一般定向（上北下南左西右东）
图例是？###地图上各种符号和颜色的说明（教学地图三要素：比例尺、方向、图例）

# 第二节 地形图的判读
海拔的定义是？###地面某个地点高出海平面的垂直距离
相对高度的定义是？###某个地点高出另一个地点的垂直距离
等高线密集表示？###坡度陡
等高线稀疏表示？###坡度缓
五种基本地形类型是？###高原、山地、盆地、平原、丘陵

# ===== 第三章 陆地和海洋 =====

# 第一节 大洲和大洋
七大洲是？###亚洲、非洲、北美洲、南美洲、南极洲、欧洲、大洋洲
四大洋是？###太平洋、大西洋、印度洋、北冰洋
面积最大的大洲是？###亚洲
面积最大的大洋是？###太平洋
面积最小的大洋是？###北冰洋

# 第二节 世界的地形
世界陆地最高点与最低点？###珠穆朗玛峰（约8848.86米）与死海
平原与高原的区别？###平原海拔较低、起伏小；高原海拔较高、边缘陡峭顶部平坦

# 第三节 海陆的变迁
海陆变迁的原因有？###地壳运动、海平面升降、人类活动
板块构造学说认为？###地球岩石圈由六大板块组成，板块交界地带地壳活跃、多火山地震
世界上主要有哪两大火山地震带？###环太平洋火山地震带、地中海—喜马拉雅火山地震带

# ===== 第四章 天气与气候 =====

# 第一节 多变的天气
天气与气候的区别？###天气是短时间大气状况，多变；气候是多年平均状况，较稳定
天气预报中表示降雨的符号？###雨点/云+雨滴等（晴、多云、阴、雨、雪等）
空气质量指数与空气的关系？###指数越大，空气质量越差（污染越重）

# 第二节 气温的变化与分布
气温日变化中一天最低气温出现在？###日出前后
气温年变化中北半球大陆最热月是？###7月（最冷月1月）
气温从低纬向高纬的变化规律？###逐渐降低
同纬度海拔越高气温越低（每升高100米约降）？###约0.6℃

# 第三节 降水的变化与分布
世界降水分布规律？###赤道附近多雨、两极少雨；中纬度沿海多内陆少；回归线附近大陆东岸多西岸少
降水的主要形式？###降雨（还有降雪、冰雹）

# 第四节 世界的气候
热带雨林气候的特征？###全年高温多雨
地中海气候的特征？###夏季炎热干燥、冬季温和多雨（分布在地中海沿岸等）
影响气候的主要因素？###纬度位置、海陆位置、地形

# ===== 第五章 居民与文化 =====

# 第一节 人口与人种
世界人口稠密地区？###亚洲东部和南部、欧洲、北美洲东部
世界人口稀疏地区？###极端干旱的沙漠、湿热的热带雨林、寒冷的高纬度、高峻山地
世界三大人种是？###黄色人种、白色人种、黑色人种

# 第二节 城镇与乡村
聚落分为哪两种？###城市聚落（从事非农业生产）与乡村聚落（从事农业生产）

# 第三节 多样的文化
世界主要语言中使用人数最多的是？###汉语
使用最广泛的语言是？###英语

# ===== 第六章 发展与合作 =====
什么是发展中国家与发达国家？###根据经济发展水平高低划分；发达国家集中在欧洲、北美、大洋洲等，发展中国家多分布在亚洲、非洲、拉丁美洲
当代世界面临的主要问题之一？###人口、资源、环境与发展问题（南北对话、南南合作含义）
国际合作的例子？###联合国等国际组织促进各国经济文化合作与交流
