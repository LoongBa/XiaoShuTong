## 二、核心记忆性知识点

### 1. 行政区划（🟢 必考，34 组）

| 类别 | 记忆点 |
|------|--------|
| 34 省级行政区 | 23 省 + 5 自治区 + 4 直辖市 + 2 特别行政区 |
| 全称-简称-省会 | 山东-鲁-济南；湖北-鄂-武汉；四川-川/蜀-成都；云南-云/滇-昆明；陕西-陕/秦-西安 |
| 双简称 | 川/蜀、云/滇、贵/黔、陕/秦、甘/陇（5 组） |
| 直辖市 | 北京-京、天津-津、上海-沪、重庆-渝 |
| 特别行政区 | 香港-港、澳门-澳 |
| 易错省会 | 广西-南宁（非桂林）、福建-福州（非厦门）、青海-西宁 |

### 2. 地形（🟢 必考）

| 类别 | 记忆点 |
|------|--------|
| 三级阶梯 | 一二级分界：昆仑山-祁连山-横断山；二三级分界：大兴安岭-太行山-巫山-雪峰山 |
| 四大高原 | 青藏（最高，雪山冰川）、内蒙古（平坦，草原）、黄土（千沟万壑）、云贵（喀斯特，崎岖） |
| 四大盆地 | 塔里木（最大，沙漠）、准噶尔（纬度最高）、柴达木（海拔最高）、四川（紫色，天府） |
| 三大平原 | 东北（最大，黑土）、华北（黄土地）、长江中下游（鱼米之乡） |
| 主要山脉 | 东西走向：天山-阴山、昆仑山-秦岭、南岭；东北-西南：大兴安岭-太行山-巫山-雪峰山 |

### 3. 气候（🟢 必考）

| 类别 | 记忆点 |
|------|--------|
| 5 种气候类型 | 温带季风、亚热带季风、热带季风、温带大陆性、高原山地 |
| 6 温度带 | 寒温带、中温带、暖温带、亚热带、热带、高原气候区 |
| 4 干湿区 | 湿润、半湿润、半干旱、干旱 |
| 秦岭-淮河意义 | 1月0℃等温线、800mm 等降水量线、南北方分界、水田/旱地分界 |

### 4. 河流（🟢 必考）

| 类别 | 记忆点 |
|------|--------|
| 长江 | 发源唐古拉山，注入东海，流经 11 省，"黄金水道"；上中下游分界：宜昌/湖口 |
| 黄河 | 发源巴颜喀拉山，注入渤海，流经 9 省，"地上河"；分界：河口/桃花峪 |
| 珠江 | 汛期最长 |
| 塔里木河 | 最大内流河 |
| 京杭运河 | 最长人工河 |

### 5. 自然资源（🟡 中）

| 类别 | 记忆点 |
|------|--------|
| 耕地 | 东部季风区；北旱地（小麦）南水田（水稻） |
| 林地 | 东北、西南、东南 |
| 草地 | 内蒙古高原、青藏高原 |
| 矿产 | 煤（山西）、铁（辽宁/河北/四川）、石油（大庆/胜利） |
| 水资源 | 南多北少；南水北调工程 |

### 6. 交通与工农业（🟡 中）

| 类别 | 记忆点 |
|------|--------|
| 铁路 | 南北干线：京广线、京沪线；东西干线：陇海线 |
| 四大工业基地 | 辽中南（重工业）、京津唐（北方最大）、沪宁杭（最大）、珠江三角洲 |
| 农业 | 南方水稻、北方小麦；甘蔗南方、甜菜北方 |
