# 四年级上册 语文背诵内容背景钩子（记忆增强器）

> 用途：背诵时展示的"记忆钩子"，用故事化背景帮助精细复述，强化记忆
> 展示时机：✕ 阶段学习新篇目时展示；△○★ 复习时默认隐藏，卡壳时由 AI 导师按需提示
> 设计原则：讲故事，不考核。中高年级（9-11 岁）含"作者定位 + 创作背景 + 记忆钩子 + 关联作品"

# ===== 课内古诗 =====

## 《题西林壁》苏轼/宋
- **作者定位**：苏轼，字子瞻，号东坡居士，北宋大文豪，诗文书画俱佳，与父苏洵、弟苏辙并称"三苏"
- **创作背景**：苏轼游玩江西庐山，在西林寺的墙壁上题下这首诗。庐山云雾缭绕，远近高低各个角度看都不一样
- **记忆钩子**："不识庐山真面目，只缘身在此山中"——因为身在庐山之中，反倒看不清庐山的全貌。道理：旁观者清，当局者迷
- **关联作品**：苏轼《饮湖上初晴后雨》（三上）同写风景与哲理

## 《游山西村》陆游/宋
- **作者定位**：陆游，字务观，号放翁，南宋爱国诗人，一生不忘收复中原
- **创作背景**：陆游被罢官回乡，闲居山阴（今浙江绍兴），游山西村，受到农民热情款待，写下这首诗
- **记忆钩子**："山重水复疑无路，柳暗花明又一村"——走到没路的"绝境"，转过弯又是新天地。名句意思是：困境中总会有希望
- **关联作品**：陆游"王师北定中原日，家祭无忘告乃翁"（《示儿》）同是爱国名篇

## 《过故人庄》孟浩然/唐
- **作者定位**：孟浩然，唐代山水田园诗人，与王维并称"王孟"，一生未做官，隐居襄阳
- **创作背景**：老朋友准备了饭菜，请孟浩然到农家做客。绿树环绕、青山斜倚，两人开窗面对谷场菜园，把酒聊农事
- **记忆钩子**："绿树村边合，青山郭外斜"写景；"待到重阳日，还来就菊花"写约。记住：做客+吃饭+看景+再来
- **关联作品**：孟浩然《春晓》（一下）耳熟能详；唐代田园诗派代表即"王孟"

# ===== 文言文 =====

## 《精卫填海》文言文（选自《山海经》）
- **作者定位**：《山海经》是我国古代一部志怪古籍，保存了大量神话传说
- **创作背景**：上古神话——炎帝的小女儿女娃在东海游玩时溺亡，化为精卫鸟，立志用石子填平大海
- **记忆钩子**："常衔西山之木石，以堙于东海"——精卫日复一日衔石填海，象征坚韧不拔、敢于坚持。成语"精卫填海"由此而来
- **关联作品**：《山海经》里还有"夸父逐日""后羿射日"等神话；与《愚公移山》都是"锲而不舍"的主题

## 《王戎不取道旁李》文言文（选自《世说新语》）
- **作者定位**：《世说新语》由南朝宋刘义庆组织门客编写，记录东汉末至魏晋名士的言行轶事
- **创作背景**：王戎是西晋名士，"竹林七贤"之一，自幼聪慧有主见
- **记忆钩子**：别的孩子都抢着摘路边李子，只有王戎不动——"树在道边而多子，此必苦李"（路边的李子如果甜早就被摘光了）。学会推理，眼见不如脑想
- **关联作品**：《世说新语》是志人小说集，与志怪神话书《山海经》相对照

# ===== 日积月累古诗 =====

## 《鹿柴》王维/唐
- **作者定位**：王维，字摩诘，唐代大诗人、画家，人称"诗佛"，诗中有画、画中有诗
- **创作背景**：鹿柴（zhài）是王维终南山辋川别墅的一处景。空山不见人影，只闻人声
- **记忆钩子**：以"有声"衬"无声"（但闻人语响），以"光亮"衬"幽暗"（返景照青苔）。记住：不见人、闻人语、深林、青苔
- **关联作品**：王维《九月九日忆山东兄弟》（三下）同为名篇；"诗中有画"是他最大的标签

## 《浪淘沙（其一）》刘禹锡/唐
- **作者定位**：刘禹锡，字梦得，唐代诗人，人称"诗豪"
- **创作背景**：刘禹锡在黄河边作此诗，"浪淘沙"本为唐代曲名。黄河裹挟万里泥沙，奔腾到天涯
- **记忆钩子**："同到牵牛织女家"——黄河水淘呀淘，仿佛要直达银河、牛郎织女家。夸张的想象是"诗豪"本色
- **关联作品**：刘禹锡与柳宗元并称"刘柳"；其"沉舟侧畔千帆过"也是千古名句

## 《江南春》杜牧/唐
- **作者定位**：杜牧，字牧之，唐代诗人，与李商隐并称"小李杜"
- **创作背景**：杜牧游江南，见千里莺啼、红花绿柳、水村山郭、酒旗飘飘，又见南朝寺庙掩映在烟雨中
- **记忆钩子**：大处着墨（千里）+ 细小点染（酒旗）——像一幅水墨画。"南朝四百八十寺，多少楼台烟雨中"暗含历史兴衰的感慨
- **关联作品**：杜牧《清明》（三下）同为写江南的名篇

## 《书湖阴先生壁》王安石/宋
- **作者定位**：王安石，字介甫，北宋政治家、文学家，"唐宋八大家"之一
- **创作背景**：湖阴先生是王安石隐居江宁（今南京）时的邻居杨德逢。王安石题诗在他家墙上
- **记忆钩子**：庭院整洁（净无苔）、花木成畦，绿水护田、青山送翠——"护""送"二字把山水写活了，好像山水有心亲近人
- **关联作品**：王安石《元日》（三下）同为其代表作；"一水护田，两山排闼"是拟人写法的典范
