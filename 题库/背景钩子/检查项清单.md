# 背景钩子检查项清单（7 维核对法）

> 用途：对每个古诗文篇目的背景钩子做系统性核对，确保文学常识覆盖完整
> 方法：先看"要查什么"（本清单），再逐篇逐维核对，标记 ✔ 有 / △ 部分 / ✘ 缺失，最后补齐缺失项
> 适用范围：7-9 年级全部古诗文篇目

---

## 七个核对维度

| 维度 | 检查内容 | 典型示例 |
|------|---------|---------|
| **A 作者定位** | 朝代/字号/称号/文学地位/**并称**/流派 | 李白号"青莲居士"，与杜甫并称"李杜"；刘禹锡称"诗豪"，与柳宗元并称"刘柳" |
| **B 人物关系** | 赠答对象/唱和/交往/家族师承 | 李白写诗慰王昌龄贬谪；杜甫重逢李龟年；诸葛亮写给儿子诸葛瞻 |
| **C 创作时空** | 时间/地点/**境遇**（被贬/赴任/出征/羁旅/隐居） | 曹操北征乌桓凯旋登碣石；刘禹锡被贬朗州写《秋词》；陆游闲居山阴 |
| **D 地理钩子** | 诗内地名 → 今地对照 | 龙标=湖南黔阳；北固山=江苏镇江；受降城=内蒙古 |
| **E 用典成语** | 化用典故/衍生成语 | "左迁"=降职；"天塌下来"出自杞人忧天；陶渊明菊酒典故 |
| **F 关联作品** | 教材内同作者/同主题篇目互链 | 《诫子书》↔《出师表》；《峨眉山月歌》↔《渡荆门送别》（同一段旅程） |
| **G 趣闻点评** | 历史评价/文坛轶事/记忆锚点 | "海日生残夜"被张说挂政事堂；《天净沙》被称"秋思之祖" |

## 操作流程

1. 打开篇目清单（`题库/背诵篇目清单-7-9年级.md`）确认全部篇目
2. 对每个篇目过 7 维，逐项标记 ✔/△/✘
3. 汇总 ✘/△ 项 → 输出"差异清单"
4. 按差异清单补齐背景钩子
5. 复核对账（差异清单逐项关闭）
