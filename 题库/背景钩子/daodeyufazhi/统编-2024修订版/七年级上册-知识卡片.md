# 七年级上册 道德与法治 知识卡片（concept_card）

> 用途：背诵时展示的记忆增强卡片，用关键词锚定 + 易混点对比 + 口诀辅助精细复述
> 展示时机：✕ 阶段学习新知识点时展示；△○★ 复习时默认隐藏，卡壳时由 AI 导师按需提示
> 设计原则：正面问题化、关键词锚定、层级递进、易混点配对

---

# ===== 第一单元 成长的节拍 =====

## 中学时代
- **意义**：人生发展的一个新阶段，为我们的一生奠定重要基础
- **关键词**：新阶段 / 奠定基础
- **易混点**：中学时代（新阶段）vs 小学时代（启蒙阶段）
- **口诀**："中学新阶段，一生奠基础"

## 梦想与努力
- **少年梦想特点**：天真无邪美丽可爱；与个人人生目标紧密相连；与时代脉搏紧密相连
- **核心观点**：努力是梦想与现实之间的桥梁
- **关键词**：天真无邪 / 人生目标 / 时代脉搏 / 努力
- **易混点**：梦想（愿望）vs 目标（具体）vs 努力（行动）
- **口诀**："梦想三特点，努力是桥梁"

## 学习的意义
- **两重意义**：让我们能够生存，拥有更充实的生活；点亮心中的明灯，激发前进的动力
- **学会学习**：发现并保持学习兴趣、掌握科学学习方法、善于运用不同学习方式
- **关键词**：生存 / 充实生活 / 点亮明灯 / 激发动能
- **易混点**：学习意义（宏观）vs 学习方法（具体）
- **口诀**："学习意义大，生存加充实；学会三方法，兴趣方法方式"

## 认识自己
- **途径**：自我评价、他人评价
- **做更好的自己**：接纳欣赏自己、扬长避短、主动改正缺点、不断激发潜能
- **关键词**：自我评价 / 他人评价 / 接纳欣赏 / 扬长避短
- **易混点**：认识自己（了解）vs 做更好的自己（行动）
- **口诀**："认识两途径，更好四方法"

# ===== 第二单元 友谊的天空 =====

## 友谊的特质
- **三特质**：亲密的关系、平等双向、心灵的相遇
- **澄清**：友谊不是一成不变的、竞争不必然伤害友谊、友谊不能没有原则
- **关键词**：亲密 / 平等双向 / 心灵相遇 / 不变 / 原则
- **易混点**：友谊（情感）vs 友情（关系）
- **口诀**："友谊三特质，澄清三要点"

## 交友的智慧
- **建立**：开放自己、持续行动
- **呵护**：关怀对方、尊重对方、正确处理冲突、承受伤害
- **网络交友**：理性辨别慎重选择、自我保护意识、转化为现实朋友要慎重
- **易混点**：建立友谊（开始）vs 呵护友谊（维护）
- **口诀**："建立开放加行动，呵护关怀加尊重"

# ===== 第三单元 师长情谊 =====

## 教师职业
- **特点**：人类文明的主要传承者之一、承担教书育人的使命、履行教育教学职责的专业人员
- **良好状态**：学生乐于学习，老师寓教于乐，师生彼此尊重、相互关心、携手共进
- **关键词**：传承者 / 教书育人 / 专业人员 / 教学相长
- **易混点**：教师（职业）vs 老师（称呼）
- **口诀**："教师三特点，传承育人专业"

## 亲情之爱
- **家的意义**：身心的寄居之所、心灵的港湾
- **化解亲子冲突**：互动沟通技巧、接纳父母做法、理解父母的爱
- **和谐家庭**：相互理解信任体谅包容、有效交流沟通、良好心态面对问题
- **关键词**：寄居之所 / 心灵港湾 / 沟通技巧 / 理解包容
- **易混点**：家（物理空间）vs 家庭（关系组织）
- **口诀**："家是港湾靠沟通，理解包容建和谐"

# ===== 第四单元 生命的思考 =====

## 生命的特质
- **四特质**：来之不易、独特、不可逆、短暂
- **敬畏生命**：生命价值高于一切；珍惜自己生命，尊重关怀善待身边每一个人
- **关键词**：来之不易 / 独特 / 不可逆 / 短暂 / 高于一切
- **易混点**：生命特质（客观）vs 敬畏生命（态度）
- **口诀**："生命四特质，价值高于一切"

## 守护生命
- **两方面**：身体（健康生活方式）和精神（养护精神）
- **增强韧性**：发掘生命力量，培养勇气意志；与他人建立联系寻求帮助
- **关键词**：身体 / 精神 / 韧性 / 勇气 / 意志
- **易混点**：守护身体（物质）vs 养护精神（心理）
- **口诀**："守护两方面，身体加精神；韧性靠发掘，求助增力量"

## 生命的意义
- **理解**：需要自己发现和创造；实现自我价值；承担起自己的责任
- **活出精彩**：拒绝贫乏充盈生命；拒绝冷漠关切他人；在平凡中创造伟大
- **关键词**：发现创造 / 自我价值 / 责任 / 充盈 / 关切 / 平凡伟大
- **易混点**：生命意义（个人）vs 生命价值（社会）
- **口诀**："意义靠创造，精彩三拒绝"
