# ===== 第一单元 走进社会生活 =====

## 个人与社会
- **核心关系**：个人是社会的有机组成部分；人的身份是在社会关系中确定的
- **关键词**：有机组成部分 / 社会关系 / 身份确定
- **易混点**：个人与社会的关系 vs 个人与集体的关系（前者更宏观）
- **口诀**："个人社会不可分，身份关系来确定"

## 亲社会行为
- **定义**：谦让、分享、帮助他人、关心社会发展
- **养成时机**：在人际交往和社会实践中养成
- **关键词**：谦让 / 分享 / 帮助 / 关心 / 实践中养成
- **易混点**：亲社会行为（利他）vs 自利行为（利己）
- **口诀**："谦让分享助他人，社会实践养品行"
- **关联**：社会责任、奉献社会

## 网络素养
- **两面性**：丰富日常生活 + 推动社会进步
- **基本准则**：恪守道德和法律
- **关键词**：媒介素养 / 信息节食 / 辨析信息 / 道德法律
- **易混点**：网络丰富生活（个人层面）vs 网络推动进步（社会层面）
- **口诀**："网络双刃要分辨，媒介素养记心间"

# ===== 第二单元 遵守社会规则 =====

## 社会秩序
- **含义**：社会生活的一种有序化状态
- **作用**：社会正常运行需要秩序；社会秩序是人民安居乐业的保障
- **关键词**：有序化 / 正常运行 / 安居乐业
- **易混点**：社会秩序（宏观）vs 社会规则（具体约束）
- **口诀**："秩序保证运行好，安居乐业少不了"

## 自由与规则
- **关系**：社会规则划定了自由的边界；自由受道德、纪律、法律等社会规则的约束
- **核心**：社会规则是人们享有自由的保障
- **关键词**：划定边界 / 约束 / 保障自由
- **易混点**：自由不是绝对的（有边界）vs 自由是相对的（受约束）
- **口诀**："自由规则相伴生，边界约束保自由"

## 文明有礼
- **三重意义**：立身处世的前提 / 促进社会和谐 / 体现国家形象
- **关键词**：立身处世 / 社会和谐 / 国家形象
- **易混点**：文明有礼（个人素养）vs 法治（国家治理）
- **口诀**："有礼立身促和谐，国家形象靠大家"

## 诚信
- **三重价值**：安身立命之本 / 企业无形资产 / 促进社会文明国家兴旺
- **关键词**：安身立命 / 无形资产 / 社会文明
- **易混点**：诚信（道德范畴）vs 守法（法律范畴）
- **口诀**："诚信立身企业兴，文明国家靠诚信"

## 犯罪三特征
- **最本质特征**：严重社会危害性
- **法律标志**：刑事违法性
- **必然法律后果**：应受刑罚处罚性
- **关键词**：严重危害 / 刑事违法 / 刑罚处罚
- **易混点**：犯罪（三特征）vs 一般违法（社会危害较轻）
- **口诀**："危害严重是本质，违法刑事是标志，刑罚处罚是后果"

# ===== 第三单元 勇担社会责任 =====

## 责任来源
- **来源**：对他人的承诺、分配的任务、上级的任命、职业的要求、法律规定、传统习俗、道德原则、公民身份
- **核心**：每一种角色都意味着承担相应的责任
- **关键词**：承诺 / 任务 / 法律 / 角色 / 责任
- **易混点**：责任来源（多种）vs 法定义务（单一法律来源）
- **口诀**："承诺任务与任命，法律习俗和道德，角色不同责任异"

## 承担责任
- **代价**：时间、精力、金钱，可能受到责备甚至处罚
- **回报**：物质方面和精神方面（良好的自我感觉、获得新的知识和技能、赢得他人的尊重和赞许）
- **态度**：不言代价与回报，勇于承担责任
- **易混点**：代价（付出）vs 回报（获得）
- **口诀**："代价回报两相随，不言代价勇担当"

## 关爱他人的艺术
- **三要点**：心怀善意 / 尽己所能 / 讲究策略
- **关键词**：善意 / 尽力 / 策略
- **易混点**：关爱他人（利他）vs 宠溺他人（过度）
- **口诀**："善意尽力讲策略，关爱他人才是德"

# ===== 第四单元 维护国家利益 =====

## 国家利益
- **定义**：一个主权国家在国际社会中生存需求和发展需求的总和
- **内容**：安全利益、政治利益、经济利益、文化利益等
- **关系**：国家利益与个人利益在根本上是一致的
- **关键词**：生存发展 / 总和 / 根本一致
- **易混点**：国家利益（整体）vs 个人利益（局部）
- **口诀**："国家利益总和大，个人利益根一致"

## 总体国家安全观
- **内涵**：以人民安全为宗旨，以政治安全为根本，以经济安全为基础，以军事、文化、社会安全为保障，以促进国际安全为依托
- **口诀**："人民宗旨政治根，经济基础军文社，国际依托保安全"
- **关键词**：宗旨 / 根本 / 基础 / 保障 / 依托
- **易混点**：人民安全（宗旨）vs 政治安全（根本）vs 经济安全（基础）
- **关联**：国家安全是国家生存与发展的重要保障；是人民幸福安康的前提

## 劳动与实干
- **劳动意义**：劳动是财富的源泉，也是幸福的源泉
- **核心观点**：劳动创造价值，实干成就梦想
- **关键词**：源泉 / 创造价值 / 实干
- **易混点**：劳动（创造财富）vs 知识（创造价值）
- **口诀**："劳动财富幸福源，实干梦想靠青年"
