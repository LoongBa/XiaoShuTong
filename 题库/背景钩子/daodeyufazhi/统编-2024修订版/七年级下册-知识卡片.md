# 七年级下册 道德与法治 知识卡片（concept_card）

> 用途：背诵时展示的记忆增强卡片，用关键词锚定 + 易混点对比 + 口诀辅助精细复述
> 展示时机：✕ 阶段学习新知识点时展示；△○★ 复习时默认隐藏，卡壳时由 AI 导师按需提示
> 设计原则：正面问题化、关键词锚定、层级递进、易混点配对

---

# ===== 第一单元 青春时光 =====

## 青春期变化
- **身体变化**：身体外形变化、内部器官完善、性机能成熟
- **矛盾心理**：反抗与依赖、闭锁与开放、勇敢与怯懦
- **关键词**：外形 / 器官 / 性机能 / 反抗依赖 / 闭锁开放 / 勇敢怯懦
- **易混点**：身体变化（生理）vs 矛盾心理（心理）
- **口诀**："身体三变化，心理三矛盾"

## 独立思考与批判精神
- **独立思考**：不人云亦云，有自己独到见解，同时接纳他人合理意见
- **批判精神**：敢于表达不同观点，敢于说"不"，敢于向权威挑战
- **关键词**：独到见解 / 接纳合理 / 表达不同 / 说不 / 挑战权威
- **易混点**：独立思考（有见解）vs 批判精神（敢质疑）
- **口诀**："独立有见解，批判敢质疑"

## 行己有耻与止于至善
- **行己有耻**：自己认为可耻的就不去做；有知耻之心、树立底线意识、磨砺意志
- **止于至善**：精神境界，毕生追求；从小事做起、寻找榜样、自我省察
- **关键词**：可耻不做 / 知耻 / 底线 / 意志 / 小事 / 榜样 / 省察
- **易混点**：行己有耻（底线）vs 止于至善（高线）
- **口诀**："有耻是底线，至善是追求"

# ===== 第二单元 做情绪情感的主人 =====

## 情绪管理
- **基本情绪**：喜、怒、哀、惧
- **管理方法**：改变认知评价、转移注意、合理宣泄、放松训练
- **关键词**：喜怒哀惧 / 认知评价 / 转移注意 / 宣泄 / 放松
- **易混点**：情绪（即时反应）vs 情感（稳定体验）
- **口诀**："情绪四类型，管理四方法"

## 情感的作用
- **三重作用**：最基本的精神需求；影响判断选择驱使行动；有助于全面观察探索
- **获得途径**：阅读、与人交往、参与有意义的社会活动
- **传递正能量**：用热情行动影响环境；传递美好情感；创造美好体验
- **关键词**：精神需求 / 判断选择 / 全面观察 / 阅读 / 交往 / 实践
- **易混点**：情感（深层）vs 情绪（表层）
- **口诀**："情感三作用，获得靠实践"

# ===== 第三单元 在集体中成长 =====

## 集体的温暖
- **含义**：人们联合起来的有组织的整体
- **温暖体现**：获得安全感和归属感；被认可接纳获得尊重理解
- **个人成长**：培养负责任态度和能力；培养人际交往基本态度和能力；发展个性
- **关键词**：有组织 / 安全感 / 归属感 / 责任 / 交往 / 个性
- **易混点**：集体（组织）vs 群体（松散）
- **口诀**："集体有组织，温暖靠归属"

## 个人与集体
- **利益关系**：本质上一致；冲突时集体利益优先
- **处理关系**：做好自己遵守规则；解决集体困难；集体利益优先
- **关键词**：一致 / 集体优先 / 遵守规则 / 解决困难
- **易混点**：集体主义（集体优先）vs 个人主义（个人优先）
- **口诀**："利益本质一，冲突集体先"

## 美好集体
- **四特征**：民主公正、充满关怀友爱、善于合作、充满活力
- **建设方法**：自主建设自我管理；共同确定愿景目标；共同商定规则制度；共同创造良好氛围
- **关键词**：民主公正 / 关怀友爱 / 合作 / 活力 / 自主 / 共同
- **易混点**：美好集体（理想）vs 实际集体（现实）
- **口诀**："美好四特征，建设靠共同"

# ===== 第四单元 走进法治天地 =====

## 法律的特征与作用
- **三特征**：国家制定或认可、国家强制力保证实施、对全体社会成员普遍约束力
- **两作用**：规范行为保护生活；解决纠纷制裁违法犯罪
- **关键词**：制定认可 / 强制力 / 普遍约束 / 规范 / 保护
- **易混点**：法律（强制力）vs 道德（自觉性）
- **口诀**："法律三特征，作用两方面"

## 未成年人保护
- **六大保护**：家庭保护、学校保护、社会保护、网络保护、政府保护、司法保护
- **特殊保护原因**：身心发育不成熟、自我保护能力弱、辨别是非和自控能力不强
- **关键词**：家庭 / 学校 / 社会 / 网络 / 政府 / 司法 / 不成熟 / 弱
- **易混点**：六大保护（外部）vs 自我保护（内部）
- **口诀**："六大保护护成长，身心不成熟需特殊"

## 法治意识
- **要求**：认可崇尚遵守服从法律；依法办事养成习惯；依法维护权益
- **如何树立**：发自内心认可崇尚遵守服从；学法尊法守法用法
- **关键词**：认可 / 崇尚 / 遵守 / 服从 / 依法办事 / 维护权益
- **易混点**：法治意识（观念）vs 法治行为（行动）
- **口诀**："法治意识四要求，认可崇尚守服从"
