# 八年级上册 历史背景钩子（记忆增强器）

> 用途：背诵时展示的"记忆钩子"，用故事化背景帮助精细复述，强化记忆
> 展示时机：✕ 阶段学习新篇目时展示；△○★ 复习时默认隐藏，卡壳时由 AI 导师按需提示
> 设计原则：讲故事，不考核。每课提炼 1-2 个核心事件的 event_card（时间/地点/人物/起因/经过/结果/影响/关联）+ 记忆钩子

# ===== 第一单元 中国开始沦为半殖民地半封建社会 =====

## 鸦片战争（第1课）
- **时间**：1840-1842年
- **人物**：林则徐（虎门销烟）、道光帝
- **起因**：根本——英国为打开中国市场、倾销商品；直接——林则徐禁烟
- **经过**：1840年英舰封锁珠江口 → 1842年英舰到达南京下关江面
- **结果**：清政府战败，签订《南京条约》
- **影响**：中国开始沦为半殖民地半封建社会，中国近代史开端
- **记忆钩子**：1840 = "一把钥匙"，打开了中国近代史的大门
- **关联**：《南京条约》→《虎门条约》《望厦条约》《黄埔条约》

## 第二次鸦片战争（第2课）
- **时间**：1856-1860年
- **人物**：英法联军（主凶）、美俄（帮凶）
- **经过**：亚罗号事件/马神甫事件 → 火烧圆明园
- **结果**：《天津条约》《北京条约》；沙俄割占150多万平方千米
- **影响**：半殖民地化程度进一步加深
- **记忆钩子**："圆明园的烈火"——万园之园化为灰烬，铭记国耻
- **关联**：沙俄是近代割占中国领土最多的国家（《瑷珲条约》割地最多）

## 太平天国运动（第3课）
- **时间**：1851-1864年
- **人物**：洪秀全、洪仁玕
- **经过**：金田起义→定都天京→《天朝田亩制度》→天京事变（由盛转衰）
- **结果**：1864年天京陷落
- **影响**：中国历史上规模最宏大的农民战争，沉重打击清朝和外国侵略势力
- **记忆钩子**："天京"就是南京，定都南京改名天京

# ===== 第二单元 早期现代化的初步探索和民族危机加剧 =====

## 洋务运动（第4课）
- **时间**：19世纪60年代-90年代中期
- **人物**：奕訢、曾国藩、李鸿章、左宗棠、张之洞
- **口号**：前期"自强"（军事工业）、后期"求富"（民用企业）
- **经过**：安庆内军械所/江南制造总局/福州船政局 → 轮船招商局/汉阳铁厂
- **结果**：1895年北洋舰队覆没，宣告失败
- **影响**：中国早期近代化的初步探索，客观上促进民族资本主义产生
- **记忆钩子**：洋务 = "学习西方技术"，只学"器物"不学"制度"
- **关联**：左宗棠收复新疆（1878）、新疆建省（1884）

## 甲午中日战争（第5课）
- **时间**：1894-1895年
- **人物**：邓世昌（黄海海战殉国）、丁汝昌（威海卫殉国）
- **经过**：丰岛海战→平壤→黄海→辽东→威海卫（北洋舰队覆没）
- **结果**：《马关条约》
- **影响**：大大加深半殖民地化程度；列强掀起瓜分中国狂潮
- **记忆钩子**：甲午 = 1894年农历甲午年；"台湾割让"是《马关条约》最痛条款
- **关联**：三国干涉还辽（俄国联合德法迫使日本归还辽东半岛）

## 戊戌变法（第6课）
- **时间**：1898年（103天百日维新）
- **人物**：康有为、梁启超、光绪帝、慈禧太后
- **经过**：公车上书（1895）→《明定国是诏》→戊戌政变
- **结果**：失败，谭嗣同等戊戌六君子遇害
- **影响**：思想文化方面产生广泛而持久的影响（思想启蒙）
- **记忆钩子**："我自横刀向天笑"——谭嗣同甘为变法流血

## 义和团运动与八国联军（第7课）
- **时间**：1900-1901年
- **口号**："扶清灭洋"
- **结果**：《辛丑条约》
- **影响**：中国完全沦为半殖民地半封建社会；清政府成为"洋人的朝廷"
- **记忆钩子**：《辛丑条约》赔款4.5亿两——按当时中国人口算，每人一两，史称"人均一两"
- **关联**：改总理衙门为外务部，班列六部之前

# ===== 第三单元 资产阶级民主革命与中华民国的建立 =====

## 辛亥革命（第9课）
- **时间**：1911年10月10日武昌起义
- **人物**：孙中山
- **经过**：武昌起义→各省响应→1912.1.1中华民国建立
- **结果**：推翻清朝，终结两千多年君主专制
- **影响**：使民主共和观念深入人心；但果实被袁世凯窃取
- **记忆钩子**："10月10日"双十节；民国纪年 = 公元纪年 - 1911
- **关联**：《临时约法》是中国第一部资产阶级共和国宪法性质文件

## 袁世凯复辟（第10课）
- **时间**：1915年末称帝
- **人物**：袁世凯、蔡锷（护国战争）
- **结果**：1916年3月取消帝制，6月死去
- **记忆钩子**：袁世凯称帝83天即垮台，违背历史潮流
- **关联**：军阀割据——直系（英美）、皖系/奉系（日本）

# ===== 第四单元 新民主主义革命的兴起 =====

## 五四运动（第11课）
- **时间**：1919年5月4日
- **导火索**：巴黎和会外交失败（山东问题）
- **口号**：外争主权、内除国贼
- **经过**：北京学生→上海工人（中心转移）
- **结果**：释放被捕学生、罢免曹汝霖等、拒签和约
- **影响**：新民主主义革命的开端；工人阶级登上政治舞台
- **记忆钩子**：5月4日 = 青年节；"外争主权"对应山东，"内除国贼"对应曹章陆

## 中国共产党诞生（第12课）
- **时间**：1921年7月
- **地点**：上海→嘉兴南湖（红船）
- **影响**：开天辟地的大事变
- **记忆钩子**：7月1日建党节；"红船精神"——嘉兴南湖的小船
- **关联**：中共二大（1922）第一个彻底反帝反封建的民主革命纲领

# ===== 第五单元 从国共合作到农村革命根据地的建立 =====

## 南昌起义与井冈山（第14课）
- **时间**：1927年8月1日（建军节）
- **人物**：周恩来、贺龙、叶挺、朱德、刘伯承
- **经过**：南昌起义→八七会议→秋收起义→井冈山根据地→古田会议
- **影响**：打响武装反抗国民党反动统治第一枪；开辟"农村包围城市"道路
- **记忆钩子**：8月1日建军节源于南昌起义；"枪杆子里面出政权"

## 长征与遵义会议（第15课）
- **时间**：1934.10-1936.10
- **路线**：瑞金→湘江→遵义→赤水→金沙江→大渡河→雪山草地→会宁
- **遵义会议**：1935年1月，生死攸关的转折点
- **影响**：粉碎国民党围剿、转危为安、铸就长征精神
- **记忆钩子**："遵义" = 转折之城；四渡赤水 = 毛泽东军事生涯得意之笔

# ===== 第六单元 中华民族的抗日战争 =====

## 九一八事变（第16课）
- **时间**：1931年9月18日
- **地点**：沈阳
- **影响**：东北三省沦陷，中国局部抗战开始
- **记忆钩子**："九一八"勿忘国耻日（9月18日）

## 西安事变（第16课）
- **时间**：1936年12月12日
- **人物**：张学良、杨虎城
- **影响**：十年内战基本结束，抗日民族统一战线初步形成
- **记忆钩子**："双十二"事变——逼蒋抗日

## 七七事变（第17课）
- **时间**：1937年7月7日
- **地点**：北平卢沟桥
- **影响**：全民族抗战开始
- **记忆钩子**：卢沟桥 = 全面抗战爆发地

## 抗日战争的胜利（第19课）
- **时间**：1945年8月15日
- **意义**：中国近代以来反抗外来侵略第一次取得完全胜利
- **记忆钩子**：8月15日 = 抗战胜利日；9月3日 = 抗战胜利纪念日

# ===== 第七单元 人民解放战争 =====

## 三大战役（第21课）
- **时间**：1948年9月-1949年1月
- **内容**：辽沈、淮海、平津
- **影响**：国民党军队主力基本被消灭
- **记忆钩子**：辽沈（东北）→淮海（中原）→平津（华北），从北到南推进
- **关联**：渡江战役（1949.4）解放南京，国民党在大陆统治覆灭

## 重庆谈判（第20课）
- **时间**：1945年8月
- **人物**：毛泽东、蒋介石
- **结果**：《双十协定》
- **记忆钩子**：毛泽东"弥天大勇"赴重庆谈判，争取和平民主
