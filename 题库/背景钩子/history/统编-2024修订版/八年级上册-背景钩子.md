# ===== 第一单元 中国开始沦为半殖民地半封建社会 =====

## 第1课 鸦片战争
- **禁毒与销烟**：林则徐（湖广总督）上书道光"中原几无可以御敌之兵，且无可以充饷之银"→ 1838年底任命钦差大臣 → 1839年6月3日-25日虎门销烟（110多万千克）
- **战争**：1840年6月英国舰队封锁珠江口开战 → 关天培虎门殉国（1841年1月）→ 三元里抗英（1841年5月30日）→ 1842年8月英舰抵南京下关
- **条约**：1842年《南京条约》（近代第一个不平等条约）→ 1843年《虎门条约》（领事裁判权/片面最惠国待遇）→ 1844年《望厦条约》《黄埔条约》
- **易混点**：虎门销烟（1839，禁烟）vs 鸦片战争爆发（1840）；《南京条约》割"香港岛"（不是香港全部）
- **口诀**："39销烟41战，关天培死三元里抗；南京条约五口通，割岛赔款二一零"（2100万银元）
- **记忆钩子**：林则徐《四洲志》→ 魏源《海国图志》"师夷之长技以制夷"，林则徐是"中国近代开眼看世界第一人"

## 第2课 第二次鸦片战争
- **借口**：英国"亚罗号事件"、法国"马神甫事件"（俄、美支持）→ 1856年10月英军炮轰广州
- **条约**：1858年《天津条约》（公使驻京/增开汉口南京等十口/长江自由航行）→ 1860年《北京条约》（增开天津/割九龙半岛南端）
- **罪行**：1860年10月英法联军火烧圆明园（圆明、长春、绮春三园）
- **沙俄割地**：1858年《瑷珲条约》60多万平方千米 + 1860年《北京条约》约40万 + 1864年《勘分西北界约记》44万多 + 1881年《改订条约》等7万多 = 共150多万平方千米
- **易混点**：《天津条约》（增开汉口南京等"十处"）vs 《北京条约》（增开天津，割九龙）vs 《南京条约》（五口）
- **口诀**："56亚罗马神起，58天津60京；圆明园焚两强盗，沙俄割地150万"
- **记忆钩子**：1861年设立"总理各国事务衙门"（总理衙门）——中国第一个近代外交机构

## 第3课 太平天国运动
- **兴起**：1843年洪秀全创立拜上帝会 → 1851年1月11日金田起义（建号太平天国）→ 永安封王（东王杨秀清等五王）
- **鼎盛**：1853年3月定都天京（南京改名）→ 《天朝田亩制度》（按人口年龄平均分地，空想色彩未推行）→ 北伐西征，1856年军事全盛
- **转折**：1856年天京事变（杨秀清被杀、韦昌辉被处死、石达开出走）→ 由盛转衰
- **衰亡**：洪仁玕《资政新篇》（向西方学习，未实践）→ 1864年夏天京陷落，运动失败（14年）
- **易混点**：《天朝田亩制度》（分田地，平均主义）vs 《资政新篇》（学西方，改革内政）
- **口诀**："51金田53京，天朝田亩空想行；56事变盛转衰，64天京终陷落"
- **记忆钩子**：天京=南京；失败主因是"农民阶级的局限性"+"中外反动势力联合镇压"

# ===== 第二单元 早期现代化的初步探索和民族危机加剧 =====

## 第4课 洋务运动和边疆危机
- **洋务运动**：19世纪60-90年代中以"自强""求富"为口号；代表：中央奕䜣，地方曾国藩、李鸿章、左宗棠、张之洞
- **企业**：军事——江南机器制造总局、福州船政局；民用——轮船招商局、开平煤矿、汉阳铁厂、湖北织布局；1888年北洋舰队成军
- **评价**：客观上促进民族资本主义产生，是中国早期现代化的初步探索；求强求富目标未实现
- **边疆危机**：1874年日本侵台（勒索50万两）→ 1879年吞并琉球；1865年阿古柏入侵新疆 → 1878年左宗棠收复（先北后南、缓进急战）→ 1881年收回伊犁大部；1883-1885年中法战争 → 1885年镇南关大捷（冯子材）→ 1884年新疆建省、1885年台湾建省
- **易混点**：左宗棠（收复新疆/新疆建省") vs 刘铭传（督办台湾军务/台湾建省）；海防塞防之争：李鸿章（海防重）vs 左宗棠（二者并重）
- **口诀**："60起自强求富，江南福州轮船局；左公1878复新疆，84新省85台省"
- **记忆钩子**：1884年"故土新归"改称新疆；知识拓展：1862年京师同文馆（第一所官办新式学堂）

## 第5课 甲午中日战争与列强瓜分中国狂潮
- **战争**：1894年（甲午年）日本借东学党起义出兵 → 平壤之战（左宝贵牺牲）→ 黄海海战（邓世昌、林永升与舰同沉）→ 旅顺大屠杀 → 1895年初威海卫之战（丁汝昌殉国）北洋舰队全军覆没
- **《马关条约》**：1895年签订：割辽东半岛/台湾全岛及附属岛屿/澎湖列岛；赔2亿两；开沙市、重庆、苏州、杭州四口；日本可在通商口岸开设工厂（资本输出）
- **影响**：领土主权严重破坏；资本输出；半殖民地化程度大大加深
- **瓜分狂潮**：三国干涉还辽 → 列强强租租借地、划分势力范围（德胶州湾/山东、俄旅大/长城以北、法广州湾/两广云南、英九龙威海卫/长江流域、日福建）→ 1899年美国"门户开放"
- **易混点**：《马关条约》开放四口（沙市/重庆/苏州/杭州，深入内陆）vs 《南京条约》五口（东南沿海）；"半殖民地化大大加深"（马关）vs "进一步加深"（第二次鸦片）
- **口诀**："94甲午95约，割台赔2开四口设厂；三国还辽掀瓜分，门户开放39（1899）"
- **记忆钩子**：张謇"实业救国"创办大生纱厂（状元实业家）；台湾军民抗日武装斗争（1895年5-10月）

## 第6课 戊戌变法
- **序幕**：1895年公车上书（康有为、梁启超，拒和/迁都/变法）
- **宣传**：《时务报》（梁启超"法者天下之公器也，变者天下之公理也"）、《国闻报》（严复《天演论》"物竞天择、适者生存"）
- **高潮**：1898年6月11日"明定国是"诏书 → 百日维新：政治（裁撤冗官/允许上书）、经济（鼓励兴办工矿/改革财政）、教育（废八股/创办京师大学堂）、军事（裁绿营/练新军）
- **失败**：9月21日慈禧政变、软禁光绪 → 戊戌六君子（谭嗣同等）遇害；历时103天
- **易混点**：戊戌变法（学西方制度/思想启蒙）vs 洋务运动（学西方技术/器物层面）
- **口诀**："95公车上书起，98明定国是诏；废八股设大学堂，政变六君子血写史"
- **记忆钩子**：谭嗣同"我自横刀向天笑"慷慨赴死；颁旨办京师大学堂→辛亥革命后改名北京大学

## 第7课 义和团运动和八国联军侵华
- **兴起**：义和拳发展而来，主要成员农民；1898年10月冠县起义揭开序幕；口号"扶清灭洋"
- **评价**："灭洋"反帝但盲目排外；"扶清"对清政府认识不清，抱有幻想；带迷信色彩
- **八国联军**：1900年6月八国联军（英美德法俄日奥匈意）西摩率军进犯 → 廊坊阻击战 → 8月14日攻陷北京，慈禧携光绪西逃
- **《辛丑条约》**：1901年9月与11国签订：惩办首祸诸臣/停科举5年；赔4.5亿两（39年还清，本息9.8亿）；东交民巷使馆界；拆大沽炮台、驻兵北京—山海关铁路沿线；严禁反帝；改总理衙门为外务部
- **易混点**：《辛丑条约》影响是"完全陷入半殖民地半封建社会的深渊"（vs 鸦片"开始沦为"、马关"大大加深"）
- **口诀**："扶清灭洋义和团，00（1900）联军进北京；辛丑4.5亿两，东交民巷设使馆，完全陷落深渊"
- **记忆钩子**：赔款4.5亿两约合当时每人1两；"量中华之物力，结与国之欢心"（慈禧）上榜历史耻辱

# ===== 第三单元 资产阶级民主革命与中华民国的建立 =====

## 第8课 中国同盟会
- **先行者**：1894年孙中山上书李鸿章遭冷遇 → 檀香山成立兴中会（"振兴中华""驱除鞑虏，恢复中国，创立合众政府"）
- **思想传播**：章炳麟《驳康有为论革命书》、邹容《革命军》、陈天华《猛回头》《警世钟》→ 华兴会、光复会
- **同盟会**：1905年8月日本东京成立；纲领"驱除鞑虏，恢复中华，创立民国，平均地权"；总理孙中山；机关报《民报》；第一个全国规模统一的资产阶级革命政党
- **三民主义**：民族主义（驱除鞑虏恢复中华）、民权主义（创立民国）、民生主义（平均地权）—— 孙中山领导革命的指导思想
- **起义**：1906萍浏醴起义（第一次）→ 1907徐锡麟安庆起义、秋瑾就义 → 1911黄花岗起义（黄兴，七十二烈士）
- **易混点**：兴中会（第一个革命团体）vs 同盟会（第一个全国性革命政党）；"三民主义"≠"三大政策"（后者是国共合作时联俄联共扶助农工）
- **口诀**："94兴中05盟，驱除鞑虏创民国平均地权；民报发刊三民义，黄花岗上烈士魂"
- **记忆钩子**：孙黄并称（黄兴）；秋瑾"秋风秋雨愁煞人"

## 第9课 辛亥革命
- **武昌起义**：1911年10月10日晚新军工程营率先起义 → 占领武昌，武汉三镇胜利 → 湖北军政府（黎元洪都督）→ 各省响应，一半以上省份独立
- **中华民国**：1912年1月1日孙中山在南京就任临时大总统，宣告中华民国临时政府成立，1912年为民国元年
- **《临时约法》**：1912年3月颁布：主权属于全体国民；国民一律平等、有各项自由权利；参议院立法、国务员行政、法院司法（司法独立）；中国历史上第一部具有资产阶级共和国宪法性质的文件
- **结局**：1912年2月12日清帝退位（260多年统治结束）→ 袁世凯窃取果实 → 宋教仁案 → 二次革命失败
- **易混点**：辛亥革命推翻的是"君主专制制度"（不是"封建制度"）；"民族独立、人民解放"任务未完成
- **口诀**："10月10日武昌起，1月1日民国立；临时约法第一部，清帝退位袁窃权"
- **记忆钩子**：民国纪年换算：民国元年=1912年，"民国X年=1911+X"；辛亥=1911农历辛亥年

## 第10课 帝制复辟与军阀割据
- **复辟**：解散国民党、解散国会、废《临时约法》改总统制 → 1915年接受"二十一条"大部分 → 1915年底改国号"中华帝国"，年号"洪宪"
- **护国战争**：1915年底唐继尧、蔡锷、李烈钧云南独立，组织护国军讨袁 → 1916年3月袁世凯取消帝制，6月死去
- **军阀割据**：直系（冯国璋、曹锟，直隶江苏江西湖北）、皖系（段祺瑞，掌握北京政府，皖浙鲁闽陕）、奉系（张作霖，东北）、滇系（唐继尧）、桂系（陆荣廷）
- **易混点**：袁世凯称帝（1915年末-1916年3月，共83天）vs 复辟清室（张勋1917年，教材未列）；"二十一条"vs"五四运动"中都出现（1915接受大部分 vs 1919要求取消）
- **口诀**："15洪宪皇帝梦，蔡锷护国云南起；16年3月取消帝，直皖奉滇桂割据"
- **记忆钩子**：袁死后的动乱 = "城头变幻大王旗"；知识拓展：民族工业短暂春天（1914一战期间）

# ===== 第四单元 新民主主义革命的兴起 =====

## 第11课 五四运动
- **新文化运动**：1915年陈独秀创办《青年杂志》（后改《新青年》）→ 口号"民主与科学"（德先生赛先生）→ 抨击旧道德旧文化（李大钊《孔子与宪法》、鲁迅《狂人日记》）→ 文学革命（胡适《文学改良刍议》、陈独秀《文学革命论》）→ 阵地：北京大学、《新青年》
- **导火索**：1919年巴黎和会中国外交失败（列强将德国在山东的特权转让给日本）
- **经过**：5月4日学生游行（"外争主权、内除国贼"等口号，烧赵家楼）→ 6月3日后工人罢工、商人罢市，中心由北京转移到上海，工人阶级成主力
- **结果**：释放被捕学生、罢免曹汝霖等、拒绝签字——直接目标实现
- **历史意义**：彻底反帝反封建；促进马克思主义传播；为中共诞生做思想干部准备；新旧民主主义革命转折点；五四精神核心=爱国主义
- **易混点**：新文化运动口号"民主与科学" vs 五四口号"外争主权、内除国贼"；五四运动后期主力（工人/上海）vs 前期先锋（学生/北京）
- **口诀**："15新青举旗帜，民主科学两大旗；19巴黎和会败，5月4日学生起；工人登场成主力，新旧革命转折点"
- **记忆钩子**：曹汝霖、陆宗舆、章宗祥烧赵家楼；"德先生"Democracy="赛先生"Science

## 第12课 中国共产党诞生
- **思想准备**：十月革命 → 李大钊《庶民的胜利》《我的马克思主义观》（1919年《新青年》马克思研究专号）→ 陈望道译《共产党宣言》（1920年8月出版）
- **组织准备**：1920年3月李大钊马克思学说研究会 → 1920年夏陈独秀在上海建立中国第一个共产党早期组织
- **中共一大**：1921年7月23日上海开幕（后转嘉兴南湖游船）；毛泽东、何叔衡、董必武等13人代表50多名党员；确定党名"中国共产党"、第一个纲领（推翻资产阶级政权/建立无产阶级专政/实现共产主义）、中心工作领导组织工人运动、中央局书记陈独秀
- **中共二大**：1922年7月，第一次提出明确的反帝反封建民主革命纲领
- **工人运动**：京汉铁路大罢工（1923.2，吴佩孚镇压"二七惨案"，林祥谦）
- **易混点**：中共一大（建党/上海南湖）vs 中共二大（民主革命纲领/1922）；陈独秀（一大中央局书记，末到会）vs 李大钊（宣传第一人）
- **口诀**："十月革命送马列，李大钊举旗译宣言；21年7月一大开，南湖红船定乾坤；22二大提纲领，京汉罢工斗军阀"
- **记忆钩子**："新纪元""赤旗的世界"（李大钊语）；红船=梦想起航的地方；伟大建党精神（2021年提炼）"坚持真理、坚守理想，践行初心、担当使命，不怕牺牲、英勇斗争，对党忠诚、不负人民"

# ===== 第五单元 从国共合作到农村革命根据地的建立 =====

## 第13课 国共合作与北伐战争
- **合作**：1923年中共三大（党员以个人身份加入国民党）→ 1924年1月国民党一大确立三大政策（联俄联共扶助农工），合作正式建立，国民革命开始
- **黄埔军校**：1924年5月创办；孙中山兼总理、廖仲恺党代表、蒋介石校长、周恩来政治部主任
- **北伐**：1926年7月誓师，蒋介石任总司令；对象吴佩孚、孙传芳、张作霖；叶挺独立团连克汀泗桥、贺胜桥，"铁军"；从珠江流域打到长江流域；1927年1月国民政府迁武汉
- **破裂**：1927年4月12日蒋介石四一二反革命政变 → 南京国民政府（大地主大资产阶级性质）→ 7月汪精卫"分共"（"宁可枉杀千人"），国民革命失败 → 1928年底东北易帜（张学良），形式上统一全国
- **易混点**：第一次国共合作（1924-1927，革命统一战线）vs 第二次（1937年抗日民族统一战线）；黄埔军校校址广州黄埔（非上海）
- **口诀**："24一大建合作，三大政策定基础；黄埔军校育人才，26北伐打三军阀；27四一二分共变，宁汉合流革命败"
- **记忆钩子**：李大钊1927年4月28日被奉系军阀绞杀——"铁肩担道义"；叶挺独立团=北伐名将

## 第14课 毛泽东开辟井冈山道路
- **南昌起义**：1927年8月1日周恩来、贺龙、叶挺、朱德、刘伯承领导；打响武装反抗国民党反动派第一枪；中共独立领导革命战争、创建人民军队、武装夺取政权的开端（8月1日建军节）
- **八七会议**：1927年8月7日汉口；土地革命和武装起义总方针；毛泽东"政权是由枪杆子中取得的"
- **秋收起义→井冈山**：1927年9月湘赣边界（工农革命军）→ 三湾改编（支部建在连上，党领导军队）→ 10月到井冈山，创建第一个农村革命根据地 → 1928年4月朱德陈毅会师，合编中国工农红军第四军
- **工农武装割据**：打土豪分田地、土地革命、工农民主政权、游击战争；1929年古田会议（思想建党、政治建军）；1931年冬瑞金成立中华苏维埃共和国临时中央政府
- **易混点**：南昌起义（城市/建军）vs 秋收起义（改向农村进军）vs 井冈山（第一个农村根据地）；建军节8月1日源自南昌起义
- **口诀**："8月1日南昌城，打响第一枪建军；八七会议枪杆子，秋收起义上井冈；1928朱毛会，农村包围城市新路"
- **记忆钩子**：井冈山"中国革命的摇篮"；瑞金="共和国的摇篮"；"农村包围城市、武装夺取政权"=中国特色革命道路

## 第15课 中国工农红军长征与遵义会议
- **起因**：第五次反"围剿"失败（博古、李德"左"的错误）
- **长征**：1934年10月从瑞金/于都出发 → 突破四道封锁线、血战湘江（8万→3万）→ 强渡乌江、攻占遵义
- **遵义会议**：1935年1月：肯定毛泽东正确军事主张、增选毛泽东为政治局常委、取消博古李德军事指挥权；生死攸关转折点，挽救党、红军、中国革命
- **继续长征**：四渡赤水 → 金沙江（跳出包围）→ 强渡大渡河/飞夺泸定桥 → 爬雪山过草地 → 腊子口 → 1935年10月吴起镇 → 1936年10月会宁、将台堡三大主力会师
- **意义**：粉碎围剿企图、保存基干力量、转危为安；铸就长征精神；打开中国革命新局面
- **易混点**：遵义会议标志"开始确立"毛泽东领导地位（vs 中共七大"确立"毛泽东思想为指导思想）；长征结束"1936年10月"（vs 开始1934年10月，注意同年同月）
- **口诀**："34年10月长征始，血战湘江折大半；35遵义转折点，赤水金沙铁索寒；36会宁三军会，长征精神万古传"
- **记忆钩子**：飞夺泸定桥22勇士；半条被子故事（课后活动）；《长征组歌》"红军威名天下扬"

# ===== 第六单元 中华民族的抗日战争 =====

## 第16课 从九一八事变到西安事变
- **九一八事变**：1931年9月18日，柳条湖事件为借口，炸毁南满铁路路轨反诬中国军队 → 沈阳北大营 → 不抵抗政策致东北三省四个多月沦陷 → 1932年溥仪伪满洲国（长春）
- **局部抗战**：东北抗日义勇军 → 中共派杨靖宇、赵尚志组织游击队 → 1936年东北抗日联军；九一八事变=中国人民抗日战争起点、世界反法西斯战争序幕
- **一二·九运动**：1935年12月9日北平学生（"打倒日本帝国主义""停止内战，一致对外"）→ 抗日救亡运动新高潮；瓦窑堡会议确定建立抗日民族统一战线方针
- **西安事变**：1936年12月12日张学良、杨虎城兵谏蒋介石（"双十二事变"）→ 中共主张和平解决、派周恩来谈判 → 和平解决=时局转换枢纽、十年内战基本结束
- **易混点**：九一八事变（局部抗战开始）vs 七七事变（全民族抗战开始）；西安事变"和平解决"（因中共力主）vs 如果打蒋（会扩大内战）
- **口诀**："31年9.18，柳条湖起东北陷；不抵抗丢三省略，义勇抗联战白山；35一二九运动起，36西安兵谏促团结"
- **记忆钩子**：杨靖宇胃里只有草根和棉絮；《松花江上》唱出东北同胞悲愤；马占山江桥抗战

## 第17课 七七事变与全民族抗战
- **七七事变**：1937年7月7日卢沟桥事变（借口士兵失踪要求入宛平城搜查被拒）→ 全民族抗战开始；佟麟阁、赵登禹北平殉国
- **第二次国共合作**：红军主力→八路军（朱德总指挥、彭德怀副总指挥）；南方八省游击队→新四军（叶挺军长）；1937年9月国共合作宣言发表 → 抗日民族统一战线正式建立
- **淞沪会战**：1937年8月爆发，三个月毙伤日军4万多人，打破日本三个月灭亡中国迷梦；姚子青守宝山、谢晋元守四行仓库；南京失陷，国民政府迁重庆（战时陪都）
- **南京大屠杀**：1937年12月13日日军攻陷南京，六周屠杀30万人以上
- **易混点**：第二次国共合作正式建立＝国共合作宣言发表+蒋介石谈话（1937年9月）；七七事变（全民族抗战开始）vs 九一八（局部抗战）；国家公祭日12月13日（vs 抗战胜利纪念9月3日）
- **口诀**："37.7.7卢沟桥，全民族抗战起高潮；八路军新四军改编，统一战线9月建；淞沪三月亮剑折，12.13南京殇"
- **记忆钩子**：平型关大捷（1937.9，第一个大胜仗，属第18课内容但时间紧接七七，注意归位）；南京大屠杀纪念馆"三个必胜"？——不延伸，记"30万+6周"

## 第18课 全民族抗战中的正面战场和敌后战场
- **正面战场**：平型关大捷（1937.9，八路军，第一个重大胜利，粉碎"不可战胜"神话）→ 台儿庄大捷（1938.3，李宗仁，正面战场最大胜仗）→ 武汉会战（1938.6-10，战略相持阶段到来）→ 张自忠枣宜会战殉国 → 第三次长沙会战（1941）
- **敌后战场**：八路军、新四军建16块根据地，中枢延安；游击战（神头岭、响堂铺、黄土岭击毙阿部规秀）；百团大战（1940，彭德怀，100多个团，毙伤俘4万多人、毁交通线2000千米、拔据点3000个）；反"扫荡"（麻雀战、地道战、地雷战、破袭战、水上游击战）；左权牺牲（1942，最高将领）
- **全民族抗战**：汪精卫伪国民政府（1940.3南京）；皖南事变（1941.1，周恩来"千古奇冤，江南一叶"）；各族人民、华侨抗战
- **东方主战场**：珍珠港事件后太平洋战争爆发 → 《联合国家宣言》（1942.1，26国）→ 中国远征军入缅作战（仁安羌大捷、戴安澜殉国）→ 《开罗宣言》（1943，东北台湾澎湖归还中国）→ 中国战场=东方主战场（抗击歼灭日本陆军三分之二以上）
- **易混点**：平型关大捷（八路军/敌后）vs 台儿庄大捷（正面战场最大）；百团大战指挥彭德怀、八路军主动出击
- **口诀**："正面台儿庄最大胜仗，敌后百团彭德怀；持久战相持阶段转，远征军仁安羌外线；开罗宣言台湾归，东方主战场中国承担"
- **记忆钩子**：阿部规秀=被击毙的日军中将，"名将之花凋谢在太行山上"；戴安澜远征殉国；白求恩国际主义精神

## 第19课 抗日战争的胜利
- **中流砥柱**：《为日军进攻卢沟桥通电》主张全民族抗战 → 洛川会议全面抗战路线、《抗日救国十大纲领》→ 《论持久战》（1938年5月，驳"亡国论""速胜论"）→ 坚持抗战反对投降（1939年7月三条方针）→ 根据地建设（三三制/精兵简政/大生产运动/减租减息）
- **中共七大**：1945年4-6月延安；政治路线（放手发动群众，打败日本侵略者，建立新民主主义中国）；确立毛泽东思想为指导思想并写入党章
- **胜利进程**：《波茨坦公告》（1945.7）→ 原子弹（8.6广岛、8.9长崎）→ 苏联对日宣战（8.8）→ 《对日寇的最后一战》（8.9）→ 8月15日日本宣布无条件投降 → 9月2日签署投降书（9月3日为抗战胜利纪念日）
- **意义**：近代以来反抗外敌入侵第一次取得完全胜利的民族解放斗争；抗战精神；中华民族走向复兴的历史转折点；台湾回到祖国怀抱；提高国际地位
- **易混点**：中共七大（确立毛泽东思想"指导思想"+写入党章）vs 遵义会议（确立毛泽东"领导地位"）；14年抗战（1931-1945）vs 8年全民族抗战（1937-1945）
- **口诀**："论持久战指方向，三三制建根据地；七大确立毛思想，45年8.15日降；台湾回归举国欢，东方主战场美名扬"
- **记忆钩子**：9月2日签字/9月3日纪念日；何应钦代表中国接受投降书；"中流砥柱"=中国共产党

# ===== 第七单元 人民解放战争 =====

## 第20课 国民党挑起内战
- **重庆谈判**：1945年8月毛泽东"弥天大勇"赴重庆 → 10月10日"双十协定"（《政府与中共代表会谈纪要》：和平民主团结统一、避免内战、召开政协）→ 1946年1月政治协商会议（重庆）
- **内战爆发**：1946年6月蒋介石撕毁政协协议，围攻中原解放区，全面内战爆发
- **自卫反击**：集中优势兵力、各个歼灭敌人；运动战；到1947年6月歼敌112万粉碎全面进攻
- **重点进攻**：1947年3月进攻陕北和山东；中共中央转战陕北，青化砭、沙家店；孟良崮战役歼灭整编第七十四师
- **易混点**："双十协定"（1945.10.10，重庆谈判成果）vs 政协协议（1946.1，未被执行即被撕毁）；全面内战（1946年6月）vs 战略反攻开始（1947年夏刘邓跃进大别山）
- **口诀**："45.8重庆谈，双十协定避内战；46.6撕协议，全面内战中原起；运动战歼敌112万，孟良崮上七十四师歼"
- **记忆钩子**：刘胡兰"生的伟大，死的光荣"；"一切反动派都是纸老虎"（毛泽东1946年8月）；国共力量对比：430万 vs 127万

## 第21课 人民解放战争的胜利
- **土地改革**：1947年全国土地会议颁布《中国土地法大纲》：没收地主土地、废除封建剥削土地制度、耕者有其田、按乡村全部人口平均分配土地；总路线（依靠贫雇农、团结中农……）；作用：翻身农民踊跃参军参战，提供人力物力保障
- **战略反攻**：1947年夏刘伯承、邓小平千里跃进大别山（揭开战略进攻序幕）
- **三大战役**：辽沈（1948.9-11，攻占锦州解放东北全境）、淮海（以徐州为中心，1949.1结束）、平津（傅作义和平改编，北平和平解放）；共歼灭和改编国民党军队150多万人，主力基本消灭
- **渡江战役**：1949年4月百万雄师过大江，解放南京，国民党反动统治覆灭，残余退往台湾
- **七届二中全会**：1949年3月西柏坡：党的工作重心由乡村转向城市；把农业国变为工业国；"两个务必"
- **意义**：毛泽东思想的伟大胜利；结束半殖民地半封建社会地位和长期战乱、四分五裂局面；实现民族独立和人民解放；为实现中华民族伟大复兴创造根本社会条件
- **易混点**：三大战役各成果：辽沈（东北解放）淮海（中原、歼敌最多55万）平津（北平和平解放）；渡江战役解放南京（1949.4）vs 三大战役（1948.9-1949.1）
- **口诀**："47土改大纲颁，耕者有其田人心向；刘邓跃进大别山，战略反攻拉开幕；辽沈淮海平津战，150万主力全歼；1949过大江，总统府上红旗扬"
- **记忆钩子**：淮海战役=人民群众用小车推出来的胜利；董存瑞（隆化战役）；"两个务必"至今传颂；《没有共产党就没有新中国》与"新"字由来
