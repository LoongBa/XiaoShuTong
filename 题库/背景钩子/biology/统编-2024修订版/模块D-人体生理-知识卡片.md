# ===== D1 人体营养 =====

## 六大营养物质
- **范围**：糖类、脂肪、蛋白质、水、无机盐、维生素
- **糖类**：主要供能物质
- **脂肪**：备用能源物质
- **蛋白质**：建造和修复身体的重要原料
- **口诀**："糖供能，脂备能，蛋白质造身体"

## 消化与吸收
- **消化吸收主要场所**：小肠
- **淀粉**：口腔开始消化 → 葡萄糖
- **蛋白质**：胃开始消化 → 氨基酸
- **脂肪**：小肠开始消化 → 甘油和脂肪酸
- **易混点**：三种物质开始消化的部位不同（口/胃/小肠）
- **口诀**："口淀胃蛋肠脂肪，小肠是主消化场"
- **关键词**：环形皱襞、小肠绒毛、一层上皮细胞

# ===== D2 人体呼吸 =====

## 呼吸道与肺
- **呼吸道**：鼻→咽→喉→气管→支气管
- **气体交换场所**：肺泡
- **肺泡特点**：数量多、壁薄（一层上皮细胞）、外包绕毛细血管
- **易混点**：呼吸道（通道）vs 肺（交换场所）
- **口诀**："鼻咽喉气管支，肺泡交换气体"

## 呼吸运动
- **吸气**：肋间肌+膈肌收缩 → 胸廓扩大 → 肺扩张 → 气压降低 → 气体入肺
- **呼气**：肌肉舒张 → 胸廓缩小 → 肺回缩 → 气压升高 → 气体出肺
- **易混点**：吸气（主动，收缩）vs 呼气（被动，舒张）
- **口诀**："吸缩呼舒"

# ===== D3 血液循环 =====

## 血液组成
- **血浆 + 血细胞**（红细胞/白细胞/血小板）
- **红细胞**：运输氧气（血红蛋白）
- **白细胞**：吞噬病菌
- **血小板**：止血凝血
- **易混点**：红细胞（运氧）vs 白细胞（防御）vs 血小板（凝血）
- **口诀**："红运氧，白防御，血小止血"

## 心脏与循环
- **心脏四腔**：左心房、左心室、右心房、右心室
- **体循环**：左心室→主动脉→全身→上下腔静脉→右心房（动脉血→静脉血）
- **肺循环**：右心室→肺动脉→肺→肺静脉→左心房（静脉血→动脉血）
- **易混点**："肺反体同"——肺循环中血管与血液相反，体循环中相同
- **口诀**："房静室动，左主右腔"

## 动脉血与静脉血
- **动脉血**：含氧丰富、颜色鲜红
- **静脉血**：含氧少、颜色暗红
- **易混点**：肺动脉流静脉血，肺静脉流动脉血（看含氧量不看血管名）
- **口诀**："看氧不看名"

# ===== D4 废物排出 =====

## 泌尿系统
- **组成**：肾脏→输尿管→膀胱→尿道
- **肾单位**：肾小球 + 肾小囊 + 肾小管
- **尿的形成**：肾小球滤过（原尿）→ 肾小管重吸收（尿液）
- **重吸收**：全部葡萄糖、大部分水、部分无机盐
- **易混点**：原尿（有糖）vs 尿液（无糖）
- **口诀**："原尿有糖尿液无糖"

## 排泄vs排遗
- **排泄**：排出代谢废物（CO₂、尿素、水）
- **排遗**：排出食物残渣（粪便）
- **口诀**："排泄排废物，排遗排残渣"

---

# ===== D5 神经调节 =====

## 神经系统与反射
- **组成**：脑（大脑/小脑/脑干）+ 脊髓 + 神经
- **基本方式**：反射；**结构基础**：反射弧
- **反射弧**：感受器→传入神经→神经中枢→传出神经→效应器
- **易混点**：反射（功能）vs 反射弧（结构）
- **口诀**："感传神传效"

## 简单反射vs复杂反射
- **简单反射**：生来就有，中枢在脊髓/脑干（缩手、膝跳）
- **复杂反射**：后天学习，中枢在大脑皮层（望梅止渴、谈虎色变）
- **口诀**："膝跳眨眼简单，望梅谈虎复杂"

## 视觉与听觉
- **近视**：晶状体曲度过大/眼球前后径过长 → 物像在视网膜前方 → 凹透镜
- **远视**：相反 → 凸透镜
- **口诀**："近凹远凸"
- **视觉形成**：光线→角膜→瞳孔→晶状体→玻璃体→视网膜→视神经→视觉中枢

# ===== D6 激素调节 =====

## 主要内分泌腺
| 腺体 | 激素 | 不足 | 过多 |
|------|------|------|------|
| 垂体 | 生长激素 | 侏儒症（智力正常） | 巨人症 |
| 甲状腺 | 甲状腺激素 | 呆小症（智力低下） | 甲亢 |
| 胰岛 | 胰岛素 | 糖尿病 | — |

- **易混点**：侏儒症（智力正常）vs 呆小症（智力低下）
- **口诀**："垂体生长甲腺素，胰岛胰岛素"

## 内分泌腺vs外分泌腺
- **内分泌腺**：无导管，分泌物直接进入血液（垂体/甲状腺/胰岛）
- **外分泌腺**：有导管（汗腺/唾液腺）
- **口诀**："内无外有"

# ===== D7 运动系统 =====

## 骨关节肌肉
- **组成**：骨 + 关节 + 骨骼肌
- **关节**：关节面 + 关节囊 + 关节腔（滑液润滑）
- **屈肘**：肱二头肌收缩、肱三头肌舒张
- **伸肘**：肱二头肌舒张、肱三头肌收缩
- **易混点**：屈肘vs伸肘的肌肉状态相反
- **口诀**："屈二伸三"（屈肘二头肌收缩）

# ===== D8 免疫与健康 =====

## 传染病三环节
- **传染源**（能散播病原体的人或动物）→ **传播途径** → **易感人群**
- **预防措施**：控制传染源、切断传播途径、保护易感人群
- **口诀**："源途径群三环节，控源断径护易感"

## 三道防线
| 防线 | 组成 | 类型 |
|------|------|------|
| 第一道 | 皮肤和黏膜 | 非特异性免疫 |
| 第二道 | 杀菌物质和吞噬细胞 | 非特异性免疫 |
| 第三道 | 免疫器官和免疫细胞 | 特异性免疫 |

## 特异性免疫
- **过程**：抗原 → 刺激淋巴细胞 → 产生抗体
- **特点**：抗体只针对特定抗原起作用
- **计划免疫**：接种疫苗（保护易感人群）
- **口诀**："抗原抗体特异配，疫苗免疫防疾病"
