# ===== 第一单元 人的由来 =====

## 人类的起源和发展
- **共同祖先**：森林古猿
- **最关键转变**：直立行走（使前肢解放出来，能制造和使用工具）
- **里程碑**：制造和使用工具
- **易混点**：直立行走（最关键）vs 制造工具（里程碑）
- **口诀**："森林古猿共祖先，直立行走最关键，制造工具里程碑"

## 人的生殖
- **男性主要器官**：睾丸（产生精子 + 雄性激素）
- **女性主要器官**：卵巢（产生卵细胞 + 雌性激素）
- **受精场所**：输卵管
- **胚胎发育场所**：子宫
- **物质交换**：胎盘和脐带
- **易混点**：睾丸（精子+雄性激素）vs 卵巢（卵细胞+雌性激素）
- **口诀**："睾丸精子雄激素，卵巢卵细胞雌激素"

## 青春期
- **显著特点**：身高突增
- **第二性征（男）**：喉结突出、声音变粗、长出胡须
- **第二性征（女）**：骨盆宽大、乳房增大、声音变细
- **易混点**：身高突增（显著特点）vs 第二性征（性别差异）
- **口诀**："青春期身高突增，第二性征男女分"

# ===== 第二单元 人体的营养 =====

## 合理营养与食品安全
- **平衡膳食宝塔**：谷类→蔬菜水果→肉蛋类→奶豆类→油脂类
- **合理营养**：全面而平衡的营养
- **食品安全**：关注生产日期、保质期、生产厂家
- **易混点**：合理营养（全面平衡）vs 食品安全（关注标识）
- **口诀**："宝塔五层谷果蔬肉蛋奶油，合理营养全面平衡"

## 消化和吸收
- **消化系统**：消化道 + 消化腺
- **小肠**：消化吸收主要场所（长、皱襞绒毛、多种消化液）
- **淀粉消化**：口腔（麦芽糖）→小肠（葡萄糖）
- **蛋白质消化**：胃（多肽）→小肠（氨基酸）
- **脂肪消化**：小肠（胆汁乳化→甘油脂肪酸）
- **易混点**：淀粉（口腔开始）vs 蛋白质（胃开始）vs 脂肪（小肠开始）
- **口诀**："淀粉口腔蛋白质胃，脂肪小肠三步走"

# ===== 第三单元 人体的呼吸 =====

## 呼吸道对空气的处理
- **呼吸系统**：呼吸道（鼻咽喉气管支气管）+ 肺
- **处理作用**：温暖、湿润、清洁
- **易混点**：温暖（毛细血管）vs 湿润（黏膜）vs 清洁（鼻毛纤毛黏液）
- **口诀**："呼吸道温暖湿润清洁，肺是气体交换场所"

## 发生在肺内的气体交换
- **吸气**：膈肌肋间外肌收缩→胸廓扩大→肺扩张→外界气体入
- **呼气**：膈肌肋间外肌舒张→胸廓缩小→肺回缩→气体出
- **肺泡特点**：数量多、外包毛细血管、壁薄（一层上皮细胞）
- **气体交换原理**：气体扩散（氧气从肺泡到血液，二氧化碳从血液到肺泡）
- **易混点**：吸气（肌收缩）vs 呼气（肌舒张）
- **口诀**："吸气收缩胸扩大，呼气舒张胸缩小"

# ===== 第四单元 人体内物质的运输 =====

## 流动的组织——血液
- **血液组成**：血浆 + 血细胞（红/白/血小板）
- **红细胞**：最多、无核、含血红蛋白（氧高结合氧低分离）
- **白细胞**：最大、有核、吞噬病菌
- **血小板**：最小、无核、止血凝血
- **易混点**：红细胞（最多/无核/血红蛋白）vs 白细胞（最大/有核/吞噬）vs 血小板（最小/无核/凝血）
- **口诀**："红细胞最多无核血红蛋白，白细胞最大有核吞噬，血小板最小无核凝血"

## 血流的管道——血管
- **动脉**：心脏→全身（壁厚弹性大）
- **静脉**：全身→心脏（壁薄弹性小，有瓣膜）
- **毛细血管**：壁薄（一层上皮细胞）、腔小（红细胞单行通过）、血流最慢
- **易混点**：动脉（心脏→全身）vs 静脉（全身→心脏）vs 毛细血管（物质交换）
- **口诀**："动脉心脏到全身，静脉全身到心脏，毛细血管物质交换"

## 输送血液的泵——心脏
- **四腔**：左心房、左心室、右心房、右心室
- **左心室最厚**：要将血液泵至全身，路程最远
- **瓣膜**：防止血液倒流（房室瓣：心房→心室；动脉瓣：心室→动脉）
- **体循环**：左心室→主动脉→全身→上下腔静脉→右心房（动脉血→静脉血）
- **肺循环**：右心室→肺动脉→肺→肺静脉→左心房（静脉血→动脉血）
- **易混点**：体循环（左心室开始）vs 肺循环（右心室开始）
- **口诀**："体循环左室到右房，肺循环右室到左房"

# ===== 第五单元 人体内废物的排出 =====

## 尿的形成和排出
- **泌尿系统**：肾脏→输尿管→膀胱→尿道
- **尿形成**：肾小球滤过（原尿）→肾小管重吸收（尿液）
- **原尿**：不含大分子蛋白质
- **尿液**：不含葡萄糖
- **重吸收**：全部葡萄糖、大部分水、部分无机盐
- **排泄途径**：呼吸系统（CO₂）、皮肤（水无机盐尿素）、泌尿系统（尿素水无机盐）
- **易混点**：原尿（无大分子蛋白）vs 尿液（无葡萄糖）
- **口诀**："肾小球滤过原尿成，肾小管重吸收尿液成"

# ===== 第六单元 人体生命活动的调节 =====

## 人体对外界环境的感知
- **视觉**：光线→角膜→瞳孔→晶状体→玻璃体→视网膜→视神经→大脑
- **近视**：晶状体曲度过大/眼球前后径过长→物像在视网膜前→凹透镜
- **听觉**：声波→外耳道→鼓膜→听小骨→耳蜗→听觉神经→大脑
- **易混点**：视觉（光线路径）vs 听觉（声波路径）
- **口诀**："视觉光线角瞳晶玻网，听觉声波外鼓听耳蜗"

## 神经系统的组成
- **中枢神经系统**：脑（大脑/小脑/脑干）+ 脊髓
- **周围神经系统**：脑神经 + 脊神经
- **大脑**：最高级中枢（调节生理活动）
- **小脑**：协调运动，维持平衡
- **脑干**：基本生命活动（心跳呼吸血压）
- **神经元**：细胞体 + 突起（树突/轴突），产生并传导兴奋
- **易混点**：大脑（最高级中枢）vs 小脑（协调平衡）vs 脑干（基本生命活动）
- **口诀**："大脑中枢小脑平衡，脑干心跳呼吸"

## 神经调节的基本方式
- **反射**：通过神经系统对刺激发生的有规律反应
- **反射弧**：感受器→传入神经→神经中枢→传出神经→效应器
- **非条件反射**：先天性，神经中枢在皮层以下
- **条件反射**：后天形成，神经中枢在大脑皮层
- **易混点**：非条件反射（先天）vs 条件反射（后天）
- **口诀**："反射弧五部分，感受传入中传出效应"

## 激素调节
- **内分泌腺**：无导管，分泌物直接入血
- **外分泌腺**：有导管，分泌物通过导管排出
- **生长激素**：促生长（过多→巨人症，过少→侏儒症）
- **甲状腺激素**：促代谢发育（过少→呆小症）
- **胰岛素**：调节糖代谢（过少→糖尿病）
- **易混点**：巨人症（生长激素过多）vs 侏儒症（生长激素过少）vs 呆小症（甲状腺激素过少）
- **口诀**："生长激素促生长，甲状腺促代谢，胰岛素调糖"

# ===== 第七单元 人类活动对生物圈的影响 =====

## 人类活动对生物圈的影响
- **人口问题**：资源短缺、环境污染、生态破坏
- **保护措施**：植树造林、节约资源、减少污染、绿色出行
- **易混点**：人口增长（问题根源）vs 保护措施（解决方案）
- **口诀**："人口增长问题多，植树造林绿色出行"
