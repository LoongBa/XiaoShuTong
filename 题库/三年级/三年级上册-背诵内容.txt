# 《大青树下的小学》吴然（片段背诵：第1-2自然段）
课文理解：《大青树下的小学》是一所怎样的学校？###不同民族的小学生一起上学、快乐玩耍的学校
课文理解：这所小学的学生来自哪些民族？###傣族、景颇族、阿昌族、德昂族，还有汉族
句子接龙：从山坡上，从坪坝里，###从一条条开着绒球花和太阳花的小路上，走来了许多小学生
句子接龙：同学们向在校园里欢唱的小鸟打招呼，向敬爱的老师问好，###向高高飘扬的国旗敬礼
句子接龙：上课了，不同民族的小学生###在同一间教室里学习。大家一起读课文，那声音真好听！
课文理解：同学们读课文时，窗外为什么十分安静？###树枝不摇了，鸟儿不叫了，蝴蝶停在花朵上，好像都在听同学们读课文
句子接龙：下课了，大家在大青树下跳孔雀舞、摔跤、做游戏，###招引来许多小鸟，连松鼠也赶来看热闹

# 《花的学校》泰戈尔（全文背诵）
文学常识：《花的学校》的作者是？###泰戈尔（印度诗人）
课文理解：课文把花当作"学生"来写，这是什么写法？###拟人（把花朵当作人来写）
句子接龙：当雷云在天上轰响，###六月的阵雨落下的时候
句子接龙：雨一来，###他们便放假了
句子接龙：这时，花孩子们便穿了紫的、黄的、白的衣裳，###冲了出来
课文理解：花孩子们为什么急急忙忙地要到天上去？###因为他们的家在天上，在星星所住的地方；他们也有他们的妈妈，就像我有我自己的妈妈一样

# 《不懂就要问》（片段背诵）
课文理解：《不懂就要问》讲的是谁小时候的故事？###孙中山
课文理解：孙中山小时候在哪里读书？###私塾
课文理解：孙中山对"只背书、不讲意思"的读书方法是怎么想的？###觉得糊里糊涂地背没有用，心里很不满足
句子接龙：学问学问，###不懂就要问
名句理解：孙中山关于做学问说的名言是？###学问学问，不懂就要问。为了弄清楚道理，就是挨打也值得。
课文理解：这篇课文告诉了我们什么道理？###遇到不懂的问题要大胆发问，做学问就要"不懂就问"

# 《铺满金色巴掌的水泥道》张秋生（片段背诵：第1-2自然段）
课文理解：课文中的"金色巴掌"指的是什么？###法国梧桐树的落叶（金黄的落叶像金色的小巴掌）
句子接龙：一夜秋风，###一夜秋雨
句子接龙：水泥道像铺上了一块彩色的地毯，###这是一块印着落叶图案的、闪闪发光的地毯，从脚下一直铺到很远很远的地方，一直到路的尽头
句子接龙：每一片法国梧桐树的落叶，###都像一个金色的小巴掌，熨帖地、平展地粘在水泥道上
句子接龙：我穿着一双棕红色的小雨靴。你瞧，###这多像两只棕红色的小鸟，在秋天金黄的叶丛间，愉快地蹦跳着、歌唱着
课文理解：作者把"我"的两只小雨靴比作什么？###两只棕红色的小鸟

# 《秋天的雨》陶金鸿（片段背诵：第1-3自然段）
句子接龙：秋天的雨，是一把钥匙，###它带着清凉和温柔，轻轻地，轻轻地，趁你没留意，把秋天的大门打开了
句子接龙：它把黄色给了银杏树，###黄黄的叶子像一把把小扇子，扇哪扇哪，扇走了夏天的炎热
句子接龙：它把红色给了枫树，###红红的枫叶像一枚枚邮票，飘哇飘哇，邮来了秋天的凉爽
句子接龙：金黄色是给田野的，###看，田野像金色的海洋
句子接龙：橘子、柿子你挤我碰，###争着要人们去摘呢
名句理解："小朋友的脚，常被那香味勾住"中"勾住"表现出什么？###秋雨里藏着好闻的气味，把小朋友吸引住（写出秋天气味的香甜诱人）

# 《富饶的西沙群岛》（片段背诵：第3-4自然段）
句子接龙：海底的岩石上长着各种各样的珊瑚，###有的像绽开的花朵，有的像分枝的鹿角
句子接龙：海参到处都是，###在海底懒洋洋地蠕动
课文理解：大龙虾的样子为什么显得威武？###大龙虾全身披甲，划过来，划过去
句子接龙：鱼成群结队地在珊瑚丛中穿来穿去，###好看极了
句子接龙：正像人们说的那样，###西沙群岛的海里一半是水，一半是鱼
名句理解："一半是水，一半是鱼"运用了什么修辞手法？###夸张（突出西沙群岛海里的鱼非常多）

# 《海滨小城》林遐（片段背诵：第3-5自然段）
课文理解：小城的庭院里栽了哪些树？###桉树、椰子树、橄榄树、凤凰树，还有别的许多亚热带树木
句子接龙：凤凰树开了花，###开得那么热闹，小城好像笼罩在一片片红云中
句子接龙：小城的公园更美，###这里种着许多榕树。一棵棵榕树就像一顶顶撑开的绿绒大伞
句子接龙：一棵棵榕树就像一顶顶撑开的绿绒大伞，###树叶密不透风，可以遮太阳，挡风雨
句子接龙：小城的街道也美，###除了沥青的大路，都是用细沙铺成的，踩上去咯吱咯吱地响，好像踩在沙滩上一样
句子接龙：人们把街道打扫得十分干净，###甚至连一片落叶都没有

# 《美丽的小兴安岭》（片段背诵：第1-2自然段）
句子接龙：我国东北的小兴安岭，###有数不清的红松、白桦、栎树
句子接龙：几百里连成一片，###就像绿色的海洋
句子接龙：春天，树木抽出新的枝条，###长出嫩绿的叶子
句子接龙：山上的积雪融化了，###雪水汇成小溪，淙淙地流着
句子接龙：小鹿在溪边散步，###它们有的俯下身子喝水，有的侧着脑袋欣赏自己映在水里的影子
名句理解："树木抽出新的枝条"中的"抽出"写出了什么？###枝条迅速向上生长、生机勃勃的样子

# 《大自然的声音》（片段背诵：第1-2自然段）
句子接龙：大自然有许多美妙的声音，###风，是大自然的音乐家
句子接龙：风，是大自然的音乐家，###他会在森林里演奏他的手风琴
句子接龙：当他翻动树叶，###树叶便像歌手一样，唱出各种不同的歌曲
句子接龙：不一样的树叶，有不一样的声音；###不一样的季节，有不一样的音乐
句子接龙：当微风拂过，###那声音轻轻柔柔的，好像呢喃细语，让人感受到大自然的温柔
句子接龙：当狂风吹起，###整座森林都激动起来，合奏出一首雄伟的乐曲

# 《读不完的大书》朱维之（片段背诵）
句子接龙：我五六岁时，###就喜欢到大自然去寻找好玩的东西
句子接龙：小麻雀叽叽喳喳、蹦蹦跳跳的，###叫人愉悦
句子接龙：老鹰在高空盘旋，展翅滑翔，突然猛扑而下，###给人以雄健勇猛的感觉
名句理解：课文结尾的名句是？###大自然是一本看不完的大画册，是一部永远读不完的大书，里面有无穷的奥秘，有无尽的乐趣。
课文理解：为什么说大自然是一本"读不完的大书"？###因为大自然里有数不清的动植物和不断变化的景物，奥秘和乐趣无穷无尽
句子接龙：大自然是一本看不完的大画册，###是一部永远读不完的大书

# 《望天门山》李白/唐
文学常识：《望天门山》的作者及朝代是？###李白，唐
文学常识：李白被人们称为？###诗仙
补全：《望天门山》中"天门中断楚江开"的后一句是？###碧水东流至此回
补全：《望天门山》中"两岸青山相对出"的后一句是？###孤帆一片日边来
名句理解：《望天门山》中写两岸青山对峙、小船从日边驶来的句子是？###两岸青山相对出，孤帆一片日边来。
整篇默写：默写《望天门山》###天门中断楚江开，碧水东流至此回。两岸青山相对出，孤帆一片日边来。

# 《饮湖上初晴后雨》苏轼/宋
文学常识：《饮湖上初晴后雨》的作者及朝代是？###苏轼，宋
文学常识：苏轼号什么？###东坡居士（世称"苏东坡"）
补全：水光潋滟晴方好，###山色空蒙雨亦奇
补全：《饮湖上初晴后雨》中"欲把西湖比西子"的后一句是？###淡妆浓抹总相宜
名句理解：《饮湖上初晴后雨》中描写西湖晴天和雨天两种美的名句是？###水光潋滟晴方好，山色空蒙雨亦奇。
名句理解：诗中把西湖比作什么？###把西湖比作西施（西子）
整篇默写：默写《饮湖上初晴后雨》###水光潋滟晴方好，山色空蒙雨亦奇。欲把西湖比西子，淡妆浓抹总相宜。

# 《望洞庭》刘禹锡/唐
文学常识：《望洞庭》的作者及朝代是？###刘禹锡，唐
文学常识：刘禹锡被称为？###诗豪
补全：《望洞庭》中"湖光秋月两相和"的后一句是？###潭面无风镜未磨
补全：《望洞庭》中"遥望洞庭山水翠"的后一句是？###白银盘里一青螺
名句理解：《望洞庭》中把洞庭湖比作"白银盘"、把君山比作"青螺"的句子是？###遥望洞庭山水翠，白银盘里一青螺。
整篇默写：默写《望洞庭》###湖光秋月两相和，潭面无风镜未磨。遥望洞庭山水翠，白银盘里一青螺。

# 《司马光》（全文背诵）
文学常识：《司马光》这个故事选自哪部史书？###《宋史》
文学常识：司马光生活在哪个朝代？###北宋
补全：群儿戏于庭，###一儿登瓮，足跌没水中
文言文理解："众皆弃去"中"弃"的意思是什么？###放弃、离开（大家都吓跑了）
文言文理解：司马光用什么办法救了落水的小朋友？###持石击瓮破之（拿起石头砸破水瓮，让水流出来）
文言文理解：这个故事表现了司马光怎样的品质？###遇事沉着冷静、机智勇敢
整篇默写：默写《司马光》###群儿戏于庭，一儿登瓮，足跌没水中。众皆弃去，光持石击瓮破之，水迸，儿得活。
