# 《海底世界》（片段背诵：第3-4自然段）
句子接龙：海里的动物，###各有各的活动方法
句子接龙：海参靠肌肉伸缩爬行，###每小时只能前进四米
句子接龙：有一种鱼身体像梭子，###每小时能游几十千米，攻击其他动物的时候，比普通的火车还快
名句理解：乌贼和章鱼是怎样前进的？###能突然向前方喷水，利用水的反推力迅速后退
句子接龙：还有些贝类自己不动，###却能巴在轮船底下做免费的长途旅行
名句理解："免费的长途旅行"写出了贝类怎样的活动方式？###贝类借助轮船四处活动，好像搭便车旅行，生动有趣
句子接龙：海底的植物差异也很大，###它们的色彩多种多样，有褐色的，有紫色的，还有红色的
句子接龙：最小的单细胞海藻，###要用显微镜才能看清楚

# 《火烧云》萧红（片段背诵：第1-2自然段）
句子接龙：晚饭过后，###火烧云上来了
句子接龙：天上的云从西边一直烧到东边，###红彤彤的，好像是天空着了火
课文理解：霞光下，哪几种动物变成了什么颜色？###大白狗变红，红公鸡变金，黑母鸡变紫檀色，小白猪变小金猪
名句理解：为什么叫"火烧云"？###因为天上的云从西边一直烧到东边，红彤彤的，好像是天空着了火

# ===== 课内古诗（第 1 课 / 第 9 课 古诗三首）=====

# 《绝句》杜甫/唐
文学常识：《绝句》（迟日江山丽）的作者及朝代是？###杜甫，唐
文学常识：杜甫被人们称为？###诗圣
补全：迟日江山丽，###春风花草香
补全：《绝句》中"泥融飞燕子"的后一句是？###沙暖睡鸳鸯
名句理解：《绝句》中写燕子筑巢、鸳鸯安睡春日图景的句子是？###泥融飞燕子，沙暖睡鸳鸯。
整篇默写：默写《绝句》###迟日江山丽，春风花草香。泥融飞燕子，沙暖睡鸳鸯。

# 《惠崇春江晚景》苏轼/宋
文学常识：《惠崇春江晚景》的作者及朝代是？###苏轼，宋
文学常识：诗中的"惠崇"是什么人？###北宋著名僧人、画家，（这幅《春江晚景》图是惠崇画的）
补全：竹外桃花三两枝，###春江水暖鸭先知
补全：《惠崇春江晚景》中"蒌蒿满地芦芽短"的后一句是？###正是河豚欲上时
名句理解：诗中最能表现"春江水暖"、先知春意的名句是？###春江水暖鸭先知。
整篇默写：默写《惠崇春江晚景》###竹外桃花三两枝，春江水暖鸭先知。蒌蒿满地芦芽短，正是河豚欲上时。

# 《三衢道中》曾几/宋
文学常识：《三衢道中》的作者及朝代是？###曾几，宋
文学常识：诗题中的"三衢"指的是哪里？###今浙江衢州一带（三衢山）
补全：梅子黄时日日晴，###小溪泛尽却山行
补全：《三衢道中》中"绿阴不减来时路"的后一句是？###添得黄鹂四五声
名句理解："绿阴不减来时路，添得黄鹂四五声"中的"添得"写出了什么？###山路上传来黄鹂的叫声，给旅途增添了快乐（表现诗人愉快的心情）
整篇默写：默写《三衢道中》###梅子黄时日日晴，小溪泛尽却山行。绿阴不减来时路，添得黄鹂四五声。

# 《元日》王安石/宋
文学常识：《元日》的作者及朝代是？###王安石，宋（北宋）
文学常识："元日"指的是什么节日？###春节（农历正月初一）
补全：爆竹声中一岁除，###春风送暖入屠苏
补全：《元日》中"千门万户曈曈日"的后一句是？###总把新桃换旧符
名句理解："总把新桃换旧符"写的是哪种习俗？###春节换桃符的习俗（象征除旧迎新）
整篇默写：默写《元日》###爆竹声中一岁除，春风送暖入屠苏。千门万户曈曈日，总把新桃换旧符。

# 《清明》杜牧/唐
文学常识：《清明》的作者及朝代是？###杜牧，唐（晚唐）
文学常识："清明"是什么？###二十四节气之一，也是纪念先人、踏青的节日
补全：清明时节雨纷纷，###路上行人欲断魂
补全：《清明》中"借问酒家何处有"的后一句是？###牧童遥指杏花村
名句理解："路上行人欲断魂"写出了行人怎样的心情？###清明时节思念亲人、心情忧伤
整篇默写：默写《清明》###清明时节雨纷纷，路上行人欲断魂。借问酒家何处有？牧童遥指杏花村。

# 《九月九日忆山东兄弟》王维/唐
文学常识：《九月九日忆山东兄弟》的作者及朝代是？###王维，唐
文学常识：王维被人们称为？###诗佛（他的诗"诗中有画"）
文学常识："九月九日"是什么节日？###重阳节
补全：独在异乡为异客，###每逢佳节倍思亲
补全：《九月九日忆山东兄弟》中"遥知兄弟登高处"的后一句是？###遍插茱萸少一人
名句理解：表达游子节日思念亲人的千古名句是？###独在异乡为异客，每逢佳节倍思亲。
整篇默写：默写《九月九日忆山东兄弟》###独在异乡为异客，每逢佳节倍思亲。遥知兄弟登高处，遍插茱萸少一人。

# 《忆江南》白居易/唐
文学常识：《忆江南》的作者及朝代是？###白居易，唐
文学常识：《忆江南》的体裁是什么？###词（"忆江南"是词牌名）
补全：江南好，###风景旧曾谙
补全：《忆江南》中"日出江花红胜火"的后一句是？###春来江水绿如蓝
名句理解：《忆江南》中写江南春景色彩明丽的名句是？###日出江花红胜火，春来江水绿如蓝。
整篇默写：默写《忆江南》###江南好，风景旧曾谙。日出江花红胜火，春来江水绿如蓝。能不忆江南？

# 《滁州西涧》韦应物/唐
文学常识：《滁州西涧》的作者及朝代是？###韦应物，唐
补全：独怜幽草涧边生，###上有黄鹂深树鸣
补全：《滁州西涧》中"春潮带雨晚来急"的后一句是？###野渡无人舟自横
名句理解："野渡无人舟自横"描绘了一幅怎样的画面？###傍晚渡口静悄悄没有人，一只小船随意横在水面上（一幅幽静恬淡的山水画）
整篇默写：默写《滁州西涧》###独怜幽草涧边生，上有黄鹂深树鸣。春潮带雨晚来急，野渡无人舟自横。

# 《大林寺桃花》白居易/唐
文学常识：《大林寺桃花》的作者及朝代是？###白居易，唐
文学常识：诗中的大林寺在哪里？###庐山
补全：人间四月芳菲尽，###山寺桃花始盛开
补全：《大林寺桃花》中"长恨春归无觅处"的后一句是？###不知转入此中来
名句理解："人间四月芳菲尽，山寺桃花始盛开"蕴含了什么地理知识？###山上地势高、气温低，花开得晚（春天在高山上还有）
整篇默写：默写《大林寺桃花》###人间四月芳菲尽，山寺桃花始盛开。长恨春归无觅处，不知转入此中来。

# 《守株待兔》（全文背诵）
文学常识：《守株待兔》选自哪部书？###《韩非子·五蠹》
文学常识：韩非是哪个学派的代表？###法家（战国末期思想家）
文言文理解："兔走触株"中"走"的意思是什么？###跑（古文中"走"指跑）
文言文理解：农民为什么放下农具守在树桩旁？###因释其耒而守株，冀复得兔（希望再捡到撞死的兔子）
补全：兔走触株，###折颈而死
补全：因释其耒而守株，###冀复得兔
文言文理解：故事的结局是怎样的？###兔不可复得，而身为宋国笑（兔子没等到，自己反被宋国人笑话）
名句理解：成语"守株待兔"现在比喻什么？###死守经验、不知变通，妄想不劳而获
整篇默写：默写《守株待兔》###宋人有耕者。田中有株。兔走触株，折颈而死。因释其耒而守株，冀复得兔。兔不可复得，而身为宋国笑。

成语题：语文园地二日积月累中的九个寓言成语是？###邯郸学步、滥竽充数、掩耳盗铃、自相矛盾、刻舟求剑、画蛇添足、杞人忧天、井底之蛙、杯弓蛇影
成语出处："滥竽充数"出自哪部书？###《韩非子》
成语出处："自相矛盾"出自哪部书？###《韩非子》
成语出处："刻舟求剑"出自哪部书？###《吕氏春秋》
成语出处："画蛇添足"出自哪部书？###《战国策》
成语出处："邯郸学步"出自哪部书？###《庄子》
成语理解："掩耳盗铃"比喻什么？###自己欺骗自己（明明掩盖不住，偏要自己想办法掩饰）
成语理解："杯弓蛇影"比喻什么？###疑神疑鬼、自己吓自己（因多疑而自相惊扰）

# 语文园地四 歇后语
补全歇后语：小葱拌豆腐，###一清（青）二白

补全歇后语：芝麻开花，###节节高
补全歇后语：十五个吊桶打水，###七上八下
