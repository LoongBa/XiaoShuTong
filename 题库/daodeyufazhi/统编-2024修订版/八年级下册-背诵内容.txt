# 教材：人教统编版 2024 修订版（5 单元 14 课）

# ===== 第一单元 坚持宪法至上 =====

# 第1课 治国安邦的总章程
我国宪法的核心价值追求是？###规范国家权力运行以保障公民权利
中华人民共和国是什么性质的国家？###工人阶级领导的、以工农联盟为基础的人民民主专政的社会主义国家
我国的根本制度是？###社会主义制度
中国特色社会主义最本质的特征是？###中国共产党领导
宪法的地位是？###宪法是国家的根本法，是治国安邦的总章程，具有最高的法律效力
宪法的核心内容是？###公民的基本权利和义务
宪法的基本原则是？###国家的一切权力属于人民
尊重和保障人权是我国的一项什么？###宪法原则
人权的实质内容和目标是？###人的自由、平等地生存和发展
宪法为什么要规范国家权力运行？###权力是一把双刃剑，在法治轨道上行使可以造福人民，在法律之外行使则祸害国家和人民
宪法如何规范国家权力运行？###授予国家机构特定职权、划定权力边界、规定运行程序，把权力关进制度的笼子
我国宪法是谁制定和完善的？###中国共产党领导人民制定和完善的，集中体现了党和人民的统一意志

# 第2课 维护宪法权威
坚持依法治国首先要坚持什么？###依宪治国
依宪治国的要求有哪些？###①坚持党的领导地位不动摇；②坚持人民民主专政和人民代表大会制度不动摇；③一切组织和个人都必须在宪法和法律范围内活动；④坚持宪法至上，维护国家法制统一、尊严和权威
宪法最高法律效力表现在哪里？###宪法是其他法律的立法基础和立法依据，其他法律不得与宪法相抵触，否则因违宪无效
行使监督宪法实施职权的机关是？###全国人民代表大会及其常务委员会
全国人大常委会对宪法的职权是？###有权解释宪法和法律
增强宪法意识的途径有哪些？###认同宪法、学习宪法、践行宪法
为什么说宪法与我们每个人息息相关？###宪法是我们一生的保护伞，我们要依据宪法和法律行使权利、履行义务

# ===== 第二单元 理解权利义务 =====

# 第3课 公民的基本权利和义务
公民基本权利包括哪些？###平等权、政治权利和自由、人身自由、社会经济权利、文化教育权利、监督权与获得国家赔偿权、宗教信仰自由等
平等权的含义是？###公民在法律面前一律平等，平等享有权利、平等履行义务、平等适用法律
选举权和被选举权的条件及重要性？###年满18周岁的中国公民且未被剥夺政治权利；是公民参与管理国家和管理社会的基础
政治自由包括哪些？###言论、出版、集会、结社、游行、示威的自由
监督权的内容是？###对任何国家机关和国家工作人员有批评建议权，对其违法失职行为有申诉、控告、检举权
人身自由的地位是？###公民最基本、最重要的权利
人身自由不受侵犯的含义是？###公民的人身不受非法侵犯的自由，包括人格尊严、住宅、通信自由和通信秘密不受侵犯
人格尊严权包括哪些？###姓名权、肖像权、名誉权、荣誉权、隐私权
社会经济权利包括哪些？###财产权、劳动权、物质帮助权
文化教育权利包括哪些？###受教育权、文化权利
公民基本义务包括哪些？###维护国家统一和全国各民族团结、遵守宪法和法律、维护国家安全荣誉和利益、依法服兵役、依法纳税等
依法纳税的意义？###税收是国家财政收入的主要来源，逃税、欠税、骗税、抗税是违法行为

# 第4课 依法行使权利和履行义务
权利与义务的关系是？###相互依存、相互促进；公民既是权利的享有者，又是义务的承担者；某些权利同时也是义务（劳动和受教育）
如何依法行使权利？###行使权利时要尊重他人权利，不能损害国家、社会、集体的利益，按照法定程序，以合法方式进行
如何依法履行义务？###法律要求做的必须做，法律禁止做的坚决不做，法律鼓励做的积极去做
公民维护权利的途径有哪些？###协商、调解、仲裁、诉讼等

# ===== 第三单元 认识国家制度 =====

# 第5课 我国的政治制度
我国的根本政治制度是？###人民代表大会制度
我国的基本政治制度有哪些？###中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度
多党合作的基本方针是？###长期共存、互相监督、肝胆相照、荣辱与共
人民政协的职能是？###政治协商、民主监督、参政议政
处理民族关系的基本原则是？###民族平等、民族团结、各民族共同繁荣
基层群众自治制度的内容是？###实行村民委员会和居民委员会自我管理、自我教育、自我服务

# 第6课 我国的基本经济制度
我国的基本经济制度是？###公有制为主体、多种所有制经济共同发展；按劳分配为主体、多种分配方式并存；社会主义市场经济体制
公有制经济包括哪些？###国有经济、集体经济、混合所有制经济中的国有成分和集体成分
非公有制经济包括哪些？###个体经济、私营经济、外资经济等
社会主义市场经济体制中市场与政府的作用？###市场在资源配置中起决定性作用，更好发挥政府作用

# ===== 第四单元 走近国家机构 =====

# 第7课 国家权力机关
我国的最高国家权力机关是？###全国人民代表大会
人民代表大会的职权有哪些？###立法权、决定权、任免权、监督权
全国人大的地位是？###最高国家权力机关，代表人民统一行使国家权力

# 第8课 中华人民共和国主席
国家主席的性质是？###代表国家行使宪法赋予的职权，由全国人民代表大会产生
国家主席的职权有哪些？###公布法律、发布命令；任免权；外事权；荣典权

# 第9课 国家行政机关
国家行政机关的性质是？###国家权力机关的执行机关，国务院是最高国家行政机关
依法行政的要求是？###法定职责必须为、法无授权不可为；有权必有责、用权受监督

# 第10课 中央军事委员会
中央军事委员会的性质是？###领导全国武装力量，由全国人民代表大会产生并对其负责

# 第11课 国家监察机关
国家监察机关的性质是？###行使国家监察职能的专责机关，对所有行使公权力的公职人员监察
监察委员会的职责有哪些？###监督职责（首要职责）、调查职责（经常性工作）、处置职责

# 第12课 国家司法机关
人民法院的性质是？###国家的审判机关
人民检察院的性质是？###国家的法律监督机关
司法机关行使职权的原则是？###以事实为根据、以法律为准绳，依法独立公正行使职权

# ===== 第五单元 建设法治中国 =====

# 第13课 坚持全面依法治国
全面依法治国的行动指南是？###习近平法治思想
全面依法治国的总目标是？###建设中国特色社会主义法治体系，建设社会主义法治国家
全面依法治国的十六字方针是？###科学立法、严格执法、公正司法、全民守法
科学立法对应哪个机关？###全国人大及其常委会
严格执法对应哪个机关？###行政机关
公正司法对应哪个机关？###人民法院和人民检察院
法治的地位是？###法治是现代政治文明的核心，是治国理政的基本方式

# 第14课 以法治推进国家治理现代化
法治与改革的关系是？###改革和法治相辅相成、相互促进；重大改革于法有据，在法治轨道上推进改革
法治与德治的关系是？###法律是成文的道德，道德是内心的法律；法安天下，德润人心；坚持依法治国和以德治国相结合，使法治和德治相得益彰
