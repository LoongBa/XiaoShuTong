# 八年级上册 道德与法治 背诵篇目清单

> 来源：教材原文复核（2026-09 对照《义务教育教科书·道德与法治八年级上册》全文逐课核对）
> 基准版本：人教统编版 2024 修订版（依据 2022 年版课程标准编写，4 单元 12 课）
> 用途：题库建设篇目元信息（L0 层）
> 可靠度：🟢 高（直接对照教材目录与正文逐课核对）
> 结构说明：教材为 单元—课—框题 结构，背诵以【课】为单位组织，考点主要是框题下的核心观点/概念/要求/意义（教材正文黑体句、相关链接、阅读感悟、探究与分享中的关键结论）
> 备注：旧版清单（10 课框架）为 2017 旧教材结构，已整体替换为 2024 修订版 12 课结构

## 一、教材结构（4 单元 12 课）

### 第一单元 走进社会生活（第1-3课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第1课 丰富的社会生活 | 1.1 认识社会生活 | 社会生活特点（丰富多彩/变化发展/公共性）、社会活动构成 | ~7 |
| | 1.2 我们都是社会的一员 | 人是社会的人、"大网"结点、社会关系类型、身份在社会关系中确定 | ~10 |
| 第2课 在社会中健康成长 | 2.1 人的社会化 | 社会化含义、社会化学习内容（技能/规范/角色）、影响因素 | ~9 |
| | 2.2 养成亲社会行为 | 亲社会行为含义、意义、养成途径 | ~8 |
| 第3课 共建网络美好家园 | 3.1 网络改变世界 | 网络改变生活方式/人际交往/生产方式/社会治理 | ~10 |
| | 3.2 营造清朗空间 | 媒介素养、选择信息、抵制不良信息、恪守道德法律、传播正能量 | ~10 |

### 第二单元 维护社会秩序（第4-6课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第4课 遵守社会规则 | 4.1 维护秩序靠规则 | 社会秩序含义、秩序分类、规则的含义与作用 | ~9 |
| | 4.2 遵守规则 | 增强规则意识、他律与自律、维护规则、完善规则 | ~8 |
| 第5课 社会生活讲道德 | 5.1 文明有礼 | 文明有礼的意义（立身处世/社会和谐/国家形象）、做法 | ~9 |
| | 5.2 诚实守信 | 诚信的含义、立身/社会/企业意义、做法 | ~10 |
| | 5.3 友善待人 | 友善含义、宽容、换位思考、助人为乐 | ~7 |
| 第6课 提升法治素养 | 6.1 树立法治观念 | 法律的地位、法治观念含义、敬畏信仰法律、学习法律、自觉守法 | ~10 |
| | 6.2 学会依法办事 | 自觉守法、遇事找法、解决问题靠法、依法办事习惯 | ~8 |

### 第三单元 勇担社会责任（第7-9课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第7课 追求自由平等 | 7.1 珍视自由 | 自由的含义、意义、珍惜权利、依法行使权利、尊重他人权利 | ~11 |
| | 7.2 践行平等 | 平等含义（同等情况同等对待）、人格平等、权利义务平等、践行平等 | ~9 |
| 第8课 维护公平正义 | 8.1 坚守公平 | 公平含义、公平价值、维护公平 | ~9 |
| | 8.2 守护正义 | 正义含义、正义价值、守护正义（勇气智慧/司法公正/国际正义） | ~10 |
| 第9课 积极奉献社会 | 9.1 社会责任我担当 | 责任含义、"三个负责"、承担责任的意义 | ~9 |
| | 9.2 奉献社会我践行 | 奉献社会的表现与意义、加强学习、向团组织靠拢、志愿服务、担当时代责任 | ~10 |

### 第四单元 维护国家利益（第10-12课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第10课 国家利益至上 | 10.1 国家利益高于一切 | 国家利益含义、核心利益、主权和领土红线、国家利益与人民利益关系 | ~10 |
| | 10.2 捍卫国家利益 | 捍卫国家利益的神圣职责、责任感和使命感、正确处理国家与个人利益、斗争精神 | ~9 |
| 第11课 军强才能国安 | 11.1 党和人民信赖的英雄军队 | 军队构成、党对军队绝对领导、人民军队性质（四支军队） | ~12 |
| | 11.2 全面推进国防和军队现代化 | 强军目标、新"三步走"、坚持党的领导、全民国防教育 | ~10 |
| 第12课 树立总体国家安全观 | 12.1 认识国家安全 | 国家安全含义、重要性、总体国家安全观（"总体"/"五个以"/"十个坚持"） | ~12 |
| | 12.2 维护国家安全 | 维护国家安全义务、提升国家安全素养 | ~7 |
