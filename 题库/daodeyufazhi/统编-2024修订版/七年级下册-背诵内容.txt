# 七年级下册 道德与法治 背诵内容测试题
# 教材：人教统编版 2024 修订版（4 单元 10 课）
# 格式：问题###答案（# 开头为注释）

# ===== 第一单元 青春时光 =====

# 第1课 青春的邀约
青春期身体变化主要表现在哪些方面？###身体外形的变化、内部器官的完善、性机能的成熟
青春期矛盾心理有哪些表现？###反抗与依赖、闭锁与开放、勇敢与怯懦
如何处理青春期矛盾心理？###①参加集体活动，在集体的温暖中放松自己；②通过求助他人，学习化解烦恼的方法；③培养兴趣爱好转移注意力；④学习自我调节，成为自己的"心理保健医生"
独立思考的含义是？###独立思考并不等同于一味追求独特，而是表现为不人云亦云，有自己独到的见解，同时能接纳他人合理、正确的意见
批判精神的表现是？###对事情有自己的看法，并且敢于表达不同观点，敢于对不合理的事情说"不"，敢于向权威挑战

# 第2课 青春的心弦
性别角色认识的作用？###可以帮助我们了解自己与异性的不同特点，学习如何与异性相处
如何正确对待异性情感？###①内心慎重、理智处理；②学会保护自己；③举止得体、把握分寸
异性交往的原则？###内心坦荡、言谈得当、举止得体

# 第3课 青春的证明
自信的作用是？###自信让我们充满激情；自信的人有勇气交往与表达，有信心尝试与坚持
自强的重要内容是？###不断克服自己的弱点，战胜自己、超越自己
如何做到自强？###①靠坚强的意志、进取的精神和不懈的坚持；②树立坚定的理想；③战胜自我，超越自我
行己有耻的含义是？###一个人行事，凡自己认为可耻的就不去做
如何做到行己有耻？###①需要我们有知耻之心，不断提高辨别"耻"的能力；②要求我们树立底线意识，触碰道德底线的事情不做，违反法律的事情坚决不做；③需要我们磨砺意志，拒绝不良诱惑，不断增强自控力
止于至善的含义是？###人的一种精神境界，是我们毕生的追求
如何做到止于至善？###①从点滴小事做起；②在生活中寻找好的榜样；③养成自我省察的习惯；④以修身为本，行走在"止于至善"的路上

# ===== 第二单元 做情绪情感的主人 =====

# 第4课 揭开情绪的面纱
基本情绪有哪些？###喜、怒、哀、惧
情绪的作用是？###情绪影响着我们的观念和行动；积极的情绪激励我们克服困难、努力向上；消极的情绪可能让我们因为某个小小的挫败而止步不前
如何管理情绪？###①改变认知评价；②转移注意；③合理宣泄；④放松训练

# 第5课 品出情感的韵味
情感的作用是？###情感是人最基本的精神需求；情感反映着我们对人和对事的态度、观念，影响我们的判断和选择，驱使我们做出行动；丰富、深刻的情感有助于我们更全面地观察事物，探索未知
如何获得美好情感？###通过阅读、与人交往、参与有意义的社会活动等方式
如何传递情感正能量？###①用自己的热情和行动来影响环境；②在与他人的情感交流中传递美好的情感；③在生活中不断创造美好的情感体验

# ===== 第三单元 在集体中成长 =====

# 第6课 "我"和"我们"
集体的含义是什么？###集体是人们联合起来的有组织的整体
集体的温暖体现在？###在集体中可以获得安全感和归属感；被认可和接纳，获得尊重和理解
集体生活对个人成长的作用？###①集体生活可以培养我们负责任的态度和能力；②集体生活可以培养人际交往的基本态度和能力；③在集体中可以发展个性

# 第7课 共奏和谐乐章
个人利益与集体利益的关系是？###①在集体中，个人利益与集体利益本质上是一致的；②当个人利益与集体利益发生冲突时，应把集体利益放在个人利益之上，坚持集体主义
如何处理个人节奏与集体旋律的关系？###①尽力做好自己，遵守规则；②通过自己的努力解决集体遇到的困难；③当个人利益与集体利益发生冲突时，把集体利益放在个人利益之上

# 第8课 美好集体有我在
美好集体的特征是？###①美好集体是民主的、公正的；②美好集体是充满关怀与友爱的；③美好集体是善于合作的；④美好集体是充满活力的
如何建设美好集体？###①需要我们自主建设、自我管理；②需要我们共同确定愿景和目标；③需要我们共同商定集体的规则与制度内容；④需要我们共同创造良好的集体氛围

# ===== 第四单元 走进法治天地 =====

# 第9课 法律在我们身边
法律与生活的关系是？###法律就在我们身边，我们的生活离不开法律；法律已经深深地嵌入我们的生活之中，渗透到社会的方方面面
法律的特征有哪些？###①法律是由国家制定或认可的；②法律是由国家强制力保证实施的；③法律对全体社会成员具有普遍约束力
法律的作用是？###①规范着全体社会成员的行为，保护着我们的生活，为我们的成长和发展创造安全、健康、有序的社会环境；②法律通过解决纠纷和制裁违法犯罪，惩恶扬善、伸张正义，维护我们的合法权益

# 第10课 法律伴我们成长
对未成年人的特殊保护有哪些？###家庭保护、学校保护、社会保护、网络保护、政府保护、司法保护
为什么要对未成年人特殊保护？###未成年人身心发育尚不成熟，自我保护能力较弱，辨别是非能力和自我控制能力不强，容易受到不良因素的影响和不法侵害
如何树立法治意识？###①发自内心地认可、崇尚、遵守和服从法律；②学会依法办事，养成学法尊法守法用法的习惯；③依法维护自己的合法权益，依法维护国家利益
