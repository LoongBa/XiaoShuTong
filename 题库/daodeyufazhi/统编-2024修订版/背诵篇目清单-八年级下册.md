# 八年级下册 道德与法治（法治专册）背诵篇目清单

> 基准版本：人教统编版 2024 修订版（依据 2022 年版课程标准编写，5 单元 14 课）
> 用途：题库建设篇目元信息（L0 层）
> 可靠度：🟢 高（直接对照教材目录与正文逐课核对）
> 结构说明：教材为 单元—课—框题 结构，背诵以【课】为单位组织，考点主要是框题下的核心观点/概念/要求/意义（教材正文黑体句、相关链接、探究与分享中的关键结论）

## 一、教材结构（5 单元 14 课）

### 第一单元 坚持宪法至上（第1-2课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第1课 治国安邦的总章程 | 1.1 党领导人民制定宪法 | 宪法定性（治国安邦总章程）、产生与发展历程、国家性质/根本制度/最本质特征、党的主张与人民意志统一 | ~5 |
| | 1.2 宪法的内容和作用 | 宪法内容（国家性质/权力属于人民/基本权利义务/国家机构）、根本法地位、规范权力运行、尊重保障人权 | ~6 |
| 第2课 维护宪法权威 | 2.1 依宪治国 | 依宪治国地位与要求、宪法最高效力、宪法实施与监督 | ~6 |
| | 2.2 尊崇宪法 | 宪法根基在人民拥护、宪法与我们息息相关、认同/学习/践行宪法 | ~5 |

### 第二单元 理解权利义务（第3-4课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第3课 公民的基本权利和义务 | 3.1 公民基本权利 | 平等权/政治权利/人身自由/社会经济权利/文化教育权利/监督权与获得国家赔偿权/宗教信仰自由 | ~7 |
| | 3.2 公民基本义务 | 维护国家统一和民族团结/遵守宪法法律/维护国家安全荣誉利益/依法服兵役/依法纳税/其他义务 | ~6 |
| 第4课 依法行使权利和履行义务 | 4.1 权利与义务相统一 | 权利义务相互依存、促进，既是享有者又是承担者，某些权利同时也是义务 | ~5 |
| | 4.2 依法行使权利 | 行使权利不得损害国家社会集体利益、按法定程序行使、和解/调解/仲裁/诉讼维权 | ~5 |
| | 4.3 依法履行义务 | 法定义务强制性、法律要求做的必须做、法律禁止做的坚决不做、法律责任 | ~4 |
