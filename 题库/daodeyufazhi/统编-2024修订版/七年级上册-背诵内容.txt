# 七年级上册 道德与法治 背诵内容测试题
# 教材：人教统编版 2024 修订版（4 单元 10 课）
# 格式：问题###答案（# 开头为注释）

# ===== 第一单元 成长的节拍 =====

# 第1课 中学时代
中学时代的意义是什么？###中学时代是人生发展的一个新阶段，为我们的一生奠定重要基础
少年梦想的特点是？###少年的梦想，是人类天真无邪、美丽可爱的愿望；与个人的人生目标紧密相连；与时代的脉搏紧密相连
如何实现梦想？###努力，是梦想与现实之间的桥梁；努力需要立志、坚持、方法

# 第2课 学习新天地
学习的含义是什么？###学习不仅局限在学校，我们所看、所听、所尝、所触、所做都可以是学习
学习的重要性是？###学习不仅让我们能够生存，而且让我们能够拥有更充实的生活；学习点亮我们心中的明灯，激发前进的动力
如何享受学习？###学会学习（发现并保持学习兴趣、掌握科学学习方法、善于运用不同学习方式）；体味学习的苦与乐

# 第3课 发现自己
认识自己的途径有哪些？###自我评价、他人评价
自我评价的方法？###自我观察和分析、与他人比较
如何做更好的自己？###①接纳与欣赏自己；②扬长避短；③主动改正缺点；④不断激发自己的潜能

# ===== 第二单元 友谊的天空 =====

# 第4课 友谊与成长同行
友谊的力量是？###朋友对一个人的影响很大，见证了我们一起走过的成长历程，丰富了我们的生活经验
友谊的特质是？###①友谊是一种亲密的关系；②友谊是平等的、双向的；③友谊是一种心灵的相遇
如何澄清友谊？###①友谊不是一成不变的；②竞争并不必然伤害友谊；③友谊不能没有原则

# 第5课 交友的智慧
如何建立友谊？###①建立友谊，需要开放自己；②建立友谊，需要持续的行动
如何呵护友谊？###①用心去关怀对方；②学会尊重对方；③学会正确处理冲突；④学会承受并正确对待交友中受到的伤害
网络交友的特点是？###虚拟、平等、自主
网上交友要注意什么？###①需要理性辨别、慎重选择；②要有一定的自我保护意识；③将网上的朋友转化为现实中的朋友需要慎重

# ===== 第三单元 师长情谊 =====

# 第6课 师生之间
教师职业的特点是？###教师是人类文明的主要传承者之一；教师承担教书育人的使命；教师是履行教育教学职责的专业人员
如何正确对待老师的表扬和批评？###①老师的表扬意味着肯定、鼓励和期待；②老师的批评意味着关心、提醒和劝诫；③要把注意力放在批评的内容和用意上，理解老师的良苦用心
师生交往的良好状态是？###学生乐于学习，老师寓教于乐，师生之间彼此尊重、相互关心、携手共进
如何建立教学相长的师生关系？###①彼此尊重是我们与老师建立良好关系的开始；②在平等相待、相互促进的师生交往中，我们可以和老师成为朋友

# 第7课 亲情之爱
家的意义是什么？###家是我们身心的寄居之所；家是我们心灵的港湾
家庭的含义？###家庭是由婚姻关系、血缘关系或收养关系结合成的亲属生活组织
如何化解亲子冲突？###①爱是需要呵护的，互动沟通的技巧和应对冲突的智慧是亲子之间爱的润滑剂；②我们要试着去接纳父母的做法，理解父母行为中蕴含的爱；③尝试让父母了解我们的变化和需要
如何建设和谐家庭？###①家庭成员之间相互理解、信任、体谅和包容；②进行有效交流和沟通；③以良好的心态面对家庭发展中的问题

# ===== 第四单元 生命的思考 =====

# 第8课 生命可贵
生命的特质是？###生命来之不易；生命是独特的；生命是不可逆的；生命是短暂的
为什么要敬畏生命？###生命是脆弱的、艰难的，也是坚强的、有力量的，也是崇高的、神圣的；生命价值高于一切
如何敬畏生命？###①珍惜自己的生命，也尊重、关注、关怀和善待身边的每一个人；②与周围的生命休戚与共

# 第9课 珍视生命
守护生命要关注什么？###①首先要关注自己的身体，养成健康的生活方式；②要关注并养护我们的精神
如何增强生命的韧性？###①发掘生命的力量，培养面对困难的勇气和坚强的意志；②学会与他人建立联系，向他人寻求帮助，获得他人的支持和鼓励

# 第10课 活出生命的精彩
如何理解生命的意义？###①生命的意义需要自己发现和创造；②能够活出自己的人生，实现自我价值；③在看到别人的需要时付出自己的爱心，承担起自己的责任
如何活出生命的精彩？###①拒绝贫乏，充盈生命；②拒绝冷漠，关切他人；③在平凡中创造伟大；④将个体生命和他人的、集体的、民族的、国家的甚至人类的命运联系在一起
