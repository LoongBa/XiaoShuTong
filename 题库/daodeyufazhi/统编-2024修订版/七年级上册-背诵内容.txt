# ===== 第一单元 少年有梦 =====

# 第1课 开启初中生活
初中阶段为我们的发展提供了哪些新的机会？###富有挑战的课程和学习任务，带领我们探索新的知识领域；丰富多彩的社团活动，给我们提供更多培养兴趣的平台；各种各样的社会实践，为我们打开认识社会的大门；在新的集体生活中，我们涵养品格，提升自我
进入初中后，家庭、学校、社会对我们提出了哪些新的要求？###期待我们越来越上进，志存高远，追梦远航；越来越踏实，努力学习，勤于思考；越来越包容，尊重他人，学会合作；越来越坚强，能坚持，有韧劲，取得更大进步
为什么说初中阶段对我们的人生具有独特的价值？###我们正处于生命成长的"拔节孕穗期"，初步形成世界观、人生观、价值观，需要精心引导和栽培
做好初中生活规划，应当怎样做？###先确定个人发展目标（在老师和家长帮助下，结合社会需要和兴趣、性格、能力等自身条件）；再制订行动方案（分解发展目标、明确实施细节、列出时间表，使方案切实可行）；持之以恒，将"努力"落实在每一天的具体行动中
"努力"有哪些方法？###分清主次，合理规划和管理时间；劳逸结合，学会科学用脑；"不积跬步，无以至千里"，每天进步一点点；"学而不思则罔，思而不学则殆"，学思并进；珍视团队合作

# 第2课 正确认识自我
为什么要正确认识自己？###人贵自知。正确认识自己，准确把握自己的禀赋和特性，有助于我们增强自信，促进自我发展，促进与他人的交往，正确处理个人与社会的关系，从而更好地认识和改造外部世界
认识自己有哪些途径？###①通过自我的全面分析来认识（从生理状况、心理特征、社会关系等方面）；②通过他人的评价来认识（客观冷静对待，既不盲从也不轻视）；③在生活实践中认识自己（不断证明自己、检视自己）
如何正确对待他人的评价？###他人的评价是我们认识自己的一面镜子，有助于形成对自己更为客观、完整、清晰的认识；要客观冷静地对待他人的评价，既不盲从也不轻视；做到用心聆听、注重沟通、勇于面对、理性应对
怎样做更好的自己？###①尊重和接受个体的差异，根据自身特点和社会需要发展自己；②学会欣赏自己（不是孤芳自赏、骄傲自大，而是欣赏自己的长处和优势）；③学会接纳自己（接纳自己的全部）；④不断完善自己（发挥优点长处，及时主动改正缺点）；⑤不断发掘自己的潜能
"做更好的自己"是在哪里实现的？###是在为他人、为社会服务中实现的；不仅是初中阶段的成长要求，而且是值得我们用一生去探寻的人生课题

# 第3课 梦想始于当下
梦想的含义和作用是什么？###梦想是对未来美好生活的愿望；梦想能不断激发我们对生命的热情和勇气，让生活更有色彩；有梦想，就会有希望；有了梦想，人类社会才能不断发展和进步
做有梦想的少年，应当怎样做？###①树立远大志向——"志不立，天下无可成之事"，志向是人生的航标，是奋斗的原动力，我们要早立志、立大志、立长志；②紧扣时代脉搏——共同享有人生出彩、梦想成真、同祖国和时代一起成长与进步的机会，努力成为担当民族复兴大任的时代新人
怎样理解学习？###初中阶段的学习内容非常丰富，既有知识的获取，又有能力的提升、品德的培养等；学习并不局限在学校，生活中的所看、所听、所尝、所触、所做都可以是学习；学习不仅表现为接受和掌握，而且表现为探究、发现、体验和感悟
梦想的实现需要我们怎样学习？###发现并保持对学习的兴趣，更加自觉、主动地学习；养成良好学习习惯，掌握科学学习方法，提高学习效率；积极参加社会实践活动，到社会大课堂去读好"无字之书"，获得更多启迪
学习对国家和民族有什么意义？###学习不仅关乎个人的前途和命运，更关乎民族的未来和发展；我们应学以致用、开拓进取、勇于创新，运用所学知识帮助他人、服务社会，为实现中华民族伟大复兴的中国梦贡献力量

# 第4课 幸福和睦的家庭
家庭的含义是什么？###家庭是由婚姻关系、血缘关系或收养关系结合成的亲属生活组织
怎样理解"家"？###家是生命的居所，是心灵的港湾；家不只是一所房子，家里有亲人，家中有亲情，家让我们的心灵有所依托；家是代代传承、血脉相连的生活共同体；家是我们的第一所学校，是我们的修身之所
家风有什么作用？###家风是一种无形的力量，会融入家庭成员的血脉中，潜移默化地影响家庭成员的价值观念、性格特征、道德修养和行为习惯；优良家风引导我们向上向善，促进家庭幸福和谐
建设美好家庭有哪些要求？###①用心体味亲情之爱；②相互关爱、彼此尊重（对父母长辈孝顺敬重，对兄弟姐妹相携相助，换位思考、主动化解矛盾）；③传承中华民族传统家庭美德（尊老爱幼、勤俭持家、知书达礼、遵纪守法等）；④家庭成员的共同责任（提高自我管理能力，增强家庭责任意识）
家庭与社会有什么关系？###家庭是社会的基本细胞；家庭和睦则社会安定，家庭幸福则社会祥和，家庭文明则社会文明

# 第5课 和谐的师生关系
教师是一个什么样的职业？###教师是一个神圣的职业，承担教书育人的使命；教师是履行教育教学职责的专业人员，是人类文明的传承者，承载着传播知识、传播思想、传播真理，塑造灵魂、塑造生命、塑造新人的重任
老师在我们的成长中发挥着怎样的作用？###老师在我们的成长过程中发挥着不可替代的作用；老师是我们锤炼品格的引路人，是我们学习知识的引路人，是我们创新思维的引路人，是我们奉献祖国的引路人
新时代好老师的标准是什么？###努力成为有理想信念、有道德情操、有扎实学识、有仁爱之心的好老师
师生交往理想而美好的状态是什么？###彼此尊重、教学相长、携手共进，是师生交往理想而美好的状态；老师是我们敬重的长辈，是我们的良师益友，我们应主动理解、关心老师
怎样正确对待老师的表扬和批评？###老师的表扬意味着肯定、鼓励和期待，对待表扬应戒骄戒躁、再接再厉，争取做得更好；老师的批评意味着关心、提醒和劝诫，帮助我们反省自己、完善自我，应把注意力放在老师批评的内容上，理解老师的良苦用心；还要尊重并适应不同风格的老师

# 第6课 友谊之树常青
友谊的真谛是什么？###①友谊是一种亲密的关系——获得朋友的理解和帮助、信任和忠诚、肯定和关心，获得精神上的支持和满足；②友谊是一种心灵的相遇——超越物质条件、家庭背景、学业成绩等，实现心灵的沟通与契合；③友谊是平等的、双向的——接受朋友的帮助，也主动帮助对方
为什么说"友谊是一种心灵的相遇"？###因为友谊的美好就在于它可以超越物质条件、家庭背景、学业成绩等，实现心灵的沟通与契合；志趣相投、志同道合的友谊，更能够经得住时间的考验和风雨的洗礼，让我们更深刻地体悟人生的美好
交友需要具备哪些智慧？###①志趣相投、互相鼓励、互相切磋、互相劝勉；②真诚和热情——敞开心扉，主动表达，热情待人；③慎重选择——与品德高尚的人交朋友，理性辨别，慎交友、结好伴；④关心和尊重对方——把握好界限和分寸，不替朋友做决定；⑤学会处理矛盾和冲突
交友为什么需要讲原则？###友谊需要信任和忠诚，但不等于不加分辨地为朋友做任何事；当朋友做错事，甚至误入歧途时，我们要坚持正确立场、不随波逐流，并积极予以规劝，帮助朋友及时改正错误
怎样处理朋友之间的矛盾和冲突？###发生矛盾和冲突时，我们可以一起协商，寻找彼此能够接受的解决方式；基本策略：保持冷静、坦诚交流、换位思考、及时处理、勇担责任

# 第7课 在集体中成长
怎样理解集体？###集体不是个体的简单相加，而是人们联合起来的有组织的整体；每个人都有过集体生活的需要，集体生活在某种程度上可以影响甚至改变一个人
集体生活对我们有什么作用？###①能带给我们温暖，让我们获得安全感和归属感；②有助于我们学会与人交往（学会接纳和尊重，学会理解和包容）；③有助于培养我们的责任感；④有助于我们发展个性——人与人之间的差异是我们发展个性的"明镜"；⑤集体是我们共同成长的园地
建设美好集体有哪些要求？###①确定共同的愿景（愿景是集体的精神动力之源，是推动集体发展的内驱力）；②树立主人翁意识（主动作为，各负其责，各尽其能）；③营造和谐有序的集体环境（自觉遵守共同规则，推己及人、宽容理解，弘扬正气、抵制并机智应对欺凌行为）；④树立正确的合作与竞争观念；⑤坚持集体主义原则
怎样对待合作与竞争？###集体发展既有赖于成员间的相互合作，也需要成员间的良性竞争；我们既要敢于竞争、勇于挑战，又要善于合作、共同进步
怎样理解集体主义原则？###当个人利益与集体利益发生冲突时，应把集体利益放在个人利益之上；同时，要充分重视和保障个人的正当利益，促进集体和个人不断发展

# ===== 第三单元 珍爱我们的生命 =====

# 第8课 生命可贵
人的生命有哪些特点？###每个人的生命都是独特的（每个生命都不可替代）；每个人的生命都是不可逆的（生命的时光一去不复返，要珍惜生命的每一天）；每个人的生命都是有限的（新陈代谢、生老病死是无法抗拒的规律）；人的生命是代代接续的（每个人的生命不仅是"我"的生命，还是"我们"的生命）
怎样正确对待有限的生命？###我们应感恩生命的获得，把有限的生命投入到无限的奋斗和奉献之中，让生命的每一段历程都变得精彩和有意义
为什么要敬畏生命？###当人的生命遭遇不可抗拒的自然灾害、人为的灾难、不可预知的意外时，我们会感受到生命的脆弱与艰难；当人们万众一心，为挽救生命而努力、为守护生命而拼搏、为悼念生命而默哀时，我们又会体悟到生命的坚强、崇高和神圣；我们对生命要有一种敬畏的情怀
怎样敬畏生命？###①敬畏生命，就要尊重并遵循生命存在和发展的规律（效法天地自然，遵循自然界的规律）；②就要关爱他人的生命（"仁者爱人""推己及人"，尊重、关怀和善待他人）；③就要坚持人民至上、生命至上（生命重于泰山，每个人的生命都比金钱、权势等身外之物更为重要）
敬畏生命给我们带来什么？###当我们对生命怀有敬畏之心时，我们会珍视它，在行动前思考后果，保持良好的判断力，避免鲁莽行事和不负责任的决策；也会用超凡的勇气面对挑战，以无畏的态度追求更高的生命价值

# 第9课 守护生命安全
生命安全的重要性是什么？###生命安全是维系人的生命存在的条件和保障，也是我们创造和享受一切美好的前提
怎样增强安全意识？###①树立规则意识——"禁令"看似是对我们的限制，其实是对我们自由和生命安全的保障，要自觉遵守规则；②牢固树立安全意识——对可能对自己或他人造成伤害的外在环境、人为侵害有所警觉和戒备；③增强风险意识——"居安思危，思则有备，有备无患"，远离危险，方能平安生活
怎样提高防护能力？###①提高危险预判能力——见微知著，对潜在的危险作出科学判断，防患于未然；②学习防护和急救的知识与技能；③提高避险和逃生能力——积极参加安全演练，危险来临时保持头脑冷静，就近、快速逃离到安全地带
为什么说安全与每个人息息相关？###我们所做的事情不仅影响到自己，也影响着他人；用心对待和做好事关安全的每一件事，既是对自己的生命安全负责，也是对家庭和社会负责
危险预判能力为什么重要？###自然灾害发生之前，往往有兆可循，危险大多可以预判；一些人为事故，经过得当考虑，本来可以避免；危险预判能力不是天生就有的，我们要在日常生活中主动学习安全知识，防患于未然

# 第10课 保持身心健康
身体健康有什么意义？###身体是生命存在的根本；身体健康既关系个人的成长和发展，也关系家庭的生活质量，还关系国家的人口素质和社会的发展；爱护自己的身体，是一种对生命负责任的态度，我们要做自身健康的第一责任人
怎样爱护身体？###①关注自己的身体状况——关注并记录自身健康状况，定期体检，如有不适及时科学就医；②养成健康的生活方式——自觉自律，饮食有节、起居有常、动静结合，杜绝不良嗜好；③积极、主动、科学地锻炼身体，强健体魄
为什么要滋养心灵？###良好的生命状态既需要健康的身体，也需要健康的心理和丰富的精神；拥有健康、和谐的内心世界，是我们幸福生活的重要支柱
怎样保持心理健康？###心理健康表现为个人具有生命的活力、积极的内心体验、良好的社会适应能力，并能有效地激发个人潜能；主动学习心理健康知识，掌握自我调节的方法，必要时积极寻求专业帮助；勤于磨炼意志，增强生命韧性
怎样丰富自己的精神世界？###学知识、长见识、练胆识，提升自己的底气与能力；在生活实践中扩展生活阅历，提升人生境界，让生命充满色彩与活力

# ===== 第四单元 追求美好人生 =====

# 第11课 确立人生目标
人生目标有什么作用？###人生目标体现着人在社会实践中对未来的向往和追求，决定着人生道路的发展方向；正确的人生目标会带来稳定而持久的内在激励，让我们排除干扰，克服困难，坚定前行，少走弯路，指引我们走上正确的人生道路
近期目标和长远目标有什么关系？###人生目标可以分为近期目标和长远目标；所有近期目标都应该围绕长远目标展开；只有分阶段实现一个个近期目标，才能实现长远目标
树立正确的人生目标，需要考虑哪些方面？###①正确认识个人与社会的关系——社会是由个人组成的，个人的发展离不开社会，在个人与社会的统一中明确人生目标；②应当从自身实际出发——综合评估兴趣爱好、性格特征、知识能力、家庭环境等，以客观务实的态度树立切实可行的人生目标；③应当与国家、民族和人民的利益相结合；④应当与人类的福祉相统一
为什么树立人生目标要和国家、民族、人民的利益相结合？###要把个人的发展牢牢植根于国家、民族和人民的需要，植根于中华民族伟大复兴的事业
为什么树立人生目标要与人类的福祉相统一？###志存高远，方能登高望远；胸怀天下，才可大展宏图；个人的追求与进步，只有与人类的发展进步紧密联系在一起，人生才能焕发无限的生机和活力

# 第12课 端正人生态度
什么是人生态度？###人生态度是人在生活实践中形成的看待生活、对待人生的心理和行为倾向；积极的人生态度，会令人看到事物好的一面，从而热爱生活，对未来充满信心；我们应当努力拥有积极的人生态度
积极的人生态度体现在哪些方面？###①体现为乐观向上——乐观豁达、积极向上，遇困难和挫折及时调整心态，不畏惧、不退缩，勇敢面对；②体现为认真务实——有严谨的态度、强烈的责任心和踏实的作风，做任何事情精益求精；③体现为勤奋进取——全力以赴、坚持不懈、努力前行，勤学上进、追求卓越
怎样对待顺境？###顺境不骄。顺境中的有利因素使我们更容易接近和实现目标；身处顺境时，应珍惜美好时光，抓住机遇，顺势而为；同时要有忧患意识，警惕优越条件滋生的骄傲、懈怠等不良心态，时刻保持谦虚谨慎的态度
怎样对待逆境？###逆境不馁。在逆境中前行，需要鼓足勇气，迎难而上；在青少年时期经历一些挫折和考验，有助于我们走好人生路
顺境和逆境是什么关系？###无论顺境还是逆境，对人生的作用都是双重的，关键是以何种态度对待人生的境遇；顺境和逆境在一定条件下可以相互转化；无论身处何种境地，只要我们正确对待成败得失，处优而不养尊，受挫而不短志，顺境和逆境都可以成为人生成长的阶梯

# 第13课 实现人生价值
什么是人生价值？###人生价值是指人的生命和活动对自己、他人和社会所具有的积极意义；人生价值是通过劳动创造的，人们通过劳动创造物质财富和精神财富
衡量人生价值的尺度是什么？###一个人对他人和社会的贡献是衡量其人生价值的尺度；一个人通过劳动为他人和社会作出的贡献越大，他的价值就越大；只要为社会进步作出了贡献，就是为社会创造了价值，也就创造和实现了人生价值
怎样理解劳动创造价值？###人生价值是通过劳动创造的；人们通过劳动创造物质财富和精神财富；人世间的一切美好生活都是通过劳动创造的；国家富强、民族复兴、人民幸福的美好愿景都要靠劳动来实现
怎样在奉献中成就精彩人生？###①把个人的小我融入时代，融入祖国和人民的大我之中；②立足岗位作奉献——任何一项工作都是社会存在和发展的需要，没有高低贵贱之分，在奉献社会中创造自身价值；③在奉献中走向伟大——将个人命运和他人、集体、民族、国家乃至人类的命运联系在一起；④在踏实奋进中绽放人生的光彩——青春是用来奋斗的，干一行、爱一行、精一行
青少年应怎样弘扬劳动精神？###崇尚劳动、尊重劳动，懂得劳动最光荣、劳动最崇高、劳动最伟大、劳动最美丽的道理，长大后能够辛勤劳动、诚实劳动、创造性劳动
