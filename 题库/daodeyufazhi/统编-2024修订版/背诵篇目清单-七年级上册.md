## 一、教材结构（4 单元 13 课）

### 第一单元 少年有梦（第1-3课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第1课 开启初中生活 | 1.1 奏响中学序曲 | 中学新身份、新机会、新要求、独特价值 | ~6 |
| | 1.2 规划初中生活 | 规划的意义、确定目标、制订方案、努力有方法 | ~6 |
| 第2课 正确认识自我 | 2.1 认识自己 | 认识自己的意义与途径（自我分析/他人评价/生活实践） | ~6 |
| | 2.2 做更好的自己 | 尊重差异、欣赏/接纳/完善自己、发掘潜能 | ~6 |
| 第3课 梦想始于当下 | 3.1 做有梦想的少年 | 梦想含义、远大志向、紧扣时代脉搏 | ~5 |
| | 3.2 学习成就梦想 | 学习意义、学习内容、努力学习善于学习 | ~6 |

### 第二单元 成长的时空（第4-7课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第4课 幸福和睦的家庭 | 4.1 家的意味 | 家庭含义、家是生命的居所/心灵港湾、家风传承 | ~6 |
| | 4.2 让家更美好 | 家庭与社会、建设美好家庭四要求 | ~6 |
| 第5课 和谐的师生关系 | 5.1 走近老师 | 教师职业、四个引路人、好老师标准 | ~5 |
| | 5.2 珍惜师生情谊 | 师生交往理想状态、对待表扬批评、适应不同风格 | ~5 |
| 第6课 友谊之树常青 | 6.1 友谊的真谛 | 亲密关系、心灵相遇、平等双向、见证成长 | ~5 |
| | 6.2 交友的智慧 | 真诚热情、慎重选择、关心尊重、处理冲突、讲原则 | ~6 |
| 第7课 在集体中成长 | 7.1 集体生活成就我 | 集体含义、温暖、学会交往、责任感、发展个性 | ~6 |
| | 7.2 共建美好集体 | 共同愿景、主人翁意识、规则环境、合作竞争、集体主义 | ~6 |

### 第三单元 珍爱我们的生命（第8-10课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第8课 生命可贵 | 8.1 认识生命 | 生命独特/不可逆/有限/接续、精神传承 | ~6 |
| | 8.2 敬畏生命 | 敬畏情怀、尊重规律、关爱他人、生命至上 | ~5 |
| 第9课 守护生命安全 | 9.1 增强安全意识 | 规则意识、安全意识、风险意识 | ~5 |
| | 9.2 提高防护能力 | 危险预判、防护急救、避险逃生 | ~4 |
| 第10课 保持身心健康 | 10.1 爱护身体 | 身体健康意义、关注状况、健康生活方式、科学锻炼 | ~5 |
| | 10.2 滋养心灵 | 心理健康、磨炼意志、丰富精神世界 | ~5 |

### 第四单元 追求美好人生（第11-13课）

| 课 | 框题 | 核心主题 | 记忆点 |
|----|------|---------|--------|
| 第11课 确立人生目标 | 11.1 探问人生目标 | 人生目标含义与作用、人是创造性活动 | ~4 |
| | 11.2 树立正确的人生目标 | 近期/长远目标、个人与社会、从实际出发、与国族人民利益结合、与人类福祉统一 | ~7 |
| 第12课 端正人生态度 | 12.1 拥有积极的人生态度 | 乐观向上、认真务实、勤奋进取 | ~5 |
| | 12.2 正确对待顺境和逆境 | 顺境不骄、逆境不馁、相互转化 | ~5 |
| 第13课 实现人生价值 | 13.1 在劳动中创造人生价值 | 人生价值含义、劳动创造价值、贡献是尺度 | ~5 |
| | 13.2 在奉献中成就精彩人生 | 小我融入大我、立足岗位、劳动精神 | ~5 |
