# ===== 第一单元 走进社会生活 =====

# 第1课 丰富的社会生活
社会生活的特点有哪些？###社会生活是丰富多彩的，物质产品和精神食粮种类繁多，人们从事着不同的职业，交往方式丰富多样；社会生活是不断变化发展的，生产工具的变革、科学技术的进步、思想观念的更新，使社会生活日新月异；社会生活具有公共性，社会生活是在公共空间展开的
怎样理解社会生活的公共性？###社会生活是在公共空间展开的；社会公共利益由大家共同享有，社会秩序由大家共同维护，社会发展由大家共同推动
为什么说人是社会的人？###如果把个人看成点，把人与人之间的关系看成线，各种关系相互交织，就形成一张"大网"，每个人都是社会这张"大网"上的一个"结点"；每人在社会中都有其相应的位置
社会关系依据建立的基础可分为哪些类型？###血缘关系（以血统或生理联系等为基础而形成，如家庭、家族成员之间的关系等）；地缘关系（以空间与地理位置为基础而形成，如同乡、邻居等）；业缘关系（以人们广泛的社会分工为基础而形成，如同行、同事等）
个人与社会的关系是怎样的？###社会为人的生存和发展提供必要条件，我们的衣食住用行、学习和娱乐等方方面面都与社会发生着千丝万缕的联系，每个人都从社会中获得物质支持和精神滋养；社会的发展离不开每个人的努力，任何一个社会的存在和发展，都是人们共同努力的结果

# 第2课 在社会中健康成长
什么是社会化？###社会化是指一个人从最初的自然的生物个体转化为社会人的过程；我们的成长是不断社会化的过程，在社会生活中学习知识、提升能力、锤炼品格，逐步成长为一名合格的社会成员；家庭、学校、同伴、大众传媒等在社会化过程中都发挥重要作用，社会化伴随我们一生
在社会化过程中，我们要学习哪些内容？###学习生活技能（逐渐学会吃饭、说话、走路、穿衣等基本生活技能，学习各种科学文化知识和劳动技能）；学习行为规范（了解风俗习惯，理解伦理道德，遵守法律规范，学会明辨善恶是非，懂得礼义廉耻，形成正确的价值观）；学习扮演社会角色（在参与社会生活中与他人有效沟通和良性互动，胜任多种社会角色）
什么是亲社会行为？它有什么意义？###亲社会行为是人在社会化过程中形成的，是符合社会道德要求、有益于他人和社会的行为；谦让、分享、合作、帮助他人、关心社会发展等都是亲社会行为；亲社会行为有利于我们养成良好的行为习惯，形成正确的价值观，获得他人和社会的接纳与认可，为他人带来温暖，使人际关系更加融洽，为社会增添正能量
怎样养成亲社会行为？###亲社会行为在人际交往和社会实践中养成；要主动了解社会，关注社会变化发展；了解风俗习惯，遵守社会公德，积极融入社会生活；热心帮助他人，积极投身于社会实践，以聪明才智贡献国家，以开拓进取服务社会

# 第3课 共建网络美好家园
网络给我们的生活和社会带来哪些改变？###网络深刻改变着我们的生活方式，使生活变得更加丰富、便利和美好；促进人际交往，打破传统人际交往的时空限制，世界变成"地球村"；推动生产方式的深刻变革，不断催生新产业、新业态、新模式；改进社会治理方式，提高社会治理水平，促进民主政治的进步
网络怎样改进社会治理方式？###网络推动信息互联互通，完善线上线下一体的智能化、精细化公共服务，提高社会治理水平；畅通人们参与社会治理的渠道，保障人们的知情权、参与权、表达权和监督权，促进民主政治的进步
什么是媒介素养？怎样学会选择网络信息？###媒介素养一般是指人们正确地、建设性地使用媒介资源的能力，包括面对各种信息时的选择、理解、质疑、评估等能力；要学会选择网络信息，注意浏览、寻找对学习和生活有意义的信息，学会"信息节食"，不能只关注自己感兴趣的信息，把自己禁锢在"信息茧房"中
为什么说网络无限、自由有界？###网络不是法外之地，每个人都应该对自己的网络言论负责；我们要自觉抵制不良信息，文明互动、理性表达，不制造和传播谣言，不泄露他人隐私，不恶意攻击他人，拒绝网络暴力和欺凌；只有自觉遵守道德和法律，才能做一名负责任的网络参与者
怎样传播网络正能量、做网络文明使者？###努力提高媒介素养，科学、文明、安全、合理使用网络，高扬主旋律，培育积极健康的网络文化，营造清朗的网络空间，建设网上精神家园；践行社会主义核心价值观，通过网络平台积极参与公共事务，投身于公益行动，做网络强国的建设者、创新者

# ===== 第二单元 维护社会秩序 =====

# 第4课 遵守社会规则
什么是社会秩序？###社会秩序是社会生活有条不紊、井然有序的状态；与人们日常生活关系密切的社会秩序，包括交通秩序、生产秩序、公共场所秩序等
为什么说社会生活需要秩序？###社会正常运行需要每个社会成员各司其职、密切合作，有序利用社会资源，积极承担社会责任；只有这样，我们才能拥有安全、有序、和谐的社会环境
什么是社会规则？社会规则有哪些类型？###社会规则是人们为了维护良好的社会环境，在逐渐达成默契与共识的基础上形成的；社会规则有很多，如道德、纪律、法律等，其中道德和法律是两种主要社会规则
社会规则具有什么作用？###社会规则具有规范社会行为、调节社会关系、维护社会秩序的作用；社会规则保障社会秩序的实现，明确告诉我们应该怎样处理与他人、社会的关系，如何行使权利、承担责任；不遵守社会规则，就会受到道德的谴责，甚至受到纪律的处罚、法律的制裁
怎样做到遵守社会规则？###遵守规则，需要增强规则意识，对规则心怀敬畏，知方圆、守规矩；需要他律与自律相结合，自律就是严于律己，通过自省和慎独，不断发现并及时纠正自己的不良行为；需要坚定地维护规则，将规则内化于心、外化于行，用恰当的方法提醒、劝导、帮助他人遵守规则；还需要积极完善规则，关心和参与规则的改进、完善

# 第5课 社会生活讲道德
文明有礼有什么意义？###文明有礼是调整和规范人际关系的行为准则，直接体现一个人的基本素质，也事关社会风尚、国家形象；文明有礼是一个人立身处世的前提，有利于提升自己的内在修养，树立真诚待人的良好形象，赢得他人的尊重与认可；文明有礼促进社会和谐发展，有利于形成安定有序、文明祥和的社会氛围；文明有礼塑造良好国家形象，是国际交往的"通行证"
怎样做文明有礼的人？###在社会生活中，要增强文明有礼意识，讲文明、懂礼貌、守礼仪；做文明有礼的人，要言谈文明、举止端庄，说话和气，着装得体，注重仪表；要不断学习、观察、思考和践行，从小事做起，从细节做起，做一个学礼、明礼、守礼的人
什么是诚信？诚信有什么意义？###诚实守信，就是言行一致、表里如一、信守承诺；诚信是中华民族的传统美德，是社会各行各业的共同道德要求，也是社会主义核心价值观和公民基本道德规范的重要内容；人以诚信立身，诚信是做人做事的基本准则，是一个人赢得信任、拥有更多发展机会和更大发展平台的保证；诚信促进社会文明，增进社会互信，减少社会矛盾，净化社会风气；诚信是企业的无形资产，坚持诚信经营才能塑造良好的形象和信誉
怎样践行诚信？###真诚待人，积极履行承诺，不要轻易许诺自己不可能做到的事情，作出承诺后要对自己的承诺负责；讲究策略，注重方式方法，遵循道德原则和法律要求，权衡利弊，做一个有智慧的诚实守信者；遵纪守法，珍惜诚信记录，身体力行弘扬诚信文化，以诚实守信为荣、以见利忘义为耻
什么是友善？怎样做到友善待人？###友善，就是待人热情友好，与人为善，友善是社会主义核心价值观的要求，是中华民族的传统美德；友善待人要宽容他人（学会体谅和包容他人，求同存异、和而不同，但在涉及道德底线与法律等原则问题上应不让步、不迁就）；要换位思考（"己所不欲，勿施于人"，将心比心，设身处地为他人着想）；要助人为乐（用爱心温暖需要帮助的人，尽己所能搭把手、出份力，在道义上、物质上、精神上予以帮助和关怀）

# 第6课 提升法治素养
法律是一种什么样的规则？###法律是一种社会规则和行为规范，是评价人们的行为是否合法有效的准绳；我们必须在法律范围内活动，以法律为行为准则，依照法律行使权利、履行义务
什么是法治观念？###法治观念体现为人们对法律发自内心的认可、崇尚、遵守和服从；法律的权威源自人民的内心拥护和真诚信仰；只有当法律真正铭刻在内心时，尊法学法守法用法才会成为人们的共同追求和自觉行为
怎样树立法治观念？###敬畏和信仰法律，坚持宪法法律至上，牢固树立法律红线不能触碰、法律底线不可逾越的观念，把依法办事当成自己的生活习惯；积极主动地学习法律，学习个人成长和参与社会生活必备的基本法律常识，积极参与各种法治实践活动；树立守法光荣、违法可耻的观念，自觉践行社会主义核心价值观，自觉履行法定义务、社会责任、家庭责任
建设法治社会，需要全体社会成员做到什么？###需要全体社会成员自觉守法、遇事找法、解决问题靠法，养成依法办事的习惯；自觉守法，就是要遵守宪法和法律这一公民的基本义务，在行动上以法律为准绳，自觉遵守法律的各项规定
怎样做到遇事找法、解决问题靠法？###遇事找法：在遇到法律问题或者合法权益受到侵害时，主动咨询相关专业人士，充分利用能够提供法律服务的组织和机构，如人民调解委员会、律师事务所、公证处、法律援助中心等；解决问题靠法：当权益受到非法侵害时，学会以合法的方式表达诉求，通过法律途径、运用法律武器加以解决，可以寻求国家的法律救济，依法到公安机关、人民检察院或者人民法院控告、举报，必要时可以直接向人民法院提起诉讼

# ===== 第三单元 勇担社会责任 =====

# 第7课 追求自由平等
什么是自由？###自由是人类的永恒追求，是社会活力之源，是社会主义核心价值观的重要内容；自由意味着在遵守道德、纪律、法律等社会规则的前提下，人们能够依照自己的意志活动，具有充分的自主性，拥有广阔的发展空间
自由有什么重要意义？###自由促进人们的全面发展，使人们免于恐吓、羞辱和歧视，过有尊严的生活，享有人生出彩、梦想成真的机会；自由推动社会的繁荣进步，激发全体社会成员的积极性、主动性和创造性，使整个社会充满创新的力量
怎样珍视自由？###珍惜宪法和法律赋予的权利，当权利受到侵犯时敢于捍卫自己的合法权利；依法行使权利，自由不是随心所欲，它是有限制的、相对的，要在遵守道德、纪律、法律等社会规则的前提下行使权利；尊重他人的权利，尊重他人的自由选择权和人格尊严，不能把自己的观点和意志强加于人，更不能侮辱、诽谤他人
什么是平等？###平等是人类的崇高理想，是社会主义核心价值观的重要内容；平等意味着同等情况同等对待，比如男女同工同酬、一次选举一人一票等；平等表现为人格平等（在人格上是一律平等的，没有高低贵贱之分）和权利义务平等（平等地享有权利，平等地履行义务）
怎样践行平等？###平等对待他人，尊重他人人格，不欺生、不凌弱；敢于抵制不平等的行为，面对不平等现象不能听之任之，应据理力争，用合法的方式捍卫平等；坚决反对特权，任何人都必须在宪法和法律范围内活动，不得有超越宪法和法律的特权

# 第8课 维护公平正义
什么是公平？公平有什么价值？###公平通常指人们基于一定标准或原则，处理事情合情合理、不偏不倚；公平意味着每个人都拥有同等的发展机会和条件，都要按照规则办事；公平是个人生存和发展的重要保障，是社会稳定和进步的重要基础
怎样维护社会公平？###维护社会公平，需要每个人努力追求公平、捍卫公平，面对利益冲突站在公平的立场，敢于对不公平说"不"，采用合理合法的方式谋求最大限度的公平；需要充分发挥规则的保障作用，全体社会成员都遵守规则、按规则行事，社会公平才有可靠的保障
什么是正义？正义有什么价值？###正义是社会文明的尺度，表达了人们对美好社会的期待和追求；正义是人类良知的"声音"，体现了弘扬真善美、摒弃假恶丑的价值导向；正义行为有利于促进社会进步、维护公共利益；正义保障人们有尊严地生活，营造风清气正的社会风尚
怎样守护正义？###守护正义需要勇气和智慧，面对非正义行为，一方面要敢于斗争，另一方面要讲究策略，善于做到见义智为；守护正义需要维护司法公正，法律是维护和实现正义的基本途径，公正司法是捍卫正义的最后一道防线；守护正义需要维护国际正义，坚持国家不分大小、强弱、贫富一律平等，反对干涉别国内政，反对搞双重标准
做得公平正义，青少年应该怎样做？（追求公平正义）###每个人都要自觉识事理、辨是非、知善恶，以实际行动推动正义的实现；有正义感、为人正直是做人的基本要求，期盼正义、捍卫正义是我们的共同心声；公平的实现是一个不断推进的过程，我们要积极行动起来，通过不懈努力追求和捍卫公平

# 第9课 积极奉献社会
什么是责任？做负责任的人要怎样做？###责任是一个人分内应该做的事情；积极履行对他人的承诺、认真完成社会实践任务、遵守道德和法律等都是承担社会责任的表现；做负责任的人，既要对自己和他人负责，更要对社会和国家负责，从而构建起人人有责、人人尽责的美好社会
对自己负责有什么意义？###对自己负责，有助于充分挖掘和发挥自己的潜能，更好地承担起对他人、社会和国家的责任；我们要对自己的身心健康和学习成长负责，保持健康的生活方式，合理规划时间，认真完成作业，等等
对他人、对国家和社会负责的要求是什么？###对他人负责：要平等、真诚对待他人，公正处事，心怀感恩、善待他人，主动关心、帮助和服务他人，尽己所能为他人排忧解难；对国家和社会负责：要有强烈的主人翁意识和社会责任感，关心国家大事，将个人成长进步与国家社会发展紧密结合起来，以实际行动报效祖国、服务人民、奉献社会
承担责任有什么意义？###承担责任意味着我们要付出时间、精力和金钱，甚至可能会被误解和责备；但在这个过程中，我们也会增长才干，赢得他人的尊重和赞许；我们要甘于奉献，勇于承担应尽的责任，不抱怨、不懈怠，不计个人得失，全身心地投入
怎样奉献社会？###奉献社会能够使我们的视野不断拓展，知识不断丰富，能力不断提高，道德境界不断提升，推动国家发展、社会进步；奉献社会要自觉加强学习，不断增强本领，以真才实学服务社会；追求进步，主动向团组织靠拢；积极参与志愿服务活动，弘扬"奉献、友爱、互助、进步"的志愿精神；勇于担当时代责任，立志成才、勤奋学习，努力做一个有责任担当的时代新人

# ===== 第四单元 维护国家利益 =====

# 第10课 国家利益至上
什么是国家利益？###国家利益是一个主权国家在国际社会中生存需求和发展需求的总和，涉及政治、经济、文化、社会、军事等领域，关系民族生存、国家兴亡
我国的核心利益包括哪些？###国家主权、国家安全、领土完整、国家统一、宪法确立的国家政治制度和社会大局稳定、经济社会可持续发展的基本保障；确保国家主权和领土完整是一条不可逾越的红线

# 第12课 树立总体国家安全观
什么是国家安全？###国家安全是国家政权、主权、统一和领土完整、人民福祉、经济社会可持续发展和国家其他重大利益相对处于没有危险和不受内外威胁的状态，以及保障持续安全状态的能力
国家安全有什么重要性？###国家安全是国家生存与发展的重要保障，是民族复兴的根基；国家安全是人民幸福安康的前提，维护国家安全是全国各族人民根本利益所在；国泰才能民安，维护国家安全的根本目的，是实现人民安全
为什么说总体国家安全观关键在"总体"？###总体国家安全观突出的是"大安全"理念，涵盖政治、军事、国土、经济、文化、社会、科技、网络、生态、资源、核、海外利益、太空、深海、极地、生物等诸多领域；进入新时代，国家安全的内涵和外延比历史上任何时候都要丰富，时空领域比任何时候都要宽广，内外因素比任何时候都要复杂
贯彻总体国家安全观，我们要坚持哪些"五个以"？###坚持以人民安全为宗旨、以政治安全为根本、以经济安全为基础、以军事科技文化社会安全为保障、以促进国际安全为依托，统筹外部安全和内部安全、国土安全和国民安全、传统安全和非传统安全、自身安全和共同安全，统筹维护和塑造国家安全；总体国家安全观的核心要义，集中体现为"十个坚持"
