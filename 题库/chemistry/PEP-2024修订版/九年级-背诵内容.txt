## 第一单元 走进化学世界
# K2 基本概念
物理变化和化学变化的根本区别###有无新物质生成
化学变化的基本特征###有新物质生成，常伴随发光、放热、变色、产生气体或沉淀
化学性质和物理性质的区别###是否需要通过化学变化表现出来
# K4 实验现象
蜡烛燃烧的现象###发出黄色火焰，放热，生成二氧化碳和水
点燃蜡烛后，在火焰上方罩一个冷而干燥的烧杯，现象###烧杯内壁出现水雾
向澄清石灰水中吹气，现象###澄清石灰水变浑浊
# K5 实验操作
取用固体粉末药品的操作###一斜二送三直立（试管倾斜，药匙送入底部，直立）
量筒的使用注意事项###量筒不能加热、不能作反应容器、读数时视线与凹液面最低处保持水平

## 第二单元 我们周围的空气
# K1 化学用语
氮气的化学式###N₂
氧气的化学式###O₂
# K2 基本概念
空气的主要成分###氮气（N₂）约占78%，氧气（O₂）约占21%
纯净物和混合物的区别###由一种物质组成的是纯净物，由多种物质组成的是混合物
# K3 物质性质
氧气的物理性质###无色无味气体，密度比空气略大，不易溶于水
氧气的化学性质###支持燃烧（助燃性）、供给呼吸
# K4 实验现象
硫在空气中燃烧的现象###发出淡蓝色火焰，生成有刺激性气味的气体
硫在氧气中燃烧的现象###发出明亮的蓝紫色火焰，生成有刺激性气味的气体
铁丝在氧气中燃烧的现象###剧烈燃烧，火星四射，生成黑色固体（四氧化三铁）
# K5 制取氧气
实验室制取氧气的方法###加热高锰酸钾、加热氯酸钾和二氧化锰混合物、分解过氧化氢溶液
二氧化锰在制取氧气中的作用###催化作用（加快反应速率，本身质量和化学性质不变）

## 第三单元 物质构成的奥秘
# K1 化学用语
元素符号的书写规则###第一个字母大写，第二个字母小写（如Ca、Fe）
原子序数的含义###原子序数 = 质子数 = 核外电子数
# K2 基本概念
分子和原子的区别###在化学变化中，分子可分，原子不可分
元素的概念###元素是质子数（核电荷数）相同的一类原子的总称
# K3 物质构成
物质由什么构成###物质由分子、原子或离子构成
原子的结构###原子由原子核（质子+中子）和核外电子构成

## 第四单元 自然界的水
# K1 化学用语
水的化学式###H₂O
# K2 基本概念
电解水实验的结论###水由氢元素和氧元素组成
# K3 物质性质
水的物理性质###无色无味液体，4℃时密度最大（1g/cm³）
# K4 实验现象
电解水实验现象###正极产生氧气，负极产生氢气，体积比约为1:2
# K5 规律口诀
化合价口诀###一价氢氯钾钠银；二价氧钙钡镁锌；三铝四硅五氮磷；二三铁、二四碳，二四六硫都齐全

## 第五单元 化学方程式
# K1 化学用语
质量守恒定律###参加化学反应的各物质的质量总和等于反应后生成的各物质的质量总和
化学方程式的书写步骤###写、配、注、等（写化学式→配平→注明条件和状态→等号）
# K2 基本概念
质量守恒的原因###化学反应前后原子种类、数目、质量均不变
# K4 实验现象
验证质量守恒定律的实验###白磷燃烧前后天平平衡（密闭容器中）
# K5 计算
化学方程式计算步骤###设→找→列→解→答

## 第六单元 碳和碳的氧化物
# K1 化学用语
二氧化碳的化学式###CO₂
一氧化碳的化学式###CO
# K3 物质性质
二氧化碳的性质###无色无味气体，密度比空气大，不燃烧不支持燃烧，能溶于水
一氧化碳的性质###无色无味气体，密度比空气略小，有毒，可燃，具有还原性
# K4 实验现象
二氧化碳通入澄清石灰水的现象###澄清石灰水变浑浊（生成碳酸钙沉淀）
检验二氧化碳的方法###通入澄清石灰水，若变浑浊则为二氧化碳
# K5 实验操作
实验室制取二氧化碳的药品###大理石（或石灰石）和稀盐酸
不用稀硫酸制取二氧化碳的原因###生成微溶的硫酸钙覆盖在大理石表面，阻止反应继续进行

## 第七单元 燃料及其利用
# K2 基本概念
燃烧的条件###可燃物、与氧气接触、温度达到着火点（三者缺一不可）
灭火的原理###清除可燃物、隔绝氧气、降低温度到着火点以下
# K3 物质性质
三大化石燃料###煤、石油、天然气（均为不可再生能源）
# K5 口诀
燃烧条件口诀###可燃物、氧气、着火点，三者缺一不可
