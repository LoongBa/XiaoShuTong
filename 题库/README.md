# 题库目录

> 小书童官方基础题库 —— 人教社（统编/部编）语文教材背诵测试题，覆盖**小学 1-6 年级**与**初中 7-9 年级**。
> 版本基准：2026-2027 学年现行教材（小学 2024 修订版全学段启用；七年级 2024 修订版 / 八年级 2024 修订版 / 九年级上 2026 新版、九下旧版）。
> 建设规范：见 `题库建设规范.md`（L0 篇目清单 → L3 背景钩子全链路标准）。

---

## 文件格式（V3 需求：`问题###答案`）

- 每行一条题目：`问题###答案`
- 以 `#` 开头的行为注释/元信息（导入时跳过）
- 文件编码：UTF-8
- 单文件 ≤10M（当前远低于上限）

示例：

```
# 注释：七年级上册-课内古诗
《观沧海》中描写大海吞吐日月的句子是？###日月之行，若出其中；星汉灿烂，若出其里。
# 注释：一年级上册-课内古诗
《静夜思》中"床前明月光"的后一句是？###疑是地上霜
```
