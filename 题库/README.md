# 题库目录

> 小书童官方题库——覆盖**语文**（小学 1-6 + 初中 7-9）、**英语**（小学 3-6 + 初中 7-9）、**历史**（初中 7-9）、**地理**（初中 7-8）、**生物**（初中）、**化学**（九年级）、**道德与法治**（初中 7-9）等多学科，按人教社（统编/PEP）教材版本组织。
> 版本基准：2026-2027 学年现行教材。
> 建设规范：见 `题库建设规范.md`（V1.1 多学科扩展版）。
