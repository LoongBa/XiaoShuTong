# 题库建设规范

> 小书童题库内容生产的统一规范。本规范从现有 7-9 年级语文古诗文题库（原始题库 / 背诵训练 / 背景钩子 / 判题 Prompt / Schema）实践中提炼，适用于**小学 1-6 年级 / 初中 7-9 年级 / 高中**各学段语文背诵内容，以及已落地的英语、历史、地理、生物、道德与法治等学科（见 `多学科题库建设方案-横向对比.md`）。
> 版本：V1.1（2026-09-04）
> 状态：活跃

---

## 一、规范总览

题库建设遵循 **「四件套」完整交付** 原则：一份篇目清单 + 一份原始题库 + 一套背诵训练 + 一套背景钩子，外加判题 Prompt 与 Schema 作为平台层底座。

| 层 | 产物 | 格式 | 用途 |
|----|------|------|------|
| L0 元信息 | 背诵篇目清单 | `.md`（Markdown 表格） | 全部背诵篇目的一览台账（篇名/作者/朝代/体裁/位置/背诵要求） |
| L1 原始题库 | `<年级><册>-背诵内容.txt` | `.txt`（`问题###答案`） | 按篇目组织的测试题，判定"会不会" |
| L2 背诵训练 | `<年级><册>-背诵训练.txt` | `.txt`（题型标记 + `###`） | 分阶检索训练题（S1-S4），驱动记忆升级 |
| L3 背景钩子 | `<年级><册>-背景钩子.md` | `.md`（结构化卡片） | 背诵时展示的记忆增强器（作者/背景/钩子/关联） |
| 平台底座 | `schema/bank.v1.json`、`schema/question.v1.json` | `.json`（JSON Schema） | 题库与题目统一数据结构 |
| 判题资产 | `判题Prompt/*.md` | `.md`（Prompt 契约） | AI 导师判题 / 提示生成的大模型资产 |

## 二、目录结构规范（V1.1 多学科版）

```
题库/
├── README.md                    # 题库总说明（版本基准、版本映射表、目录结构、待办）
├── 题库建设规范.md               # 本文档
├── schema/                      # 版本化正式 Schema + 注册表 + 判题引擎
│   ├── bank.v1.json             # 题库元数据 Schema
│   ├── question.v1.json         # 题目统一 Schema
│   ├── 题型注册表.json           # 题型注册（R1-R4 / O1-O5 / X 系列）
│   ├── 学科注册表.json           # 学科适配器（supportedTypes / gradingPreference / promptOverrides）
│   ├── rule_grader.py           # O 系列客观题规则判题引擎
│   ├── txt2json.py              # txt → JSON 迁移解析器
│   └── verify_*.py              # 学科适配器验证脚本
├── 背诵篇目清单-<学段>.md         # 篇目元信息清单（如：7-9年级 / 小学1-6年级）
├── <学科>/                      # 学科顶层目录（chinese / english / history / geography / biology / chemistry ...）
│   ├── 背诵篇目清单-<范围>.md     # 学科级篇目清单（可选，如 history/统编-2024修订版/背诵篇目清单-八年级.md）
│   └── <教材版本>/               # 教材版本目录层（见 §二.2 版本命名）
│       ├── <册>-背诵内容.txt      # 原始题库（问题###答案）
│       ├── <bank_id>.json        # 统一 JSON 题库（txt 迁移产物）
│       └── <bank_id>-cards.json  # 知识卡片 JSON（可选）
├── 背诵训练/                     # 分阶检索训练题库
│   ├── 训练法说明.md             # 训练法说明（四阶状态机映射）
│   ├── <学科>/<教材版本>/        # 多学科训练（V1.1 起，如 geography/统编-2024修订版/）
│   └── <年级>/                  # 语文遗留 txt 目录（过渡期保留，见 §八 迁移规则）
├── 背景钩子/                     # 记忆增强器
│   ├── 检查项清单.md             # 背景钩子核对法
│   ├── <学科>/<教材版本>/        # 多学科钩子/卡片（V1.1 起，如 biology/统编-2024修订版/）
│   └── <年级><册>-背景钩子.md     # 语文遗留 md（过渡期保留）
├── 判题Prompt/                  # AI 判题 Prompt 资产库
│   ├── README.md                # Prompt 库索引 + 跨学科绑定矩阵（§七.2 引用）
│   ├── 通用判题-Prompt.md        # 兜底基线
│   ├── 题型-R1-补全记忆.md       # 语文 R1（上句接下句/名句填空）
│   ├── 题型-R2-逆向补全.md       # 语文 R2（下句接上句）
│   ├── 题型-R3a-段落默写.md      # 语文 R3a（段落默写）
│   ├── 题型-R3b-整篇默写.md      # 语文 R3b（整篇默写）
│   ├── 学科-english-R1R2-翻译判题.md   # 英语 R1/R2 翻译判题
│   ├── 学科-english-R3aR3b-拼写判题.md # 英语 R3a/R3b 拼写判题
│   ├── 背景钩子-提示生成-Prompt.md
│   └── 趣味点评-Prompt.md
├── examples/                    # 跨学科客观题示例
│   └── 客观题示例.json           # O1-O5 跨 4 学科示例
```
> **学科建设方案归属**：各学科专项建设方案（语文/英语/历史/地理/生物/化学/道法 + 多学科横向对比）为项目文档，存放于 `docs/草稿/归档/`（定稿后升级正式文档），**不放入题库目录**。

> **学段差异**：初中（7-9）语文背诵内容以古诗文为主，文件命名为 `<册>-古诗文.txt`；小学（1-6）语文背诵内容含课文/古诗/文言文/日积月累多类，文件命名为 `<册>-背诵内容.txt`，内容分类见 §五。其他学科（历史/地理/生物/道法/英语）统一用 `<册>-背诵内容.txt` 命名。

### 2.2 教材版本命名规范（过渡期新老教材并存，必须区分）

**背景**：教材改版采用逐年推进，同一学段内可能出现"新老教材并存"的过渡期（如小学 2024 修订版 2024 秋起逐年启用、2026 秋全学段；九年级下 2027 春才换新版）。**题库命名必须区分教材版本，严禁混用。**

**目录命名规则**（教材版本目录层）：

```
<教材名>-<版本标识>-<教材系列>
示例：
  chinese/统编-2024修订版/          # 语文统编 2024 修订版
  chinese/统编-2016旧版/            # 语文统编 2016 旧版（过渡期保留）
  english/PEP-2024修订版/          # 英语人教 PEP 2024 修订版
  english/PEP-2012旧版/            # 英语人教 PEP 2012 旧版（过渡期保留）
  history/统编-2024修订版/          # 历史统编 2024 修订版
```

**版本标识推荐**（统一采用"年份 + 修订/新版/旧版"）：

| 版本标识 | 含义 | 示例 |
|---------|------|------|
| `2024修订版` | 2024 年修订（当前现行主版本） | 统编-2024修订版 |
| `2026新版` | 2026 年全新改版 | 统编-2026新版 |
| `XXXX旧版` | 改版前的旧版本（过渡期保留） | 统编-2016旧版 |

**bank_id 命名规则**（对齐 schema：`^[a-z]{2,}-[0-9a-z-]+$`，全小写拉丁字母 + 数字 + 连字符）：

```
{学科}-{学段缩写}-[{教材缩写}-]{版本标识}
```

| 段位 | 取值 | 说明 |
|------|------|------|
| 学科 | `chinese / english / history / geography / biology / chemistry / math / physics` | 对齐学科注册表 |
| 学段缩写 | `p1to6`（小学1-6）`p3to6`（小学3-6）`7to9`（初中7-9）`senior`（高中） | — |
| 教材缩写（可省略） | `pep`（人教）`tjb`（统编）等 | **单一教材主流的学科可省略**（历史/地理/生物/道法省略）；多教材并存学科（英语）必填 |
| 版本标识（必填） | `2024r`（2024 修订）`2026n`（2026 新版）`2012o`（2012 旧版）等 | 与版本目录层一一对应 |

示例（对齐 V1.1 实际落地）：

```
  chinese-7to9-2024r          # 语文 7-9 年级 2024 修订版（P1 遗留 bank_id 为 chinese-7to9-pep，见下方遗留说明）
  chinese-p1to6-2024r         # 语文小学 1-6 2024 修订版（P1 遗留为 chinese-p1to6-pep）
  english-p3to6-pep-2024r     # 英语小学 3-6 PEP 2024 修订版
  english-7to9-pep-2024r      # 英语初中 7-9 PEP 2024 修订版
  history-7to9-2024r          # 历史 7-9 2024 修订版（统编，省略教材缩写）
  geography-7to9-2024r        # 地理 7-9 2024 修订版
  biology-7to9-2024r          # 生物 7-9 2024 修订版
  daodeyufazhi-7to9-2024r     # 道法 7-9 2024 修订版
```

> **P1 遗留兼容**：语文统一 JSON（P1 迁移产物）bank_id 为 `chinese-7to9-pep` / `chinese-p1to6-pep`（V1.0 格式，缺版本标识），目录为 `chinese/七-九年级-统编教材/`、`chinese/小学1-6年级-统编教材/`。**暂不重命名**（避免 JSON 内部 id 链断裂），由 README 版本映射表兜底声明 2024 修订基准；下次大版本（教材改版）时按 V1.1 规则重建。

**版本映射表**：题库 README 必须维护一张"教材版本映射表"，逐年级逐册声明使用版本，例如：

| 年级/册 | 2026-2027 学年使用版本 |
|---------|----------------------|
| 三年级 | PEP-2024修订版 |
| 五年级 | PEP-2024修订版 |
| 六年级 | PEP-2012旧版（2027 秋换新版） |

**迁移规则**：
- 旧版题库**不删除**，保留在 `XXXX旧版/` 目录下，用 `superseded_by` 标记指向新版
- 学生端按"当前年级 → 版本映射表"路由到对应题库
- 新版题库建好后，README 更新版本映射表，标注各年级切换时间

## 三、L0 篇目清单规范

### 3.1 文件格式

`背诵篇目清单-<学段>.md`，含：

1. **文件头注释**：来源（调研渠道）、基准版本（教材版本学年）、用途
2. **分年级、分册、分类**的篇目表格
3. **表格列**：`篇目 | 作者/朝代 | 体裁`（古诗文类），或 `课文 | 位置 | 背诵要求`（课文类）
4. **版本提示**：教材修订变化单独列章节说明
5. **来源**：调研渠道清单

### 3.2 篇目分类体系（小学版）

| 分类 | 说明 | 典型示例 |
|------|------|---------|
| 课文背诵（全文/片段） | 现代文、儿歌、童谣、散文的背诵要求 | 《小小的船》《四季》《秋天》 |
| 课内古诗 | 课文单元内的古诗（含语文园地"日积月累"） | 《静夜思》《登鹳雀楼》 |
| 文言文/小古文 | 教材中的文言文篇目 | 《司马光》《精卫填海》《少年中国说（节选）》 |
| 日积月累 | 谚语、名言警句、歇后语、成语等 | "一年之计在于春"、关于学习的名言 |

### 3.3 篇目分类体系（初中版）

| 分类 | 说明 |
|------|------|
| 课内古诗 | 课文内古代诗歌（如"古代诗歌四首"） |
| 课内文言文 | 课文内文言文（含《论语》十二章等） |
| 课外古诗词诵读 | 单元后的课外诵读篇目 |

### 3.4 元数据要求

每篇目标注：**篇名 / 作者 / 朝代 / 体裁 / 所在册别与单元位置 / 背诵要求**（全文背诵 / 片段背诵）。小学课文类补充：**背诵范围**（全文或指定段落，如"背诵第2-3自然段"）。

## 四、L1 原始题库规范

### 4.1 文件格式（核心：`问题###答案`）

- 每行一条题目：`问题###答案`
- 以 `#` 开头的行为注释/元信息（导入时跳过）
- 文件编码：UTF-8
- 单文件 ≤10M（当前远低于上限）

### 4.2 文件头模板

```
# <年级><册> 语文背诵内容测试题
# 教材：人教社统编版 <版本>
# 格式：问题###答案（# 开头为注释）
```

### 4.3 题目类型（原始题库）

原始题库按篇目组织，每个篇目下覆盖 4 类题目：

| 题类 | 形式 | 示例 |
|------|------|------|
| 文学常识 | 作者及朝代 | 《静夜思》的作者及朝代是？###李白，唐 |
| 补全 | 上句接下句 / 关键词填空 | 《静夜思》中"床前明月光"的后一句是？###疑是地上霜 |
| 名句理解 | 找名句/主旨句 | 《登鹳雀楼》中蕴含哲理的名句是？###欲穷千里目，更上一层楼。 |
| 整篇默写 | 默写《篇名》###全文 | 默写《静夜思》###床前明月光，疑是地上霜。举头望明月，低头思故乡。 |

> 小学低年级（1-2 年级）题型以补全 + 整篇默写为主（句子短、无生僻字），文学常识可适度简化（如"《静夜思》的作者是？###李白"）。

### 4.4 答案规范

- 古诗文答案用教材通行版本（含标点），标点以规范中文标点为准
- 文言文答案保留原文句读
- 日积月累类答案逐条列出，多条用分号分隔

## 五、L2 背诵训练规范（分阶检索法）

### 5.1 四阶映射

> **题型命名桥接**：生产层（.txt）沿用 S1-S4 标记；`txt2json.py` 迁移到统一 JSON 后映射为注册表题型 **R1（S1）/ R2（S2）/ R3a（S3）/ R3b（S4）**（见 `schema/题型注册表.json`），判题 Prompt 也按 R 系列命名。

| 记忆状态 | 训练题型 | 说明 |
|---------|---------|------|
| ✕ 未掌握 | 整篇跟读（不测试） | 输入阶段：朗读、理解大意、建立完整印象 |
| △ 模糊 | **S1 上句接下句** | 正向检索：给上句，补下句（最容易） |
| ○ 掌握 | **S2 下句接上句** + **S3 段落默写** | 逆向检索（记忆强度 +1 档）；段落检验逻辑连贯 |
| ★ 熟练 | **S4 整篇默写** | 完整性检验，进入长期记忆 |

### 5.2 题型标记（文件内用注释标注）

- `# S1` 上句接下句：`上句###下句`
- `# S2` 下句接上句：`下句###上句`
- `# S3` 段落默写：`提示（出处+要求）###段落原文`
- `# S4` 整篇默写：`默写《篇名》###全文`

### 5.3 文件头模板

```
# <年级><册> 背诵训练题库（分阶检索法）
# 教材：人教社统编版 <版本>
# 题型：# S1 上句接下句 / # S2 下句接上句 / # S3 段落默写 / # S4 整篇默写
# 格式：题目###答案（# 开头为注释）
# 用法：✕→S1 跟读 | △→S1/S2 | ○→S2/S3 | ★→S4
```

### 5.4 生成规则

- 每篇目下按 `## 《篇名》作者/朝代` 分节
- 每篇目必须含：S1（≥2 条）+ S2（≥2 条）+ S4（1 条）；长文（>4 句）补 S3 段落默写
- S1/S2 以完整诗句为单位，不拆半句
- S4 答案与 L1 整篇默写答案一致
- 低年级课文：S1/S2 以句子为单位接龙；S3 以自然段为单位；S4 全文

## 六、L3 背景钩子规范

### 6.1 七维核对法

每个篇目的背景钩子按 7 个维度核对覆盖：

| 维度 | 检查内容 | 典型示例 |
|------|---------|---------|
| A 作者定位 | 朝代/字号/称号/文学地位/并称/流派 | 李白号"青莲居士"，与杜甫并称"李杜" |
| B 人物关系 | 赠答对象/唱和/交往/家族师承 | 李白写诗慰王昌龄贬谪；诸葛亮写给儿子诸葛瞻 |
| C 创作时空 | 时间/地点/境遇（被贬/赴任/出征/羁旅/隐居） | 曹操北征乌桓凯旋登碣石 |
| D 地理钩子 | 诗内地名 → 今地对照 | 龙标=湖南黔阳；北固山=江苏镇江 |
| E 用典成语 | 化用典故/衍生成语 | "左迁"=降职；"天塌下来"出自杞人忧天 |
| F 关联作品 | 教材内同作者/同主题篇目互链 | 《诫子书》↔《出师表》 |
| G 趣闻点评 | 历史评价/文坛轶事/记忆锚点 | "海日生残夜"被张说挂政事堂 |

### 6.2 文件格式

```markdown
# <年级><册> 语文背诵内容背景钩子（记忆增强器）

> 用途：背诵时展示的"记忆钩子"，用故事化背景帮助精细复述，强化记忆
> 展示时机：✕ 阶段学习新篇目时展示；△○★ 复习时默认隐藏，卡壳时由 AI 导师按需提示
> 设计原则：讲故事，不考核

---

# ===== <分类> =====

## 《篇名》作者/朝代
- **作者定位**：...
- **谁送谁/谁写给谁**：...
- **创作背景**：...
- **记忆钩子**：...
- **关联作品**：...
```

### 6.3 小学适配

- 低年级（1-2）：简化内容，聚焦"作者是谁 + 讲了什么故事 + 一个记忆点"，语言口语化
- 中年级（3-4）：增加"创作背景 + 关联作品"，控制篇幅
- 高年级（5-6）：接近初中标准，七维基本全覆盖

## 七、平台底座规范

### 7.1 Schema（`schema/bank.v1.json` + `question.v1.json`）

- 题库元数据遵循 `bank.v1.json`：`bank_id / subject / name / version / source / purpose_tags / default_prompt / type_overrides / privacy / owner`
- 题目遵循 `question.v1.json`：`id / bank_id / subject / topic / knowledge_points / type / purpose_tags / content / meta`
- 题目 ID 格式：`Q-{学科}-{库缩写}-{序号}`，如 `Q-ch-7a-0001`

### 7.2 判题 Prompt 库（`判题Prompt/`）

> V1.1 起题型命名由 S1-S4 升级为 R1/R2/R3a/R3b（见 `schema/题型注册表.json`），并新增学科级 Prompt。

| 文件 | 类型 | 适用 |
|------|------|------|
| `通用判题-Prompt.md` | 通用基线 | 所有问答型题目（兜底） |
| `题型-R1-补全记忆.md` | 题型专用 | 语文 R1：上句接下句/名句填空 |
| `题型-R2-逆向补全.md` | 题型专用 | 语文 R2：下句接上句（逆向） |
| `题型-R3a-段落默写.md` | 题型专用 | 语文 R3a：判段落完整性/顺序/关键词 |
| `题型-R3b-整篇默写.md` | 题型专用 | 语文 R3b：判整篇完整性 |
| `学科-english-R1R2-翻译判题.md` | 学科专用 | 英语 R1/R2：翻译判题，双重容错 |
| `学科-english-R3aR3b-拼写判题.md` | 学科专用 | 英语 R3a/R3b：拼写宽容判题 |
| `背景钩子-提示生成-Prompt.md` | 专用（提示生成器） | "请提示我"交互，从背景钩子库提取线索 |
| `趣味点评-Prompt.md` | 专用（PK 赛后点评） | PK 挑战：AI 评分 + 趣味点评 + 错题知识彩蛋 |
| `README.md` | 索引 | Prompt 库索引 + **跨学科绑定矩阵**（历史/地理/道法/生物/化学复用通用 + 规则判题） |

**绑定优先级**：单题级 > 题型级 > 题库级 > 全局默认

**O 系列（O1-O5）客观题**：统一走 `schema/rule_grader.py` 规则判题引擎（零 LLM 成本，跨学科复用），绑定见 `判题Prompt/README.md` §三 跨学科绑定矩阵。

**判题输出统一 JSON 契约**：

```json
  "confidence": 0.92,
  "matched_keywords": ["..."],
  "missing_keywords": ["..."],
  "hint": "提示：..."
}
```

## 八、版本管理规范

| 变更类型 | 版本动作 | 说明 |
|---------|---------|------|
| 新增题目（不改变教材基准） | 小版本 +1（如 V1.0 → V1.1） | 同目录文件内追加 |
| 教材改版（篇目变化） | 大版本 +1（如 V1.x → V2.0） | **新建版本目录层**（`统编-2026新版/`），旧版不删 |
| 篇目/答案修订 | 记录于 README 版本说明 | 不删除旧题，用 `superseded_by` 标记 |
| **过渡期新老教材并存** | 建独立版本目录 + 维护版本映射表 | 见 §二.2：`XXXX旧版/` 与 `XXXX修订版/` 并列，学生端按映射表路由 |

**版本基准**：每份题库 README 必须声明教材基准（如"2024 修订版""2026 秋新版"），篇目以人民教育出版社现行教材课后背诵要求为准。**过渡期必须给出逐年级/逐册的版本映射表**（哪些年级用新版、哪些仍用旧版、何时切换）。

- [ ] 七维核对法逐项标记 ✔/△/✘

- [ ] README 声明教材版本基准

- [ ] 原文答案正式使用前经人工逐篇复核

## 十、建设流程（SOP）

```
1. 调研篇目     → 生成《背诵篇目清单-<学段>.md》（多源交叉验证）
2. 建原始题库   → 生成 <年级><册>-背诵内容.txt（按篇目组织，4 类题目）
3. 建背诵训练   → 生成 <年级><册>-背诵训练.txt（S1-S4 分阶）
4. 建背景钩子   → 生成 <年级><册>-背景钩子.md（7 维核对法）
5. 格式校验     → 对照 §九 质量检查清单自查
6. 复核         → 原文对照教材逐篇复核（人工或 AI 交叉验证）
7. 入库         → 更新 README 目录结构与待办状态
```
