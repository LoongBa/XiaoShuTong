## 二、各子类核心记忆性知识点

### D1 人体营养
| 记忆点 | 标准表述 |
|--------|---------|
| 六大营养物质 | 糖类、脂肪、蛋白质、水、无机盐、维生素 |
| 糖类 | 主要供能物质 |
| 脂肪 | 备用能源物质 |
| 蛋白质 | 建造和修复身体的重要原料 |
| 小肠 | 消化和吸收的主要场所（长5-6米、环形皱襞、小肠绒毛） |
| 淀粉消化 | 口腔开始，最终分解为葡萄糖 |
| 蛋白质消化 | 胃开始，最终分解为氨基酸 |
| 脂肪消化 | 小肠开始，分解为甘油和脂肪酸 |

### D2 人体呼吸
| 记忆点 | 标准表述 |
|--------|---------|
| 呼吸道组成 | 鼻→咽→喉→气管→支气管 |
| 吸气过程 | 肋间肌、膈肌收缩→胸廓扩大→肺扩张→肺内气压降低→气体入肺 |
| 肺泡适于气体交换 | 数量多、壁薄（一层上皮细胞）、外包毛细血管 |
| 气体交换 | 氧气进入血液，二氧化碳进入肺泡 |

### D3 血液循环
| 记忆点 | 标准表述 |
|--------|---------|
| 血液组成 | 血浆 + 血细胞（红细胞/白细胞/血小板） |
| 红细胞 | 运输氧气（含血红蛋白） |
| 白细胞 | 吞噬病菌（防御） |
| 血小板 | 止血凝血 |
| 心脏四腔 | 左心房/左心室/右心房/右心室 |
| 体循环 | 左心室→主动脉→全身→上下腔静脉→右心房（动脉血→静脉血） |
| 肺循环 | 右心室→肺动脉→肺→肺静脉→左心房（静脉血→动脉血） |
| 动脉血 | 含氧丰富、颜色鲜红 |
| 静脉血 | 含氧少、颜色暗红 |

### D4 废物排出
| 记忆点 | 标准表述 |
|--------|---------|
| 泌尿系统 | 肾脏→输尿管→膀胱→尿道 |
| 肾单位 | 肾小球 + 肾小囊 + 肾小管 |
| 尿的形成 | 肾小球滤过（形成原尿）→肾小管重吸收（形成尿液） |
| 排泄途径 | 呼吸（CO₂和水）、皮肤（汗液）、泌尿系统（尿液） |
| 排泄vs排遗 | 排泄=代谢废物；排遗=食物残渣 |

### D5 神经调节
| 记忆点 | 标准表述 |
|--------|---------|
| 神经系统 | 脑（大脑/小脑/脑干）+ 脊髓 + 神经 |
| 反射弧 | 感受器→传入神经→神经中枢→传出神经→效应器 |
| 简单反射 | 生来就有（膝跳反射、缩手反射） |
| 复杂反射 | 后天学习（望梅止渴、谈虎色变） |
| 视觉形成 | 光线→角膜→瞳孔→晶状体→玻璃体→视网膜→视神经→视觉中枢 |

### D6 激素调节
| 记忆点 | 标准表述 |
|--------|---------|
| 垂体 | 生长激素（幼年不足→侏儒症；过多→巨人症） |
| 甲状腺 | 甲状腺激素（幼年不足→呆小症；过多→甲亢） |
| 胰岛 | 胰岛素（不足→糖尿病） |
| 内分泌腺vs外分泌腺 | 内分泌腺无导管、直接进入血液 |

### D7 运动系统
| 记忆点 | 标准表述 |
|--------|---------|
| 运动系统组成 | 骨 + 关节 + 骨骼肌 |
| 关节结构 | 关节面 + 关节囊 + 关节腔 |
| 屈肘 | 肱二头肌收缩、肱三头肌舒张 |
| 伸肘 | 肱二头肌舒张、肱三头肌收缩 |

### D8 免疫与健康
| 记忆点 | 标准表述 |
|--------|---------|
| 传染病三环节 | 传染源、传播途径、易感人群 |
| 预防三措施 | 控制传染源、切断传播途径、保护易感人群 |
| 特异性免疫 | 抗原→淋巴细胞→抗体 |
| 非特异性免疫 | 第一道防线（皮肤黏膜）、第二道防线（吞噬细胞/杀菌物质） |
| 计划免疫 | 接种疫苗 |

## 三、易混淆点（O4 连线素材）

动脉血vs静脉血（"肺反体同"）、动脉vs静脉（"房静室动"）、光合作用vs呼吸作用、排泄vs排遗（"排泄排废物，排遗排残渣"）、血浆vs血清、原尿vs尿液（"原尿有糖尿液无糖"）、显性vs隐性（"无中生有为隐性"）、简单反射vs复杂反射、完全变态vs不完全变态（"有蛹完全"）、有性生殖vs无性生殖、内分泌腺vs外分泌腺（"内无外有"）、近视vs远视（"近凹远凸"）
