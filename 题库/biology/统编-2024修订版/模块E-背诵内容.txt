# ===== 第一章 生物的生殖 =====

# 第1节 无性生殖
无性生殖的概念是？###不经过两性生殖细胞的结合，由母体直接产生新个体的生殖方式
无性生殖的特点？###后代只具有母体的遗传特性，能迅速繁殖后代
常见的无性生殖方式有？###分裂生殖（草履虫）、出芽生殖（水螅、酵母菌）、孢子生殖（真菌）、营养生殖（扦插、嫁接）
扦插的概念？###剪取植物的一段枝条，插入土壤中，在适宜条件下长成一个新个体
嫁接的概念？###把一个植物体的枝或芽（接穗）接到另一个植物体（砧木）上，使它们结合在一起长成一个完整植物体
嫁接成活的关键是？###使接穗与砧木的形成层紧密结合
组织培养的概念？###在人工配制的培养基上，利用植物细胞的全能性，培养出完整植物体（如草莓）
无性生殖在生产实践中的应用？###扦插（月季、柳树）、嫁接（果树）、组织培养（快速繁殖、培育无病毒植株）

# 第2节 有性生殖
有性生殖的概念是？###经过两性生殖细胞（精子和卵细胞）的结合，形成受精卵，由受精卵发育成新个体的生殖方式
有性生殖的意义？###后代具有双亲的遗传物质，变异性更强，有利于生物的进化
昆虫的发育类型有？###完全变态发育（卵→幼虫→蛹→成虫，如家蚕、蝴蝶、蚊、蝇）和不完全变态发育（卵→若虫→成虫，如蝗虫、蟋蟀、蝉）
完全变态与不完全变态的区别？###完全变态有蛹期，幼虫与成虫形态差异很大；不完全变态无蛹期，若虫与成虫形态相似
两栖动物的生殖发育特点？###体外受精、变态发育（如青蛙：卵→蝌蚪→幼蛙→成蛙）；生殖离不开水
鸟卵的结构及功能？###卵壳（保护）、气室（提供氧气）、卵白（提供水分和营养）、卵黄（提供主要营养）、胚盘（含有细胞核，是胚胎发育的部位）
鸡卵中将来发育成雏鸡的结构是？###胚盘
哺乳动物的生殖发育特点？###胎生、哺乳（提高后代成活率）

# ===== 第二章 生物的遗传与变异 =====

# 第3节 基因的显性和隐性
基因与性状的关系？###基因控制生物的性状（如豌豆的高茎/矮茎由基因决定）
显性基因和显性性状？###控制显性性状的基因是显性基因（用大写字母表示，如D）；显性基因控制的性状是显性性状
隐性基因和隐性性状？###控制隐性性状的基因是隐性基因（用小写字母表示，如d）；隐性基因只有在纯合状态下才表现出隐性性状
孟德尔的豌豆杂交实验结论？###①相对性状有显性和隐性之分；②在杂合体（Dd）中，隐性基因控制的性状不表现，但会遗传下去；③子二代中显隐性性状比例为3:1
纯合体和杂合体？###含相同基因的个体（DD或dd）是纯合体；含不同基因的个体（Dd）是杂合体
禁止近亲结婚的原因？###近亲携带相同隐性致病基因的概率大，后代患遗传病的几率增加

# 第4节 人的性别遗传
人的体细胞中有多少对染色体？###23对（22对常染色体+1对性染色体）
人的性染色体组成？###男性：XY；女性：XX
生男生女的决定因素？###由精子含有的性染色体决定：含X的精子与卵细胞结合→女孩（XX）；含Y的精子与卵细胞结合→男孩（XY）
生男生女的比例？###理论上1:1（各50%）
双胞胎的类型？###同卵双胞胎（同一受精卵分裂，性别相同、性状相似）和异卵双胞胎（两个受精卵发育，性别可不同）

# 第5节 生物的变异
变异的概念？###生物亲代与子代之间、子代个体之间在性状上的差异
可遗传变异？###由遗传物质改变引起的变异，能遗传给后代（如基因突变）
不可遗传变异？###由环境因素引起的变异，遗传物质没有改变，不能遗传给后代（如光照不足使叶色发黄）
变异的意义？###为生物进化提供原始材料；使生物能适应不断变化的环境
遗传育种的方法有？###人工选择（选育优良品种）、杂交育种（基因重组，如杂交水稻）、诱变育种（基因突变）
袁隆平的杂交水稻利用的是？###基因的多样性（杂交育种）

# ===== 第三章 生物的进化 =====

# 第6节 生命的起源
生命起源的化学进化过程？###原始大气（甲烷、氨、氢气、水蒸气等，无氧气）→简单的有机物（在高温、紫外线等作用下）→复杂的有机物→原始生命（在原始海洋中诞生）
原始生命诞生的场所？###原始海洋
米勒实验证明了什么？###在一定条件下，原始大气中的无机物能合成简单的有机物（氨基酸）

# 第7节 生物进化的历程
研究生物进化的最重要证据是？###化石
始祖鸟化石证明了什么？###鸟类是由爬行动物进化来的（过渡类型）
生物进化的总体趋势？###从简单到复杂、从低等到高等、从水生到陆生
生物进化的历程中，植物进化的顺序？###藻类→苔藓→蕨类→种子植物（裸子→被子）
生物进化的历程中，动物进化的顺序？###无脊椎动物→脊椎动物（鱼类→两栖类→爬行类→鸟类/哺乳类）

# 第8节 生物进化的原因
自然选择学说的主要内容？###①过度繁殖；②生存斗争；③遗传和变异；④适者生存
自然选择学说的核心是？###适者生存、不适者被淘汰（自然选择）
自然选择的素材是？###遗传和变异（可遗传的变异为进化提供原材料）
自然选择的结果是？###生物与环境相适应（生物的适应性）
桦尺蛾体色变化的实例说明了？###自然选择使与环境颜色相似的变异类型生存下来并遗传下去（保护色的形成）
长颈鹿长颈的形成原因？###具有长颈变异的个体能吃到高处食物而生存下来并遗传（自然选择，而不是用进废退）
达尔文进化论的贡献？###否定了神创论和物种不变论，科学解释了生物的进化

# ===== 第四章 生物多样性及其保护 =====

# 第9节 生物多样性的内涵
生物多样性的三个层次？###物种多样性、遗传多样性（基因多样性）、生态系统多样性
物种多样性的实质是？###基因的多样性（遗传多样性）
为什么一个物种的消失是基因库的损失？###一个物种就是一个独特的基因库，物种灭绝意味着该物种特有的基因信息无法继续传递
我国生物多样性的特点？###我国是世界上生物遗传多样性极其丰富的国家之一；家养动物、栽培植物品种众多

# 第10节 生物多样性的保护
生物多样性面临的威胁？###栖息地破坏（最主要）、过度捕猎采集、环境污染、外来物种入侵
保护生物多样性的根本措施？###保护生物的栖息环境，保护生态系统的多样性
保护生物多样性最有效的措施是？###就地保护（建立自然保护区）
迁地保护的措施？###动物园、植物园、水族馆、濒危物种繁育中心
我国保护生物多样性的法律？###《中华人民共和国野生动物保护法》等
保护生物多样性的公众参与？###不捕杀野生动物、不随意放生外来物种、低碳生活、宣传教育
