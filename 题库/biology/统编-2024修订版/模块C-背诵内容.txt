# 模块C 生物圈中的人 背诵内容测试题
# 教材：人教统编版 2024 修订版
# 格式：问题###答案（# 开头为注释）

# ===== 第一单元 人的由来 =====

# 第1课 人类的起源和发展
现代类人猿和人类的共同祖先是？###森林古猿
从猿到人转变过程中最重要的一步是？###直立行走
直立行走的意义是？###使前肢解放出来，能够制造和使用工具
制造和使用工具是？###人类发展的里程碑
# 第2课 人的生殖
男性生殖系统的主要器官是？###睾丸（产生精子，分泌雄性激素）
女性生殖系统的主要器官是？###卵巢（产生卵细胞，分泌雌性激素）
受精的场所是？###输卵管
胚胎发育的场所是？###子宫
胎儿与母体进行物质交换的结构是？###胎盘和脐带
# 第3课 青春期
青春期的显著特点是？###身高突增
男性的第二性征是？###喉结突出、声音变粗、长出胡须等
女性的第二性征是？###骨盆宽大、乳房增大、声音变细等

# ===== 第二单元 人体的营养 =====

# 第4课 合理营养与食品安全
平衡膳食宝塔从下到上依次是？###谷类→蔬菜水果→肉蛋类→奶豆类→油脂类
合理营养的要求是？###全面而平衡的营养（五类食物合理搭配）
# 第5课 消化和吸收
消化系统的组成是？###消化道和消化腺
小肠是消化和吸收主要场所的原因是？###①长5-6米；②有皱襞和小肠绒毛增大面积；③含多种消化液
淀粉的消化过程是？###口腔（唾液淀粉酶→麦芽糖）→小肠（肠液胰液→葡萄糖）
蛋白质的消化过程是？###胃（胃蛋白酶→多肽）→小肠（肠液胰液→氨基酸）
脂肪的消化过程是？###小肠（胆汁乳化→肠液胰液→甘油和脂肪酸）
# 第6课 关注合理营养与食品安全
合理营养是指？###全面而平衡的营养
食品安全要注意？###关注生产日期、保质期、生产厂家等信息

# ===== 第三单元 人体的呼吸 =====

# 第7课 呼吸道对空气的处理
呼吸系统的组成是？###呼吸道和肺
呼吸道对空气的处理作用是？###温暖、湿润、清洁
# 第8课 发生在肺内的气体交换
吸气时呼吸肌的状态是？###膈肌和肋间外肌收缩→胸廓扩大→肺扩张→外界气体进入肺
肺泡适于气体交换的特点是？###①数量多；②外包毛细血管；③壁薄（一层上皮细胞）
肺泡内气体交换的原理是？###气体扩散作用

# ===== 第四单元 人体内物质的运输 =====

# 第9课 流动的组织——血液
血液的组成是？###血浆和血细胞
红细胞的特点是？###数量最多，无细胞核，含血红蛋白
血红蛋白的特性是？###在氧含量高的地方结合，在氧含量低的地方分离
白细胞的功能是？###吞噬病菌，防御保护
血小板的功能是？###止血和加速凝血
# 第10课 血流的管道——血管
动脉的功能是？###将血液从心脏输送到身体各部分
静脉的功能是？###将血液从身体各部分送回心脏
毛细血管的特点是？###壁薄、腔小、血流最慢（便于物质交换）
# 第11课 输送血液的泵——心脏
心脏的四个腔是？###左心房、左心室、右心房、右心室
左心室壁最厚的原因是？###要将血液泵至全身，路程最远
体循环的途径是？###左心室→主动脉→全身毛细血管→上下腔静脉→右心房
肺循环的途径是？###右心室→肺动脉→肺部毛细血管→肺静脉→左心房
体循环中血液变化是？###动脉血→静脉血
肺循环中血液变化是？###静脉血→动脉血
# 第12课 血液循环的途径
体循环的意义是？###输送氧气和营养，带走废物
肺循环的意义是？###使静脉血变成动脉血

# ===== 第五单元 人体内废物的排出 =====

# 第13课 尿的形成和排出
排泄的途径有？###①呼吸系统（CO₂和水）；②皮肤（水、无机盐、尿素）；③泌尿系统（尿素、水、无机盐）
泌尿系统的组成是？###肾脏、输尿管、膀胱、尿道
尿的形成过程是？###肾小球滤过（形成原尿）→肾小管重吸收（形成尿液）
原尿与血浆的区别是？###原尿不含大分子蛋白质
尿液与原尿的区别是？###尿液不含葡萄糖
肾小管重吸收的物质是？###全部葡萄糖、大部分水、部分无机盐

# ===== 第六单元 人体生命活动的调节 =====

# 第14课 人体对外界环境的感知
视觉形成的过程是？###光线→角膜→瞳孔→晶状体→玻璃体→视网膜→视神经→大脑视觉中枢
近视眼的原因和矫正？###晶状体曲度过大或眼球前后径过长→物像落在视网膜前方→佩戴凹透镜
听觉形成的过程是？###声波→外耳道→鼓膜→听小骨→耳蜗→听觉神经→大脑听觉中枢
# 第15课 神经系统的组成
神经系统的组成是？###中枢神经系统（脑、脊髓）和周围神经系统（脑神经、脊神经）
大脑的功能是？###调节人体生理活动的最高级中枢
小脑的功能是？###协调运动，维持身体平衡
脑干的功能是？###调节心跳、呼吸、血压等基本生命活动
神经元的结构和功能是？###细胞体和突起；受到刺激产生兴奋并传导兴奋
# 第16课 神经调节的基本方式
反射的定义是？###通过神经系统对外界或内部刺激发生的有规律的反应
反射弧的组成是？###感受器→传入神经→神经中枢→传出神经→效应器
非条件反射的特点是？###生来就有的先天性反射（神经中枢在大脑皮层以下）
条件反射的特点是？###后天形成的（神经中枢在大脑皮层）
# 第17课 激素调节
内分泌腺的特点是？###没有导管，分泌物直接进入毛细血管
生长激素的作用？###促进生长发育（幼年过多→巨人症，过少→侏儒症）
甲状腺激素的作用？###促进新陈代谢和生长发育，提高神经系统兴奋性（幼年过少→呆小症）
胰岛素的作用？###调节糖的吸收利用转化（过少→糖尿病）

# ===== 第七单元 人类活动对生物圈的影响 =====

# 第18课 人类活动对生物圈的影响
人口增长带来的问题？###资源短缺、环境污染、生态破坏
保护生物圈的措施？###植树造林、节约资源、减少污染、绿色出行
