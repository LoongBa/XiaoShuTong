# 生物模块 D 人体生理与健康 背诵内容测试题

# ===== D1 人体营养 =====

人体必需的六大营养物质是？###糖类、脂肪、蛋白质、水、无机盐、维生素
人体主要的供能物质是？###糖类
人体的备用能源物质是？###脂肪
建造和修复身体的重要原料是？###蛋白质
人体消化和吸收的主要场所是？###小肠
小肠适于消化吸收的结构特点？###长5-6米、有环形皱襞和小肠绒毛、绒毛壁一层上皮细胞
淀粉最终被分解为？###葡萄糖
蛋白质最终被分解为？###氨基酸
脂肪最终被分解为？###甘油和脂肪酸
淀粉开始消化的部位是？###口腔
蛋白质开始消化的部位是？###胃
脂肪开始消化的部位是？###小肠
缺乏维生素A会导致？###夜盲症
缺乏维生素C会导致？###坏血病
缺钙会导致？###佝偻病（儿童）、骨质疏松症（老人）

# ===== D2 人体呼吸 =====

呼吸道的组成是？###鼻→咽→喉→气管→支气管
呼吸系统由哪两部分组成？###呼吸道和肺
肺进行气体交换的主要结构是？###肺泡
肺泡适于气体交换的特点？###数量多、壁薄（一层上皮细胞）、外包绕毛细血管
吸气时肋间肌和膈肌的状态？###收缩，胸廓扩大，肺扩张，肺内气压降低，气体入肺
呼气时肋间肌和膈肌的状态？###舒张，胸廓缩小，肺回缩，肺内气压升高，气体出肺
肺泡内的气体交换结果是？###氧气进入血液，二氧化碳进入肺泡
人体呼出的气体中含量增加的是？###二氧化碳和水蒸气

# ===== D3 血液循环 =====

血液由哪两部分组成？###血浆和血细胞
血细胞包括哪三种？###红细胞、白细胞、血小板
运输氧气的血细胞是？###红细胞（含血红蛋白）
吞噬病菌、防御疾病的血细胞是？###白细胞
止血凝血的血细胞是？###血小板
心脏的四个腔是？###左心房、左心室、右心房、右心室
与左心室相连的血管是？###主动脉
与右心房相连的血管是？###上下腔静脉
体循环的途径是？###左心室→主动脉→全身毛细血管→上下腔静脉→右心房
肺循环的途径是？###右心室→肺动脉→肺部毛细血管→肺静脉→左心房
体循环中血液的变化？###动脉血变为静脉血
肺循环中血液的变化？###静脉血变为动脉血
动脉血的特点是？###含氧丰富、颜色鲜红
静脉血的特点是？###含氧少、颜色暗红
体循环的起点和终点？###起点左心室，终点右心房

# ===== D4 废物排出 =====

泌尿系统的组成？###肾脏、输尿管、膀胱、尿道
形成尿液的主要器官是？###肾脏
肾单位由哪三部分组成？###肾小球、肾小囊、肾小管
尿的形成过程？###肾小球滤过形成原尿→肾小管重吸收形成尿液
肾小球滤过作用留下的是？###血细胞和大分子蛋白质不能滤过，形成原尿（含葡萄糖）
肾小管重吸收的物质？###全部葡萄糖、大部分水、部分无机盐
正常尿液中不含的物质？###葡萄糖、血细胞、蛋白质
人体排泄的三条途径？###呼吸系统（CO₂和水）、皮肤（汗液）、泌尿系统（尿液）
排泄与排遗的区别？###排泄排出代谢废物，排遗排出食物残渣（粪便）
膀胱的作用是？###暂时储存尿液

# ===== D5 神经调节 =====

神经系统的组成？###脑（大脑、小脑、脑干）、脊髓、神经
反射弧的组成？###感受器→传入神经→神经中枢→传出神经→效应器
人体神经调节的基本方式是？###反射
反射的结构基础是？###反射弧
简单反射的特点？###生来就有，神经中枢在脊髓或脑干（如缩手反射、膝跳反射）
复杂反射的特点？###后天学习形成，神经中枢在大脑皮层（如望梅止渴、谈虎色变）
视觉形成的部位？###视网膜成像，视觉在大脑皮层形成
近视的成因及矫正？###晶状体曲度过大或眼球前后径过长，物像落在视网膜前方，用凹透镜矫正
听觉形成的部位？###耳蜗内形成听觉感受器，听觉在大脑皮层形成
小脑的功能？###协调运动、维持身体平衡
脑干的功能？###调节心跳、呼吸等基本生命活动

# ===== D6 激素调节 =====

生长激素分泌异常的疾病？###幼年不足→侏儒症；幼年过多→巨人症；成年过多→肢端肥大症
甲状腺激素分泌异常的疾病？###幼年不足→呆小症；过多→甲亢；饮食缺碘→地方性甲状腺肿
胰岛素分泌不足导致的疾病？###糖尿病
内分泌腺与外分泌腺的区别？###内分泌腺无导管，分泌物直接进入血液（如垂体、甲状腺、胰岛）
人体最重要的内分泌腺是？###垂体
糖尿病患者的症状及治疗？###多饮、多食、多尿、消瘦；注射胰岛素
侏儒症与呆小症的区别？###侏儒症智力正常（生长激素不足），呆小症智力低下（甲状腺激素不足）

# ===== D7 运动系统 =====

运动系统由哪三部分组成？###骨、关节、骨骼肌
关节由哪几部分组成？###关节面、关节囊、关节腔
关节腔内的滑液作用？###润滑关节、减少摩擦
屈肘时肱二头肌和肱三头肌的状态？###肱二头肌收缩、肱三头肌舒张
伸肘时肱二头肌和肱三头肌的状态？###肱二头肌舒张、肱三头肌收缩
骨骼肌由什么组成？###肌腱和肌腹
运动产生需要哪三个系统配合？###运动系统、神经系统、循环系统等

# ===== D8 免疫与健康 =====

传染病流行的三个基本环节？###传染源、传播途径、易感人群
预防传染病的三个措施？###控制传染源、切断传播途径、保护易感人群
传染源指的是？###能够散播病原体的人或动物
传播途径包括？###空气传播、饮食传播、接触传播、生物媒介传播等
人体的第一道防线？###皮肤和黏膜
人体的第二道防线？###体液中的杀菌物质和吞噬细胞
特异性免疫的过程？###抗原→刺激淋巴细胞→产生抗体
抗体与抗原的关系？###抗体只针对特定的抗原起作用（特异性免疫）
计划免疫（接种疫苗）属于？###保护易感人群、特异性免疫
艾滋病的传播途径？###血液传播、性传播、母婴传播（不通过握手、拥抱等日常接触传播）
