# ===== 第一单元 生物圈中的绿色植物 =====

# 第1课 绿色植物的主要类群
藻类植物的主要特征是？###大多生活在水中，没有根、茎、叶的分化，结构简单
苔藓植物的主要特征是？###生活在阴湿的环境中，有茎和叶的分化，没有真正的根（假根），叶只有一层细胞
蕨类植物的主要特征是？###生活在阴湿的环境中，有根、茎、叶的分化，体内有输导组织
裸子植物的主要特征是？###能产生种子，但种子裸露，没有果皮包被（如松、柏、银杏、苏铁）
被子植物的主要特征是？###能产生种子，种子外面有果皮包被，是植物界中最高等、分布最广的类群
藻类→苔藓→蕨类→种子植物的进化趋势是？###从水生到陆生，从简单到复杂，从低等到高等

# 第2课 绿色植物与生物圈的水循环
根尖的结构从下到上依次是？###根冠（保护）、分生区（分裂）、伸长区（伸长生长）、成熟区（吸收水分和无机盐的主要部位）
成熟区是吸收水分和无机盐的主要部位的原因是？###有大量根毛，增大了吸收面积
导管的功能是？###自下而上运输水分和无机盐
筛管的功能是？###自上而下运输有机物
蒸腾作用的定义是？###水分以气体状态从植物体内散失到体外的过程
蒸腾作用的意义是？###①促进水分的吸收和运输；②促进无机盐在体内的运输；③降低叶片表面的温度，避免被阳光灼伤
蒸腾作用的主要器官是？###叶（气孔是蒸腾作用的"门户"）
气孔的开闭由什么控制？###保卫细胞（吸水张开，失水闭合）

# 第3课 绿色植物的光合作用和呼吸作用
光合作用的公式是？###二氧化碳+水→有机物（储存能量）+氧气（光能/叶绿体）
光合作用的原料是？###二氧化碳和水
光合作用的产物是？###有机物（主要是淀粉）和氧气
光合作用的条件是？###光
光合作用的场所是？###叶绿体
光合作用的实质是？###合成有机物，储存能量（将光能转变为化学能）
光合作用的应用是？###合理密植（充分利用光照）
验证绿叶在光下制造淀粉的实验步骤是？###暗处理→遮光对照→光照→摘下叶片→酒精脱色→漂洗加碘→观察颜色
酒精脱色的目的使？###溶解叶绿素，使叶片变成黄白色，便于观察碘液的颜色变化
碘液遇淀粉变蓝，说明？###绿叶在光下制造了淀粉
呼吸作用的公式是？###有机物（储存能量）+氧气→二氧化碳+水+能量（线粒体）
呼吸作用的原料是？###有机物和氧气
呼吸作用的产物是？###二氧化碳和水
呼吸作用的场所是？###线粒体
呼吸作用的实质是？###分解有机物，释放能量
光合作用与呼吸作用的区别是？###光合作用：合成有机物储存能量，需要光，在叶绿体进行；呼吸作用：分解有机物释放能量，有光无光都可，在线粒体进行
光合作用与呼吸作用的联系是？###相互依存：光合作用为呼吸作用提供有机物和氧气，呼吸作用为光合作用提供二氧化碳和能量

# 第4课 绿色植物在生物圈中的作用
绿色植物是生产者的原因是？###通过光合作用制造有机物，为自身和其他生物提供食物和能量
绿色植物维持碳—氧平衡的原因是？###光合作用吸收二氧化碳，释放氧气，使大气中氧气和二氧化碳含量保持相对稳定
绿色植物参与水循环的方式是？###通过蒸腾作用将水分散失到大气中，增加大气湿度，促进降水

# ===== 第二单元 生物圈中的人 =====

# 第1课 人类的起源和发展
现代类人猿和人类的共同祖先是？###森林古猿
从猿到人转变过程中，最重要的一步是？###直立行走
直立行走的意义是？###使前肢解放出来，能够制造和使用工具
人类发展的里程碑是？###制造和使用工具
# 第2课 人的生殖
男性生殖系统的主要器官是？###睾丸（产生精子，分泌雄性激素）
女性生殖系统的主要器官是？###卵巢（产生卵细胞，分泌雌性激素）
受精的场所是？###输卵管
胚胎发育的场所是？###子宫
胎儿与母体进行物质交换的结构是？###胎盘和脐带
# 第3课 青春期
青春期的显著特点是？###身高突增
男性的第二性征是？###喉结突出、声音变粗、长出胡须等
女性的第二性征是？###骨盆宽大、乳房增大、声音变细等
# 第4课 合理营养与食品安全
平衡膳食宝塔从下到上依次是？###谷类→蔬菜水果→肉蛋类→奶豆类→油脂类
合理营养的要求是？###全面而平衡的营养（五类食物合理搭配）
# 第5课 消化和吸收
消化系统由什么组成？###消化道（口腔→咽→食道→胃→小肠→大肠→肛门）和消化腺（唾液腺、胃腺、肝脏、胰腺、肠腺）
小肠是消化和吸收的主要场所的原因是？###①长5-6米；②内表面有皱襞和小肠绒毛，增大了面积；③含有多种消化液（胆汁、胰液、肠液）
营养物质的吸收主要发生在？###小肠
淀粉的消化过程是？###口腔（唾液淀粉酶→麦芽糖）→小肠（肠液胰液→葡萄糖）
蛋白质的消化过程是？###胃（胃蛋白酶→多肽）→小肠（肠液胰液→氨基酸）
脂肪的消化过程是？###小肠（胆汁乳化→脂肪微粒→肠液胰液→甘油和脂肪酸）
# 第6课 关注合理营养与食品安全
合理营养是指？###全面而平衡的营养
食品安全要注意？###关注食品包装上的生产日期、保质期、生产厂家等信息

# ===== 第三单元 人体的呼吸 =====

# 第7课 呼吸道对空气的处理
呼吸系统的组成是？###呼吸道（鼻→咽→喉→气管→支气管）和肺
呼吸道对空气的处理作用是？###温暖（毛细血管）、湿润（黏膜）、清洁（鼻毛、纤毛、黏液）
肺是呼吸系统的主要器官的原因是？###是气体交换的场所
# 第8课 发生在肺内的气体交换
呼吸运动包括？###吸气和呼气两个过程
吸气时呼吸肌的状态是？###膈肌和肋间外肌收缩→胸廓扩大→肺扩张→肺内气压降低→外界气体进入肺
呼气时呼吸肌的状态是？###膈肌和肋间外肌舒张→胸廓缩小→肺回缩→肺内气压升高→肺内气体排出
肺泡内的气体交换原理是？###气体扩散作用（氧气从肺泡扩散到血液，二氧化碳从血液扩散到肺泡）
肺泡适于气体交换的特点是？###①肺泡数量多；②肺泡外面包绕着毛细血管；③肺泡壁和毛细血管壁都很薄（只有一层上皮细胞）

# ===== 第四单元 人体内物质的运输 =====

# 第9课 流动的组织——血液
血液的组成是？###血浆（运载血细胞，运输营养物质和废物）和血细胞（红细胞、白细胞、血小板）
红细胞的特点是？###数量最多，呈两面凹的圆饼状，成熟的红细胞没有细胞核，富含血红蛋白
血红蛋白的特性是？###在氧含量高的地方容易与氧结合，在氧含量低的地方容易与氧分离
白细胞的特点是？###个体最大，有细胞核，数量最少
白细胞的功能是？###吞噬病菌，防御和保护
血小板的特点是？###个体最小，没有细胞核，形状不规则
血小板的功能是？###止血和加速凝血
# 第10课 血流的管道——血管
动脉的功能是？###将血液从心脏输送到身体各部分
静脉的功能是？###将血液从身体各部分送回心脏
毛细血管的特点是？###管壁最薄（只有一层上皮细胞）、管腔最小（只允许红细胞单行通过）、血流速度最慢
毛细血管的功能是？###便于血液与组织细胞充分进行物质交换
# 第11课 输送血液的泵——心脏
心脏的四个腔是？###左心房、左心室、右心房、右心室
左心室壁最厚的原因是？###左心室要将血液泵至全身，路程最远
心脏内瓣膜的作用是？###防止血液倒流（房室瓣：心房→心室；动脉瓣：心室→动脉）
体循环的途径是？###左心室→主动脉→全身毛细血管→上下腔静脉→右心房
肺循环的途径是？###右心室→肺动脉→肺部毛细血管→肺静脉→左心房
体循环中血液成分的变化是？###动脉血（含氧丰富）→静脉血（含氧较少）
肺循环中血液成分的变化是？###静脉血（含氧较少）→动脉血（含氧丰富）
# 第12课 血液循环的途径
体循环的意义是？###将氧气和营养物质输送到全身各处，同时带走二氧化碳等废物
肺循环的意义是？###使静脉血变成动脉血（在肺部进行气体交换）

# ===== 第五单元 人体内废物的排出 =====

# 第13课 尿的形成和排出
排泄的概念是？###人体将二氧化碳、尿素、以及多余的水和无机盐等排出体外的过程
排泄的途径有？###①呼吸系统（二氧化碳和水）；②皮肤（水、无机盐、尿素）；③泌尿系统（尿素、水、无机盐）
排遗的概念是？###食物残渣排出体外的过程
泌尿系统的组成是？###肾脏（形成尿液）、输尿管（输送尿液）、膀胱（暂时储存尿液）、尿道（排出尿液）
尿的形成过程包括？###肾小球的滤过作用（形成原尿）和肾小管的重吸收作用（形成尿液）
原尿与血浆相比不含？###大分子蛋白质
尿液与原尿相比不含？###葡萄糖
肾小管重吸收的物质有？###全部葡萄糖、大部分水、部分无机盐

# ===== 第六单元 人体生命活动的调节 =====

# 第14课 人体对外界环境的感知
眼的主要结构有？###角膜、瞳孔、晶状体、玻璃体、视网膜
视觉形成的过程是？###外界物体反射的光线→角膜→瞳孔→晶状体→玻璃体→视网膜（形成物像）→视神经→大脑皮层的视觉中枢（形成视觉）
近视眼的原因是？###晶状体曲度过大或眼球前后径过长，物像落在视网膜前方
近视眼的矫正方法是？###佩戴凹透镜
耳的主要结构有？###外耳（耳廓、外耳道）、中耳（鼓膜、听小骨）、内耳（耳蜗、听觉神经）
听觉形成的过程是？###外界声波→外耳道→鼓膜→听小骨→耳蜗→听觉神经→大脑皮层的听觉中枢

# 第15课 神经系统的组成
神经系统的组成是？###中枢神经系统（脑、脊髓）和周围神经系统（脑神经、脊神经）
脑的组成是？###大脑、小脑、脑干
大脑的功能是？###调节人体生理活动的最高级中枢
小脑的功能是？###协调运动，维持身体平衡
脑干的功能是？###调节心跳、呼吸、血压等基本生命活动
神经元的结构是？###细胞体和突起（树突和轴突）
神经元的功能是？###受到刺激后能产生兴奋，并且能把兴奋传导到其他神经元
# 第16课 神经调节的基本方式
反射的定义是？###人体通过神经系统，对外界或内部的各种刺激所发生的有规律的反应
反射弧的组成是？###感受器→传入神经→神经中枢→传出神经→效应器
非条件反射（简单反射）的特点是？###生来就有的先天性反射，神经中枢在大脑皮层以下（如膝跳反射、缩手反射）
条件反射（复杂反射）的特点是？###在生活过程中逐渐形成的后天性反射，神经中枢在大脑皮层
# 第17课 激素调节
内分泌腺与外分泌腺的区别是？###内分泌腺没有导管，分泌物直接进入腺体内的毛细血管；外分泌腺有导管，分泌物通过导管排出
生长激素的作用是？###促进生长发育（幼年过多→巨人症，幼年过少→侏儒症）
甲状腺激素的作用是？###促进新陈代谢和生长发育，提高神经系统的兴奋性（幼年过少→呆小症）
胰岛素的作用是？###调节糖的吸收、利用和转化（过少→糖尿病）

# ===== 第七单元 人类活动对生物圈的影响 =====

# 第18课 人类活动对生物圈的影响
人口增长带来的问题有？###资源短缺、环境污染、生态破坏等
人类活动对生物圈的影响有？###①乱砍滥伐导致森林减少；②过度放牧导致草场退化；③工业和生活污染导致环境恶化
保护生物圈的措施有？###植树造林、节约资源、减少污染、绿色出行等
