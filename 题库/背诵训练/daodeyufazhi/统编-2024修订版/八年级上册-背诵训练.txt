# ===== 第一单元 走进社会生活 =====

## 第1课 丰富的社会生活
# S1 正向检索
社会生活的三个显著特点是什么？###丰富多彩、不断变化发展、具有公共性
社会关系依据建立基础可分为哪几类？###血缘关系、地缘关系、业缘关系
# S2 逆向检索
以空间与地理位置为基础形成的社会关系是？###地缘关系（如同乡、邻居）
"这张大网上的一个结点"指的是？###每个人（个人是社会这张大网上的结点）
# S3 要点默写
默写个人与社会的关系###社会为人的生存和发展提供必要条件，每个人都从社会获得物质支持和精神滋养；社会的发展离不开每个人的努力，社会的存在和发展是所有人共同努力的结果
# S4 综合默写
默写"社会生活的特点与个人社会关系"###社会生活：丰富多彩（物质精神食粮/职业多样/交往丰富）/不断变化发展（生产工具变革/科技进步/观念更新）/公共性（公共空间展开、公共利益共享、秩序共同维护、发展共同推动）；个人：社会大网上的结点、身份在社会关系中确定、社会关系分血缘地缘业缘

社会规则具有什么作用？###规范社会行为、调节社会关系、维护社会秩序
# S2 逆向检索
道德和法律是两种主要的社会规则——这一说法正确吗？###正确（社会规则有道德、纪律、法律等，道德和法律是两种主要的社会规则）
自律的含义是什么？###严于律己，通过自省和慎独，不断发现并及时纠正自己的不良行为
# S3 要点默写
默写怎样遵守社会规则###增强规则意识（心怀敬畏、知方圆守规矩）；需要他律与自律（他律：监督提醒惩戒；自律：自省慎独）；坚定地维护规则（内化于心、外化于行）；积极完善规则（制定/废除/调整改进）
# S4 综合默写
默写"秩序、规则与自由的关系及有关要求"###社会生活需要秩序（各司其职、密切合作）；社会规则是在达成默契与共识的基础上形成的；社会规则保障社会秩序的实现，不守规则将受到道德谴责、纪律处罚、法律制裁；遵守规则需增强规则意识、他律自律结合、维护与完善规则

## 第6课 提升法治素养

法律在社会生活中的地位是什么？###法律是一种社会规则和行为规范，是评价人们的行为是否合法有效的准绳
# S2 逆向检索
公民可以通过哪些法律服务机构获得帮助？###人民调解委员会、律师事务所、公证处、法律援助中心

默写学会依法办事的要求###自觉守法（遵守宪法和法律是公民基本义务）；遇事找法（主动咨询专业人士、利用法律服务机构）；解决问题靠法（以合法方式表达诉求、寻求国家法律救济、必要时提起诉讼）
# S4 综合默写
默写"建设法治社会对全体社会成员的要求"###自觉守法、遇事找法、解决问题靠法，养成依法办事的习惯，依法维护社会秩序，确保社会和谐有序；最终成长为社会主义法治的忠实崇尚者、自觉遵守者、坚定捍卫者

# ===== 第三单元 勇担社会责任 =====

## 第7课 追求自由平等
# S1 正向检索
什么是自由？###自由意味着在遵守道德、纪律、法律等社会规则的前提下，人们能够依照自己的意志活动，在思想、言论和行为等方面具有充分自主性
平等的含义是什么？###平等意味着同等情况同等对待，比如男女同工同酬、一次选举一人一票等
# S2 逆向检索
"同等情况同等对待"体现的是社会主义核心价值观的哪个内容？###平等
为什么说自由是有限制的、相对的？###无限制的自由只会走向自由的反面，导致混乱和伤害；自由不是随心所欲，要在遵守社会规则的前提下行使权利
# S3 要点默写
默写怎样珍视自由###珍惜宪法和法律赋予的权利（知晓权利、正确认识权利价值、敢于捍卫合法权利）；依法行使权利（在遵守社会规则前提下行使权利）；尊重他人的权利（不把观点意志强加于人、不侮辱诽谤他人）
默写怎样践行平等###平等对待他人（不欺生、不凌弱）；敢于抵制不平等的行为（不能听之任之、据理力争、用合法方式捍卫平等）；坚决反对特权（不得有超越宪法和法律的特权）
# S4 综合默写
默写"自由的意义与平等价值"###自由：促进人们全面发展（免于恐吓羞辱歧视、过有尊严的生活）；推动社会繁荣进步（营造民主宽容和谐氛围、激发积极性主动性创造性）；平等：人类崇高理想、社会发展永恒主题，有助于政治上平等参与、经济上共同富裕、文化上共建共享

## 第8课 维护公平正义
# S1 正向检索
什么是公平？###公平通常指人们基于一定标准或原则，处理事情合情合理、不偏不倚；意味着每个人都拥有同等的发展机会和条件
公平有什么价值？###公平是个人生存和发展的重要保障；公平是社会稳定和进步的重要基础
# S2 逆向检索
"衡量社会发展进步的重要尺度"是指？###公平正义（公正即公平正义，是人类的永恒追求）
公正司法在维护正义中的地位是？###捍卫正义的最后一道防线（司法公正对社会公正具有重要引领作用）
# S3 要点默写
默写怎样维护社会公平###每个人努力追求公平、捍卫公平，面对利益冲突站在公平立场，敢于对不公平说"不"，采用合理合法方式；充分发挥规则的保障作用，全体社会成员都遵守规则、按规则行事
默写怎样守护正义###守护正义需要勇气和智慧（敢于斗争+讲究策略、见义智为）；需要维护司法公正（公正司法是最后一道防线）；需要维护国际正义（国家不分大小强弱贫富一律平等、反对干涉别国内政、反对双重标准）
# S4 综合默写
默写"正义的含义与价值"###含义：社会文明的尺度、人类良知的"声音"、弘扬真善美摒弃假恶丑的价值导向；价值：保障人们有尊严地生活（对弱者给予必要扶助）、营造风清气正的社会风尚（明辨是非、惩恶扬善）、促进社会进步维护公共利益

# S1 正向检索

# S4 综合默写
默写"奉献社会的意义"###能够使视野拓展、知识丰富、能力提高、道德境界提升；能够推动国家发展、社会进步，推动形成向上向善的强大力量，使社会更加和谐美好

# ===== 第四单元 维护国家利益 =====

## 第10课 国家利益至上
# S1 正向检索
什么是国家利益？###国家利益是一个主权国家在国际社会中生存需求和发展需求的总和，涉及政治、经济、文化、社会、军事等领域，关系民族生存、国家兴亡
我国的核心利益包括哪些？###国家主权、国家安全、领土完整、国家统一、宪法确立的国家政治制度和社会大局稳定、经济社会可持续发展的基本保障
# S2 逆向检索
为什么维护国家利益是每个公民的基本义务？###国家利益关系民族生存、国家兴亡；国家利益是人民利益的集中体现，国家利益与人民利益高度统一；国兴我荣，国衰我耻
当国家利益与个人利益冲突时应怎么办？###应顾全大局，把国家利益放在第一位，为了国家利益必要时应放弃个人利益，甚至献出自己的生命
# S3 要点默写
默写怎样捍卫国家利益###牢固树立国家利益至上观念，坚决维护国家的尊严、荣誉和利益；增强维护国家利益的责任感和使命感，用理性、务实、文明的心态，合法有序地表达爱国情感；发扬斗争精神，敢于斗争、善于斗争
# S4 综合默写
默写"国家利益与个人利益的关系"###国家利益是整体利益，个人利益是局部利益；从根本上说两者是一致的，国家利益反映人民利益、依靠人民艰苦奋斗才能实现；有时会冲突，此时把国家利益放在第一位

## 第12课 树立总体国家安全观
# S1 正向检索
什么是国家安全？###国家安全是国家政权、主权、统一和领土完整、人民福祉、经济社会可持续发展和国家其他重大利益相对处于没有危险和不受内外威胁的状态，以及保障持续安全状态的能力
国家安全有什么重要性？###国家安全是国家生存与发展的重要保障，是民族复兴的根基；国家安全是人民幸福安康的前提
# S2 逆向检索
总体国家安全观关键在哪里？###关键在"总体"（突出的是"大安全"理念，涵盖政治、军事、国土、经济、文化、社会、科技、网络、生态、资源、核、海外利益、太空、深海、极地、生物等领域）
维护国家安全的根本目的是？###实现人民安全，让广大人民群众安居乐业、幸福生活
# S3 要点默写
默写贯彻总体国家安全观的"五个以"###以人民安全为宗旨、以政治安全为根本、以经济安全为基础、以军事科技文化社会安全为保障、以促进国际安全为依托
