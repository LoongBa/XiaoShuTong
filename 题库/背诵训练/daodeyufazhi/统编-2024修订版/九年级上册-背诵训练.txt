# ===== 第一单元 坚持党的全面领导 =====

## 第一课 百年大党风华正茂
# S1 正向检索
党的百年奋斗归结起来的一个主题是？###实现中华民族伟大复兴
伟大建党精神的内涵？###坚持真理、坚守理想，践行初心、担当使命，不怕牺牲、英勇斗争，对党忠诚、不负人民
# S2 逆向检索
1921年召开、宣告中国共产党成立的是？###中国共产党第一次全国代表大会
中国共产党人精神谱系的源头是？###伟大建党精神
# S3 要点默写
默写四个时期党创造的伟大成就及意义###新民主主义革命→根本社会条件；社会主义革命和建设→根本政治前提和制度基础；改革开放→充满新的活力的体制保证和物质条件；新时代→更为完善的制度保证、物质基础、精神力量
默写改革开放的历史地位###是决定当代中国前途命运的关键一招
# S4 综合默写
默写"为什么没有中国共产党就没有中华民族的伟大复兴"###党团结带领人民创造丰功伟业；形成伟大建党精神源头的精神谱系；四个时期伟大成就奠定复兴基础；党的领导是历史和人民的选择

## 第二课 坚持以人民为中心

默写为什么不能忘记人民这个根###坚守初心使命才能在困境中发展壮大；忘记初心使命就会改变性质、失去人民、失去未来
# S4 综合默写
默写"坚持以人民为中心的原因"###党的初心使命所系；人民是党的根基和力量源泉；人民至上；全心全意为人民服务

# ===== 第二单元 进入新时代 =====

## 第四课 新的历史方位
# S1 正向检索
新时代我国社会主要矛盾？###人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾
中国特色社会主义进入新时代的时间定位？###这是我国发展新的历史方位
# S2 逆向检索
"两个没有变"指？###我国仍处于并将长期处于社会主义初级阶段的基本国情没有变；我国是世界最大发展中国家的国际地位没有变
# S3 要点默写
默写社会主要矛盾变化的背景###短缺经济和供给不足状况已根本改变；人民生活全方位改善；对民主法治公平正义安全环境等要求日益增长
默写进入新时代的意义###中华民族迎来了从站起来、富起来到强起来的伟大飞跃
# S4 综合默写
默写"新时代社会主要矛盾（历史对比）"###1956年党的八大：先进工业国要求vs落后农业国；1981年：物质文化需要vs落后社会生产；2017年十九大：美好生活需要vs不平衡不充分发展
