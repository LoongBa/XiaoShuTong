# ===== 第二单元 理解权利义务 =====

## 第3课 公民的基本权利和义务
# S1 正向检索
公民最基本、最重要的权利是？###人身自由
公民参与管理国家和社会的基础是？###选举权和被选举权
人格尊严权包括哪些？###姓名权、肖像权、名誉权、荣誉权、隐私权
公民基本义务包括哪些？###维护国家统一和民族团结、遵守宪法和法律、维护国家安全荣誉和利益、依法服兵役、依法纳税等
# S2 逆向检索
人身自由是公民的什么权利？###最基本、最重要的权利
选举权和被选举权是公民参与什么的基础？###参与管理国家和管理社会
税收是国家财政收入的主要来源，与之相关的义务是？###依法纳税
# S3 要点默写
默写公民基本权利的分类###平等权、政治权利和自由、人身自由、社会经济权利、文化教育权利、监督权与获得国家赔偿权、宗教信仰自由等
# S4 综合默写
默写"人身自由"的含义###公民的人身不受非法侵犯的自由，包括人身自由不受侵犯、人格尊严不受侵犯、住宅不受侵犯、通信自由和通信秘密受法律保护

## 第4课 依法行使权利和履行义务
# S1 正向检索
权利与义务的关系是？###相互依存、相互促进；公民既是权利的享有者，又是义务的承担者
哪些权利同时也是义务？###劳动和受教育
如何依法行使权利？###尊重他人权利，不损害国家社会集体利益，按法定程序，以合法方式进行
# S2 逆向检索
劳动和受教育既是权利也是什么？###义务
相互依存、相互促进，说的是权利与什么的关系？###义务
# S3 要点默写
默写依法履行义务的准则###法律要求做的必须做，法律禁止做的坚决不做，法律鼓励做的积极去做
# S4 综合默写
默写"如何依法行使权利"###公民行使权利时要尊重他人权利，不能损害国家、社会、集体的利益和其他公民合法的自由和权利，要按照法定程序，以合法方式进行
