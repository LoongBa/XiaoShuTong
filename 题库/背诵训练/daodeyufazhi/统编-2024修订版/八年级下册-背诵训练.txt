# ===== 第一单元 坚持宪法至上 =====

## 第1课 治国安邦的总章程
# S1 正向检索
我国宪法的核心价值追求是什么？###规范国家权力运行以保障公民权利
我国宪法在国家法律体系中处于什么地位？###宪法是治国安邦的总章程，集中体现了党和人民的统一意志和共同愿望，是国家意志的最高表现形式；宪法是国家根本法，是国家一切法律法规的总依据、总源头，具有最高的法律地位、法律权威、法律效力
我国宪法除序言外，规定了哪些主要内容？###设第一章"总纲"、第二章"公民的基本权利和义务"、第三章"国家机构"、第四章"国旗、国歌、国徽、首都"，共四章一百四十三条；确认了我国的国家性质，明确了人民当家作主的地位，规定了公民的基本权利和义务，通过设置国家机构授予其特定职权，使国家权力的运行稳定有序
# S2 逆向检索
"把权力关进制度的笼子里"指的是什么？###依法设定权力、规范权力、制约权力、监督权力（权力是一把双刃剑，在法治轨道上行使可以造福人民，在法律之外行使则必然祸害国家和人民）
我国现行宪法是哪一年、由哪次会议通过的？###1982年12月4日，五届全国人大五次会议通过了全面修改后的《中华人民共和国宪法》，这是我国的现行宪法；此后全国人大先后于1988年、1993年、1999年、2004年、2018年5次修正，共通过了52条宪法修正案
# S3 要点默写
默写宪法与其他法律的关系###宪法是国家根本法，是国家一切法律法规的总依据、总源头，具有最高的法律地位、法律权威、法律效力；法律、行政法规和地方性法规是根据宪法制定的，不得与宪法的规定、原则和精神相违背；宪法巩固国家政权，规范和制约国家权力，保障公民权利，维护社会稳定，推动社会进步，增进人民福祉，实现国家长治久安
默写我国宪法产生和发展的历程###1949年《中国人民政治协商会议共同纲领》起临时宪法作用；1954年宪法为巩固社会主义政权和社会主义建设发挥重要保障作用，也为现行宪法的制定和完善奠定基础；1982年12月4日五届全国人大五次会议通过现行宪法；此后1988年、1993年、1999年、2004年、2018年先后5次修正，共通过52条宪法修正案
# S4 综合默写
默写"治国安邦的总章程"知识链###性质地位（总章程/国家意志的最高表现形式/根本法/一切法律法规的总依据总源头/最高法律地位权威效力）；产生（党领导人民制定，集中人民智慧、体现全体人民共同意志，实现党的主张和人民意志高度统一）；内容（四章一百四十三条：总纲、公民的基本权利和义务、国家机构、国旗国歌国徽首都）；国家性质（工人阶级领导的、以工农联盟为基础的人民民主专政的社会主义国家；社会主义制度是根本制度；中国共产党领导是中国特色社会主义最本质的特征）；作用（巩固政权/规范和制约权力/保障公民权利/实现长治久安）；核心价值追求（规范国家权力运行以保障公民权利）

## 第2课 维护宪法权威
# S1 正向检索
坚持依宪治国，就要坚持什么不动摇？###坚持宪法确定的中国共产党领导地位不动摇，坚持宪法确定的人民民主专政和人民代表大会制度不动摇
怎样增强宪法意识、维护宪法权威？###①认同宪法——理解宪法的价值，让宪法精神在心中生根发芽；②学习宪法——了解宪法产生和发展历程，理解主要内容，领会原则和精神，参与宪法宣传活动；③践行宪法——严格遵守宪法和法律规定，学会运用宪法规定、原则和精神分析解决实际问题，自觉抵制损害宪法尊严、妨碍宪法实施的行为
# S2 逆向检索
"宪法的根基在于人民发自内心的拥护，宪法的伟力在于人民出自真诚的信仰"说明什么？###加强宪法宣传教育是实施宪法的重要基础；国家在全社会广泛开展尊崇宪法、学习宪法、遵守宪法、维护宪法、运用宪法的宣传教育活动，大力弘扬宪法精神，增强人民群众的宪法意识
全国人大及其常委会在宪法实施和监督方面行使什么职权？###全国人大及其常委会行使监督宪法实施的职权，全国人大常委会有权解释宪法和法律；对于各种违反宪法的行为，都必须予以追究和纠正
# S3 要点默写
默写依宪治国的要求###①坚持宪法确定的中国共产党领导地位不动摇，坚持宪法确定的人民民主专政和人民代表大会制度不动摇；②一切组织和个人都必须在宪法和法律范围内活动，都必须维护宪法权威，捍卫宪法尊严，保证宪法实施，任何组织或者个人都不能凌驾于宪法之上；③坚持宪法至上，维护国家法制统一、尊严和权威（一切法律、行政法规和地方性法规都不得同宪法相抵触）；④加强宪法实施和监督，对各种违反宪法的行为予以追究和纠正
默写"践行宪法"的具体做法###严格遵守宪法和法律规定，学会运用宪法规定、原则和精神来分析和解决生活中的实际问题，自觉抵制各种损害宪法尊严、妨碍宪法实施的行为，维护宪法权威；宪法是公民享有权利和履行义务的基本遵循
# S4 综合默写
默写"维护宪法权威"知识链###宪法与我们每个人息息相关，我们的一生都离不开宪法的保护；依法治国首先要依宪治国（坚持党的领导地位、人民民主专政和人民代表大会制度不动摇）；依宪治国四要求（范围内活动/宪法至上法制统一/加强实施监督）；尊崇宪法（宪法宣传教育、12月4日国家宪法日、宪法宣誓制度）；增强宪法意识三方面（认同/学习/践行）；维护宪法权威就是维护党和人民共同意志的权威

# ===== 第二单元 理解权利义务 =====

## 第3课 公民的基本权利和义务
# S1 正向检索
我国公民的基本权利包括哪些？###平等权、政治权利、人身自由、社会经济权利、文化教育权利、监督权与获得国家赔偿权、宗教信仰自由等
我国公民的基本义务包括哪些？###维护国家统一和全国各民族团结，遵守宪法和法律，维护国家安全、荣誉和利益，依法服兵役，依法纳税等；此外还有劳动的义务、受教育的义务、夫妻双方实行计划生育的义务、父母抚养教育未成年子女的义务和成年子女赡养扶助父母的义务等
# S2 逆向检索
"中华人民共和国公民在法律面前一律平等"保障的是哪项基本权利？它有何地位？###平等权——公民平等地享有权利，不受任何不合理的差别对待；平等权是公民行使其他权利的基础
行使选举权和被选举权在公民政治生活中居于什么地位？###是公民参与管理国家和社会事务的基础（我国年满十八周岁的公民，不分民族、种族、性别、职业、家庭出身、宗教信仰、教育程度、财产状况、居住期限，都有选举权和被选举权；但是依照法律被剥夺政治权利的人除外）
# S3 要点默写
默写人身自由包括的内容及其地位###人身自由是指公民的人身不受非法侵犯的自由，包括人身自由不受侵犯、人格尊严不受侵犯、住宅不受侵犯、通信自由和通信秘密受法律的保护；人身自由是公民参加国家政治生活、经济生活与社会生活的基础，只有在人身自由得到保障的前提下，公民才能独立、自由、有尊严地生活
默写公民依法服兵役的规定及意义###保卫祖国、抵抗侵略是公民的神圣职责，依照法律服兵役和参加民兵组织是公民的光荣义务；我国实行以志愿兵役为主体的志愿兵役与义务兵役相结合的兵役制度；依照宪法和兵役法的规定，中华人民共和国公民不分民族、种族、职业、家庭出身、宗教信仰和教育程度，都有义务服兵役
# S4 综合默写
默写"公民基本权利"知识链###含义（公民基本权利是人权在宪法上的具体化，为追求有尊严的生活、实现人生幸福提供保障）；七大类别（平等权——行使其他权利的基础/政治权利——选举权和被选举权+言论出版集会结社游行示威自由/人身自由——人身、人格尊严、住宅、通信自由和通信秘密不受侵犯/社会经济权利——财产权、劳动权、劳动者休息权、社会保障权和物质帮助权/文化教育权利——受教育权+文化权利/监督权与获得国家赔偿权/宗教信仰自由）；监督权行使方式（提出批评和建议、提出申诉控告或者检举）

## 第4课 依法行使权利和履行义务
# S1 正向检索
权利与义务的关系是怎样的？###公民的权利与义务相互依存、相互促进；公民既是权利的享有者，又是义务的承担者；公民的某些权利同时也是义务，如劳动和受教育既是公民的基本权利，也是公民的基本义务；公民自觉履行义务，促进国家发展和社会进步，又为其权利的实现提供和创造更好的条件
当合法权益受到侵害时，公民可以通过哪些方式维权？###和解、调解、仲裁和诉讼等方式，依照法定程序来寻求救济、解决纠纷、维护权利
# S2 逆向检索
"没有无义务的权利，也没有无权利的义务"说明什么？###要坚持权利与义务相统一——公民既不能只享有权利而不承担义务，也不应只承担义务而不享有权利；要增强权利意识和义务观念，依法行使权利，自觉履行义务
公民违反法律要承担什么责任？###公民违反法律，要依法承担民事责任或行政责任，构成犯罪的，要依法承担刑事责任
# S3 要点默写
默写和解、调解、仲裁、诉讼四种维权方式的含义###和解是当事人之间通过协商自行解决纠纷的方式（在法律允许的范围内，自愿、互谅基础上直接对话，分清责任，达成协议）；调解是通过调解组织解决纠纷的方式（调解组织对当事人进行疏导、劝说，促使相互谅解，自愿达成协议）；仲裁是通过仲裁机构解决纠纷的方式（平等主体之间发生的合同纠纷和其他财产权益纠纷可以仲裁，根据仲裁协议自愿提交，受仲裁裁决约束）；诉讼是通过人民法院解决纠纷的方式（主要包括民事诉讼、行政诉讼、刑事诉讼）
默写"依法行使权利"的两条要求###①行使权利有界限——任何权利都不是绝对的，公民在行使自由和权利的时候，不得损害国家的、社会的、集体的利益和其他公民的合法的自由和权利，超出宪法和法律所许可和保障的范围要承担相应的法律责任；②行使权利守程序——树立按照法定程序办事的意识，按照规定的活动方式、步骤和过程行使权利
# S4 综合默写
默写"依法履行义务"知识链###法定义务是由我国宪法和法律规定的，具有强制性，自觉履行法定义务是公民不可推卸的责任；法律要求做的必须去做（公民必须按照法律要求去做，否则就可能构成违法甚至犯罪）；法律禁止做的坚决不做（实施法律所禁止的行为，构成违法甚至犯罪的，依法承担相应法律责任）；违反法律依法承担民事责任或行政责任，构成犯罪的承担刑事责任

# ===== 第三单元 认识国家制度 =====

## 第5课 我国的政治制度
# S1 正向检索
我国的根本政治制度是什么？它有哪些基本内容？###人民代表大会制度；基本内容包括：国家的一切权力属于人民；人民通过民主选举选出代表，组成各级人民代表大会作为国家权力机关；由人民代表大会产生国家行政机关、监察机关、审判机关、检察机关，这些国家机关依法行使各自的职权，并对人民代表大会负责，受人民代表大会监督；实行民主集中制，重大问题经人民代表大会充分讨论，遵循少数服从多数原则，民主决定
我国的基本政治制度有哪些？###中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度
人民政协围绕什么主题、履行哪些职能？###围绕团结和民主两大主题，履行政治协商、民主监督和参政议政的职能（中国人民政治协商会议是爱国统一战线组织、多党合作和政治协商的重要机构、人民民主的重要实现形式，是社会主义协商民主的重要渠道和专门协商机构）
# S2 逆向检索
"长期共存、互相监督、肝胆相照、荣辱与共"是我国处理什么关系的方针？###中国共产党同各民主党派的关系（中国共产党领导的多党合作和政治协商制度的基本方针）
各少数民族聚居的地方实行什么制度？自治机关是什么？###民族区域自治制度；民族自治地方的自治机关是民族自治地方的人民代表大会和人民政府，在行使一般地方国家机关职权的同时，依照宪法、民族区域自治法和其他法律规定的权限行使自治权
# S3 要点默写
默写人民代表大会制度的地位和优越性###人民代表大会制度是坚持党的领导、人民当家作主、依法治国有机统一的根本政治制度安排，它最大限度保障人民当家作主，是实现我国全过程人民民主的重要制度载体；实践证明，它是符合我国国情和实际、体现社会主义国家性质、保证人民当家作主的好制度，是能够有效凝聚全体人民力量一道推进中国式现代化的好制度，具有强大生命力和显著优越性
默写民族区域自治制度"统一和自治相结合"的要求###我国民族区域自治是在党和国家统一领导下的自治，各民族自治地方是国家不可分割的组成部分；民族自治地方的自治机关必须服从中央的领导，做到统一和自治相结合、民族因素和区域因素相结合；实施民族区域自治制度的根本目的是维护国家统一和民族团结
# S4 综合默写
默写"我国的政治制度"四种制度对比###根本政治制度（人民代表大会制度：一切权力属于人民/民主选举组成人大/其他国家机关由人大产生对其负责受其监督/民主集中制）；基本政治制度三（中国共产党领导的多党合作和政治协商制度——十六字方针：长期共存互相监督肝胆相照荣辱与共，人民政协围绕团结民主两大主题履行政治协商民主监督参政议政职能；民族区域自治制度——自治区、自治州、自治县三级，自治机关是人大和政府，统一和自治相结合、民族因素和区域因素相结合；基层群众自治制度——居委会村委会是自我管理、自我服务、自我教育、自我监督的基层群众性自治组织，实行民主选举、民主协商、民主决策、民主管理、民主监督）

## 第6课 我国的基本经济制度
# S1 正向检索
我国的社会主义基本经济制度包括哪些内容？###公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制等（党的十九届四中全会指出）
公有制经济包括哪些？国有经济在国民经济中处于什么地位？###公有制经济包括国有经济、集体经济以及混合所有制经济中的国有成分和集体成分；国有经济是国民经济的主导力量，国有经济的生产资料属于全体人民共同所有；集体经济的生产资料属于一部分劳动者共同所有
# S2 逆向检索
市场经济中"看不见的手"指的是什么？它通过哪些机制调节资源配置？###市场机制——我国实行社会主义市场经济体制，市场在资源配置中起决定性作用；生产什么、如何生产、生产多少，主要通过价格、供求、竞争等机制来调节
按劳分配是由什么决定的？它按什么尺度进行分配？###按劳分配是由生产资料公有制决定的；在作了必要的扣除后，以劳动者所提供的劳动（包括劳动数量和质量）为尺度对个人进行分配，多劳多得，少劳少得；在现阶段，要着重保护劳动所得，增加劳动者劳动报酬
# S3 要点默写

默写"国家司法机关"知识链###司法机关组成（人民法院=审判机关/人民检察院=法律监督机关）；法院体系（最高人民法院、地方各级人民法院——高级、中级、基层、专门人民法院——军事、海事、知识产权、金融法院）；检察院体系（最高人民检察院、地方各级人民检察院、专门人民检察院）；行使职权（法院审判权/检察院检察权，均以事实为根据、以法律为准绳）；独立原则（独立行使审判权/检察权，不受行政机关、社会团体和个人干涉）；区别（法院上下级是监督关系，检察院上下级是领导关系；法院、检察院均对本级人大及其常委会负责并报告工作）

## 第14课 以法治推进国家治理现代化
# S1 正向检索
法治与改革的关系是怎样的？###改革是社会发展的强大动力，法治是国家治理体系和治理能力的重要依托；改革和法治相辅相成、相互促进；实现国家治理现代化，必须正确处理法治与改革的关系，坚持在法治下推进改革，在改革中完善法治
法治与德治的关系是怎样的？###法治和德治都是治国理政不可或缺的重要手段，都具有规范社会行为、调节社会关系、维护社会秩序的作用；法治对德治具有促进作用，德治对法治具有支撑作用；要坚持依法治国和以德治国相结合，使法治和德治在国家治理中相互补充、相互促进、相得益彰
# S2 逆向检索
"法安天下，德润人心""法律是成文的道德，道德是内心的法律"说明什么？###法律的有效实施有赖于道德支持，道德的自觉践行离不开法律约束（法治和德治相辅相成，都是治国理政不可或缺的重要手段）
"确保重大改革于法有据"体现处理法治与改革关系的哪个方面？###在法治下推进改革——以法治引领改革，依照法定程序把改革方案和举措上升为国家意志，确保重大改革于法有据；以法治深化改革，既以法的强制力保证改革顺利推进，又以法治方式巩固和扩大改革成果
# S3 要点默写
默写"在改革中完善法治"的内容###改革开放为解放和发展社会生产力提供了动力，也推动了社会主义法治国家建设；对于实践证明比较成熟的改革经验、行之有效的改革举措，立法机关及时通过立法、修法等方式，将其上升为法律规定，促进法律规范体系更加完备
默写法治对德治的促进作用###以法治承载道德理念，德治才有可靠的制度支撑；把实践中广泛认同、较为成熟、操作性强的道德要求及时上升为法律规范，严格执法、公正司法，能够激励立德扬善，提升全社会道德素质
# S4 综合默写
默写"以法治推进国家治理现代化"知识链###改革与法治（改革是强大动力/法治是重要依托；在法治下推进改革——重大改革于法有据/在改革中完善法治——成熟经验上升为法律）；法治与德治（法安天下德润人心；法治促进德治——以法治承载道德理念、提升全社会道德素质/德治支撑法治——提供伦理基础、评判标准、社会基础和源头活水；坚持依法治国和以德治国相结合）；青少年要求（牢固树立法治思维，培养改革创新精神，增强法治观念、提升道德素养，做崇德向善、遵纪守法的新时代好公民）
