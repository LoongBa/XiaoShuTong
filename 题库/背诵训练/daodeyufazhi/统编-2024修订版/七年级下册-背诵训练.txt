# ===== 第一单元 珍惜青春时光 =====

## 第1课 青春正当时
# S1 正向检索
青春期生理变化主要表现在哪些方面？###身体外形的变化、体内机能的增强、性的发育和成熟；这些生理变化让我们感受到旺盛的生命力，身体充满能量，精力充沛、思维敏捷
青春期心理变化有哪些表现？###认知能力得到提高、自我意识不断增强、情感世界愈加丰富
与异性交往有什么积极作用？###可以增进对异性的了解、消除神秘感；可以扩大交往范围、提高交往能力；有助于完善自身，在团结和睦的集体中共同成长
# S2 逆向检索
身心处于不平衡状态、在心理上表现出一定矛盾性的是哪个时期？###青春期（矛盾性表现：独立与依赖、闭锁与开放、勇敢与怯懦）
面对生活中可能出现的对异性的朦胧情感，应该怎样对待？###慎重对待，理智处理（真正的爱情不仅意味着热烈的情感、彼此的欣赏和尊重，而且需要责任、能力和担当）
# S3 要点默写
默写积极面对青春期心理矛盾和困惑的方法###参加集体活动，在集体的温暖中接纳和调整自己；求助老师、家长和心理医生，化解烦恼、解决问题；学会自我调节，成为自己的"心理保健医生"
默写与异性交往应把握的尺度###注意交往的方式、场合、时间和频率，既要热情大方，又要掌握分寸，做到言谈得当、举止得体
默写学会自我保护的要求###树立正确的道德观念和牢固的法律意识，遵守中学生日常行为规范，触碰道德底线的事情坚决不做、违反法律的事情坚决不做；增强自我保护意识，提高预防和应对性骚扰、性侵害的能力，学会辨别并抵制性骚扰、性侵害等行为，运用法律武器维护自己的合法权益
# S4 综合默写
默写"青春期的变化与应对"###生理变化（外形/体内机能/性发育节奏各有不同，不焦虑不自卑、不嘲弄他人）+心理变化（认知提高/自我意识增强/情感丰富）+心理矛盾性（独立与依赖/闭锁与开放/勇敢与怯懦，可自我调节）；异性交往（积极作用+把握尺度+朦胧情感慎重理智处理）+自我保护（道德底线、法律意识，防性骚扰/性侵害）

## 第2课 做情绪情感的主人
# S1 正向检索
人的情绪有什么特点？###情绪复杂多样，除了常见喜、怒、哀、惧，还有自豪、感激、焦虑、厌恶、内疚等；情绪是主观体验，常常伴随生理感受，通过语言、表情和行为等表现出来，是人的内心世界的"晴雨表"
管理情绪的方法有哪些？###学会认识自己的情绪；学会调节情绪（注意转移、合理宣泄、认知调节、放松训练）；学会合理表达情绪；在帮助他人、奉献社会中培养积极健康的情绪
# S2 逆向检索
情绪受哪些因素的影响？###外部环境、生活事件、个人的性格特点、对事物的观念和看法等都会影响人的情绪
比情绪更为深刻、稳定的内心体验，也是人的基本精神需求的是什么？###情感（当对某些人或事物的情绪随时间的推移形成比较稳定的倾向时，我们就会产生某种情感）
# S3 要点默写
默写情绪对人的观念和行动的影响###积极情绪通常伴随愉悦体验，可以提高积极性和活动能力；消极情绪通常带来不良体验、产生负面影响；在一定条件下消极情绪也有积极作用（如适度的焦虑可以把压力转化为动力，有助于提升思考能力、加快反应速度、提高学习效率）
默写情感的作用###情感反映我们对人对事的态度、观念，影响判断和选择，促使我们作出行动；情感能提升想象力、创造力，有助于更全面地观察事物、探索未知；情感的发展体现生命成长，使情怀更宽广、博大
默写怎样获得积极情感体验、对待消极情感###通过与人交往、积极参与有意义的社会活动等方式有意识地增加积极情感体验；学会承受和转化消极情感（体验消极情感未必是坏事）；在实践中提升情感境界，从做好小事、管好小节开始，让情感升华为高尚情操
# S4 综合默写
默写"做情绪情感的主人的路径"###认识情绪（复杂多样、受多因素影响、"晴雨表"、影响观念行动）→ 管理情绪（认识情绪/调节情绪四法/合理表达/奉献中培养）→ 品味美好情感（有意识地增加积极情感体验/承受和转化消极情感/在实践中提升情感境界）

# ===== 第二单元 焕发青春活力 =====

## 第3课 人贵自尊
# S1 正向检索
什么是自尊？基于什么需要？###自尊是对自我价值的肯定，包括自我尊重和赢得他人的尊重；每个人都有自尊的需要，当这种需要得到满足时，我们便会感到快乐
自尊的人有哪些表现？###能认可自己（了解优点和长处、肯定自己的价值、积极表现自己）；知廉耻、明是非（有羞耻心、行己有耻、自觉约束自己）；不爱慕虚荣（不为名利所惑、不过分追求表面上的荣耀）
# S2 逆向检索
"凡自己认为可耻的事就不去做"指的是什么？###"行己有耻"（出自《论语》，对自己不善的动机和行为有羞耻心，能够以羞耻心约束自己的行为）
"自尊者，则人尊之；自贵者，则人贵之"说明什么？###自尊是一种良好的心理状态，是一个人德行的具体表现
# S3 要点默写
默写怎样维护自己的人格尊严###恪守为人之德，坚持人格独立，不做有损人格的事；面对他人的议论或批评，要有平和、豁达的心态，做到"有则改之，无则加勉"；面对他人的侮辱和诋毁，应当予以回击，必要时运用法律武器保护自己
默写怎样尊重他人###尊重他人的隐私和人格，不取笑、歧视他人，更不能侮辱他人；接纳他人不同的个性和处世风格，尊重他人不同的生活习惯，珍视他人的劳动和付出
# S4 综合默写
默写"做自尊的人"###维护人格尊严（恪守为人之德/平和豁达/"有则改之，无则加勉"/依法回击侮辱诋毁）+不断提升自己（真正的自尊来自一个人的努力、拼搏和进取）+尊重他人（尊重隐私人格/接纳差异/珍视劳动付出）；尊重他人，才可能赢得他人的尊重

## 第4课 自信给人力量
# S1 正向检索
什么是自信？###自信就是相信自己，是一个人对自身能力的肯定，是一个人自身能力的彰显，是一个人精神风貌的体现
自信有什么作用？###自信让人远离自负与自卑；自信让人乐观坚定（自信是"我能行"的信念，面对困难和失败不轻言放弃，朝着既定目标勇毅前行）
# S2 逆向检索
过高地估计自己、自以为是、好高骛远是？###自负
轻视自己、认为自己不如别人、低估自己的能力、不敢尝试是？###自卑
# S3 要点默写
默写自信的来源###自信并非凭空而来，自信源于成长过程中积累的实力，源于在和他人交往中获得的肯定，源于从社会稳定发展、国家繁荣富强中获得的安全感、成就感和自豪感
默写做自信的人的方法###找准定位、扬长避短（客观认识自己、准确定位自己，认清不足、避免盲目自信）；专注当下、积极行动（明确目标，心无旁骛、全力以赴，不惧失败）；勇于探索、增强底气（有直面挑战的勇气，在解决问题中展现实力、提升能力）
# S4 综合默写
默写"自信、自负、自卑的区别"###自信：实事求是地看待自己、坦然面对真实的自己、从容应对学习和生活中的问题；自负：过高估计自己、自以为是、好高骛远；自卑：轻视自己、低估能力、不敢尝试；青春的自信既体现在个人成长的努力之中，也体现在为民族振兴的奋斗之中

## 第5课 人生当自强
# S1 正向检索
什么是自强？###自强是自我勉励、发愤图强，是一种奋发进取的精神状态，是一种不断完善自我、超越自我的人生追求
自强与人有什么关系？###自强使人自主自立（能"克己""自胜"，主动发掘自身力量，依靠自己的努力拼搏勇敢面对生活，获得生存和发展的机会）；自强使人奋发向上（有锲而不舍的坚毅品格，积极进取，知不足而奋进、望远山而力行，不断挑战自我、超越自我）
# S2 逆向检索
"天行健，君子以自强不息"说明了什么？###自强不息是中华民族几千年文化传承和社会实践沉淀出的优良传统
自强与个人、民族、国家有什么关系？###自强不仅关系个人的成长，而且关系民族的命运和国家的未来；正是一代又一代中国人自强不息地接力传承，中华民族才历经沧桑而不衰、饱经磨难而更强，自立于世界民族之林
# S3 要点默写
默写自强使人自主自立、奋发向上的表现###自主自立：能够"克己""自胜"，主动发掘自身力量，依靠自己的努力拼搏勇敢面对生活，获得生存和发展的机会；奋发向上：有锲而不舍的坚毅品格，积极进取，知不足而奋进、望远山而力行，不断挑战自我、超越自我
默写怎样做自强不息的中国人###树立远大理想（怀有拳拳爱国之心、立下报国之志，把个人命运与祖国发展结合起来）；求得真学问、练就真本领（认真对待各门课程、勤学好问、夯实基础，提高解决问题的能力）；在苦干实干中磨砺成长、砥砺前行（学会依靠自己、对自己负责，不怕吃苦、努力耕耘）
# S4 综合默写
默写"自强与个人、民族、国家的联系"###自强使人自主自立（克己自胜、依靠自己）+使人奋发向上（锲而不舍、超越自我）；自强不仅关系个人成长，而且关系民族命运和国家未来——一代代中国人自强不息接力传承，中华民族才历经沧桑而不衰、饱经磨难而更强

# ===== 第三单元 传承中华优秀传统文化 =====

## 第6课 传承核心思想理念
# S1 正向检索
中华优秀传统文化有哪些重要的思想理念？###道法自然、天人合一的思想；脚踏实地、实事求是的思想；革故鼎新、与时俱进的思想；惠民利民、安民富民的思想
今天传承中华优秀传统文化要弘扬哪些核心思想理念？###讲仁爱、重民本、守诚信、崇正义、尚和合、求大同等核心思想理念
# S2 逆向检索
"民惟邦本，本固邦宁"体现的是哪一核心思想理念？###重民本（充分认识人民在国家中的地位和作用，爱民保民利民，站稳人民立场，增强为人民服务的本领）
"物之不齐，物之情也""和实生物，同则不继"体现的是哪一核心思想理念？###尚和合（追求和谐，强调多样性统一，构建人与人、人与社会、人与自然之间的和谐关系）
# S3 要点默写
默写"道法自然、天人合一"的思想###主张尊重、顺应大自然运行的规律，与天地万物和谐共生（"天地与我并生，而万物与我为一"）；在敬畏自然、尊重自然、顺应自然、保护自然的意义上构建人与自然生命共同体
默写"讲仁爱""守诚信""崇正义"的要求###讲仁爱：亲亲、仁民、爱物，关爱亲人、友善待人、爱惜万物，将仁爱之心融入生活实践；守诚信：真实无欺、言行一致，树立诚信意识，做诚实守信的人；崇正义：坚持做正确的事、做符合道义的事，将道义置于优先位置，让言行合乎道义
默写"求大同"的要求###胸怀天下，牢记"大道之行也，天下为公"的古训，将天下视作天下人的天下，热爱祖国和人民，积极为人类的发展和进步作贡献
# S4 综合默写
默写"六大核心思想理念及其要求"###讲仁爱（亲亲/仁民/爱物）、重民本（民惟邦本/站稳人民立场）、守诚信（真实无欺/言行一致）、崇正义（义以为上/道义优先）、尚和合（多样性统一/和谐关系）、求大同（天下为公/胸怀天下）；借助书法绘画故事格言等多种形式古为今用、守正创新，坚定文化自信

## 第7课 弘扬中华人文精神
# S1 正向检索
中华人文精神主要体现在哪些方面？###处世方法、教化思想、美学追求、生活理念等诸多方面
"求同存异、和而不同"的含义和意义是什么？###求同存异：既找出共同点、找到最大公约数，又保留不同点、尊重不同意见；和而不同：倡导和谐相处，协调不同意见，但不盲从苟同；有助于解决人际矛盾，为化解当代社会冲突提供重要启示
# S2 逆向检索
"文以载道、以文化人"指的是哪一方面的思想？###教化思想（文化表现形式承载着做人做事的道理，可以教育人、感化人、成就理想人格）
倡导俭朴、简约的生活方式，强调不为物役、追求身心和谐统一的是哪一生活理念？###俭约自守、中和泰和
# S3 要点默写
默写"形神兼备、情景交融"的美学追求###文艺作品不但具有美妙形态，而且富有独特神韵（"形具而神生"）；人们追求立象尽意，主张将人的思想情感与外界景物融为一体；塑造了中华民族独特的审美气质
默写怎样弘扬中华人文精神###弘扬促进社会和谐的思想文化（推崇"万物并育而不相害，道并行而不相悖"，正确运用求同存异、和而不同的方法）；弘扬向上向善的思想文化（立己达人、兼善天下，爱人利人、择善而行，向榜样学习、勇担使命，争做向上向善的好少年）
# S4 综合默写
默写"中华人文精神的四个方面与弘扬"###处世方法（求同存异、和而不同）+教化思想（文以载道、以文化人）+美学追求（形神兼备、情景交融）+生活理念（俭约自守、中和泰和）；弘扬促进社会和谐、向上向善的思想文化

## 第8课 践行中华传统美德
# S1 正向检索
中华传统美德具有怎样的地位？###中华传统美德是中华优秀传统文化的精髓，是世代相传的民族智慧，是中华民族走向未来的宝贵精神财富
中华传统美德包括哪些主要内容？###孝悌忠信、礼义廉耻的荣辱观念；崇德向善、见贤思齐的社会风尚；精忠报国、振兴中华的爱国情怀；天下兴亡、匹夫有责的担当意识
在生活中有哪些需要大力弘扬和践行的中华传统美德？###自强不息、敬业乐群、扶危济困、见义勇为、孝老爱亲等中华传统美德
# S2 逆向检索
"位卑未敢忘忧国""苟利国家生死以，岂因祸福避趋之"体现的是？###精忠报国、振兴中华的爱国情怀（中华儿女将自己的前途命运与祖国兴衰、民族存亡紧紧联系在一起）
"见贤思齐焉，见不贤而内自省也"体现的是？###崇德向善、见贤思齐的社会风尚（不断向有美德、有才能、有贡献的人学习）
# S3 要点默写
默写"孝悌忠信、礼义廉耻"的基本含义###孝：对父母长辈的尊重和爱戴；悌：对兄长的敬爱和恭顺，也泛指对同辈和朋友的尊敬和友善；忠：尽心竭力、尽职尽责，常指为国尽忠；信：讲诚信；礼：为人处世懂礼貌、讲规矩；义：做事情符合道义；廉：廉洁奉公；耻：自尊自重，有羞耻之心
默写做中华传统美德践行者的五个要求###做自强不息的人（自立自强、刚健有为，以顽强的意志和不屈的精神不断开辟人生的新天地）；做敬业乐群的人（专心致志、爱岗敬业、尽职尽责，与人和睦相处、团结协作）；做扶危济困的人（当他人身处困境时主动伸出援助之手）；做见义勇为的人（当国家利益和社会公共利益受到侵害、他人遇到危难时敢于挺身而出）；做孝老爱亲的人（孝敬老人、爱护亲人，将爱的情感和责任扩展到全社会）
# S4 综合默写

## 第11课 远离违法犯罪
# S1 正向检索

违法行为有哪些分类？###民事违法行为（违反民事法律规范、承担民事责任）、行政违法行为（违反行政法律规范、承担行政责任）和刑事违法行为即犯罪（违反刑事法律规范、承担刑事责任）；民事违法行为和行政违法行为对社会的危害相对轻微，称为一般违法行为
犯罪具有哪些特征？###严重社会危害性（犯罪的最本质特征）、刑事违法性（区分犯罪与其他违法行为的法律分界线）、应受刑罚处罚性
