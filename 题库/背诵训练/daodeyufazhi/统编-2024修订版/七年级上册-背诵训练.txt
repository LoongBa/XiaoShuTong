# ===== 第一单元 少年有梦 =====

## 第1课 开启初中生活
# S1 正向检索
初中阶段为我们的发展提供了哪些新的机会？###富有挑战的课程和学习任务；丰富多彩的社团活动；各种各样的社会实践；在新的集体生活中涵养品格、提升自我
初中阶段对我们的人生具有怎样的独特价值？###正处于生命成长的"拔节孕穗期"，初步形成世界观、人生观、价值观，需要精心引导和栽培
# S2 逆向检索
"志存高远、追梦远航；越来越踏实、努力学习、勤于思考"是初中阶段对谁的期望？###对中学生成长提出的新要求（家庭、学校、社会对我们的期望）
做好初中生活规划的第一步是什么？###先确定个人发展目标（在老师和家长帮助下，结合社会需要和兴趣、性格、能力等自身条件）
# S3 要点默写
默写规划初中生活的两大步骤###①先确定个人发展目标；②再制订行动方案——分解发展目标，明确实施细节，列出时间表，使行动方案切实可行
默写"努力"的五种方法###分清主次，合理规划和管理时间；劳逸结合，学会科学用脑；每天进步一点点；学思并进；珍视团队合作
# S4 综合默写
默写"奏响中学序曲"的核心观点###新身份（中学生）；新机会（课程/社团/社会实践/集体生活）；新要求（上进/踏实/包容/坚强）；独特价值（拔节孕穗期、三观形成需引导）；要珍视当下、把握机遇、确立更高发展目标，努力成为有理想、敢担当、能吃苦、肯奋斗的中学生

## 第2课 正确认识自我
# S1 正向检索
认识自己有哪些途径？###①对自我的全面分析（生理状况、心理特征、社会关系）；②他人的评价；③在生活实践中认识自己
怎样做更好的自己？###尊重和接受个体差异、根据自身特点和社会需要发展自己；学会欣赏自己；学会接纳自己；不断完善自己；不断发掘自己的潜能
# S2 逆向检索
"知人者智，自知者明"告诉我们什么道理？###人贵自知——要正确认识自己（有助于增强自信、促进自我发展、促进与他人的交往）
他人评价过誉或贬损时应该怎么做？###理性应对——经过理性思考后选择忽略或者平静地拒绝，不让这样的评价影响自己
# S3 要点默写
默写正确对待他人评价的四个方法###用心聆听；注重沟通；勇于面对；理性应对
默写"接纳自己"的具体要求###接纳自己的全部：既接纳优点又接纳不足，既接纳现在又接纳过去，接纳自己满意的部分也接纳不满意的部分；接纳不足不意味着裹足不前，而是以乐观、勇气和智慧面对现实，努力向更好的方向发展
# S4 综合默写
默写"做更好的自己"的完整要求###尊重和接受个体差异，根据自身特点和社会需要发展自己；①欣赏自己（不是孤芳自赏、骄傲自大，而是欣赏长处和优势）；②接纳自己（接纳全部）；③完善自己（发挥优点、主动改正缺点、向他人书本社会学习）；④发掘潜能（通过学习、参与活动、与他人合作）；做更好的自己是在为他人、为社会服务中实现的，是值得用一生探寻的人生课题

## 第3课 梦想始于当下
# S1 正向检索
梦想的含义是什么？###梦想是对未来美好生活的愿望；编织人生梦想，是青少年时期的重要主题
做有梦想的少年，应当怎样做？###①树立远大志向——早立志，立大志，立长志；②紧扣时代脉搏——努力成为担当民族复兴大任的时代新人

"志不立，天下无可成之事"说明志向是什么？###志向是人生的航标，是奋斗的原动力
学习是我们现阶段的基本任务，也是我们成就什么的路径？###成就梦想的重要路径（学习是立身做人的永恒主题，也是报国为民的重要基础）

默写梦想的作用###梦想能不断激发我们对生命的热情和勇气，让生活更有色彩；有梦想，就会有希望；有了梦想，人类社会才能不断发展和进步
默写实现梦想需要怎样学习###发现并保持学习的兴趣，更加自觉主动地学习；养成良好学习习惯，掌握科学学习方法，提高学习效率；积极参加社会实践活动，到社会大课堂去读好"无字之书"
# S4 综合默写
默写"学习成就梦想"的知识链###学习意义（立身做人永恒主题/报国为民重要基础/提升思想品德精神境界、增强能力增长智慧）；学习内容（知识获取+能力提升+品德培养，不局限在学校）；实现梦想要努力学习、善于学习；学习关乎个人前途命运，更关乎民族未来与发展，要学以致用、开拓进取、勇于创新

## 第4课 幸福和睦的家庭
# S1 正向检索
家庭的含义是什么？###家庭是由婚姻关系、血缘关系或收养关系结合成的亲属生活组织
建设美好家庭有哪些要求？###①用心体味亲情之爱；②相互关爱、彼此尊重；③传承中华民族传统家庭美德；④建设美好的家庭是家庭成员的共同责任
# S2 逆向检索
"家是生命的居所，是心灵的港湾"说明家在个人成长中的地位是？###家让我们的心灵有所依托，我们的生命是父母给予的，成长离不开家庭的哺育和支持
孝亲敬老在我国具有怎样的地位？###孝亲敬老既是中华民族的传统美德，也是公民的法定义务（宪法规定成年子女有赡养扶助父母的义务）
# S3 要点默写
默写优良家风的作用###家风是代代传承的无形力量，会融入家庭成员的血脉中，潜移默化地影响家庭成员的价值观念、性格特征、道德修养和行为习惯；优良家风引导我们向上向善，促进家庭幸福和谐
默写建设美好家庭中"相互关爱、彼此尊重"的具体做法###对父母长辈要孝顺敬重；对兄弟姐妹要相携相助；以彼此尊重为前提进行沟通和交流；学会换位思考，有事多商量，主动化解矛盾
# S4 综合默写
默写"让家更美好"的四大要求###①用心体味亲情之爱（家人间的爱蕴含在生活点滴之中）；②相互关爱、彼此尊重（孝顺敬重/相携相助/换位思考/化解矛盾）；③传承中华民族传统家庭美德（尊老爱幼、勤俭持家、知书达礼、遵纪守法，培育和弘扬社会主义核心价值观）；④家庭成员共同责任（提高自我管理能力，增强家庭责任意识）

## 第5课 和谐的师生关系
# S1 正向检索
教师是一个怎样的职业？###教师是一个神圣的职业，承担教书育人的使命；教师是履行教育教学职责的专业人员，是人类文明的传承者
老师对我们的成长有哪些作用？###老师是我们锤炼品格的引路人、学习知识的引路人、创新思维的引路人、奉献祖国的引路人（发挥不可替代的作用）
# S2 逆向检索
"师者，所以传道受业解惑也"说明教师承担什么使命？###教书育人的使命（教师对人类数千年文明的延续发挥着重要作用）
对我们提出"有理想信念、有道德情操、有扎实学识、有仁爱之心"要求的是？###新时代好老师（随着时代发展，老师不断改变工作理念和方式、提高自身素养）
# S3 要点默写
默写师生交往理想而美好的状态###彼此尊重、教学相长、携手共进；老师是我们敬重的长辈，是我们的良师益友，也是有血有肉、有喜怒哀乐的普通人，我们应主动理解、关心老师
默写正确对待老师表扬和批评的做法###对待表扬：戒骄戒躁、再接再厉，争取做得更好；对待批评：把注意力放在老师批评的内容上，理解老师的良苦用心（批评意味着关心、提醒和劝诫，帮助我们反省自己、完善自我）
# S4 综合默写
默写"珍惜师生情谊"的要点###师生理想状态（彼此尊重、教学相长、携手共进）；真诚接受老师的引领和指导（发自内心尊重老师、勤学好问积极主动）；正确对待表扬批评（表扬=肯定鼓励期待，批评=关心提醒劝诫）；尊重并适应不同风格的老师（年龄专业阅历性格差异导致方式不同，不同风格都有值得学习之处）

## 第6课 友谊之树常青
# S1 正向检索
友谊的真谛有哪些？###①友谊是一种亲密的关系；②友谊是一种心灵的相遇；③友谊是平等的、双向的
交友需要哪些智慧？###真诚和热情；慎重选择；关心和尊重对方；学会处理矛盾和冲突；讲原则
# S2 逆向检索
"人之相识，贵在相知；人之相知，贵在知心"体现友谊的什么特质？###友谊是一种心灵的相遇（可超越物质条件、家庭背景、学业成绩，实现心灵的沟通与契合）
友谊需要信任和忠诚，但不等于什么？###不加分辨地为朋友做任何事（当朋友做错事甚至误入歧途时，要坚持正确立场、不随波逐流，积极予以规劝）
# S3 要点默写
默写处理朋友间矛盾和冲突的五步策略###保持冷静（先稳定情绪，必要时冷处理）；坦诚交流（给彼此解释机会）；换位思考（从对方角度看问题）；及时处理（时间拖得越久问题越难解决）；勇担责任（错了真诚道歉，对方错了也要学会谅解）
默写"交友需要慎重选择"的内容###与品德高尚的人交朋友，有助于我们走好成长之路；无论是现实生活中的交友还是网上交友，都应学会理性辨别，做到慎交友、结好伴
# S4 综合默写
默写"交友的智慧"完整要点###志趣相投（互相鼓励、互相切磋、互相劝勉）；真诚热情（敞开心扉、主动表达、热情待人）；慎重选择（品德高尚、理性辨别、慎交友结好伴）；关心尊重（以行动表达关心、把握界限分寸、不替朋友做决定）；处理矛盾冲突（保持冷静/坦诚交流/换位思考/及时处理/勇担责任）；讲原则（不加分辨为朋友做任何事，坚持立场、积极规劝）

## 第7课 在集体中成长
# S1 正向检索
集体生活对我们有什么作用？###带给我们温暖；有助于我们学会与人交往；有助于培养我们的责任感；有助于我们发展个性；集体是我们共同成长的园地
建设美好集体有哪些要求？###确定共同的愿景；树立主人翁意识；营造和谐有序的集体环境；树立正确的合作与竞争观念；坚持集体主义原则
# S2 逆向检索
集体中"人与人之间的差异"被比作什么？###我们发展个性的"明镜"（在集体中学习他人的优点，有助于不断完善自己）
当个人利益与集体利益发生冲突时应该怎么办？###把集体利益放在个人利益之上（同时充分重视和保障个人的正当利益，促进集体和个人不断发展）
# S3 要点默写
默写集体生活的温暖如何获得###集体生活能带给我们温暖；一般来说，集体的联结度越高，个体感受到的温暖就越多；集体成员间的相互体贴、团结互助，传递着关爱和温暖，让我们获得安全感和归属感
默写美好集体的共同愿景###拥有共同的梦想，向往美好的未来，承担共同的使命，认同正确的价值观，形成一致的目标和追求；共同的愿景引领集体成员团结一致，开拓进取
# S4 综合默写
默写"共建美好集体"五大要求###①确定共同的愿景（精神动力之源、内驱力）；②树立主人翁意识（主动作为、各负其责、各尽其能）；③营造和谐有序的集体环境（遵守规则、推己及人多些宽容理解、弘扬正气抵制欺凌）；④树立正确的合作与竞争观念（敢于竞争、勇于挑战，善于合作、共同进步）；⑤坚持集体主义原则（集体利益优先、保障个人正当利益）

怎样敬畏生命？###①尊重并遵循生命存在和发展的规律；②关爱他人的生命；③坚持人民至上、生命至上
# S2 逆向检索
"仁者爱人""推己及人"体现的敬畏生命要求是？###关爱他人的生命（既要珍惜自己的生命，又要关爱他人的生命，尊重、关怀和善待他人）
"生命重于泰山"体现哪个敬畏生命的要求？###坚持人民至上、生命至上（每个人的生命都比金钱、权势等身外之物更为重要）

默写"每个人的生命都是不可逆的"告诉我们什么###生命的时光一去不复返（从婴孩到儿童、青少年、中年、老年），我们要珍惜生命的每一天
默写怎样正确对待有限的生命###我们应感恩生命的获得，把有限的生命投入到无限的奋斗和奉献之中，让生命的每一段历程都变得精彩和有意义
# S4 综合默写
默写"认识生命"的完整知识链###生命是大自然的奇迹、地球上最珍贵的财富；生命特点：独特（不可替代）/不可逆（一去不复返）/有限（生老病死无法抗拒）/代代接续（"我"的生命也是"我们"的生命）；精神生命不断传承（伟大的思想、崇高的信仰、高尚的道德）

## 第10课 保持身心健康
# S1 正向检索
怎样爱护身体？###①关注自己的身体状况；②养成健康的生活方式；③积极、主动、科学地锻炼身体，强健体魄
怎样滋养心灵？###①保持心理健康；②磨炼意志，增强生命韧性；③不断丰富自己的精神世界
# S2 逆向检索
"饮食有节、起居有常、动静结合，杜绝不良嗜好"属于爱护身体的哪个方面？###养成健康的生活方式（自觉自律）
良好的生命状态由什么构成？###健康的身体 + 健康的心理 + 丰富的精神（拥有健康、和谐的内心世界是幸福生活的重要支柱）
# S3 要点默写
默写爱护身体"关注身体状况"的做法###关注并记录自身健康状况，定期体检，合理利用卫生保健服务维护自身健康；积极主动获取健康信息，知道生理健康的基本标准，能够判断自己的身体是否处于正常状态；如有不适，应及时科学就医

# S4 综合默写

## 第12课 端正人生态度

## 第13课 实现人生价值
# S1 正向检索
什么是人生价值？###人生价值是指人的生命和活动对自己、他人和社会所具有的积极意义；人生价值是通过劳动创造的
怎样在奉献中成就精彩人生？###把个人小我融入时代、融入祖国和人民的大我之中；立足岗位作奉献；在奉献中走向伟大；在踏实奋进中绽放人生的光彩
# S2 逆向检索

"劳动最光荣、劳动最崇高、劳动最伟大、劳动最美丽"属于哪个方面？###青少年弘扬劳动精神的要求（崇尚劳动、尊重劳动，长大后能够辛勤劳动、诚实劳动、创造性劳动）

默写"立足岗位作奉献"的内容###任何一项工作都是社会存在和发展的需要，没有高低贵贱之分；人们在自己的岗位上勤勤恳恳、兢兢业业，在奉献社会中创造自身价值
# S4 综合默写
默写"实现人生价值"完整知识链###①在劳动中创造人生价值（价值含义/劳动创造物质精神财富/贡献是衡量尺度）；②在奉献中成就精彩人生（小我融入大我/立足岗位作奉献/在奉献中走向伟大/在踏实奋进中绽放光彩）；③弘扬劳动精神（劳动最光荣最崇高最伟大最美丽，辛勤劳动、诚实劳动、创造性劳动）
