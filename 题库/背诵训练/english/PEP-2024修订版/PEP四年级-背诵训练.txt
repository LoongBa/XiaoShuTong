# 小学PEP四年级 英语 背诵训练题库（分阶检索法）
# 教材：人教PEP版 2024 修订版（三年级起点）
# 题型：# S1 正向检索 / # S2 逆向检索 / # S3 要点默写 / # S4 综合默写
# 格式：题目###答案（# 开头为注释）
# 用法：✕→S1 跟读 | △→S1/S2 | ○→S2/S3 | ★→S4

# ===== 四年级上册 =====

## Unit 1 My classroom
# S1 正向检索
教室用英语怎么说？###classroom
窗户用英语怎么说？###window
门用英语怎么说？###door
# S2 逆向检索
classroom 这是什么场所的英语？###教室
window 这是什么物品的英语？###窗户
# S3 要点默写
默写"教室里有什么？"的英语表达###What's in the classroom?
