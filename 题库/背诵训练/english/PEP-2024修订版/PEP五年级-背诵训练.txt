# 小学PEP五年级 英语 背诵训练题库（分阶检索法）
# 教材：人教PEP版 2024 修订版（三年级起点）
# 题型：# S1 正向检索 / # S2 逆向检索 / # S3 要点默写 / # S4 综合默写
# 格式：题目###答案（# 开头为注释）
# 用法：✕→S1 跟读 | △→S1/S2 | ○→S2/S3 | ★→S4

# ===== 五年级上册 =====

## Unit 1 What's he like?
# S1 正向检索
年长的用英语怎么说？###old
年轻的用英语怎么说？###young
滑稽的用英语怎么说？###funny
和蔼的用英语怎么说？###kind
# S2 逆向检索
old 这是什么特征的英语？###年长的
young 这是什么特征的英语？###年轻的
# S3 要点默写
默写"他/她是什么样的人？"的英语表达###What's he/she like?
