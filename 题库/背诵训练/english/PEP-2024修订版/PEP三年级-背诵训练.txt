# 小学PEP三年级 英语 背诵训练题库（分阶检索法）
# 教材：人教PEP版 2024 修订版（三年级起点）
# 题型：# S1 正向检索 / # S2 逆向检索 / # S3 要点默写 / # S4 综合默写
# 格式：题目###答案（# 开头为注释）
# 用法：✕→S1 跟读 | △→S1/S2 | ○→S2/S3 | ★→S4

# ===== 三年级上册 =====

## Unit 1 Hello!
# S1 正向检索
你好用英语怎么说？###Hello! / Hi!
再见用英语怎么说？###Goodbye! / Bye!
# S2 逆向检索
Hello! / Hi! 这是什么的英语表达？###你好
Goodbye! / Bye! 这是什么的英语表达？###再见
# S3 要点默写
默写"我叫..."的英语表达###I'm... / My name is...
