# ===== 第一单元 中华人民共和国成立和社会主义制度建立 =====

## 第1课 中华人民共和国成立
# S1 正向检索
中国人民政治协商会议第一届全体会议召开的时间和地点？###1949年9月，在北平召开
《共同纲领》的历史地位是？###新中国的建国纲领，具有临时宪法的作用
# S2 逆向检索
1949年10月1日下午3时在天安门广场举行的盛典是？###开国大典（毛泽东宣告"中华人民共和国中央人民政府今天成立了"）
1951年10月人民解放军进驻拉萨，标志什么？###西藏和平解放，祖国大陆获得完全统一
# S3 要点默写
默写新中国成立的历史意义###彻底结束了旧中国半殖民地半封建社会的历史，彻底废除了列强强加给中国的不平等条约和帝国主义在中国的一切特权，实现了中国从几千年封建专制政治向人民民主的伟大飞跃；中国人民从此站起来了，中国发展从此开启了新纪元
默写政协一届全体会议的重要决定###定都北平并改名为北京；采用公元纪年；以《义勇军进行曲》为国歌；以五星红旗为国旗；选举中央人民政府委员会（毛泽东为主席）；建立人民英雄纪念碑
# S4 综合默写
默写"中华人民共和国成立的过程"###1949年9月政协一届全体会议筹备（通过《共同纲领》、定都改名、国歌国旗）→1949年10月1日开国大典宣告成立→成立意义（四个彻底/新纪元/改变世界政治格局）→1951年西藏和平解放实现祖国大陆完全统一

## 第2课 巩固人民民主政权
# S1 正向检索
《中华人民共和国土地改革法》颁布的时间和内容是？###1950年；废除地主阶级封建剥削的土地所有制，实行农民的土地所有制
抗美援朝战争的司令员和政治委员是？###彭德怀
# S2 逆向检索
1950年10月应朝鲜党和政府请求入朝作战的部队是？###中国人民志愿军（抗美援朝、保家卫国）
彻底摧毁我国存在2000多年封建土地制度的运动是？###土地改革（1950—1952年底全国大陆基本完成）
# S3 要点默写
默写土地改革的意义###彻底摧毁了我国存在2000多年的封建土地制度，消灭了地主阶级；农民翻了身，得到土地，成为土地的主人；解放了农村生产力，为国家的工业化建设准备了条件
默写抗美援朝战争的伟大意义###抵御了帝国主义侵略扩张，捍卫了新中国安全，保卫了中国人民和平生活；稳定了朝鲜半岛局势，维护了亚洲和世界和平，彰显了新中国的大国地位；是中国人民站起来后屹立于世界东方的宣言书，是中华民族走向伟大复兴的重要里程碑
默写抗美援朝英雄人物###杨根思、黄继光、邱少云、罗盛教等30多万名英雄功臣和近6000个功臣集体；他们被誉为"最可爱的人"
# S4 综合默写
默写"巩固人民民主政权的三大措施"###土地改革（1950年《土地改革法》，1952年底完成，废除封建土地制度）+镇压反革命（1950—1951年扫除反革命残余）+抗美援朝（1950年10月—1953年7月，彭德怀指挥，打败侵略者）

## 第3课 社会主义制度建立
# S1 正向检索
第一个五年计划的基本任务是？###集中主要力量发展重工业，建立国家工业化和国防现代化的初步基础；相应发展交通运输业、轻工业、农业和商业，相应培养建设人才
赎买政策的意义是？###实现了和平过渡，是中国社会主义改造的创举
# S2 逆向检索
1957年建成、结束长江"有舟无桥"历史的大桥是？###武汉长江大桥
1954年9月通过《中华人民共和国宪法》的会议是？###第一届全国人民代表大会第一次会议
# S3 要点默写
默写一五计划的重大成就###鞍山钢铁公司三大工程、长春第一汽车制造厂、沈阳第一机床厂和飞机制造厂；新建宝成、鹰厦铁路，川藏、青藏、新藏公路；1957年武汉长江大桥建成；到1957年底超额完成，初步奠定社会主义工业化基础
默写三大改造的方式###农业参加农业生产合作社；手工业参加手工业生产合作社；资本主义工商业实行加工订货和公私合营，国家对资本家占有的生产资料实行赎买政策
默写1954年宪法确立的政治制度###以国家根本法的形式确立人民代表大会制度（根本政治制度）；人民政协制度、民族区域自治制度（基本政治制度）为人民当家作主提供制度保证
# S4 综合默写
默写"社会主义制度建立的三条线索"###一五计划（1953—1957年，重工业，奠定工业化基础）→三大改造（1956年基本完成，社会主义经济制度建立）→1954年宪法与三大政治制度确立（社会主义政治制度）；1956年社会主义制度在我国建立起来，是历史上最为广泛而深刻的社会变革

## 第4课 独立自主的和平外交
# S1 正向检索
和平共处五项原则是哪一年提出的？内容？###1953年底周恩来在接见印度代表团时首次提出；互相尊重主权和领土完整、互不侵犯、互不干涉内政、平等互利、和平共处
"求同存异"方针是在哪次国际会议上提出的？###1955年印度尼西亚万隆会议（亚非会议）
# S2 逆向检索
新中国"站在社会主义和世界和平民主阵营一边"的外交方针是？###"一边倒"
第一个宣布承认中华人民共和国并与我国建交的国家是？###苏联（1949年10月）
# S3 要点默写
默写新中国三条外交方针###"另起炉灶"——不承认国民党政府同各国建立的旧的外交关系，取消帝国主义在华特权；"打扫干净屋子再请客"——把帝国主义在中国的残余势力清除干净之后再考虑建交；"一边倒"——明确宣布新中国站在社会主义和世界和平民主阵营一边
默写和平共处五项原则的意义###成为中国对外政策的基石，是国际关系史上的重大创举，为推动建立公正合理的国际政治经济秩序作出了历史性贡献
# S4 综合默写
默写"新中国成立初期外交成就"###第一条建交高潮（同苏联等十几个国家建交，粉碎孤立封锁）→1950年《中苏友好同盟互助条约》→1953年底和平共处五项原则→1954年日内瓦会议（五大国身份）→1955年万隆会议"求同存异"

## 第5课 艰辛探索与曲折发展
# S1 正向检索

# S2 逆向检索

# ===== 第三单元 改革开放与中国特色社会主义的开创 =====

## 第8课 伟大的历史转折
# S1 正向检索

中共十一届三中全会召开的时间和作出的历史性决策是？###1978年12月；把全党工作重点转移到社会主义现代化建设上来、实行改革开放
# S2 逆向检索
1978年5月《光明日报》发表的文章是？###《实践是检验真理的唯一标准》
"两个凡是"方针的实质问题是什么？###凡是毛主席作出的决策、凡是毛主席的指示都必须维护遵循，其推行引起普遍不满
# S3 要点默写
默写中共十一届三中全会的内容###思想上冲破长期"左"的错误的严重束缚，彻底否定"两个凡是"；政治上果断结束"以阶级斗争为纲"；重新确立马克思主义的思想路线、政治路线、组织路线；作出把工作重点转移到社会主义现代化建设上来、实行改革开放的历史性决策
默写拨乱反正的成果###平反冤假错案全面推开（到1982年底300多万名干部冤假错案得到平反）；1980年彻底推翻强加给刘少奇的种种罪名；1981年《关于建国以来党的若干历史问题的决议》标志指导思想上的拨乱反正胜利完成
# S4 综合默写
默写"伟大的历史转折"###背景（文化大革命后百废待兴、"两个凡是"束缚）→思想先导（真理标准问题大讨论1978年5月）→转折（十一届三中全会1978年12月：工作重心转移+改革开放）→拨乱反正（平反冤假错案+历史问题决议）→新时期（改革开放和社会主义现代化建设新时期开启）

## 第9课 改革开放的起步
# S1 正向检索
农村家庭联产承包责任制的主要形式是？###包产到户、包干到户（到1983年在农村普遍实行）
1980年兴办的四个经济特区是？###深圳、珠海、汕头、厦门（在广东、福建两省兴办）
# S2 逆向检索
1978年率先实行包干到户、自负盈亏的村庄是？###安徽凤阳小岗村
克服吃"大锅饭"弊病、扩大企业自主权的城市改革是什么？###城市经济体制改革初步展开（1979年首都钢铁公司等8家大型企业试点）
# S3 要点默写
默写家庭联产承包责任制的内容和意义###在土地公有制基础上，把集体所有的土地长期包给各家各户使用，分户经营、自负盈亏（"保证国家的，留足集体的，剩下都是自己的"）；激发农民生产积极性，带来农村生产力大解放；乡镇企业异军突起，为农民致富和实现现代化开辟新路
默写经济特区的地位###兴办经济特区是党和国家为推进改革开放和社会主义现代化建设进行的伟大创举；敢闯敢试、敢为人先、埋头苦干的特区精神彰显
# S4 综合默写
默写"改革开放的起步"###农村改革（1978年小岗村包干到户→1983年全国推开家庭联产承包责任制→乡镇企业异军突起）→城市改革（1979年扩大企业自主权试点）→对外开放（1980年四个经济特区）→外交政策调整（1978年中日和平友好条约、1979年中美建交、1985年和平和发展是当代世界两大问题）
