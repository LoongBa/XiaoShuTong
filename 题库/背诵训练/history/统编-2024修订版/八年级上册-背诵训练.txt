# ===== 第一单元 中国开始沦为半殖民地半封建社会 =====

## 第1课 鸦片战争
# S1 正向检索
虎门销烟的时间、主持人和意义是？###1839年6月3日至25日，林则徐主持在虎门海滩当众销毁鸦片；是中国人民禁烟斗争的伟大胜利，显示了中华民族反抗外来侵略的坚强意志
鸦片战争爆发的时间是？###1840年6月，英国舰队封锁广东珠江口，鸦片战争爆发
# S2 逆向检索
《南京条约》中割让给英国的中国领土是？###香港岛
中国近代史的开端是？###鸦片战争（中国开始沦为半殖民地半封建社会）
# S3 要点默写
默写《南京条约》的主要内容###开放广州、福州、厦门、宁波、上海五处为通商口岸；割香港岛给英国；赔偿英国2100万银元；英商进出口货物应纳的税款必须经过双方协议
默写鸦片战争中殉国的爱国将领###关天培（虎门炮台，广东水师提督）、葛云飞/王锡朋/郑国鸿（定海三总兵）、陈化成（吴淞）、海龄（镇江）
# S4 综合默写
默写"鸦片战争的影响"###中国独立主权的完整性遭到破坏，传统小农经济逐步瓦解，中国开始沦为半殖民地半封建社会；帝国主义与中华民族、封建主义与人民大众的矛盾成为近代中国社会主要矛盾；鸦片战争成为中国近代史的开端

# S2 逆向检索

# S3 要点默写

默写1861年清政府设立的中央机构###总理各国事务衙门（总理衙门），负责对外交涉以及通商、海关等事务
# S4 综合默写

## 第3课 太平天国运动
# S1 正向检索
金田起义的时间和地点是？###1851年1月11日，洪秀全在广西桂平金田村发动武装起义，建号太平天国
《天朝田亩制度》的核心内容是？###不分男女，按人口和年龄平均分配土地，建立"有田同耕，有饭同食，有衣同穿，有钱同使"的理想社会
# S2 逆向检索
1856年秋太平天国由盛转衰的标志是？###天京事变
1864年天京陷落标志着什么？###太平天国运动失败
# S3 要点默写
默写《天朝田亩制度》的评价###反映了千百年来农民要求得到土地的强烈愿望，对发动和鼓舞农民参加反封建斗争起了积极作用；带有浓厚的空想色彩，在长期战争环境下未能推行
默写洪仁玕《资政新篇》###提出向西方学习、改革内政等一系列主张，得到洪秀全赞赏；受当时历史条件限制，未能付诸实践
# S4 综合默写
默写"太平天国运动的意义与局限"###意义：中国历史上一次规模宏大的农民战争，坚持斗争14年，转战大半个中国，沉重打击了清朝的统治和外国侵略势力；局限：由于农民阶级的局限性（无法提出切合实际的革命纲领、无法制止领导集团腐败、无法保持团结），在中外反动势力联合镇压下最终失败

# ===== 第二单元 早期现代化的初步探索和民族危机加剧 =====

## 第4课 洋务运动和边疆危机
# S1 正向检索
洋务运动的时间和口号是？###19世纪60年代到90年代中期；前期以"自强"为口号，70年代起又提出"求富"主张
洋务派创办的军事工业和民用企业各举两例？###军事工业：江南机器制造总局、福州船政局；民用企业：轮船招商局、开平煤矿、汉阳铁厂、湖北织布局
# S2 逆向检索
采取"先北后南、缓进急战"策略收复新疆的将领是？###左宗棠（1878年消灭阿古柏侵略势力）
1885年在镇南关大捷中抗法的老将是？###冯子材
# S3 要点默写
默写中法战争后清政府采取的措施###1884年根据左宗棠建议在新疆建立行省（"故土新归"）；1885年建立台湾行省（加强海防、强化治理）
默写洋务运动的结果与评价###经过30多年建设，客观上促进了中国民族资本主义的产生；由于清朝政治的腐败和外国势力的挤压，求强求富的目标没有实现，是中国早期现代化的初步探索
# S4 综合默写
默写"19世纪中后期的边疆危机"###东南海疆：美国觊觎、日本1874年侵台（勒索50万两后撤兵）、1879年吞并琉球改设冲绳县；西北：1865年阿古柏入侵新疆、沙俄1871年占伊犁；西南：英法侵略越南后法国把矛头指向中国（中法战争）；结局：1884年新疆建省、1885年台湾建省

# S2 逆向检索

# S3 要点默写
默写《马关条约》的主要内容###割辽东半岛、台湾全岛及所有附属各岛屿、澎湖列岛给日本；赔偿日本军费白银2亿两；开放沙市、重庆、苏州、杭州为通商口岸；日本可在中国通商口岸开设工厂

# S4 综合默写
默写"《马关条约》的影响"###领土主权严重破坏；巨额赔款迫使清政府大举外债，遭列强进一步控制；外国侵略势力深入中国腹地，加紧资本输出；中国的半殖民地化程度大大加深；清政府放松民间设厂限制，民族资本主义得到初步发展

# S2 逆向检索

# S3 要点默写

# S4 综合默写
默写"辛亥革命的意义与局限"###意义：推翻清王朝统治，宣告两千多年君主专制制度终结，拉开完全意义上的近代民族民主革命序幕，极大推动中华民族思想解放；局限：没有解决近代中国社会的主要矛盾，没有完成民族独立、人民解放的历史任务，半殖民地半封建的社会性质没有改变
