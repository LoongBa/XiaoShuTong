# ===== D1 人体营养 =====

## 六大营养物质
# S1 正向检索
人体主要的供能物质是？###糖类
建造和修复身体的重要原料是？###蛋白质
# S2 逆向检索
备用能源物质是？###脂肪
提供能量的物质主要有哪些？###糖类、脂肪、蛋白质
# S3 要点默写
默写六大营养物质###糖类、脂肪、蛋白质、水、无机盐、维生素
# S4 综合默写
默写糖类/脂肪/蛋白质的功能###糖类主要供能、脂肪备用能源、蛋白质建造修复身体

## 消化与吸收
# S1 正向检索
消化和吸收的主要场所是？###小肠
淀粉最终分解为？###葡萄糖
# S2 逆向检索
葡萄糖是哪种物质消化后的产物？###淀粉（糖类）
氨基酸是哪种物质消化后的产物？###蛋白质
# S3 要点默写
默写小肠适于消化吸收的结构特点###长5-6米、有环形皱襞和小肠绒毛、绒毛壁一层上皮细胞

# ===== D2 人体呼吸 =====

## 呼吸道与肺
# S1 正向检索
呼吸道的组成是？###鼻→咽→喉→气管→支气管
肺进行气体交换的主要结构是？###肺泡
# S2 逆向检索
鼻、咽、喉、气管、支气管共同组成了什么？###呼吸道
# S3 要点默写
默写肺泡适于气体交换的特点###数量多、壁薄（一层上皮细胞）、外包绕毛细血管

## 呼吸运动
# S1 正向检索
吸气时肋间肌和膈肌的状态？###收缩，胸廓扩大，肺扩张，肺内气压降低
# S2 逆向检索
呼气时胸廓如何变化？###胸廓缩小，肺回缩，肺内气压升高

# ===== D3 血液循环 =====

## 血液与血管
# S1 正向检索
运输氧气的血细胞是？###红细胞
吞噬病菌的血细胞是？###白细胞
# S2 逆向检索
含血红蛋白、运输氧气的是？###红细胞
止血凝血的是？###血小板
# S3 要点默写
默写血液的组成###血浆和血细胞（红细胞、白细胞、血小板）

## 心脏与循环途径
# S1 正向检索
体循环的途径是？###左心室→主动脉→全身→上下腔静脉→右心房
肺循环的途径是？###右心室→肺动脉→肺→肺静脉→左心房
# S2 逆向检索
体循环中血液的变化？###动脉血变为静脉血
肺循环中血液的变化？###静脉血变为动脉血
# S3 要点默写
默写心脏的四个腔###左心房、左心室、右心房、右心室
# S4 综合默写
默写体循环与肺循环的起点终点###体循环：左心室→右心房；肺循环：右心室→左心房

## 动脉血与静脉血
# S1 正向检索
动脉血的特点是？###含氧丰富、颜色鲜红
# S2 逆向检索
含氧少、颜色暗红的是？###静脉血
# S3 要点默写
默写区分动脉血静脉血的关键###看含氧量，不看血管名称（"肺反体同"）

# ===== D4 废物排出 =====

## 泌尿系统
# S1 正向检索
泌尿系统的组成？###肾脏、输尿管、膀胱、尿道
肾单位由哪三部分组成？###肾小球、肾小囊、肾小管
# S2 逆向检索
形成尿液的主要器官是？###肾脏
# S3 要点默写
默写尿的形成过程###肾小球滤过形成原尿→肾小管重吸收形成尿液
默写肾小管重吸收的物质###全部葡萄糖、大部分水、部分无机盐
# S4 综合默写
默写排泄的三条途径###呼吸系统（CO₂和水）、皮肤（汗液）、泌尿系统（尿液）

# ===== D5 神经调节 =====

## 神经系统与反射
# S1 正向检索
神经系统的组成？###脑（大脑、小脑、脑干）、脊髓、神经
人体神经调节的基本方式是？###反射
# S2 逆向检索
反射的结构基础是？###反射弧
协调运动、维持平衡的是？###小脑
# S3 要点默写
默写反射弧的组成###感受器→传入神经→神经中枢→传出神经→效应器
# S4 综合默写
默写简单反射与复杂反射的区别###简单反射生来就有（中枢在脊髓/脑干）；复杂反射后天学习（中枢在大脑皮层）

## 视觉与听觉
# S1 正向检索
近视的成因及矫正？###晶状体曲度过大或眼球前后径过长，物像落在视网膜前方，用凹透镜矫正
# S2 逆向检索
物像落在视网膜后方是什么眼？###远视（凸透镜矫正）
# S3 要点默写
默写视觉形成的过程###光线→角膜→瞳孔→晶状体→玻璃体→视网膜→视神经→大脑皮层视觉中枢

# ===== D6 激素调节 =====

## 内分泌腺与激素
# S1 正向检索

胰岛素分泌不足导致？###糖尿病
# S2 逆向检索
幼年甲状腺激素不足导致？###呆小症
甲亢是由于什么激素过多？###甲状腺激素
# S3 要点默写
默写主要内分泌腺及其激素###垂体-生长激素、甲状腺-甲状腺激素、胰岛-胰岛素
# S4 综合默写
默写侏儒症与呆小症的区别###侏儒症智力正常（生长激素不足），呆小症智力低下（甲状腺激素不足）

# ===== D8 免疫与健康 =====

预防传染病的三个措施？###控制传染源、切断传播途径、保护易感人群
# S2 逆向检索
能够散播病原体的人或动物是？###传染源

# S3 要点默写

# S1 正向检索
特异性免疫的过程？###抗原→刺激淋巴细胞→产生抗体
# S2 逆向检索

# S3 要点默写
