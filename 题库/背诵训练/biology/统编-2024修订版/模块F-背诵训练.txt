# ===== 第一章 生态系统 =====

## 第1节 生物与环境的相互作用
# S1 正向检索
生态因素分为哪两类？###非生物因素和生物因素
非生物因素包括？###光、温度、水、空气等
# S2 逆向检索
影响小麦生活的光、温度、水属于？###非生物因素
影响某种生物生活的其他生物属于？###生物因素
# S3 要点默写
默写生物对环境的适应实例###骆驼刺深根（干旱）、北极熊白毛（冰雪）、保护色、警戒色、拟态
默写生物对环境的影响实例###蚯蚓疏松土壤、植物蒸腾增加湿度、森林调节气候
# S4 综合默写
默写"生物与环境的关系"###环境（非生物+生物因素）影响生物；生物适应环境并影响环境；适者生存

## 第2节 生态系统的结构和功能
# S1 正向检索
生态系统的组成？###生物部分（生产者/消费者/分解者）+非生物部分（阳光空气水温度）
食物链的书写规则？###以生产者为起点，箭头指向捕食者；只含生产者和消费者
# S2 逆向检索
通过光合作用制造有机物的绿色植物是？###生产者
将有机物分解为无机物的细菌真菌是？###分解者
# S3 要点默写
默写食物链举例###草→鼠→蛇→鹰（生产者→初级消费者→次级消费者→三级消费者）
默写生态系统能量流动特点###单向流动、逐级递减
默写生态系统自我调节能力###生物种类越多、营养结构越复杂，自我调节能力越强，但有一定限度
# S4 综合默写
默写"生态系统的组成与功能"###组成：生产者（植物）+消费者（动物）+分解者（细菌真菌）+非生物部分；功能：能量单向逐级递减流动、物质反复循环

## 第3节 生物圈
# S1 正向检索
生物圈的范围？###大气圈的底部、水圈的大部、岩石圈的表面
生物圈是最大的生态系统吗？###是（地球上所有生物与其环境的总和）
# S2 逆向检索
"绿色水库""地球之肺"指？###森林生态系统
"地球之肾"指？###湿地生态系统
# S3 要点默写
默写生物圈为生物生存提供的基本条件###营养物质、阳光、空气、水、适宜的温度、一定的生存空间

# ===== 第二章 生态安全 =====

## 第4节 人类活动对生态环境的影响
# S1 正向检索
温室效应的成因？###大量燃烧化石燃料、砍伐森林使大气二氧化碳增多
酸雨的成因？###工厂排放二氧化硫、氮氧化物与水结合形成
# S2 逆向检索
水葫芦、加拿大一枝黄花属于？###外来物种入侵（破坏生态平衡）
# S3 要点默写
默写温室效应和酸雨的危害###温室：气候变暖、冰川融化、海平面上升；酸雨：腐蚀建筑物、土壤酸化、危害生物
默写外来物种入侵的危害###缺乏天敌疯长、排挤本地物种、破坏生态平衡

## 第5节 维护生态安全
# S1 正向检索
生态安全的概念？###生态系统的健康和完整情况，是生产生活所需的基本生态环境保障
维护生态安全的措施？###植树造林、退耕还林还草、保护湿地、治理污染、低碳生活
# S2 逆向检索
个人可做的环保行动？###节约用水用电、垃圾分类、绿色出行、减少一次性用品
