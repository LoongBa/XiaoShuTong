# ===== 第一单元 生物和生物圈 =====

## 第1课 认识生物
# S1 正向检索
生物的共同特征有哪些？###生活需要营养、能呼吸、能排出废物、能对外界刺激反应、能生长繁殖、有遗传变异、由细胞构成（除病毒外）
# S2 逆向检索
生活需要营养、能呼吸、能繁殖，这些是什么的特征？###生物
# S3 要点默写
默写生物与非生物的根本区别###生物具有生命特征

## 第2课 了解生物圈
# S1 正向检索
生态系统的组成是？###生物部分（生产者、消费者、分解者）和非生物部分（阳光、空气、水等）
食物链的书写规则是？###起点是生产者，箭头指向捕食者，不包括分解者和非生物部分
# S2 逆向检索
生产者、消费者、分解者和非生物部分组成的整体是？###生态系统
# S3 要点默写
默写生产者、消费者、分解者的区别###生产者：绿色植物；消费者：动物；分解者：细菌真菌
默写生物圈的范围###大气圈底部、水圈大部、岩石圈表面
# S4 综合默写
默写"生态系统的组成"###生物部分：生产者（植物）+消费者（动物）+分解者（细菌真菌）；非生物部分：阳光空气水等

# ===== 第二单元 生物体的结构层次 =====

## 第3课 观察细胞的结构
# S1 正向检索
显微镜的使用步骤是？###取镜安放→对光→观察→收镜
植物细胞与动物细胞的区别是？###植物细胞有细胞壁、液泡、叶绿体
# S2 逆向检索
取镜安放→对光→观察→收镜，这是什么的操作步骤？###显微镜
# S3 要点默写
默写植物细胞的基本结构###细胞壁、细胞膜、细胞质、细胞核、液泡、叶绿体
默写动物细胞的基本结构###细胞膜、细胞质、细胞核
默写细胞壁的功能###保护和支持细胞
默写细胞核的功能###含有遗传物质，是细胞生命活动的控制中心
# S4 综合默写
默写"植物细胞与动物细胞的区别"###植物有细胞壁液泡叶绿体，动物没有

## 第4课 细胞的生活
# S1 正向检索
细胞中的能量转换器有？###叶绿体和线粒体
叶绿体的功能是？###将光能转变成化学能，储存在有机物中
# S2 逆向检索
将光能转变成化学能的是？###叶绿体
# S3 要点默写
默写线粒体的功能###将有机物中的化学能释放出来，供细胞利用
默写细胞核是控制中心的原因###含有遗传物质（DNA），能传递遗传信息
# S4 综合默写
默写"细胞中的能量转换器"###叶绿体（光能→化学能）和线粒体（化学能→细胞能利用的能量）

## 第5课 细胞怎样构成生物体
# S1 正向检索
细胞分裂的意义是？###使细胞数目增多
细胞分化的结果是？###形成了不同的组织
# S2 逆向检索
使细胞数目增多的是？###细胞分裂
形成不同组织的是？###细胞分化
# S3 要点默写
默写人体的四种基本组织###上皮组织、肌肉组织、神经组织、结缔组织
默写植物体的主要组织###保护组织、营养组织、输导组织、分生组织
默写生物体的结构层次（动物）###细胞→组织→器官→系统→个体
默写生物体的结构层次（植物）###细胞→组织→器官→个体（没有系统）
# S4 综合默写
默写"细胞分裂和分化的区别"###分裂：细胞数目增多；分化：形成不同组织

# ===== 第三单元 生物圈中的绿色植物 =====

## 第6课 绿色植物是生物圈中有机物的制造者
# S1 正向检索
光合作用的原料和产物是？###原料：二氧化碳和水；产物：有机物和氧气
呼吸作用的实质是？###分解有机物，释放能量
# S2 逆向检索
二氧化碳和水→有机物和氧气，这是什么过程？###光合作用
分解有机物释放能量的是？###呼吸作用
# S3 要点默写
默写光合作用的条件和场所###光、叶绿体
默写呼吸作用的场所###线粒体
默写光合作用与呼吸作用的关系###相互依存
# S4 综合默写
默写"光合作用和呼吸作用的比较"###光合：合成有机物储存能量，需光，叶绿体；呼吸：分解释放能量，有光无光都可，线粒体
