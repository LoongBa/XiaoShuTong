# ===== 第一章 生物的生殖 =====

## 第1节 无性生殖
# S1 正向检索
无性生殖的概念？###不经过两性生殖细胞的结合，由母体直接产生新个体
常见的无性生殖方式？###分裂生殖、出芽生殖、孢子生殖、营养生殖（扦插嫁接）
# S2 逆向检索
水螅、酵母菌的出芽生殖属于？###无性生殖
剪取枝条插入土壤长成新个体是？###扦插（无性生殖）
# S3 要点默写
默写嫁接成活的关键###使接穗与砧木的形成层紧密结合
默写无性生殖的特点###后代只具有母体遗传特性，能迅速繁殖后代
# S4 综合默写
默写"无性生殖在生产实践中的应用"###扦插（月季柳树）、嫁接（果树）、组织培养（快速繁殖、培育无病毒植株）

## 第2节 有性生殖
# S1 正向检索
有性生殖的概念？###经过两性生殖细胞结合形成受精卵，由受精卵发育成新个体
鸟卵中将来发育成雏鸡的结构是？###胚盘
# S2 逆向检索
卵→幼虫→蛹→成虫的发育方式是？###完全变态发育
体外受精、变态发育（离不开水）的是？###两栖动物（青蛙）
# S3 要点默写
默写完全变态与不完全变态的区别###完全变态有蛹期、幼虫与成虫差异大；不完全变态无蛹期、若虫与成虫形态相似
默写鸟卵各部分功能###卵壳保护、气室供氧、卵白供水分营养、卵黄供主要营养、胚盘含细胞核发育成雏
# S4 综合默写
默写"有性生殖的意义"###后代具有双亲遗传物质，变异性更强，有利于生物进化

# ===== 第二章 生物的遗传与变异 =====

## 第3节 基因的显性和隐性
# S1 正向检索
基因与性状的关系？###基因控制生物的性状
孟德尔豌豆杂交实验子二代显隐性状比例？###3:1
# S2 逆向检索
控制显性性状的基因是？###显性基因（大写字母）
纯合体（DD/dd）与杂合体（Dd）？###含相同基因的个体是纯合体，含不同基因的是杂合体
# S3 要点默写
默写孟德尔豌豆实验的结论###相对性状有显隐性之分；杂合体中隐性基因不表现但会遗传；子二代显隐比3:1
默写禁止近亲结婚的原因###近亲携带相同隐性致病基因概率大，后代患遗传病几率增加
# S4 综合默写
默写"基因的显性和隐性规律"###显性基因控制显性性状、隐性基因纯合才表现隐性性状；杂合体Dd表现显性但携带隐性基因

## 第4节 人的性别遗传
# S1 正向检索
人的体细胞染色体组成？###23对（22对常染色体+1对性染色体）
男性性染色体组成？###XY；女性是XX
# S2 逆向检索
含X精子与卵细胞结合发育成？###女孩（XX）
含Y精子与卵细胞结合发育成？###男孩（XY）
# S3 要点默写
默写生男生女的原因###由精子含有的性染色体决定；理论上生男生女比例1:1
# S4 综合默写
默写"人的性别遗传过程"###父亲XY产生X和Y两种精子、母亲XX只产生X卵细胞；X精子+卵细胞→女孩XX，Y精子+卵细胞→男孩XY

## 第5节 生物的变异
# S1 正向检索
变异的概念？###亲代与子代、子代个体之间在性状上的差异
可遗传变异与不可遗传变异的区别？###可遗传变异由遗传物质改变引起能遗传；不可遗传变异由环境引起不能遗传
# S2 逆向检索
基因突变引起的变异属于？###可遗传变异
光照不足使叶色发黄属于？###不可遗传变异
# S3 要点默写
默写变异的意义###为生物进化提供原始材料；使生物适应不断变化的环境
默写遗传育种的方法###人工选择、杂交育种（基因重组）、诱变育种（基因突变）
# S4 综合默写
默写"可遗传变异与不可遗传变异的区别"###遗传物质是否改变：改变→可遗传；未改变（仅环境）→不可遗传

# ===== 第三章 生物的进化 =====

## 第6节 生命的起源
# S1 正向检索
原始生命诞生的场所？###原始海洋
米勒实验证明了什么？###原始大气中的无机物在一定条件下能合成简单有机物（氨基酸）
# S2 逆向检索
不含氧气的原始大气成分是？###甲烷、氨、氢气、水蒸气等
# S3 要点默写
默写生命起源的化学进化过程###原始大气→简单有机物→复杂有机物→原始生命（原始海洋）

## 第7节 生物进化的历程
# S1 正向检索
研究生物进化的最重要证据？###化石
始祖鸟化石证明了什么？###鸟类由爬行动物进化而来
# S2 逆向检索
从简单到复杂、从低等到高等、从水生到陆生描述的是？###生物进化的总体趋势
# S3 要点默写
默写植物进化顺序###藻类→苔藓→蕨类→种子植物（裸子→被子）
默写动物进化顺序###无脊椎动物→脊椎动物（鱼类→两栖类→爬行类→鸟类/哺乳类）

## 第8节 生物进化的原因
# S1 正向检索
自然选择学说的四要素？###过度繁殖、生存斗争、遗传和变异、适者生存
自然选择的结果？###生物与环境相适应（生物的适应性）
# S2 逆向检索
适者生存、不适者被淘汰是？###自然选择（核心）
长颈鹿长颈形成的原因是？###自然选择（长颈变异个体能吃到高处食物生存下来并遗传）
# S3 要点默写
默写桦尺蛾体色变化实例说明的道理###自然选择使与环境颜色相似的变异类型生存下来并遗传（保护色形成）
默写自然选择与遗传变异的关系###遗传变异为自然选择提供原材料，自然选择保存有利变异
# S4 综合默写
默写"自然选择学说的要点"###过度繁殖→生存斗争→遗传变异→适者生存；核心是适者生存、不适者淘汰

# ===== 第四章 生物多样性及其保护 =====

## 第9节 生物多样性的内涵
# S1 正向检索
生物多样性的三个层次？###物种多样性、遗传多样性（基因多样性）、生态系统多样性
物种多样性的实质？###基因的多样性
# S2 逆向检索
一个物种就是一个独特的？###基因库
# S3 要点默写
默写物种灭绝的损失###该物种特有的基因信息无法继续传递，加速物种多样性和遗传多样性的丧失

## 第10节 生物多样性的保护
# S1 正向检索
生物多样性面临的主要威胁？###栖息地破坏（最主要）、过度捕猎采集、环境污染、外来物种入侵
保护生物多样性最有效的措施？###就地保护（建立自然保护区）
# S2 逆向检索
保护生物的栖息环境、保护生态系统多样性是？###保护生物多样性的根本措施
动物园、植物园、濒危物种繁育中心属于？###迁地保护
# S3 要点默写
默写保护生物多样性的措施###就地保护（自然保护区最有效）、迁地保护（动物园植物园）、法制管理、宣传教育
默写外来物种入侵的危害###破坏本地生态平衡、排挤本地物种、导致生物多样性下降
