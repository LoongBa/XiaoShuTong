# ===== 第七章 我们生活的大洲——亚洲 =====

## 第1节 自然环境
# S1 正向检索
亚洲的面积是多少？###约4400万平方千米，是世界面积最大的大洲
亚洲的地势特点是？###中部高、四周低
# S2 逆向检索
北、东、南三面依次濒临北冰洋、太平洋、印度洋的大洲是？###亚洲
季风气候显著、大陆性气候分布广、气候类型多样，这是哪个大洲的气候特点？###亚洲
# S3 要点默写
默写亚洲大河分布特点###多发源于中部山地、高原，呈放射状流向周边的海洋
默写亚洲气候三大特点###季风气候显著；大陆性气候分布广；气候类型多样
# S4 综合默写
默写"亚洲的自然环境特征"###面积最大（约4400万km²）；地势中部高四周低；大河呈放射状；气候季风显著+大陆性广+类型多样

## 第2节 人文环境
# S1 正向检索
亚洲人口稠密的地区有？###东亚、东南亚和南亚
2020年亚洲人口约多少？###46.4亿（世界人口最多的大洲）
# S2 逆向检索
以占世界1/3的陆地养活了占世界3/5的人口的是？###亚洲
# S3 要点默写
默写亚洲季风气候区和热带雨林气候区人口稠密的原因###地处中低纬度，气候适宜，离海洋较近，平均海拔较低，河流多；自然条件优越适宜农耕，农业开发历史悠久

# ===== 第八章 我们邻近的地区和国家 =====

## 第3节 日本
# S1 正向检索
日本多火山地震的原因是？###位于亚欧板块与太平洋板块交界地带，地壳活跃
日本工业的主要分布地区？###太平洋沿岸和濑户内海沿岸
# S2 逆向检索
由北海道、本州、四国、九州四个大岛组成的国家是？###日本
进口原料、出口产品的加工贸易型经济是哪个国家的经济特点？###日本
# S3 要点默写
默写日本工业集中分布太平洋沿岸的原因###原料燃料依靠进口；产品主要用于出口；城市和人口集中、是国内最大消费地；海岸线曲折多优良港湾
默写日本应对地震的措施###建筑采用轻质材料；定期举行防震演练；普及抗震知识
# S4 综合默写
默写"日本的地理特征"###岛国（四大岛）；多火山地震（板块交界）；山地丘陵为主；海洋性季风气候；加工贸易型经济、工业沿太平洋沿岸分布

## 第4节 东南亚
# S1 正向检索
马六甲海峡的重要性是？###西亚、非洲石油运输到东亚的重要通道，被称为"海上生命线"
东南亚主要的气候类型有？###热带雨林气候（马来群岛）和热带季风气候（中南半岛）
# S2 逆向检索
"十字路口"位置指哪个地区？###东南亚（亚洲与大洋洲、太平洋与印度洋之间）
山河相间、纵列分布的地形是哪个地区的特征？###中南半岛
# S3 要点默写
默写东南亚成为世界重要稻米出口地的原因###热带气候，水热充足；种植历史悠久；平原面积较大（河口三角洲）
默写中南半岛大城市沿河分布的原因###河流沿岸地形平坦、土壤肥沃、水源充足、交通便利
# S4 综合默写
默写"东南亚的地理位置与农业"###十字路口（马六甲海峡）；中南半岛+马来群岛；热带雨林/季风气候；水稻+天然橡胶/油棕/蕉麻/椰子

## 第5节 印度
# S1 正向检索
印度水旱灾害频繁的原因是？###西南季风不稳定
印度被称为"世界办公室"的原因是？###服务外包产业迅速发展
# S2 逆向检索
南亚面积最大的国家是？###印度
改进农业技术、推广高产良种以提高粮食产量，这是印度的？###"绿色革命"
# S3 要点默写
默写印度主要粮食作物的分布###水稻：东北部和沿海平原（降水多）；小麦：德干高原西北部（降水较少）
默写印度服务外包产业的特点###信息技术含量高、利润大、资源消耗少；中心是班加罗尔
# S4 综合默写
默写"印度农业与气候的关系"###热带季风气候（全年高温、分旱雨两季）；西南季风不稳定→水旱灾害频繁→影响农业；绿色革命提高产量

## 第6节 俄罗斯
# S1 正向检索
俄罗斯的主要气候类型是？###温带大陆性气候
西伯利亚大铁路的地位是？###世界最长的铁路
# S2 逆向检索
世界上面积最大的国家是？###俄罗斯
以铁路运输为主、重工业发达、资源基本自给的国家是？###俄罗斯
# S3 要点默写
默写俄罗斯被认为是欧洲国家的原因###欧洲部分面积仅占1/4，却集中全国约3/4的人口；一直是全国政治、经济和文化的中心地区；起源于欧洲
默写俄罗斯的自然资源特点###十分丰富，种类多、储量大，是世界少数几个资源基本自给的大国之一
# S4 综合默写
默写"俄罗斯的经济发展特点"###重工业发达、轻工业相对薄弱；石油天然气出口收入比重大；航天核技术先进；铁路运输为主（西伯利亚大铁路世界最长）

# ===== 第九章 东半球其他的地区和国家 =====

## 第7节 西亚
# S1 正向检索
西亚石油主要分布在？###波斯湾及其沿岸地区
霍尔木兹海峡的地位？###波斯湾沿岸地区唯一的出海通道，全球约1/3海上石油运输经过
# S2 逆向检索
"三洲五海"之地指？###西亚（亚欧非三洲之间，阿拉伯海、红海、地中海、黑海、里海之间）
波斯湾沿岸地区唯一的出海通道是？###霍尔木兹海峡
# S3 要点默写
默写西亚水资源匮乏的原因及对策###气候干旱、降水稀少；发展节水农业（以色列滴灌喷灌）、海水淡化
默写西亚成为热点地区的原因###地理位置重要、石油资源丰富、水资源匮乏、宗教文化差异大
# S4 综合默写
默写"西亚的自然环境与石油经济"###三洲五海之地；热带沙漠气候为主、水资源匮乏；石油分布在波斯湾沿岸、出口东亚/欧洲西部/北美；霍尔木兹海峡是唯一出海通道

## 第8节 欧洲西部
# S1 正向检索
欧洲西部畜牧业发达的原因是？###温带海洋性气候，全年温和湿润，适合多汁牧草生长
欧洲西部主要的气候类型有？###温带海洋性气候和地中海气候
# S2 逆向检索
牧草被称为"绿色金子"的地区是？###欧洲西部
发达国家集中的地区是？###欧洲西部
# S3 要点默写
默写温带海洋性气候的特点###全年温和湿润，降水均匀，适合多汁牧草生长
# S4 综合默写
默写"欧洲西部的经济特点"###发达国家集中；工业中心多、工艺水平高；农业机械化程度高；畜牧业发达（温带海洋性气候）；旅游业发达

## 第9节 撒哈拉以南非洲
# S1 正向检索
撒哈拉以南非洲的人种特点是？###黑种人的故乡（90%以上是黑种人）
撒哈拉以南非洲的经济特点？###历史上形成单一商品经济，近年来快速发展、走向多样化
# S2 逆向检索
被称为"高原大陆"、气候以赤道为中心南北对称分布的地区是？###撒哈拉以南非洲
黑种人的故乡是？###撒哈拉以南非洲
# S3 要点默写
默写撒哈拉以南非洲面临的主要问题###人口增长过快、粮食供应不足、环境恶化（三大问题）
默写单一商品经济的弊端###出口初级产品、进口工业制成品，在国际贸易中处于不利地位
# S4 综合默写
默写"撒哈拉以南非洲的自然与人文特征"###高原大陆；气候对称分布；黑种人故乡；单一商品经济→多样化发展；人口粮食环境问题突出

## 第10节 澳大利亚
# S1 正向检索
澳大利亚被称为"骑在羊背上的国家"的原因是？###养羊业发达，羊毛产量和出口量居世界前列
澳大利亚被称为"坐在矿车上的国家"的原因是？###煤炭和铁矿石产量、出口量居世界前列
# S2 逆向检索
世界上唯一独占一块大陆的国家是？###澳大利亚
有袋鼠、考拉、鸭嘴兽等特有动物的国家是？###澳大利亚
# S3 要点默写
默写澳大利亚特有动物多的原因###长期孤立于其他大陆，缺少大型食肉动物，演化出独特动植物
默写澳大利亚成为我国最大铁矿石进口国的原因###铁矿石储量全球首位、品质优、埋藏浅、开采成本低；距离我国最近、运输成本低
# S4 综合默写
默写"澳大利亚的农牧业与矿业"###骑在羊背上的国家（养羊业）+坐在矿车上的国家（煤铁出口）；气候半环状分布；人口集中在东南沿海

## 第12节 巴西
# S1 正向检索
亚马孙热带雨林被称为？###"地球之肺"（地球上面积最大的热带雨林，60%在巴西境内）
巴西的主要农产品有？###咖啡、蔗糖（甘蔗）、柑橘等产量和出口量居世界前列
# S2 逆向检索
世界流域面积最广、水量最大的河流是？###亚马孙河
南美洲人口最多、混血种人约占总人口45%的国家是？###巴西
# S3 要点默写

默写热带雨林遭受破坏的原因及影响###大规模开发（修路、开矿、伐木、开辟农场）→水土流失加剧、生物多样性减少、影响全球气候
# S4 综合默写
默写"巴西的自然与经济发展"###热带大国（大部分位于热带）；亚马孙平原+巴西高原；混血种人社会；咖啡蔗糖柑橘出口前列；铁矿石储量大；生物燃料（甘蔗乙醇）发展迅速；热带雨林保护与开发矛盾

# ===== 第十一章 极地地区 =====

## 第13节 极地地区
# S1 正向检索
南极地区的气候特点是？###酷寒、多狂风、降水稀少（"冰雪高原"）
南极地区的代表性动物是？###企鹅；北极地区是北极熊
# S2 逆向检索
覆盖2000多米厚冰层、被称为"冰雪高原"的是？###南极大陆
主体是北冰洋、年平均气温约-10℃、比南极温暖的是？###北极地区
# S3 要点默写
默写南极比北极冷得多的原因###南极主体是大陆、平均海拔超2300米、被冰冷海水环绕；北极近2/3是海洋、海拔低、有温暖海水流入
默写我国在南极的科考站###长城站、中山站、昆仑站、泰山站等
# S4 综合默写
默写"极地地区的自然与科考"###南极（大陆、酷寒、冰雪高原、企鹅）；北极（海洋、较温暖、北极熊）；科考意义重大；《南极条约》规定只用于和平目的
