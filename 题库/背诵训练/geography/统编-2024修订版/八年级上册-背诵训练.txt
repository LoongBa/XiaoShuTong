# S4 综合默写
默写"我国地势三级阶梯概况"###第一阶梯：青藏高原（4000米以上）；第二阶梯：高原盆地为主；第三阶梯：平原丘陵为主；分界线：昆仑-祁连-横断 / 大兴安岭-太行-巫山-雪峰山

## 第5节 气候
# S1 正向检索
我国主要气候类型有哪些？###温带季风、亚热带季风、热带季风、温带大陆性、高原山地
秦岭-淮河一线的地理意义？###1月0℃等温线、800mm等降水量线、南北分界、水田旱地分界
# S2 逆向检索
我国气候的两大特征？###气候复杂多样、季风气候显著
南暖北冷、南北温差大描述的是我国什么季节的气温特点？###冬季
# S3 要点默写
默写我国温度带和干湿地区###温度带：寒温带/中温带/暖温带/亚热带/热带/高原气候区；干湿区：湿润/半湿润/半干旱/干旱
默写影响我国气候的主要因素###纬度位置、海陆位置、地形
# S4 综合默写
默写"我国气候的主要特征"###气候复杂多样；季风气候显著；夏季全国普遍高温（青藏高原除外）；冬季南暖北冷；降水从东南沿海向西北内陆递减

## 第6节 河流与湖泊

# S2 逆向检索
发源于唐古拉山脉、注入东海的大河是？###长江
我国含沙量最大的河流是？###黄河
# S3 要点默写
默写长江上中下游分界及"黄金水道"###宜昌（上中游）/湖口（中下游）；航运价值高，称"黄金水道"
默写黄河的治理措施###上中游保持水土（植树造林），下游加固堤坝、疏浚河道
# S4 综合默写
默写"黄河的忧患与治理"###中游黄土高原水土流失→含沙量大→下游泥沙淤积成"地上河"；治理：中游保持水土、下游加固堤坝

# S2 逆向检索

# S3 要点默写

默写耕地/林地/草地分布###耕地：东部平原低山丘陵；林地：山区（东北西南东南）；草地：西部干旱半干旱区

## 第10节 水资源
# S1 正向检索

# S2 逆向检索
把长江水调往华北西北的工程是？###南水北调

# S3 要点默写

## 第11节 矿产资源
# S1 正向检索
我国能源矿产的分布特点？###多煤少油气，北多南少、西多东少
我国储量居世界首位的矿产？###钨、锡、锑；三稀矿产（稀土、锂、镓、铟）
# S2 逆向检索
"有而不够、有而不优"描述的是我国什么资源状况？###矿产资源供需
我国最大的盐场是？###长芦盐场（渤海沿岸）
# S3 要点默写
默写我国铁矿资源特点###储量排世界第四位，但贫矿多、富矿少；主要进口自澳大利亚、巴西
默写我国海洋资源概况###世界最大海鱼、海盐生产国；舟山渔场；长芦盐场；油气分布在渤海和南海北部大陆架；海水养殖量超过捕捞量
# S4 综合默写
默写"我国矿产资源的特征与对策"###种类齐全、储量丰富、人均少；多煤少油气、北多南少；有而不够有而不优、多数依赖进口；对策：加强勘探、提高利用率、循环利用、保障战略安全
