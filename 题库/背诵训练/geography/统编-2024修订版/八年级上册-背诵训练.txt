# 八年级上册 地理背诵训练题库（分阶检索法）
# 教材：人教版统编地理 2024 修订版（中国地理）
# 题型：# S1 正向检索（区域→特征/全称→简称省会）/ # S2 逆向检索（特征→区域/省会→省）/ # S3 要点默写 / # S4 综合默写
# 格式：题目###答案（# 开头为注释）

# ===== 第一章 从世界看中国 =====

## 疆域与行政区划
# S1 正向检索

# S2 逆向检索

鄂是哪个省的简称？###湖北省

成都、昆明、西安分别是哪些省的省会？###四川、云南、陕西
# S3 要点默写
默写我国四大直辖市和两个特别行政区###直辖市：北京、天津、上海、重庆；特别行政区：香港、澳门
默写双简称的省份###四川（川/蜀）、云南（云/滇）、贵州（贵/黔）、陕西（陕/秦）、甘肃（甘/陇）
# S4 综合默写
默写我国省级行政区数量构成###23个省、5个自治区、4个直辖市、2个特别行政区，共34个
