# 题型：S1 正向 / S2 逆向 / S3 要点默写 / S4 综合
# 格式：题目###答案（# 开头为注释）

# ===== 第一章 地球 =====
## 第一章 地球
# S1 正向检索
太阳系行星由近及远排序？###水金地火木土天海（八颗）
地球平均半径与赤道周长？###约6371千米；约4万千米
# S2 逆向检索
两极指？###地轴与地球表面的两个交点（北极为地球最北点）
# S3 要点默写
默写地球表面积及形状？###约5.1亿平方千米；两极稍扁、赤道略鼓的不规则球体
默写自转/公转？###自转自西向东约24h（昼夜交替）；公转自西向东约365天（四季）
# S4 综合默写
说明地球为何是唯一宜居家园？###距日远近适中、体积质量适中→适宜温度大气水

# ===== 第二章 地图 =====
## 第二章 地图
# S1 正向
比例尺公式？###图上距离÷实际距离
等高线密集/稀疏？###密集=坡陡；稀疏=坡缓
# S2 逆向
比例尺分母大小与详略？###分母越小说比例尺越大、内容越详细
# S3 要点默写
地图三要素？###比例尺、方向、图例
五种地形？###高原、山地、盆地、平原、丘陵
# S4 综合
判读地形图的步骤？###看比例尺→定向→读海拔及等高线疏密→判断地形

# ===== 第三章 陆地和海洋 =====
## 第三章 陆地和海洋
# S1 正向
七大洲四大洋？###七洲：亚非北美南美南极欧大洋；四洋：太平洋大西洋印度洋北冰洋
# S2 逆向
面积最大洲与洋？###亚洲与太平洋
# S3 要点默写
海陆变迁原因？###地壳运动、海平面升降、人类活动
两大火山地震带？###环太平洋、地中海—喜马拉雅
# S4 综合
用板块学说解释地震分布？###板块交界处地壳活跃，多火山地震

# ===== 第四章 天气与气候 =====
## 第四章 天气与气候
# S1 正向
天气与气候区别？###天气短时多变；气候多年稳定
# S2 逆向
一天最低温时间？###日出前后
# S3 要点默写
影响气候三因素？###纬度、海陆、地形
# S4 综合
说明气候与生活关系？###高温多雨区适水稻；地中海气候适橄榄
