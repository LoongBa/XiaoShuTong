# ===== 第六章 中国的地理差异 =====

## 第1节 中国的地理差异
# S1 正向检索
我国四大地理区域是？###北方地区、南方地区、西北地区、青藏地区
秦岭—淮河一线是我国什么的界线？###南北方分界线（重要地理分界线）
# S2 逆向检索
耕地为旱地、种小麦为主的是哪一侧？###秦岭—淮河以北
耕地为水田、种水稻为主的是哪一侧？###秦岭—淮河以南
# S3 要点默写
默写秦岭—淮河一线的地理意义###1月0℃等温线、800mm等降水量线、南北方分界、旱地水田分界、小麦水稻分界、温带季风与亚热带季风分界
默写四大地理区域划分的主导因素###南北：气候（气温降水）；西北与北方：降水（海陆位置）；青藏：地形（海拔）
# S4 综合默写
默写"我国南北方的自然差异"###秦岭—淮河以北：旱地小麦、温带季风、河流有结冰期；以南：水田水稻、亚热带季风、河流无结冰期

# ===== 第七章 北方地区 =====

## 第2节 自然特征与农业
# S1 正向检索
北方地区的地形特点？###以平原和高原为主（东北平原、华北平原、黄土高原）
北方地区的土壤？###东北"黑土地"、黄土高原华北"黄土地"
# S2 逆向检索
重要的旱作农业区指？###北方地区（小麦玉米等）
最冷月平均气温在0℃以下的地区是？###北方地区（温带季风气候）
# S3 要点默写
默写北方地区的位置###大兴安岭、青藏高原以东，内蒙古高原以南，秦岭—淮河以北，东临渤海黄海
默写北方地区主要农作物###小麦、玉米、大豆、甜菜、棉花等
# S4 综合默写
默写"北方地区的农业特征"###旱地为主；温带季风气候（冬季寒冷）；东北平原种水稻较多、华北平原春旱严重

## 第3节 "白山黑水"——东北三省

# S2 逆向检索
"山环水绕、沃野千里"形容哪里？###东北三省
从"北大荒"到"北大仓"指？###东北平原开垦为商品粮基地
# S3 要点默写
默写东北三省成为商品粮基地的条件###夏季暖热、雨热同期；平原辽阔坦荡、适宜机械化耕作；黑土地肥沃
默写东北三省的气候特点###纬度较高、邻近冬季风源地，冬季严寒漫长、夏季暖热短促
