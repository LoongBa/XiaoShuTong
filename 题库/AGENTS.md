# AGENTS.md - 小书童-题库内容资产

> 本目录为**内容资产**（非代码）——小书童官方背诵题库（「四件套」+ 判题引擎资产），由 TKWF 的 Bank/Judging 域代码消费。**代码纪律见仓库根 `Agents_Use_TKWF.md`**，本文档只管内容资产。

## 定位

- 小书童官方内容资产，覆盖 **7 学科四件套**：语文 / 英语 / 历史 / 地理 / 生物 / 化学 / 道德与法治。
- **数学/物理仅整理资源，不参与背诵**（背诵产品核心在语文/英语/历史/道法/地理/生物/化学），详见 `README.md` 进度表。
- 版本基准：**2026-2027 学年现行教材（2024 修订版统编/人教）**；建设规范见 `题库建设规范.md`（V1.1）。

## 四件套定义

| 层 | 产物 | 格式 | 用途 |
|----|------|------|------|
| L0 篇目清单 | 背诵篇目清单 | `.md`（表格） | 全部背诵篇目台账（篇名/作者/朝代/体裁/位置/背诵要求） |
| L1 原始题库 | `<册>-背诵内容.txt` | `.txt`（`问题###答案`） | 按篇目组织的测试题，判定"会不会" |
| L2 背诵训练 | `<册>-背诵训练.txt` | `.txt`（S1-S4 分阶 + `###`） | 分阶检索训练题，驱动记忆升级 |
| L3 背景钩子 | `<册>-背景钩子.md` | `.md`（结构化记忆卡片） | 背诵时展示的记忆增强器（作者/背景/钩子/关联） |

> 判题 Prompt（`判题Prompt/`）与 Schema（`schema/`）为平台层底座。完整规范见 `题库建设规范.md` §一。

## 目录结构（要点）

- `<学科>/<教材版本>/`：学科题库（篇目清单 + `<bank_id>.json` 统一 JSON）
- `背诵训练/<学科>/<教材版本>/`：L2 分阶训练（S1-S4）
- `背景钩子/<学科>/<教材版本>/`：L3 记忆卡片
- `schema/`：JSON Schema + 判题引擎 + 注册表；`判题Prompt/`：AI 判题 Prompt 资产库
- 完整目录树以 `README.md` 为准（对齐规范 V1.1 §二）

## 状态权威索引（关键）

- **素材到位 / 复核进度唯一权威** = `各册更新情况清单.md`（素材到位矩阵 + 复核/重建进度 + 版本决策 + 检查时间点）。
- **学科总览** = `README.md`（多学科进度表 + 版本说明 + 待办）。
- **学科版本要点**（语文九上 2026 新版/道法历史九上重建/物理沪科技版等现状）＝ `各册更新情况清单.md` §四 版本决策备忘。
- 口径冲突时**以 `各册更新情况清单.md` 为准**；禁止从题库 JSON/txt 反推状态。

## 同步纪律（关键）

任何素材到位或题库复核完成后，**必须四文档联动更新**，防止状态过期：

1. `题库/各册更新情况清单.md` —— 更新素材到位表 / 复核进度表 / 版本决策备忘
2. `题库/README.md` —— 同步多学科进度表 + 版本说明 + 待办勾选
3. `docs/变更记录.md` —— 增量追加条目（日期/版本/变更内容，不覆盖历史）
4. `docs/AGENTS.md` —— 检查「题库素材与版本状态」节是否需同步（该节仅保留路由级信息，状态本体在 `各册更新情况清单.md`）

## 格式红线

- **题目 ID 必须合规**：`schema/question.v1.json` 正则 `^Q-[a-z]{2,}-[a-z0-9]+-[0-9]{4,}$`，格式 `Q-{学科}-{库缩写}-{序号}`（如 `Q-ch-7a-0001`）。
- **knowledge_points 用篇目/事件级粒度**（非单词级）；**内容必须可溯源教材**（不臆造；教材 PDF 素材在 `F:\_教材素材\初中`）。
- **判题引擎资产在 `schema/`**：`grader.py`（rule / similarity / ai 三引擎）+ `bank.v1.json` / `question.v1.json`（JSON Schema）+ `题型注册表.json` / `学科注册表.json`。
- 已知格式缺口（**待办、未修复**，不可声称已修复）：部分题目 ID 不合规、英语 kp 为单词级、`txt2json.py` 仅覆盖语文。

## 版本管理

- 教材改版（篇目变化）→ 大版本 +1，**新建独立版本目录**（如 `统编-2026新版/`），**旧版不删**，用 `superseded_by` 标记取代关系。
- **过渡期新老教材并存** → 独立版本目录 + 维护**版本映射表**（逐年级/逐册：哪些用新版、哪些仍旧版、何时切换），见 `题库建设规范.md` §八。
- 新增题目（教材基准不变）→ 小版本 +1，同目录文件内追加。

## 检查时间点

- ⏰ **2027 年寒假或开学前**：检查九年级下册系列教材（语文/英语/历史/道法）发布情况，确认后补素材并复核，完成后走四文档联动同步。
