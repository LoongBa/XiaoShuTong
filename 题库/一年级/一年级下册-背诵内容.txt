# 一年级下册 语文背诵内容测试题
# 教材：人教社统编版 2024 修订版
# 格式：问题###答案（# 开头为注释）
# 说明：低年级题型以补全（上句接下句）+ 整篇默写为主，文学常识适度简化

# ===== 课文背诵 =====

《春夏秋冬》中"春风吹"的后一句是？###夏雨落
《春夏秋冬》中"秋霜降"的后一句是？###冬雪飘
《春夏秋冬》中"池草青"的后一句是？###山花红
《春夏秋冬》中"鱼出水"的后一句是？###鸟入林
默写《春夏秋冬》###春风吹，夏雨落，秋霜降，冬雪飘。池草青，山花红，鱼出水，鸟入林。

《姓氏歌》中"你姓什么"的后一句是？###我姓李
《姓氏歌》中"什么李"的后一句是？###木子李
《姓氏歌》中"古月胡"的后一句是？###口天吴
《姓氏歌》中"双人徐"的后一句是？###言午许
默写《姓氏歌》###你姓什么？我姓李。什么李？木子李。他姓什么？他姓张。什么张？弓长张。古月胡，口天吴，双人徐，言午许。中国姓氏有很多，赵、钱、孙、李，周、吴、郑、王，诸葛、东方，上官、欧阳……

《古对今》中"古对今"的后一句是？###圆对方
《古对今》中"严寒对酷暑"的后一句是？###春暖对秋凉
《古对今》中"晨对暮"的后一句是？###雪对霜
《古对今》中"和风对细雨"的后一句是？###朝霞对夕阳
默写《古对今》###古对今，圆对方。严寒对酷暑，春暖对秋凉。晨对暮，雪对霜。和风对细雨，朝霞对夕阳。桃对李，柳对杨。莺歌对燕舞，鸟语对花香。

《人之初》中"人之初"的后一句是？###性本善
《人之初》中"性相近"的后一句是？###习相远
《人之初》中"苟不教"的后一句是？###性乃迁
《人之初》中"玉不琢"的后一句是？###不成器
默写《人之初》###人之初，性本善，性相近，习相远。苟不教，性乃迁，教之道，贵以专。子不学，非所宜，幼不学，老何为。玉不琢，不成器，人不学，不知义。

《荷叶圆圆》中"荷叶圆圆的"的后一句是？###绿绿的
《荷叶圆圆》中"小水珠说"的后一句是？###"荷叶是我的摇篮。"
《荷叶圆圆》中"小青蛙说"的后一句是？###"荷叶是我的歌台。"
《荷叶圆圆》中"小鱼儿说"的后一句是？###"荷叶是我的凉伞。"
默写《荷叶圆圆》###荷叶圆圆的，绿绿的。小水珠说："荷叶是我的摇篮。"小水珠躺在荷叶上，眨着亮晶晶的眼睛。小蜻蜓说："荷叶是我的停机坪。"小蜻蜓立在荷叶上，展开透明的翅膀。小青蛙说："荷叶是我的歌台。"小青蛙蹲在荷叶上，呱呱地放声歌唱。小鱼儿说："荷叶是我的凉伞。"小鱼儿在荷叶下笑嘻嘻地游来游去，捧起一朵朵很美很美的水花。

# ===== 课内古诗 =====

《静夜思》的作者是？###李白
《静夜思》中"床前明月光"的后一句是？###疑是地上霜
《静夜思》中"举头望明月"的后一句是？###低头思故乡
《静夜思》中表达思念家乡的句子是？###举头望明月，低头思故乡。
默写《静夜思》###床前明月光，疑是地上霜。举头望明月，低头思故乡。

《池上》的作者是？###白居易
《池上》中"小娃撑小艇"的后一句是？###偷采白莲回
《池上》中"不解藏踪迹"的后一句是？###浮萍一道开
默写《池上》###小娃撑小艇，偷采白莲回。不解藏踪迹，浮萍一道开。

《小池》的作者是？###杨万里（宋）
《小池》中"泉眼无声惜细流"的后一句是？###树阴照水爱晴柔
《小池》中"小荷才露尖尖角"的后一句是？###早有蜻蜓立上头
默写《小池》###泉眼无声惜细流，树阴照水爱晴柔。小荷才露尖尖角，早有蜻蜓立上头。

《画鸡》的作者是？###唐寅（明）
《画鸡》中"头上红冠不用裁"的后一句是？###满身雪白走将来
《画鸡》中"平生不敢轻言语"的后一句是？###一叫千门万户开
默写《画鸡》###头上红冠不用裁，满身雪白走将来。平生不敢轻言语，一叫千门万户开。

# ===== 日积月累古诗（语文园地）=====

《春晓》的作者是？###孟浩然（唐）
《春晓》中"春眠不觉晓"的后一句是？###处处闻啼鸟
《春晓》中"夜来风雨声"的后一句是？###花落知多少
默写《春晓》###春眠不觉晓，处处闻啼鸟。夜来风雨声，花落知多少。

《赠汪伦》的作者是？###李白
《赠汪伦》中"李白乘舟将欲行"的后一句是？###忽闻岸上踏歌声
《赠汪伦》中"桃花潭水深千尺"的后一句是？###不及汪伦送我情
默写《赠汪伦》###李白乘舟将欲行，忽闻岸上踏歌声。桃花潭水深千尺，不及汪伦送我情。

《寻隐者不遇》的作者是？###贾岛（唐）
《寻隐者不遇》中"松下问童子"的后一句是？###言师采药去
《寻隐者不遇》中"只在此山中"的后一句是？###云深不知处
默写《寻隐者不遇》###松下问童子，言师采药去。只在此山中，云深不知处。
