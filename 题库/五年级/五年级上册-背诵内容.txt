# 《白鹭》郭沫若（全文背诵）
文学常识：《白鹭》的作者是？###郭沫若
句子接龙：白鹭是一首###精巧的诗
句子接龙：色素的配合，身段的大小，###一切都很适宜
句子接龙：那雪白的蓑毛，那全身的流线型结构，那铁色的长喙，那青色的脚，###增之一分则嫌长，减之一分则嫌短，素之一忽则嫌白，黛之一忽则嫌黑
句子接龙：在清水田里，时有一只两只白鹭站着钓鱼，###整个的田便成了一幅嵌在玻璃框里的画
名句填空：白鹭实在是一首诗，###一首韵在骨子里的散文诗
默写题目答案衔接：《白鹭》全文的起句和结句分别是？###起句"白鹭是一首精巧的诗"；结句"白鹭实在是一首诗，一首韵在骨子里的散文诗"

# 《落花生》许地山（背诵第10-13自然段）
文学常识：《落花生》的作者是？###许地山（笔名落华生）
名句理解：父亲说花生最可贵的是什么？###它的果实埋在地里，不像桃子、石榴、苹果那样把鲜红嫩绿的果实高高挂在枝头上，让人一见就生爱慕之心
句子接龙：所以你们要像花生，###它虽然不好看，可是很有用
名句理解："人要做有用的人"的后一句是？###不要做只讲体面，而对别人没有好处的人
课文理解：课文借花生告诉我们什么道理？###要做默默奉献、对他人有用的人

# 《桂花雨》琦君（背诵第3-4自然段）
文学常识：《桂花雨》的作者是？###琦君
句子接龙：桂花树的样子笨笨的，###不像梅树那样有姿态
名句理解：母亲说的那句"这里的桂花再香，也比不上家乡院子里的桂花"表达什么？###对故乡的思念之情
课文理解：为什么"我"喊"真像下雨，好香的雨呀"？###摇桂花时桂花纷纷落下来，像下雨一样香

# 《少年中国说（节选）》梁启超（全文背诵）
文学常识：《少年中国说》的作者是？###梁启超
句子接龙：故今日之责任，不在他人，而全在我少年。少年智则国智，少年富则国富，少年强则国强，###少年独立则国独立，少年自由则国自由，少年进步则国进步
句子接龙：红日初升，###其道大光
句子接龙：河出伏流，###一泻汪洋
句子接龙：潜龙腾渊，###鳞爪飞扬
句子接龙：乳虎啸谷，###百兽震惶
句子接龙：天戴其苍，###地履其黄
句子接龙：纵有千古，###横有八荒
名句理解："美哉，我少年中国，与天不老！壮哉，我中国少年，与国无疆！"表达了什么？###对少年中国的赞美和期待
默写《少年中国说（节选）》###故今日之责任，不在他人，而全在我少年。少年智则国智，少年富则国富，少年强则国强，少年独立则国独立，少年自由则国自由，少年进步则国进步，少年胜于欧洲，则国胜于欧洲，少年雄于地球，则国雄于地球。红日初升，其道大光。河出伏流，一泻汪洋。潜龙腾渊，鳞爪飞扬。乳虎啸谷，百兽震惶。鹰隼试翼，风尘吸张。奇花初胎，矞矞皇皇。干将发硎，有作其芒。天戴其苍，地履其黄。纵有千古，横有八荒。前途似海，来日方长。美哉，我少年中国，与天不老！壮哉，我中国少年，与国无疆！

# 《古人谈读书》（全文背诵，文言文）

# ===== 文言文 =====

《古人谈读书》选自哪些著作？###《论语》、朱熹《童蒙须知》、曾国藩家书等
# 第一则（《论语》）：
名句理解："敏而好学"的后一句是？###不耻下问
句子接龙：知之为知之，不知为不知，###是知也
默写第一则###敏而好学，不耻下问。知之为知之，不知为不知，是知也。
# 第二则（朱熹）：
名句理解："读书有三到"是哪三到？###心到、眼到、口到
句子接龙：三到之中，###心到最急
句子接龙：心既到矣，###眼口岂不到乎
默写第二则###余尝谓：读书有三到，谓心到、眼到、口到。心不在此，则眼不看仔细，心眼既不专一，却只漫浪诵读，决不能记，记亦不能久也。三到之中，心到最急。心既到矣，眼口岂不到乎？
# 第三则（曾国藩）：
名句理解：士人读书，第一要有志，第二要有识，第三要有？###恒
句子接龙：有志则断不甘为下流；有识则知学问无尽；###有恒则断无不成之事
默写第三则###盖士人读书，第一要有志，第二要有识，第三要有恒。有志则断不甘为下流；有识则知学问无尽，不敢以一得自足，如河伯之观海，如井蛙之窥天，皆无识者也；有恒则断无不成之事。此三者缺一不可。

# ===== 课内古诗 =====

《山居秋暝》的作者及朝代是？###王维，唐
《山居秋暝》中"空山新雨后"的后一句是？###天气晚来秋
《山居秋暝》中"明月松间照"的后一句是？###清泉石上流
《山居秋暝》中"竹喧归浣女"的后一句是？###莲动下渔舟
《山居秋暝》中描写月照松林、清澈泉水的名句是？###明月松间照，清泉石上流。
默写《山居秋暝》###空山新雨后，天气晚来秋。明月松间照，清泉石上流。竹喧归浣女，莲动下渔舟。随意春芳歇，王孙自可留。

《枫桥夜泊》的作者及朝代是？###张继，唐
《枫桥夜泊》中"月落乌啼霜满天"的后一句是？###江枫渔火对愁眠
《枫桥夜泊》中"姑苏城外寒山寺"的后一句是？###夜半钟声到客船
《枫桥夜泊》中描写羁旅愁思的名句是？###月落乌啼霜满天，江枫渔火对愁眠。
默写《枫桥夜泊》###月落乌啼霜满天，江枫渔火对愁眠。姑苏城外寒山寺，夜半钟声到客船。

《长相思·山一程》的作者及朝代是？###纳兰性德，清
《长相思·山一程》中"山一程，水一程"的后一句是？###身向榆关那畔行
《长相思·山一程》中"夜深千帐灯"的上一句是？###身向榆关那畔行
《长相思·山一程》中"风一更，雪一更"的后一句是？###聒碎乡心梦不成
《长相思·山一程》中表达思乡之情的名句是？###聒碎乡心梦不成，故园无此声。
默写《长相思·山一程》###山一程，水一程，身向榆关那畔行，夜深千帐灯。风一更，雪一更，聒碎乡心梦不成，故园无此声。
