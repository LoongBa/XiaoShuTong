## 二、审核结论

**总评：通过**

V0.6.9 登记的两项错题配合项全部闭环，且暴露并修复了 **gen-ts-client codegen 两处潜伏 bug**（input 数组字段 isList 丢失 + 可空列表 null 语义丢失），连锁正确化了一处 V0.6.8 遗留契约错配（create.tsx JSON 串传数组）。核心交付：

1. **学习-BR-51 错题专练**：GetNextQuestionService（Bank Callee）+ ReqDto 加 `QuestionIds` 白名单——`null`=全库（既有行为）/ `[]`=显式空集（BR-18 空结果）/ `[>0]`=available∩白名单 + **短路混合比按 BR-20 排序直出**（Oracle M2 裁决：错题专练=只练错题，混合比 30% 新题违背语义）；Learning/GetSessionQuestionService 薄包装透传；前端 sessionQuestion_Execute 携带（`[String!]`）。
2. **学习-BR-52 MarkMasteredService**：学习域新增（激励-BR-15 域边界），LearningErrorCodes 补 `WrongNotFound(4007)`；翻转 WrongQuestions.Mastered——幂等（User+QuestionId 唯一）、BR-23 作答事件权威不豁免（选项 A：手动标记=临时展示分组，答错重置、不删记录）。
3. **前端闭环**：wrong.tsx 重练=整 tab 待掌握错题白名单（经 Zustand store 传递，Oracle C7 规避 URL 长度）；待掌握 tab 补"已掌握"、已掌握 tab 补"移回错题本"真实按钮（markMastered_Execute + refetch，Oracle C5）；task.tsx 门禁放宽 + 透传 + endStudy 清空（白名单生命周期=会话全程）。
4. **codegen 修复×2 + 连锁正确化**：
   - **(a) input 数组 isList 丢失**：extractTypeFields 解析了 `isList` 但未存入 TypeFieldDef，旧降级用 extractTypeBlock（只匹配 `type` 不匹配 `input`）→ **input 类型数组字段错生成标量**（GetSessionQuestion/GetWrongQuestions 等 input 潜在受影响）。修复：TypeFieldDef 加 isList + push 保存 + 生成处优先用 f.isList。
   - **(b) 可空列表 null 语义丢失**：`[T!]`（sessionQuestion questionIds）生成 `Array<T>` 丢失 null → 修复生成 `Array<T> | null`（null=全库/[]=空集，M1 决策语义）。
   - **(c) 连锁**：create.tsx V0.6.8 遗留 `questionIds: JSON.stringify([])` 字符串（契约 `[String!]!` 数组）类型对齐后暴露 → 改 `[]`。
5. **测试**：新增 8 用例（白名单内/显式空集/全已答 + MarkMastered 翻转/幂等/RLS/BR-23 共存记录保留）。
