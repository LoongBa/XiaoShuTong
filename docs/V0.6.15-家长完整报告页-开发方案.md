# 家长完整报告页 - 开发方案（V0.6.15）

## 一、背景与目标

### 1.1 背景

V0.6.12 审核报告 §七："完整报告页（/parent/progress 等）：V0.6.7 §七 既定后续迭代（付费解锁完整报告的前置页面）"。当前 parent/dashboard 的"查看完整报告"卡在订阅后 alert 提示（V0.6.12 L318-321："完整报告页将在后续版本上线，敬请期待"）——本迭代建真实页面闭环。

**现状核查（后端 Service 实读 + 契约实证）**：

1. **后端契约已就绪（无后端改动）**：
   - `GetProgressReportService`（UC-10.8）：`progressReport_Execute({studentId, period: Week/Month})` → `{success, errorCode, trend: DailyStatsDto[], vsLastWeek: {learnedDelta, weaknessShift}}`——BR-20 订阅门控（allowPreview=false 未订阅→8001）/ BR-21 Period 校验 / BR-22 无数据→4001 / BR-23 合规无排名 / BR-24 vsLastWeek 仅与自己比
   - `GetWeaknessReportService`（UC-10.9）：`weaknessReport_Execute({studentId})` → `{success, errorCode, weakPoints: [{subject, knowledgePoint, accuracy, stateText}]}`——BR-25 订阅门控 / BR-26 按需聚合 / BR-27 State 映射家长文案（未掌握/模糊/掌握/熟练）
2. **UI 设计**（L417-421）：`/parent/progress`（正确率/背诵量时间曲线 + 周/月切换 + 相对进步本周vs上周 + 不显示群组排名）+ `/parent/weakness`（知识点-掌握度矩阵）
3. **mock 已就绪**：data.ts getProgressReportResDtos（1条，含 trend+vsLastWeek）+ getWeaknessReportResDtos（2条：含弱项/空）——确认字段对齐契约后零补
4. **DailyStatsDto 字段**：statDate/learnedCount/starredCount/reviewCount/accuracy(null)/studySeconds
5. **前端路由**：parent 目录已有 dashboard.tsx；progress/weakness 为新建页

### 1.2 目标

1. **新建 /parent/progress**：进度趋势页——周/月切换（period 参数）+ 背诵量曲线（learnedCount）+ 正确率（accuracy）+ vsLastWeek 相对进步卡（多背 N 篇 / 薄弱点迁移）
2. **新建 /parent/weakness**：薄弱知识点页——掌握度矩阵列表（accuracy 降序 or 升序 + stateText 徽章 + 学科分组）
3. **订阅门控消费**：未订阅（8001）→ 页面引导回 dashboard 开通（与 V0.6.12 支付卡联动）；无数据（4001）→ 空态
4. **dashboard 卡导航接通**："查看完整报告"订阅后 navigate 到 /parent/progress（弱→完整报告双入口：progress 页内可切 weakness tab 或独立卡）
5. **共享上下文**：selectedChild 传递（报告按孩子独立计费，UI L414）——经 store 或查询参数

### 1.3 范围决策（不做什么）

| 不做 | 理由 | 归属 |
|------|------|------|
| 掌握度矩阵可下钻到具体篇目（UI L421） | 后端 GetWeaknessReport 无下钻维度（仅知识点粒度） | 后续迭代 |
| 多孩子切换器内嵌报告页 | dashboard 已有孩子切换；报告页接收当前 selectedChild | 不做 |
| 图表库（recharts 等） | 新增依赖需 ADR；背诵量/正确率曲线可用轻量自制 SVG/条形实现 | 不做（无新依赖） |
| 后端改动 | 两 Service 契约已就绪 | 不做 |

## 二、方案要点

### 2.1 路由与页面结构

```
routes/parent/progress.tsx      # /parent/progress 进度趋势
└── ProgressPage
    ├── 顶部导航（返回 dashboard + 孩子名）
    ├── 周/月切换（Week/Month 默认 Week；切换重拉）
    ├── vsLastWeek 相对进步卡（learnedDelta：本周较上周 多背 N 篇；weaknessShift：薄弱点数）
    ├── 背诵量曲线（learnedCount 逐日条形/折线，SVG 手绘，无依赖）
    ├── 正确率曲线（accuracy 逐日，缺失日跳过）
    └── 底部导航（报告→薄弱点切换入口）

routes/parent/weakness.tsx      # /parent/weakness 薄弱知识点
└── WeaknessPage
    ├── 顶部导航（返回 dashboard + 孩子名）
    ├── 薄弱知识点列表（subject 分组 + accuracy 升序 + stateText 徽章：未掌握✕/模糊△/掌握○/熟练★）
    └── 底部导航（薄弱→报告切换入口）
```

### 2.2 订阅门控与错误处理

- `progressReport_Execute`/`weaknessReport_Execute` 返回 `success=false`：
  - `errorCode === '8001'`（SubscriptionRequired）→ 显示"开通成长报告解锁完整报告"引导卡 + [去开通]按钮（回 dashboard）
  - `errorCode === '4001'`（NoStatsData）→ 空态"孩子还没有学习记录，让他/她背第一首诗吧"（UI L415）
  - 其他 → 错误态 + 重试
- 门控判定对齐 V0.6.12（parentReportGate 语义）：未订阅/试用过期 → 8001

### 2.3 共享上下文（selectedChild）

- 报告页从 store currentUser/children 取当前孩子——或 dashboard navigate 时带 `?child=studentId`
- 更简：dashboard "查看完整报告"按钮 navigate `/parent/progress?studentId={selectedChild.studentId}`（查询参数，V0.6.7 P0-4 已有 validateSearch 先例）；报告页内切换 weakness 传同一 studentId

### 2.4 mock 补齐（Oracle C1 实证修正：mock 字段未对齐契约，T4 工作量升级"小→中"）

实测 mock（data.ts L743-770）与契约字段有 3 处缺口，须补齐（非"已就绪"）：

| 位置 | 契约字段 | mock 现状 | 修正 |
|------|---------|----------|------|
| trend | reviewCount / studySeconds | wrongCount / sessionCount（旧字段） | 改对齐契约（或补缺） |
| vsLastWeek | learnedDelta / **weaknessShift** | learnedDelta + accuracyDelta/starredDelta/wrongDelta（多余旧字段） | 补 weaknessShift |
| weakPoints（ParentWeakPointDto） | **subject** / knowledgePoint / accuracy / stateText | 缺 subject，多 questionCount | 补 subject（weakness 页学科分组核心依赖） |

## 五、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 订阅门控判定（8001 vs 4001 优先级） | 未订阅+无数据双重态 | 按 errorCode 显式分支（8001→开通引导 / 4001→空态 / 其他→错误重试） |
| selectedChild 传递 | 报告页需知道看哪个孩子 | dashboard navigate 带 ?studentId 查询参数（validateSearch 先例） |
| accuracy 可空（DailyStatsDto.accuracy 为 null） | 曲线断点/空值 | 曲线跳过 null 日；正确率卡显示"暂无数据" |
| 图表无依赖实现 | 自制 SVG 曲线复杂度 | 保持简单：条形图（背诵量）+ 折线（正确率），shadcn 风格 |
| **accuracy 整段 null（Oracle C3）** | 新用户整周未答题，正确率曲线整段空白 | 整周 accuracy 全 null 时正确率区显示空态卡"暂无正确率数据（完成作答后可查看）"，非半截空线 |
| **周/月切换加载态（Oracle C3）** | 切换期间 UI 表现未定 | 切换期间旧数据保留 + 顶部 loading bar，避免闪烁 |
| **studentId 缺失兜底（Oracle C3）** | 直接访问 /parent/progress 无 ?studentId（书签失效） | studentId 缺失时 navigate 回 /parent/dashboard |

> **C4（产品确认，不阻塞实施）**：8001 提示策略——纯引导开通卡（契约 BR-20 allowPreview=false 技术已定）；是否需"预览样例+模糊化"提升付费转化属产品层决策，待产品确认，本次按纯引导卡实施。
