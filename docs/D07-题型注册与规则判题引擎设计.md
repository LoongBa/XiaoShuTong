# 题型注册与规则判题引擎设计（D07）

> 本文档定义小书童的**题型注册表**（13 种题型的注册配置）与**规则判题引擎**（O1-O5 客观题规则判题算法），是 D01 框架 L2 题型契约层 + L3 判题引擎的落地实现规格。
> 关联文档：`docs/D01-统一题库与多学科学习平台设计.md`（框架 V1.2.1）、`docs/D03-API契约设计.md`（判题契约）、`docs/adr/ADR-003-判题引擎三层路由.md`（判题三层路由）、`题库/schema/题型注册表.json`（注册表数据）

---

## 一、目标

1. **数据驱动注册**：题型注册表 JSON 为唯一事实源，判题引擎按 `key` 查表路由，新增题型零代码改动（D01 设计原则 2）。
2. **规则判题**：O1-O5 客观题纯规则比对（零 LLM 成本），输出对齐 D03 判题契约。
3. **统一契约**：所有题型判题输出 `{result, confidence, matched_keywords, missing_keywords, hint}`。
4. **可测试**：规则判题引擎配套测试矩阵，边界用例全覆盖。

## 三、规则判题引擎（O1-O5）

### 3.1 统一判题输入/输出

```json
// 输入
{
  "question": "题目对象（含 content）",
  "user_answer": "用户提交答案",
  "hint_level": "none"
}
// 输出（D01 判题契约）
{
  "result": "correct | partial | wrong",
  "confidence": 0.0-1.0,
  "matched_keywords": [],
  "missing_keywords": [],
  "hint": ""
}
```

### 3.2 各题型判题算法

#### O1 单选（exact）

```
correct_option = content.correct_option（如 "A"）
user = user_answer 规范化（去除空白）
result = (user == correct_option) ? correct : wrong
confidence = 1.0（完全确定）
```

#### O2 多选（set_exact + 允许部分）

```
correct_set = content.correct_option 按 "," 拆分（如 "A,B" → {A,B}）
user_set   = user_answer 按 "," 拆分
全对  = (user_set == correct_set)                     → correct,  confidence 1.0
部分  = (user_set ⊂ correct_set 或 correct_set ⊂ user_set 且非全对)
                                                     → partial, confidence = |user_set ∩ correct_set| / |correct_set|
错选  = 无交集                                           → wrong
```

> allow_partial 时缺选/多选均判 partial；strict 模式（allow_partial=false）缺/多直接 wrong。

#### O3 判断（exact）

```
correct = content.correct_option（"对" / "错"）
user = 规范化（"正确"→"对"，"错误"→"错"，"√"→"对"，"×"→"错"）
result = (user == correct) ? correct : wrong
confidence = 1.0
```

#### O4 连线（pairs + 部分）

```
标准：content.pairs = [{left, right}, ...]
user：数组 [{left, right}] 或 {left: right} 映射
逐对比对：对 left 相同的条目比较 right
命中 = 匹配对数 / 总对数
  全部命中 → correct, confidence 1.0
  部分命中 → partial, confidence = 命中率
  零命中   → wrong
matched_keywords = 命中的 left 列表
missing_keywords = 未命中的 left 列表
```

#### O5 填空（keyword 主判，复用 keywords 同义词组）

```
命中率 = Σ(命中组权重×是否命中) / Σ(组权重)
  ≥0.85     → correct
  0.60-0.85 → partial（required 组未命中强制 partial）
  <0.60     → wrong
required=true 且未命中 → 强制 partial（即使命中率 ≥0.85）
```

### 3.3 判题路由（D01 9.1 落地）

```
题型注册表.grading → 判题链
rule      → 规则引擎（O1-O4 零成本）
hybrid    → keyword ≥85% correct / 60-85% partial / <60% LLM（O5 同）
llm       → LLM 判题（X1/X2）
display_only → R4 不判题（展示）
```
