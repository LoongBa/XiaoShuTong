## 二、审核结论

**总评：通过**

V0.6.12 登记的"完整报告页"遗留闭环，纯前端消费端改动（后端两 Service 契约 V0.6.3/07 已就绪，0 后端改动）。核心交付：

1. **/parent/progress 进度趋势页**：progressReport_Execute({studentId, period: Week/Month}) 真实契约——周/月切换 + 背诵量逐日条形图（自制 SVG，无新依赖）+ 正确率折线（null 日跳过，整段空→空态卡 C3）+ vsLastWeek 相对进步卡（learnedDelta 多背篇数 / weaknessShift 薄弱点，BR-23 仅与自己比无群组排名）。
2. **/parent/weakness 薄弱知识点页**：weaknessReport_Execute({studentId}) 消费——学科分组（subject）+ accuracy 升序 + stateText 徽章（未掌握✕/模糊△/掌握○/熟练★，BR-27 家长文案）。
3. **订阅门控消费**：8001/8003（未订阅/试用过期）→ 引导开通卡[去开通]回 dashboard；4001（无统计）→ 空态"孩子还没有学习记录"（UI L415）；其他 → 错误重试。后端 BR-20/25 `allowPreview=false` 权威兜底（C4：纯引导卡，预览模糊化产品决策待确认不阻塞）。
4. **dashboard 卡导航接通**："查看完整报告"订阅后 navigate `/parent/progress?studentId={selectedChild.studentId}`（validateSearch 先例；Oracle M2 唯一可行——selectedChild 在组件 useState 非全局 store）——删 V0.6.12 alert 占位。
5. **抽 deriveSubscription 公共派生函数**（Oracle C2）：dashboard 原内联判定（sub.status ∈ {Active, Trialing, Cancelled}）抽为 lib/parent-subscription.ts 纯函数；`parentReportGate` 符号在 dashboard 引用错误实证更正；公共判定防三处复制漂移。
6. **mock 补齐**（Oracle C1 实证：mock 字段未对齐契约）——trend 旧字段 wrongCount/sessionCount → 契约 reviewCount/studySeconds；vsLastWeek 补 weaknessShift 去旧 accuracyDelta/starredDelta/wrongDelta；weakPoints 补 subject（学科分组核心依赖）+ stateText 改家长文案。
7. **导航安全**（Oracle C3）：studentId 缺失（书签/深链接失效）→ 回 dashboard；周/月切换旧数据保留（非全屏 loading 闪烁）；整段 accuracy null → 空态卡。
