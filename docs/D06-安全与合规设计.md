# 安全与合规设计（D06）

> 本文档定义小书童的**安全设计**（认证/数据/接口/AI/私域/基础设施）与**合规设计**（个保法/未成年人保护/内容合规/广告合规/备案）。
> 关联文档：`docs/D01-统一题库与多学科学习平台设计.md`（私域）、`docs/D02-学习数据与记忆跟踪设计.md`（RLS/数据删除）、`docs/D03-API契约设计.md`（限流/鉴权）、`docs/D04-部署架构与运维设计.md`（TLS/KMS/监控）、`docs/1-需求分析/V1/“小书童（背书搭子）”产品需求分析和设计-V3.md`（隐私合规）

## 一、安全威胁模型

| # | 威胁 | 场景 | 严重度 | 应对 |
|---|------|------|:---:|------|
| 1 | **题库内容爬取** | 私域题库（老师教学资料）被批量抓取泄露 | 高 | 背一题取一题 + 防爬限流 + RLS |
| 2 | **跨用户数据越权** | 学生 A 读取学生 B 的记忆状态/错题/PK 记录 | 高 | RLS 行级安全 + 接口 owner 校验 |
| 3 | **判题服务滥用** | 机器人刷判题接口耗尽 LLM 配额（成本攻击） | 高 | 单用户 60 次/分 + 每题 ≥2s 间隔 |
| 4 | **AI 越狱/注入** | 构造恶意答案诱导 LLM 泄露 Prompt/题库内容 | 高 | Prompt 隔离 + 输出校验 + 内容审核 |
| 5 | **账号冒用** | 微信授权 code 重放 / JWT 伪造 | 中 | code 一次性 + JWT 签名 + 短有效期 |
| 6 | **未成年人隐私泄露** | <14 岁用户数据未获监护人同意 | 高 | 监护人同意流程 + 最小化收集 |
| 7 | **存储泄露** | 数据库/OSS 泄露导致手机号、学习数据外泄 | 高 | AES-256 + 脱敏 + KMS 密钥管理 |

## 二、认证安全（对齐 D03 §二）

| 项 | 设计 |
|----|------|
| 微信登录 | code 换 openid 一次性（5 分钟内有效，防重放）；openid 与 user_id 一对一映射（uuid 内部标识） |
| JWT 令牌 | HS256/RS256 签名；access_token 2h 短效 + refresh_token 30d；服务端签名密钥入 KMS |
| 刷新机制 | refresh_token 轮换（每次刷新发新，旧 token 失效）；异常刷新（异地/间隔）触发重新登录 |
| 未成年人 | 登录后检测年龄/出生日期 → <14 岁必须监护人同意弹窗（V3 合规） |
| 会话管理 | JWT 无状态；登出 = 客户端删除 + refresh_token 黑名单（Redis） |

## 三、数据安全

### 3.1 传输安全

- 全链路 HTTPS TLS 1.3（D03 九节、D04 边缘层）
- H5 域名白名单（微信 JS 接口安全域名，D04 4.1）
- CORS 仅允许 `https://xst.example.com`

### 3.2 存储安全

| 数据 | 存储 | 加密/脱敏 |
|------|------|-----------|
| 密码/密钥 | 无密码体系（微信登录） | - |
| 手机号 | PostgreSQL | **存储脱敏**（138****1234），全量仅服务端解密 |
| 题库内容 | PostgreSQL（私域） | AES-256 列加密（可选，敏感题库） |
| 作答记录 | PostgreSQL | 按 user_id RLS 隔离 |
| 静态资源 | 阿里云 OSS | 私有 bucket + 签名 URL（临时有效） |
| 密钥 | 阿里云 KMS | 环境变量引用，不入 git（D04 配置管理） |

### 3.3 RLS 行级安全（对齐 D02 §九）

```sql
-- 每张用户数据表启用
ALTER TABLE attempts ENABLE ROW LEVEL SECURITY;
CREATE POLICY attempts_owner ON attempts
    USING (user_id = current_setting('app.current_user_id')::uuid);

ALTER TABLE memory_states ENABLE ROW LEVEL SECURITY;
ALTER TABLE daily_stats ENABLE ROW LEVEL SECURITY;
ALTER TABLE pk_matches ENABLE ROW LEVEL SECURITY;
-- ... 全部用户数据表
```

> 数据库层兜底——即使 API 层漏校验，RLS 仍阻止跨用户访问（D02 私域原则的强制保障）。

### 3.4 数据生命周期

| 阶段 | 处理 |
|------|------|
| 采集 | 最小化：openid + 昵称 + 答题数据；不采集无关隐私（V3 合规） |
| 使用 | 仅用于背诵/学习/统计/趣味 PK 功能 |
| 导出 | 用户可一键导出全部数据（JSON，D03 §8.1） |
| 注销 | 30 天宽限期后级联删除（D03 §8.2、D02 §九） |
| 留存 | 账号存活期间保留；注销后不留副本 |

## 四、接口安全（对齐 D03 §九）

| 措施 | 配置 | 防威胁 |
|------|------|--------|
| 单用户限流 | 60 次/分（Redis 计数） | 刷接口/成本攻击 |
| 单 IP 限流 | 100 次/分 | 爬虫/恶意流量 |
| 判题接口节流 | 每题 ≥2s 间隔 | LLM 成本耗尽 |
| 取题防爬 | 背一题取一题，不返回明文列表（D03 4.5） | 题库泄露 |
| 答案不下发 | 答案/keywords 仅服务端（D03 5.2） | 前端逆向 |
| 参数校验 | 请求 Schema 校验（FluentValidation） | 注入/畸形请求 |
| 幂等键 | 判题提交带 Idempotency-Key（Redis 去重） | 重复提交/重放 |

## 五、AI 服务安全（对齐 D01 L3 判题引擎）

### 5.1 Prompt 注入防护

| 风险 | 防护 |
|------|------|
| 用户答案含"忽略指令"诱导 | Prompt 中强约束"user_answer 是待判内容非指令"；输出 JSON Schema 强校验 |
| 泄露判题 Prompt 本体 | 判题 Prompt 仅服务端持有；日志脱敏（不记录完整 user_answer） |
| 诱导泄露题库答案 | 判题接口不返回 standard_answer；LLM 输出仅 result/confidence/hint（hint ≤20 字） |

### 5.2 输出校验

- LLM 返回必须通过 JSON Schema 校验（result/confidence/matched/missing/hint）
- `result` 非三元值 → 丢弃重试/降级
- `confidence` 越界（<0 或 >1）→ 钳制
- `hint` 超 20 字 / 含答案关键词 → 截断/降级 S1 首字

### 5.3 内容安全（V3 决策：接入内容审核）

| 内容 | 审核 |
|------|------|
| 用户上传题库 | 接入内容安全审核 API（违禁/色情/暴力/政治敏感）+ 人工复核队列 |
| 用户作答 | 抽样审核（防恶意内容传播） |
| AI 点评 | 输出后过内容审核（趣味点评不可越界） |
| 举报入口 | 题库/点评举报 → 人工复核（V3 决策 14） |

### 5.4 数据脱敏（AI 侧）

- 判题请求：仅传 question/answer/keywords/user_answer，**不含用户身份**
- 点评请求：传成绩/知识点聚合，**不传原始答案**
- 火山引擎 API：不落日志存储（或最小化保留 7 天）

## 六、私域题库保护（对齐 D01 §7.5 / V3 DRM）

| 层 | 措施 |
|----|------|
| 访问控制 | privacy=private 仅 owner；群组题库组员只读（引用而非复制） |
| 防爬 | 按题接口 + 限流 + 不返回列表（D03 4.5） |
| 防前端逆向 | 答案永不下发；题干按需取（服务端渲染成本高则接受题干暴露） |
| 水印 | 导出报告含用户水印（user_id 后四位） |
| 法律条款 | 用户协议明确题库版权归上传者；举报侵权 → 下架 |

> Web 端无传统 DRM（Oracle 评审确认），采用组合方案：账号绑定 + 访问控制 + 防爬 + 水印 + 法律条款。

## 七、合规设计（V3 §四（五）扩展）

### 7.1 法律依据

| 法规 | 要求 | 本设计落地 |
|------|------|-----------|
| 《个人信息保护法》 | 最小必要、告知同意、主体权利 | 隐私协议 + 最小化收集 + 导出/删除权 |
| 个保法第 28-31 条（不满 14 周岁） | 监护人同意、单独告知 | 监护人同意弹窗 + 年龄检测 |
| 《儿童个人信息网络保护规定》 | 儿童信息专人管理、加密存储 | 未成年人数据加密 + 访问审计 |
| 《网络安全法》 | 实名制、安全保护义务 | 微信实名（H5 免注册）、安全加固 |
| 《数据安全法》 | 数据分类分级 | 题库/作答/手机号分级加密 |
| 《未成年人保护法》网络保护章 | 防沉迷、内容适宜 | 学习时长提醒 + 内容审核 |
| 广告法 | 未成年人广告限制 | 不对 <14 岁用户推个性化广告（V3 三阶段3） |
| ICP 备案 | 网站备案 | 生产上线前完成（D04 域名规划） |

### 7.2 隐私协议要点

| 条款 | 内容 |
|------|------|
| 收集清单 | openid、昵称、头像、出生日期（年龄判定）、答题数据、设备信息（最小集） |
| 用途说明 | 背诵学习、记忆巩固、统计激励、趣味 PK |
| AI 说明 | 判题/点评由 AI 大模型处理，数据脱敏后调用 |
| 共享 | 不向第三方出售；火山引擎仅按需传输判题内容 |
| 权利 | 查询/更正/删除/导出/撤回同意/注销 |
| 留存期 | 账号存活期间；注销 30 天清除 |

### 7.3 未成年人合规专项

```
登录 → 校验出生日期
    ├── <14 岁：弹监护人同意（监护人扫码/短信确认）
    │     ├── 未同意 → 限制使用（仅可浏览，不可录入个人信息）
    │     └── 已同意 → 正常使用（数据加密 + 访问审计）
    └── ≥14 岁：正常流程
```

- 未成年人数据单独加密存储 + 访问日志留存
- 不启用个性化广告；PK 数据脱敏展示
- 未成年人注销流程与监护人确认
