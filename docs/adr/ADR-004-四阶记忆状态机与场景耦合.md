# ADR-004 四阶记忆状态机 + 场景耦合策略

## 状态

活跃

## 上下文

- 问题描述：V2 需求定义了四阶记忆状态（✕△○★）与艾宾浩斯复习，但缺少精确状态迁移规则（"多次答对"是几次？○答错降级到△还是✕？），且 22 份 AI 评估 10/10 一致要求补全状态机公式。多学习场景（背记/检验/PK）对状态机的影响方式未定义。
- 约束条件：V3 核心"艾宾浩斯记忆原理 + 四阶记忆状态追踪"；状态机须跨学科复用（英语单词/历史年代/化学方程式同用）。
- 相关需求：V3 三阶段1.2 四阶记忆状态追踪
- 关联 ADR：ADR-002（跨学科复用载体）

## 选项

### 选项 A：固定间隔无迁移规则

- 描述：按 V2 原文 12h/1d/3d/7d 固定，无状态迁移定义
- 优点：实现最简单
- 缺点：10/10 模型指出"状态机缺精确转换规则无法开发"；无边界条件（★答错/首次背诵/跨天计数）

### 选项 B：固定间隔 + 完整迁移矩阵 + 场景耦合（选定）

- 描述：状态迁移矩阵（独立答对/求助后对/答错 × 4 状态）+ 边界条件（★→○降一级、首次 30min 复习、连续 2 次→★）+ 场景-状态机耦合策略（full/feedback_only/isolated）
- 优点：Oracle 评审确认字段补齐（consecutive_correct/history_accuracy/last_hint_level）；PK 娱乐性与背记严肃性解耦（isolated）；状态机与学科无关
- 缺点：需 hint×result×state 迁移矩阵落库（D01 10.2）；首次间隔科学依据需 Anki FSRS 参考

## 决策

选定：选项 B（固定间隔 + 完整迁移矩阵 + 场景耦合）

理由：Oracle 评审（B8/C5，高严重度）确认 memory_states 缺 `consecutive_correct`/`history_accuracy` 则"连续 2 次→★"无法实现；场景耦合策略（D01 10.3）让 PK 不影响记忆状态、检验只降不升、背记全量演进——三场景数据互不污染（D02 场景隔离设计呼应）。

## 后果

- 正面影响：状态机可复现可审计（attempts 记录 pre/post_state）；跨学科复用；PK/检验不污染背记
- 负面影响 / 风险：Kimi 2.5 指出固定间隔与科学遗忘曲线不符（建议 FSRS），已按 Phase 2 SM-2 演进预留 ease_factor 字段
- 后续待办：D02 attempts/memory_states DDL 落地；Phase 2 引入 SM-2
