## 二、审核结论

**总评：通过**

V0.6.7 审核报告 §四-④ 显式登记的三项后端配合项**全部闭环**，且超出登记范围修复了走查实测暴露的**两类真实缺陷**（G8 表达式缺陷×3、契约可空 NRE×2），teacher create/detail 两页从纯 mock 完整切换到真实契约。核心收益：

1. **taskId 链路打通（配合项 2a）**：`MyTaskItemDto.TaskId`（long，Tasks.Id）直通 → home.tsx 透传 store → task.tsx `createStudySession` 的 `taskId` 由 P0-3 防退化的恒 null **改接真实 DB Id**——任务进度归因链路打通，V0.6.7 登记的防退化注释解除。
2. **children 真实列表（配合项 2b）**：`ChildItemDto.StudentId`（long）与 `dashboardReport.studentId` 同源直通 → parent/dashboard 删 `MOCK_CHILDREN` 改 `children_Execute` 真实拉取（nickname/className 跨账户域空串占位，页面 `学生{id}` 兜底）。
3. **错题标准答案（配合项 2c）**：`WrongQuestionsDto.Answer` 计算字段（`[DtoField(IsComputed=true)]`），GetWrongQuestionsService 富化——**内容权威源优先**（ContentFileStore JSON 反查）→ Keywords 重组兜底（联调种子无内容文件），批处理防 N+1；防爬 BR-19 语义已论证（错题本展示答案属作答后复习场景，非作答前出题通道）。
4. **G8 同款缺陷修复×3（超出登记）**：`string.IsNullOrWhiteSpace(request.Xxx)` 写进 FreeSql 表达式树（SQLite 方言无法翻译，走查实测抛 "request.Status 不能为 null"/INTERNAL_ERROR）→ 状态/学科/用途过滤全部移内存层（G8 先例），排序/分页语义内存层保持。
5. **契约可空 NRE 防御×2（超出登记）**：GQL 省略 request 合法 → 方法签名可空化 + `request ??= new()` 兜底，新增 2 防御用例锁定。
6. **teacher create/detail 完整接线（V0.6.7 遗留）**：create.tsx 删 MOCK_BANKS 改 `listBanks_Execute`+`listGroups_Execute` 真实数据源 + `createTask_Execute` 发布（groupUid 默认第一个、allowRedo 开关、deadline 快捷值→完整 ISO，V0.6.6 教训）；detail.tsx 删三块 mock 改 `taskDetail_Execute`（task + members，状态映射/完成率/学生列表；薄弱点契约无字段 → progress 最低 3 人推导，登记待后端）。
