## 1. 应用概述

**应用名称**：背书小助手（小书童）

**应用描述**：一个面向 6-15 岁学生、群主（原老师/班主任）和家长的家校互动背书应用。核心理念是"提升背书执行力"——**群主布置任务 → 学生执行背诵 → 家长查看成长**。通过记忆曲线算法、进度可视化、鼓励式反馈（★/进度条/热力图）、搭子社交与 PK 激励，帮助学生高效完成背诵任务，同时让家长了解孩子的学习进展。

**视觉风格**：清爽、鼓励感。避免"考试压迫感"，用**进度感**（★/进度条/热力图）代替"分数感"。学生端采用大按钮、图形化、奖励动画；家长/群主端采用信息密度高、表格化设计。

### 1.1 设计语言基调

| 维度 | 约定 |
|------|------|
| 核心视觉 | 清爽、鼓励感。避免"考试压迫感"，用进度感（★/进度条/热力图）代替"分数感" |
| 记忆状态色 | ✕灰-再背背 / △橙-快熟了 / ○绿-很棒 / ★金-点亮了（贯穿全端的状态标识） |
| 年龄适配 | 学生端（6-15 岁）：大按钮、图形化、奖励动画；家长端/群主端：信息密度高、表格化 |
| 移动端 | H5 即点即用，底部 Tab 导航，单列卡片流，一次一题 |
| 反馈规则 | 判题后必须有【正确/错误 + 记忆状态变化】的即时视觉反馈，绝不只弹"打卡成功" |
| 组件基座 | shadcn/ui（tailwind + radix），统一色板/字号/间距/圆角 token |

## 2. 用户与使用场景

### 目标用户

- **学生（6-15岁）**：每天打开 App 查看群主布置的背诵任务，完成任务获得星星奖励，查看自己的学习进度
- **群主（原老师/班主任）**：创建/管理群组，布置背诵任务，查看全组执行进度，了解学生掌握情况
- **家长**：付费查看孩子的成长报告，了解学习进展

### 核心使用场景

1. **学生每日任务**：打开 App → 查看今日任务 → 完成背诵 → 获得反馈 → 与搭子 PK
2. **群主布置任务**：选择内容 → 设定截止时间 → 发布任务 → 查看执行进度
3. **家长查看报告**：查看孩子今日完成情况 → 学习趋势与薄弱点 → 付费解锁完整报告
4. **内测邀请激活**（V2.1 新增）：平台发放内测码 → 群主激活建群 → 导入名单 → 生成一次性邀请码 → 导出 CSV 分发 → 成员凭码 + 微信登录激活

#### 群组任务执行页 /student/study/task ★★核心
- 任务头：任务名 + 群主名 + 截止时间 + 总体进度（已背 x/y）
- 题目区：一次一题，题型渲染（R1 上句接下句 / R2 下句接上句 / R3 段落默写 / O 系列点选）
- 输入方式：文本框（系统语音输入法）+ 语音按钮
- "想不起来？"提示按钮（HintBubble，S1 首字→S2 意象→S3 逻辑逐级加深）
- 判题反馈：正确→绿色+★点亮动画+鼓励语；错误→红色+正确句展示+"再看一遍/下一题"
- 底部进度点阵（当前高亮）

```
│ └────────────────────────┘ │

└────────────────────────────┘
```

**交互时序**（作答→判题→反馈→下一题完整循环）：
1. **进入**：加载第 1 题（题型按 D01 规则取），答题框聚焦（移动端自动调起键盘）
2. **作答**：文本输入或语音输入（语音转文字回填可编辑再提交）
3. **提交**：点"提交"或回车 → 请求判题（≤1s 快判），期间"判题中…"转圈，禁重复提交
4. **正确反馈**：绿色高亮 + ★点亮动画 + 随机鼓励语 → 1.5s 后出"下一题"
5. **错误反馈**：红色高标 + 正确句完整展示 + 记忆状态提示"这题还不熟，✕" → 【再看一遍】原地重背 / 【下一题】跳过进错题本
6. **卡壳求助**：点"想不起来？"→ HintBubble 逐级加深；求助后答对 = 黄色△徽章
7. **中途退出**：进度增量已保存，再次进入从当前题继续
8. **最后一题完成**：自动进入完成庆祝页（"你已完成群主布置的任务"+ 本次点亮 N 颗★ + 分享激励卡可选）

**状态枚举**：
| 状态 | 表现 |
|------|------|
| 作答中 | 答题框可见，提交按钮可点，进度点阵当前题高亮 |
| 判题中 | 按钮 loading"判题中…"，≤1s，禁重复提交 |
| 判题正确 | 绿色反馈区 + ★点亮动画 + 鼓励语，"下一题"1.5s 后出现 |
| 判题错误 | 红色反馈区 + 正确句展示 +【再看一遍/下一题】双按钮 |
| 求助后答对 | 黄色△ 徽章标注"求助后答对"，收益低于独立答对 |
| 作答超长 | 输入框高度约束 3 行内，超出滚动，不撑破布局 |
| 题目为空/加载失败 | 居中占位"题目加载失败" + 重试按钮 |
| 任务全部完成 | 完成庆祝动画，防重复提交（幂等） |

## 4. 文案规范（Copy Tone & Voice）

> 全端文案基调：**鼓励、具体、诚实**。不制造焦虑、不敷衍、不夸大。面向 6-15 岁学生，语气像"靠谱的大朋友"，不带爹味、不用网络烂梗。

### 按钮文案

| 场景 | 文案 | 禁用 |
|------|------|------|
| 主操作 | 动词开头："开始背诵 / 提交 / 发布任务 / 开通报告 / 激活建群" | "确认 / 确定 / OK" |
| 危险操作 | "删除 / 移出群组 / 注销账号"（红色） | "移除"（歧义） |
| 破坏性确认 | 按钮上直接写后果："确认注销账号（不可恢复）" | 弹窗内才说明 |

### 鼓励语库（判题反馈随机取）

| 情感 | 示例 |
|------|------|
| 正确·全对 | "全对！今天的★都被你点亮了" / "这句百分百原味，老师都要给你点赞" |
| 正确·部分 | "背得很顺！下次试试不看提示" |
| 求助后对 | "提示一下就想起来了，记忆正在长出来" |
| 错题·安抚 | "这题还不熟，谁都会卡，再看一眼就熟了"（**不出现"又错了"等指责**） |
| 复习完成 | "记得牢，才是真的会" |

### 空态文案模板（三步式）

| 场景 | 发生了什么 | 为什么 | 下一步 |
|------|-----------|--------|--------|
| 首页无任务 | "今天没有群主布置的任务" | "休息也是积累" | [去自由背诵] |
| 复习无到期 | "今天没有要复习的" | "记得很牢！" | [回首页看看] |
| 错题本空 | "没有错题" | "说明都会了" | [去挑战新内容] |
| 内测码未领取 | "还没有可领取的内测邀请码" | "内测邀请码由平台发放" | [联系平台开通] |
| 名单为空 | "名单是空的" | "没有可导入的手机号" | [重新粘贴/上传] |
| 激活码无效 | "邀请码无效" | "可能输错或已失效" | [重新输入/联系群主] |

### 状态徽章辅助文案

| 状态 | 文案（学生端） | 文案（群主/家长端） |
|------|---------------|---------------------|
| ✕ 灰 | "再背背" | "未掌握" |
| △ 橙 | "快熟了" | "需巩固" |
| ○ 绿 | "很棒" | "已掌握" |

### 合规敏感词（全端禁用）

- ❌ 群组分数/正确率排名、优秀率、及格率、平均分对比
- ✅ 允许：坚持天数、完成度、★数、个人对上周（仅与自己比）

## 6. 业务规则与逻辑

### 记忆状态系统
- ✕灰：未掌握（再背背）｜△橙：需巩固（快熟了）｜○绿：已掌握（很棒）｜★金：熟练（点亮了）

### 判题反馈规则
- 正确：绿色高亮 + ★点亮动画 + 鼓励语
- 错误：红色高标 + 正确句展示 + "再看一遍"按钮
- 求助后答对：黄色△徽章（收益低于独立答对）

### 复习队列规则
- 基于记忆曲线算法；到期知识点自动进入复习队列；逾期知识点红标警示

### 付费报告规则
- 试用期 7 天；订阅费用 10 元/月或 100 元/年；多孩子独立计费；到期报告区锁定置灰

### 学习搭子规则
- 最多添加 5 个学习搭子；可查看搭子的连续打卡天数；邀请通过海报二维码或链接；**双向同意才成为搭子**；搭子互看排名

### 排名趋势规则
- 每天记录排名变化（RankSnapshots 每日冻结）；上升↑绿 / 下降↓红 / 持平→灰；战力榜 = 坚持天数+背诵量+PK 胜场；战绩榜 = 正确率+掌握度（**受群组开关 RankEnabled 控制**）

### 内测邀请机制规则（V2.1新增）
- 平台发放内测邀请码给群主（用户端无生成入口），群主凭码激活建群资格（一码一群组，used/expired）
- 群主导入/批量粘贴成员手机号名单 → Agent 整理（去重/格式校验/非法剔除）→ 预览确认 → 每人生成一个一次性邀请码（码↔手机号后四位绑定，同一名单内唯一）
- 一次性码仅可激活一次（激活后 used 不可复用），默认 30 天过期
- CSV 导出仅含手机号后四位 + 一次性邀请码（不含 openid/完整手机号/学习数据），OSS 存 7 天过期（对齐 D02 §4.17/4.18 隐私合规）
- 成员激活：输入一次性码 + 手机号后四位 + 微信登录 → 校验码未用/未过期且后四位与名单一致 → 加入群组、绑定微信 ID（手机号补绑定留内测后）

## 11. 给 UI 设计的关键提示（设计原则）

1. **先接设计系统，再画页面**——色板/字号/间距/圆角 token 全端保持一致（shadcn/ui）
2. **首页"今日任务"必须最醒目**——学生每天打开的第一眼，执行力工具的门面
3. **判题反馈不等于打卡**——错误要展示"错在哪、正确是什么"，绝不做"已完成"糊弄
4. **记忆状态色是贯穿语言**——✕灰/△橙/○绿/★金全端统一，让学生看懂"上涨还是回落"
5. **努力度 > 分数**——所有排名/对比只呈现坚持天数/完成度/★数，永不展示正确率排名（合规红线）
6. **家长报告是付费产品**——信息密度可以高，但要"看得懂、有收获"，展示相对进步而非焦虑榜
7. **空态和加载态也是设计**——每个空态配"发生了什么/为什么/下一步"三步文案，不留空白页
8. **移动端一次一题**——答题场景绝不并排多题；大按钮 + 拇指可达区（底部操作区 56px 以上）
