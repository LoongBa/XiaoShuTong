# 全页面真实链路走查补齐 - 开发方案（V0.6.7）

## 一、背景与目标

### 1.1 背景

V0.6.6 打通了浏览器端到端走查（登录/首页/排名榜 5/5 PASS），修复了：
- GraphQL 契约接线（`selectionMap` + `variableTypesMap`，tsclient 1.0.10）
- 首页 DateTime 契约（reviewQueue ISO + heatmap 区间必填）
- 框架会话通道缺陷（ADR80，框架组实验 3 修复）

但 V0.6.6 审核报告 §七 明确：**仅聚焦 V0.6.4/05 目标页（首页/排名榜）**，其余页面（任务执行/结果/复习/错题本/热力图/自由背诵/个人中心/家长端/老师端）真实数据链路未验证。页面级契约审计（explore 全矩阵）发现：

**核心根因——store 双轨断裂**：
- `home.tsx:39-41` 用**本地 useState** 遮蔽了 store 同名 setter（`setTasks/setReviewItems/setLearningStats`），首页真实拉到的数据永远留在首页内部
- `store/appStore.ts` 的 6 个 setter（:129-134）**全仓库 0 调用者**；`initMockData`（:226）**全仓库 0 调用**
- 结果：review / wrong / heatmap / self / profile 5 个页面读到的 store 恒为 `[]`——它们不是"接到 mock"，是**从未接到任何数据源**

**接线分布**：14 个业务页面中，7 个（login/home/rank/task/result + teacher-dashboard + parent-dashboard）发出 17 个真实 GraphQL 操作；另 **7 个零真实调用**（review/wrong/heatmap/self/profile + teacher-create/detail）。

**契约错配 4 类（会静默出错）**：
1. `rank.tsx:134` subject 传小写英文（`'chinese'/'math'/...`），契约要求 `All/语文/…/政治`（DOMAIN_MAP.md:360）
2. `task.tsx:133` `Number(taskUid字符串)` 恒 NaN → taskId 恒 null（任务进度永不归因）
3. `teacher/dashboard.tsx:92` 数值 `groupId` 转字符串当 `groupUid` 用
4. `home.tsx:102` 用显示符号 `✕△○` 比对后端 PascalCase 枚举 → 所有复习项误显为 ★点亮

**运行时前提**：`main.tsx` 走真实 `/graphql`，`MockTransport` 全仓库 0 导入——**无任何 mock 兜底**，走查失败即真 400，不会有假通过。

### 1.2 目标

1. **走查推广**：浏览器端到端走查覆盖全部 14 个业务页面（V0.6.6 未走查的 9 个 + 已走查 2 个复验）
2. **断链修复**：打通 store 数据回写（P0-1），使 5 个"死页面"从空态变为能拉到真实数据
3. **契约修复**：修复走查暴露的 P0/P1 契约错配（rank subject 枚举 / taskId 语义 / teacher 字段 / parent 未消费字段 / home 记忆状态）
4. **数据可用**：7 个零调用页面中，可由现有契约直接接线的页面（review/self/profile/heatmap 三接口）接通真实数据
5. **文档闭环**：补 `.TKWF/GraphQL_Api.md` ReqDtoInput 缺口 + 页面→操作映射，登记契约缺口（WrongQuestionsDto 答案字段等）

### 1.3 范围决策（不做什么）

| 不做 | 理由 | 归属 |
|------|------|------|
| teacher/tasks/create + detail 的**完整功能接线**（表单补 questionIds/allowRedo/deadline 输入、任务详情全量展开） | 涉及 UI 表单扩展与交互设计，超出"走查补齐"目标，工作量最大 | 另立迭代（V0.6.8+） |
| wrong.tsx 错题本 UI 改设计（契约无 wrongAnswer/correctAnswer） | 需产品决策（改显 summary+wrongCount 或后端补字段），本次仅走查并登记缺口 | 待产品决策 |
| 学习搭子（rank.tsx MOCK_BUDDIES）接 buddies_Execute | 独立功能域，本次走查仅验证有 mock 占位不阻断 | 另立迭代 |
| Parent 付费流程（startTrial_Execute/subscriptions_Execute） | 依赖真实计费环境，本次仅消费已返回字段 + 修死路由 | 保留 mock |
| 后端 Domain 层 DTO 改动（MyTaskItemDto.taskId / ChildItemDto 映射 / WrongQuestionsDto 答案） | 跨模块，需 tkwf-entity/tkwf-service 路由 + 独立评审 | 登记为后端配合项，本次标记 |
