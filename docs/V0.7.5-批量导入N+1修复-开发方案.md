### 1.3 实现路径（框架批量 API 实证）

- **批量 API 实证**（`_TKWF\docs\AC-Kit\references\DataService-API-参考.md` L49-59）：`DomainDataServiceBase<TEntity>` 提供 `EntitySelectAsync`（谓词批量查询，支持 `ids.Contains(x.Id)` IN）+ `EntityCreateBatchAsync` / `EntityUpdateBatchAsync` / `EntityUpdateColumnsBatchAsync`（批量写，sealed，CRUD 自动处理权限/审计/事务）。
- **G15 实证（V0.7.3）**：`EntityUpdateBatchAsync`（FreeSql `UpdateRange`）要求实体**已 attach**，`EntitySelectAsync` 返回游离实体 → "不可更新，数据未被跟踪"；**`EntityUpdateColumnsBatchAsync`（SetSource 路径）支持游离实体**——ImportBankJson update 侧必须用后者。
- **已修复范式参照**：V0.7.3 四个 Job（读侧一次 IN + 内存分组/map、写侧批量 UpdateColumns）+ V0.7.2 `TaskOverdueScanJob`（一次 IN → 内存分组）——照抄。
- **SQLite IN 上限（测试环境）**：Tier 1.5 SQLite :memory: `MAX_VARIABLE_NUMBER=999`——测试数据量 < 999 行。

## 二、任务 T1：ImportQuestionsService（读侧一次 IN + 写侧批量 + 文件 IO 移出循环）

### 2.1 现状（源码实证）

`ImportQuestionsService.ExecuteAsync` L75-107：

- **L75-78 读侧 N+1**：`foreach (var q in parsed.Questions)` → `QuestionsDs.EntityGetAsync(x => x.BankId == bank.BankId && x.QuestionId == q.QuestionId)` —— 每题一次判重查询
- **L89-91 文件 IO 循环内**：`LoadOrCreateContentFileAsync`（读整文件）+ `ContentFileStore.Save`（写整文件）—— 每题全量读改写（内存字典桩但序列化/反序列化全量）
- **L94-106 写侧 N+1**：`QuestionsDs.EntityCreateAsync(...)` —— 每题一次提交

### 2.2 改动

```csharp
// 读侧：一次 IN 全量取库内题目 → 内存 HashSet 判重
var existingQuestions = await QuestionsDs.EntitySelectAsync(
    x => x.BankId == bank.BankId, ct);
var existingIds = existingQuestions.Select(q => q.QuestionId).ToHashSet(StringComparer.Ordinal);

// 文件 IO：循环外 Load 一次、循环内仅内存 Add、循环外 Save 一次
var contentFile = await LoadOrCreateContentFileAsync(bank.JsonPath, ct);
var toCreate = new List<Questions>(parsed.Questions.Count);

foreach (var q in parsed.Questions)
{
    if (existingIds.Contains(q.QuestionId))
    {
        failures.Add($"题目 {q.QuestionId} 重复，跳过");
        continue;
    }

    var keywordGroups = ExtractKeywordGroups(q.Answer);
    contentFile.Questions.Add(new ContentQuestionRecord(q.QuestionId, q.Stem, q.Answer, keywordGroups));

    toCreate.Add(new Questions
    {
        UId = UidGenerator.NewId(),
        QuestionId = q.QuestionId,
        BankId = bank.BankId,
        ChapterId = q.ChapterId,
        QType = q.QType,
        Content = JsonSerializer.Serialize(new { q.QuestionId, q.Stem, q.ChapterId }),
        Keywords = JsonSerializer.Serialize(keywordGroups),
        KnowledgePoints = q.KnowledgePoints,
        Difficulty = 0,
        Status = QuestionStatus.Active,
    });
}

ContentFileStore.Save(bank.JsonPath, SerializeContent(contentFile));  // 循环外一次

if (toCreate.Count > 0)
    await QuestionsDs.EntityCreateBatchAsync(toCreate, ct);  // 写侧批量
```

## 三、任务 T2：ImportBankJsonService（读侧一次 IN + create/update 分列批量 + 文件 IO 移出循环）

### 3.1 现状（源码实证）

`ImportBankJsonService.ExecuteAsync` L100-151：

- **L103-104 读侧 N+1**：`foreach (var q in questions)` → `QuestionsDs.EntityGetAsync(x => x.BankId == bank.BankId && x.QuestionId == q.QuestionId)` —— 每题一次 upsert 判重查询
- **L113-116 文件 IO 循环内**：`LoadOrCreateContentFileAsync` + `ContentFileStore.Save` —— 每题全量读改写
- **L120-146 写侧 N+1**：`EntityCreateAsync`（新题）/ `EntityUpdateAsync`（存量 upsert）—— 每题一次提交

### 3.2 改动（Oracle 决策点：create/update 分离批量 + 游离实体更新）

```csharp
// 读侧：一次 IN 全量取库内题目 → 内存 dict by QuestionId
var existingQuestions = await QuestionsDs.EntitySelectAsync(
    x => x.BankId == bank.BankId, ct);
var existingById = existingQuestions.ToDictionary(q => q.QuestionId, StringComparer.Ordinal);

// 文件 IO：循环外 Load 一次、循环内仅内存增删、循环外 Save 一次
var contentFile = await LoadOrCreateContentFileAsync(bank.JsonPath, ct) ?? new ContentFileRecord("", "V1.0", []);
var toCreate = new List<Questions>(questions.Count);
var toUpdate = new List<Questions>(questions.Count);

foreach (var q in questions)
{
    var hint = cardMap.GetValueOrDefault(q.KnowledgeCardId ?? string.Empty);
    var keywordGroups = ImportQuestionsService.ExtractKeywordGroups(q.Answer);

    contentFile.Questions.RemoveAll(x => x.QuestionId == q.QuestionId);
    contentFile.Questions.Add(new ContentQuestionRecord(q.QuestionId, q.Stem, q.Answer, keywordGroups, hint));

    var contentMirror = new { q.QuestionId, q.Stem, q.ChapterId, CardType = "authorCard", Card = hint };
    if (!existingById.TryGetValue(q.QuestionId, out var existing))
    {
        toCreate.Add(new Questions { ... UId = UidGenerator.NewId(), ... Hint = hint });
    }
    else
    {
        existing.Content = JsonSerializer.Serialize(contentMirror);
        existing.Keywords = JsonSerializer.Serialize(keywordGroups);
        existing.KnowledgePoints = q.KnowledgePoints;
        existing.Topic = q.Topic;
        existing.Hint = hint;
        toUpdate.Add(existing);
    }
}

ContentFileStore.Save(bank.JsonPath, SerializeContent(contentFile));  // 循环外一次

if (toCreate.Count > 0)
    await QuestionsDs.EntityCreateBatchAsync(toCreate, ct);  // 写侧批量（create）
if (toUpdate.Count > 0)
    await QuestionsDs.EntityUpdateColumnsBatchAsync(toUpdate, ct);  // 写侧批量（update，游离实体 → 必须 UpdateColumns，G15 实证）
```

**Oracle 决策点 M2（update 批量 API 选择）**：`EntityUpdateBatchAsync` 要求已 attach 实体（G15 实证：游离抛"未跟踪"），`EntitySelectAsync` 返回游离实体 → **必须用 `EntityUpdateColumnsBatchAsync`**（SetSource 路径，V0.7.3 BankHint 实证可用）——方案默认即此，Oracle 确认。

**语义保持**：BR-11/13 权限预检不变；幂等键 = QuestionId upsert（不重复创建，`ExecuteAsync_Reimport_UpsertsNotDuplicates` 测试验证）不变；ADR-010 决策六 Hint join 不变；BR-15 原子（`[Transactional]` + sealed 批量单事务）不变；Content 镜像 cardType/card 字段不变。

```csharp
private async Task<List<string?>> LoadGradesAsync(IEnumerable<long> groupIds, CancellationToken ct)
{
    var ids = groupIds.ToArray();
    if (ids.Length == 0) return [];
    var groups = await GroupsDs.EntitySelectAsync(x => ids.Contains(x.Id), ct: ct);  // 一次 IN
    return groups.Select(g => g.Grade).ToList();
}
```

## 八、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| `EntityUpdateBatchAsync` 游离实体不可用（G15） | ImportBankJson update 批量直接沿用会抛"未跟踪" | **已实证**：用 `EntityUpdateColumnsBatchAsync`（SetSource 路径）——V0.7.3 BankHint 已落地 |
| 批量写事务语义 | 批量失败整体回滚 vs 逐行部分成功 | 类级 `[Transactional]` + sealed 批量单事务：BR-15 要求文件+索引**原子**——批量恰好符合（单事务原子）；逐行部分成功反而是非原子 |
| 读侧全量 IN 取库内题目 | 大题库全量加载内存 | 判重必须全量（要知"是否存在"）；题库规模有限（≤万级题目），单库一次 IN 可接受；如超 IN 上限可分块 |
| 文件 IO 移出循环 | contentFile 内存引用在循环外 Save | 循环内仅内存 Add/RemoveAll，引用同一实例——无并发问题（单方法单线程） |
| SQLite IN 上限（测试环境） | 测试数据超限即失败 | 测试数据 < 999 行 |
