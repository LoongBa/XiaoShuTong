# 家长端付费流程真实化 - 开发方案（V0.6.12）

## 一、背景与目标

### 1.1 背景

家长端付费流程（startTrial/subscriptions）为 V0.6.7 审核报告 §七 登记的独立功能域遗留项（"付费流程（startTrial/subscriptions）——独立功能域另立"）。V0.6.3~08 期间已消费 dashboardReport 部分字段（P1-5），但**付费核心交互仍是纯 mock**。

**现状核查（后端 Service 实读 + 契约实证）**：

1. **后端订阅能力**（Services/Parent/ 手写源码实读）：
   - `StartTrialService`（[GenerateController] 暴露）：BR-05 授权链→8002 / BR-06 已试用幂等返回原记录 / BR-07 试用 +7 天（Trialing）。`startTrial_Execute({studentId})` → `{subscriptionUid, status:"Trialing", trialEndAt}`
   - `ListSubscriptionsService`（暴露）：`listSubscriptions_Execute`（无参）→ `items[{subscriptionUid, studentUid, studentNickname, plan, status, trialEndAt, periodEndAt}]`
   - `CancelSubscriptionService`（暴露）：`cancelSubscription_Execute({subscriptionUid})`
   - **`ActivateSubscriptionService` = Callee 不暴露**（V0.6.8 WARN004 登记：支付回调，非对外 RPC）——**前端无"支付开通" mutation**。BR-08 授权链 / BR-09 重复回调幂等 / BR-10 Plan=Month+1月 Year+1年
   - `ParentReportGate`（共享校验）：dashboard 无订阅 → 预览模式（locked=true）；progress/weakness 无订阅 → 8001；试用过期 → 8003；有效权益（Trialing/Active/Cancelled 周期内）→ unlocked

2. **dashboardReport 已返回订阅字段**（P1-5 已消费部分）：
   - `GetDashboardReportResDto.subscription: SubscriptionBriefDto | null`（status/trialEndAt）+ `locked: boolean`
   - **契约错配**：前端 L122 `(status === 'Active' || status === 'Trial')`——**'Trial' 应为 'Trialing'**（SubscriptionStatus.Trialing.ToString()="Trialing" 实证）→ 试用中会被误判未订阅（真实缺陷）

3. **前端现状**（parent/dashboard.tsx 实读）：
   - `isSubscribed` state（init false）→ L122 已被订阅判断填充（但 Trialing 错配）
   - `locked` state（init false）→ L124 已消费 res.locked
   - `trialDaysLeft` state（**本地硬编码 init 7**）→ L181 试用提示"剩余 7 天"恒死值
   - "确认支付"按钮（L382-383）= `setIsSubscribed(true)` + 关弹窗 **纯本地假交互**（无任何后端调用）
   - 订阅弹窗（月付/年付选择）纯 UI

4. **UI 设计规则**（L546-547）：试用 7 天；订阅 10 元/月或 100 元/年；多孩子独立计费；到期锁定置灰。L390：未付费预览前 2 项+模糊遮罩+"开通"CTA；试用中黄条倒计时；已订阅隐藏付费入口

### 1.2 目标

1. **订阅状态真实化**：subscription 字段全消费——isSubscribed 判定修正（'Trial'→'Trialing'，真实缺陷修复）+ trialDaysLeft 从 `subscription.trialEndAt` 计算（替代本地 7）+ locked 门控对齐
2. **试用真实接线**：新增"免费试用 7 天"交互接 `startTrial_Execute({studentId})`（多孩子独立计费：startTrial 按孩子开，与当前 SelectedChild 绑定）——幂等安全（BR-06 重复点击返回原记录）
3. **支付开通登记配合项**：ActivateSubscription 是 Callee（支付回调签名验证对接切片未实施）→ "确认支付"保留占位，登记生产配合项（微信支付回调基建 + 前端支付下单）
4. **mock 补齐**：mock data subscription/trialEndAt 字段对齐（若缺）
5. **锁定态预览对齐**：locked=true 时报告区预览+遮罩（UI L390 语义）

## 四、技术方案

### 4.1 订阅状态真实化（T1）

```tsx
// 订阅状态：从 dashboardReport.subscription 契约值派生（替代本地 mock；Trialing 修正）
const sub = res.subscription; // SubscriptionBriefDto | null
setIsSubscribed(sub !== null && (sub.status === 'Active' || sub.status === 'Trialing' || sub.status === 'Cancelled')); // Trialing 大写修正 + Cancelled 周期内仍有权
setTrialDaysLeft(sub?.status === 'Trialing' && sub.trialEndAt
  ? Math.max(0, Math.ceil((new Date(sub.trialEndAt).getTime() - Date.now()) / 86400000))
  : 0);
setLocked(res.locked ?? false); // 既有 L124 保留
```

- **Trialing 判断修正**（契约错配实证）：后端 `SubscriptionStatus.Trialing.ToString()="Trialing"`，前端原 `'Trial'` 永不命中——试用中被误判未订阅。修正为 `'Trialing'`
- **trialDaysLeft 计算**：从 trialEndAt 差值取 ceil 天数（试用提示"剩余 N 天"真实化）；过期归 0
- **Cancelled 周期内**：ParentReportGate L60 "Cancelled 周期内有效"——订阅中但已取消（周期内）仍应视为已订阅
- **试用过期边界（Oracle C2）**：`SubscriptionStatus.Expired=2` 独立枚举（实证）；`Trialing` 且 trialEndAt 已过 → 显示"试用已过期，立即开通"（非"剩余 0 天"）；`Expired` → locked 态锁定

### 4.2 试用接线（T2）

订阅提示卡（"解锁完整成长报告"）旁新增"免费试用 7 天"按钮（或与"立即开通"并列：试用主 CTA，开通副 CTA）：

```tsx
const handleStartTrial = async () => {
  if (!selectedChild) return;
  setTrialSubmitting(true); setTrialError('');
  try {
    const res = await Tkwf.User.Use<StartTrial_ExecuteService>().startTrial_Execute({
      request: { studentId: selectedChild.studentId },
    });
    if (!res.success) { setTrialError(res.errorCode || '开通试用失败'); return; }
    // 成功（含幂等返回原记录 BR-06）→ 置试用态 + 刷新报告（locked 解除）
    setIsSubscribed(true); setTrialDaysLeft(7); setLocked(false);
    setShowSubscribeDialog(false);
    void loadMastery(); // 重拉 dashboardReport 获取真实 trialEndAt/locked
  } catch (err: any) {
    setTrialError(err?.code || err?.message || '开通试用失败');
  } finally { setTrialSubmitting(false); }
};
```

- **多孩子独立计费**（UI L547）：startTrial 入参 `studentId = selectedChild.studentId`（当前选中孩子）——与 dashboardReport 查询同一孩子绑定（下钻按 SelectedChild 拉）
- **幂等安全**（BR-06）：已试用/已订阅 → 后端返回原记录（Success=true），重复点击不重复开试用
- **多孩子切换刷新（Oracle C3）**：`selectedChild` 变化 → 触发 loadMastery（重拉 dashboardReport）→ 订阅状态自动刷新（切换孩子后 isSubscribed/trialDaysLeft 随新孩子更新，不残留上一孩子状态）
- **已订阅隐藏试用（Oracle C4）**：`isSubscribed === true` 时隐藏"免费试用"按钮（对齐 UI L547"已订阅隐藏付费入口"）；试用中显示剩余天数条 + 隐藏试用按钮
- **本地置态 vs 重拉权威（Oracle 建议）**：本地 `setIsSubscribed(true)` 为即时反馈，`loadMastery()` 重拉为权威校正（后端 locked/status 为准覆盖本地）——注释说明避免实施时纠结顺序

### 4.3 "确认支付"改造（T3）

### 4.4 锁定态预览（locked 门控）

- locked=true（无订阅/试用过期）→ 报告区已预览（当前 subjectMastery 等已渲染）+ 付费入口置灰（当前 `opacity-70` 已有）——对齐 UI L390

### 4.5 mock 补齐（T4，Oracle C1 修正：多场景并存，勿改 Active）

mock data dashboardReportResDtos **保留既有场景并新增 Trialing 场景**：
- 场景 A：`subscription=null, locked=true`（无订阅预览，已存在 L699）✅ 保留
- 场景 B：`subscription: { status: "Trialing", trialEndAt: +7d }`（**新增**——试用中走查，当前 mock 缺此场景）
- 场景 C：`subscription: { status: "Active" }`（已订阅，已存在 L705）✅ 保留——**勿改为 Trialing**（丢失已订阅覆盖）

startTrialResDtos 已存在（data.ts:674-677）✅ 可用；补 1 条错误场景（`success:false, errorCode:"8002"` 授权链失败）供错误链路走查。
