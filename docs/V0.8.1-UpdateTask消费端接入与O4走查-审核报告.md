### 5.3 走查伴生修复（新发现缺陷）

**home.tsx L95 status 映射缺陷**（走查实证：任务卡消失）：服务端 `MyTaskItemDto.Status` 返回 PascalCase（`InProgress`/`Overdue`）→ 前端 `item.status?.toLowerCase()` 得 `inprogress`（无下划线），但 L140 今日任务过滤条件用 snake_case `in_progress` → **InProgress/Overdue 任务被错误过滤**（首页「今天没有老师布置的任务」假空态；Pending/Completed 拼写恰好一致未暴露）。修复：显式映射 `inprogress → in_progress`（L95 三目）。**typecheck 0 错误 + 运行时实证**（修复后任务卡恢复显示 + Pending 路径无回归）。

> 注：该缺陷此前未暴露（走查前任务分配均为 Pending；本次走查将任务改 InProgress 后首现）——走查价值再实证。
