### 2.2 编译实证（关键纠偏）

- **CS0104 命名空间歧义**：`XiaoShuTong.Services.TaskManagement`（非 Api）与 `.Api` 均定义 `GetTaskDetailResDto`/`UpdateTaskReqDto`——Oracle C7 建议「补 using」经编译验证**反向修正**为「移除非 Api using，仅保留 .Api」（SG 生成 .Api 副本为准）。
- **`MessageService` 无 Confirm**：反射 AntDesign.dll 实证仅 Success/Error/Info/Warning——二次确认改用 `ModalService.ConfirmAsync(ConfirmOptions) → Task<bool>`（`OkType` 为 `ButtonType` 枚举非 string；`ButtonType` 无 Danger 值，用 Primary）。
- **契约刷新**：`dotnet build` AdminWasm 触发 `_EnsureWebApiMetadata`（csproj L84-95 实证）→ ApiMetadata.g.cs 6:46 刷新，含 `IUpdateTaskService` + `UpdateTaskReqDto/ResDto`（含 QuestionSetChanged/RecalculatedAssignments/QuestionCount）→ SG3 生成代理，**build 0 错误**（4 警告为既有 MSB3277 Localization 冲突）。
