### 0.3 WARN004 消歧核对结论（AdminWasm-V0.1.9，V0.6.18+ 补充实证）

**触发面**：领域层 62 个 Service 方法名统一为 `ExecuteAsync`（TKWF 官方模板约定），SG2 检测到 Query/Mutation 根下 resolver 字段名 `Execute` 全面重名 → 报 `TKWF_SG2a_WARN004` 并**自动消歧**为 `{服务短名}_Execute`（如 `CreateBankController`/`GetBankDetailController` → `createBank_Execute`/`bankDetail_Execute`；`Get` 前缀剥除、其余保留，方法段保留 PascalCase `Execute`）。schema 现暴露 **54 个 `_Execute` 字段**（运行时实证：`createBank_Execute` 存在、裸 `execute` 字段不存在）。

**消费端核对（V0.6.18 全链路实证）**：
- **WebH5（React/ts-client）**：gen-ts-client 解析 schema.graphql 生成 → 天然使用消歧名（`createBank_Execute` 等），运行时走查全 PASS（V0.6.3~V0.6.7 真实链路实证）✅
- **AdminWasm（Blazor/SG3）**：当前**无 SG3 GraphQL 代理**（编译产物 `createBank_Execute`/`execute`/`Api.Client` 字符串计数全 0，`obj/` 无 generated/ 目录）→ **事实上未受影响**。⚠️ 但注意：SG3 客户端生成器从 `ApiMethodInfo`（仅 Name/ReturnType/ApiType/Parameters/IsExposed 五字段，**不含消歧后字段名**）本地重推导 `execute`——若将来启用 SG3 GraphQL 代理通道将 400（字段不存在）→ **已登记框架侧缺陷建议**（SG2b 把最终字段名写入 ApiMethodInfo，或 SG3 复刻冲突检测算法）。规避：AdminWasm 走 `ApiClientType.Rest`（REST 路由 `/create-bank/execute` 完全不受 WARN004 影响）。
- **judgment**：**无需代码改动**（服务端已正确、WebH5 天然对齐、AdminWasm 当前零影响）；**不静默关闭警告**（`<NoWarn>` 不可取——WARN004 是"静默丢失服务"的唯一可观测信号，V4.9.109 前曾有服务因重名被静默覆盖的历史）；不批量改名 53+ 服务（破坏性变更 + 与官方模板 `ExecuteAsync` 约定冲突 + 牵动 REST 路由）。

**遗留登记**：SG3 GraphQL 契约缺口（框架侧）、`Execute` 全量归 Query 根——**已 Oracle 评审定为「维持现状（事实状态，功能正确）+ G16 客户端根治」（2026-10-03，方案 `docs/草稿/P1-Execute归Query根评估方案.md`，附条件通过）**：不改框架 `IsMutationMethod` 判定表（Execute 统一模板加入前缀表会双向恶化——读方法一并迁 Mutation 根）、不改应用 Service 命名（与官方模板冲突）、不迁 54 字段（双消费端零重建）。真问题 = G16 `@tkwf/tsclient` SDK 前缀启发式（已绕行，待框架根治）。闭环条件（M1 五项）：框架 G16 修复部署 → 升级 SDK → 移除 `sdk-bypass.ts` 还原 3 处直调 → 验证剩余 4 方法（createBank/createGroup/createParentRelation/createPkMatch，M2 已盘点：当前均无业务调用→低风险）→ 验收。

## 六、实施纪律

- 前端页面开发走 **AntDesign Pro 组件模式**（参考 DMP-Lite.AdminUI 的页面写法），不引入新 UI 库
- 数据访问一律 `DomainUser.Use<TService>()`（GraphQL），**不手写 HttpClient/gql 字符串**
- 不读生成源码（*.g.cs / DataServices\*.cs / Entities\*.cs）；DTO 字段以 Service 源文件注释为准
- 每迭代结束：`dotnet build` + 提交（逻辑单元收敛为 1-2 个提交）
- 阶段不 tag（tag 需另行征求同意，遵循 AdminWasm-V 版本线纪律）
