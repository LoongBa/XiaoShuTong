# 错题闭环：重练定向出题 + 标记已掌握 - 开发方案（V0.6.14）

## 一、背景与目标

### 1.1 背景

V0.6.9 审核报告 §七 登记两项配合项：
- **重练定向出题**："handlePractice 仅 navigate 到 task 页，GetNextQuestion 无'错题专练'模式——登记配合项"
- **移回错题本真实后端操作**："当前无 MarkMastered 写服务，已掌握 tab 无操作按钮——登记配合项（需后端新增 Service + 测试，tkwf-service 路由）"

**现状核查（explore 后端机制实证）**：

1. **GetNextQuestionService 机制**（Bank 域 internal Callee，WARN004 登记）：
   - 对外取题走 `Learning/GetSessionQuestionService`（`getSessionQuestion_Execute` 薄包装），响应复用 `GetNextQuestionResDto`
   - `GetNextQuestionReqDto` 仅 4 字段：`SessionId / BankId / Type(可空) / KnowledgePoint(可空)`——**均为正向过滤，无法表达"限定为某用户错题集"**（需 QuestionId 白名单反向限定）
   - 出题逻辑：BR-17 访问权 / BR-18 空题返回空 / BR-04 混合比（ReviewRatio=0.7）/ BR-20 状态机排序 / BR-19 防爬
2. **WrongQuestions 实体**：`Mastered` 布尔（唯一可用字段，无 Status/MasteredAt）；BR-23 由 SubmitAttemptService 自动流转——**答错强制 `Mastered=false`**，连续 2 次 Correct 置 true
3. **无既有 MarkMastered 链路**：grep 证实 `.Mastered` 赋值仅存在于 BR-23 三处；WrongQuestionsDataService 仅被写（SubmitAttempt）读（GetWrongQuestions）两个 Service 消费
4. **错题查询能力**（GetWrongQuestionsReqDto，V0.6.9 已接）：`Mastered(false=待掌握) / Subject / PageIndex / PageSize`——可拿错题集（含 QuestionId）
5. **BR 缺口**：错题专练、MarkMastered **均无 BR 依据**（BR-43~46 仅覆盖查询；激励-BR-15 限定"Mastered 置位在学习域"）——需 tkwf-business 增量物化

### 1.2 目标

1. **错题专练**：重练导航（→ /student/study/task）后创建的会话按**当前用户待掌握错题集**定向出题——复用 GetNextQuestionService 加 `QuestionIds` 白名单参数（最轻量，防爬/排序/混合比逻辑全复用）
2. **MarkMasteredService**：错题本"标记已掌握/移回"真实后端操作（学习域，对齐激励-BR-15 域边界）——仅翻转 `Mastered` 布尔（选项 A：手动标记是临时展示分组，BR-23 作答照常驱动，答错重置不豁免）
3. **前端 wrong.tsx 接线**：重练按钮传错题 QuestionId 集（重练会话定向出题）；已掌握 tab 补"移回"按钮（调 MarkMastered(false)）、待掌握 tab 补"标记已掌握"按钮（调 MarkMastered(true)）
4. **合约链路**：GetNextQuestionReqDto 加字段 → 薄包装转发 → 前端 codegen 刷新

### 1.3 范围决策（不做什么）

| 不做 | 理由 | 归属 |
|------|------|------|
| MarkMastered 豁免 BR-23 重置（选项 B） | 需新增 `ManuallyMastered` 实体字段，成本高；产品语义"手动标记是临时分组、答错重新进入错题"合理 | 不做（选项 A） |
| MarkMastered 删除错题记录（选项 C） | 删除语义丢失错题历史（WrongCount/LastWrongAt），与"移回"需求冲突 | 不做（选项 A） |
| 场景枚举/新 Service（路径 2/3） | 参数扩展最轻量，避免新出题入口重复防爬/排序/混合比逻辑 | 不做（路径 1） |
| 会话模型改造 | 复用现有 createStudySession + sessionQuestion 链路，仅出题参数加白名单 | 不做 |
| BankId 过滤错题集 | GetWrongQuestionsReqDto 无 BankId，错题专练=全学科待掌握错题（当前语义） | 不做 |

## 二、方案要点（供 Oracle 最优解验证）

### 2.1 新增 BR（先 tkwf-business 物化；Oracle C1：学习-BR-47~50 已被 KnowledgeMastery 占用，改用 51/52）

| BR | 内容 |
|---|---|
| 学习-BR-51 | 错题专练：会话带 QuestionIds 白名单时，出题范围 = available ∩ 白名单（Oracle C4：白名单耗尽即会话结束信号）；白名单 `null`=全库、`[]`=显式空集（空集返回空） |
| 学习-BR-52 | 手动标记已掌握：MarkMasteredService 翻转 WrongQuestions.Mastered（学习域，激励-BR-15 域边界）；幂等（User+QuestionId 唯一）；BR-23 作答事件照常驱动不豁免（答错重置）；并发以"最后写入胜出 + BR-23 作答事件权威"处置 |

### 2.2 错题专练路径：GetNextQuestionReqDto 加 QuestionIds 白名单

```csharp
// GetNextQuestionReqDto 新增字段（Bank 域 Callee 内联）
/// <summary>题目白名单（错题专练：限定出题范围；null=全库、[]=显式空集）</summary>
public string[]? QuestionIds { get; init; }
```

- **出题逻辑（ExecuteAsync 内；Oracle M2：白名单非空时短路混合比）**：
  - 现有链：BR-17 访问权 → BR-18 空题 → Type/KnowledgePoint 过滤 → available
  - **白名单介入**（available 计算后）：
    - `QuestionIds == null` → 全库（既有行为，走 BR-04 混合比 + BR-20 排序）
    - `QuestionIds is []`（显式空集）→ 直接 BR-18 空结果（会话结束信号）
    - `QuestionIds is [>0]`（错题专练）→ `available ∩ 白名单` → **跳过 BR-04 混合比** → BR-20 排序直出（Oracle C2 裁决：错题专练=只练错题，混合比的 30% 新题违背语义）
  - 防爬 BR-19 全复用（白名单在防爬前完成，不改变返回形状）
- 薄包装 `Learning/GetSessionQuestionService` 同步转发 `questionIds` 参数
- 前端 `sessionQuestion_Execute` 入参表加 `questionIds`（生成物，`[String!]` 可空列表）
- **前端传递链路（Oracle C7）**：QuestionIds 经 Zustand store（重练上下文）而非路由参数（规避 URL 长度限制）
- **白名单大小（Oracle C8）**：错题专练会话题量受 BR-04 题量上限（10/20/30/50）天然约束，前端按当前 tab 分页集传（≤100/页）

### 2.3 MarkMasteredService（学习域新增）

```csharp
// Services/Learning/MarkMasteredService.cs
[GenerateController]
[AuthorityFilter<XiaoShuTongUserInfo>]
internal class MarkMasteredService(DomainUser<XiaoShuTongUserInfo> user) : DomainServiceBase<XiaoShuTongUserInfo>(user)
{
    // BR-48：翻转 WrongQuestions.Mastered（学习域；BR-23 作答驱动不豁免）
    public async Task<MarkMasteredResDto> ExecuteAsync(MarkMasteredReqDto request, CancellationToken ct = default)
}
```

- ReqDto：`QuestionId`（string）；ResDto：`Success / ErrorCode / Mastered`（翻转后状态，幂等返回）
- 逻辑：RLS 查 User+QuestionId → 无记录返回错误码（如 WRONG_NOT_FOUND）→ 翻转 Mastered → Update → 返回
- 幂等：重复标记同值返回 Success=true + 当前 Mastered
- **并发处置（Oracle C6）**：MarkMastered 不与 SubmitAttempt 同事务；Update 走最后写入胜出——BR-23 作答事件为 Mastered 权威驱动（答错强制 false 覆写手动标记，符合 BR-52 不豁免语义）

### 2.4 前端 wrong.tsx 接线

- **重练定向（Oracle C7：经 store 传递）**：handlePractice 由 `navigate('/student/study/task')` 改为先 `setWrongPracticeIds(当前 tab 错题 QuestionId 集)` 到 Zustand store → navigate；task 页会话创建后 sessionQuestion 携带 `questionIds`（store 读取；重练结束清空）
- **标记已掌握**：待掌握 tab 卡片补操作按钮（"标记已掌握"→ MarkMastered(true)）——成功后 **refetch 当前 tab**（Oracle C5：列表刷新用 refetch 而非本地翻转，保契约一致）
- **移回**：已掌握 tab 卡片补"移回"按钮（→ MarkMastered(false)）——V0.6.9 移除的假交互以真实后端操作恢复，同 refetch
- **Empty 态（Oracle C3）**：错题专练白名单耗尽（后端空结果）→ task 页展示"错题已练完，回到错题本"Empty 态引导返回，非空白停留

## 四、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 白名单与混合比逻辑冲突（BR-04） | 错题专练会话若带 SessionId 会走混合比拉新题 | **Oracle M2 裁决**：白名单非空 → 短路 BR-04 混合比 → BR-20 排序直出（错题专练语义=只练错题） |
| MarkMastered 与 BR-23 答错重置语义 | 手动标记后答错被重置 | BR-52 明确"作答驱动不豁免"（选项 A 决策）；并发最后写入胜出 + BR-23 权威（C6）；前端标记后提示"答错会重新进入错题" |
| QuestionIds 传递（会话 vs 出题） | 前端重练需带白名单到 sessionQuestion | Oracle C7：经 Zustand store 传递（非路由参数，规避 URL 长度限制）；白名单大小受 BR-04 题量上限天然约束（C8） |
| 联调种子无 Attempts/WrongQuestions | 错题专练空集、MarkMastered NOT_FOUND | B1 阶段同步补种子 Attempts 驱动 WrongQuestions（V0.6.17 种子补齐联动） |
