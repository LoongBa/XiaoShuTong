# 任务进度联动与Hint补写 - 开发方案（V0.6.0）

## 一、本版目标

- 核心交付：
  1. **BR-24 TaskAssignments.Progress 联动（ADR-010 决策一~五）**：SubmitAttemptService 每次有效作答后同步推进任务进度（重算式、跨会话聚合），全部完成 → Status=Completed + CompletedAt 写入；激活群主看板/周报/家长报告等既有只读消费方（当前 Progress 全仓无写入方、执行率恒 0）。

- 完成定义（DoD）：
  - 后端：全套件 `dotnet test` **367/0/2 基线不降** + 新增 BR-24 用例（Progress 推进/Completed 迁移/豁免路径）+ JSON 导入/回填 Job 用例全绿。
  - 前端：`pnpm typecheck` 0 错误；O4/O3 组件 mock 走查可见。
  - Hint：JSON 导入后 Questions.Hint 非空断言；回填 Job 计数上报。
  - 文档：Business.md 增量修订（BR-24 口径/状态机/C-18 例外）+ 变更记录 + 审核报告入档。

  - **`assignment.SessionId` 语义澄清（Oracle 评审闭环）**：仅作"最新会话指针"（续做新会话覆盖），**不参与 Progress 重算**（后者按 TaskId 查全部会话）

### 核心流程

**作答 → 进度推进时序（T1，BR-24）**

```
submitAttempt_Execute 有效作答（非 Full/Play/幂等/个人会话）
  → SyncWrongQuestionsAsync（既有，L320）
  → SyncTaskProgressAsync（新增，L226 位置）：
      session.TaskId == null → return（个人会话豁免）
      assignment = Assignments.Where(TaskId && UserId)（BR-05 唯一）
      assignment.SessionId = session.Id; StartedAt ??= now
      Status == Pending → InProgress（首次推进）
      consumed = 该任务全部会话 attempts 中 Correct||达 MaxAttempts 去重 QuestionId
      Progress = Round(consumed.Count / Tasks.QuestionCount * 100)
      Progress >= 100 && Status != Completed → Status=Completed + CompletedAt=now
      Status == Completed → 不再变更（AllowRedo 重做不改变）
```

**JSON 导入 → Hint 写入时序（T4）**

```
ImportBankJsonService.ExecuteAsync(BankId, JsonContent)
  → BR-17 题库权限校验
  → 解析 背诵内容.json（id/bank_id/type/content/meta.knowledge_card_id）
  → 读 背景钩子-知识卡片.json（fields.记忆钩子，按 knowledge_card_id join；无卡片→空）
  → ContentFileStore 写权威文件（BR-15 原子）+ upsert Questions 索引
    Hint = 卡片记忆钩子 / Content 补 card 镜像
```

**存量回填时序（T5）**

```
BankHintBackfillJob.ExecuteAsync()
  → Questions.Where(Hint == null 或空).Chunk(batch)
  → 每批按 KnowledgePoints[0] 反查知识卡片 fields.记忆钩子
  → 命中 → UpdateAsync(Hint)；未命中 → 留空 + 计数
  → 日志：回填数 / 未命中数 / 总行数
```

| bankId | string | 题库业务键 |
| jsonPath | string? | **生产首选**：服务端读题库目录 `*-背诵内容.json`（避免大 payload 经 RPC） |
| jsonContent | string? | 仅小批量/测试用例（含全量文本）；大文件须走 jsonPath |
| knowledgeCardsJson | string? | 背景钩子-知识卡片 JSON（可选，缺省从题库目录读） |

响应 `ImportBankJsonResDto`：`success / errorCode / importedCount / skippedCount / hintFilledCount`（Hint 填充计数回显）

**既有契约（本迭代仅消费，不修改）**：`submitAttempt_Execute`（Progress 派生写，判题契约不动）、`getSessionQuestion_Execute`。

### 数据模型

**Progress 重算口径表（ADR-010 决策一~三）**

| 项 | 口径 |
|----|------|
| 计数方式 | 重算式（非增量）：`consumed.Count / Tasks.QuestionCount * 100` |
| 完成判定 | `Result == Correct` **或** `AttemptCount >= MaxAttempts(2)`（NeedsGuidance=false） |
| 统计窗口 | 跨会话聚合（该任务该用户全部会话，含已结束）——支持 BR-05 续做 + BR-23 逾期复习不回退 |
| 幂等 | BR-27 幂等命中不新增 Attempt → 重算天然不变 |

**状态迁移表（ADR-010 决策四）**

| 当前 | 触发 | 目标 |
|------|------|------|
| Pending | 首次作答推进 | InProgress |
| InProgress | 全部消费（Progress≥100） | Completed + CompletedAt |
| Overdue | 作答驱动全部完成（BR-23 复习后） | Completed（允许，非逾期扫描变更） |
| Completed | AllowRedo 重做 | 不变（幂等） |

**Hint join 链路表（ADR-010 决策六）**

| 层 | 数据源 |
|----|--------|
| 题目 JSON | `*-背诵内容.json` `meta.knowledge_card_id`（如 `KC-chinese-三峡`） |
| 知识卡片 | `背景钩子-知识卡片.json`（`id`/`fields.记忆钩子`；语文 7-9 年级 130/130、小学 67/92） |
| 落库 | `Questions.Hint`（string?，Position 15，V0.5.0 已加列） |
| 消费 | GetHintService → QuestionMetaProvider → TruncateHint ≤20（BR-29） |
