# 前端页面结构与测试策略设计（D05）

> 本文档定义小书童**前端页面结构**（Vue3 + Uni-app 页面路由、状态管理）与**分层测试策略**（单元/集成/E2E/回归）。
> 关联文档：`docs/D01-统一题库与多学科学习平台设计.md`（框架）、`docs/D02-学习数据与记忆跟踪设计.md`（数据）、`docs/D03-API契约设计.md`（接口）、`docs/D04-部署架构与运维设计.md`（部署）、`docs/adr/ADR-001~006`（决策）

---

## 一、总体原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **场景驱动路由** | 页面按学习场景组织（背记/检验/PK/统计），与 D01 场景引擎一一对应 |
| 2 | **API 域对齐** | 页面数据来源对应 D03 六大 API 域（auth/bank/study/stats/pk/user） |
| 3 | **状态前端缓存** | 会话状态/记忆状态走 Pinia，离线数据走 LocalStorage（微信 H5 无 SW，D04 4.1） |
| 4 | **答案永不下发** | 取题接口只给题干，判题结果由服务端返回（D03 4.5/5.2） |
| 5 | **测试金字塔** | 单元测试（状态机/判题逻辑）> 集成测试（API 契约）> E2E（关键流程） |
| 6 | **契约驱动** | 后端 OpenAPI/Swagger 生成契约，前端类型与契约测试同源 |

## 二、页面结构（Uni-app 路由）

### 2.1 页面地图

```
pages/
├── auth/                       # 认证域（D03 §二）
│   ├── login.vue               # 微信授权登录（+ 手机号绑定弹窗）
│   └── privacy.vue             # 隐私协议（首次登录必读，V3 合规）
├── index/                      # 首页
│   ├── index.vue               # 今日复习卡片 + 热力图入口 + 连续天数
│   └── daily.vue               # 每日挑战（跨学科 5-10 题）
├── bank/                       # 题库域（D03 §四）
│   ├── list.vue                # 题库列表（按学科/用途筛选）
│   ├── detail.vue              # 题库详情（知识点层级）
│   ├── import.vue              # 题目导入（.txt/.json 上传）
│   └── manage.vue              # 我的题库管理（私域）
├── study/                      # 学习域（D03 §五）
│   ├── session.vue             # 答题会话主界面（S1-S4 分阶渲染）
│   ├── result.vue              # 会话结果（正确率/★点亮）
│   └── review.vue              # 复习队列
├── stats/                      # 统计域（D03 §六）
│   ├── heatmap.vue             # 记忆热力图（Canvas）
│   ├── wrong.vue               # 错题本
│   └── report.vue              # 周/月报
├── pk/                         # PK 域（D03 §七）
│   ├── lobby.vue               # PK 大厅（发起/加入/战绩）
│   ├── battle.vue              # 对战（同步实时 / 异步回合）
│   └── result.vue              # 结果 + AI 点评
├── user/                       # 用户数据域（D03 §八）
│   ├── profile.vue             # 个人中心
│   ├── export.vue              # 数据导出
│   └── delete.vue              # 账号注销（30 天宽限）
└── common/                     # 通用组件
    ├── QuestionCard.vue        # 答题卡片（按题型交互分发）
    ├── HintBubble.vue          # 背景钩子提示气泡（S1/S2/S3 档位）
    ├── KnowledgeCard.vue       # 知识卡片弹层
    └── StreakBadge.vue         # 连续天数徽章
```

### 2.2 TabBar（5 个主入口）

| Tab | 页面 | 说明 |
|-----|------|------|
| 首页 | index/index.vue | 今日任务 + 激励入口 |
| 学习 | study/session.vue | 一键开始背诵（默认背记场景） |
| 题库 | bank/list.vue | 题库浏览/管理 |
| PK | pk/lobby.vue | 趣味竞技 |
| 我的 | user/profile.vue | 统计/导出/设置 |

### 2.3 页面-场景-API 映射

| 页面 | 学习场景 | 主调 API | 数据落库（D02） |
|------|---------|---------|----------------|
| study/session | 背记 memorize | POST /study/attempts、POST /study/hint | attempts + memory_states |
| study/review | 背记复习 | GET /study/review-queue | memory_states 视图 |
| index/index | 背记聚合 | GET /stats/heatmap、GET /stats/streak | daily_stats |
| stats/wrong | 错题回练 | GET /stats/wrong-questions | wrong_questions |
| pk/battle | 趣味 play | PK 系列 + WS | pk_matches/players/attempts |
| study/session(assess) | 检验 assess | POST /study/attempts（scenario=assess） | attempts（不升级状态） |

## 三、前端状态管理（Pinia）

```
stores/
├── authStore.ts      # token/user_id/角色/监护人同意标记
├── bankStore.ts      # 当前题库/题型筛选/知识点树（缓存）
├── studyStore.ts     # 会话状态机/当前题/四阶状态/hint_level
├── statsStore.ts     # 热力图/连续天数/周报缓存
├── pkStore.ts        # 比赛状态/倒计时/成绩/AI 点评
└── offlineStore.ts   # LocalStorage 离线队列（微信 H5 无 SW 降级）
```

**关键状态流**（答题会话）：

```
studyStore.loadQuestion()  → GET /questions/next（不含答案）
studyStore.submit(answer)  → POST /study/attempts
    ← result/confidence/pre_state/post_state/next_review_at
studyStore.updateMemory()  → 本地四阶状态渲染（★ 点亮动画）
studyStore.requestHint()   → POST /study/hint → HintBubble 展示
```

**离线降级**（微信 H5，D04 4.1）：`offlineStore` 暂存未提交作答，联网后批量 `POST /study/attempts` 增量同步（V3 决策：LocalStorage + 增量同步）。

## 四、测试策略

### 4.1 测试金字塔

```
         E2E（Playwright）          ← 关键用户流程
       ┌────────────────┐
       │ 集成测试（xUnit）│          ← API 契约 + 判题链路
       ├────────────────┤
       │ 单元测试（Vitest/xUnit）│   ← 状态机/判题路由/PK 计分
       └────────────────┘
```

### 4.2 单元测试（L0）—— 核心逻辑

| 模块 | 测试点 | 框架 |
|------|--------|------|
| 四阶状态机 | **迁移矩阵全组合**（hint×result×state，D01 10.2 共 10 组用例） | xUnit / Vitest |
| 判题路由 | 阈值边界（84%/85%/86%、59%/60%/61% 命中率 → correct/partial/LLM） | xUnit |
| keywords 引擎 | 同义词组命中（"唐太宗"="李世民"）、required 未命中→partial、权重计分 | xUnit |
| 复习间隔 | 艾宾浩斯序列（首次30min→12h→1d→3d→7d→30d）、history_accuracy 系数 0.5-1.5 | xUnit |
| PK 计分 | 胜负规则（总分/同分比用时/平局）、每题超时 0 分、异步合并计分 | xUnit |
| 场景耦合 | full/feedback_only/isolated 三策略 × 答对/答错 状态影响 | xUnit |

### 4.3 集成测试（L1）—— API 契约 + 链路

| 测试 | 内容 | 工具 |
|------|------|------|
| 契约测试 | D03 全部接口请求/响应 Schema 校验（用 OpenAPI 生成） | Swagger + Pact（可选） |
| 判题链路 | 提交作答 → attempts 写入 → memory_states 更新 → daily_stats 聚合（事务原子性） | xUnit + Testcontainers（PG） |
| PK 流程 | 发起→加入→作答→合并计分→AI 点评（async 模式） | xUnit + Testcontainers |
| 鉴权 | token 过期/无效/越权访问私域题库（RLS 生效） | xUnit |
| 数据迁移 | .txt 解析器 → 435 题 schema 校验全通过（回归基线） | xUnit |

### 4.4 E2E 测试（L2）—— 关键流程

| 流程 | 场景 | 断言 |
|------|------|------|
| 登录→背诵→判题 | 微信登录 → 选库 → 答题 5 题（含 1 次"请提示我"）→ 结果页 | 状态机迁移正确、★ 点亮、热力图更新 |
| 错题回练 | 答错 1 题 → 错题本出现 → 回练答对 → mastered | 错题消失 |
| PK 对战 | 发起 → 好友加入 → 双方作答 → 结果 + AI 点评展示 | 胜负/点评正确渲染 |
| 离线补传 | 断网答 2 题 → 联网 → 自动同步 | 增量同步成功 |

**工具**：Playwright（H5 真机 UA 模拟微信 X5）；本地起 dev 全栈（D04 D4-P1 Docker Compose）。

### 4.5 回归基线

| 基线 | 触发 | 通过标准 |
|------|------|---------|
| 435 题 schema 校验 | 每次题库变更 | 100% 通过 |
| 状态机迁移矩阵（10 用例） | 每次代码变更 | 100% 通过 |
| Prompt 变更回归 | 判题 Prompt 修改 | 500 题测试集判题准确率 ≥95%（V3 决策 4） |
| API 契约快照 | 每次后端变更 | 无破坏性变更 |

## 五、前端性能与体验（V3 非功能）

| 指标 | 目标 | 手段 |
|------|------|------|
| 首屏加载 | ≤5s（微信中低端安卓） | 骨架屏 + 路由懒加载 + CDN（D04 4.1） |
