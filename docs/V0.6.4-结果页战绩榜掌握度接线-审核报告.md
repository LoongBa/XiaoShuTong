**总评：通过**

## 四、关键设计决策与风险

| # | 决策 | 说明 |
|---|------|------|
| ① | Accuracy 口径 | 结果页 = 会话内 correctCount/TotalCount（SessionResultAggregator 派生，零新增计算）；战绩榜 accuracy/mastery = RankSnapshots 对应 MetricType 冻结值（FreezeJob 真实口径）——两地均为 0~1 透出，前端 accuracyToPercent 统一映射 |
| ② | 契约向后兼容 | 仅增字段（暂无类型变更/删除），schema.graphql 刷新后消费端不读即零影响——符合 V0.6.3 DoD「契约零变化」验证方式（grep + typecheck） |
| ③ | 战绩 vs 战力 | 本迭代接战绩榜（Performance accuracy+mastery 双指标）；战力榜（streak/volume 无单指标）保留 mock 标注，接线另立避免后端增 6 字段扩大契约面 |
| ④ | RankEnabled 门控 | 后端已返回 rankEnabled（BR-02）；rank.tsx 消费:rankEnabled=false → 战力 tab 隐藏/禁用（UI 文档 L249/L553） |
| ⑤ | 联调种子快照 | 优先 FreezeJob 手工跑归 Real口径（补 DailyStats/KnowledgeMastery 种子）；直插 RankSnapshots 免跑 Job 立即可查。实现：群 UId 落常量 + Direct 种子 DailyStats32/KnowledgeMastery×3 + RankSnapshots×6（3用户×Accuracy+Mastery） |
| ⚠️ WARN | WebApi build 中途 MSB3492（AssemblyInfoInputs.cache 读取失败） | buildSchema.ps1 环境性/瞬时告警，schema.graphql 经 CommandLine 实际导出成功且新字段入产物（grep 核验），不影响契约正确性；记入风险，复跑即消 |
