# 学生作答流端到端接线 - 开发方案（V0.4.0）

## 一、本版目标

- 核心交付：
  1. **G-1 出题契约暴露（ADR-008 决策一）**：Learning 域新建 `GetSessionQuestionService` 薄包装对外暴露 `getSessionQuestion_Execute` RPC，Bank 域 `GetNextQuestionService`（BR-17~20，全库 0 调用方）保持 internal Callee，响应复用 `GetNextQuestionResDto` 不新建 POCO。
  2. **G-2 判题元数据去桩（ADR-008 决策二）**：5 个消费点（SubmitAttempt / GetHint / GetSessionResult / GetWrongQuestions / KnowledgeMasteryAggregationJob）从 `LearningQuestionRegistry` 静态桩切换为 `Questions`/`Banks` 真实读取；`Questions` 新增 `Hint` 列（可空 string，背景钩子落库）；注册表降级为测试专用。
  3. **前端端到端接线（审核报告 §八 #1/#2 闭环）**：task.tsx 会话初始化（createStudySession_Execute → sessionUid 活源）+ 判题接线（useAttemptFlow 四态驱动，替换 MOCK_QUESTIONS 与本地判题）+ hint 升级 + result.tsx 接 sessionResult + review 入口传参修复；appStore 会话三件套扩展。
  4. **mock 补数**：submitAttemptResDtos 按新契约重填、getSessionQuestionResDtos 新表、getHintResDtos 语文文案、queryOne 轮转/scenarioOverrides 覆盖四态。
- 完成定义（DoD）：
  - 后端：全套件 `dotnet test` **基线不降**（当前记录 353/0/2，Domain AGENTS.md 另有 350 记载——**实施前先跑一次 `dotnet test` 确认实际通过/失败/跳过数，以实际值为准**）+ 新增 GetSessionQuestionService / Hint 去桩用例全绿。
  - 生成链路：`getSessionQuestion_Execute` 出现在 `schema.graphql`（SG1/SG2）+ `ts-client.g.ts`（SG3），`ts-client.mock.g.ts` 同步。
  - 前端：`pnpm typecheck` 0 错误；mock 模式下 task.tsx 真实链路（createSession→getQuestion→submitAttempt 四态）端到端可见。
  - 文档：变更记录追加 + 审核报告产出入档。

### 核心流程

**学生新学会话时序（task?taskId=xxx）**

```
进入 task 页
  → createStudySession_Execute({ scenario: Memorize, bankId, sessionType: Progressive, taskId })
  → sessionUid 存 appStore，questionCount 取回
  → getSessionQuestion_Execute({ sessionUid, bankId }) → 第 1 题渲染（R1/R2 题干镜像，无答案）
  → [作答循环]  userAnswer + hintLevel(None|Partial|Full) + timeCostMs
      → submitAttempt_Execute → AttemptFlowAction 四态：
          celebrate → ★ 动画 + postState 徽章 → 下一题（getSessionQuestion）
          guidance  → △ + hint + 再试一次/求助升级（hint_Execute 升档回填）
          answer-sheet → missingKeywords 展示 → 必进下一题
          error     → 停留 + 提示
  → 题集耗尽（Success=true 无 QuestionId）→ result?sessionUid=xxx
      → sessionResult_Execute({ sessionUid }) → correctCount/totalCount/newStarCount/blockedPoints 渲染
```

**复习会话时序（review → task?reviewQuestionId=xxx）**

```
review.tsx 点卡 → task?reviewQuestionId=xxx
  → createStudySession_Execute({ scenario: Assess, bankId, sessionType: Progressive, questionId 关联 })
    （BR-20 状态机排序：到期复习优先；BR-05 同任务续做幂等）
  → 与上同作答循环；题集耗尽 → result
```

> 记忆状态徽章（✕△○★）由 SubmitAttempt 响应 preState/postState 驱动（判题方案 §4.3 setMemoryState），不再本地推导。
