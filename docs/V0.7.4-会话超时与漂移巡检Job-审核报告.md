## 二、改动逐项审查（Sisyphus 亲自审核）

### T1：SessionTimeoutJob（新增，`Services/Learning/`）

| 项 | 审查 |
|----|------|
| 扫描条件 ✅ | `EndedAt == null && StartedAt < UtcNow-24h` 一次查询（V0.7.3 读侧一次 IN 范式） |
| 空批跳过 ✅ | `stale.Count == 0 return`（幂等） |
| 竞态幂等检查 ✅ | `session.EndedAt.HasValue → continue`（Oracle 风险补充②——扫描后用户可能已 EndStudySession 收尾，防覆盖） |
| EndedAt 取值 ✅ | M1-A（Oracle 采纳）：`EndedAt = StartedAt.AddHours(24)` 业务时间语义，不聚合 CorrectCount/TotalTimeMs（弃用会话统计不可信） |
| 单会话失败继续 ✅ | catch 吞异常（对齐 TaskOverdueScanJob BR-21） |
| 语义保持 ✅ | BR-05 复用释放（EndedAt 置值后 CreateStudySession 不复用）+ GetSessionQuestionService SessionEnded 校验对齐 |

### T2：ProgressDriftAuditJob（新增，`Services/TaskManagement/`）

| 项 | 审查 |
|----|------|
| 扫描条件 ✅ | `Status == Pending || InProgress` 一次查询（Completed 幂等 + Overdue 语义自洽排除） |
| 空批跳过 ✅ | `assignments.Count == 0 return` |
| 无会话早退 ✅ | `sessionIds.Count == 0 return`（无作答记录不巡检） |
| 无作答早退 ✅ | `taskAttempts.Count == 0 return`（**Oracle C1**：不创造"有作答但未消费"的迁移副作用） |
| 全量重算 ✅ | `GroupBy(QuestionId).Where(Correct || Count>=MaxAttempts)`——对齐 BR-24 判定口径 + **C3 溯源注释**（SubmitAttemptService.RebuildIfDriftedAsync L487-491 + Business.md BR-24 + MaxAttempts=2 L35） |
| 比对校正 ✅ | `SetEquals` 不一致 → 重建集合 + 重算 Progress + 状态迁移 |
| 归一化修复 ✅ | **Oracle C4**：SetEquals 一致但序列化不一致（空格/重复/乱序损坏）→ 写回归一化集合 |
| 状态迁移 ✅ | **Oracle C1 修正**：`Pending → InProgress`（无 Count>0 条件，对齐 SubmitAttempt L445-446）；`Progress>=100 → Completed + CompletedAt` |
| 单分配失败继续 ✅ | catch 吞异常 |
| 语义保持 ✅ | 一致不写（幂等）；BR-24 判定口径权威对齐 |
