## 二、审核结论

**总评：通过**

V0.6.7 登记的"付费流程"遗留闭环（受限于 ActivateSubscriptionService 为支付回调 Callee 不暴露，支付开通环节登记生产配合项，其余真实化）。核心交付：

1. **订阅状态真实化（T1）**：isSubscribed 从 `dashboardReport.subscription` 契约派生——**修复契约错配**：前端原 `=== 'Trial'` 永不命中（`SubscriptionStatus.Trialing.ToString()="Trialing"` 实证），试用中被误判未订阅 → 修正为 `'Trialing'` + Active + Cancelled（周期内仍有权，对齐 ParentReportGate L60）；trialDaysLeft 从 `subscription.trialEndAt` ceil 计算（替代本地硬编码 7）。
2. **试用真实接线（T2）**：新增"免费试用 7 天"主 CTA 接 `startTrial_Execute({studentId: selectedChild.studentId})`——BR-05 授权链→8002 / BR-06 幂等返回原记录 / BR-07 +7 天；多孩子独立计费（切换孩子重拉 dashboardReport 刷新订阅状态，Oracle C3）；已订阅隐藏试用按钮（Oracle C4）；本地置态即时反馈 + 重拉权威校正。
3. **"确认支付"改造（T3）**：不再假 `setIsSubscribed(true)`——明确提示"支付功能即将上线，可先免费试用 7 天"（ActivateSubscriptionService=Callee 不暴露，V0.6.8 WARN004 实证；微信支付回调基建为生产配合项）。
4. **mock 多场景（T4）**：getDashboardReportResDtos 3 场景并存（无订阅 locked / 试用中 Trialing / 已订阅 Active，Oracle C1 勿改 Active）+ startTrialResDtos 补 8002 错误场景。
