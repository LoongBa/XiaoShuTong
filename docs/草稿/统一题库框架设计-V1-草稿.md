# 统一题库框架设计 V1（草稿）

> 目标：在统一框架下满足不同学科（语文/英语/历史/地理/生物/化学，数学物理少量背记）、不同题型、不同学习目的（背记/检验/趣味学习）
> 设计原则：三维正交解耦（学科 × 题型 × 学习目的），通过"注册表 + 适配器"自由组合
> 现状：语文古诗文题库已实现（首个学科适配器实例），本框架为其抽象化

---

## 一、三维模型

```
学科 (Subject) × 题型 (QuestionType) × 学习目的 (Scenario)
```

- **学科**：决定内容领域、判题容错度、知识卡片模板、Prompt 覆盖
- **题型**：决定数据结构契约、判题策略、交互方式
- **学习目的**：决定出题调度、反馈呈现、激励体系

任何组合均通过注册表查表实现，不写死组合逻辑。

---

## 二、五层架构

```
┌─────────────────────────────────────────────────┐
│ L5 场景引擎   背记调度 / 组卷评分 / 闯关互考 PK    │ ← 学习目的
├─────────────────────────────────────────────────┤
│ L4 出题调度   题型路由 + 四阶状态机 + 艾宾浩斯     │
├─────────────────────────────────────────────────┤
│ L3 判题引擎   规则比对 / 关键词 / LLM + 降级路由   │
├─────────────────────────────────────────────────┤
│ L2 题型契约层 题型注册表（Schema+判题+Prompt绑定） │ ← 题型
├─────────────────────────────────────────────────┤
│ L1 资源层     统一题库 JSON + 知识卡片 + 元数据    │ ← 学科
└─────────────────────────────────────────────────┘
```

**层间依赖单向向下**：L5 依赖 L4，L4 依赖 L3/L2，L3 依赖 L2/L1，L2 依赖 L1。上层不知道下层的学科/题型细节。

## 三、题型注册表（L2）

### 3.1 注册表结构

```json
{
  "key": "R1",
  "name": "补全记忆",
  "contentSchema": {
    "question": "string",
    "answer": "string",
    "keywords": "string[]"
  },
  "grading": "keyword+llm",
  "prompt": "题型-R1-补全记忆",
  "interaction": "text_input",
  "purpose_support": ["memorize", "play"]
}
```

### 3.2 题型族定义

| 族 | 键 | 名称 | 判题策略 | 交互 | 示例 |
|----|-----|------|---------|------|------|
| 记忆型 | R1 | 补全记忆 | 关键词+LLM | 文本框 | 语文"上句→下句"、英语"英→中" |
| | R2 | 逆向补全 | 关键词+LLM | 文本框 | 语文"下句→上句"、历史"年代→事件" |
| | R3 | 默写 | 关键词+LLM | 文本框 | 语文段落/全文、英语拼写、化学方程式 |
| | R4 | 知识卡片 | 非判题（展示） | 卡片 | 背景钩子/历史典故/地理趣闻 |
| 客观型 | O1 | 单选 | 规则比对 | 点选 | 各学科通用 |
| | O2 | 多选 | 规则比对 | 点选 | 各学科通用 |
| | O3 | 判断 | 规则比对 | 点选 | 各学科通用 |
| | O4 | 连线 | 规则比对 | 拖拽/点选 | 历史人物-朝代、地理省-简称 |
| | O5 | 填空 | 规则比对+LLM | 文本框 | 生物名词、化学用语 |
| 主观型 | X1 | 简答 | LLM | 文本框 | 语文简答、历史分析 |
| | X2 | 论述 | LLM+人工 | 文本框 | 语文作文、历史小论文 |
| | X3 | 计算 | 规则/步骤 | 文本框 | 数学/物理（少量背记场景） |

## 四、学科适配器（L1 扩展）

### 4.1 适配器结构

```json
{
  "subject": "chinese",
  "supportedTypes": ["R1", "R2", "R3", "R4", "O1", "O2", "O3"],
  "gradingPreference": "semantic_tolerant",
  "knowledgeCardTemplate": "author_card",
  "promptOverrides": {
    "R1": "语文-R1-默写判题",
    "R2": "语文-R2-逆向判题"
  }
}
```

### 4.2 各学科适配器规划

| 学科 | 支持题型 | 判题容错度 | 知识卡片模板 | 说明 |
|------|---------|-----------|-------------|------|
| 语文 | R1-R4, O1-O3 | 语义宽容（同义/通假） | 作者卡片（7 维） | **已实现**（古诗文） |
| 英语 | R1-R3, O1-O5 | 拼写宽容（时态/单复数） | 单词卡片（词源/用法） | 单词/句型/语法 |
| 历史 | R1/R2, O1-O4 | 精确（年代/人名） | 事件卡片（起因经过结果） | 年代/人物/事件连线 |
| 地理 | R1/R2, O1-O4 | 精确（地名/物产） | 地域卡片（地形/气候） | 省简称连线/河流山川 |
| 生物 | O1-O3, O5 | 精确（术语） | 概念卡片（定义/功能） | 名词/分类/流程 |
| 化学 | O1-O3, R3 | 精确（符号/方程式） | 元素卡片（性质/发现史） | 元素符号/方程式 |
| 数学/物理 | X3（少量 R3） | 精确 | 定理卡片 | 公式/定理背记（低优先级） |

## 五、场景引擎（L5）

### 5.1 场景定义

| 场景 | 出题调度 | 反馈 | 激励 | 状态机 |
|------|---------|------|------|--------|
| 背记 memorize | 分阶检索 S1→S4 + 艾宾浩斯 | 判题 + 引导提示 | 热力图 / ★ 点亮 | 四阶 ✕△○★ |
| 检验 assess | 按知识点/难度/题型比例组卷 | 评分 + 错题解析 + 报告 | 正确率 / 成绩单 | 错题本 |
| 趣味 play | 闯关（章节关卡解锁）/ 互考 / PK | 即时反馈 + 挑战感 | 非分数排名 / 徽章 | 关卡进度 |

### 5.2 趣味场景子模式

| 模式 | 机制 | 示例 |
|------|------|------|
| 闯关 | 章节关卡顺序解锁，完成解锁下一关 | 文学常识闯关：李白→杜甫→苏轼 |
| 互考 | A 同学从题库选题，B 同学作答，互相评分 | 同学互考文学常识/历史知识 |
| PK 挑战 | 两人同答一组题，比正确率/速度 | 班级历史知识 PK 赛 |
| 每日挑战 | 固定 5-10 题，跨学科混合 | 每日一练 |

## 六、统一数据模型（L1）

### 6.1 统一 JSON Schema

```json
{
  "id": "Q-001",
  "subject": "chinese",
  "topic": "七上-古诗文",
  "type": "R1",
  "purpose_tags": ["memorize", "play"],
  "content": {
    "question": "日月之行",
    "answer": "若出其中",
    "keywords": ["若出其中"]
  },
  "meta": {
    "difficulty": 1,
    "source": "2024修订版七上",
    "knowledge_card_id": "观沧海"
  }
}
```

### 6.2 兼容性

- 现有 `问题###答案` .txt 题库可**无损解析**为统一 JSON（`type` 按目录/注释推断）
- 背景钩子 `.md` 为知识卡片数据源（`knowledge_card_id` 关联）

## 七、判题引擎（L3）

### 7.1 判题路由

```
题型注册表.grading 决定判题链
├── rule      → 规则引擎（选择/判断/连线：直接比对）
├── keyword   → 本地关键词匹配（≥80% 直接判，零成本）
├── llm       → LLM 判题（通用基线 → 学科覆盖 → 题型专用）
└── hybrid    → keyword 前置 + llm 兜底（记忆型题型默认）
```

### 7.2 Prompt 绑定矩阵

Prompt 按 **(学科 × 题型)** 组织，三层覆盖：

```
全局通用基线（跨学科兜底）
├── 学科层：语文判题 / 英语判题 / 历史判题 ...
└── 题型层：R1 补全 / R2 逆向 / R3 默写 / O4 连线 ...
    绑定优先级：单题 > 学科×题型 > 题型 > 学科 > 全局
```

## 八、现有资产映射（证明是抽象化而非重写）

| 现有实现 | 框架层 | 角色 |
|---------|--------|------|
| `题库/<年级>/*.txt`（435 题） | L1 资源层 | 语文适配器数据（可解析为 JSON） |
| `题库/背诵训练/*`（1278 题） | L2 题型注册表 | 记忆型 R1-R3 的语文实例（S1-S4） |
| `题库/背景钩子/*`（7 维） | L1 知识卡片 | 语文作者卡片模板 |
| `题库/判题Prompt/*` | L3 + L2 | 通用基线 + 题型专用（语文版） |
| 四阶状态机（✕△○★） | L4 调度 | 背记场景调度器 |

**结论**：语文是第一个完全落地的学科适配器；新增学科 = 新适配器 + 新题库数据 + 学科 Prompt 覆盖，框架代码零改动。
