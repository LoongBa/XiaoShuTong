# U01-家长报告与订阅 · 用况与契约

> **所属阶段**：第一阶段（设计层），切片验证（路径 B 转化）
> **前置条件**：DS01 + 定稿场景 S01 已产出
> **产出物**：家长成长报告与订阅域 Use-Case + 契约定义 → 输入给 Agentic Coding
>
> **转化说明**：由 D03 V1.3（§6.8/6.9 家长域 + §11 订阅与报告域 11.1~11.7）API 契约拆分为 UC。**错误码决策**：保留 D03 数字域错误码（80xx 订阅 / 40xx 统计 / 10xx 全局）+ SNAKE_CASE 语义名双列（DG-06 附录「既有错误码体系迁移」）。
> **命名决策（对齐 D03 原则 #6）**：API JSON 字段一律 camelCase（**D03 明示禁止 snake_case**）；SNAKE_CASE 仅用于错误码语义名（D03 未提供语义名，由本 U01 推导标注）。
> **跨模块依赖**：学习 Session（报告数据链式聚合）、群组管理（家长看报告权限）。

## UC-10.4：订阅（支付成功回调）（Callee）

**调用方**：微信支付回调 → `ActivateSubscriptionService`
**子域**：`Parent`
**事务范围**：CROSS（订阅激活 + 状态迁移）
**故障容忍度**：Required
**关联 R 功能点**：R01-10.2

### Precondition（数据状态条件）
- 微信支付成功回调到达；订阅记录存在（试用已开通或直接开通）

### Main Flow（系统流程，无用户操作）
1. 接收支付回调（方案 month/year）
2. 校验授权链 → 订阅置 Active，PeriodEndAt 推进（月 +1 月 / 年 +1 年）
3. 报告全量解锁

### Alternative Flow
- 1a. 孩子未授权 → 8002（BR-08）
- 1b. 重复回调 → 幂等（BR-09）

### Postcondition
- 数据：Subscriptions.Status=Active；PeriodEndAt 推进

### [契约层]

#### Service 类声明

```csharp
// 不加 [GenerateController]、不加 [AuthorityFilter]（支付回调，内部调用）
[Transactional]
public class ActivateSubscriptionService : DomainServiceBase<TUserInfo>
{
    public async Task<ActivateSubscriptionResDto> ExecuteAsync(ActivateSubscriptionReqDto request) { throw new NotImplementedException(); }
}
```

#### 业务规则

| BR# | 规则说明 | 测试场景 |
|:---:|---------|---------|
| BR-08 | StudentId 授权校验 → 8002 | 未授权 -> 8002 |
| BR-09 | 重复回调幂等 | 二次回调 -> 不重复推进周期 |
| BR-10 | Plan=Month 周期 +1 月；Year +1 年 | month 订阅 -> PeriodEndAt +1 月 |

#### 错误码定义

| 错误码 | 语义名 | HTTP | 业务含义 | 触发条件 |
|:------:|:------:|:----:|---------|:--------:|
| 8002 | PARENT_STUDENT_NOT_AUTHORIZED | 400 | 家长-孩子未建立授权关系 | BR-08 |

> Callee UC 错误码由调用方处理（支付平台），不直接暴露前端（DG-06 规则）。

#### 依赖的 DataService

```csharp

```

#### Service 编排逻辑
