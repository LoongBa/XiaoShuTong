## 枚举定义

#### ParentRelation ── 家长关系

存储格式：`string`（PascalCase；存量小写 parent/guardian/grandparent）
使用场景：ParentStudentRelations.Relation

| 枚举值 | 业务含义 |
|:------:|---------|
| Parent | 父母 |
| Guardian | 监护人 |
| Grandparent | 祖辈 |

#### SubscriptionPlan ── 订阅方案

存储格式：`string`（PascalCase；存量小写 month/year）
使用场景：Subscriptions.Plan

| 枚举值 | 业务含义 |
|:------:|---------|
| Month | 月付（10 元/月） |
| Year | 年付（100 元/年） |

#### SubscriptionStatus ── 订阅状态

存储格式：`string`（PascalCase；存量小写 trialing/active/expired/cancelled）
使用场景：Subscriptions.Status

| 枚举值 | 业务含义 |
|:------:|---------|
| Trialing | 试用中（7 天） |
| Active | 已订阅 |
| Expired | 已过期 |
| Cancelled | 已取消（权益至周期末） |

## 实体关系

```
Users (1) ──→ (N) ParentStudentRelations    家长关联孩子（ParentId）
Users (1) ──→ (N) ParentStudentRelations    孩子被关联（StudentId）
Users (1) ──→ (N) Subscriptions             家长订阅（ParentId + StudentId）
```

> 消费实体引用（不在本 DS 定义）：`Users`（账户域）、`MemoryStates`/`DailyStats`/`KnowledgeMastery`（学习域，切片 02，报告数据链式聚合）、`GroupMembers`（群组域，家长获看报告权限）——FK/业务键引用，编译依赖通过框架 DI 注入。

## 存量差异标注（D02 DDL → TKWF 框架）

| # | 差异项 | D02 存量 | TKWF 要求（DG-05） | 处理建议 |
|:-:|-------|---------|-------------------|---------|
| ① | **主键类型** | `uuid` | `long Id`（硬性） | **沿用前序切片决策**：内部 `long Id`；外部关联、跨系统用 `Uid`（uuid 业务键）——实体表补 Uid 列（唯一索引），API/DTO 暴露 Uid |
| ② | **审计字段** | ParentStudentRelations 为 CreatedAt；Subscriptions 原无审计列 | `CreateTime/UpdateTime` | 本 DS 已转化并补齐 |
| ③ | **枚举存储** | 小写（parent/month/trialing） | PascalCase `"Parent"/"Month"/"Trialing"` | 本 DS 已转化；存量数据迁移映射 |
| ④ | **错误码** | 数字域码 80xx（订阅）/ 40xx（统计）/ 10xx（全局） | DG-06 默认 SNAKE_CASE | **沿用决策**：保留数字码 + 语义名双列（见 U01 错误码表） |
| ⑤ | **授权链校验** | 应用层校验（非 DB 约束） | 框架无强制 | **标注**：订阅前校验 ParentStudentRelations 存在记录（应用层，防越权订阅） |
| ⑥ | **价格字段** | D03 无 API 价格字段（10 元/100 元仅文案） | 框架无强制 | **标注**：Plan 仅 month/year，单价由外部支付配置承载（非本表字段） |

> **字段覆盖校对（S/UI → DS）**：S01 场景与 UI 展示字段（孩子信息/今日任务完成状态/坚持天数/本周进度/学科掌握度、正确率/背诵量曲线、相对进步、掌握度矩阵/篇目下钻、试用倒计时/订阅状态/到期锁定/方案选择）——① 孩子列表/授权 = ParentStudentRelations + Users ✅；② 订阅状态/试用/方案 = Subscriptions ✅；③ 今日任务/坚持天数/本周进度 = DailyStats/TaskAssignments（跨模块）✅；④ 学科掌握度/薄弱点 = KnowledgeMastery（跨模块）✅；⑤ 相对进步 = DailyStats/KnowledgeMastery 时间窗对比（跨模块聚合）✅；⑥ 篇目下钻 = Questions（跨模块，API 缺口标注待补）✅
