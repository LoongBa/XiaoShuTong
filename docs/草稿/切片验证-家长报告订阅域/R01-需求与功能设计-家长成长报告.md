# 模块 10：家长成长报告与订阅

## 模块描述

家长经授权关联孩子后，付费查看孩子的成长报告（成长总览/进度趋势/薄弱知识点），为"知情权"付费（试用 7 天 → 10 元/月或 100 元/年，多孩子独立计费）。报告只呈现**相对进步**（本周 vs 上周），**不显示群组正确率排名**（合规红线）。家长经 `ParentStudentRelations` 授权链查看，订阅校验控制完整内容访问。

---

### 10.1 家长关联孩子与孩子列表

#### 功能描述

家长关联自己的孩子（建立授权链），随后可查看孩子列表并对孩子订阅/查看报告。

#### 操作描述

1. 家长关联孩子（学生角色校验）→ 建立 ParentStudentRelations
2. 家长查看我的孩子列表（含各孩子订阅状态）
3. 多孩子切换（报告/订阅按孩子独立）

#### 约束条件

- 关联的孩子角色必须为学生（应用层校验）
- 一个家长可关联多个孩子（二胎）；一个孩子可被多位家长关联（父+母+祖辈）
- 家长经 GroupMembers 获得看报告权限 + ParentStudentRelations 建立授权链（双重条件）
- 家长只能看到自己孩子的学习数据（RLS）

---

### 10.2 订阅开通（试用 → 付费）

#### 功能描述

家长为孩子开通成长报告订阅：先触发 7 天试用，试用后可付费订阅（月/年），多孩子独立计费。

#### 操作描述

1. 家长访问报告区 → 未订阅时预览前 2 项 + 模糊遮罩 + "开通"CTA
2. 点开通 → 触发 7 天试用（trialing，全量报告可用，黄条倒计时）
3. 试用到期后订阅（选择月/年方案 → 微信支付）
4. 已订阅 → 隐藏付费入口，提供"管理订阅/取消续费"

#### 约束条件

- 试用与计费按 (Parent, Student) 对独立（多孩子各自试用/计费）
- StudentId 必须在 ParentStudentRelations 有授权（应用层校验，防越权订阅）
- 订阅状态机：trialing → active / expired / cancelled
- 到期 → 报告区锁定置灰 + "解锁完整报告"按钮；试用中黄条倒计时
- 试用已过期 → 8003；未订阅查看完整报告 → 8001

---

### 10.3 家长成长总览（dashboard）

#### 功能描述

家长查看孩子成长总览：今日任务完成状态 + 坚持天数 + 本周进度 + 各学科掌握度概览（付费内容）。

#### 操作描述

1. 家长进入成长总览页（多孩子切换器选择孩子）
2. 展示今日任务完成状态（红/绿点）+ 坚持天数（🔥N 天）+ 本周进度条 + 各学科掌握度概览
3. 未订阅 → 预览前 2 项 + 模糊遮罩 + "开通"CTA；试用中 → 全量 + 黄条；已订阅 → 全量
4. 点"查看完整报告 ▸" → 完整报告（订阅后）或开通浮层（未订阅）

#### 约束条件

- 支付前报告区预览前 2 项 + 模糊遮罩 + "开通"CTA（D03 §11.5 `locked: true` 驱动）
- 报告只呈现相对进步，不显示群组正确率排名（合规红线）
- 家长无数据 → 空态"孩子还没有学习记录，让他/她背第一首诗吧"
- 数据源：MemoryStates/DailyStats/KnowledgeMastery 链式聚合（订阅校验控制完整内容）

---

### 10.4 进度趋势（progress）

#### 功能描述

家长查看孩子正确率/背诵量时间曲线（周/月切换），只呈现相对进步（本周 vs 上周），不显示群组正确率排名。

#### 操作描述

1. 家长选择周期（周/月）
2. 展示正确率/背诵量时间曲线（趋势数据点）
3. 展示相对进步（本周 vs 上周：多背 N 篇 / 薄弱点迁移 / 坚持天数）

#### 约束条件

- **报告内容红线**：只呈现相对进步（多背了 N 篇、薄弱点迁移、坚持天数），不显示群组正确率排名
- 相对进步 = 本周 vs 上周对比（仅与自己比，不与他人/群组比）
- 数据源：DailyStats + KnowledgeMastery 时间窗聚合
- **契约缺口**：D03 `vsLastWeek` API 仅 `learnedDelta`（多背 N 篇）+ `weaknessShift`（薄弱点迁移）两字段，缺"坚持天数"——本切片标注待 D03 补充（见缺口决策）

---

### 10.5 薄弱知识点（weakness）

#### 功能描述

家长查看孩子知识点-掌握度矩阵（可下钻到具体篇目），定位薄弱知识点。

#### 操作描述

1. 家长查看薄弱知识点页
2. 展示知识点-掌握度矩阵（按学科分组 + 掌握状态色）
3. 点某知识点 → 下钻到具体篇目

#### 约束条件

- 数据源：KnowledgeMastery（按需触发聚合——家长报告打开时触发刷新）
- 掌握度状态色映射（家长端文案）：✕灰-未掌握 / △橙-需巩固 / ○绿-已掌握 / ★金-熟练
- 下钻篇目需补 API（D03 无下钻参数/子接口，标注缺口）

---

### 10.6 取消续费 / 管理订阅

#### 功能描述

已订阅家长管理订阅：查看订阅列表（多孩子）、取消续费。

#### 操作描述

1. 家长查看我的订阅列表（各孩子订阅状态：试用中/已订阅/已过期/已取消）
2. 取消续费 → Status=cancelled（权益至周期末）

#### 约束条件

- 取消续费后权益保留至当前周期末（cancelled）
- 已订阅隐藏付费入口，提供"管理订阅/取消续费"
