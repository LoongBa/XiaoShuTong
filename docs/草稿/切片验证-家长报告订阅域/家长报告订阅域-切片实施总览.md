> **编制依据**：U01-家长成长报告 全部 UC
> **用途**：AC 阶段 Agent 的 Service 实现总纲（切片验证版）

## 各 Service 测试要点

| Service 类 | 重点验证 | 边界条件 | 注意 |
|-----------|---------|---------|------|
| `CreateParentRelationService` | 孩子角色校验、幂等（UNIQUE） | 非学生/重复关联 | 授权链建立 |
| `ListChildrenService` | 仅本人孩子（RLS）、订阅状态关联 | 无孩子空列表 | 多孩子切换数据源 |
| `StartTrialService` | 授权链校验（8002）、试用 7 天 | 已试用幂等 | 付费入口 |
| `ActivateSubscriptionService` | 支付回调激活、周期推进（月/年） | 重复回调幂等 | Callee |
| `ListSubscriptionsService` | 仅本人订阅（RLS） | 无订阅空列表 | |
| `CancelSubscriptionService` | 置 cancelled、权益至周期末 | 非本人订阅 | |
| `GetDashboardReportService` | 订阅门控（前2项+locked）、链式聚合、合规 | 无数据 4001/试用过期 8003 | 报告核心 |
| `GetProgressReportService` | 相对进步计算（本周 vs 上周）、合规无排名 | 无周期数据占位 | vsLastWeek 缺天数字段标注 |
| `GetWeaknessReportService` | 订阅门控、按需触发聚合、状态映射 | 无数据触发聚合 | 下钻 API 缺口标注 |

## 存量差异与迁移决策（实施前置确认）

| # | 项 | 状态 | 影响 |
|:-:|---|:----:|------|
| ① | 主键 uuid → long Id | **沿用决策**：内部 long + 外部 Uid(uuid) | 实体表补 Uid 列（唯一索引）；API/DTO 暴露 Uid |
| ② | 审计字段 | ParentStudentRelations CreatedAt 转化 + Subscriptions 补齐 | 迁移脚本改名/补列 |
| ③ | 枚举小写 → PascalCase | 本切片已转化（parent→Parent、month→Month、trialing→Trialing） | 存量数据映射 |
| ④ | 错误码 80xx/40xx + SNAKE_CASE 双列 | 本切片已采用 | DG-06 附录迁移规则 |
| ⑤ | 授权链应用层校验 | 非 DB 约束（对齐 D02） | 订阅/报告前校验 ParentStudentRelations |
| ⑥ | 价格字段 | Plan 仅 month/year，单价外部配置 | 非本表字段 |
