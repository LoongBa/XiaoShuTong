# DS01-题库与判题 · 数据结构设计

> **所属阶段**：第一阶段（设计层），切片验证（路径 B 转化）
> **前置条件**：R01 + S01 已产出
> **产出物**：题库域 2 实体（Banks/Questions）+ 判题域 1 实体（JudgmentFeedback）定义 → 输入给 xCodeGen
>
> **转化说明**：本 DS 由 D01 V1.3 §7.6 题库元数据 DDL + D02 V1.4 §4.15 判错反馈转化。**内容权威仍是 JSON 文件**（bank.v1.json），DB 表为 API 查询索引；存量 DDL 与 TKWF 框架约定的差异在「存量差异标注」节集中说明。
> **子域决策**：本切片使用子域 `Bank`（Banks/Questions 题库核心）+ `Judging`（判题反馈）——题库与判题各自内聚；题型注册表/学科注册表为配置 JSON（非实体），由服务层读取。

## 实体关系

```
Users (1) ──→ (N) Banks                群主创建私域题库（OwnerId；官方题库 NULL）
Banks (1) ──→ (N) Questions           题库包含题目（BankId 业务键引用）
Attempts (1) ──→ (N) JudgmentFeedback  作答被反馈（跨模块：Attempts 在学习域）
Users (1) ──→ (N) JudgmentFeedback    学生提交反馈
```

> 跨模块实体引用（不在本 DS 定义）：`Users`（账户域）、`Attempts`（学习域）——FK 引用，编译依赖通过框架 DI 注入。

## 存量差异标注（D01/D02 DDL → TKWF 框架）

| # | 差异项 | D01/D02 存量 | TKWF 要求（DG-05） | 处理建议 |
|:-:|-------|-------------|-------------------|---------|
| ① | **主键类型** | `uuid` | `long Id`（硬性） | **沿用前序切片决策**：内部 `long Id`；外部关联、跨系统用 `Uid`（uuid 业务键）——实体表补 Uid 列（唯一索引），API/DTO 暴露 Uid |
| ② | **审计字段** | `CreatedAt/UpdatedAt` | `CreateTime/UpdateTime` | 本 DS 已按 CreateTime/UpdateTime 转化，迁移时改名 |
| ③ | **枚举存储** | 小写 `'memorize'/'private'/'active'` | PascalCase `"Memorize"/"Private"/"Active"` | 本 DS 已按 PascalCase 转化（含中文"分阶"类 → 英文，本域无中文枚举；D02 会话类型中文归学习域）；存量数据迁移映射 |
| ④ | **错误码** | 数字域码 15xx/90xx | DG-06 默认 SNAKE_CASE | **沿用决策**：保留数字码 + 语义名双列（见 U01 错误码表） |
| ⑤ | **内容权威** | JSON 文件（非 DB）为唯一事实源；DB 为索引 | Entity 每实体一表 | **特殊标注**：Banks/Questions 表为查询索引，内容权威仍在 JsonPath 文件；判题/答案读取走内容服务不从 Entity 直读（防爬） |
| ⑥ | **答案存储** | 答案仅在 JSON 文件 + 判题服务端，永不下发客户端 | 常规 Entity 含全部字段 | **特殊标注**：Questions.Content 镜像**不含答案**；答案由判题服务从 JSON 读取（防爬 DRM） |

> **字段覆盖校对（S/UI → DS）**：S01 场景与 UI 页面展示字段（学科卡片、题库名/版本/题量/用途标签、知识点树、篇目预览、导入结果统计、预处理状态徽章、校验列表、判题反馈、判错了）——学科/题库列表/知识点均能映射。① 学科卡片 = Banks.Subject + QuestionCount（聚合）；② 知识点树 = Questions.KnowledgePoints/ChapterId；③ 题量 = Questions 聚合；④ 知识卡片/题目预览内容 = Questions.Content 镜像（不含答案 ✅）；⑤ 判错了 = JudgmentFeedback ✅。（题目内容展示字段在 Content JsonDocument 内，字段覆盖按 JSON Schema 校验）
