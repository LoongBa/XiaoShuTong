# 模块 3：题库管理

## 模块描述

群主（教师）创建私域题库、导入/录入题目（`问题###答案` txt / JSON / 批量粘贴 / 单题录入）、上传 PDF/Word/文本经 AI 预处理生成背诵点草稿（人工校验后入库）、维护单元章节与分类标签；学生端提供自由背诵入口（学科卡片网格）与题库浏览（知识点树预览），复习/任务场景经防爬取题接口按需取题。题库默认私有，按 DRM 规则防护。

---

### 3.1 多学科题库浏览（列表/详情）

#### 功能描述

按学科（语文/数学/英语/物理/化学/生物/历史/地理/政治 + 趣味）分类展示题库；学生可浏览题库结构（知识点树）与预览题目示例（不含答案）。

#### 操作描述

1. 学生进入自由背诵入口 → 展示学科卡片网格（语文/趣味热门前置，未解锁学科标注"群主布置后开启"）
2. 点选学科 → 展示该学科题库卡片列表（库名/版本/题量/用途标签）
3. 点入题库 → 展示知识点树（章节层级展开）+ 篇目真题示例（只展示题目不展示答案）
4. 群主端"我的资料库"入口（阶段二 UI）展示自建题库列表（名称/学科/题量/使用次数）

#### 约束条件

- 题库列表支持学科筛选（互斥单选）、用途过滤、分页
- 题目预览**不展示答案**（防剧透），仅展示题目内容
- 空题库展示空态"暂无内容" + 引导"等群主布置"
- 全学科体系 9 科 + 趣味（官方冷启动语文 + 趣味免费引流，小三科群主上传主战场）

---

### 3.2 创建私域题库

#### 功能描述

群主创建自己的题库（名称/学科/用途/隐私），成为题库所有者。

#### 操作描述

1. 群主进入"我的资料库" → 点击新建
2. 填写题库名称、选择学科、用途（背诵/检验）、隐私（默认私有）
3. 系统创建题库 → 题库进入空态（待导入/录入题目）

#### 约束条件

- 题库名称必填；学科必填；隐私默认私有（仅创建者可见）
- 群主可创建多个题库（不同学科/用途）
- 官方题库只读、不可改不可删；私域题库仅 Owner 可管理
- 非 Owner 对私域题库操作返回无权限

---

### 3.3 题目导入（txt / JSON / 批量粘贴）

#### 功能描述

群主通过结构化文本（`问题###答案` 注释 `#`）或 JSON 文件导入题目，或批量粘贴文本；导入后自动提取判题关键词、按目标章节归位。

#### 操作描述

1. 群主进入题库 → 选择导入方式（上传 .txt/.json 文件 / 批量粘贴）
2. 系统预检（格式/大小 ≤10M/解析）→ 导入解析：按目录/注释推断学科与题型，生成题目内容
3. 系统 Schema 校验 + 重复题检测 + 内容安全扫描
4. 返回导入结果（成功数/失败数/失败明细行号）

#### 约束条件

- 单文件 ≤10M；支持 `问题###答案` 格式，`#` 为注释行
- 导入时自动提取判题关键词（同义词组/权重/必中要点），供判题一层使用
- 导入题目写入内容权威 JSON 文件 + 更新题库/题目元数据索引（事务内）
- 导入对当前题库必须有管理权限
- 失败明细必须给出行号与原因（如"行 45: 格式错误"）

---

### 3.4 AI 预处理生成背诵点（生产端工具链，阶段二 UI）

#### 功能描述

群主上传 PDF/Word/纯文本资料，AI 预处理生成背诵点草稿，**人工校验后**入库（AI 不得直接入库）。

#### 操作描述

1. 群主上传资料文件（PDF/Word/纯文本）→ 预检（格式/大小）
2. 系统异步 AI 预处理（长耗时可后台化：离开页面后可继续，稍后回来查看状态徽章）
3. 预处理完成 → 逐条审核 AI 生成的背诵点（可改可删），校验进度条
4. 通过 → 入库到"我的资料库"（可选提交官方题库候选，不承诺上架）

#### 约束条件

- **AI 生成的背诵点必须人工校验后才能入库**（内容准确性把关由人工完成）
- 预处理为后台任务，支持页面间保留状态 + 完成后通知
- 未校验条目防误提交：提示"还有 N 条未校验，确认跳过？"
- UI 页阶段二（V2.2 标注），业务链路 MVP 先行

---

### 3.5 单题录入/修改/删除与单元章节管理

#### 功能描述

群主逐题录入新题目、修改/删除既有题目，维护单元章节归属。

#### 操作描述

1. 群主在题库中"单题录入" → 填写题型/题目内容/答案/知识点/难度
2. 保存 → Schema 校验 → 入库
3. 群主修改题目（改版）→ 旧题标记失效（不物理删除，以替代关系指向新题）
4. 群主删除题目（软删除/下线）→ 历史作答保留，题目原文不可见
5. 群主维护单元章节（新增/重命名/调整章节归属）

#### 约束条件

- 题目改版**不删除旧题**，以替代关系标记（保留作答历史追溯）
- 题目删除 = 下线（历史学习记录保留，新题展示"题目已下线"）
- 知识点与题型必填，Schema 校验（题型注册表决定 content 字段要求）
- 仅题库 Owner 可录入/修改/删除

---

### 3.6 分类标签

#### 功能描述

题库与题目支持按主题、难度分类 + 自定义标签（如"高频考点""易错点"）。

#### 操作描述

1. 群主在题库/题目上添加自定义标签（可多选可新建）
2. 系统标签以标签集合存储（题库级 JSONB、题目级）
3. 学生端可按标签/知识点筛选题目（列表场景）

#### 约束条件

- 标签为题库/题目级附加元数据（不建独立标签表，合并入内容元数据）
- 标签命名 ≤N 字，无敏感词
- MVP 不实现标签体系管理页（P1 延后），API 保留能力

---

### 3.7 防爬取题（背一题取一题）

#### 功能描述

学习会话按需取题（回答案与关键词仅判题服务端校验），实现"背一题取一题"防爬。

#### 操作描述

1. 学习会话请求下一题（携带会话/题库/题型/知识点条件）
2. 系统按状态机出题规则（到期复习优先 → 未掌握优先 → 新题）选题
3. 任务会话出题范围限任务题集；返回题目内容（不含答案）+ 点知识卡片 ID

#### 约束条件

- **响应不含答案**：答案与关键词仅判题服务端从内容源读取校验
- 不发返回明文题列表（防爬核心）
- 出题必须携带会话上下文（状态机按用户记忆状态路由）
- 私域题库按 OwnerId RLS 行级安全；群组引用不复制（组员只读）

---

### 3.8 知识卡片浏览

#### 功能描述

题目关联的知识卡片（背景钩子）展示（语文背景/历史典故/地理趣闻/生物概念等）。

#### 操作描述

1. 学生/群主查看题目详情 → 请求关联知识卡片
2. 系统按题目模板返回知识卡片字段（作者卡/字卡/事件卡等）
3. 求助提示（S1/S2/S3）从知识卡片提取线索（不从答案提取）

#### 约束条件

- 知识卡片按题库模板渲染，字段由题库定义
- R4 知识卡片题型为非判题（展示型）
- 提示生成从知识卡片提取，**严禁从答案提取**

## 模块 5：AI 导师判题

## 模块描述

两层判题架构：本地关键词拦截（零成本 60-70%）→ LLM 语义判题（OpenAI 兼容，可插拔，超时降级本地规则）。输出统一五键契约（结果/置信度/命中词/缺失词/引导提示）。学生"判错了"反馈进入人工复核队列。

---

### 5.1 规则判题（客观题 O1-O5）

#### 功能描述

客观题型（单选/多选/判断/连线/填空）经规则引擎零成本比对判题。

#### 操作描述

1. 系统按题型注册表路由到 O 系列规则引擎
2. 规则引擎比对（单选 exact、多选集合比对、判断规范化、连线配对、填空关键词）
3. 输出统一契约（result/confidence/matched/missing/hint）

#### 约束条件

- O1-O4 纯规则比对零 LLM 成本；O5 填空走关键词主判
- 多选/连线支持部分得分（partial + 比例置信度）
- 规则判题置信度确定（全对 1.0、部分按命中率）
- 边界：多选错选无交集 → wrong；判断"对/√/正确"归一化

---

### 5.2 两层判题（关键词 + LLM 语义判题）

#### 功能描述

记忆型/主观型题目判题：本地关键词拦截（≥85% 直接判正确，60-85% 部分正确，<60% 走 LLM）；LLM 语义判题输出统一契约；超时降级本地规则。

#### 操作描述

1. 系统按题型 register 路由（memory→hybrid；subjective→LLM；objective→rule）
2. 关键词层：按同义词组/权重/必中要点计算命中率 → 满足阈值直接判定
3. 未达阈值 → LLM 语义判题（供应商可插拔，Prompt 绑定矩阵按单题>学科×题型>题型>学科>全局）
4. LLM 超时(>3s)/失败 → 降级本地规则引擎 + 提示用户"判题降级"
5. 输出五键契约 → 学习域写 Attempts + 记忆状态迁移

#### 约束条件

- 关键词命中率 ≥85% → 正确；60-85% → 部分正确；<60% → LLM
- required 必中要点未命中 → 强制部分正确（即使命中率达标）
- 同义词组（aliases）组内任一命中即该组命中（"唐太宗"="李世民"）
- LLM 超时 >3s 降级；判题 P95 ≤3s；本地拦截 60-70% 请求（成本前提）
- AI 只判题不解释新知识点（防幻觉污染学习内容）

---

### 5.3 判错反馈（"判错了"）

#### 功能描述

学生对判题结果有异议时一键"判错了"，反馈进入人工复核队列，计入判题质量统计。

#### 操作描述

1. 学生学习中对某次作答点"判错了"（判题结果旁）
2. 系统记录反馈（关联作答 + 反馈类型）→ 状态待复核（pending）
3. 人工复核 → 已复核/已解决；计入判题质量统计（准确率 ≥95% 目标）

#### 约束条件

- 每作答最多一次有效反馈（幂等）
- 反馈必须关联到实际作答记录
- 复核后反馈状态流转（pending → reviewed → resolved）
- 判题准确率 ≥95% 以用户反馈为基准
