## UC-B.1：题库列表

**对应场景**：S01-3.1 → 步骤 2~3；S01-3.2 → 步骤 1
**对应 UI 图**：bank-self#2~3
**子域**：`Bank`
**事务范围**：SINGLE
**故障容忍度**：Required
**权限要求**：`student` / `owner`（群主看资料库）
**关联 R 功能点**：R01-3.1
**API 路由**：`GET /api/v1/banks?subject=chinese&purpose=memorize&page=1&size=20`

### [场景层]

#### Precondition
1. 已登录（[SDKStep] 微信授权完成）

#### Main Flow
1. 学生进入自由背诵入口 → 系统按学科分类返回题库卡片（库名/版本/题量/用途标签）
2. 学生切换学科筛选/用途 → 列表即时更新（保留滚动位）

#### Alternative Flow
- 1a. 无题库 → 空态"暂无内容" + 引导"等群主布置"（BR-01）
- 1b. 学科/分页参数非法 → 1002（BR-02）

#### Postcondition
- 数据：无写入
- 页面：题库卡片列表

## UC-B.4：导入题目（txt/JSON）

**对应场景**：S01-3.3 → 步骤 1~3b
**对应 UI 图**：content-import#1
**子域**：`Bank`
**事务范围**：CROSS（写 JSON 文件 + 事务内 upsert Banks/Questions 索引）
**事务策略说明**：内容权威文件写入与元数据索引必须原子——文件已写但索引缺失会造成内容断层
**故障容忍度**：Required
**权限要求**：`owner`
**关联 R 功能点**：R01-3.3
**API 路由**：`POST /api/v1/banks/{bankId}/import`（multipart/form-data）

### [场景层]

#### Precondition
1. 已登录且角色为群主；题库存在且为 Owner

#### Main Flow
1. 群主上传 .txt/.json 文件（或批量粘贴，见 [Proposed] 变体）→ 系统预检（格式/大小）
2. 系统解析（txt `问题###答案`，`#` 注释；按目录/注释推断学科与题型）
3. Schema 校验 + 重复题检测 + 内容安全扫描 + 自动提取关键词
4. 返回导入结果（imported/failed/failures 行号明细）

#### Alternative Flow
- 1a. 题库不存在 → 1501（BR-11）
- 1b. 文件超 10M / 格式不支持 → 预检拒绝（BR-12）
- 1c. 非 Owner → 1004（BR-13）
- 4a. 部分行失败 → 返回失败行 + 原因（BR-14）

#### Postcondition
- 数据：JSON 文件更新（权威）+ Banks/Questions 索引 upsert；关键词提取入库
- 页面：导入结果态（成功/失败明细）

## UC-B.5：防爬取题（背一题取一题）（Callee）

**调用方**：学习域 → `CreateStudySessionService` / `SubmitAttemptService`（切片 02）
**触发场景**：S01-3.2 → 步骤 3（"去背诵"）
**子域**：`Bank`
**事务范围**：SINGLE
**事务策略说明**：纯读（无写入事务）
**故障容忍度**：Required
**关联 R 功能点**：R01-3.7
**API 路由**：`GET /api/v1/questions/next?bankId=xxx&type=R1&knowledgePoint=观沧海&sessionId=uuid`

### Precondition（数据状态条件）
- 会话有效（sessionId）；题库存在且有访问权
- 调用方（学习域）已按状态机规则传递选题条件

### Main Flow（系统流程，无用户操作）
1. 学习域请求下一题（题库/题型/知识点/会话）
2. 系统按状态机出题规则选题（到期复习优先 → 未掌握优先 → 新题）
3. 任务会话出题范围限任务题集（Tasks.QuestionIds）
4. 返回题目内容（镜像，不含答案）+ 知识卡片 ID

### Alternative Flow（数据异常路径）
- 1a. 题库不存在/无权限 → 1501/1004（BR-17）
- 1b. 无可用题目（题集耗尽）→ 空结果（BR-18）

### Postcondition
- 数据：无写入
- 返回：questionId/type/content(无答案)/knowledgePoint/knowledgeCardId

# 三、横切关注点标注

| 关注点 | 实现方式 | 本域 UC 标注 |
