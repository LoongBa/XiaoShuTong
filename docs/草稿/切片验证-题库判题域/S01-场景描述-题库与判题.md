# S01 · 题库与判题场景

> **所属模块**：模块 3（题库管理）+ 模块 5（AI 导师判题）
> **前置条件**：R01-需求与功能设计-题库与判题.md 已产出
> **路径选择**：学生端自由背诵/题库预览有 UI → 完整模板；群主端内容管理页阶段二（V2.2）→ 场景仍按业务能力描述（UI 页标注阶段二，业务走 API）；AI 预处理为后台任务 → [BackgroundJob]
>
> 本文档从 UI设计文档-v2 V2.2（/student/bank/self 自由背诵入口、/student/study/task 判题反馈、/owner/content/* 阶段二入口）与归档输入文档 §16（PGC 上传管线）反推。

## 场景 3：群主导入题目（txt/JSON/批量粘贴）

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-3.3 |
| 场景名称 | 群主向私域题库导入题目 |
| 关联 R 功能点 | R01-3.3 |
| 触发条件 | 群主创建题库后导入题目 |
| 前置系统判断 | 已登录且角色为群主；题库存在且当前用户为 Owner |
| 涉众 | 群主 |
| 涉及端 | 群主 PC（业务能力 MVP 先行；UI 页阶段二） |
| 跨模块依赖 | 依赖模块 2（账户/认证：Owner 判定） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 |
|:----:|:--:|---------|---------|-------------|
| 1 | 群主PC | 题库选择导入：上传 .txt/.json 或批量粘贴 | 文件进度条 / 解析中 | 导入中态 |
| 2 | 群主PC | — | 预检（格式/大小 ≤10M/解析）→ Schema 校验 + 重复检测 + 内容安全 | 校验中态 |
| 3 | 群主PC | — | 返回导入结果（imported/failed/failures 行号明细） | 结果态 |
| 3a | 群主PC | （部分失败）查看失败明细 | 展示失败行 + 原因（如"行 45: 格式错误"） | 部分失败态 |
| N | — | — | 流程结束 | 停留题库详情 |

### 异常路径

| 步骤 | 场景 | 处理方式 |
|:----:|------|---------|
| 1a | 文件超 10M / 格式不支持 | 预检拒绝 + 提示 → 停留上传态 |
| 3b | 全量失败 | 失败汇总 + 修改重试入口 |
| 3c | 题库不存在/非 Owner | 资源不存在/无权限（1501/1004） |

## 场景 4：群主上传资料 AI 预处理（BackgroundJob）

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-3.4 |
| 场景名称 | 群主上传 PDF/Word/文本 → AI 预处理 → 人工校验 → 入库 |
| 关联 R 功能点 | R01-3.4 |
| 触发条件 | 群主上传资料文件 |
| 前置系统判断 | 已登录且角色为群主；题库存在且为 Owner |
| 涉众 | 群主 |
| 涉及端 | 群主 PC（UI 页阶段二，业务链路 MVP） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 |
|:----:|:--:|---------|---------|-------------|
| 1 | 群主PC | 上传资料（PDF/Word/文本） | 预检通过 → 触发异步 AI 预处理 | 上传中态 → 预处理中态 |
| 2 | 群主PC | （离开页面可继续） | 后台任务状态徽章（页面间保留）→ 完成后通知 | 预处理中态（可后台化） |
| 3 | 群主PC | 查看校验列表 | 逐条背诵点：来源高亮（AI 生成）+ 编辑/删除/通过 | 校验列表态 |
| 3a | 群主PC | （未全部校验点入库） | 提示"还有 N 条未校验，确认跳过？" | 防误提交确认态 |
| 4 | 群主PC | 确认入库 | 入库到"我的资料库"（可选官方候选） | 入库完成态 |
| N | — | — | 流程结束 | 停留资料库 |

> **数据处理 [BackgroundJob]**：AI 预处理为异步后台任务（长耗时），详见 U01 UC-3.x（预处理调度规则 + 幂等 BR）。
