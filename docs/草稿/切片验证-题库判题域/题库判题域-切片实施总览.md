# 题库判题域 · 切片实施总览

> **项目**：小书童（XiaoShuTong）
> **编制依据**：U01-题库与判题 全部 UC
> **用途**：AC 阶段 Agent 的 Service 实现总纲（切片验证版）
> **范围**：题库管理域（模块 3）+ AI 判题域（模块 5）
> **子域**：`Bank`（题库）+ `Judging`（判题）

> **框架自动生成原则**：只需用 tkwf-entity 编写 Entity、用 tkwf-service 编写 Service，其余全部自动生成——Entity → xCodeGen → DataService/DTO/Conditions，Service → `[GenerateController]` → SG → Controller/契约接口/Api/Wasm 客户端与 ts 客户端。

## 各 Service 测试要点

| Service 类 | 重点验证 | 边界条件 | 注意 |
|-----------|---------|---------|------|
| `ListBanksService` | 学科筛选/分页、可见性过滤（私域仅 Owner） | 空列表正常返回 | 官方库只读过滤 |
| `GetBankDetailService` | 知识点树组装、预览不含答案 | 题库不存在/无权限 | 防剧透（答案剔除） |
| `CreateBankService` | 创建 + Owner 落库、Group 隐私校验 | 名称超长/隐私 Group 无组 | 官方库只读拦截 |
| `ImportQuestionsService` | 解析 txt/json、关键词提取、文件+索引原子 | 超 10M/部分行失败 | 批量粘贴变体 [Proposed] |
| `GetNextQuestionService` | 防爬（不含答案）、状态机排序 | 题集耗尽空结果 | Callee，被学习域调用 |
| `GetKnowledgeCardService` | 题库模板渲染 | 无关联卡片空返回 | |
| `BankContentPreprocessJob` | AI 预处理幂等、草稿生成、状态流转 | 预处理超时/失败 | 人工校验硬门槛 |
| `ReviewBackingPointsService` | 未校验确认拦截、文件+索引原子 | 跳过未校验 | AI 草稿不可静默入库 |
| `JudgingEngineService` | **规则 O1-O5 比对**（D07 测试矩阵 14 例）、关键词组判、required 强制 partial、LLM 降级 | 阈值边界 0.85/0.5、超时 >3s | Callee；五键契约输出 |
| `SubmitJudgmentFeedbackService` | 作答存在校验、幂等、质量统计 | 重复反馈 | 跨模块引用学习域 Attempts |

## 存量差异与迁移决策（实施前置确认）

| # | 项 | 状态 | 影响 |
|:-:|---|:----:|------|
| ① | 主键 uuid → long Id | **沿用决策**：内部 long + 外部 Uid(uuid) | 实体表补 Uid 列（唯一索引）；API/DTO 暴露 Uid |
| ② | CreatedAt/UpdatedAt → CreateTime/UpdateTime | 本切片已转化 | 迁移脚本改名 |
| ③ | 枚举小写 → PascalCase | 本切片已转化（memorize→Memorize；小写 subject→Chinese 等） | 存量数据映射 |
| ④ | 错误码 15xx/90xx + SNAKE_CASE 双列 | 本切片已采用（1501/1502/9001 存量 + 6001 无新造码值） | DG-06 附录迁移规则 |
| ⑤ | **内容权威=JSON 文件（非 DB）** | 特殊标注（DS01 差异⑤⑥） | Banks/Questions 仅为查询索引；答案/关键词由判题服务从文件读 |
| ⑥ | D03 题库 CRUD 缺口 | 已建模 [Proposed-待D03补充]（更新/删除/单题/标签/批量粘贴/上传） | 实施前需回改 D03 或业务确认 |
