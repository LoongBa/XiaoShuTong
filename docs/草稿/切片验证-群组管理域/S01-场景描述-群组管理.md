## 场景 1：群主激活建群并创建群组

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-6.1 |
| 场景名称 | 群主凭内测邀请码激活建群 |
| 关联 R 功能点 | R01-6.1 |
| 触发条件 | 群主收到平台发放的内测邀请码 |
| 前置系统判断 | 登录身份为群主（Role=owner） |
| 涉众 | 群主（教师/班主任） |
| 涉及端 | 群主 PC |
| 跨模块依赖 | 依赖模块 1（账户/认证：群主身份） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 | 对应UI图 |
|:----:|:--:|---------|---------|-------------|:--------:|
| 1 | 群主PC | 进入"内测邀请码领取"页 | 展示输入框 + 说明文案 | 未领取态 | beta-invite#1 |
| 2 | 群主PC | 输入 16 位内测邀请码 | 校验中 loading | 校验中态 | beta-invite#2 |

| 2b | 群主PC | （失败）码已过期 | 状态卡灰置"邀请码已过期"+联系平台续期文案 | 已过期态 | beta-invite#4 |
| 3 | 群主PC | 校验通过 → 填写群组名/学科/年级 → 创建群组 | 成功 Toast + 引导进入群组管理 | 激活成功态 → 群组列表 | beta-invite#5 |
| 4 | 群主PC | — | 码标记已使用，不可复用 | 已激活态（显示已激活群组 + "进入群组"） | beta-invite#6 |
| N | — | — | 流程结束 | 跳转群组管理页 | [定稿后填] |

## 场景 3：成员凭一次性邀请码激活加入群组

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-6.3 |
| 场景名称 | 成员凭码 + 微信登录激活入群 |
| 关联 R 功能点 | R01-6.9 |
| 触发条件 | 成员收到群主分发的邀请码（话术模板） |
| 前置系统判断 | 微信已授权（OpenId 已建 Users 行）；身份为学生/家长（由名单预设） |
| 涉众 | 学生 / 家长 |
| 涉及端 | 成员 H5 |
| 跨模块依赖 | 依赖模块 1（账户/认证：微信登录） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 | 对应UI图 |
|:----:|:--:|---------|---------|-------------|:--------:|
| 1 | 成员H5 | 进入"成员激活"页 | 展示邀请码 + 手机号后四位输入框 | 默认态 | activate#1 |
| 2 | 成员H5 | 输入 8 位一次性邀请码 + 4 位手机号后四位 | 点击"微信一键登录并激活" | 校验中态 | activate#2 |
| 2a | 成员H5 | （失败）码无效 | 提示"邀请码无效，请检查后重新输入" | 停留默认态 | activate#3 |
| 2b | 成员H5 | （失败）码已使用 | 提示"该邀请码已被使用，请联系群主" | 停留默认态 | activate#4 |
| 2c | 成员H5 | （失败）码已过期 | 提示"该邀请码已过期，请联系群主重新生成" | 停留默认态 | activate#5 |
| 2d | 成员H5 | （失败）后四位不匹配 | 提示"手机号后四位与名单不符，请核对" | 停留默认态 | activate#6 |
| 3 | 成员H5 | 微信授权 → 服务端绑定微信 ID → 写入群组成员 → 码置 used | 成功动画"已加入群组" | 激活成功态 | activate#7 |
| N | — | — | 流程结束 | 进入学生/家长首页 | [定稿后填] |
