## 枚举定义

#### GroupStatus ── 群组状态

存储格式：`string`（PascalCase，存量 DDL 为小写，见存量差异③）
使用场景：Groups.Status

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Active | 启用 | 正常使用 |
| Archived | 归档 | 群组停用 |

#### MemberRole ── 群组成员角色

存储格式：`string`（PascalCase）
使用场景：GroupMembers.Role

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Student | 学生 | 名单预设 |
| Parent | 家长 | 名单预设 |

#### BetaCodeStatus ── 内测邀请码状态

存储格式：`string`（PascalCase）
使用场景：BetaInviteCodes.Status

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Pending | 待使用 | 平台发放未使用 |
| Used | 已使用 | 群主激活建群 |
| Expired | 已过期 | 超过有效期 |

#### OneTimeCodeStatus ── 一次性邀请码状态

存储格式：`string`（PascalCase）
使用场景：OneTimeInviteCodes.Status

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Unused | 未使用 | 可激活 |
| Used | 已使用 | 激活成功，不可复用 |
| Expired | 已过期 | 超过有效期 |

#### RosterImportStatus ── 名单批次状态

存储格式：`string`（PascalCase）
使用场景：RosterImports.Status

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Processing | 整理中 | Agent 异步整理 |
| Ready | 就绪 | 可生成一次性码 |
| Exported | 已导出 | CSV 已生成 |
| Failed | 失败 | 整理失败 |

## 实体关系

```
Users (1) ──→ (N) Groups                群主创建群组
Groups (1) ──→ (N) GroupMembers         群组包含成员
Users (1) ──→ (N) GroupMembers          用户加入群组
Users (1) ──→ (N) BetaInviteCodes       群主领取内测码
BetaInviteCodes (1) ──→ (0..1) Groups   内测码激活群组（一个码只能激活一个群组）
Groups (1) ──→ (N) OneTimeInviteCodes  群主按名单生成一次性码
OneTimeInviteCodes (1) ──→ (0..1) GroupMembers  码激活 → 写入成员（InviteCodeId 溯源）
Users (1) ──→ (N) OneTimeInviteCodes   成员激活绑定（BoundUserId）
RosterImports (1) ──→ (N) OneTimeInviteCodes  名单批次 → 生成码
Groups (1) ──→ (N) RosterImports       群主导入名单批次
```

## 存量差异标注（D02 DDL → TKWF 框架）

| # | 差异项 | D02 存量 | TKWF 要求（DG-05） | 处理建议 |
|:-:|-------|---------|-------------------|---------|
| ① | **主键类型** | `uuid` | `long Id`（硬性） | **已决策（2026-09-06）**：系统内部用 `long Id` 主键/外键；**外部关联、跨系统用 `Uid`（uuid 业务键）**——API 参数/响应/DTO 暴露 Uid，内部关联用 long。DS01 实体表应补 `Uid` 列（唯一索引），存量 uuid 列迁移为 Uid |
| ② | **审计字段** | `CreatedAt/UpdatedAt` | `CreateTime/UpdateTime`（AutoManagedField 对齐） | 本 DS 已按 CreateTime/UpdateTime 转化，迁移时改名 |
| ③ | **枚举存储** | 小写 `'active'/'pending'` | PascalCase `"Active"/"Pending"` | 本 DS 已按 PascalCase 转化，存量数据迁移时映射 |
| ④ | **错误码** | 数字域码 52xx | DG-06 默认 SNAKE_CASE | **决策**：保留数字码 + 语义名双列（见 U01 错误码表） |

> **字段覆盖校对（S/UI → DS）**：S01 场景与 UI 页面展示字段（群组名/学科/人数/执行率/排名开关/成员角色昵称/邀请码/手机号后四位/导入统计）均能在上述实体找到对应字段 ✅
