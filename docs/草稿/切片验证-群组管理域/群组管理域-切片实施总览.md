## 各 Service 测试要点

| Service 类 | 重点验证 | 边界条件 | 注意 |
|-----------|---------|---------|------|
| `CreateGroupService` | 码状态校验、一码一群组、群组创建+码标记原子性 | 已 used 码/过期码/群组名超长 | 内测开关关闭时拒绝 |
| `ListGroupsService` | 仅返回本人群组、成员数聚合 | 无群组空态 | 分页正确性 |
| `ManageGroupMembersService` | 成员列表聚合、移除不删学习数据 | 群组不存在/非 Owner | 二次确认在前端 |
| `SetRankEnabledService` | 开关默认 true、即时生效 | 非群主操作 | 战绩榜隐藏但战力榜不受影响 |
| `ImportRosterService` | 批次创建、统计原始行数 | 空名单 | 异步触发整理 |
| `RosterCleanupJob` | 去重/格式校验/非法剔除统计 | 全非法名单 | 幂等（不重复处理） |
| `GetRosterPreviewService` | 脱敏展示、状态轮询 | Processing 批次 | 脱敏合规（无完整手机号） |
| `GenerateInviteCodesService` | 每人一码、码↔后四位绑定、30 天过期 | 已生成批次重复生成 | 全局码唯一冲突重试 |
| `ExportRosterCsvService` | CSV 仅含后四位+码、OSS 7 天过期 | CSV 过期重导 | 合规（无 openid/学习数据） |
| `ActivateMemberService` | 码校验、后四位匹配、幂等、成员写入+码标记原子 | 码无效/已用/过期/后四位不匹配 | 角色由名单预设 |
