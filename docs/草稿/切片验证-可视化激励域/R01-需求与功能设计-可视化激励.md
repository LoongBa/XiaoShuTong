# 模块 6：可视化激励

## 模块描述

面向学生（6-15 岁）的成长可视化与激励体系：以记忆热力图、连续天数、学习报告、错题本、分享战报、学习路线图六类功能，将学习行为转化为**可见的进步反馈**（★/进度/热力），驱动持续背诵。核心理念：**进度感代替分数感**（合规红线：不出现正确率排名，只呈现努力度与相对进步）。

---

### 6.1 记忆热力图

#### 功能描述

按时间维度可视化学生的背诵活跃度（每日点亮 ★ 数），支持时间范围切换，展示学习天数/背诵题数/个人正确率与四阶熟练度分布。

#### 操作描述

1. 学生从首页快捷入口/今日热力图横条进入热力图页
2. 选择时间范围（本周/本月/本季度/今年/学习天数）
3. 系统按范围聚合每日点亮 ★ 数与学习题数（按日粒度）
4. 展示统计卡片（学习天数/背诵题数/正确率）+ 掌握情况四阶熟练度水平柱（✕灰-再背背/△橙-快熟了/○绿-很棒/★金-点亮了）
5. 本周期表现按范围自动调整周期粒度（周/月/季度/年），每条水平柱按熟练度颜色分段

#### 约束条件

- 数据源：DailyStats.StarredCount 按日期聚合（**复用切片 02 实体**，同步派生写入）
- 时间范围切换由前端传入起止日期（D03 仅 start/end，无预设枚举——本域决策：预设在前端换算为区间）
- 统计卡片"正确率"为**个人自己的正确率**（允许展示），非群组排名（禁止——合规红线）
- 空数据显示引导文案（"每天 5 分钟，点亮你的日历"，归档文档文案），非空白坐标轴

---

### 6.2 连续天数（打卡）

#### 功能描述

展示学生连续背诵天数（当前连击/历史最长），作为坚持力的核心激励指标。

#### 操作描述

1. 学生查看首页问候条连击徽章（🔥N 天）或统计页
2. 系统按日期连续性计算当前/最长连续天数
3. 断更清零，重新累计

#### 约束条件

- 数据源：DailyStats.StatDate 连续性 SQL 派生（当日/昨日有记录即延续，**不单独建表**）
- 连续天数按自然日（UTC+8）；断更清零
- 连击天数计入战力榜指标（跨模块，排行榜域消费）

---

### 6.3 学习报告（周/月）

#### 功能描述

按周期（周/月）聚合学习数据（学习题数/正确率/点亮★数/薄弱知识点），为学生提供周期回顾。

#### 操作描述

1. 学生选择周期（周/月）
2. 系统聚合周期内学习题数/正确率/★数/薄弱知识点
3. 展示周期报告（学习量 + 掌握质量 + 薄弱点）

#### 约束条件

- 数据源：DailyStats + KnowledgeMastery 时间窗聚合
- **合规红线**：报告只呈现相对进步（本周 vs 上周：多背 N 篇/薄弱点迁移/坚持天数），**不显示群组正确率排名**
- D03 §7.3 无相对进步字段（vsLastWeek 仅在家长域 §11.6）——本域学生端报告本期不含 vsLastWeek，标注待扩展

### 6.4 错题本（查看/重练/已掌握）

#### 功能描述

展示学生错题列表（知识点/错因/错误次数），支持重练入口；连续答对 2 次转"已掌握"分组（可移回）。

#### 操作描述

1. 学生从首页快捷入口/错误反馈【下一题】进入错题本
2. 查看错题列表（按学科分组/已掌握过滤）
3. 点"重练" → 进入复习会话（复用学习域会话流程）
4. 连续答对 2 次 → 题目转"已掌握"分组（带动画）；可"移回错题本"

#### 约束条件

- 数据源：WrongQuestions（**复用切片 02 实体**；Mastered 置位发生在学习域作答事务，本域只读）
- 空态"没有错题，记得很牢！"正面空态（三步式：没有错题 → 说明都会了 → 去挑战新内容）
- **文案决策**：空态文案取三步式模板"说明都会了"（对齐 §4 规范；页面级"记得很牢！"为表情文案，两者并存）
- 重练入口复用学习域会话（跨模块），不新建重练端点（D03 无独立重练 API）
- 错题数据仅本人可见（RLS）

### 6.5 分享战报（MVP 模拟）

#### 功能描述

将热力图数据生成为战报图片/文字/链接，支持 4 种风格切换，可保存/复制/分享（**MVP 为前端模拟分享**）。

#### 操作描述

1. 热力图页底部点"分享战报" → 弹窗
2. 切换 4 种风格（简约/活力/清新/优雅）
3. 保存图片 / 复制文字 / 复制链接 / 朋友圈 / 微信群（MVP 模拟）
4. 分享失败 → Toast"分享失败，请重试" + 重试

#### 约束条件

- **MVP 为前端模拟分享**（D03 无分享 API；真实社交分享/图片生成本期不实现）
- 战报内容基于热力图数据（当日/周期 ★ 数 + 坚持天数 + 相对进步文案）
- 合规红线：战报不出现群组正确率排名；文案允许"这周比上周多背了 3 篇"
- 分享失败 Toast + 重试按钮；保存图片/复制文字为验收项

### 6.6 学习路线图（简化版，UI 待补）

#### 功能描述

以单元/章节为节点展示学习进度路线（单元列表 + 完成率进度条 + 解锁状态），帮助学生看到整体学习路径。

#### 操作描述

1. 学生查看学习路线图（**入口与 UI 规格待补**——V2.2 无此页）
2. 按单元列表展示完成率进度条与解锁状态
3. 点单元/章节 → 进入对应学习内容

#### 约束条件

- **UI 文档 V2.2 中不存在此页面**（页面结构树/逐页说明/异常边界均无）——仅 PRD V3 有需求（"单元列表 + 完成率进度条 + 解锁状态，不做 Canvas 动画"）
- 本切片标注"UI 规格待补"，功能需求按 PRD 最小实现；**列入本期待确认项**
- 数据源：单元/章节（题库域 Questions.ChapterId）+ 掌握度（学习域 KnowledgeMastery）
- 不做 Canvas 动画（简化版）
