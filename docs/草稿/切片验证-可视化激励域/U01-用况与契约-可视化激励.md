## UC-6.1：查看记忆热力图

**对应场景**：S01-6.1 → 步骤 1~4
**对应 UI 图**：heatmap#1~4
**子域**：`Stats`
**事务范围**：SINGLE
**故障容忍度**：Required
**权限要求**：`student`
**关联 R 功能点**：R01-6.1
**API 路由**：`GET /api/v1/stats/heatmap?start=2026-08-01&end=2026-09-04`

### [场景层]

#### Precondition
1. 已登录且角色为学生

#### Main Flow
1. 学生进入热力图页 → 系统按日期区间返回每日 ★ 数与学习题数
2. 学生切换时间范围（前端换算 start/end）→ 图表刷新

#### Alternative Flow
- 1a. 无数据 → 空数据态（全年灰格 + 引导文案）（BR-01）
- 1b. 参数非法（start > end / 格式错）→ 1002（BR-02）

#### Postcondition
- 数据：无写入
- 页面：热力图 + 统计卡片 + 四阶柱

### [契约层]

#### Service 类声明

位置：`Domain/Services/Stats/`

```csharp
[GenerateController]
public class GetHeatmapService : DomainServiceBase<TUserInfo>
{
    public async Task<GetHeatmapResDto> ExecuteAsync(GetHeatmapReqDto request) { throw new NotImplementedException(); }
}
```

#### Request DTO

位置：`Domain/Dtos/Stats/Request/`

| 属性 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| Start | DateTime | ✅ | 区间起（YYYY-MM-DD） |
| End | DateTime | ✅ | 区间止 |

#### Response DTO

位置：`Domain/Dtos/Stats/Response/`

| 属性 | 类型 | 说明 |
|------|------|------|
| Days | DailyStatsDto[] | StatDate/StarredCount/LearnedCount（DTO 最小化：复用自动生成 DailyStatsDto，字段名 Date→StatDate） |

#### 业务规则

| BR# | 规则说明 | 测试场景 |
|:---:|---------|---------|
| BR-01 | 无数据正常返回空数组（前端展示空数据态） | 无记录 -> Days 空 + 码 0 |
| BR-02 | start ≤ end，格式 YYYY-MM-DD | start > end -> 1002 |
| BR-03 | 仅返回当前学生数据（RLS） | 无法查他人热力图 |
| BR-04 | 聚合粒度按日（StarredCount/LearnedCount） | 两日数据 -> 两条记录 |

#### 错误码定义

| 错误码 | 语义名 | HTTP | 业务含义 | 触发条件 |
|:------:|:------:|:----:|---------|:--------:|
| 1002 | PARAM_INVALID | 400 | 参数错误 | BR-02 |
| 1001 | UNAUTHORIZED | 401 | 未登录/令牌失效 | Precondition |

#### 依赖的 DataService

```csharp
ILearningDailyStatsDataService      // DailyStats 查询（跨模块，学习域——复用切片 02 DataService）
```

#### Service 编排逻辑

| 步骤 | 容忍度 | 操作描述 | 涉及 DataService | 对应规则 |
|:----:|:------:|---------|:----------------:|:--------:|
| 1 | Required | 校验参数（start/end） | — | BR-02 |
| 2 | Required | 按 UserId + 日期区间查 DailyStats | `ILearningDailyStatsDataService` | BR-03/BR-04 |
| 3 | Required | 聚合按日 StarredCount/LearnedCount，空返回空数组 | — | BR-01 |
