## 二、本域数据访问边界

### 2.1 查询模式（Service 层编排，不新建实体）

| 查询需求 | 数据源 | 编排方式 |
|---------|--------|---------|
| 热力图按日聚合 | DailyStats（UserId + StatDate 范围） | Service 按日期区间聚合 StarredCount/LearnedCount |
| 连续天数 | DailyStats.StatDate | Service 层 SQL 派生（当日/昨日连续性） |
| 周期报告 | DailyStats + KnowledgeMastery | 时间窗聚合 + 掌握度归并 |
| 四阶熟练度分布 | MemoryStates（跨模块，切片 02） | 按 State 分组计数 |
| 错题列表 | WrongQuestions（UserId + Mastered + Subject） | 分页查询 |
| 薄弱知识点 | KnowledgeMastery | 按 Accuracy 升序 TopN |

### 2.2 查询 DTO 定义（本切片新增，供 Service 返回）

| DTO | 字段 | 数据来源 | 说明 |
|-----|------|---------|------|
| HeatmapDayDto | Date / StarredCount / LearnedCount | DailyStats | 热力图单日数据 |
| StreakDto | CurrentStreak / LongestStreak | DailyStats（派生） | 连续天数 |
| PeriodReportDto | LearnedCount / Accuracy / StarredCount / WeakPoints[] | DailyStats + KnowledgeMastery | 周期报告 |
| WrongQuestionItemDto | QuestionId / Subject / WrongCount / LastWrongAt / Mastered | WrongQuestions | 错题条目（题目摘要内容取题库域） |

> DTO 遵循 D03 原则 #6：JSON 字段 camelCase；C# DTO 属性 PascalCase（框架自动序列化）。

## 三、实体关系（跨模块引用）

```
DailyStats (N) ── 用户（1）Users       每日统计（学习域写入，本域只读）
KnowledgeMastery (N) ── 用户（1）Users 掌握度聚合（学习域写入，本域只读）
WrongQuestions (N) ── 用户（1）Users   错题（学习域写入，本域只读）
MemoryStates (N) ── 用户（1）Users    四阶分布（学习域，本域聚合）
Banks/Questions ── 错题/单元           题目摘要/单元章节（题库域，本域跨模块取题元数据）
```

> 跨模块实体引用（不在本切片定义）：`Users`（账户域）、`DailyStats/KnowledgeMastery/WrongQuestions/MemoryStates`（学习域，切片 02）、`Banks/Questions`（题库域，切片 03）。

## 四、存量差异标注

| # | 差异项 | 说明 |
|:-:|-------|------|
| ① | **无新增实体** | 本域纯消费展示，实体复用切片 02——差异仅在于**查询 DTO 由本切片定义**（DTO 不建表） |
