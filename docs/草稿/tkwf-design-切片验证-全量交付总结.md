## 五、实施阶段规划（AC-Kit 编码顺序）

**依赖排序（跨切片依赖步骤 0 驱动）**：

```
阶段 1：切片 01（群组）→ 切片 02（学习 Session）→ 切片 03（题库判题）
阶段 2：切片 04（家校任务，依赖 02/03）→ 切片 05（可视化激励，复用 02）→ 切片 06（排行榜搭子，依赖 02/03/07）
阶段 3：切片 07（PK，依赖 03/06）→ 切片 08（家长报告，依赖 02/04）
```

**实施要点**：
- 每个切片按 HANDOVER §五「编码启动序列」执行（步骤 0 检查前序切片 Entity + xCodeGen 产物）
- 先完成阶段 1 三切片（核心层实体），再并行阶段 2（场景层），最后阶段 3
- 切片 05 无新增 Entity——直接复用切片 02 `Entities/Learning/*.cs`，仅写查询 DTO + Service
- 实施中如遇 D03/D02 缺口 → 按上表排期回改，回改后同步切片文档（DG-08）
