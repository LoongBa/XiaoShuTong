# 排行榜搭子域 · 切片实施总览

> **项目**：小书童（XiaoShuTong）
> **编制依据**：U01-排行榜与学习搭子 全部 UC
> **用途**：AC 阶段 Agent 的 Service 实现总纲（切片验证版）
> **范围**：排行榜域（模块 7）+ 学习搭子域（模块 8）
> **子域**：`Rank`（排行榜）+ `Buddy`（搭子）

> **框架自动生成原则**：只需用 tkwf-entity 编写 Entity、用 tkwf-service 编写 Service，其余全部自动生成——Entity → xCodeGen → DataService/DTO/Conditions，Service → `[GenerateController]` → SG → Controller/契约接口/Api/Wasm 客户端与 ts 客户端。

## 各 Service 测试要点

| Service 类 | 重点验证 | 边界条件 | 注意 |
|-----------|---------|---------|------|
| `GetRankingsService` | 快照查询、RankEnabled 门控（战绩榜 7001）、趋势箭头 | 无快照/参数非法 | 战力榜不受开关影响 |
| `GetMyRankingService` | RankChange 计算（今日−昨日） | 无快照空响应 | 仅个人排名 |
| `RankSnapshotFreezeJob` | 指标聚合（战力=streak+volume+pk_wins；战绩=accuracy+mastery）、幂等 upsert | 无指标数据跳过/单范围失败 | 每日 0:00 UTC+8 |
| `InviteBuddyService` | ≤5 校验、单日 ≤10（Redis）、同群组/同年级 OR、重复邀请拦截 | 已满/超限/非同源/重复 | ExpiresAt=+7 天 |
| `AcceptBuddyInviteService` | 双方 ≤5 FOR UPDATE 防并发、状态流转 | 邀请不存在/过期/已满 | CROSS 事务 |
| `RejectBuddyInviteService` | 状态置 rejected | 邀请不存在/已处理 | |
| `ListBuddiesService` | UNION 双向查询仅 accepted、排名快照互看 | 无搭子空态 | 不暴露答题明细 |
| `GetBuddyRankService` | 仅 accepted 可查看对方排名 | 非搭子 6004 | 最小化暴露 |
| `RemoveBuddyService` | 置 removed、历史保留 | 非当事人 | 二次确认在前端 |
