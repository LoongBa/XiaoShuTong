## 枚举定义

#### RankScopeType ── 排名范围类型

存储格式：`string`（PascalCase；存量小写 group/grade）
使用场景：RankSnapshots.ScopeType

| 枚举值 | 业务含义 |
|:------:|---------|
| Group | 群组范围 |
| Grade | 年级范围 |

#### RankMetricType ── 排名指标类型

存储格式：`string`（PascalCase；存量小写 streak/stars/volume/pk_wins/accuracy/mastery）
使用场景：RankSnapshots.MetricType

| 枚举值 | 业务含义 | 榜单归属 |
|:------:|---------|---------|
| Streak | 坚持天数 | 战力榜 |
| Volume | 背诵量 | 战力榜（**口径待确认**：D02 未定义 volume 来源，建议 = DailyStats.LearnedCount 累计，见存量差异④） |
| PkWins | PK 胜场 | 战力榜（跨模块 PkPlayerStats） |
| Accuracy | 正确率 | 战绩榜 |
| Mastery | 掌握度 | 战绩榜 |
| Stars | 点亮★数 | **当前无榜单消费**（枚举保留，D02 未在公式引用） |

#### BuddyStatus ── 搭子状态

存储格式：`string`（PascalCase；存量小写 pending/accepted/rejected/removed/expired）
使用场景：StudyBuddies.Status

| 枚举值 | 业务含义 |
|:------:|---------|
| Pending | 邀请中（ExpiresAt 内） |
| Accepted | 已搭子（双向同意生效） |
| Rejected | 已拒绝 |
| Removed | 已解除 |
| Expired | 已过期（7 天未响应） |

## 实体关系

```
Users (1) ──→ (N) StudyBuddies      用户作为邀请方
Users (1) ──→ (N) StudyBuddies      用户作为被邀请方
Users (1) ──→ (N) RankSnapshots     用户排名快照
```

## 存量差异标注（D02 DDL → TKWF 框架）

| # | 差异项 | D02 存量 | TKWF 要求（DG-05） | 处理建议 |
|:-:|-------|---------|-------------------|---------|
| ① | **主键类型** | `uuid` | `long Id`（硬性） | **沿用前序切片决策**：内部 `long Id`；外部关联、跨系统用 `Uid`（uuid 业务键）——实体表补 Uid 列（唯一索引），API/DTO 暴露 Uid |
| ② | **审计字段** | RankSnapshots 原无审计列；StudyBuddies 无 CreatedAt/UpdatedAt | `CreateTime/UpdateTime` | 本 DS 已补齐审计列 |
| ③ | **枚举存储** | 小写（group/grade/streak/pending） | PascalCase `"Group"/"Grade"/"Streak"/"Pending"` | 本 DS 已转化；存量数据迁移映射 |
| ④ | **volume 指标口径** | D02 仅列名，未定义来源（战力榜 = streak + volume + pk_wins） | 无强制 | **决策**：volume = DailyStats.LearnedCount 按范围累计（**实施前确认**——D02 缺口 G3） |
| ⑤ | **stars 指标** | MetricType 枚举含 stars，但战力/战绩榜公式均未引用 | 无强制 | **标注**：枚举保留，当前无榜单消费（待 PRD 确认是否用于分享战报展示） |
| ⑥ | **错误码** | 数字域码 60xx/70xx | DG-06 默认 SNAKE_CASE | **沿用决策**：保留数字码 + 语义名双列（见 U01 错误码表） |
| ⑦ | **同年级来源** | D02 无 Users.Grade 字段；搭子规则要求"同年级" | 无强制 | **决策**：年级经 `GroupMembers → Groups.Grade` 交集推导（非用户属性）；ScopeType=Grade 时同平台同年级（见缺口决策 G1/G12） |

> **字段覆盖校对（S/UI → DS）**：S01 场景与 UI 页面展示字段（范围选择/学科筛选/榜单类型/排名序号/前三样式/头像昵称/数值/趋势箭头/我的排名/变化量、搭子头像昵称/连续打卡天数/搭子排名快照、海报二维码/链接、确认页文案、空态文案）——① 排名列表 = RankSnapshots（Rank/MetricValue/SnapshotDate）+ Users 昵称头像 ✅；② 趋势箭头 = 今日 vs 昨日 SnapshotDate 对比（Service 层）✅；③ 搭子列表 = StudyBuddies + Users ✅；④ 连续打卡天数 = DailyStats 派生（跨模块）✅；⑤ 海报/链接 = 前端生成邀请链接 + 二维码（非持久化字段，标注"前端合成"）✅
