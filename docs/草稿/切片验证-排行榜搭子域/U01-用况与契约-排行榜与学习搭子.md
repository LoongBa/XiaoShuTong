## UC-7.1：榜单查询（战力榜/战绩榜）

**对应场景**：S01-7.1 → 步骤 1~6
**对应 UI 图**：rank#1~7
**子域**：`Rank`
**事务范围**：SINGLE
**故障容忍度**：Required
**权限要求**：`student`
**关联 R 功能点**：R01-7.1
**API 路由**：`GET /api/v1/rankings?scopeType=group&scopeId=uuid&subject=all&metric=combat&date=2026-09-05&limit=50`

### [场景层]

#### Precondition
1. 已登录且角色为学生；为群组/年级成员

#### Main Flow
1. 学生查看排行榜（范围/学科/榜单类型）→ 系统返回排名列表 + 趋势箭头
2. 切换榜单类型/范围/学科 → 列表刷新（保留滚动位）

#### Alternative Flow
- 1a. 无排名数据 → "还没有排名数据，完成背诵任务即可上榜"（BR-01）
- 1b. 战绩榜已关闭（RankEnabled=false）→ 7001 + rankEnabled=false（BR-02）
- 1c. 参数非法 → 1002（BR-03）

#### Postcondition
- 数据：无写入
- 页面：排名列表 + 我的排名

### [契约层]

## UC-7.3：排名快照每日冻结（BackgroundJob）

**调度规则**：Hangfire 每日 0:00（UTC+8）执行
**事务范围**：CROSS（聚合指标 + 批量写入快照）
**故障容忍度**：Optional（单范围失败记录，不中断整批）
**关联 R 功能点**：R01-7.3

### Precondition（数据状态条件）
- 排名指标数据就绪（DailyStats/PkPlayerStats/KnowledgeMastery）

### Main Flow（系统流程，无用户操作）
1. 扫描各范围（群组/年级）× 学科 × 指标
2. 聚合指标值（streak/volume/pk_wins/accuracy/mastery）→ 排序
3. 写入 RankSnapshots（SnapshotDate=当日，Rank 冻结）

### Alternative Flow（数据异常路径）
- 1a. 无指标数据 → 跳过该范围（BR-09）
- 2a. 单范围聚合失败 → 记录日志继续下一范围（BR-10）

### Postcondition
- 数据：RankSnapshots 已写入（当日冻结）

### [契约层]

#### Service 类声明

位置：`Domain/Services/Rank/`

```csharp
// 不标注 [GenerateController]（调度器触发）
// 不标注 [AuthorityFilter]（系统内部任务）
public class RankSnapshotFreezeJob : DomainServiceBase<TUserInfo>
{
    public async Task ExecuteAsync(CancellationToken ct) { throw new NotImplementedException(); }
}
```

#### 业务规则

| BR# | 规则说明 | 测试场景 |
|:---:|---------|---------|
| BR-09 | 无指标数据跳过（幂等） | 无数据 -> 不写入 |
| BR-10 | 单范围失败不中断整批 | 某范围异常 -> 跳过继续 |
| BR-11 | 战力榜指标 = streak + volume + pk_wins（简单求和） | 3 指标值 -> 求和 |
| BR-12 | 战绩榜指标 = accuracy + mastery（简单求和） | 2 指标值 -> 求和 |
| BR-13 | 同一 (User,Scope,Subject,Metric,Date) 幂等 upsert | 重复触发 -> 不重复写 |

#### 错误码定义

| 错误码 | 语义名 | HTTP | 业务含义 | 触发条件 |
|:------:|:------:|:----:|---------|:--------:|
| 1006 | INTERNAL_ERROR | 500 | 批次处理失败（仅日志/告警） | BR-10 |

#### 依赖的 DataService

```csharp
ILearningKnowledgeMasteryDataService // mastery 指标（跨模块，学习域）

```

#### 编排逻辑

| 步骤 | 容忍度 | 操作描述 | 涉及 DataService | 对应规则 |
|:----:|:------:|---------|:----------------:|:--------:|
| 1 | Required | 扫描范围列表（群组/年级） | — | BR-09 |
| 2 | Optional | 逐范围聚合指标（战力/战绩） | `ILearning*DataService`/`IPkPlayerStatsViewService` | BR-11/BR-12 |
| 3 | Required | upsert 快照（当日冻结，幂等） | `IRankSnapshotsDataService` | BR-10/BR-13 |

> **调度方式**：Hangfire 每日 0:00(UTC+8)，不生成 Controller、不进服务契约一览表（模式列标注 `C`）。

# 三、横切关注点标注

| 关注点 | 实现方式 | 本域 UC 标注 |
|--------|---------|-------------|
| 认证鉴权 | `[AuthorityFilter]` + 角色枚举 | 全部 UC 权限要求 student；UC-7.3 Job 不标注 |
| 事务管理 | `[Transactional]` AOP | UC-8.2 CROSS（双方 ≤5 FOR UPDATE）；UC-7.3 CROSS；其余 SINGLE |
| 数据权限（RLS） | DataService 注入当前用户 | 排名按 Scope 成员可见；搭子仅 accepted 互看 |
| 幂等性 | 业务级幂等 | 快照 upsert（BR-13）；搭子关系唯一约束 |
| 限流 | Redis 计数 | 搭子单日邀请 ≤10（BR-15） |
| 缓存 | `[ContentCacheFilter]` | 排行榜读多写少（冻结快照），标注缓存 TTL |
