# 模块 7：排行榜

## 模块描述

基于努力度（坚持天数/★数/完成度/PK 胜场）而非分数的排名激励体系。排行榜数据由 **RankSnapshots 每日冻结快照**（Hangfire 每日 0:00 UTC+8）提供，趋势箭头 = 今日 vs 昨日快照对比。支持群组/年级范围 + 学科筛选 + 战力/战绩双榜单；战绩榜受群组全局开关控制。

---

### 7.1 榜单查询（战力榜/战绩榜）

#### 功能描述

学生查看群组/年级范围内的排行榜：战力榜（坚持天数+背诵量+PK 胜场）或战绩榜（正确率+掌握度，受群组开关控制）。

#### 操作描述

1. 学生进入排行榜页，选择范围（群组/年级互斥按钮）+ 学科筛选（下拉）+ 榜单类型（战力/战绩）
2. 系统返回排名列表（序号+前三特殊样式+头像昵称+数值+趋势箭头）
3. 趋势箭头：上升↑绿 / 下降↓红 / 持平→灰（今日 vs 昨日冻结快照）

#### 约束条件

- 排名数据源：RankSnapshots 冻结快照（不实时计算，不回溯漂移）
- 战力榜 = 坚持天数 + 背诵量 + PK 胜场（努力度维度，**不含正确率**）
- 战绩榜 = 正确率 + 掌握度——**受 Groups.RankEnabled 控制**（默认 true；关闭后该群组战绩榜入口隐藏、榜单不展示，战力榜不受影响）
- 范围选择群组/年级互斥；学科筛选支持全部/9 学科
- 合规红线：不出现群组正确率排名对外暴露（战绩榜经群组开关授权后仅限组内）

---

### 7.2 我的排名 + 趋势

#### 功能描述

学生查看自己在当前范围/学科/榜单下的当前排名、数值与趋势（含排名变化量）。

#### 操作描述

1. 学生查看"我的排名"区域
2. 系统返回当前排名 + 战力/战绩值 + 趋势箭头 + 排名变化（今日 rank − 昨日 rank）

#### 约束条件

- rankChange = 今日 rank − 昨日 rank（正=上升，由两份冻结快照对比，不回溯）
- 仅展示个人排名与数值，不暴露他人答题明细

---

### 7.3 排名快照每日冻结（后台）

#### 功能描述

系统每日 0:00（UTC+8）批量计算排名快照并冻结，作为排行榜与趋势的数据源。

#### 操作描述

1. 系统扫描各范围（群组/年级）× 学科 × 指标
2. 聚合指标值（streak/volume/pk_wins/accuracy/mastery）→ 排序 → 冻结 Rank + MetricValue
3. 写入 RankSnapshots（SnapshotDate=当日）→ 供排行榜/搭子互看读取

#### 约束条件

- **不实时写 Rank**（避免回溯漂移）；Hangfire 每日 0:00 UTC+8 批量冻结
- 趋势箭头 = 今日快照 vs 昨日快照对比
- 战力榜 = streak + volume + pk_wins；战绩榜 = accuracy + mastery

## 模块 8：学习搭子

## 模块描述

双向同意的同伴激励社交：A 发起邀请（海报二维码/链接）→ B 确认 → 成为搭子（accepted）；搭子互看排名、可发起 PK（跨模块，切片 07）。未成年人保护：邀请限定同群组/同年级，单日邀请 ≤10 次。

---

### 8.1 发起搭子邀请

#### 功能描述

学生向同群组/同年级的其他学生发起搭子邀请，生成海报二维码/链接供对方确认。

#### 操作描述

1. 学生在搭子区域点"+"按钮 → 邀请弹窗
2. 选择目标学生（仅同群组/同年级可选）→ 发起邀请
3. 系统创建邀请（pending，ExpiresAt=+7 天）→ 生成海报（二维码）/链接供分享

#### 约束条件

- **未成年人保护**：邀请对象限定同群组/同年级用户（应用层校验 GroupMembers 交集；**决策：同群组或同年级 OR 语义**——D02 未明确，见缺口决策）
- 单日发出邀请 ≤10 次（Redis 计数器 `buddy_invite_quota:{UserId}:{date}`，**决策：TTL 24h**）
- accepted 状态每用户 ≤5 个搭子（超出需先解除旧搭子）
- 不可重复邀请同一用户（存在 pending/accept 关系时拦截）

---

### 8.2 同意 / 拒绝邀请

#### 功能描述

被邀请方收到确认页"XX 邀请你成为学习搭子"，可同意（关系生效）或拒绝。

#### 操作描述

1. 被邀请方收到邀请（海报/链接进入确认页）
2. 点"同意" → 关系生效（accepted，校验 ≤5 双向）；点"拒绝" → 关系关闭（rejected）
3. 忽略 → 7 天未响应自动过期（expired，Hangfire 清理）

#### 约束条件

- 同意时事务内校验双方 accepted 数量 ≤5（FOR UPDATE 防并发超限）
- 邀请过期/已处理后二次操作 → 6002
- 拒绝后可重新邀请

---

### 8.3 搭子列表与排名互看

#### 功能描述

展示已添加搭子（4-5 个一行），搭子之间互看对方在群组/年级范围的当前排名 + 趋势箭头。

#### 操作描述

1. 学生查看搭子区域（排行榜页内嵌）
2. 系统返回搭子列表（头像昵称/连续打卡天数）+ 各搭子最新排名快照（rank/trend）
3. 仅互为 accepted 搭子可见对方排名（最小化暴露）

#### 约束条件

- **排名互看特权**：仅 accepted 搭子可见对方排名与数值（不暴露答题明细）
- 搭子列表返回对方最新 RankSnapshots 快照（排名/数值/趋势）
- 可查看搭子连续打卡天数
- 无搭子空态："还没有学习搭子，快邀请好友一起学习吧！"

---

### 8.4 解除搭子

#### 功能描述

任一方可解除搭子关系；解除后历史 PK/答题数据保留，不影响学习数据。

#### 操作描述

1. 学生选择搭子 → 解除（前端二次确认）
2. 系统将关系置为 removed

#### 约束条件

- 任一方可解除；解除后 PK/答题历史保留
- 解除后不可再互看排名/发起 PK（需重新邀请）
