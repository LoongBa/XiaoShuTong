## 一、独立深度分析（基于草稿全文）

### 1.1 战略/定位层

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| S1 | **产品形态矛盾** | 高 | 标题"背书小程序" vs 技术方案"微信 H5 + PWA"——形态未最终确定，影响全部技术选型 |
| S2 | **付费者与使用者分离** | 高 | 学生使用、家长/老师决策。商业模式（谁付费、付什么）未定义 |
| S3 | **"私域"概念混淆** | 中 | 内容私域（题库保护）与传播私域（微信群裂变）是两个不同概念，混为一谈导致运营与技术策略不清 |
| S4 | **竞品分析缺失** | 高 | 墨墨背单词（算法背词）、Anki（卡片复习）、Quizlet（学习集）、多邻国（路线图+激励）均为直接竞品，未对比，差异化主张未受检验 |

### 1.2 需求层

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| R1 | **四阶记忆状态迁移规则缺失** | 极高 | 产品核心算法。✕△○★ 如何迁移未定义："多次"是几次？○ 答错后降级到 △ 还是 ✕？★ 会不会降级？复习间隔（12h/1d/3d/7d→30d）参数依据？无规则则无法开发 |
| R2 | **AI 判题边界与容错标准未定义** | 极高 | 语义容错到什么程度算正确？置信度阈值？判错如何纠正？判错污染记忆状态如何处理？无边界则算法不可验收 |
| R3 | **求助引导线索生成机制缺失** | 高 | 题库仅"问/答"结构、答案一句话时，AI 如何生成"首字/意象/逻辑"线索？预置字段还是大模型实时生成？成本与延迟考量 |
| R4 | **上传文件格式未定义** | 高 | 阶段1核心功能"结构化文本上传"的具体格式（Markdown/CSV/JSON/分隔符）与模板缺失，无法开发 |
| R5 | **单元章节层级不清** | 中 | 路线图示例"唐朝→贞观之治→科举制度"是 3 级，章节管理说"单元章节"是 2 级——层级未定 |
| R6 | **"多模态"名不副实** | 中 | 实际仅文字输入 + TTS 朗读（输出），无 ASR 输入。手机语音输入法 ≠ 应用内语音识别，表述需澄清 |
| R7 | **离线报告闭环缺失** | 中 | 导出"Todo + Checklist"格式（PDF/图片）未定；离线如何打卡记录、回连后如何同步、冲突如何处理 |
| R8 | **群组隐私边界** | 高 | 群主可查看组员"记忆状态"——学生隐私数据授权边界、最小化原则、家长/老师权限层级未定义 |
| R9 | **群组规模假设缺失** | 中 | SignalR 实时群动态的并发假设（100/500人？）未定义，影响架构容量 |

### 1.3 技术层

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| T1 | **Blazor 技术栈概念混淆** | 极高 | "前端 Blazor WASM + 后端 Blazor Server"错误——Blazor Server 是服务端渲染模型而非后端框架。正确组合应为：Blazor WASM + Web API，或纯 Blazor Server + Web API |
| T2 | **微信 X5 内核 + WASM 兼容性存疑** | 高 | Blazor WASM 首屏需下载 .NET runtime（~2MB+），微信内置浏览器（X5）支持不佳，弱网场景更差。草稿声称"适配弱网"但无方案（预渲染/流式/降级） |
| T3 | **DRM 在 H5 形态基本不可行** | 极高 | 网页内容可查看源码、复制、抓包，传统 DRM（加密+播放器）在 Web 端无有效实现。题库市集版权保护需重新设计（账号绑定/水印/服务端分段渲染/法律条款） |
| T4 | **AI 成本模型缺失** | 高 | 无"单位成本 = 每题 token 成本 × 答题次数 × 用户量"模型，"100-300元/月"缺乏依据，影响商业模式可行性 |
| T5 | **数据库 ER 设计缺失** | 中 | 记忆状态、复习序列、热力图、群组等核心数据模型完全未设计 |
| T6 | **迁移触发无评估机制** | 中 | H5→小程序/原生 App 的触发条件合理，但无数据迁移方案、成本评估、时间点检查机制 |

### 1.4 合规/安全层

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| C1 | **未成年人数据合规缺失** | 极高 | 目标用户含学生（不满14周岁需监护人同意，个保法第28-31条）。微信授权 openid 属个人信息，无未成年人数据处理方案 |
| C2 | **真题版权风险** | 高 | "考试真题题库"付费分享——真题版权归属、侵权风险未评估 |
| C3 | **AI 幻觉责任** | 高 | AI 导师产生错误历史知识将误导学生，教育内容准确性责任与审核机制未讨论 |

### 1.5 运营/验收层

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
