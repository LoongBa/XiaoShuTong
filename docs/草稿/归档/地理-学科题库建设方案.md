## 一、设计定位与核心差异

地理背诵与语文/英语的**骨架一致、灵魂不同**：

| 维度 | 英语 | 地理 | 设计影响 |
|------|------|------|---------|
| 记忆维度 | 音 + 形 + 义 | **位置 + 名称 + 特征**（空间定位为第一锚点） | 记忆依赖"图上定位"，配 image_url 辅助 |
| 记忆粒度 | 单词→短语→句型→语篇 | **知识点 → 区块 → 区域** 三级递进 | 以"区域"为记忆单元，跨知识点聚合 |
| 判题容错 | 拼写宽容 | **精确（exact）**：地名/术语必须准确 | 双简称/别名通过 keywords.aliases 显式声明（"川"="蜀"） |
| 遗忘曲线 | 单词遗忘陡峭 | 名称性知识遗忘中等，但**近似混淆严重**（两湖/两广/两河/两山） | 易混淆点优先 O4 连线对比强化 |
| 知识卡片 | word_card | **region_card**（位置/地形/气候/资源/人文/趣闻） | 卡片模板完全不同，按区域组织 |
| 核心题型 | S1-S5 记忆型为主 | **O4 连线为核心**（中考高频、规则即判零成本） | 客观题比重高于语文/英语 |

**核心结论**：地理题库沿用四件套结构（篇目/知识点清单 → 原始题库 → 背诵训练 → 背景钩子）+ 统一 Schema，但在**内容分层、题型重心（O4 连线）、判题规则（exact + 别名表）、知识卡片（region_card）**四个层面做学科化改造。

## 三、题型设计：S1-S4 的地理映射 + O4 连线为核心（L2 训练层）

### 3.1 S1-S4 映射（分阶检索方向驱动）

| 现有题型 | 地理映射（刺激 → 反应） |
|---------|------------------------|
| **S1 正向检索** | 给区域 → 回忆特征（"青藏高原 → 高寒、日照强"）；给省份 → 回忆省会/简称 |
| **S2 逆向检索** | 给特征 → 推区域（"千沟万壑、支离破碎 → 黄土高原"）；给省会 → 反推省份（最强记忆） |
| **S3 默写区域要素** | 给区域名 → 默写要素清单（位置/地形/气候/河流） |
| **S4 综合复述** | 给区域卡片 → 全要素复述（输出完整性，衔接 region_card） |

### 3.2 复用 O 系列客观题（地理核心阵地）

| 题型 | 地理应用示例 | 优先级 |
|------|-------------|--------|
| **O4 连线** | **省区-简称-省会、地形区-特征、民族-节日、山脉-两侧地形、国家-气候类型、河流-注入海洋、区域-物产** | **核心**，按中考出现频率排序（省区-简称-省会 > 地形区-特征 > 山脉-两侧地形 > 河流-注入海洋 > 国家-气候类型 > 区域-物产 > 民族-节日） |
| **O5 填空** | 省会/简称填空：`____省的简称是"川"。### 四川` | 高 |
| **O1 单选** | 区域特征四选一（如"我国最大的咸水湖是？"） | 中 |
| **O3 判断** | "黄河是我国第一长河（错，应为第二长河）" | 中 |

### 3.3 复用 R 系列与 X1

| 题型 | 地理应用示例 |
|------|-------------|
| **R1 补全记忆** | 给区域/省份 → 补特征/省会（正向） |
| **R2 逆向补全** | 给特征/省会 → 反推区域/省份（逆向） |
| **X1 简答** | 综合描述区域特征（"简述东北平原的自然环境特征"），LLM 按要点判题 |

### 3.4 题型标记（文件内注释）

```
# S1 区域特征：区域名###特征
# S2 特征推区域：特征###区域名
# S3 区域要素默写：默写《区域》要素###位置/地形/气候/河流
# S4 综合复述：复述《区域》###全要素
# R1 补全记忆：区域/省份###特征/省会
# R2 逆向补全：省会/特征###省份/区域
# O4 连线：左列###右列（一一对应）
# O5 填空：题干___###答案
# X1 简答：简述...###要点
```

## 四、判题引擎适配（L3 层）

D01 已为地理规定 `exact`（精确）：术语/地名/符号必须准确。落地细则：

| 容错维度 | 策略 | 示例 |
|---------|------|------|
| **全称/简称** | 基准 exact，双简称在 keywords.aliases 显式声明 | "川"="蜀"、"冀"="河北" 均判 correct |
| **常见别名** | 别名归一化进 aliases | "亚马逊"="亚马孙"（大陆译名差异放行） |
| **大小写/空格** | 放行 | 英文专名、空格差异 |
| **数字与术语** | 必须准确，不宽容 | 阶梯分界线山脉名、气候类型名不可错 |
| **易错省会专项** | 高错题目单独标记，O5/X1 优先覆盖并加强 hint | **广西-南宁（非桂林）、福建-福州（非厦门）、青海-西宁（非兰州）** |

**易混淆点专项（优先 O4 连线强化对比）**：
- **两湖/两广/两河/两山**：湖南-湖北、广东-广西、河南-河北、山东-山西（全称-简称-省会三重混淆）
- **四大高原对比**：青藏-高寒、内蒙古-平坦开阔、黄土-千沟万壑、云贵-喀斯特崎岖
- **季风气候三型**：温带/亚热带/热带季风气候的分布与特征对比
- **世界之最**：尼罗河 vs 亚马孙河（最长 vs 流量最大）对比

> **实现机制**：exact 作为判题链默认容错度，但 keywords 支持 `aliases` 数组（组内任一命中即该组命中，D01 §7.3），双简称/别名在此归一化后进入关键词比对——既保证"精确"基准，又避免合理等价表述误判。

## 五、记忆状态机与调度（✕△○★）

四阶状态机完全复用，地理特有以下迁移与降级规则：

```
✕ 未掌握：浏览/跟读 region_card（输入阶段，建立位置-名称-特征联结）
△ 模糊：S1 区域特征 / R1 补全（正向检索）
○ 掌握：S2 特征推区域 / O5 填空（逆向检索 + 精确输出）
★ 熟练：S4 综合复述 / X1 简答（完整性 + 综合运用）

降级规则（地理特有）：
- 简称/省会答错 → △→✕（exact 精确硬约束）
- 特征张冠李戴（高原/气候混淆）→ ○→△
- 区域要素缺漏 → ★→○
```

**艾宾浩斯调度（地理特调）**：

| 内容层 | 首次间隔 | 递进 | 批量策略 |
|--------|---------|------|---------|
| G1 行政区划 | 30min → 4h | 1d → 3d → 7d | 高频小批量（每日 5-10 组连线） |
| G2-G4 中国自然地理 | 12h → 1d | 3d → 7d → 15d | 中批量（按区域分组） |
| G6-G8 世界/人文地理 | 1d → 3d | 7d → 14d → 30d | 低频大批量 |

## 六、知识卡片：`region_card`（L1 层）

D01 预留 `region_card`（位置/地形/气候/物产/人文/趣闻），调研建议扩展为 8 字段：

```
字段：name / location / terrain / climate / resources / culture / trivia / keywords
```

**S1-S4 渐进隐藏设计**：

| 阶段 | 显示 | 隐藏 |
|------|------|------|
| ✕ / S1 | name | location/terrain/climate/... 全隐藏（输入阶段先建立联结） |
| △ / S2 | 特征字段（terrain/climate 等） | name（给特征推区域） |
| ○ / S3 | name + keywords 提示 | 要素明细（默写要素） |
| ★ / S4 | name | 全要素复述（完整性检验） |

**示例：青藏高原 region_card**

```markdown
## 青藏高原
- **name（名称）**：青藏高原
- **location（位置）**：我国西南部，昆仑山以南、喜马拉雅山以北、祁连山与横断山脉之间；世界海拔最高的大高原
- **terrain（地形）**：平均海拔 4000 米以上，有"世界屋脊"之称；雪山连绵、冰川广布
- **climate（气候）**：高原山地气候，高寒、气温低、日照强、昼夜温差大
- **resources（资源）**：太阳能、地热能丰富；雅鲁藏布江谷地水能丰富；柴达木盆地"聚宝盆"矿产富集
- **culture（人文）**：藏族为主；青稞、牦牛、酥油茶；拉萨"日光城"
- **trivia（趣闻）**："世界屋脊"；珠穆朗玛峰位于本区；"一山有四季，十里不同天"
- **keywords（关键词）**：高寒、世界屋脊、日照强、冰川广布、藏族、青稞、牦牛
```

**设计原则**：
- 记忆钩子优先（趣闻 + 对比），讲故事不考核
- 易混淆区域出**对比卡**（四大高原对比、季风气候三型对比）
- 卡片全局唯一，跨册复用（青藏高原在八上与七下均出现时引用同一卡片 ID）
- 建议配图（image_url：地图/景观），空间定位依赖图上记忆
