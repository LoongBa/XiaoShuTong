## 一、设计定位与核心差异

英语背诵与语文的**骨架一致、灵魂不同**：

| 维度 | 语文 | 英语 | 设计影响 |
|------|------|------|---------|
| 记忆维度 | 形（汉字）+ 义 | **音 + 形 + 义** 三要素 | 新增"发音"维度，需 S5 跟读题型 |
| 记忆粒度 | 诗句/段落（较大） | **单词→短语→句型→语篇** 递进金字塔 | 四级内容分层，粒度更细 |
| 判题容错 | 语义宽容（semantic_tolerant） | **拼写宽容（spelling_tolerant）** | 拼写是硬约束，hint 引导方式不同 |
| 遗忘曲线 | 诗文较缓 | **单词遗忘陡峭** | 艾宾浩斯间隔缩短、单词高频小批量 |
| 知识卡片 | author_card（作者/背景） | **word_card（词源/词根/搭配/助记）** | 卡片模板完全不同 |

**核心结论**：英语题库沿用语文的四件套结构（篇目清单 → 原始题库 → 背诵训练 → 背景钩子）+ 统一 Schema，但在**内容分层、题型变体、判题规则、知识卡片**四个层面做学科化改造。

## 二、内容分层：四级金字塔（L0 资源层）

| 层级 | 内容 | 典型来源 | 记忆难点 | 学段权重 |
|------|------|---------|---------|---------|
| **T1 单词** | 核心词、高频词 | PEP 教材词汇表、课标 800 词 | 音-形-义三要素割裂 | 低年级主，贯穿全程 |
| **T2 短语** | 动词短语、介词短语、固定搭配 | 课本 Let's learn、词组表 | 搭配固定性（look *after*, depend *on*） | 中年级主 |
| **T3 句型** | 交际用语、功能句型、重点句式 | Let's talk、Grammar focus | 语序、时态、语用场景 | 中高年级主 |
| **T4 语篇** | 课文段落、对话、韵文/歌曲 | Let's read、Story time | 整体流畅度、逻辑连贯 | 高年级主，低年级韵文 |

> **权重策略**：小学低年级（3-4 年级）重 T1 单词 + T4 韵文/歌曲；小学高年级（5-6 年级）重 T2 短语 + T3 句型；初中重 T3 句型 + T4 语篇（可衔接人教版 Go for it）。

## 三、题型设计：S1-S4 的英语映射 + 新增 S5（L2 训练层）

现有 S1-S4 是"检索方向"驱动，天然适配英语，只需做**刺激-反应**内容的学科化映射：

| 现有题型 | 语文示例 | 英语映射（刺激 → 反应） |
|---------|---------|------------------------|
| **S1 正向检索** | 床前明月光 → 疑是地上霜 | 看**中**文 → 说/写**英**文（义→形）<br>看**英**文前半句 → 补全后半句（句型接龙） |
| **S2 逆向检索** | 疑是地上霜 → 床前明月光 | 听**英**音 → 写**英**文拼写（音→形，最强记忆）<br>看**英**文 → 说/写**中**文（形→义） |
| **S3 段落默写** | 默写某自然段 | 看中文提示 → 默写英文段落（重点考语序+时态） |
| **S4 整篇默写** | 默写全文 | 看图/关键词 → 复述/默写全文（输出完整性） |
| **S5 跟读发音（新增）** | — | 听标准音 → 跟读 → AI 判发音准确性（音标比对 + ASR） |

### 3.1 复用 O 系列客观题

| 题型 | 英语应用示例 |
|------|-------------|
| **O1 单选** | 选出正确时态/介词/单词拼写 |
| **O2 多选** | 选出所有正确搭配（如与 "make" 搭配的短语） |
| **O4 连线** | 单词 ↔ 图片/音标/中文释义；短语 ↔ 中文意思（小学神器） |
| **O5 填空** | `I ___ (go) to school yesterday.`（时态变形） |

### 3.2 题型标记（文件内注释）

```
# S1 看中写英：中文###英文
# S1 句型接龙：前半句###后半句
# S2 听音写词：音标/音频标记###英文拼写
# S2 看英写中：英文###中文
# S3 段落默写：中文提示###英文段落
# S4 整篇默写：默写《篇名》###全文
# S5 跟读发音：跟读单词/句子###音标（判发音用）
```

## 四、判题引擎适配（L3 层）

D01 已为英语预留 `spelling_tolerant`（拼写宽容），落地细则：

| 容错维度 | 策略 | 示例 |
|---------|------|------|
| **大小写** | 放行 | `monday` = `Monday` |
| **时态/单复数** | 判 partial 并提示 | 写 `go` 应 `went` → partial，hint 指向时态 |
| **拼写错误** | 1-2 字母错 → partial；AI 提示正确拼写但**不直接给答案** | `recieve` → 提示"i before e" |
| **发音** | ASR 判读 + 音标比对 | /ˈnɒlɪdʒ/ 读成 /ˈnɒlɪdʒi/ → partial |
| **同义表达** | 语义等价放行 | "look after" = "take care of"（口语场景放行） |

**与语文判题的核心差异**：
- 语文语义宽容（同义放行），英语**拼写是硬约束**（写错字母就是错）
- 英语 hint 引导方式更丰富：词根、词缀、自然拼读规则（如 "ea" 发 /iː/）
- S5 发音判题依赖 ASR 能力，成本高于纯文本判题 → **建议 V1.1 再做**

## 五、记忆状态机与调度（✕△○★）

四阶状态机完全复用，但英语的**降级触发条件**增加"音"维度：

```
✕ 未掌握：跟读 + 听音（输入阶段，建立音-形联结）
△ 模糊：S1 看中写英 / S2 听音写词（正向/逆向检索）
○ 掌握：S2 反向 + S3 短语/句型默写
★ 熟练：S4 语篇输出 + 发音流利度判定

降级规则（英语特有）：
- 拼写错 1 字母 → △→✕（比语文严）
- 发音错 1 音素 → ○→△（新增维度）
- 时态/搭配错误 → ★→○（语用不熟）
```

**艾宾浩斯调度（英语特调）**：

| 内容层 | 首次间隔 | 递进 | 批量策略 |
|--------|---------|------|---------|
| T1 单词 | 30min → 4h | 1d → 3d → 7d | 高频小批量（每日 15-20 新词） |
| T2 短语 | 30min → 12h | 1d → 3d → 7d → 15d | 中批量（每日 5-8 组） |
| T3 句型 | 12h → 1d | 3d → 7d → 15d | 场景分组 |
| T4 语篇 | 1d → 3d | 7d → 14d → 30d | 低频大批量（每周 1-2 篇） |

## 六、背景钩子：`word_card` 知识卡片（L1 层）

语文用 `author_card`（作者/背景/钩子），英语换成 D01 预留的 `word_card`：

```markdown
## apple /ˈæpl/ n. 苹果
- **音**：/æ/ 短音，口型要大（对比 cat/bag 同音素）
- **形**：ap-ple 双音节；同根词 pineapple
- **义**：苹果；联想"亚当夏娃的苹果""牛顿的苹果"
- **用**：an apple a day keeps the doctor away（谚语记忆）
- **搭配**：apple pie / apple juice / the Big Apple（纽约）
- **助记**：A 像苹果蒂，双 p 像两片叶子
```

**设计原则**：
- 小学低年级：谐音联想 + 图片联想 + 歌曲韵文
- 小学高年级：自然拼读规则 + 简单词根
- 初中：词根词缀（`un-`、`-tion`、`re-`）+ 文化梗 + 谚语

> **版本映射表**：README 必须维护逐年级逐册版本映射（哪些年级用 2024 修订版、哪些过渡期仍用 2012 旧版、何时切换），学生端按映射路由。

**题库元数据（bank.json）**：

```json
{
  "bank_id": "english-p3to6-pep-2024r",
  "name": "小学3-6年级-PEP教材",
  "version": "V0.1",
  "source": "人教PEP版小学英语",
  "purpose_tags": ["memorize", "assess", "play"],
  "default_prompt": "通用判题",
  "type_overrides": { "R3": "学科-english-R3-spelling" },
  "privacy": "private",
  "owner": "system"

```

**题目 Schema 要点**（`question.v1.json` 兼容）：
- `id`: `Q-en-p3a-0001`（英语 = en）
- `content.question`: 刺激（中文/英文/音标）
- `content.answer`: 反应（英文/中文/拼写）
- `content.keywords`: 判题关键词（英文原文）
- `content.audio_url`: S2 听音写词 / S5 跟读的标准音 URL
