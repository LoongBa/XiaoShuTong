## 一、设计定位与核心差异

生物背诵与语文的**骨架一致、灵魂不同**：

| 维度 | 语文 | 生物 | 设计影响 |
|------|------|------|---------|
| 记忆维度 | 形（汉字）+ 义 | **概念 + 结构-功能 + 过程/流程** 三种节点 | 题型需覆盖"名词 / 功能 / 过程"三类刺激 |
| 记忆粒度 | 诗句/段落（较大） | **术语 → 定义 → 结构与功能 → 过程/流程 → 对比体系** 网络化 | 五级内容分层，强调横向对比（易混点） |
| 判题容错 | 语义宽容（semantic_tolerant） | **精确（exact）** | 专业术语是硬约束（肾小球≠肾小囊），辅以同义词白名单 |
| 遗忘曲线 | 诗文较缓 | **概念中等、流程/对比易串** | 艾宾浩斯间隔中等，易混对比组高频重复 |
| 知识卡片 | author_card（作者/背景） | **concept_card（定义/功能/位置/易混点/口诀）** | 卡片模板完全不同，字段按知识点类型裁剪 |

**核心结论**：生物题库沿用语文的四件套结构（篇目清单 → 原始题库 → 背诵训练 → 背景钩子）+ 统一 Schema，但在**内容分层、题型变体、判题规则、知识卡片**四个层面做学科化改造。生物最强势的记忆武器是**结构-功能连线**与**易混点横向对比**，题型与卡片都要为之服务。

## 二、内容分层：6 大模块 × 22 子类（L0 资源层）

生物记忆性知识点调研结论：**6 大模块 × 22 子类，初中合计约 500 个核心知识点，可支撑 1500-2000 题**。

| 模块 | 子类 | 所在册（现行教材） | 核心知识点（约） | 占比 |
|------|------|------------------|----------------|------|
| **A 细胞与生物体结构层次** | 3：显微镜使用与临时装片 / 细胞结构与功能 / 组织、器官、系统与生物体结构层次 | 7 上 | 60 | 12% |
| **B 生物分类与多样性** | 4：生物分类单位 / 主要植物类群 / 主要动物类群 / 微生物与生物多样性保护 | 7 上 | 70 | 14% |
| **C 植物的生活** | 4：种子萌发 / 植株生长 / 开花与结果 / 光合、呼吸与蒸腾作用 | 7 下 | 80 | 16% |
| **D 人体生理与健康** | 6：营养与消化吸收 / 呼吸与气体交换 / 血液循环与物质运输 / 泌尿与废物排出 / 神经与激素调节 / 免疫、传染病与健康生活 | 7 下 + 8 上 | **120（最密集）** | **24%** |
| **E 生物与环境** | 3：生物与环境的关系 / 生态系统的组成与能量流动 / 生态平衡与人类活动的影响 | 8 上 | 80 | 16% |
| **F 生命的延续与发展** | 2：生物的生殖与发育 / 遗传、变异与进化 | 8 下 | 90 | 18% |

> **权重策略**：模块 D 人体生理（7 下 + 8 上）知识点最密集（约 120 点、占 24%），是**首期主攻、高频调度**的重心；模块 C 植物的生活含全程式内容（光合/呼吸）需要流程题支撑；模块 F 遗传概念抽象、与数学比值结合，需配对比卡片。

## 三、题型设计：S1-S4 的生物映射（L2 训练层）

现有 S1-S4 是"检索方向"驱动，天然适配生物，只需做**刺激-反应**内容的学科化映射：

| 现有题型 | 语文示例 | 生物映射（刺激 → 反应） |
|---------|---------|------------------------|
| **S1 正向检索** | 床前明月光 → 疑是地上霜 | 给**术语** → 回忆**定义**（线粒体 → 是细胞中分解有机物、释放能量的场所）<br>给**结构** → 回忆**功能** |
| **S2 逆向检索** | 疑是地上霜 → 床前明月光 | 给**功能** → 推**结构**（细胞中分解有机物释放能量的场所 → 线粒体）<br>给**特征** → 找**类群**（有花有果、种子有果皮包被 → 被子植物） |
| **S3 段落默写** | 默写某自然段 | 默写**完整定义** / **流程**（如光合作用反应式，含条件与场所）<br>默写**对比表**（排泄 vs 排遗 差异） |
| **S4 整篇默写** | 默写全文 | **综合复述概念卡片**：基于 keyword 提示串联 term/definition/function/related 输出完整卡片内容 |

### 3.1 O 系列客观题：**O4 连线是生物核心题型**

| 题型 | 生物应用示例 |
|------|-------------|
| **O1 单选** | 选出正确概念判断题（下列对"动脉血"的描述正确的是？） |
| **O2 多选** | 选出所有属于排泄的途径（呼气/排汗/排尿 → 各选其是） |
| **O3 判断** | 静脉里流的不一定是静脉血（肺静脉流动脉血） |
| **O4 连线（核心）** | **结构-功能匹配**，四大典型对：<br>线粒体 ↔ 呼吸作用<br>叶绿体 ↔ 光合作用<br>心脏四腔 ↔ 相连血管（左心房-肺静脉、右心室-肺动脉…）<br>消化腺 ↔ 消化液（唾液腺-唾液、肝脏-胆汁…）<br>内分泌腺 ↔ 激素（胰岛-胰岛素、垂体-生长激素…） |
| **O5 填空（术语精确）** | 尿液是在 ___ 中形成的（肾小球？肾小囊？→ 正确为肾小囊中形成原尿／肾单位）<br>**【易错】** 线粒体≠粒线体、肾小球≠肾小囊，错字即错 |

### 3.2 题型标记（文件内注释）

```
# S1 术语定义：线粒体###是细胞中分解有机物、释放能量的主要场所
# S2 功能寻结构：细胞中分解有机物、释放能量的主要场所###线粒体
# S2 特征寻类群：种子有果皮包被的绿色植物###被子植物
# R1 流程补全：光合作用：CO₂ + H₂O ?→ ? (光能/叶绿体)→###有机物 + O₂
# R3 定义默写：默写"排泄"的完整定义###...
# R3 对比表默写：默写"动脉血与静脉血"对比表###...
# X1 简答：探究"唾液对淀粉的消化"实验的结论###...
# O4 连线：线粒体###呼吸作用
# O5 填空：尿液在 （） 中形成###肾单位（肾小囊）
```

> **R1 补全示例（流程/公式补全）**：`CO₂ + H₂O →(光能/叶绿体)→ 有机物 + O₂`，判题校验反应物、产物、条件、场所四要素。
> **R2 逆向示例**：给功能找结构、给特征找类群（见上表）。

## 四、判题引擎适配（L3 层）

D01 §5.2 已定生物为 **`exact`（精确）**：术语/年代/符号必须准确，是硬约束。

### 4.1 容错策略

| 容错维度 | 策略 | 示例 |
|---------|------|------|
| **同义词（白名单）** | 白名单内等价放行 | 红细胞 = 红血球、白细胞 = 白血球、无性生殖 = 无性繁殖（白名单须经教材复核） |
| **专业术语错字** | **硬错（wrong）** | 线粒体 ≠ 粒线体、肾小球 ≠ 肾小囊、胚轴 ≠ 胚根 |
| **标点 / 时空格** | 放行 | 序号、顿号、换行差异忽略 |
| **单位 / 符号** | 精确 | 克/毫克、CO₂ 下标写法容错但数值不可错 |
| **定义完整性** | 关键词命中判定（≥85% correct、60-85% partial） | "排泄是排出体内代谢废物的过程"缺"代谢废物"→ partial |

### 4.2 同义词容错表（建议独立维护并随教材复核）

```json
{
  "红细胞": ["红血球"],
  "白细胞": ["白血球"],
  "繁殖": ["生殖"],
  "……（待调研补充）": []
}
```

> 原则：**专业形态学名词不可错字**（同义白名单可放行，错白字不放行）；凡白名单外出现一个概念对应多个表述的，一律走 `exact` 判错并在 `keywords.aliases` 中显式登记。

### 4.3 15 组易混淆点专项（建议独立专项库，tag 标记 `kc:易混`）

| # | 易混组 | 区分要点 / 口诀 |
|---|--------|----------------|
| 1 | 动脉血 vs 静脉血 | 含氧量定血型，不看血管名；**"肺反体同"**（肺动脉流静脉血，肺静脉流动脉血） |
| 2 | 光合作用 vs 呼吸作用 | 场所（叶绿体/线粒体）、条件（光/活细胞）、原料产物互为逆过程 |
| 3 | 排泄 vs 排遗 | 排泄=排代谢废物（尿/汗/呼气）；排遗=排未消化食物残渣 |
| 4 | 原尿 vs 尿液 | **"原尿有糖尿液无糖"**（肾小管重吸收全部葡萄糖） |
| 5 | 简单反射 vs 复杂反射 | 生来就有 vs 后天学习；脊髓 vs 大脑皮层参与 |
| 6 | 完全变态 vs 不完全变态 | **"有蛹完全"**（有蛹期=完全变态，如蝶、蜂、蚊） |
| 7 | 近视 vs 远视 | **"近凹远凸"**（近视凹透镜、远视凸透镜）；物像成于视网膜前/后 |
| 8 | 导管 vs 筛管 | 导管运输水/无机盐（自下而上）、筛管运输有机物（自上而下） |
| 9 | 胚芽 vs 胚根 | 胚芽→茎和叶，胚根→根 |
| 10 | 子房 vs 胚珠 | 受精后子房→果实、胚珠→种子 |
| 11 | 基因 / DNA / 染色体 | 基因是 DNA 上有遗传效应的片段；DNA+蛋白质→染色体 |
| 12 | 蒸腾作用 vs 蒸发 | 蒸腾是植物生理过程（气孔）、蒸发是物理现象 |
| 13 | 细胞分裂 vs 细胞分化 | 分裂=数目增多、分化=形态功能差异（种类增多） |
| 14 | 生长素（植物） vs 生长激素（动物） | 前者植物激素（促进生长）、后者垂体分泌的动物激素 |
| 15 | 种群 vs 群落 vs 生态系统 | 同一物种全部个体 / 全部生物 / 生物+环境 |

> **专项题量建议**：每组 ≥5 题（O3 判断 + O4 连线 + X1 简答），首次引入高三元判题（keywords.aliases + required）时会重点依赖本表。

## 五、记忆状态机与调度（✕△○★）

```

★ 熟练：S4 综合复述概念卡片 + 易混点横向辨析

- 专业术语错字 → ✕（×勾选比语义学科严）
```

## 六、知识卡片：`concept_card`（L1 层）

D01 已为生物预留 `concept_card`（定义/功能/分类/易混点/记忆口诀）。调研建议扩展为 **8 类字段**（mnemonic 与 formula 按知识点类型二选一启用，故计 8 槽）：

| 字段 | 说明 |
|------|------|
| term | 术语名（唯一标识） |
| definition | 标准定义（判题答案基准） |
| function | 功能/作用 |
| location | 位置/分布（细胞器所在、器官所在） |
| category | 所属模块/子类（A-F × n） |
| confusion | 易混点与辨析要点 |
| mnemonic | 记忆口诀（或）formula：公式/流程/反应式 |
| related | 关联知识点（跨卡互联） |

### 卡片示例：线粒体

```markdown
## term：线粒体　|　category：A-细胞结构与功能

- **definition**：细胞中分解有机物、释放能量的主要场所，为细胞生命活动提供能量（ATP）
- **function**：呼吸作用的主要场所，将有机物中的化学能释放出来供细胞利用
- **location**：动植物细胞质中；能量需求大的细胞含量多（如心肌细胞、鸟的胸肌细胞）
- **confusion**：与叶绿体混淆 → 线粒体=呼吸放能；叶绿体=光合储能（后者仅植物绿色细胞有）
- **mnemonic**：线粒体中呼吸忙，ATP多如糖
- **formula**：C₆H₁₂O₆ + 6O₂ →(线粒体)→ 6CO₂ + 6H₂O + 能量
- **related**：呼吸作用、ATP、叶绿体（对比）、细胞能量供应
```

### S1-S4 渐进隐藏策略

| 阶段 | 卡片展示 | 学生任务 |
|------|---------|---------|
| ✕ 跟读 | 全字段展示 | 通读建立印象 |
| △ S1 | 显 definition，隐藏其余 | 由 term 回忆/核对定义 |
| ○ S2/S3 | 显 function/location/category，隐藏 term/definition | 由功能反推结构；默写完整定义/公式 |
| ★ S4 | 全部隐藏，仅留 related 作提示 | 综合复述整卡（含口诀与易混辨析） |

> 提示生成走《背景钩子-提示生成-Prompt.md》，从卡片字段提取线索（功能/位置/口诀），**不从答案提取**。
