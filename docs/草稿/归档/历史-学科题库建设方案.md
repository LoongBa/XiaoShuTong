## 一、设计定位与核心差异

历史背诵与语文的**骨架一致、灵魂不同**：

| 维度 | 语文 | 历史 | 设计影响 |
|------|------|------|---------|
| 记忆对象 | 诗句/文言文（文本） | **事实性知识**（时间/事件/人物/制度） | 题型以要素补全、连线、简答为主，非文本默写 |
| 记忆粒度 | 诗句/段落（较大） | **事件要素**（起因-经过-结果-影响） | 以"事件卡"为记忆单元，粒度中 |
| 判题容错 | 语义宽容（semantic_tolerant） | **精确（exact）**：术语/年代/条约必须准确 | 但学科内给宽容：年代 ±1 年、人物别名、条款关键词匹配 |
| 遗忘曲线 | 诗文较缓 | **事实性知识遗忘快、易混淆** | 调度节奏紧凑、易混点专项（O4 连线） |
| 知识卡片 | author_card（作者/背景） | **event_card（时间/地点/人物/起因/经过/结果/影响）** | 卡片模板完全不同 |

**核心结论**：历史题库沿用语文的四件套结构（篇目清单 → 原始题库 → 背诵训练 → 背景钩子）+ 统一 Schema，但在**内容分层（按知识分类而非篇目）、题型变体（要素补全/连线/简答为主）、判题规则（exact + 学科内宽容）、知识卡片（event_card）**四个层面做学科化改造。

## 二、内容分层：六大知识分类（L0 资源层）

基于调研结论，历史记忆性知识点分 6 大分类：

| 分类 | 内容 | 典型示例 | 记忆难点 | 学段权重 |
|------|------|---------|---------|---------|
| **K1 时间/年代** | 事件发生年代、朝代起止 | 1840 年鸦片战争 | 相似年代易混（1911/1919/1921） | 贯穿全程，八年级最重 |
| **K2 历史事件** | 起因-经过-结果-影响 | 鸦片战争、戊戌变法 | 要素链条长、张冠李戴 | 八年级最重 |
| **K3 历史人物** | 人物-时代-主要事迹 | 林则徐虎门销烟 | 同名/同代人物混淆 | 贯穿全程 |
| **K4 朝代更替** | 朝代顺序、更替时间/标志 | 夏→商→周→秦→汉… | 顺序易混、正反写反 | 七年级最重 |
| **K5 制度/政策/条约** | 条约条款、变法措施 | 《南京条约》五口通商 | 三大条约条款易混 | 八年级最重 |
| **K6 意义/影响评价** | 历史意义、影响、评价 | 洋务运动的历史意义 | 表述要求规范（考试语言） | 八年级/九年级最重 |

**教材框架**：初中六册 129 课

| 册别 | 内容 | 记忆重点 |
|------|------|---------|
| 七上 | 中国古代史（上） | K4 朝代更替、K3 人物、K5 制度 |
| 七下 | 中国古代史（下） | K4 朝代更替、K5 制度 |
| 八上 | 中国近代史 | K1 年代、K2 事件、K5 条约 |
| 八下 | 中国现代史 | K2 事件、K6 意义评价 |
| 九上 | 世界古代 + 近代史 | K2 事件、K6 影响 |
| 九下 | 世界现代史 | K2 事件、K6 影响 |

**记忆点规模**：初中三年总计约 **1100-1330 个记忆点**，其中**八年级（中国近现代史）压力最大**，是首期建设重点。

> **权重策略**：七年级重 K4 朝代更替 + K3 人物；八年级重 K1 年代 + K2 事件 + K5 条约制度；九年级重 K2 事件 + K6 影响评价。

## 三、题型设计：S1-S4 的历史映射（L2 训练层）

现有 S1-S4 是"检索方向"驱动，天然适配历史，只需做**刺激-反应**内容的学科化映射：

| 现有题型 | 语文示例 | 历史映射（刺激 → 反应） |
|---------|---------|------------------------|
| **S1 正向检索** | 床前明月光 → 疑是地上霜 | 给事件要素 → 回忆**时间/人物**（事件→年代/人物） |
| **S2 逆向检索** | 疑是地上霜 → 床前明月光 | 给**影响/特征** → 逆向推事件（影响→事件） |
| **S3 段落默写** | 默写某自然段 | **默写条约内容/变法措施**（条款性知识） |
| **S4 整篇默写** | 默写全文 | **综合复述事件全要素**（起因-经过-结果-影响） |

### 3.1 题型映射（对齐 D01 题型注册表）

| 题型 | 历史应用示例 | 判题 |
|------|-------------|------|
| **R1 补全** | 补全事件要素：虎门销烟的领导人？###林则徐 | 关键词+LLM |
| **R2 逆向** | 给影响推事件：标志着中国近代史开端的事件？###鸦片战争 | 关键词+LLM |
| **R3 默写** | 默写《南京条约》的主要内容（五口通商/割香港岛/赔款/协定关税） | 关键词+LLM（R3a 条款段落 / R3b 整组条款） |
| **O4 连线** | 人物-事件、条约-内容、朝代-时间（**易混淆点首选**） | 规则比对 |
| **O5 填空** | ____年辛亥革命。###1911 | 规则+LLM |
| **X1 简答** | 历史意义/比较异同：比较戊戌变法与明治维新的异同 | LLM |

> 客观型 O1-O3 亦可用（如"以下哪个条约签订于 1895 年？"），但历史学科以 R 系记忆型 + O4/O5 + X1 为主。

### 3.2 题型标记（文件内注释）

```
# S1 事件要素回忆：事件###时间/人物
# S2 影响逆向推事件：影响/特征###事件
# S3 条约/措施默写：条约/变法###条款内容
# S4 事件全要素复述：事件###起因-经过-结果-影响
# R1 补全：问题###答案
# R2 逆向：问题###答案
# O4 连线：左列###右列（匹配对）
# O5 填空：____###答案
# X1 简答：问题###参考答案要点
```

## 四、判题引擎适配（L3 层）

D01 已为历史配置 `exact`（精确：术语/年代/符号必须准确），落地细则（学科内宽容）：

| 容错维度 | 策略 | 示例 |
|---------|------|------|
| **年代书写** | 允许 ±1 年容错；"1840"="1840年"（数字/汉字年等价） | 答"1840"判对；1839/1841 → partial 并提示核对 |
| **人物别名** | 允许别名（keywords `aliases` 同义词组，组内任一命中即对） | "孙中山"="孙文"="中山先生" |
| **条约/制度条款** | 关键词匹配（≥85% 命中判 correct，60-85% partial） | 《南京条约》答出"五口通商+割香港岛+赔款"主要条款即判对 |
| **条款顺序** | 顺序不计分 | 条款内容先后颠倒不判错 |
| **意义/评价** | X1 简答走 LLM，按评分要点给分 | 评分要点在 keywords 中声明（required=true 强制命中） |

**易混淆点专项**（优先 O4 连线题型）：
- **三大条约**：《南京条约》（1842）《马关条约》（1895）《辛丑条约》（1901）条款内容区分
- **相似年代**：1911 辛亥革命 / 1919 五四运动 / 1921 中共成立
- **相似人物/事件**：鉴真（东渡日本）/ 玄奘（西行天竺）

**与语文判题的核心差异**：
- 语文语义宽容（同义放行），历史 **exact 基准**（术语/年代/条约必须准确）
- 但历史非死板精确，含学科内宽容：**年代 ±1 年、人物别名、条款关键词匹配**
- 条约/制度类不要求逐字默写，按关键词命中判，hint 引导指向"漏掉的条款/错位的要素"

## 五、记忆状态机与调度（✕△○★）

四阶状态机完全复用：

```
✕ 未掌握：浏览 event_card（输入阶段，建立事件完整印象）
△ 模糊：S1 补全事件要素（正向检索，最容易）
○ 掌握：S2 逆向推事件 + S3 条约/措施默写
★ 熟练：S4 综合复述事件全要素 + X1 简答

降级规则（历史特有）：
- 年代答错（超出 ±1 年）→ △→✕
- 人物/事件张冠李戴（如鉴真/玄奘）→ ○→△
- 条约条款缺主要项 → ★→○
```

**艾宾浩斯调度（历史特调）**：事实性知识遗忘快、易混淆，节奏参考英语单词的紧凑型：

| 内容分类 | 首次间隔 | 递进 | 批量策略 |
|---------|---------|------|---------|
| K1 年代 | 30min → 4h | 1d → 3d → 7d | 高频小批量（每日 10-15 个） |
| K2 事件 | 12h → 1d | 3d → 7d → 15d | 中批量（每日 5-8 个事件） |
| K3 人物 | 30min → 12h | 1d → 3d → 7d → 15d | 与事件联动记忆（事件-人物成对） |
| K4 朝代顺序 | 12h → 1d | 3d → 7d → 15d → 30d | 顺口溜/时间轴辅助 |
| K5 条约/制度 | 1d → 3d | 7d → 15d → 30d | 低频大批量（每周 2-3 组，易混点专项） |
| K6 意义评价 | 1d → 3d | 7d → 14d → 30d | 结合 X1 简答练习 |

## 六、背景钩子：`event_card` 知识卡片（L1 层）

语文用 `author_card`，历史换成 D01 预留的 `event_card`。调研建议字段：

```markdown
## 事件：鸦片战争（1840-1842）
- **event_name**：鸦片战争
- **time**：1840 年 6 月 - 1842 年 8 月
- **location**：中国东南沿海（广州 → 长江下游）
- **key_figures**：林则徐、道光帝、义律（英方代表）
- **cause**：英国为打开中国市场、扭转贸易逆差，向中国倾销鸦片
- **process**：虎门销烟（导火索）→ 英军入侵 → 清军抵抗失败 → 被迫签订条约
- **result**：签订《南京条约》，中国战败
- **impact**：中国开始沦为半殖民地半封建社会，中国近代史的开端
- **related_treaty**：《南京条约》（五口通商 / 割香港岛 / 赔款 2100 万银元 / 协定关税）
- **related_events**：虎门销烟（1839）→ 鸦片战争 → 太平天国运动
- **tags**：近代史 / 鸦片战争 / 条约
```

**配合 S1-S4 渐进隐藏字段**：
- **S1**（正向检索）：隐藏 `time` / `key_figures`，给 `event_name` → 回忆时间/人物
- **S2**（逆向检索）：隐藏 `event_name`，给 `impact` / `result` → 推事件
- **S3**（默写）：展示 `related_treaty` 条约名 → 默写条款内容
- **S4**（综合复述）：全字段隐藏 → 完整复述 `cause → process → result → impact`

**设计原则**：
- 七年级：卡片简化，聚焦朝代 + 人物 + 一个记忆钩子（K4/K3 为主）
- 八年级：全字段，易混点用对比表格（三大条约横向对比）
- 九年级：世界史卡片，增加中外对比关联（戊戌变法 ↔ 明治维新）
