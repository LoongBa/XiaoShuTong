## 二、题型映射对比（D01 题型 × 学科）

## 三、内容分层对比（记忆金字塔）

| 学科 | 层级结构 | 最重模块 |
|------|---------|---------|
| 语文 | 课文 / 课内古诗 / 文言文 / 日积月累 | 初中古诗文（中考核心） |
| 道德与法治 | A 概念 → B 观点 → C 理论 → D 法律 → E 国情 → F 名言 | D 法律（八下法治专册）+ C 理论（九上） |
| 英语 | T1 单词 → T2 短语 → T3 句型 → T4 语篇 | T1 单词（贯穿） |
| 历史 | K1 时间 → K2 事件 → K3 人物 → K4 朝代 → K5 制度条约 → K6 意义影响 | 八年级（条约多因果链复杂） |
| 地理 | 行政区划 / 地形 / 气候 / 河流 / 资源 / 世界之最 / 国家首都 / 人口民族 | 八上（行政区划+地形+气候） |
| 生物 | A 细胞 → B 分类 → C 植物 → D 人体 → E 环境 → F 遗传 | D 人体生理（~120 点，占 24%） |
| 化学 | K1 化学用语 → K2 概念 → K3 性质 → K4 实验现象 → K5 口诀 | K1 化学用语（中考占比最高） |

## 四、判题容错度对比（关键差异）

| 学科 | 容错模式 | 允许 | 禁止 |
|------|---------|------|------|
| 语文 | semantic_tolerant | 同义表述、通假字、标点差异 | 错别字（背诵场景从严） |
| 道法 | exact + 学科宽容 | 概念关键词匹配（语序可调）、观点要点匹配（≥2/3） | 数字类顺序颠倒、混淆概念张冠李戴 |
| 英语 | spelling_tolerant | 大小写、时态/单复数、1-2 字母拼错（partial） | 写错字母=错 |
| 历史 | exact + 学科宽容 | 年代 ±1 年、人物别名 | 条约/制度条款张冠李戴 |
| 地理 | exact + 学科宽容 | 双简称（川=蜀）、别名（亚马孙=亚马逊） | 省会对应错误 |
| 生物 | exact + 同义词表 | 红细胞=红血球（预置同义词表） | 专业术语错字（肾小球≠肾小囊） |
| 化学 | exact（最严） | 方程式分段评分 | 大小写错误、下标错误 |

## 六、分期建设建议（Roadmap）

| 阶段 | 学科优先级 | 理由 |
|------|-----------|------|
| P1 | **英语（小学 PEP 3-6，T1/T2/T3）+ 历史（八年级）+ 道法（八下法治专册）** | 英语闭环最快；历史八下最硬核；道法法律类最适背记 |
| P2 | 地理（八上）+ 生物（模块 D 人体） | 内容密集、会考/中考权重高 |
| P3 | 化学（K1 化学用语）+ 英语 T4/S5 | 化学仅九年级时间充裕；发音判题待 ASR |
| P4 | 各学科剩余模块按年级补齐 | 覆盖全学段 |

## 七、通用建设要点（七学科共守）

1. **新教材优先**：全部基于 2024/2025 修订版新编教材，版本目录层命名 `<教材>-<版本标识>`（`统编-2024修订版/`），过渡期旧版保留在 `XXXX旧版/` 不删除
2. **四件套结构**：篇目清单 → 原始题库 → 背诵训练（S1-S4）→ 知识卡片，统一 Schema（`question.v1.json`/`bank.v1.json`）
3. **bank_id 命名**：`{学科}-{学段}-{教材缩写}{版本标识}`（如 `chinese-7to9-pep-2024r`、`daodeyufazhi-7to9-pep-2024r`）
4. **四阶状态机复用**：✕△○★ 全学科通用，学科差异只在降级触发条件
5. **易混淆点专项**：每学科整理 10-15 组易混点，优先 O4 连线"对比记忆"专项
6. **原文复核**：正式使用前按现行教材逐篇/逐条复核（2024 修订版变化需单独标注）
