## 一、设计定位与核心差异

化学背诵与语文/英语的**骨架一致、灵魂不同**：

| 维度 | 语文/英语 | 化学 | 设计影响 |
|------|----------|------|---------|
| 记忆维度 | 形+义 / 音+形+义 | **符号 + 规则 + 现象**（化学用语三件套） | 以化学用语默写为核心题型 |
| 记忆粒度 | 诗句/单词 | **元素符号→化学式→化学方程式** 递进金字塔 | 三级用语金字塔，粒度递增 |
| 判题容错 | 语义/拼写宽容 | **exact 精确容错** | 大小写、下标是硬约束 |
| 记忆载体 | 诗文/词汇 | **口诀密集**（化合价口诀/金属活动性顺序/溶解性口诀） | concept_card 口诀卡片 |
| 学科特色 | 无 | **现象-物质-符号三向互推** | S1/S2 正向逆向检索天然适配 |

**核心结论**：化学题库沿用语文四件套结构（原始题库 → 背诵训练 → 知识卡片 → 判题 Prompt）+ 统一 Schema，但在**内容分层（五类记忆点）、题型设计（R3 方程式默写为核心）、判题规则（exact + 大小写/下标敏感）、知识卡片（concept_card 口诀）**四个层面做学科化改造。

## 二、内容分层：五类记忆性知识点（L0 资源层）

基于初中化学记忆性知识点调研结论，共五类，合计约 **450-700 个记忆点**：

| 层级 | 内容 | 典型记忆点 | 记忆难点 | 中考权重 |
|------|------|-----------|---------|---------|
| **K1 化学用语类**（最核心） | 元素符号 27 种 / 离子符号约 20 种 / 化合价 / 化学式 30-40 种 / 化学方程式 70-90 个 | 元素符号、离子符号、化合价、化学式、化学方程式 | 符号-名称对应、条件/配平/状态符号 | **最高（中考占比最高）** |
| **K2 基本概念类** | 物质分类 / 微观粒子 / 化学变化 / 反应类型 / 溶液 | 纯净物与混合物、原子/分子/离子、四大基本反应类型、饱和溶液 | 概念辨析（物理变化 vs 化学变化、元素 vs 原子） | 高 |
| **K3 物质性质类** | 氧气 / 二氧化碳 / 氢气 / 金属 / 酸碱盐性质、常见物质俗称 | 各物质物理化学性质、俗称（NaOH-烧碱、Ca(OH)₂-熟石灰） | 性质与用途对应、俗称与化学式对应 | 高 |
| **K4 实验现象类** | 燃烧现象 / 气体检验 / 沉淀颜色 / 溶液颜色 / 实验操作 | 硫在空气 vs 氧气中燃烧、带火星木条复燃、蓝色沉淀 | 现象描述准确（白烟 vs 白雾） | 中高 |
| **K5 规律口诀类** | 化合价口诀 / 金属活动性顺序 / 溶解性口诀 / 元素周期表口诀 | K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au | 顺序记忆、口诀迁移应用 | 中（贯穿全程） |

> **权重策略**：K1 化学用语是核心（覆盖最广、中考占比最高），P1 优先建设；K2 概念 + K3 性质为 P2；K4 实验现象 + K5 规律口诀为 P3 配套。

## 三、题型设计：S1-S4 的化学映射 + O/X 客观主观题型（L2 训练层）

### 3.1 记忆型题型（R 系列）：S1-S4 的化学映射

现有 S1-S4 是"检索方向"驱动，天然适配化学，只需做**刺激-反应**内容的学科化映射：

| 现有题型 | 化学映射（刺激 → 反应） |
|---------|------------------------|
| **S1 正向检索** | 给符号 → 回忆名称（元素符号/化学式/化学方程式）；给反应物 → 回忆生成物 |
| **S2 逆向检索** | 给现象/俗称 → 反推物质（带火星木条复燃 → O₂；烧碱 → NaOH） |
| **S3 整篇默写（R3 子型 b）** | 默写完整化学方程式（含反应物/生成物/条件/配平/状态符号） |
| **S4 综合输出** | 综合复述反应类型 + 规律（该反应所属类型 + 对应规律口诀） |

### 3.2 化学核心题型：R3 方程式默写

**R3 默写是化学核心题型**（对应 D01 R3b 整篇默写子型，独立 Prompt `学科-chemistry-R3-方程式`），判题按五要素分段评分：

| 段 | 要素 | 示例（电解水） |
|----|------|--------------|
| ① 反应物 | 必须写全 | 2H₂O |
| ② 生成物 | 必须写全 | 2H₂↑ + O₂↑ |
| ③ 条件 | 正确标注（通电/点燃/加热/催化剂） | 通电 |
| ④ 配平 | 化学计量数正确 | 2:2:1 |
| ⑤ 状态符号 | ↑↓ 标注正确 | H₂↑、O₂↑ |

> 五要素逐段判 partial：某段错误仅该段扣分并给针对性 hint（如"条件漏写"）。

### 3.3 复用 O 系列客观题 + R 系列记忆题 + X 系列主观题

| 题型 | 化学应用示例 |
|------|-------------|
| **O5 填空** | 元素符号/离子符号/化合价：`Cl⁻ vs Cl₂`、`2O₂`、`KIO₃ 中碘 +5 价` |
| **O4 连线** | 物质-俗称（NaOH-烧碱、Ca(OH)₂-熟石灰）；元素-符号（氧-O、铁-Fe） |
| **R1 补全** | 方程式补全：`2H₂O →(通电)→ 2H₂↑ + ___` |
| **R2 逆向** | 给现象推物质：带火星木条复燃 → O₂ |
| **X1 简答** | 实验现象描述（硫在氧气中燃烧的现象） |
| **X3 计算** | 相对分子质量 / 元素质量分数（如 H₂O 中氧元素质量分数） |

### 3.4 题型标记（文件内注释）

```

# S1 给反应物回忆生成物：2H₂O →(通电)→ ###2H₂↑ + O₂↑
```

## 四、判题引擎适配（L3 层）

D01 已为化学配置 `exact`（精确容错，术语/符号必须准确），落地细则：

| 容错维度 | 策略 | 示例 |
|---------|------|------|
| **大小写** | **敏感（Cl ≠ cl ≠ CL）** | 元素符号首字母大写、第二字母小写是硬约束 |
| **下标** | **必须正确（H₂O ≠ H2O），支持 Unicode 下标** | 化学式下标用 Unicode ₂₃₄，判题严格比对 |
| **方程式分段评分** | 五要素分段（反应物/生成物/条件/配平/状态符号），逐段判 partial | 条件写错 → 该段 partial，hint 指向条件 |
| **易混淆点专项** | 内置易混淆规则库（见下） | Cl/Cl⁻/Cl₂ 专项判题 |
| **计算题型（X3）** | 数值正确 + 计算步骤比对 | 相对分子质量/质量分数 |

**易混淆点专项判题规则**：

| 混淆点 | 助记口诀 | 判题处理 |
|--------|---------|---------|
| Cl / Cl⁻ / Cl₂ | "光身=原子，带帽=离子，成双=分子" | 逐字符精确比对 |
| 2H / H₂ / 2H₂ | "前数=个数，下数=原子数" | 区分计量数 vs 下标 |
| Fe²⁺ / Fe³⁺ | "亚铁二，铁三" | 电荷数精确比对 |
| CO / CO₂ | "少一个氧=有毒" | 下标严格区分 |
| 白烟 vs 白雾 | 固体小颗粒=烟，液体小液滴=雾 | X1 判题要点 |
| 硫在空气 vs 氧气中燃烧 | 空气淡蓝，氧气蓝紫 | 现象判题要点 |

**与语文/英语判题的核心差异**：
- 语文语义宽容、英语拼写宽容，化学 **exact 精确**——符号必须准确
- 大小写、下标、计量数是化学"硬约束"，不可放行
- 方程式分段评分是化学特有判题能力，需独立专项 Prompt（`学科-chemistry-R3-方程式.md`）
- O5 填空按 `exact` 判，无同义词组兜底（化学符号无"别名"）

## 五、记忆状态机与调度（✕△○★）

四阶状态机完全复用，但化学的**降级触发条件**增加"符号维度"：

```
✕ 未掌握：跟读/识记（输入阶段，建立符号-名称联结）
△ 模糊：S1 给符号回忆名称 / S2 给现象反推物质（正向/逆向检索）
○ 掌握：S2 逆向 + R1 方程式补全
★ 熟练：S3 方程式默写 + S4 综合复述

降级规则（化学特有）：
- 大小写/下标错误 → 直接判 wrong（硬约束，不降级容错）
- 方程式分段错误（条件/配平错） → ○→△
- 易混淆点混淆（Cl/Cl⁻/Cl₂） → ★→○
```

**艾宾浩斯调度（化学特调）**：

| 内容层 | 首次间隔 | 递进 | 批量策略 |
|--------|---------|------|---------|
| K1 化学用语 | 30min → 4h | 1d → 3d → 7d | 高频小批量（每日 15-20 个符号/方程式） |
| K2 基本概念 | 12h → 1d | 3d → 7d → 15d | 概念分组 |
| K3 物质性质 | 12h → 1d | 3d → 7d → 15d | 按物质归类 |
| K4 实验现象 | 1d → 3d | 7d → 14d → 30d | 按实验归类 |
| K5 规律口诀 | 1d → 3d | 7d → 14d → 30d | 口诀成组记忆 |

## 六、知识卡片：`concept_card`（L1 层）

D01 为化学/生物预留 `concept_card`（定义/功能/分类/易混点/记忆口诀）。**化学口诀密集是最大特色**：

```markdown
## 化合价口诀（K1/K5）
- **定义**：元素在化合物中表现出的化合能力
- **分类**：常见化合价 + 变价元素
- **口诀**：一价氢氯钾钠银；二价氧钙钡镁锌；三铝四硅五氮磷；二三铁、二四碳，二四六硫都齐全
- **易混点**：变价元素（铁 +2/+3、硫 +4/+6）需单独标记
- **助记**：颜色编码——正价红、负价蓝、变价黄

## 金属活动性顺序（K5）
- **顺序**：K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au
- **阶梯图**：按活动性从强到弱画阶梯，标注与酸/盐溶液反应规律
- **易混点**：(H) 位置——氢前金属可与酸反应，氢后不能

## 溶解性口诀（K5）
- **口诀**：钾钠铵盐全都溶，硝酸盐类也相同；盐酸盐中银难溶，硫酸盐中钡不溶……
- **易混点**：个别沉淀例外需标注
```

**设计原则**：
- **口诀卡片用颜色编码**：正价红 / 负价蓝 / 变价黄
- **金属活动性用阶梯图**：可视化强弱顺序
- 每张卡片配 **S1-S4 渐进隐藏字段**：✕ 阶段显示全部；△ 隐藏口诀后半段；○ 隐藏整段口诀仅提示首句；★ 全部隐藏仅留关键词
- 化学式/方程式卡片：公式符号统一使用 Unicode 下标（₂₃₄），与题目/判题一致

**concept_card 字段映射**：定义（概念）/ 分类（物质分类）/ 易混点（Cl vs Cl₂）/ 记忆口诀（化合价口诀）/ 助记（颜色编码/阶梯图）

## 九、分期规划（Roadmap）

化学仅在九年级开设（9 年级一学年），**无需分年级规划**：

| 阶段 | 内容 | 产出 | 依赖 |
|------|------|------|------|
| P1 | **K1 化学用语**（元素符号 + 化学式 + 化学方程式，最核心） | 原始题库 txt + 背诵训练 + concept_card | 无 |
