## 一、设计定位与核心差异

道法背诵与其他学科的**骨架一致、灵魂不同**：

| 维度 | 语文/历史 | 道德与法治 | 设计影响 |
|------|----------|-----------|---------|
| 记忆对象 | 诗文 / 事实 | **观点 + 概念 + 理论 + 法条 + 名言** | 观点陈述类内容占比高（非文本默写） |
| 记忆粒度 | 诗句/事件 | **知识点（概念定义/观点/数字类）** | 以"概念卡/观点卡"为记忆单元 |
| 判题容错 | 语义/精确 | **exact + 学科宽容** | 概念定义关键词匹配、观点要点匹配、名言较严格 |
| 开卷/闭卷 | 无差异 | **开闭卷地区差异大** | 需双模式适配（精准记忆 / 快速定位） |
| 知识卡片 | author_card/event_card | **concept_card（6 种卡型）** | 数字记忆卡、对比辨析卡是特色 |
| 时政关联 | 无 | **强时政关联** | 需"时政-知识点"关联卡 |

**核心结论**：道法题库沿用语文四件套结构 + 统一 Schema，但在**内容分层（六类记忆点）、题型设计（概念补全/观点简答/对比连线）、判题规则（exact + 关键词/要点匹配）、知识卡片（concept_card 六型）**四个层面做学科化改造。**特别处理开卷/闭卷双模式适配。**

## 二、内容分层：六大记忆类别（L0 资源层）

基于调研结论，道法记忆性知识点分 6 大类，初中三年合计约 **650-820 个记忆点**：

| 类别 | 内容 | 典型示例 | 记忆难点 | 年级分布 |
|------|------|---------|---------|---------|
| **A 核心概念定义** | 法律/道德/心理品质概念 | 法律特征（国家制定/强制力/普遍约束）；犯罪三特征；自尊/自信/自强 | 概念要素齐全性 | 七下、八下最重 |
| **B 观点陈述** | 个人成长/人际/生命观核心观点 | 友谊特质；生命特点；"生命至上" | 分点完整、表述规范 | 七年级最重 |
| **C 政治理论** | 核心价值观/民族精神/政治理论 | 24 字核心价值观；"四个自信"；中国梦 | 数字类顺序、理论表述精确 | 九上最重 |
| **D 法律常识** | 宪法/权利义务/未成年人保护 | 宪法地位；公民基本权利/义务；六大保护 | 概念辨析（权利vs义务） | 八下最重（法治专册） |
| **E 国情国策** | 基本制度/基本国策/国家安全 | 基本经济制度；处理民族关系原则；总体国家安全观 | 制度体系层级 | 八上、九上 |
| **F 名言警句** | 教材引用经典名言 | "己所不欲，勿施于人"；"天行健，君子以自强不息" | 出处对应、含义关联 | 贯穿全程 |

> **权重策略**：A 概念 + B 观点是基础层（P1）；D 法律 + C 理论是中考核心（P2）；E 国情 + F 名言配套（P3）。

## 三、题型设计：S1-S4 的道法映射 + O/X 题型（L2 训练层）

### 3.1 记忆型题型（R 系列）：S1-S4 的道法映射

| 记忆状态 | 题型 | 刺激 → 反应 |
|---------|------|------------|
| ✕ 未掌握 | 跟读理解（不测试） | 通读知识点/观点，建立印象 |
| △ 模糊 | **S1 正向检索** | 给概念名 → 回忆定义；给问题 → 回忆观点（"友谊的特质？→ 亲密/平等双向/心灵相遇"） |
| ○ 掌握 | **S2 逆向检索 + S3 默写** | 给特征/要点 → 反推概念；默写观点分点/24 字核心价值观（顺序不可颠倒） |
| ★ 熟练 | **S4 综合运用** | 给情境 → 匹配观点并阐述（X1 简答训练） |

### 3.2 客观/主观题型（O/X 系列）

| 题型 | 道法应用 | 示例 |
|------|---------|------|
| **O4 连线** | **易混淆点对比（15 组）**、概念-特征匹配、名言-出处 | 道德↔自律维持；法律↔国家强制力 |
| **O5 填空** | 概念关键词、数字类填空 | "犯罪的三个基本特征是___、___、___" |
| **R3 默写** | 24 字核心价值观、名言警句、观点分点 | "默写社会主义核心价值观 24 字" |
| **X1 简答** | 观点阐述、情境-观点应用、辨析题 | "结合材料，谈谈青少年应如何维护国家安全" |

### 3.3 开卷/闭卷双模式适配（道法独有）

| 考试模式 | 地区示例 | 题库侧重 |
|---------|---------|---------|
| 开卷 | 北京/深圳/湖南（2025-2026 改开卷） | "快速定位"训练：目录导航、关键词检索、框架结构记忆 |
| 闭卷 | 广州/浙江/山东/大庆 | "精准记忆"训练：S1-S4 分阶强化 |

> 开卷≠不用背：核心知识点/框架/高频考点必须背熟（选择题尽量不翻书），题库建议给知识点打"开卷定位优先级"标签。

## 四、判题引擎适配（L3 层）

`exact` 容错 + 学科内宽容：

| 内容类型 | 容错策略 | 示例 |
|---------|---------|------|
| 概念定义 | 关键词匹配（允许语序调整） | "由国家制定或认可"可接受"国家制定或认可" |
| 观点陈述 | 要点匹配（不要求逐字） | 友谊特质答出"亲密""双向""心灵相遇"即正确 |
| 名言警句 | 严格匹配（允许个别字误差） | 古文名言要求较高准确度 |
| 数字类（24 字等） | **顺序 + 内容双重匹配** | 核心价值观三层顺序不可颠倒 |
| 法律条文 | 关键词匹配 | "严重社会危害性"不可简化为"危害性" |
| 政治理论 | 关键词匹配（表述可小幅调整） | "根本法""治国安邦总章程"关键词命中即对 |

**易混淆点专项**（15 组，优先 O4 连线）：道德vs法律、权利vs义务、一般违法vs犯罪、自尊vs虚荣、宪法vs普通法律、公民vs人民、法定义务vs道德义务、基本权利vs普通权利、名誉权vs荣誉权、肖像权vs隐私权、人民代表大会vs人民代表大会制度、依法治国vs以德治国、公有制主体vs国有经济主导、民主选举vs民主决策、改革vs创新。

## 五、记忆状态机与调度（✕△○★）

```
✕ 未掌握：跟读理解知识点（输入）
△ 模糊：S1 正向检索（概念名→定义/问题→观点）
○ 掌握：S2 逆向检索 + S3 默写（特征→概念、顺序类完整默写）
★ 熟练：S4 综合运用（情境→观点，X1 简答）

降级规则（道法特有）：
- 概念要素缺失（如法律特征只答 1 条）→ ○→△
- 数字类顺序颠倒（24 字核心价值观顺序错）→ ★→○
- 混淆概念张冠李戴（如把"以德治国"答成"依法治国"）→ ○→△
```

**调度间隔**：与语文一致（30min → 12h → 1d → 3d → 7d → 30d）；观点类适合整组记忆（一组观点一批复习），概念类适合单点高频。

## 六、知识卡片：concept_card 六型（L1 层）

| 卡片类型 | 适用内容 | 卡片结构 | 对应题型 |
|---------|---------|---------|---------|
| 概念定义卡 | 法律特征、犯罪特征 | 概念名 → 标准定义 + 关键词 | R1 补全、O5 填空 |
| 观点陈述卡 | 友谊特质、生命意义 | 问题 → 分点答案 | X1 简答、R3 默写 |
| 对比辨析卡 | 道德vs法律、权利vs义务 | A vs B → 对比表（区别+联系） | O4 连线、R2 逆向 |
| 数字记忆卡 | 24 字核心价值观、六大保护 | 数字提示 → 完整内容 | R1 补全、O5 填空 |
| 名言出处卡 | 教材引用名言 | 名言 → 出处 + 关联 + 含义 | R3 默写、O4 连线 |
| 国情国策卡 | 基本制度、总体国家安全观 | 知识点 → 标准表述 + 关键词 | R1 补全、X1 简答 |

**卡片示例**：

```markdown
## 法律的特征（concept_card）
- **定义**：由国家制定或认可、靠国家强制力保证实施、对全体社会成员具有普遍约束力
- **关键词**：国家制定/认可、强制力、普遍约束力
- **易混点**：道德靠舆论/习惯/信念维持（自律），法律靠国家强制力（他律）
- **口诀**："制认强制普约束，法律道德分他律"
- **关联**：犯罪三特征、违法行为分类
```

**设计原则**：正面问题化（非直接给答案）、关键词锚定、层级递进（完整背诵→关键词填空→逆向辨析）、易混点配对、开卷定位优先级标签。
