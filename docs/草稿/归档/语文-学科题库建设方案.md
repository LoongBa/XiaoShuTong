## 一、设计定位与核心差异

语文作为**基准学科**，其四件套结构（篇目清单 → 原始题库 → 背诵训练 → 背景钩子）+ 统一 Schema 是其他学科的模板：

| 维度 | 语文（基准） | 设计影响 |
|------|------------|---------|
| 记忆对象 | 古诗文 + 现代文背诵 + 文言文 + 日积月累 | 内容分类最丰富（5 类） |
| 记忆粒度 | 诗句/段落/整篇（较大） | S1-S4 以诗句/句子为单位接龙 |
| 判题容错 | **semantic_tolerant（语义宽容）** | 同义表述/通假字/标点差异放行 |
| 记忆载体 | 诗文文本（韵律记忆） | 对仗/押韵天然助记 |
| 知识卡片 | author_card（七维核对法） | 故事化背景增强精细复述 |

**核心结论**：语文是 D01 框架中第一个完整适配器（原始题库 435 题 + 分阶训练 1278 题 + 背景钩子 + 判题 Prompt 库），新学科 = 复用语文四件套结构 + 学科化改造（内容分层/题型/容错/卡片四层）。

## 二、内容分层：五类记忆内容（L0 资源层）

### 2.1 小学（1-6 年级）

| 分类 | 内容 | 典型示例 | 记忆难点 |
|------|------|---------|---------|
| 课文背诵（全文/片段） | 儿歌、韵文、现代文 | 《小小的船》《四季》《秋天》 | 现代文长句、片段范围记忆 |
| 课内古诗 | 课文单元内的古诗 | 《静夜思》《登鹳雀楼》 | 易错字、名句理解 |
| 文言文/小古文 | 教材中文言文篇目 | 《司马光》《精卫填海》《少年中国说》 | 句读、通假字、句意 |
| 日积月累古诗 | 语文园地中的古诗 | 《春晓》《赠汪伦》 | 与课内古诗归属区分 |
| 日积月累其他 | 谚语、名言警句、歇后语、成语 | "一年之计在于春"、二十四节气歌 | 条目琐碎、量多 |

### 2.2 初中（7-9 年级）

| 分类 | 内容 | 典型示例 | 记忆难点 |
|------|------|---------|---------|
| 课内古诗 | 课文内古代诗歌 | 《观沧海》《望岳》 | 名句理解、手法赏析 |
| 课内文言文 | 课文内文言文 | 《论语》十二章、《岳阳楼记》 | 句读、虚词、翻译 |
| 课外古诗词诵读 | 单元后的诵读篇目 | 《峨眉山月歌》《竹里馆》 | 与课内篇目混淆 |

> **学段权重**：小学低年级（1-2）以课文/儿歌为主，古诗文自三年级起增加；初中古诗文篇幅与数量大幅上升（中考核心）。

## 三、题型设计：S1-S4 + 原始题库四类题（L2 训练层）

### 3.1 原始题库四类题（L1 层，判"会不会"）

| 题类 | 形式 | 示例 |
|------|------|------|
| 文学常识 | 作者及朝代/出处 | 《静夜思》的作者是？###李白 |
| 补全 | 上句接下句 / 关键词填空 | "床前明月光"的后一句是？###疑是地上霜 |
| 名句理解 | 找名句/主旨句 | 《登鹳雀楼》中蕴含哲理的名句是？###欲穷千里目，更上一层楼。 |
| 整篇默写 | 默写《篇名》###全文 | 默写《静夜思》###床前明月光，疑是地上霜。…… |

### 3.2 背诵训练 S1-S4（分阶检索）

| 记忆状态 | 题型 | 刺激 → 反应 |
|---------|------|------------|
| ✕ 未掌握 | 整篇跟读（不测试） | 朗读、理解大意、建立印象 |
| △ 模糊 | **S1 上句接下句** | 床前明月光 → 疑是地上霜 |
| ○ 掌握 | **S2 下句接上句 + S3 段落默写** | 逆向检索 + 段落逻辑检验 |
| ★ 熟练 | **S4 整篇默写** | 完整性检验，进入长期记忆 |

## 四、判题引擎适配（L3 层）

`semantic_tolerant`（语义宽容）——D01 定义语文判题基线：

| 容错维度 | 策略 | 示例 |
|---------|------|------|
| 同义表述 | 放行 | "唐太宗"="李世民" |
| 通假字/异体字 | 教材通行版本一致则放行 | "常"="长"、"见"="现" |
| 标点差异 | 放行 | 逗号/分号/句号差异 |
| 错别字 | 背诵场景从严：1-2 字错 → partial | "天涯"写成"天崖" → partial |
| 顺序 | 多分句只答部分 → partial | "若出其中；星汉灿烂，若出其里"只答前句 |

**hint 原则**：绝不出答案本身，只给首字/意象/逻辑线索（≤20 字），对齐 V3"请提示我"交互与 hint_level 状态机（none/partial/full）。

## 五、记忆状态机与调度（✕△○★）

```
✕ 未掌握 → S1 跟读（输入）
△ 模糊 → S1 上句接下句
○ 掌握 → S2 下句接上句 + S3 段落默写
★ 熟练 → S4 整篇默写
连续 2 次 S1 答对 → 升级 S2；S2 连续 2 次答对 → 升级 S3/S4
求助后答对 → 记 △（记忆不牢固）
答错 → 降一级（○→△，★→○）
```

**调度间隔**：艾宾浩斯首次 30min → 12h → 1d → 3d → 7d → 30d；每日复习到期 70% + 学新 30%；★ 级篇目每周 S4 抽查 1 次。

## 六、知识卡片：author_card 七维核对法（L1 层）

语文知识卡片采用 **author_card**，每个篇目按 7 维核对覆盖：

| 维度 | 检查内容 | 示例 |
|------|---------|------|
| A 作者定位 | 朝代/字号/称号/并称/流派 | 李白号"青莲居士"，与杜甫并称"李杜" |
| B 人物关系 | 赠答对象/交往/师承 | 李白写诗慰王昌龄贬谪 |
| C 创作时空 | 时间/地点/境遇 | 曹操北征乌桓凯旋登碣石 |
| D 地理钩子 | 诗内地名 → 今地 | 龙标=湖南黔阳 |
| E 用典成语 | 化用典故/衍生成语 | "天塌下来"出自杞人忧天 |
| F 关联作品 | 同作者/同主题互链 | 《诫子书》↔《出师表》 |
| G 趣闻点评 | 历史评价/文坛轶事 | "海日生残夜"被张说挂政事堂 |

> 小学低年级（1-2）简化：只讲"作者是谁 + 讲了什么故事 + 一个记忆点"；中年级（3-4）增加"创作背景 + 关联作品"；高年级（5-6）与初中接近 7 维全覆盖。核对方法见 `背景钩子/检查项清单.md`。

## 八、质量检查清单（语文特有）

- [ ] 篇目与教材逐课核对（含背诵范围：全文/片段）
