## 枚举定义

#### TaskStatus ── 任务状态

存储格式：`string`（PascalCase；存量 D02 为小写 draft/active/closed，见存量差异③）
使用场景：Tasks.Status

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Draft | 草稿 | 创建未发布（三步向导暂存，本期可省略——创建即发布，见 U01 决策） |
| Active | 进行中 | 已发布，学生可执行 |
| Closed | 已关闭 | 已截止/关闭，不可再新执行 |

#### TaskScenario ── 任务场景（状态机耦合）

存储格式：`string`（PascalCase；存量小写 memorize/assess）
使用场景：Tasks.Scenario

| 枚举值 | 业务含义 | 状态机耦合 |
|:------:|---------|-----------|
| Memorize | 背诵 | full（正常迁移） |
| Assess | 检验 | feedback_only（答错降级、答对不升级） |

#### TaskSessionType ── 任务会话类型

存储格式：`string`（PascalCase；存量 D02 为中文"分阶/自由/组卷"，见存量差异③）
使用场景：Tasks.SessionType

| 枚举值 | 业务含义 |
|:------:|---------|
| Progressive | 分阶（默认） |
| Free | 自由 |
| Assembled | 组卷 |

#### AssignmentStatus ── 任务分配状态

存储格式：`string`（PascalCase；存量小写 pending/in_progress/completed/overdue）
使用场景：TaskAssignments.Status

| 枚举值 | 业务含义 |
|:------:|---------|
| Pending | 待执行 |
| InProgress | 进行中 |
| Completed | 已完成 |
| Overdue | 已逾期 |

## 实体关系

```
Users (1) ──→ (N) Tasks                群主发布任务
Groups (1) ──→ (N) Tasks               群组布置任务
Tasks (1) ──→ (N) TaskAssignments      任务分配学生（每任务每学生唯一）
Users (1) ──→ (N) TaskAssignments      学生执行任务
TaskAssignments (N) ──→ (0..1) StudySessions  分配关联执行会话（跨模块）
Tasks (1) ──→ (N) StudySessions        任务归属会话（跨模块）
```

> 跨模块实体引用（不在本 DS 定义）：`Users`（账户域）、`Groups`/`GroupMembers`（群组域，切片 01）、`StudySessions`/`Attempts`（学习域，切片 02）——FK 引用，编译依赖通过框架 DI 注入。

## 存量差异标注（D02 DDL → TKWF 框架）

| # | 差异项 | D02 存量 | TKWF 要求（DG-05） | 处理建议 |
|:-:|-------|---------|-------------------|---------|
| ① | **主键类型** | `uuid` | `long Id`（硬性） | **沿用前序切片决策**：内部 `long Id`；外部关联、跨系统用 `Uid`（uuid 业务键）——实体表补 Uid 列（唯一索引），API/DTO 暴露 Uid |
| ② | **审计字段** | `CreatedAt/UpdatedAt`（TaskAssignments 原无审计列） | `CreateTime/UpdateTime` | 本 DS 已转化并补齐 TaskAssignments 审计列 |
| ③ | **枚举存储** | 小写（draft/active/closed/pending）+ 中文（分阶/自由/组卷） | PascalCase `"Active"/"Progressive"` | 本 DS 已转化；存量数据迁移映射（分阶→Progressive） |
| ④ | **错误码** | 数字域码 51xx | DG-06 默认 SNAKE_CASE | **沿用决策**：保留数字码 + 语义名双列（见 U01 错误码表） |
| ⑤ | **AllowRedo（是否允许重做）** | **D02 未定义**；`UNIQUE(TaskId, UserId)` 仅一条分配 | 框架无强制 | **本 DS 补充 `AllowRedo` 字段**（对齐 UI 配置步骤"是否允许重做"）；重做语义 = 已完成任务仍可进入复习（不改变 Completed 状态）——**实施前确认** |
| ⑥ | **任务状态 Draft** | D02 有 `draft` 枚举但无流转条件 | 无强制 | 本期创建即发布（Active），Draft 保留枚举值供三步向导暂存扩展——**实施前确认是否保留** |

> **字段覆盖校对（S/UI → DS）**：S01 场景与 UI 页面展示字段（任务名/截止时间/进度条/群主名、选题源题量、允许重做、预览题目、成员完成状态/用时/正确率、卡壳知识点、执行率/平均进度/逾期数/薄弱点 Top5、学生执行表列头、补救任务）——① 任务名/截止/进度 = Tasks.Title/DeadlineAt + TaskAssignments.Progress ✅；② 允许重做 = Tasks.AllowRedo（新增）✅；③ 成员完成状态/用时/正确率 = TaskAssignments.Status + Attempts 聚合（跨模块）✅；④ 卡壳知识点/薄弱点 = Attempts/KnowledgeMastery 聚合（跨模块）✅；⑤ 执行率/平均进度/逾期 = TaskAssignments 聚合（Service 层）✅

### OwnerDashboardView ── 群主看板/任务完成率聚合视图（VEntity 设计规格）

**表名**：`vw_owner_dashboard`（DisableSyncStructure=true）
**子域**：`TaskManagement`（消费域，命名歧义消解后子域）
**Id 构造方案**：A 业务唯一键透传（TaskId）
**视图类型**：普通视图（TKWF VEntity 默认；物化视图经 DBA 评估）

**引用基表**：TaskManagement.Tasks + TaskManagement.TaskAssignments
**依赖追踪**：Tasks.Status/DeadlineAt/GroupId/OwnerId、TaskAssignments.Status/Progress/TaskId DDL 变更需核对本视图

**Join 结构**：LEFT JOIN（TaskAssignments ← Tasks ON TaskId）——保留无分配任务（BR-14 空态）
**优化栅栏评估**：含 GROUP BY（按 TaskId）+ WHERE 谓词——无窗口函数/集合操作

**聚合粒度**：COUNT（分配/完成/逾期）+ AVG（进度）按任务分组

**字段表**（= UI 展示字段超集，显式列名，禁 SELECT *）：
| 字段 | 类型 | 聚合列类型 | 来源列 | 四层一致性核对(UI/属性/?fields) | 可更新列标记 |
|------|------|-----------|--------|------------------------------|:---:|
| TaskId | long | — | Tasks.Id | 看板/任务列表按任务 | 否 |
| TaskUid | string | — | Tasks.Uid | TaskUid 透传 | 否 |
| GroupId | long | — | Tasks.GroupId | 群组过滤 | 否 |
| OwnerId | long | — | Tasks.OwnerId | 权限过滤（BR-09） | 否 |
| Title | string | — | Tasks.Title | 任务名 | 否 |
| DeadlineAt | DateTime? | — | Tasks.DeadlineAt | 截止时间 | 否 |
| Status | string | — | Tasks.Status | 状态过滤（Active/Closed） | 否 |
| QuestionCount | int | — | Tasks.QuestionCount | 题数 | 否 |
| AssignmentTotal | int | COUNT | `COUNT(TaskAssignments.Id) AS AssignmentTotal` | 完成率分母（含逾期，BR-17） | 否 |
| CompletedCount | int | COUNT | `COUNT(CASE WHEN TaskAssignments.Status='Completed' THEN 1 END) AS CompletedCount` | 完成率分子 | 否 |
| OverdueCount | int | COUNT | `COUNT(CASE WHEN TaskAssignments.Status='Overdue' THEN 1 END) AS OverdueCount` | 逾期数 | 否 |
| ProgressAvg | decimal | AVG | `AVG(TaskAssignments.Progress) AS ProgressAvg` | 平均进度 | 否 |

**数据权限**：行级 WHERE（OwnerId 属主过滤——Service 经 EQR 附加 OwnerId 谓词；BR-08/BR-09）；无列级隐藏
**性能评估**：预估行数 = 任务数 / 索引建议（Tasks: IX_Tasks_OwnerId_Status、TaskAssignments: IX_TaskAssignments_TaskId_Status）/ EXPLAIN 验证要点（谓词下推? 索引扫描?）
**可维护性**：命名 `vw_` 前缀 / COMMENT ON 文档（完成率口径：分母含逾期，BR-17）/ 版本控制（纳入 git）
**查询通道暴露决策**：EQR `User.Query<OwnerDashboardView>()` / ExposeRestQuery 关（经 Service 包装 REST）/ GraphQL 开

> **指标卡口径说明**：看板总览（执行率/平均进度/逾期数）= 跨任务二次聚合（`SUM(CompletedCount)/SUM(AssignmentTotal)`、`AVG(ProgressAvg)`、`SUM(OverdueCount)`）→ 属复杂编排，Service 在本视图行集上聚合（决策表：Service 层读侧可配合 VEntity）。视图只保证任务行粒度，聚合口径唯一（收官聚合检查对齐）。

### GroupWeakPointsView ── 组内薄弱知识点聚合视图（VEntity 设计规格）

**表名**：`vw_group_weak_points`（DisableSyncStructure=true）
**子域**：`TaskManagement`（消费域）
**Id 构造方案**：A 变体（复合业务键 GroupId+KnowledgePoint → 单列 long Id 需合成：编码阶段按 `ROW_NUMBER() OVER (PARTITION BY GroupId ORDER BY Accuracy)` 或 Id 合成列，非纯报表 B 方案）
**视图类型**：普通视图（TKWF VEntity 默认）

**引用基表**：GroupManagement.GroupMembers + Learning.KnowledgeMastery
**依赖追踪**：GroupMembers.GroupId/UserId/Role、KnowledgeMastery.UserId/Accuracy/KnowledgePoint DDL 变更需核对本视图

**Join 结构**：INNER JOIN（KnowledgeMastery ← GroupMembers ON UserId，WHERE GroupMembers.Role='Student'）
**优化栅栏评估**：GROUP BY（GroupId+KnowledgePoint）+ WHERE 谓词——无窗口函数（Id 合成除外）/集合操作

**聚合粒度**：AVG(Accuracy) 按 组×知识点（正确率口径全局唯一=均值，见收官聚合检查 DG-01 三·补）

**字段表**：
| 字段 | 类型 | 聚合列类型 | 来源列 | 四层一致性核对 | 可更新列标记 |
|------|------|-----------|--------|--------------|:---:|
| GroupId | long | — | GroupMembers.GroupId | 看板按群 | 否 |
| KnowledgePoint | string | — | KnowledgeMastery.KnowledgePoint | 薄弱点知识点 | 否 |
| Accuracy | decimal | AVG | `AVG(KnowledgeMastery.Accuracy) AS Accuracy` | 正确率（升序 Top5 排序源，BR-19） | 否 |
| StudentCount | int | COUNT | `COUNT(DISTINCT GroupMembers.UserId) AS StudentCount` | 覆盖学生数（扩展列） | 否 |

**数据权限**：行级 WHERE（群组作用域经 Service EQR 谓词）；无列级隐藏
**性能评估**：预估行数 = 组数×知识点数 / 索引建议（GroupMembers: IX_GroupMembers_GroupId_Role（切片01 权威）、KnowledgeMastery: IX_KnowledgeMastery_UserId_Subject（切片02 权威））/ EXPLAIN 验证要点
**可维护性**：命名 `vw_` 前缀 / COMMENT ON 文档（口径：组内学生 KnowledgeMastery.Accuracy 均值）/ 纳入 git
**查询通道暴露决策**：EQR `User.Query<GroupWeakPointsView>()` / ExposeRestQuery 关 / GraphQL 开

### 切片验证期实现（不建视图）

- 内存 DAC（TestingEntityDAC）不支持 SQL 视图 → `GetOwnerDashboardService`/`ListTasksService` 以 Service 层聚合实现（读 Tasks+TaskAssignments 计算完成率/执行率，**口径与视图一致：分母含逾期**）
- 薄弱点 Top5：`GetOwnerDashboardService.BuildWeakPointsAsync`（GroupMembers → KnowledgeMastery 循环拉取 + GroupBy + AVG + 升序 Take5），与 `vw_group_weak_points` 口径一致
- 生产切换：建视图后两 Service 改 EQR 读取（任务行级查询），DTO 不变

### 查询契约要素（U01 引用）

- 看板/任务列表经 **Service 方法包装 REST**（VEntity 不支持 REST 端点；GraphQL 开）
- 生产切换后 `ListTasksService` 分页在 EQR 上做（框架 DefaultLimit=100 / MaxSearchLimit=100）
- 跨切片消费声明：本域消费 **GroupManagement**（Groups/GroupMembers，切片 01）+ **Learning**（KnowledgeMastery 薄弱点聚合，切片 02 产物）
