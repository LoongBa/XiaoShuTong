## 枚举定义

#### TaskStatus ── 任务状态

存储格式：`string`（PascalCase；存量 D02 为小写 draft/active/closed，见存量差异③）
使用场景：Tasks.Status

| 枚举值 | 业务含义 | 说明 |
|:------:|---------|------|
| Draft | 草稿 | 创建未发布（三步向导暂存，本期可省略——创建即发布，见 U01 决策） |
| Active | 进行中 | 已发布，学生可执行 |
| Closed | 已关闭 | 已截止/关闭，不可再新执行 |

#### TaskScenario ── 任务场景（状态机耦合）

存储格式：`string`（PascalCase；存量小写 memorize/assess）
使用场景：Tasks.Scenario

| 枚举值 | 业务含义 | 状态机耦合 |
|:------:|---------|-----------|
| Memorize | 背诵 | full（正常迁移） |
| Assess | 检验 | feedback_only（答错降级、答对不升级） |

#### TaskSessionType ── 任务会话类型

存储格式：`string`（PascalCase；存量 D02 为中文"分阶/自由/组卷"，见存量差异③）
使用场景：Tasks.SessionType

| 枚举值 | 业务含义 |
|:------:|---------|
| Progressive | 分阶（默认） |
| Free | 自由 |
| Assembled | 组卷 |

#### AssignmentStatus ── 任务分配状态

存储格式：`string`（PascalCase；存量小写 pending/in_progress/completed/overdue）
使用场景：TaskAssignments.Status

| 枚举值 | 业务含义 |
|:------:|---------|
| Pending | 待执行 |
| InProgress | 进行中 |
| Completed | 已完成 |
| Overdue | 已逾期 |

## 实体关系

```
Users (1) ──→ (N) Tasks                群主发布任务
Groups (1) ──→ (N) Tasks               群组布置任务
Tasks (1) ──→ (N) TaskAssignments      任务分配学生（每任务每学生唯一）
Users (1) ──→ (N) TaskAssignments      学生执行任务
TaskAssignments (N) ──→ (0..1) StudySessions  分配关联执行会话（跨模块）
Tasks (1) ──→ (N) StudySessions        任务归属会话（跨模块）
```

> 跨模块实体引用（不在本 DS 定义）：`Users`（账户域）、`Groups`/`GroupMembers`（群组域，切片 01）、`StudySessions`/`Attempts`（学习域，切片 02）——FK 引用，编译依赖通过框架 DI 注入。

## 存量差异标注（D02 DDL → TKWF 框架）

| # | 差异项 | D02 存量 | TKWF 要求（DG-05） | 处理建议 |
|:-:|-------|---------|-------------------|---------|
| ① | **主键类型** | `uuid` | `long Id`（硬性） | **沿用前序切片决策**：内部 `long Id`；外部关联、跨系统用 `Uid`（uuid 业务键）——实体表补 Uid 列（唯一索引），API/DTO 暴露 Uid |
| ② | **审计字段** | `CreatedAt/UpdatedAt`（TaskAssignments 原无审计列） | `CreateTime/UpdateTime` | 本 DS 已转化并补齐 TaskAssignments 审计列 |
| ③ | **枚举存储** | 小写（draft/active/closed/pending）+ 中文（分阶/自由/组卷） | PascalCase `"Active"/"Progressive"` | 本 DS 已转化；存量数据迁移映射（分阶→Progressive） |
| ④ | **错误码** | 数字域码 51xx | DG-06 默认 SNAKE_CASE | **沿用决策**：保留数字码 + 语义名双列（见 U01 错误码表） |
| ⑤ | **AllowRedo（是否允许重做）** | **D02 未定义**；`UNIQUE(TaskId, UserId)` 仅一条分配 | 框架无强制 | **本 DS 补充 `AllowRedo` 字段**（对齐 UI 配置步骤"是否允许重做"）；重做语义 = 已完成任务仍可进入复习（不改变 Completed 状态）——**实施前确认** |
| ⑥ | **任务状态 Draft** | D02 有 `draft` 枚举但无流转条件 | 无强制 | 本期创建即发布（Active），Draft 保留枚举值供三步向导暂存扩展——**实施前确认是否保留** |

> **字段覆盖校对（S/UI → DS）**：S01 场景与 UI 页面展示字段（任务名/截止时间/进度条/群主名、选题源题量、允许重做、预览题目、成员完成状态/用时/正确率、卡壳知识点、执行率/平均进度/逾期数/薄弱点 Top5、学生执行表列头、补救任务）——① 任务名/截止/进度 = Tasks.Title/DeadlineAt + TaskAssignments.Progress ✅；② 允许重做 = Tasks.AllowRedo（新增）✅；③ 成员完成状态/用时/正确率 = TaskAssignments.Status + Attempts 聚合（跨模块）✅；④ 卡壳知识点/薄弱点 = Attempts/KnowledgeMastery 聚合（跨模块）✅；⑤ 执行率/平均进度/逾期 = TaskAssignments 聚合（Service 层）✅
