## 各 Service 测试要点

| Service 类 | 重点验证 | 边界条件 | 注意 |
|-----------|---------|---------|------|
| `CreateTaskService` | 任务+全组分配原子性、群组 Owner 校验、题目归属 | 无成员群组/非法题库/重复发布 | 三步向导为前端编排，后端单次提交 |
| `ListTasksService` / `GetTaskDetailService` | 角色过滤（群主 OwnerId/学生分配）、详情聚合 | 任务不存在/越权 | 不按正确率排名（合规） |
| `ListMyTasksService` | 仅本人分配、已截止红标、无任务空态 | 截止后请求会话拦截 | 复用 6.6 数据，独立学生视图 |
| `GetOwnerDashboardService` | 执行率分母含全部、Top5 排序键、逾期数 | 无任务/无学生空态 | 学生执行表不按正确率排名 |
| `TaskOverdueScanJob` | 到期扫描幂等、未完成分配置 Overdue、AllowRedo 不阻断复习 | 无到期跳过/单任务失败 | 每日 0:00 + 发布时触发 |

## 存量差异与迁移决策（实施前置确认）

| # | 项 | 状态 | 影响 |
|:-:|---|:----:|------|
| ① | 主键 uuid → long Id | **沿用决策**：内部 long + 外部 Uid(uuid) | 实体表补 Uid 列（唯一索引）；API/DTO 暴露 Uid |
| ② | CreatedAt/UpdatedAt → CreateTime/UpdateTime | 本切片已转化（TaskAssignments 补审计列） | 迁移脚本改名/补列 |
| ③ | 枚举小写/中文 → PascalCase | 本切片已转化（draft→Draft、分阶→Progressive） | 存量数据映射 |
| ④ | 错误码 51xx + SNAKE_CASE 双列 | 本切片已采用（5101/5102 存量） | DG-06 附录迁移规则 |
| ⑤ | AllowRedo 字段 | **本切片补充**（D02 未定义，对齐 UI"是否允许重做"） | **实施前确认**：重做语义（已完成仍可复习，不改变状态） |
| ⑥ | 任务状态 Draft | 保留枚举值，本期创建即发布 | **实施前确认**：三步向导暂存扩展是否本期需要 |
