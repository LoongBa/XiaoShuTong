## 场景 1：群主布置任务（三步向导）

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-2.1 |
| 场景名称 | 群主创建并发布任务 |
| 关联 R 功能点 | R01-2.1 |
| 触发条件 | 群主进入任务创建页 |
| 前置系统判断 | 登录身份为群主；群组存在且为 Owner；群组有学生成员 |
| 涉众 | 群主 |
| 涉及端 | 群主 PC |
| 跨模块依赖 | 依赖题库（选题源）、群组（成员名单）、薄弱点（补救任务） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 | 对应UI图 |
|:----:|:--:|---------|---------|-------------|:--------:|
| 1 | 群主PC | 进入任务创建页，选择群组 | 展示三步向导第 1 步"选题源" | 创建页初始态 | tasks-create#1 |
| 2 | 群主PC | 选题源：官方题库/我的资料库/自由编排 → 勾选知识点（显示题量） | 选中项高亮 + 题量汇总 | 选题源选中态 | tasks-create#2 |
| 2a | 群主PC | （从薄弱点进入）一键生成补救任务 | 预填薄弱点对应知识点 | 补救任务预填态 | tasks-create#3 |
| 3 | 群主PC | 第 2 步"配置"：任务名（默认"背诵《XXX》"）+ 截止时间（明天/周末/自定义）+ 是否允许重做 | 字段校验：未选题/未定时"下一步"置灰 | 配置态 | tasks-create#4 |
| 4 | 群主PC | 第 3 步"预览发布"：预览题目示例（不含答案）+ 完整名单确认 | 预览题目列表 + 名单 | 预览确认态 | tasks-create#5 |
| 5 | 群主PC | 点"发布" | 发布中 loading（防重复）→ 成功 Toast + 可"分享到家长群" | 发布中 → 成功态 | tasks-create#6 |
| 6 | 群主PC | — | 自动为全组学生创建分配；跳转任务详情 | 跳转 tasks/detail | tasks-create#7 |
| N | — | — | 流程结束 | 停留详情页 | [定稿后填] |

### 异常路径

| 步骤 | 场景 | 处理方式 |
|:----:|------|---------|
| 1a | 群组无成员 | 空态"还没有成员，先去群组页导入名单发一次性邀请码" |
| 3a | 未选题/未定时 | "下一步"置灰 + 提示 |
| 5a | 发布失败 | Toast + 重试 |
| 5b | 已发布任务编辑（变更截止/题目） | 二次确认弹窗"将影响 N 名成员的任务进度" |

### UI 参考状态（给 UI 设计师）

| 状态 | 触发条件 | 展示内容 | 备注 |
|------|---------|---------|------|
| 初始态 | 进入创建页 | 三步向导第 1 步 + 群组选择器 | |
| 选题源选中态 | 勾选知识点 | 选中高亮 + 题量汇总 | 三 Tab 来源 |
| 补救任务预填态 | 薄弱点一键生成 | 预填薄弱知识点 | 看板下钻入口 |
| 配置态 | 第 2 步 | 任务名/截止快捷项/允许重做 | 默认"背诵《XXX》" |
| 预览确认态 | 第 3 步 | 题目示例（不含答案）+ 名单 | |
| 发布成功态 | 发布完成 | 成功 Toast + 分享家长群 | 跳转详情 |

## 场景 2：学生执行任务

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-2.2 |
| 场景名称 | 学生从首页任务卡进入执行任务 |
| 关联 R 功能点 | R01-2.2 / 2.3 |
| 触发条件 | 学生首页展示今日任务 |
| 前置系统判断 | 已登录且角色为学生；任务未截止（或允许重做） |
| 涉众 | 学生 |
| 涉及端 | 学生 H5 |
| 跨模块依赖 | 依赖学习 Session（执行会话）、题库（出题） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 | 对应UI图 |
|:----:|:--:|---------|---------|-------------|:--------:|
| 1 | 学生H5 | 首页查看今日任务卡（最醒目） | 任务名 + 进度条 + 截止时间 + 群主名 | 首页任务卡态 | home#1 |
| 2 | 学生H5 | 点任务卡 | 创建任务会话（taskId 关联）→ 进入执行页 | 跳转 /student/study/task | home#2 |
| 3 | 学生H5 | 逐题作答（复用判题流程） | 每次作答推进进度（已背 x/y） | 执行页进度更新 | home#3 |
| 4 | 学生H5 | 完成全部题目 | 分配状态 completed；进入结果页 | 跳转结果页 | home#4 |
| 5 | 学生H5 | 返回首页 | 任务卡进度 100%；完成庆祝 | 任务卡完成态 | home#5 |
| N | — | — | 流程结束 | 停留首页 | [定稿后填] |

### 异常路径

| 步骤 | 场景 | 处理方式 |
|:----:|------|---------|
| 1a | 无任务 | 引导卡"群主还没布置任务，先去自由背诵吧" + 按钮直达自由背诵 |
| 1b | 任务已截止 | 任务卡红色"已截止"标，进度条半透明；不可进入新会话 |
| 1c | 允许重做任务已完成 | 仍可进入复习（不改变已完成状态） |
| 2a | 任务会话创建失败（已截止/非成员） | 提示 + 返回首页 |

### UI 参考状态

| 状态 | 触发条件 | 展示内容 | 备注 |
|------|---------|---------|------|
| 任务卡态 | 首页 | 任务名/进度条/截止/群主名 | 最醒目 |
| 任务卡完成态 | 100% | 进度条满 + 完成标记 | |
| 已截止态 | 超期 | 红色"已截止"标 + 半透明进度条 | |
| 无任务态 | 无分配 | 引导卡 + 自由背诵按钮 | 三步式空态 |
