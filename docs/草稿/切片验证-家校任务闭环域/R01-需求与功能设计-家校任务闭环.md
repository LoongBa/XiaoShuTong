# 模块 2：家校任务闭环

## 模块描述

群主（教师）为群组布置背诵任务（选题源 → 配置 → 预览发布），系统自动为每位学生创建任务分配；学生在首页任务卡进入任务执行（复用学习会话），完成后回传进度；群主通过看板实时掌握全组执行情况（执行率/平均进度/逾期/薄弱点），可对薄弱知识点一键生成补救任务。任务闭环是"家校互动"核心主链路（群主布置 → 学生执行 → 家长看成长）。

---

### 2.1 布置任务（三步向导）

#### 功能描述

群主为群组创建背诵任务，经"选题源 → 配置 → 预览发布"三步完成；发布后系统自动为群组内所有学生生成任务分配。

#### 操作描述

1. 群主进入任务创建页，选择群组（多群组切换）
2. **选题源**：从官方题库 / 我的资料库 / 自由编排三个来源选题（勾选知识点，显示题量）；支持"从薄弱知识点一键生成补救任务"
3. **配置**：设定任务名（默认"背诵《XXX》"）+ 截止时间（快捷项：明天/周末/自定义）+ 是否允许重做
4. **预览发布**：预览题目示例（不含答案）+ 完整名单确认 → 发布
5. 系统创建任务（active）→ 自动为群组每位学生创建任务分配（待执行）→ 任务下发至学生首页

#### 约束条件

- 任务必选群组；群主仅可为自己的群组布置任务
- 任务名默认"背诵《XXX》"（可改，≤128 字）；截止时间必填（快捷项或自定义）
- 选题来源：官方题库（只读引用）/ 我的资料库（私有）/ 自由编排（知识点组合）
- 发布后自动为全组学生建分配（每任务每学生唯一）；名单为空时提示先导入成员
- 已发布任务变更（截止/题目）需二次确认"将影响 N 名成员的任务进度"
- 薄弱知识点一键生成补救任务（看板 Top5 下钻入口）

---

### 2.2 任务列表与详情（群主 + 学生视图）

#### 功能描述

任务列表按群组/状态展示；任务详情展示全组执行进度（每个成员完成状态/用时/正确率）与卡壳知识点聚合。

#### 操作描述

1. 群主查看"我布置的任务"列表（按群组过滤、状态过滤）
2. 学生查看"我的任务"列表（待执行/进行中/已完成/已逾期）
3. 点入任务详情：群主见全组执行进度（成员完成状态/用时/正确率）+ 卡壳知识点；学生见自己的任务进度
4. 任务已截止 → 红色截止标

#### 约束条件

- 群主仅见自己布置的任务；学生仅见分配给自己的任务（RLS）
- 详情展示成员**完成状态/用时/正确率**（不按正确率排名——合规红线）
- 卡壳知识点聚合（答错题目知识点归集）
- 学生执行详情复用执行页进度（已完成/剩余）

---

### 2.3 学生任务执行入口

#### 功能描述

学生在首页任务卡进入任务执行，进度实时回传；任务会话关联学习域执行流程。

#### 操作描述

1. 学生首页任务卡（最醒目）展示任务名 + 进度条 + 截止时间 + 群主名
2. 点任务卡 → 进入任务执行会话（跨模块：学习域创建会话，taskId 关联）
3. 每次作答回传进度（已完成题数/总题数）；全部完成 → 分配状态 completed
4. 任务已截止 → 卡红色"已截止"标，进度条半透明；不可再作答（允许重做时除外）

#### 约束条件

- 任务执行会话必须关联任务（taskId 必传，跨模块）；出题范围限任务题集（Tasks.QuestionIds）
- 每次作答同步推进分配进度；全部完成 → completed
- 允许重做 = true 时，已完成任务仍可进入复习（不改变已完成状态）
- 无任务首页展示引导卡"群主还没布置任务，先去自由背诵吧"

---

### 2.4 群主执行看板

#### 功能描述

群主按群组查看今日执行率、平均进度、逾期任务数、薄弱知识点 Top5，下钻任务详情/补救任务。

#### 操作描述

1. 群主进入看板，切换群组（多群组下拉）
2. 展示指标卡：今日执行率、平均进度、逾期任务数、薄弱知识点 Top5
3. 任务执行列表（完成率横向条 + 截止状态）+ 学生执行表（按完成度/坚持天数，不按正确率）
4. 点任务 → 任务详情；点薄弱点 → 下钻知识点名单 + "布置补救任务"

#### 约束条件

- 看板按 GroupId + TaskId 聚合分配表：执行率 = 已完成/总数、平均进度、逾期数、薄弱点（← 掌握度聚合）
- 薄弱知识点 Top5 排序键：建议按掌握度聚合正确率升序（最薄弱在前）——**Top5 与排序键需确认（D02 未定义）**
- 学生执行表**不按正确率排名**（合规红线）：按完成度/坚持天数
- 执行率低组警示文案用"加油"不说"落后"（合规措辞）

---

### 2.5 任务逾期处理（后台）

#### 功能描述

到期未完成的任务自动置逾期状态，逾期分配从首页待办移除并红标警示。

#### 操作描述

1. 系统按截止时间扫描进行中任务（超过 DeadlineAt 且仍 active）
2. 逾期任务对应未完成分配（待执行/进行中）→ 状态置为已逾期
3. 学生首页逾期任务红标"已逾期 N 天"；群主看板逾期数更新

#### 约束条件

- 逾期判定：DeadlineAt < 当前时间 且 任务 active（后台定时扫描，**机制需定义——D02 未定义**）
- 逾期分配从"待办"移除，不改变已完成分配
- 逾期任务仍可查看详情（历史保留）；允许重做 = true 时仍可进入复习
