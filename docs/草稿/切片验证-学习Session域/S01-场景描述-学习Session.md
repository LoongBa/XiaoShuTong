# S01 · 学习 Session 场景

> **所属模块**：模块 4（学习 Session 域）
> **前置条件**：R01-需求与功能设计-学习Session.md 已产出
> **路径选择**：学生端 H5 有 UI → 完整模板；错题展示页归属统计域（跨域引用，不展开）；记忆调度为后台任务 → [BackgroundJob]
>
> 本文档从 UI设计文档-v2 V2.2（/student/study/task 任务执行页、/student/study/result 结果页、/student/study/review 复习队列页、/student/stats/wrong 错题本）与 D03 V1.3 学习域 API 反推。

## 场景 1：学生执行群组任务背诵

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-4.1 |
| 场景名称 | 学生进入任务 → 一次一题作答 → 完成庆祝 |
| 关联 R 功能点 | R01-4.1 / 4.2 / 4.3 |
| 触发条件 | 学生从首页任务卡点击进入 |
| 前置系统判断 | 已登录（微信授权 [SDKStep]，Precondition=已取到用户身份）；任务未截止 |
| 涉众 | 学生 |
| 涉及端 | 学生 H5 |
| 跨模块依赖 | 依赖题库管理（取题）、AI 判题（判题回写）、任务域（进度回传） |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 | 对应UI图 |
|:----:|:--:|---------|---------|-------------|:--------:|
| 1 | 学生H5 | 首页点击任务卡（最醒目） | 加载中（骨架屏） | 任务卡 → 执行页加载态 | task#1 |
| 2 | 学生H5 | — | 创建会话 + 装载第 1 题，答题框聚焦 | 加载态 → 作答中态 | task#2 |
| 3 | 学生H5 | 输入/语音输入答案 → 提交 | "判题中…"转圈（≤1s 快判），禁重复提交 | 作答中态 → 判题中态 | task#3 |
| 4 | 学生H5 | — | 判题正确 → 绿色高亮 + ★点亮动画 + 鼓励语 | 判题中态 → 正确反馈态 | task#4 |
| 4a | 学生H5 | — | 判题错误 → 红色高标 + 正确句展示 +【再看一遍/下一题】 | 判题中态 → 错误反馈态 | task#5 |
| 4b | 学生H5 | — | 判题部分正确 → 黄色△徽章"快熟了" | 判题中态 → 部分正确态 | task#6 |
| 5 | 学生H5 | 点"想不起来？" | HintBubble 逐级加深提示（S1→S2→S3），≤20 字 | 作答中态 → 求助态 | task#7 |
| 5a | 学生H5 | 求助后作答 | 求助后答对 → 黄色△徽章（收益低于独立答对） | 求助态 → 部分正确态 | task#8 |
| 5b | 学生H5 | 直接看答案 | 不计入记录，进入下一题 | 求助态 → 作答中态 | task#9 |
| 6 | 学生H5 | 点"下一题" | 装载下一题 | 反馈态 → 作答中态 | task#10 |
| 6a | 学生H5 | 点"再看一遍"（错误态） | 原地重背本题目 | 错误反馈态 → 作答中态 | task#11 |
| 7 | 学生H5 | 中途退出（← 返回） | 进度增量已保存 | 退出 → 首页（进度保留） | task#12 |
| 8 | 学生H5 | 完成最后一题 | 自动进入完成庆祝 | 作答中态 → 完成庆祝态 | task#13 |
| N | — | — | 流程结束 | 进入结果页 S-4.2 | [定稿后填] |

### 异常路径

| 步骤 | 场景 | 处理方式 |
|:----:|------|---------|
| 2a | 任务已截止 | 任务卡红色"已截止"标，进度条半透明 → 提示后进入退出 |
| 2b | 题目加载失败 | 居中占位"题目加载失败" + 重试按钮 |
| 3a | 网络断开 | Toast"网络开小差了" + 重试按钮 |
| 3b | 判题超时（>3s） | 降级本地规则判定 + 提示用户 |
| 4c | 无记忆状态变化 | 判题后必须有状态视觉反馈，避免只弹"打卡成功" |

### UI 参考状态（给 UI 设计师）

| 状态 | 触发条件 | 展示内容 | 备注 |
|------|---------|---------|------|
| 加载态 | 进入页面/装载题目 | 骨架屏 + 判题中转圈 | |
| 作答中态 | 题目展示 | 题目 + 输入框 + 进度点阵（当前高亮） | 核心设计 |
| 判题中态 | 提交后 | 按钮 loading"判题中…" | 禁重复提交 |
| 正确反馈态 | 判题正确 | 绿色高亮 + ★动画 + 鼓励语 + 1.5s 后"下一题" | |
| 错误反馈态 | 判题错误 | 红色高标 + 正确句 + 记忆状态提示 +【再看一遍/下一题】 | |
| 部分正确态 | 求助后答对 | 黄色△徽章"快熟了" | |
| 求助态 | 点"想不起来？" | HintBubble 逐级加深 | ≤20 字 |
| 完成庆祝态 | 最后一题完成 | 完成动画 + 点亮 N 颗★ + 分享激励卡可选 | |

## 场景 2：查看会话结果

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-4.2 |
| 场景名称 | 会话结束查看本次背诵总结 |
| 关联 R 功能点 | R01-4.2 / 4.4 |
| 触发条件 | 会话完成（最后一题作答完毕 / 结束） |
| 前置系统判断 | 会话存在且属于当前学生 |
| 涉众 | 学生 |
| 涉及端 | 学生 H5 |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 |
|:----:|:--:|---------|---------|-------------|
| 1 | 学生H5 | 会话完成自动进入 | 庆祝动画 + 正确率大数字"背对了 8/10"（非百分比） | 完成庆祝态 → 结果页 |
| 2 | 学生H5 | — | 展示新增 ★ 数 + "下次重点复习"卡壳知识点列表（✕/△） | 结果页展示 |
| 3 | 学生H5 | 点"继续背" | 创建新会话 | 跳转任务/自由背诵 |
| 3a | 学生H5 | 点"返回首页" | 回到首页 | 跳转首页 |
| N | — | — | 流程结束 | 停留/跳转 |

### UI 参考状态

| 状态 | 触发条件 | 展示内容 | 备注 |
|------|---------|---------|------|
| 全对态 | 全部答对 | "全对！今天又是满分状态"强化庆祝 | 不给分数/排名 |
| 有卡壳态 | 存在 ✕/△ | 列出知识点 + "下次重点复习"区块醒目 | |
| 空会话态 | 未作答退出 | 不产生结果页，直接回首页 | 异常路径 |

## 场景 3：复习队列浏览与复习

### 场景概览

| 字段 | 值 |
|------|----|
| 场景编号 | S-4.3 |
| 场景名称 | 查看今日到期复习队列并执行复习 |
| 关联 R 功能点 | R01-4.5 / 4.4 |
| 触发条件 | 学生进入复习区块（有到期题目） |
| 前置系统判断 | 有到期复习项（NextReviewAt ≤ 当日）；★ 熟练项不纳入 |
| 涉众 | 学生 |
| 涉及端 | 学生 H5 |

### 场景流程

| 步骤 | 端 | 用户操作 | 系统反馈 | 页面状态变化 |
|:----:|:--:|---------|---------|-------------|
| 1 | 学生H5 | 进入首页复习区块 | 加载到期卡片列表（骨架屏） | 复习区块加载态 |
| 2 | 学生H5 | — | 展示到期卡片：知识点 + 状态色（△/○）+ 距上次复习天数 | 列表正常态 |
| 2a | 学生H5 | — | 逾期卡片红标"逾期 N 天"置顶 | 列表逾期态 |
| 3 | 学生H5 | 点卡片 | 进入复习会话（复用任务执行页判题流程） | 跳转 /student/study/task |
| 4 | 学生H5 | 复习作答 | 答对维持/升级；答错降级（✕），状态色即时更新 | 反馈态 → 队列刷新 |
| 5 | 学生H5 | 复习全部完成 | 空队列（列表清空） | 队列清空态 |
| N | — | — | 流程结束 | 停留/退出复习 |

### UI 参考状态

| 状态 | 触发条件 | 展示内容 | 备注 |
|------|---------|---------|------|
| 今日到期态 | 存在到期项 | 按状态色排序（△ 优先于 ○），"该复习了"标注 | |
| 已逾期态 | NextReviewAt < 今日 | 红标"逾期 N 天"，排最前 | 警示色不隐藏 |
| 无到期态 | 无到期项 | 复习区块整体隐藏，不占位 | 空态不展示 |
| 复习结果态 | 复习作答后 | 状态色即时更新 | |
