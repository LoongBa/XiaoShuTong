# UpdateTask 消费端接入 + O4 浏览器走查 - 开发方案（V0.8.1）

## 一、背景与版本规划

### 1.1 背景

依据 `docs/工作计划.md`（last_updated 2026-10-03）P0 候选推进（交接清单 🅰 项）：

- **A1 UpdateTaskService 消费端接入**：后端 Service 已闭环（`UpdateTaskService.cs`，任务编辑：标题/说明/截止/题集，BR-26/27/28 + 8 用例，492/0/2 基线），但 **AdminWasm / WebH5 双消费端零消费**——AdminWasm `TaskDetail.razor` 纯只读无编辑入口；WebH5 `teacher/tasks/detail.tsx` 无 edit；`ts-client.g.ts` 无 `updateTask_Execute` 契约（需 codegen）。

### 1.2 版本规划

## 二、任务 T1（A1-AdminWasm）：TaskDetail 加「编辑任务」

### 2.1 改动设计（参照 AiModels 编辑 Modal 蓝本 + TaskCreate 字段控件）

**编辑入口落点**：`TaskDetail.razor` 第一张 Card（任务头信息）——Card 标题右侧 `Extra` 加「编辑」按钮（对齐 AiModels 操作列「编辑」Link 按钮模式）：

```razor
<Card Style="margin-bottom: 16px;">
    <Descriptions Column="2" Bordered Title="@(_TaskDetail.Task?.Title ?? "任务详情")">
        @* ...既有字段不变... *@
    </Descriptions>
    <div style="text-align: right; margin-top: 8px;">
        <Button Type="@ButtonType.Link" Size="@ButtonSize.Small" OnClick="@ShowEditModalAsync">
            @("编辑")
        </Button>
    </div>
</Card>
```

> 注：AntDesign Blazor `Card` 无 Title 参数时 `Extra` 不可用——采纳 Oracle M5 裁定「独立工具行」（Descriptions 下方右对齐），避免结构不符（C4）。

**编辑 Modal**（AiModels 蓝本同构）：

```razor
<Modal Title="@("编辑任务")" Visible="@_EditVisible"
       OnOk="@OnEditOkAsync" OnCancel="@OnEditCancel"
       ConfirmLoading="@_Editing" OkText="@("保存")" CancelText="@("取消")">
    <Form Model="@_EditForm" Layout="@FormLayout.Vertical">
        <FormItem Label="@("任务名称")"><Input @bind-Value="@_EditForm.Title" MaxLength="128" /></FormItem>
        <FormItem Label="@("任务说明")"><TextArea @bind-Value="@_EditForm.Description" Rows="3" /></FormItem>
        <FormItem Label="@("截止时间")"><DatePicker @bind-Value="@_EditForm.DeadlineAt" Style="width:100%;" /></FormItem>
        <FormItem Label="@("题目集（题集变更将重算进度）")">
            @* CheckboxGroup 题集多选（TaskCreate 模式）：需先加载题库题目列表 *@
        </FormItem>
    </Form>
</Modal>
```

**`.razor.cs` 新增**（AiModels 模式）：

```csharp
private bool _EditVisible;
private UpdateTaskReqDto _EditForm = new();
private bool _Editing;
private BankListItemDto[] _EditBanks = [];
private string? _EditSelectedBankId;
private List<TopicNodeDto> _EditTopics = [];
private List<string> _EditAllQuestionIds = [];
private string[] _EditSelectedQuestionIds = [];

private async Task ShowEditModalAsync()
{
    // 回填：Title/Description/DeadlineAt/QuestionIds 直接来自 _TaskDetail.Task（TasksDto 契约已含 QuestionIds：Array<string> 非 null）
    _EditForm = new UpdateTaskReqDto
    {
        TaskUid = TaskUid,
        Title = _TaskDetail.Task?.Title,
        Description = _TaskDetail.Task?.Description,
        DeadlineAt = _TaskDetail.Task?.DeadlineAt,
        QuestionIds = _TaskDetail.Task?.QuestionIds,
    };
    _EditSelectedQuestionIds = _TaskDetail.Task?.QuestionIds ?? [];
    _EditVisible = true;
    await LoadEditBanksAsync();          // 加载题库列表 + 当前题集所属题库题目（M3：按 Task.BankId 预选 + Disabled）
}

private async Task OnEditOkAsync()
{
    _Editing = true; StateHasChanged();
    try
    {
        var svc = User.Use<IUpdateTaskService>();
        var res = await svc.Execute(_EditForm, CancellationToken.None);
        if (res.Success)
        {
            Message.Success(res.QuestionSetChanged ? $"已保存，{res.RecalculatedAssignments} 名成员进度已重算" : "已保存");
            _EditVisible = false;
            await LoadDataAsync();       // 刷新详情
        }
        else Message.Error($"保存失败: {res.ErrorCode}");
    }
    catch (Exception ex) { Message.Error($"保存失败: {ex.Message}"); }
    finally { _Editing = false; StateHasChanged(); }
}
```

**题集编辑交互**（Oracle 决策点闭环，见 §十一）：
- **M1 题集编辑 UI 形态**（采纳 A）：复用 TaskCreate 模式——题库下拉（**Disabled，BR-26 关联 BankId 不可变更**）+ CheckboxGroup 多选（需 `IGetBankDetailService` 拉题目列表 + 按 Task.BankId 预选 + 勾选当前 QuestionIds）。
- **M2 null=不修改语义**（采纳"原样回传 SetEquals 幂等"）：编辑 Modal 提交时若用户未触碰题集，仍传回原 `QuestionIds`（非 null）——服务端 SetEquals 幂等跳过重算（L70/L92-97），语义安全；若用户显式清空题集 → 传 `[]` → 实证 `questionSetChanged=true + recalcCount=0（不重算，L129 totalCount<=0 早退）+ QuestionCount=0`（Oracle C3 修正）→ 需二次确认"清空后任务无题目，已分配进度保持不变"。
- **M3 题库预选**（采纳）：编辑 Modal 打开时按 `Task.BankId` 预选（`bankId: string|null` L1481 需处理 null）+ 加载题目 + 勾选当前 `questionIds`（`Array<string>` 非 null，L1484，无需 null 兜底）。

## 三、任务 T2（A1-WebH5）：teacher 任务编辑页

### 3.1 改动设计

**入口**：`teacher/tasks/detail.tsx` 任务信息 Card 加「编辑」按钮（右上角）+ 跳转编辑页：

```tsx
<Button variant="outline" size="sm" onClick={() => navigate({ to: '/teacher/tasks/edit', search: { taskUid } })}>
  编辑任务
</Button>
```

**编辑页路由**：`teacher/tasks/edit.tsx`（file-based routing，`createFileRoute('/teacher/tasks/edit')` + `validateSearch: { taskUid?: string }`，对齐 detail.tsx 模式）。

**编辑页结构**（复用 create.tsx 模式，单页表单非 3 步向导——任务编辑仅 4 字段）：

```tsx
// 进入时并行加载：
// 1. taskDetail_Execute({ request: { taskUid } }) → 回填 title/description/deadlineAt/questionIds
// 2. listBanks_Execute({...}) → 题库下拉（选中 Task.bankId；**Disabled——BR-26 关联 BankId 不可变更**）
// 3. bankDetail_Execute({ request: { bankId } }) → CheckboxGroup 题目列表（勾选 Task.questionIds；type:'query' 直调安全）
// 保存（Oracle C1 致命修正：`update` 前缀命中 SDK MUTATION_PREFIXES → 必须走 sdk-bypass 绕行，直调必 400）：
import { executeQuery } from '@/lib/sdk-bypass';
import type { UpdateTaskResDto } from '@/gql/ts-client.g';
const res = await executeQuery<UpdateTaskResDto>('updateTask_Execute', {
  request: { taskUid, title, description, deadlineAt, questionIds },
});
// → 成功 navigate 回 detail（带 ?ts= 防缓存）或展示 res.questionSetChanged 提示
```

**字段表单**（对齐 create.tsx 控件风格；题集选择参照 AdminWasm TaskCreate.razor CheckboxGroup 交互逻辑 + shadcn Checkbox 自行组合——Oracle C2：WebH5 无 CheckboxGroup 既有蓝本，bankDetail 业务调用 0 先例）：

| 字段 | 控件 | 回填 |
|------|------|------|
| 任务名称 | `Input` | `task.title` |
| 任务说明 | `TextArea` | `task.description`（可为空） |
| 截止时间 | `Input type=date` + `resolveDeadlineISO`（复用 create.tsx L48-66 工具） | `task.deadlineAt` → 本地日期 |
| 题集 | 题库下拉（Disabled，BR-26）+ shadcn Checkbox 多选（bankDetail 题目列表） | `task.questionIds` + `task.bankId` |

**ts-client 契约依赖**：`updateTask_Execute` 需 codegen 后出现在 `ts-client.g.ts`。**纪律**：Agent 禁止自行导出 schema（buildSchema.ps1 需 WebApi 停止时执行）→ 实施时序依赖项目组/用户执行 `.\buildSchema.ps1` + `npm run gen-ts-client` + `npm run gen-mock`。**M4 裁定（先行编写 + 挂起）**：AdminWasm 先行（自包含，build 自动补契约）；WebH5 编辑页按预期契约先行编写 + typecheck（标注"运行时待 codegen"挂起）——注意 `executeQuery` 依赖 codegen 产物 `operationSelection['updateTask_Execute']`，codegen 前 typecheck 通过但运行时必崩（Oracle 风险补充）。

**G16 影响核查**：`updateTask_Execute` 无 create/remove 前缀 → SDK 不误判 mutation → **直调无需 executeQuery 绕行**（实证：ts-client.g.ts 中 accept/reject/list/get 前缀方法均为直调）。
