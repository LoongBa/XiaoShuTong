# 产品战略与定位（V1.1）

> **总纲**：帮老师、学生、家长**三方都减负——提质减负**。
> 站在家长的角度，做一款真正解决问题、有价值的产品。为自己的孩子负责，是质量底线。

---

## 一、核心定位

> **小书童 = 背书专用工具。专注做好"背书"这一件事——让孩子记得住、记得牢、记得快，让进度/弱项/成长清清楚楚。**
>
> 不做"泛学习平台"，不做"群组管理工具"，只深耕"背书执行力"这个垂直场景，把判定、调度、效率、报告四件事做到极致。

**一句话**：质量与体验第一，不流于形式。打卡 ≠ 背诵，功能 ≠ 价值——每条功能必须能回答"它真的帮孩子记住了吗"。

---

## 二、战略背景与动机

### 2.1 为什么是"背书"

| 判断 | 依据 |
|------|------|
| 古诗文背诗 App 已饱和（红海） | 现有"背古诗"类应用和题库已多，切入难 |
| **初中小三科（史地生）背书压力最大、无专用工具** | 背诵量大、知识琐碎、无现成数字化背诵检测——空白市场 |
| 每所学校有自己的内部资料 | 越好的学校教研投入越大，但老师缺工具让学生提高执行力 |

**结论**：切入"小三科背书执行力"——空白刚需 + 老师驱动 + 学校内部资料天然适合 PGC 供给。

### 2.2 为什么是"站在家长的角度"

第一个用户是**自己的孩子**——这意味着：

- 质量底线 = "我自己愿意让孩子天天用"，不是"比竞品强一点"
- 判题宽容度要调准（太严挫伤、太松误判）
- 背景钩子要真有趣，不是"AI 味"内容
- 不堆功能，只做"背书这一个场景的深度工具"

## 三、三方价值模型——提质减负

```
老师（传播节点，永远免费）
  减负：背书任务自动管理 + 学情看板自动生成（不靠人工批改）
  提质：按记忆曲线布置复习，看到全群组薄弱知识点
  动力：提升带班执行力/KPI，不在金钱

学生（使用主体，永远免费）
  减负：记忆曲线调度避免无效重复，背景钩子降低记忆门槛
  提质：分阶检索从"跟读→补全→默写"，卡壳有提示不是干背
  动力：PK/打卡/排名（指向努力度，不排正确率）

家长（付费节点，为知情付费）
  减负：成长报告自动生成，不用天天盯孩子
  提质：看见孩子进步趋势、薄弱知识点、相对进步（非单一分数）
  动力：为孩子成绩付费（10 元/月 / 100 元/年）
```

**核心解耦**：传播靠老师（零成本推荐，不碰钱），变现靠家长（为可视化报告付费），激励靠学生（PK 排名自驱约束）。三方动力各自独立、互相不阻塞。

## 四、产品内核：背书四件事

| 维度 | 产品承诺 | 不流于形式的证明 | 技术底座 |
|------|---------|----------------|---------|
| **记住了** | AI 逐字判背诵（错字/漏句/通假/添字） | 判题引擎"证明背了"而非"统计读了" | 三层判题引擎（规则+关键词+LLM）+ R1-R3 题型 |
| **记得牢** | 每知识点独立记忆曲线，到期必复习 | 复习不过自动降级 | 四阶状态机 ✕△○★ + FSRS 调度（D02） |
| **记得快** | 分阶检索 + 卡壳时背景钩子提示 | 222 张知识卡作为"记忆锚点" | 背景钩子 + hint 三级提示 |
| **清清楚楚** | 进度/弱项/成长可视化 | 报告让家长看见"相对进步" | memory_states + knowledge_mastery 聚合（D02 §四） |

**验收准则**（写入产品质检清单）：
> 如果孩子"打卡了但没记住"，产品就算没做完。判定必须证明"记住了"，调度必须保证"记得牢"，报告必须让家长看见"成长"。

## 五、使用模式：个人 + 群组双模式

```
模式 A：个人自愿（免费引流）
  学生自己选（语文/趣味/任意）→ 自由背 → PK/打卡/热力图
  价值：验证体验、积累留存

模式 B：群组任务（群主驱动，核心场景）
  群主建群组 → 上传/选资料 → 布置任务（截止时间）→ 发到家长群
  学生进入"任务清单"→ 按记忆曲线完成 → 群主看板看执行率
  价值：绑定群组（切换成本高）、锚定家长付费意愿
  内测机制：群主凭平台发放的内测邀请码激活建群；名单（手机号）经 Agent 整理生成一次性邀请码、导出 CSV 分发；成员凭码 + 微信登录激活，绑定微信 ID（与 §十"社交绑定"呼应，详见 D02 §四·补3）
```

**数据模型影响**：需在 D02 基础上扩展"任务"实体（`tasks / task_assignments`，关联群主-群组-学生-资料-截止时间），与现有 `study_sessions` / `memory_states` 打通但场景隔离（个人背 full 迁移、任务背也 full 但多"任务归属"维度）。

## 六、题库与内容策略

| 内容类型 | 定位 | 来源 |
|---------|------|------|
| **语文 + 趣味题** | 免费引流样本 | 官方题库（已建 3704 题） |
| **小三科（史地生）** | 主攻付费弹药 | **老师上传内部资料 + AI 预处理 + 人工校验**（PGC 工具链） |
| **英语/历史/地理** | 示例验证 | 已有示例题（10-12 题/学科） |

**内容供给策略**：

- 官方题库 = 冷启动底库（语文已够，小三科逐步补示例）
- **主攻的小三科内容靠老师供给**——每个学校有自己的内部资料，老师上传即建库
- "导入"不是用户端功能，是**生产端工具链**（AI 预处理 + 人工校验发布），放入供给侧建设

**PGC 两种场景**：

| 场景 | 优先级 | 公开性 | 版权风险 | 激励 |
|------|--------|--------|---------|------|
| 老师带自己班（私域） | **优先** | 不公开 | 低（老师原创编排） | 学生成绩/KPI（非金钱） |
| 其他人 PGC（订阅） | 后置 | 允许订阅 | 高（版权） | 押后到积累用户规模后再谈 |

## 七、商业模式

### 7.1 三端定价

| 端 | 免费 | 付费（10 元/月 / 100 元/年） |
|----|------|---------------------------|
| 群主端 | ✅ 永久免费（发布/看板/群组管理全部） | — |
| 学生端 | ✅ 全部功能（任务/背诵/PK/打卡/排名） | — |
| 家长端 | 基础页（今日完成度） | **成长报告**：进度/正确率趋势/薄弱知识点/坚持天数对比/多孩子/数据导出 |

**核心**：付费只买"家长知情权"，学生和群主的功能一个都不锁。传播零阻力，付费零功能门槛。

### 7.2 付费锚点设计

- 报告必须是"家长看了会续费"的内容：不是"正确率 87%"，而是**相对进步**——"本周比上周多背 3 篇、薄弱点从'唐朝'转向'五代十国'、群组排名从 23 上升到 15（努力度）"
- 报告含"AI 下一周建议"——让家长感到"10 块钱买了个懂孩子背书的家教"
- **广告**：学生端无广告（K12 合规，D06 已定不对 <14 岁推个性化广告），"去广告"不作为卖点

### 7.3 后续变现（阶段三评估）

- PGC 订阅（youtube 付费订阅 / b站充电 / 知识星球模式）——**必须避开直接订阅内容**（避免版权风险）
- AI 教研工作台高级功能

## 八、竞品与市场定位

### 8.1 两类对手（角色不同）

| 角色 | 对象 | 应对 |
|------|------|------|
| **产品竞品** | AI 学习工具（memo.cards / 智谱学习搭子 / Cortex / DeepTutor） | 已调研取证：不跟泛学习，只深耕背书。四者均无背诵场景（全库零 TTS/跟读/逐字判定） |
| **市场威胁** | 班级小管家类（进入门槛低，可能入场） | 用"背诵质量判定+记忆曲线+学生PK"的深度缝隙快速切入 |

### 8.2 班级小管家调研结论（缝隙实证）

| 维度 | 班级小管家（5000 万用户头部） | 小书童缝隙 |
|------|--------------------------|----------|
| 背诵任务 | "每日阅读"打卡模板 | 上传视频→人工打勾，**无 AI 逐字判** |
| 逐字判背诵 | ❌ 无 | ✅ 三层判题引擎 |
| 记忆曲线 | ❌ 无 | ✅ FSRS 调度 |
| 质量评估 | 只统计"发了/读了" | ✅ 判题结果驱动记忆状态 |
| 学生激励 | 学生被动接收 | ✅ 背诵专属 PK/连胜/★ |
| AI 能力 | 错题本/口语诊断/手环（2025 新增） | 不做广度扩张，只做深度背书 |

**关键事实**：
- 班级小管家的"跟读"是朗读不是背诵（照着读 ≠ 脱稿背）
- 教师端永久免费是其明确战略（官网"不收费"）→ 验证小书童"群主端免费"
- 它的 AI 能力是"功能点拼凑"（错题本/口语/手环），在**广度扩张**——小书童在**深度深耕**，心智错位即护城河

### 8.3 护城河

| 层 | 内容 |
|----|------|
| 内容质量 | 逐篇对照教材复核的题库（大厂粗放，小书童精细） |
| AI 判题体验 | 背诵判定（错字/通假/漏句的宽容度）+ 三层判题 |
| 私域积累 | V3"题库归用户、引用而非复制"——与公开题库模式错位 |
| 心智错位 | 它是"打卡工具"，我们是"背书专家" |
| 数据深度 | 判题结果+记忆状态+薄弱点（班级小管家只有"发了/读了"） |

## 九、长期路线（三阶段）

```
阶段一 MVP（现在）：背书执行力工具
  群主任务 + 学生 PK + 家长报告
  官方题库（语文引流 + 小三科示例）
  四端：群主端 / 学生端 / 家长端 / PC 后台

阶段二：接 Cortex 等能力 + PC 侧 RAG 增强
  群主端导入资料时 → AI 预处理（结构化/出背诵点/生成任务）
  = 成为"日常教研工具"（备课即建题库）
  候选技术：Cortex（FSRS-4.5 手写 60 行可移植）/ DeepTutor（GLM 原生适配）

阶段三：AI 教研工作台（粘性所在）
  帮老师/家长/学生"学习、集成、用好层出不穷的各类 AI 工具和教学资源"
  学校被供应商/社会热点裹挟尝试工具，但师资不专业+精力不足，难筛选用好
  = 小书童做"集成交付 + 数据沉淀"——学情/薄弱点是迁移成本
  变现：PGC 订阅（避开直接订阅内容）/ AI 工作台高级功能
```

**阶段二/三触发条件**：背书闭环验证 + 真实需求信号 + 架构允许插拔。MVP 不引入任何外部框架。

### 9.1 技术底座候选（阶段二评估，MVP 不引入）

| 项目 | 角色 | 价值点 | 短板 |
|------|------|--------|------|
| **Cortex** | FSRS 算法 + 闪卡 prompt 参考 | Apache-2.0、FSRS-4.5 手写 60 行可移植、文档→闪卡链路实证 | 桌面形态不兼容小程序、GLM 接入仅配置级（有 bug） |
| **DeepTutor** | GLM 接入参考 + 多 Agent 辅导 | zhipu 原生适配（ZAI_API_KEY 即用 GLM、国内端点）、Apache-2.0、38.7k⭐ | 重框架（多 Agent+多 RAG）、无背诵场景 |

**结论**：MVP 不引入。DeepTutor 的价值主要是证明"智谱 GLM 通过 OpenAI 兼容协议可做国内 AI 引擎"——这一点小书童判题/提示/点评三域现在就能直接用 OpenAI 兼容接口（火山引擎/DeepSeek/智谱等，供应商可插拔）实现，不需要等 DeepTutor。

## 十、贯穿原则与红线

### 10.1 贯穿原则

1. **为自己的孩子负责**——第一个用户是自己孩子，质量按"我愿意让孩子天天用"为标准
2. **不流于形式**——打卡 ≠ 背诵，功能 ≠ 价值；每条功能要能回答"它真的帮孩子记住了吗"
3. **帮助三方减负**——帮老师减负（任务管理自动化）、帮学生减负（避免无效重复）、帮家长减负（报告自动生成）
4. **快速切入 + 深耕体验 + 社交绑定**——市场威胁（班级小管家类）进入门槛低，必须快速切入并深耕

### 10.2 合规红线

| 红线 | 依据 | 对策 |
|------|------|------|
| 群主端永不收费 | 班级小管家官网"不收费"验证 | 群主端永久免费，无付费引导 |
| 不碰群组收款 | 班级小管家 2025 老师收款被教育局责令退款 | 平台只做家长-平台付费 |
| 报告不含群组成绩排名 | 班级优化大师 2023 被新华社曝光"诱导付费看排名" | 报告只给"相对进步+薄弱点+努力度" |
| 排名指向努力度 | 教育心理学共识 + 双减合规 | 排名 = 坚持天数 + ★点亮数 + PK 胜场，**绝不按正确率排名** |
| 不对 <14 岁推个性化广告 | D06 合规设计 + 广告法 | 学生端无广告 |
| 老师无分成（含间接） | 公立学校老师推荐付费产品的合规风险 | 老师任何形式返佣/分成都不做 |

### 10.3 时间窗约束

- 学校普遍不让带手机 → 小书童使用场景 = **放学后/晚上**（校外碎片时间）
- 任务时长设计：**一次 10-15 分钟**（契合"睡前/饭后"场景）
- 提醒时机集中在晚间
- 家长角色在家庭场景中比校内更重——强化"家长付费看报告"的合理性
